# 题目 T1 汇总

## 整体排序
| 名次 | 作品 | 级别 | 一句话理由 |
|---|---|---|---|
| 1 | T1-A | L2 | 三色版画，留白给时钟，叶片入日变暗的处理有记忆点；方向偏常见 |
| 2 | T1-E | L2 | 题材少见，窗光有记忆点；但满屏花纹偏吵，光的质感偏冷 |
| 3 | T1-B | L1 | 紫色层叠山日落，干净但是模板 |
| 4 | T1-C | L0（上限 L1） | 同类模板，还有硬边云带和孤立光点 |
| 5 | T1-D | L0（上限 L1） | 极光有阶梯色带，加上看不清的自我署名小字 |

## 关键两两比较
- **A vs E（相邻，同为 L2）**：在 D2 上 A 胜：A 顶部 750 px 空着，时钟可读；E 顶部也满是花砖。在 D3 上 A 胜：A 的朱红只用在一处；E 的光斑质感像雾。在 D8 上 E 胜：花砖窗光比红日芒草少见。按胜场数 A 2:1 领先。
- **E vs B（跨级）**：E 是 L2、B 是 L1，差在 D1/D8。E 有一个属于题材的瞬间（窗光）；B 的落日、层叠山、飞鸟放到任何"治愈"题都一样，D3 还是贯穿的紫渐变。
- **B vs C（相邻）**：同一套路，C 多了一个看得见的错误（硬边云带），所以 B 在前。
- **C vs D（同为 L0）**：C 的错误是局部的（天空中段几条云带），D 的错误落在主体本身（极光阶梯），而且还多了一个文字底线问题，所以 C 在前。

## 本题共同问题
- 三件（B/C/D）都落在"深蓝紫夜空/晚霞＋层叠山＋星光光晕"的同一组合里。
- 光晕星点、半透明叠层被当作"质感"来用，结果在 C、D 上直接产生了色带。
- 只有 A 认真考虑了锁屏时钟的留白。

# 整体观察

1. **深色底加发光几乎是动态画面的默认起点。** T1 有 3 件、T2 有 3 件、T3 有 1 件用的都是深蓝或深紫底，配星点、光晕、霓虹边缘。它们的问题也很一致：发光层是靠半透明叠层做出来的，一叠就出现阶梯色带（T1-C、T1-D），或者过曝成白（T2-C）。
2. **同一个题目会撞出几乎一模一样的作品。** T1-B 和 T1-C 都是"紫色晚霞＋层叠山＋三只飞鸟＋光晕星"；T2-C 和 T2-E 都是"球 → 环面 → 三叶结 → 螺旋"，加左下大写形名和 HUD 角标；T3-B 和 T3-E 都是"米白底 → 痛点问句 → 01/02/03 眉标 → 一个变色词 → 左字右机 → 深色 logo 尾卡"。这说明在需求模糊时，存在一个很强的"默认答案"。
3. **"眉标加变色词"在文字类画面里几乎是条件反射。** 凡是有标题的商业风作品，每一段都有宽字距小眉标和一个变色词。
4. **好作品的共同点是先找到对象里的一个物件**（稿纸格子、小票、账本、走马灯、花砖窗光），然后让动作或光线都从这个物件的规则里长出来。这几件都避开了上面的默认组合。但它们的弱点也一致：要么忘了交代对象本身（T3-A、T3-D 没有品牌），要么节奏只有一种速度（T2-D）。
5. **技术要求里"可循环"和"seek 可重复、可冻结"这两条容易被忽略**：C、E 的首尾不接，B、C 的 seek 有问题。而且这些问题集中出现在做法本身也最默认的作品上。
