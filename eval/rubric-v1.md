# 青出 · 评审评分表 rubric v1

> 给评审用。从**观众一侧**评作品的效果，不评"作品有没有按某个流程做"。作品附带的过程说明、方向列表、简报一律不作为加分依据——观众看不到它们。
> 适用：静态画面（如手机壁纸、海报、单张图）与动态画面（如网页动画、宣传动效、短片）。

---

## 0. 评审规则（先读）

1. **只看作品本身。** 评审只依据作品的画面、运动、声音（如有）和可交互表现。作品前面的"理解 / 方向 / 简报 / 自检"文字**不读或读后不计分**；作品自称做到了什么，不算证据，只看实际画面。
2. **不猜出处。** 不得猜测、讨论或记录作品出自哪个模型、哪个版本、用没用框架。评审意见里出现"这像某某模型做的"即作废重评。拿到的作品应已去掉标识、随机编号；如果仍能看到标识，评审时主动忽略并在报告里注明"已见标识"。
3. **同一题内：先各自定级，再排序。** 每件作品先独立地逐维度定级、写证据，全部定完后才开始横向比较和排序。定级阶段不看其他作品的结论，不因为"它比旁边那件好"而上调。
4. **每个级别必须附证据。** 静态作品给区域位置（如"左上 1/3 处标题"）；动态作品给时间码或帧号、交互步骤（如"00:02.4""窗口缩到 375 宽后"）。说不出证据的级别不成立。
5. **整体判断先于测量。** 先看一遍、写下整体印象和记住的画面（见 D1 的"先写后查"），再做测量。测量只能补充和修正，不能替代整体判断。
6. **按损害程度排问题，不按好不好修排。** 每条问题附一句具体修法。"整体不错，可以优化"不算意见。
7. **致命缺陷不被平均掉。** 封顶规则（第 3 节）优先于各维度的平均印象。
8. **不能评的写"未评"。** 拿不到证据的维度（例如听不到声音、无法运行）记"未评"，不估级；整件写成"≤X（待 Dn 补评）"。

### 0.1 评审前要准备的材料

| 作品类型 | 必备材料 |
|---|---|
| 静态画面 | 原尺寸图；缩小到目标设备实际观看大小的图；0.5 秒一瞥后的记录；如为竖屏图，另备一张叠上常见系统元素（时间、通知、底部图标或手势条）遮挡区的对照图 |
| 动态画面（视频） | 每秒 1 帧的联系表 + 每个段落边界前后各 1 帧；逐段时间线（起止、本段信息、画面事件、声音落点）；有声时的响度与静音区间 |
| 动态画面（可交互 / 浏览器内运行） | 至少两个窗口尺寸（如 1440 宽与 375 宽）下的录屏或逐帧截图；首帧出现时间；运行报错与资源加载失败记录；改变窗口尺寸后的表现；如有交互，记录每个交互步骤的结果 |

## 1. 五个级别（总定义）

| 级别 | 名称 | 一句话 | 观众的反应 |
|---|---|---|---|
| L0 | 坏 | 有观众看得见 / 听得出的错误 | 出戏、皱眉、关掉；读不完、看不清、跑不起来 |
| L1 | 能用 | 没有错误，但处处是默认值，一眼认出是机器或模板做的 | 看完没感觉，说不出它和别的同类有什么区别 |
| L2 | 商业合格 | 可以交付给付费客户：清楚、不拖、质感统一，挑不出硬伤 | "挺专业的" |
| L3 | 精品 | 每个选择都有意，删掉或换掉任何一处都会变差；至少一个记忆点 | 看完能复述出某一个画面或某一下 |
| L4 | 惊艳 | 意外但正确：观众没预料到、事后又觉得"只能这样" | "这怎么做的？"、回看、截图、转给别人 |

- **L0 与 L1 的界线是"错"**：可以指出、可以测量。
- **L1 与 L2 的界线是"默认"**：靠第 2 节每个维度的 L1 描述和第 4 节"AI 默认味"清单逐条勾选。
- **L2 以上无法写成规则**，只能靠"看到什么"的描述 + 两两比较。本表对 L3 / L4 只描述现象，不给配方。

## 2. 维度

每个维度：**看什么 → 底线测法（未过即 L0）→ 各级看到什么**。"静 / 动"标明适用于静态还是动态；不适用记 n/a，不参与合成。阈值都是起点值，记号：S = 画面短边像素，h = 正文字高。

### D1 第一眼吸引力与记忆点（静 · 动）

**看什么**：第一眼有没有把人抓住；看完能不能记住一个具体的东西；这个东西是不是从这件作品的内容里长出来的。

**测法**
- **先写后查**：评审第一次看完（静态看 3 秒，动态看一遍），在做任何测量前，不回看，写下记得的画面（≤ 3 条，每条一句）并封存，所有维度判完后再核对。
- **一瞥测试**：静态画面 / 动态作品的首个完整构图，看 0.5 秒后遮住，能否说出主角。
- **换主题测试**：把记住的那个东西换到另一个同类主题上，它还成立吗？成立 = 通用花招，不算记忆点。
- 本维度没有 L0 底线（没有记忆点不是错误）。

| 级别 | 看到什么 |
|---|---|
| L1 | 写不出任何记得的画面；或记得的是通用炫技（粒子爆发、光晕、旋转标志、故障风、发光渐变）。第一眼是"又一个这类东西" |
| L2 | 有识别度：看一眼能认出是这件作品；第一眼不乱；但说不出具体哪一处让人记住 |
| L3 | 至少一个被记住的时刻 / 局部，且它从这件内容里长出来——换个主题就不成立。第一眼就有一个清楚的抓手 |
| L4 | 意外但正确：第一次看到没预料到，回想时觉得只能这样；让人想回看、截图、转给别人那一下 |

### D2 构图与层级（静 · 动）

**看什么**：第一眼落在哪、第二眼落在哪，和作品要传达的一致吗；同一时刻是不是只有一个主角；元素之间的距离、对齐、尺寸差是"决定过的"还是"差一点"。

**底线测法**
- **主焦点唯一**：每个画面（动态取每段代表帧）都能指出一个主视觉焦点。有画面指不出（两个以上同等强度争夺）→ L0。
- **关键元素不被遮挡、不被裁切**：主体与须读文字不被装饰物、画框、系统元素遮挡区、窗口边缘裁掉 → 否则 L0。
- **模糊测试**：缩小或模糊到看不清字，能否依次指出主、次、分组（不过记 L1，不判 L0）。
- **事故区**：两个对齐 / 尺寸 / 间距之差 0 < 差 < 0.5h，"看得出差别又不像故意"，每处记一条问题。

| 级别 | 看到什么 |
|---|---|
| L0 | 指不出主焦点；关键元素被遮挡或裁切 |
| L1 | 信息都在但平铺：同大同亮，或处处强调；全部居中、每块同样边距；眼睛要自己找。或模板构图（居中大标题 + 副标题、左字右图、一排三卡） |
| L2 | 每个画面主次清楚，眼睛按设计的顺序走；强调只给真正的重点；留白和边距看起来是决定过的；没有事故区 |
| L3 | 视线被"带着走"：上一个落点的位置和方向自然引向下一个；留白在帮忙指路；空间分配本身有性格（极端偏置、出血、密排里一个例外等，且与内容咬合） |
| L4 | 构图制造了惊喜：眼睛被精确带到一个位置，答案在那里出现；回看时发现每一处安排都为这一刻服务 |

### D3 色彩与质感（静 · 动）

**看什么**：颜色和材质是从这件内容里来的，还是任何主题都能套的一套；强调色是否稀缺；材质是否可信。

**底线测法**
- **无可见色带、无压缩糊块**：大面积渐变在 100% 放大和目标设备尺寸下都看不出断层；暗部、渐变、运动段无块效应 → 否则 L0。
- **闪烁安全**（动）：任一秒内明暗大幅翻转 ≥ 3 次 → L0。
- **滤镜冒充媒介**（如矢量 + 笔刷纹理冒充水墨、噪点冒充印刷）：不判 L0，本维度最高 L1。

| 级别 | 看到什么 |
|---|---|
| L0 | 色带、糊块、闪烁超标；颜色让主要信息看不清 |
| L1 | 颜色无错，但是"默认的科技感 / 默认的清新感 / 默认的高级感"：蓝紫渐变、黑底霓虹发光、奶油纸 + 陶土、浅底 + 怯懦的蓝；处处毛玻璃、处处发光；渲染器默认材质；换任何主题都会是这套颜色 |
| L2 | 配色克制，主色与强调色分明，强调色只给重点；材质统一；在目标设备上看着舒服 |
| L3 | 色彩与质感是这件作品性格的一部分——换主题就不该用这套颜色；颜色有职责（章节、状态、唯一的例外）；细节质感（颗粒、纸纹、光的方向）一致而不喧宾夺主 |
| L4 | 一处色彩或质感的处理让人记住，并与内容意义咬合——看到那个颜色就想起那个意思 |

### D4 字体与文字可读性（静 · 动；无文字的作品 n/a）

**看什么**：读不读得清、读不读得完；字体和排版是不是这件作品的一部分。文字分三类："须读"（不读就带不走核心信息）、"可略读"、"装饰"。遮住测试：遮住这块文字，剩下的还能传达核心吗？能 → 可略读。

**底线测法**
- **零错字**：须读与可略读文字中，错别字、错数字、事实错误任一处 → L0。
- **对比度**：须读文字与其背后实际像素对比度 ≥ 4.5 : 1（大字 ≥ 3 : 1）；可略读 ≥ 3 : 1。动态背景取停留期内最差的一帧。不达 → L0。
- **最小字高**：须读文字字高 ≥ 短边 2.2%（静态）/ 2.5%（视频，约 27 px @1080）；可略读 ≥ 1.8%。不达 → L0。
- **停留够读**（动）：每块须读文字从落定（不再移动）到开始退场 ≥ 字数 ÷ 9 字/s，且 ≥ 0.83 s。不达 → L0。
- **读时不动**（动）：须读文字在读的期间仍在漂浮、晃动、逐字跳动 → 记问题；> 0.5 s 不可读的过渡态 → L0。

| 级别 | 看到什么 |
|---|---|
| L0 | 错字、看不清、读不完、被遮挡 |
| L1 | 读得完看得清，但字体字重是默认的（系统黑体、常见无衬线、"高级感"衬线、"技术感"等宽）；字是"放上去的"，与画面无关；标题上方加宽小眉标、一个变色强调词；渐变 / 描边 / 发光字；逐字打字机 |
| L2 | 层级清楚（标题、要点、注释一眼可分），相邻字级拉得开；字重克制；每块字落定后才需要读，读完才走；中英文、数字字体统一 |
| L3 | 文字本身是画面的一部分：字体、排版、出现方式都带着这件作品的性格；读的节奏就是看的节奏，观众不觉得自己在"读" |
| L4 | 一处文字处理让人记住——字的出现、变形或位置本身在说话，读到那一刻产生"原来如此" |

### D5 运动质感与节奏（动；纯静态 n/a）

**看什么**：东西动起来像不像有重量、有材质；大的小的、主的次的动法有没有区别；停下是落定还是卡住；整体有没有快慢落差；有没有"什么都没发生"的时间。

**底线测法**
- **首帧**：0.5 s 内出现有内容的画面；> 1 s 黑场或空背景 → L0。
- **无死时间**：画面不变且无新信息的区间 > 3 s（或 > 平均事件间隔 × 2）→ L0。
- **无卡顿**：连续运动中出现 ≥ 2 次单帧冻结；可交互作品明显掉帧、跳帧 → L0。
- **无频闪**：相邻帧位移远大于元素尺寸的一半且无运动模糊，读作一串拷贝 → 记问题，严重时 L0。
- **结尾**（视频类）：片尾黑场 + 静音 > 0.5 s，或无理由地长时间停在最后一帧 → L0；循环作品接缝明显跳变 → L0。可交互作品播放完毕后停在一个稳定、完整的终态是正常的，不算拖尾。

| 级别 | 看到什么 |
|---|---|
| L0 | 开头空、卡顿、死时间、接缝跳、结尾拖 |
| L1 | 运动无错，但所有元素像在同一条轨道上滑：同曲线、同时长、同时入场；或处处回弹、从 0 弹出；匀速直线；无动机的 3D 翻转与旋转；整屏持续缓慢放大；入场与退场是同一动作倒放；段落等长、全程同一速度，说不出哪里是高潮；背景粒子光斑无意义地飘 |
| L2 | 大与小、主与次的运动明显不同；落定干净，没有多余的抖；一次只有一个主角在动，其余错开；有明显起伏（至少一个峰、一处喘息）；停住时不死、也不乱飘 |
| L3 | 全片有一致的"物理人格"：观众感到这个世界里的东西有统一的重量与阻力；每种运动都在说一件事（出现、让位、被推开），没有为动而动；最重要的信息落在峰上，喘息在需要消化处；细节（停住后的微动、跟随、余波）都在 |
| L4 | 观众记住的是某个东西"怎么动的"；一次出乎预料的停顿、提前或落空抓住了人；换一种动法这个画面就不成立 |

### D6 叙事 / 信息清晰度（静 · 动）

**看什么**：观众看一遍能不能说出"这是什么、讲了什么"；重点是否得到更多时间和更强的落点；包装有没有淹没信息。纯氛围作品（无信息要传达，如以情绪为主的单张图）评"意图清晰度"：观众能否说出它想让人感到什么、它是关于什么的。

**底线测法**
- **复述测试**：给一个没看过需求的人（或独立评审，只看作品）看一遍，写下"它讲了什么 / 它是关于什么的"。与题目要求的核心对不上 → L0。
- **事实正确**：作品里出现的数据、名称、日期、引语没有编造或错误；图表比例诚实（柱高与数值成比例、比较项单位一致）。编造的用户数、评价、指标、标志 → L0。
- **有结构**（动）：多段内容时，观众知道讲到哪了；配音或文字讲第 N 点时，画面不停在第 N−1 点。

| 级别 | 看到什么 |
|---|---|
| L0 | 看完说不出是什么；有编造或错误的事实；图表误导 |
| L1 | 信息都在但每条一样重、平铺直叙；包装和信息分不开，记得"挺炫"但说不清讲了什么；空词（赋能、无缝、强大、一站式）；开头几秒没信息；结尾一句放之四海皆准的套话；同一句话在字幕、大字、口播里重复 |
| L2 | 一遍看懂；结构清楚；重点得到更多时间和更强落点；数字有比较对象；结尾有落点 |
| L3 | 展开方式本身让理解更容易——用变化、对比、拆解把一个难点"演"出来；每个动作 / 每处安排都在传递意思；作品明显是"关于这个对象的"，不是关于这一类东西的 |
| L4 | 一次揭示或一个可视化让观众真正"看见"了原本抽象的东西，理解的那一刻带来快感；看完想讲给别人听 |

### D7 完成度、一致性与细节（静 · 动）

**看什么**：像不像出自同一个在乎细节的人之手；同类元素是否同样子同动法；有没有半成品、占位、出厂值。

**底线测法**
- **无占位与半成品**：灰色占位框、"Lorem ipsum"、TODO、空白模块、明显没画完的部分 → L0。
- **同类元素一致**：把同类元素（所有标题、所有图标、所有卡片）并排比，字体、字号、颜色、位置有无理由的不一致 → 记问题；多处 → 本维度 L1。
- **无低清素材**：混入明显糊的放大素材、锯齿边、被拉伸的纹理 → L0。

| 级别 | 看到什么 |
|---|---|
| L0 | 占位、半成品、低清、拉伸 |
| L1 | 要么"一致"只是因为套了同一个模板（一致但没有性格），要么各段风格拼贴（前半扁平、后半写实；线性图标与面性图标、emoji 混用；三四种字体）；出厂值随处可见（默认阴影、默认圆角、默认滚动条和焦点框） |
| L2 | 一套视觉语法贯穿：同类元素同样子、同动法，观众很快学会"这种样子 = 这类信息"；边缘、对齐、间距干净 |
| L3 | 语法有性格，且在最关键的一刻被有意打破一次——那一下因为前面的一致而格外有力；放大看细节也经得住（光的方向、阴影、纹理、字距） |
| L4 | 规则被打破的那一刻成为记忆点；事后意识到前面所有的一致都在为它铺垫 |

### D8 原创性与"AI 默认味"（静 · 动）

**看什么**：这件作品有没有做出选择，还是落在"不费力就会做出来的那个样子"。用第 4 节清单逐条勾选，每条命中标范围：**局部**（只出现在一处 / 累计 ≤ 1/3 时长或面积）或**贯穿**（> 1/3）。

**判定口径**
- 任一**贯穿**命中，或**局部**命中 ≥ 3 条 → 本维度最高 L1。
- **同构检查**：作品的核心想法 / 记忆点与一个常见模板或流行套路同构（同一想法换皮）→ 本维度最高 L1，注明对照对象。
- **代入测试**：把作品对象换成同类的另一个对象，作品几乎不用改 → 本维度最高 L2。
- 本维度没有 L0 底线。

| 级别 | 看到什么 |
|---|---|
| L1 | 一眼"AI 做的"或"模板做的"：命中默认清单多条，或整体就是某个被做烂的组合（深色光斑 + 毛玻璃、黑底霓虹、奶油纸衬线陶土、渐变 + 居中标题 + 淡入） |
| L2 | 没有明显默认味；看得出做过选择；但方向本身是这一类作品里常见的那几种之一 |
| L3 | 方向少见且成立：观众不会预料到这个做法，而它明显属于这个对象；换成同类另一个对象就不成立 |
| L4 | 方向本身让人惊讶——第一次见这种处理用在这里，又觉得再合适不过；可以成为别人的参照 |

### D9 技术完整性（静 · 动）

**看什么**：作品能不能完整、稳定地呈现。只判"有没有错"，不判好坏（本维度最高写"通过"，在合成里按 L2 计，不拉高也不单独封顶以外的影响）。

**底线测法（任一未过 → 整件 L0）**
- **能打开、能运行、能渲染**：文件打不开、白屏、黑屏、渲染失败、只显示一部分。
- **运行报错**（可交互作品）：运行时报错、资源加载失败导致画面缺失或功能缺失。仅有不影响画面的警告记问题，不判 L0。
- **定位稳定**：在要求的尺寸 / 比例下，以及改变窗口尺寸后，元素不错位、不重叠、不溢出、不跳动；不出现回退字体闪烁、元素先出现在左上角再跳到位。
- **尺寸规格**：静态画面的尺寸 / 比例符合题目要求；在目标设备上观看时关键内容不被裁切或被系统元素遮挡。
- **性能**（动）：无明显卡顿、掉帧；不让设备明显发热卡死。
- **声音**（有声时）：无削波、爆音、断音、底噪；音乐不在乐句中途被截断。

| 级别 | 看到什么 |
|---|---|
| L0 | 任一项未过 |
| 通过 | 全部通过；记下所测尺寸、环境和任何警告 |

## 3. 综合判级

### 3.1 判级顺序

1. **看一遍，先写后查**（D1）：写下整体印象和记住的画面，封存。
2. **跑底线**：D9 全部项 + 各维度的底线测法。任一未过 → 整件 **L0**；仍继续评其余维度，结果写作"修好后的上限"。
3. **逐维度判级**（L1–L4，或 n/a、未评），每级附证据。判 L2 必须同时满足：① 该维度无"贯穿"的默认味命中；② "局部"命中 ≤ 2；③ 能写出 ≥ 2 条带证据的 L2 现象。任一不满足 → 该维度 L1。
4. **按 3.2 合成**整件级别。
5. **同题内两两比较**（3.3），确认 L3 / L4 并排序。

### 3.2 合成规则

| 整件级别 | 条件（全部满足） |
|---|---|
| L0 | 任一底线未过（D9 或任一维度的 L0 项） |
| L1 | 底线全过，但不满足 L2 |
| L2 | 所有适用维度 ≥ L2（D1 可为 L1）；D9 通过 |
| L3 | 所有适用维度 ≥ L2；D1 ≥ L3；D8 ≥ L3；L3 及以上的维度 ≥ 适用维度数的一半；两两比较确认 |
| L4 | 满足 L3；D1 = L4，且另有至少 1 个维度 L4；两两比较确认。缺用户本人的"惊艳"确认时记"L4 候选" |

**封顶（优先于一切平均印象）**
- D4 文字可读性或 D6 信息清晰度任一为 L1 → 整件最高 L1（看不懂的作品不是商业合格）。
- D8 为 L1（一眼 AI 默认味）→ 整件最高 L2，且不得进入 L3 候选。
- 整件级别不高于"最低适用维度级别 + 1"（D1 在 L1 时豁免此条）。
- 首屏 / 首个完整构图通不过一瞥测试 → 整件最高比 D2 的级别高一级。
- 未评维度不限制上限，整件写"≤X（待 Dn 补评）"。

### 3.3 两两比较与排序

- **一次只比两件，一次只问一个维度**："在 Dx 上哪一件更好？证据是？"不允许回答"差不多"，必须二选一。
- **盲比**：作品用随机编号，左右顺序随机；比较时不看各自已定的级别，只看作品。
- **排序**：先按整件级别分档；同档内用两两比较的胜场数排序；胜场相同时按 D1 → D8 → D6 → D2 的顺序逐维度比。
- **关键比较**必须写出理由：① 相邻名次之间；② 跨级的两件（为什么一件 L3、一件 L2）；③ 级别相同但名次不同的两件。每条理由要落在具体画面证据上。
- **两名评审分歧**：差一级取低者；差两级及以上引入第三名评审，取中位。

## 4. "AI 默认味"识别清单

勾选时每条标"局部 / 贯穿 / 未见"。命中不等于错——如果作品里能看出它是从内容推出来的（例如题材本身就是夜晚的霓虹招牌），可不计，但要在证据里写明理由。

**配色**
- [ ] 紫 / 靛渐变，紫→蓝、紫→粉；深蓝紫或深紫星空当"科技"底
- [ ] 近黑底 + 一个霓虹强调色 + 发光边缘 / 光晕；深底青色霓虹
- [ ] 暖奶油纸底 + 高对比衬线大标题 + 赤陶 / 铁锈强调
- [ ] 深青水面 + 波浪 + 居中白字
- [ ] 浅底 + 一个怯懦的默认蓝；白底黑字 + 一个饱和蓝按钮
- [ ] 按品类套色相（科技蓝、健康绿、AI 紫）
- [ ] 浮动模糊彩色光斑、极光 / 网格渐变团、文字后的径向聚光灯
- [ ] 品牌色撒满按钮、标题、图标、边框、背景

**字体与文字**
- [ ] 常见默认字当展示字（系统字、Inter / Roboto / Poppins 类）；"高级感"衬线；"技术感"等宽
- [ ] 标题上方加宽小号大写眉标 / 胶囊徽章
- [ ] 标题里一个词变色 / 斜体 / 高亮
- [ ] 渐变文字、发光文字、描边 + 投影叠满
- [ ] 逐字打字机、逐字跳动；字幕每句弹跳
- [ ] 空洞文案（赋能、无缝、强大、解锁、下一代；"不只是 X，而是 Y"；三连形容词）

**版式与表面**
- [ ] 居中大标题 + 副标题 + 两个按钮；左字右图分屏
- [ ] 一排三张"图标 + 标题 + 两行字"卡片；圆角便当盒网格；01/02/03 编号步骤
- [ ] 英雄数字块；灰条假仪表盘、假折线、进度环冒充内容
- [ ] 每块同边距同布局；全部居中
- [ ] 毛玻璃卡片（背景模糊 + 半透明白描边）；每张卡同一柔和投影 + 1px 边框
- [ ] 角落标签、HUD 边框、准星刻度等无信息装饰
- [ ] 无理由的斜面浮雕、仿金属、假玻璃
- [ ] 全屏均匀噪点 / 纸纹；滤镜冒充媒介

**图像与角色**
- [ ] 灰色占位、空渐变块、抽象形状代替真图；手绘浏览器栏 / 窗口"装箱截图"
- [ ] emoji 当图标；闪光 / 魔棒 / 星星代表"智能"；彩色方块里一个字母当标志
- [ ] 圆头大眼吉祥物、白壳机器人、长脸小球、火柴人、企业扁平小人
- [ ] 编造的用户数、评价、指标、logo 墙
- [ ] 流派符号套餐（落日网格棕榈、雕塑头像粉紫、红边祥云"中国风"、暖光植物猫咖啡"治愈"）

**运动与节奏（动）**
- [ ] 每块同一个上浮 + 淡入；只用透明度淡入
- [ ] 所有元素同时入场、同曲线同时长
- [ ] 处处回弹；从 0 缩放弹出
- [ ] 无理由 3D 翻转 / 旋转入场；推近后立刻拉回；全程缓慢放大
- [ ] 粒子、彩纸、光斑、镜头光晕、RGB 分离、抖动当"有活力"
- [ ] 鼠标跟随光斑、脉冲状态点、闪烁光标、自动跑马灯
- [ ] 背景大面积不动、只有中间一小块在动
- [ ] 每个切点交叉淡化；转场每次换一种花式
- [ ] 慢 logo 开场 + 结尾金句卡 / 结尾才揭晓主题

**声音（有声）**
- [ ] 通片轻松背景曲零静默
- [ ] 每个切点同一个"嗖"、每个事件同一个"叮"
- [ ] 每个场景"渐升 + 打击"；标志出现时一记重砸
- [ ] 音乐全程同一电平压人声；结尾一刀切

## 5. 按作品类型的补充检查

只补充"这类作品特有的观众侧问题"，不改变维度和合成规则。

**静态画面（如手机壁纸、海报）**
- 在目标设备的实际观看大小下看，不只看原图放大。
- 竖屏壁纸类：叠上系统元素遮挡区（顶部时间与状态栏、通知、底部图标或手势条）再看——主体和须读文字被盖住即 D2 L0；主体刚好躲开遮挡、并利用了留白的，可作为 D2 的 L3 证据。
- 多机型比例（如 9:19.5 与 9:16）裁切后，主体是否仍完整。
- 作为每天反复看到的画面：第二眼、第十眼是否还耐看、是否不吵（D1、D3 证据）。
- D5 记 n/a；带微动的静态作品可评 D5。

**动态画面 · 可交互（如网页动画）**
- 至少两个窗口尺寸（宽屏与窄屏）各看一遍；改变窗口尺寸后再看一遍（D9 定位稳定）。
- 首帧到出现内容的时间（D5 首帧）；加载期间是否有空白、布局跳动、字体闪烁（D9）。
- 运行报错与资源加载失败记录（D9）。
- 有交互时：每一步交互有没有及时、清楚的反馈；交互后的状态是否稳定、可回到初始。
- 动画结束后的终态是否本身就是一张成立的画面（D2）。

**动态画面 · 宣传动效 / 短片**
- 静音看一遍：不听声音也能懂吗（D6）？
- 首个完整构图出现前有没有空等（D5）；前 2 秒能否说出这是关于什么的（D6）。
- 时长是否符合题目；结尾是否落在对象身上（名称、标志、核心一句）且停留够读（D4、D6）。
- 有声时：声音是否给画面让路、落点是否对齐（D9 声音项、D5）。
