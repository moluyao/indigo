## 0. 本轮评什么

### 0.1 作品形态

第 3 轮的作品是**自包含 HTML 渲染出的成品**，只有两种形态：

| 形态 | 说明 | 评审拿到的 |
|---|---|---|
| 静态图 | HTML 渲染后截出的单张或多张画面 | 原尺寸 PNG；按评审卡显示方式缩到实际观看大小的图 |
| 无声动画 | HTML 按确定性时间轴逐帧录制的视频，没有音轨 | 成片 MP4；每秒 1 帧联系表 + 段落边界前后各 1 帧（动效标准 1.6）；切点表；代表帧原尺寸截图；须读文字事件表 |

- 评的是**渲染结果**，不是 HTML 源码写得好不好。源码只供自动检查读取元素坐标、字号、素材原生尺寸（各标准"有工程时"的测法），评审者不读源码做判断。
- 渲染结果白屏、黑屏、只渲染出一部分、运行报错导致画面缺块：按视觉 B-08（明显没画完的区域）判 L0。先由主控确认不是录制环节的问题；录制环节造成的（截早了、窗口尺寸设错、录制丢帧），主控重渲后再评，不记在作品上。

## 1. 盲评规则（先读）

1. **只看三样东西。** 成品评审只依据：作品本身（第 0.1 节的材料）、评审卡、自动检查结果。过程文件、方向列表、简报、自检记录、制作对话、提示词、HTML 源码一律不读。作品或评审卡自称做到了什么，不算证据，只看实际画面。
2. **不猜出处。** 不得猜测、讨论或记录作品出自哪个模型、哪个版本、用了什么框架或方法。评审意见里出现"这像某某做的""这是用了某某流程"即作废重评。作品、评审卡、自动检查结果都应已去掉标识、随机编号；评审卡上有暴露方法的字样，主控先删。如仍看到标识，主动忽略，并在评审卡抬头注明"已见标识"。
3. **同一题：先各自定级，再排序。** 每件作品先独立地跑底线、逐维度定级、打两个分、写证据；同一题的全部作品都定完，才开始撞车测试（第 6 节）和两两比较排序（第 7 节）。定级阶段不看同题其他作品，不因为"比旁边那件好"而上调。撞车测试之后只允许按第 6 节改动创意维度，并在卡上写明"撞车后调整"。
4. **两位评审互相独立。** 两位成品评审各用独立会话，各自完成全部评审卡和本题汇总，交卷前不看对方任何结论，也不看过程评审的结论。两人都交卷后再按 5.5 合并。人工测试的测试者（首看暂停、静音复述、三秒注视、代表帧测试）是另外的新会话，只拿到该测试规定的材料。
5. **先写后查。** 第一次看完（静态看 3 秒，动态静音全速看一遍），不回看，写下记住的画面（≤ 3 条）、一句话复述、动态作品再写"它在什么时候变了"，封存（视觉 4.1 第 1 步、镜头与叙事 1.5、动效 D11 协议）。几份标准共用这一次，不重复写。测量只能补充和修正，不能替代整体判断。
6. **每个级别、每个分数都附证据。** 静态给区域位置，动态给时间码或帧号。说不出证据的级别不成立。
7. **致命缺陷不被平均掉。** 各标准的底线、短板与封顶优先于整体好印象（第 5 节）。
8. **不能评的写"未评"，测不了的写"未测"**，按各标准 4.4（动效 1.8）处理，不估级；不适用的写 n/a。三者不混用。
9. **按损害程度排问题**，每条附一句具体修法，并指回该条目在标准里写的回炉章节。
10. **有意说明最后开。** 评审卡的有意说明在全部定级之后才打开，只用来解释测量数据，不改级别，不豁免底线。

## 4. 底线

### 4.1 规则

- **只引编号，不写数。** 每条底线的指标、阈值、测法、依据、回炉都在持有方标准里。共用事项一律记在持有方编号下（`standards/共用条目对照表.md`），同评时只测一次，报告写成"视觉 B-01（= 镜 B-09、镜 S-09、动效 B-18）"。
- **B 层（观众可感层）任一未过 → 整件 L0。** 共用条目记在持有方编号下，但它同时算作每一份引用它的标准的 B 层未过，所以几份标准的级别都是 L0。维度照评，写成"修好后的上限"。
- **T 层（交付技术层）未过 → 记"交付未过"，不判 L0**，不影响维度和级别，只在抬头单列，附修复方法（各标准 2.1）。录制环节造成的 T 项由主控重渲，不记在作品上（0.1）。
- **测不了写"未测"**，观众层状态写"通过（某某未测）"，不得写成"通过"（视觉 4.4、镜 4.4、动效 1.8）。镜 B-03 未测时，整件不得给 L3 及以上的结论（镜 4.4）。
- 条件条目（[静]、[动]、[信息流]、[循环]、[讲解]、[角色]、动效的形态条款）按评审卡判断适用；不适用写 n/a。

## 5. 两个分数与综合级别

### 5.1 判级顺序（每件作品）

1. 先写后查，封存（第 1 节第 5 条）。
2. 读自动检查结果：T 层列入"交付未过"；B 层自动项核对。
3. 跑需人工的 B 层（4.4），含不知情测试者的测试。任一 B 未过 → 整件 L0，列全部未过项与证据，继续往下评，写"修好后的上限"。
4. 按每份适用标准，逐维度定级（L1～L4、n/a、未评），按 3.2 计数口径判 L2。
5. 每份适用标准**各自**按本标准的合成规则得出一个级别：视觉 4.2、镜头与叙事 4.2、动效 3.2（含各自的短板与封顶）。
6. 按 5.3 合成成品综合级别；按 5.2 打两个分。
7. 同一题全部作品定完后：撞车测试（第 6 节）→ 两两比较与排序（第 7 节）。
8. 打开有意说明，只解释测量数据。

### 5.2 两个分数（1–5，每件作品单独打）

两个分只由成品标准的对应维度得出，需求理解的需 D3、需 D9 不进入（0.4）。

| 分数 | 来自 | 静态图 | 无声动画 |
|---|---|---|---|
| 创意与新鲜度 | 各标准的创意维度 | 视觉 D8 | 视觉 D8、镜 D12、动效 D14 |
| 执行与完成度 | 各标准的执行维度 | 视觉 D9 | 视觉 D9、镜 D13、动效 D15 |

**级别到分数**

| 分 | 创意与新鲜度 | 执行与完成度 |
|---|---|---|
| 5 | L4（含"L4 候选"） | L4（含"L4 候选"） |
| 4 | L3（维度级别；整件能否算 L3 另按 5.3 第 4 步做两两比较确认） | 同左 |
| 3 | L2（含命中第二层默认或同批撞车后被限在 L2 的） | L2 |
| 2 | L1：一眼默认，或命中贯穿的第一层默认 | L1 |
| 1 | L1 且同构检查命中（核心想法与已知模板或作品同构，视觉 D8、镜 D12、动效 D14 的同构检查），注明对照对象 | 整件 L0（任一 B 层未过）；括注"修好后 x 分"，x 按维度级别照上表 |

**无声动画的合成**：先映射出每个维度的分，再取**三者中最低**的那个作为该项分数（同一项被几份标准都管时取更严的结果，视觉 1.1），并把三个维度的分写在后面，例如"创意 3（视觉 D8 4 / 镜 D12 3 / 动效 D14 3）"。最低的那一层就是这件作品创意或执行上的短板，回炉单从它开始。

- 两个分**互相独立**：不得因为一项高而拉高另一项（视觉 D9、镜 D13、动效 D15 的"与创意分开看"）。整件 L0 只让执行分记 1，不动创意分。
- 第二层默认命中、同批撞车只扣创意分（第 6 节），不扣执行分。
- 维度未评 → 该分写"未评"，不估；其余能评的维度照算，并写"≤x（待某维度补评）"。

### 5.3 成品综合级别（L0–L4）

1. **L0**：任一适用标准的 B 层（含共用条目）未过。
2. 否则，**综合级别 = 各适用标准合成级别中的最低者**。静态图只有视觉一份，即视觉 4.2 的结果；无声动画取视觉、镜头与叙事、动效三者最低。声音 n/a、需求理解不并入，都不参与。
3. 各标准的短板与封顶已在第 5.1 步各自生效，取最低者时自动带入，不再另加。本轮最常触发的几条（只列编号，条件照原文）：视觉 D6 为 L1；镜 D1 为 L1；动效 D4 或 D10 为 L1 → 该份最高 L1。创意维度（视觉 D8、镜 D12、动效 D14）为 L1 → 该份最高 L2 且不进 L3 候选。代表帧或首屏过不了一瞥测试（视觉 4.2）、代表帧测试未过（镜 4.2）的封顶。各份的"最低适用维度 + 1"。动效 D15 为 L1 不豁免。
4. **L3**：每一份适用标准都达到本标准的 L3（含它要求的两两比较确认）。任一份只到"L3 候选"，综合写"L3 候选"，排序时按 L2 档计（各标准 4.2 / 3.2"候选在合成中按 L2 计"）。
5. **L4**：每一份适用标准都达到 L4 条件，且用户本人确认"惊艳"；缺用户确认写"L4 候选"。
6. **未评与未测**：某份标准有维度未评，该份写"≤X（待 Dn 补评）"，综合也写"≤X"。各标准规定"未评 / 未测时不得给 L3 及以上"的情况（视觉 D6、D8 未评；镜 D1、D12 未评或镜 B-03 未测；动效 D10、D14 未评），综合只能写"L3 候选（待补评）"。
7. **T 层不进合成**，只在抬头写"交付通过 / 交付未过：可自动修复 / 交付未过：需回工程"。

**抬头格式**（并列各标准要求的四件事）：
`整件 L_（修好后上限 L_）｜观众层：通过 / 未过 列编号 / 通过（某某未测）｜交付：通过 / 未过 列编号｜创意 _ 分 / 执行 _ 分｜视觉 L_ · 镜 L_ · 动效 L_ · 声音 n/a｜需求理解 L_ 或 n/a`

### 5.4 与评审卡目标级别对照

综合级别低于评审卡目标级别 → 回炉单只列拖住目标的维度，按差距从大到小（动效 3.2）。盲测本身不回炉，回炉单写进评审卡供复盘。

### 5.5 两位评审的合并

- 两人都交卷后才合并（第 1 节第 4 条）。合并由主控按规则做，不让两位评审商量改分。
- **级别**（综合级别、每份标准的级别、每个维度）：差一级取低者；差两级及以上，引入第三名评审（新会话、同样盲），取三人中位（各标准 4.3 / 3.3）。
- **两个分数**：同样处理，差 1 分取低者，差 ≥ 2 分引入第三名评审取中位。
- **B 层**：任一评审给出带证据的未过，主控按证据复测；复测确认 → 未过成立；复测不出 → 写"有争议"，由第三名评审独立复测定案。
- **第二层默认的"可到 L3"**：须两位评审都写出并认可"多走的那一步"（登记表"给评审看"一节），只有一人认可不算。
- 合并结果单列一张表，保留两人原分，不覆盖原卡。

## 6. 第二层默认与撞车

### 6.1 查表

- 视觉 D8、镜 D12、动效 D14 的"第二层默认识别"第 1 条，一律查 `standards/第二层默认登记表.md`（五份共用一张）。登记表正式收录的条目，加上它"各标准里写的初始条目（尚未按本表格式收录）"一节里列的条目，都按原文识别。
- 识别方法用登记表每条的"怎么识别"一栏和登记表的通用判别（换主题测试；只用于母题和外观，不用于结构原则）。
- **命中只扣新鲜度，不判错**：命中层的创意维度最高 L2；不进 B 层；不降低执行维度或任何其他维度（登记表"给评审看"、视觉 D8、镜 D12、动效 D14）。两位评审都写出并认可它"多走的那一步"时可到 L3，并把这一步写进证据。
- 命中写成：`第二层默认：登记表 #n（层）｜证据：位置或时间码 + 识别结果｜是否多走一步：是 / 否`。

### 6.2 同批撞车（始终要做，不能只查表）

登记表一旦被当成禁用清单，新的重复会出现在别处，所以每题都要做撞车测试（视觉 D8、镜 D12、动效 D14 第 2 条）。在同一题全部作品各自定级之后进行；跨题也做一次（同一批作品不同题目之间落到同一母题或同一骨架，同样算）。

| 层 | 做法（照原标准） | 判撞车 |
|---|---|---|
| 视觉 | 三层印象（标志层、一瞥层、结构层）并排分组测试：作品打乱，由不知情的分组者分堆 | 同批 ≥ 2 件分进同一组 |
| 叙事（动画） | 镜 D12 的"同批差异"三项：复述重合、画面错认、时间感 | 三中二 → 同批结构撞车 |
| 动效（动画） | 动效 D14：每秒 1 帧联系表 + 能量曲线，打乱后并排分组 | 同批 ≥ 2 件分进同一组 |

- 分组者是新会话，只拿到联系表或截帧，不拿到评审卡和任何级别。
- 撞车成立 → 组内每件在该层按第二层默认处理（6.1），卡上写"撞车后调整"，并改第 5 节的创意分。
- 撞车不是谁抄谁：组内各件都按同一规则扣，不因"做得更好"而豁免；可以按 6.1 的"多走一步"单独到 L3。

### 6.3 撞车组记录与登记表增补

- 每题汇总写一张"撞车组"表（第 9 节模板），跨题撞车另写一张。
- 同一个"聪明的第二选择"在同批独立作品里 ≥ 2 件撞车，或两位评审都指出的，按登记表"增补规则"写成候选新条目（现象 / 为什么会成为第二层默认 / 怎么识别 / 出处），交主控收录。单件不收。
- 候选条目只写现象和识别方法，不附作品截图，不写作品编号以外的任何出处。

## 7. 同题排序与两两比较

两两比较有两种用途，分开做：

**7.1 确认 L3 / L4（对标杆）**：照各标准 4.3（动效 3.3）——L3 候选对照同形态、同观看场景的 3 件 L3 标杆，胜 ≥ 2/3 确认；L4 候选对 3 件 L3 标杆全胜且对 L4 标杆不输。对标杆盲比必须二选一。标杆不足时停在"候选"，按 L2 档计。标杆由主控提供，评审不看标杆的出处。

**7.2 同题排序（作品之间）**

- 时机：同一题全部作品各自定级、撞车测试都做完之后（第 1 节第 3 条）。
- 盲比：作品用随机编号，左右顺序随机；比较时不看各自已定的级别和分数，只看作品。
- 一次只比两件、一次只问一个维度："在某维度上哪一件更好？证据在哪个位置或时间码？"必须二选一，不允许"差不多"。
- **排序规则**：
  1. 先按成品综合级别分档（L4 > L4 候选 > L3 > L3 候选按 L2 档 = L2 > L1 > L0）。L0 档内按"修好后的上限"再分。
  2. 同档内按两两比较胜场数排。每对比较至少问：创意维度、执行维度、各适用标准里"不进创意 / 执行"的最关键一维（静态图：视觉 D1；动画：镜 D1）。
  3. 胜场相同：先比创意分，再比执行分，再比各层分数之和，再直接问"整体哪一件更想再看一遍"并写理由。
- **关键比较必须写理由**，落在具体画面证据上：① 相邻名次之间；② 跨档的两件（为什么一件在 L3、一件在 L2）；③ 同档不同名次的两件；④ 创意分与执行分排序方向相反的两件（一件想法好执行差、一件执行稳想法默认，各标准都要求这两项分开看）。
- 需求理解一栏单独排序，只在附了过程文件的作品之间排，不与成品排序混合（0.4）。

## 8. 样稿内容口径

- **口径按视觉设计第 5 节**（五份标准共用的持有方），镜头与叙事、动效第 5 节只补本领域情况；**决定类的范围与判别问按需 B-06**。本表不另写。
- 评审照做的四件事：
  1. 真实世界的事实（真实品牌、人物、客户的数据和证言，真实产品能做到什么）编造了 → 视觉 B-10 / B-11 未过（动画同时是镜 S-10 / S-11、动效 B-13 / B-37）。
  2. 明显是示例的虚构内容不算编造；对照评审卡"样稿示例内容清单"。清单没列、但明显是示例的，评审补列，不扣分；看不出是示例、可能被当成真的，按视觉第 5 节"标注要贴着数据本身"判。
  3. 留空的填写栏、占位线、"待定"、空证据框 → 视觉 B-08 未过（豁免条件照视觉 B-08）。
  4. 示例同样要对：日期与星期、算式、单位、计数器终值与写出的总数（视觉 B-10；动效第 5 节的计数器条款）。
- **"发布前须用户确认"**：用需 B-06 的判别问逐项过一遍成品里的内容。评审卡已列的照录；未列的由评审补列、标"评审补列"、**不扣分**（共用条目对照表"决定类口径"一行：成品标准下评审卡未列由评审补列、不扣分）。漏标判 L0 只适用于需求理解一栏的替换表（需 B-06），不适用于成品级别。
