# T1 手机壁纸 · 过程

【理解】
原话：「帮我做一张手机壁纸。」
合同：手机壁纸；一张（静态）。格式（统一要求）：1080×2340 静态画面。
维度状态（只列非"已说"的）：
- 受众｜隐含｜手机主人自己。因为壁纸只给机主看。
- 目标反应｜空白｜交给发散；替定为"每次解锁瞥一眼都舒服，偶尔细看会发现做法"。
- 观看情境｜隐含｜一天亮屏几十上百次、每次不到 1 秒；上方压着锁屏时钟，下方压着图标和快捷键；手机屏本身是发光的。因为用途是手机壁纸。
- 材料与事实｜事实空白｜没有用户照片、名字。处理：不放任何文字、数字、标志，只用形状。
- 中心想法 / 外观 / 结构｜空白｜交给第 ③ 步发散。
- 禁止项 / 好的标准｜隐含｜上部要给时钟留干净区；图标区不能太花。因为壁纸上会叠系统界面。
替你决定的：不放字、不放日期（另一种可选：带一句自定文字的版本）；偏暗的整体明度，白色图标字更易读，OLED 也更省电（另一种可选：浅色版）。

【排除的默认】
默认：表面——紫蓝或粉橙的弥散渐变、模糊光斑、星空或极光；构图——居中一团抽象流体或远山剪影、上下对称；结构——静态一层。
变体：同一团渐变换成薄荷绿/日落橙。　反面：纯白底中间一个极细小几何图形的"极简"。

【方向】
① 字面：一幅竖幅风景插画（山、湖、天空）。（排除"抽象渐变"，但仍是常见壁纸品类）
② 伊斯兰几何镶嵌：一个八角星单元按对称铺满，越往上越稀，给时钟留空。（排除具象与渐变；结构=一个单元无限铺开）
③ 剪纸灯箱：把手机屏当成背后的灯，整张壁纸是一张深色剪纸，只有剪掉的地方透光；芦苇从底部长上来，一枚朱红"月"是透光的大孔，芦苇穿过它时阴阳反转（孔外是亮的缝，孔内是暗的纸桥）。（排除"发光=加辉光"，光只来自屏幕本身）——我平时不会这么做
④ 蜡染裂纹：三次靛蓝浸染的层次 + 蜡裂纹，下部一个大涡纹。（排除平涂与渐变，媒介=蜡防染）
距离：①与③同为植物/景物，但 L1 不同（①是"一处风景"，③是"屏幕是灯、壁纸是挡光的纸"），L2 不同（①一层画面，③两层：纸 + 光）。②与④L2 不同（铺开 vs 单一主体）。

【选择】
选了③剪纸灯箱。
契合在于：手机"屏幕本身就是背光"这个事实——剪纸窗花本来就是贴在光前面看的；它让大面积是暗纸、只有细缝发亮，正好让上方时钟区和图标区安静。
放弃了②几何镶嵌和④蜡染。
被放弃的在这些条件下更好：用户偏好不要具象、想要能无限裁切的图案时选②；用户要浅色、手作布料质感时选④。
借来的一个元素：从②借"只铺下半、上半留空"的密度分配（时钟区留空）。
方向承诺：
- 拥有的想法：屏幕是灯，壁纸是挡在灯前的一张剪纸；拒绝默认里的弥散渐变、光斑和辉光。
- 它自己的世界：一种深色纸 + 一种透过纸的暖光 + 只出现一次的朱红；孔边能看到纸的厚度（切口内壁）；没有任何发光特效。
- 第一眼：下部一枚朱红圆孔，芦苇从中穿过变成暗色剪影。

【简报】
受众：机主｜目标反应："这像真的一张剪纸贴在灯上。"｜观看情境：锁屏/桌面一瞥，上叠时钟与图标｜格式：1080×2340 静态，单 HTML，无外部资源。
做到什么算完：
1. 一瞥认得出主角。测法：看 0.5 秒遮住，问"画的是什么"。失败：说不出"芦苇/月亮"或"剪纸"。
2. 时钟区干净。测法：y 200–700 区域内透光面积占比 < 3%。失败：时钟落在花纹上。
3. 媒介可信。测法：每个孔是否都有一侧可见切口内壁、纸是否保持相连（没有悬空的纸块）。失败：像滤镜冒充剪纸。
4. 阴阳反转成立。测法：穿过圆孔的芦苇在孔内是暗纸、孔外是亮缝。失败：两边同色。
5. 格式。测法：画布 1080×2340、无网络请求。失败：任一不符。
必保项：朱红只此一处；孔内芦苇是暗色纸桥。
失败点：孔边锯齿或内壁方向不一致；底部图标区太亮太花。
不要：外观——渐变、光斑、辉光、纸纹噪点；结构——居中对称一团；内容——文字、日期、署名；技术——外链、字体依赖。
反向定位：它不是一张"好看的背景图"，它更像一扇贴了窗花的小灯箱。

【自检】
- 默认对照：过。无渐变、无光斑、无辉光；颜色只有纸、光、朱红三种（加一种内壁色），不像弥散壁纸。
- 禁用清单：过。#2 近黑底——用了深色纸，但没有霓虹与辉光，亮部来自"屏幕即灯"的内容理由；#31 纸纹噪点——未用，纸面平涂；只在透光处画了少量背衬纸纤维，这是背光看皮纸时真实可见的物理现象；#32 大面积不变纯色——上部留空是给锁屏时钟的功能区，理由来自观看情境。其余未命中。
- 代入测试：过。换成电脑横屏壁纸，"竖向芦苇从底部长、上部给时钟留空"就不成立。
- 必保项：过。朱红圆孔唯一；孔内芦苇为黑色纸桥（mask 中在圆内用黑色重画芦苇）。
- 事实：过。无文字、数字、标志、署名。
- 零错字：过（画面无字）。
- 完成标准 1：过。最大亮块是朱红圆，芦苇剪影在其中，主次清楚。
- 完成标准 2：过。最高的芦苇梢在 y≈760，它的花穗向下垂；y 200–700 内无孔。
- 完成标准 3：过。每个孔用"孔 ∩ 孔平移(-3,-4)"显示背光、其余显示内壁色，内壁统一在右下侧；芦苇孔都是开口细条、不形成闭环，纸保持相连；圆孔内的芦苇从圆外延伸进来，是连着外纸的纸桥。
- 完成标准 4：过。见必保项。
- 完成标准 5：过。SVG 1080×2340，纯内联脚本，种子随机（固定种子 1117）。
- 主焦点唯一：过。朱红圆面积与饱和度都最高。
- 模糊测试：过。模糊后：朱红圆（主）→ 下半部暖色细缝群（次）→ 上部暗纸（空）。
- 事故区：过。无文字；芦苇位置由种子随机，不存在对齐需求。
- 边距：过。圆孔 x 330–870，离左右边 ≥ 210px（> 70）。
- 颜色剂量：过。强调色朱红 1 处。
- 渲染：过（推理）。SVG 矢量无锯齿、无渐变色带。
- 多尺寸：过。主体在下半中部，等比缩放到不同机型或被裁两侧 100px 都不伤圆孔。
