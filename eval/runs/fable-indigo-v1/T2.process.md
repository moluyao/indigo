# T2 网页动画 · 过程

【理解】
原话：「做一个高质量的网页动画。」
合同：网页动画；高质量。格式（统一要求）：1920×1080，约 10 秒，可循环，`window.__seek(ms)` 确定性，自动播放，无声。
维度状态（只列非"已说"的）：
- 题材 / 对象｜空白｜交给发散。
- 受众｜空白｜替定：打开这个页面的普通人（可能是评审者）。
- 目标反应｜空白｜替定："字居然会给它让路，好巧。"
- 观看情境｜隐含｜浏览器里、横屏、无声、会循环看几遍。因为是网页 + 循环。
- 材料与事实｜事实空白｜没有任何品牌或数据。处理：画面里的文字由我原创，只讲画面里正在发生的事，不含任何事实主张。
- 中心想法 / 外观 / 结构｜空白｜交给发散。
- "好"的标准｜隐含｜"高质量"= 运动有因果、无坏帧、循环无缝。因为原话只给了这个形容词，落到可测的就是这三项。
替你决定的：用中文、用文字当主材料（另一种可选：纯图形抽象动画）。

【排除的默认】
默认：表面——深色底 + 紫蓝霓虹粒子网络 / 发光光球 / 渐变流体，ease-in-out 漂浮；构图——居中一团，或居中大标题 + 粒子；结构——10 秒同一速度的环境循环，无事件。
变体：同样的粒子换成暖橙或浅色底。　反面：白底上一个缓慢呼吸的圆点。

【方向】
① 字面：一个"网页首屏"英雄区动画——标题入场、按钮、卡片浮动。（排除抽象粒子，但仍是模板）
② 机械擒纵：一组齿轮和摆轮，严格周期运动，循环 = 机器的一转。（结构：物理驱动、天然无缝）
③ 孔版套印：两种油墨的几何版移动，重叠处出现第三色，套印错位在动。（媒介：孔版，叙事：色的生成）
④ 稿纸上逃跑的句号：一页方格稿纸写满字，末尾那个句号变大、滚出去，一路上字一格一格地给它让路（文字重排），落回原处，一切复原。——我平时不会这么做
距离：①④L1 不同（④的主角是一个标点、事件是重排）；②④L2 不同（②匀速周期，④静—滚—飞—蹦—静的事件链）；②③L1 不同。

【选择】
选了④逃跑的句号。
契合在于："网页"独有的材料是会重新排版的文字——文字绕开障碍、换行，是网页每天在做而视频不做的事；把这件事做成主角，就和"网页动画"这个对象绑紧了。稿纸让"一字一格"的重排看得见。
放弃了②擒纵和③套印。
被放弃的在这些条件下更好：需要纯图形、不想有文字时选②（循环最自然）；需要强烈色彩、做品牌视觉时选③。
借来的一个元素：从②借"物理一致"——滚动、飞行、两次弹跳用同一个重力加速度和递减的恢复系数，旋转角 = 位移 ÷ 半径。
方向承诺：
- 拥有的想法：一个标点出走，整页字给它让路；拒绝默认里的深底霓虹粒子和无事件的漂浮。
- 它自己的世界：浅绿灰稿纸、绿色方格、蓝黑墨水的楷体字；唯一的大物件是同一种墨水画的句号圆圈，粗细不匀（看得出它在转）；字只会一格一格地挪。
- 第一眼：整页写满的稿纸，右下角压着一个巨大的句号。

【简报】
受众：打开页面的普通人｜目标反应："字居然会给它让路。"｜观看情境：浏览器横屏、无声、循环｜格式：1920×1080、10 000 ms 一循环、`__seek(ms)`、固定种子（本作无随机数，全部解析计算）。
做到什么算完：
1. 第一眼说得出是什么。测法：看 0.5 秒问"这是什么"。失败：说不出"稿纸/句号"。
2. 重排看得懂。测法：在 2–4 s（滚动）任取一帧，句号环带压到的格子是否都空着、环内是否有字。失败：字和圆圈重叠，或环内永远是空的。
3. 有落差。测法：静 1.2 s → 加速滚 2.4 s → 大弧飞 2.6 s（峰）→ 两次递减弹跳 1.9 s → 静 1.9 s。失败：速度全程一样。
4. 循环无缝。测法：seek(9990) 与 seek(0)、seek(10) 画面一致。失败：接缝处任何元素跳动。
5. 读得完：静止段（0–1.2 s 和 8.1–10 s，合计 3.1 s）文字不动可读；正文字高 40px ≥ 0.033S=36px。失败：字在读时乱跳。
必保项：句号粗细不匀（旋转可见）；环内有字躲进去。
失败点：字溢出页面凭空消失；换行时的字跳动；循环接缝。
不要：外观——深底、霓虹、辉光、粒子；结构——无事件的环境循环；内容——编造的事实；技术——真实时间驱动 seek、随机数。
反向定位：它不是一段"背景动效"，它更像一页会动的绘本——字是群众演员，句号是主角。

【自检】
- 默认对照：过。浅色稿纸、无粒子、无辉光，有明确事件链，不像默认。
- 禁用清单：过。#10/#11 按主题选字——用楷体，理由是稿纸是手写的物件（物件同源），不是"文艺=楷体"；#3 暖奶油纸 + 衬线 + 赤陶——纸是浅绿灰、格是绿、墨是蓝黑，三项都不中；#38 逐字动——字只在被句号推开时挪格，静止段完全不动；#12 眉标——无。页脚"30×12＝360"是稿纸真实的印刷惯例，且数值与本页格数一致。
- 代入测试：过。换成"一张图片在网页里移动"，就不再有"标点出走、字让路"的意思。
- 必保项：过。句号描边宽度按 0.40–1.16 倍基宽变化，随位移旋转；内圈半径 ≥ 114px，正好容得下 2–4 个整格。
- 事实：过。正文为原创，只描述画面中的动作；无数字主张、无署名、无网址。
- 零错字：过。逐句核对正文 27 句共 260 字 + 2 个缩进空格。
- 完成标准 1：过。首帧即完整构图。
- 完成标准 2：过。格子判定：格子到圆心的最小距离 ≤ 外半径 + 6 且最大距离 ≥ 内半径 − 6 时空出；整格落在内圈里的照常写字。
- 完成标准 3：过。重力统一 g=568 px/s²：大弧高 480px 用时 2.6 s，两次弹跳高 110/28px 用时 1.245/0.628 s，落地速度 738→353→178 px/s。
- 完成标准 4：过。接缝在静止段，位置、角度、文字全部相同；平滑采样回看 140 ms 用取模时间。
- 完成标准 5：过。见上。
- 字溢出：过（推理）。360 格，句号最多压掉约 30 格，正文 262 格，余量 ≥ 60 格。静止时文字末尾约落在第 9 行、句号左侧。
- 第 0 帧：过。主角时序：过（唯一在动的是句号，字的挪动由它直接引起）。动作多样：过（滚、飞、弹、静；字的挪动 140 ms 平滑，比句号的运动短而小）。无死时间：过（最长静止 1.9 s+1.2 s 跨接缝合计 3.1 s，属于设计的谷，且是读字时间——略超 3 s，因静止段承担阅读功能，保留）。频闪：过（句号最大速度约 1090 px/s ≈ 18 px/帧，远小于 150px 半径）。闪烁：过（无明暗翻转）。
- 换行跳动：未过→已修。字从行尾跳到下一行行首无法平滑；同行内的挪格用"回看 4 个时刻求平均"做出滑动，跨行的保持瞬切（这也是真实排版的行为）。
- 技术完整：过。`__seek` 暂停自动播放并立即重绘；画面完全由 t 计算，无状态。
