# T3 过程 · 记账 App 15 秒宣传动效

【理解】
原话：「给一款记账 App 做一个 15 秒的宣传动效。」
合同：对象是"一款记账 App"；时长 15 秒；形态是宣传动效；技术合同 1920×1080、15.000 秒、`window.__seek(ms)` 可复现、自动播放、无声、单文件。
维度状态（只列非"已说"的）：
- App 名称、标志、功能、用户数、评分｜事实空白｜不编造。作品不依赖名字成立；页面支持 `?name=真名` 在结尾显示，不传则不显示任何名字。
- App 界面｜事实空白｜不画假界面（禁用 #24/#25）；改用记账这件事本身就是真的东西：小票、一笔一笔的流水、记账章。
- 受众｜隐含｜我推断是"会花钱但记不住花在哪的普通人"，因为记账 App 的用途就是记录日常开销。
- 目标反应｜空白｜替定："一天就花了这么多笔？——是该记一下。"
- 观看情境｜隐含｜我推断：信息流或应用商店里横屏自动播放、无声，因为合同要求无声；多数人只看一遍。
- 示例流水金额｜事实空白（但不是产品主张）｜作为"一个普通人一天的示例开销"出现，不声称是统计数据；合计按示例逐项相加 = 239.50，自洽。
替你决定的：不出现 App 界面和手机样机（另一种可选：拿到真实截图后做"产品自演"）。

【排除的默认】
默认：表面＝蓝紫渐变底、玻璃拟态卡片、金币飞散、饼图/折线、回弹弹出／构图＝正中悬浮一台手机样机，左右飘图标卡片／结构＝慢 logo 开场 → 三个功能卡（"一键记账/智能分类/报表分析"）→ 结尾 logo + "轻松记账，掌握财富"。
变体：同样结构换成绿色"理财感"配色；或换成扁平小人在手机前比划。
反面：纯黑底、只有一行白字"记账"慢慢淡入的"高级极简"。

【方向】
① 一卷小票：小票打印机把"今天"一笔一笔打出来，前两笔慢、之后越打越快，纸冒出画面；静一拍后打出合计，盖一个红色"已记"章，撕下，机器开始打明天。按"越来越快的关卡 + 一次停顿 + 一个落点"组织；排除了手机样机与功能卡。——我平时不会这么做。
② 真实时间：屏幕是一天的钟面，24 小时被压成 15 秒，每次付钱时钟面上闪一个点，最后点连成一圈。按"屏幕时间 = 事件时间"组织。
③ 借用别的品类：把一天的开销做成"天气预报"——"上午多云（咖啡），午后有阵雨（打车）"。按"借品类"组织。
④ 数据物理化：每一笔变成一枚落进玻璃罐的硬币，罐子越堆越满。按"数量有体积"组织。
距离检查：①（单据媒介，加速链）vs ②（钟面，时间映射）vs ③（播报品类，叙述）vs ④（实物堆积）——两两在 L1 或 L2 不同。

【选择】
选了①：一卷小票把今天一笔一笔打出来，越来越快，停一拍，合计，盖章"已记"，撕下，开始打明天。
契合在于：受众的问题是"钱花在哪了记不住"——小票就是每一笔钱留下的真实痕迹，"一笔接一笔越来越快"正好演出"一天里的零碎开销多到数不过来"；而"已记"章是记账这门手艺本来就有的物件，把 App 的作用（把一天收进账里）落成一个动作，不需要编造任何功能。
放弃了：②（钟面点阵抽象，静音下第一眼读不出"钱"）；③（文字量大，15 秒读不完）；④（硬币罐是理财/储蓄的语义，和"记录"不贴）。
被放弃的在以下条件下更好：App 主打"时间线"功能时选②；有配音时选③；App 主打储蓄目标时选④。
借来的一个元素：从②借"真实时间"——每一笔都带真实感的时刻（07:42、08:15……22:47），一卷小票同时就是一天的时间线。
方向承诺：拥有的想法——"今天被打成一卷小票，记下了就盖章撕走"；拒绝的默认——手机样机、功能卡三连、金币、渐变。它自己的世界：暗褐灰的台面、一台打印机、冷白的热敏纸、灰蓝的热敏字；全片只有一次红，就是那枚章；所有运动都是机械的——走纸一格一格、无回弹。第一眼：左边大字"今天 / 花了多少？"，右边打印机吐出一张小票的抬头。

【简报】
受众：花钱零碎、记不住去向的普通人｜目标反应："一天就花了这么多笔——是该记一下"｜观看情境：横屏信息流、静音、看一遍｜格式：1920×1080、15.000 秒、无声。
做到什么算完：
1. 第 0 帧就知道在讲"今天的花销"。测法：__seek(0) 看 0.5 秒。失败：说不出和钱/花销有关。
2. 节奏有落差。测法：行间隔 1200→150ms 连续缩短 ≥ 3 次（读得出加速）；7.3–8.0s 全屏静止；合计走纸 900ms（比快段慢 8 倍）。失败：说不出峰在哪。
3. 须读文字读得完。测法：钩子 7 字在屏 3.0s（需 ≥0.83s）；合计 8 字落定 8.9s→撕走 10.4s，1.5s；章"已记"9.1→10.4s，1.3s；结语 10 字 11.56→15.0s，3.4s。失败：任何一块低于下限。
4. 合计正确。测法：7+4+18+32+15+26.5+68+21+29+4+3+12 = 239.50，代码由数组求和而非手写。失败：数字不等。
5. 红只出现一次。测法：除章以外无任何红色像素。失败：多一处。
6. 可复现。测法：所有动画只依赖 t；印泥斑点用固定种子。失败：两次 __seek 同一 ms 结果不同。
必保项：走纸一格一格（步进）、红章一次、撕下后打出"明天"的同一笔早餐（变奏呼应）。
失败点：快段文字压在打印口上被遮（最新一行基线固定在 y=900，打印机顶 914）；数字换位时"笔"字跳位（数字右对齐到固定 x=640，"第""笔"不动）；撕纸瞬间跳帧（撕走用抽离曲线 650ms 连续移动）。
不要：外观——手机样机、渐变、金币、饼图、玻璃卡片／结构——logo 开场、功能卡三连、结尾金句卡夹心／内容——编造的 App 名、功能、用户数、评分、界面／技术——回弹、闪烁、文字边动边读。
反向定位：它不是一支"App 功能介绍片"，它更像收银台后面那台打印机记下的一整天。

【自检】
- 默认对照：过。全片无手机、无界面、无渐变、无功能卡，结构是"加速 → 停 → 落点 → 新一天"。
- 禁用清单：#10 系统默认字当展示字——合同要求只用系统字体，展示字用系统黑体粗体、靠尺度（150/320px）而非字体出效果，过；#11 等宽字——只用在小票上，热敏打印机本来就是等宽点阵字，物件同源，过；#18 大数字 + 小标签——"第 12 笔"的大数字是画面里真实在变的计数（随小票逐行加一），不是装饰数据，过；#23 结尾居中金句卡——结语左对齐、与右侧新一卷小票并存且仍有事件（12.8s 打出新一行），不是独立金句卡，过；#28 编造指标——无用户数/评分；流水金额标明是示例一天，过；#35 回弹——全片零回弹，过；#38 打字机逐字——小票是整行随走纸冒出，不是逐字跳出，过。
- 代入测试：把"记账 App"换成"外卖 App"——"盖'已记'章、撕下、打明天"只对记账成立，过。
- 必保项：步进走纸（每 16px 一格）、单次红章、明天的"07:40 豆浆油条 7.00"呼应开头"07:42 豆浆油条 7.00"——都在。过。
- 事实：无 App 名（默认不显示，?name 可传真名）、无标志、无功能声明；日期 2026-11-17 为周二、11-18 为周三，已核对。过。
- 零错字：今天 / 花了多少？/ 第 N 笔 / 今日流水 / 合计 / 共 12 笔 / 已记 / 花过的每一笔，/ 都记得。逐字核对。过。
- 第 0 帧：钩子大字 + 小票抬头 + 打印机，完整构图，无淡入。过。
- 主角时序：0–3s 钩子 + 慢打印；3–7s 打印为主、计数为联动配合者；8–9s 只有合计在走；9.1s 只有章；10.4s 撕纸为主、计数退场晚 100ms 且幅度更小；11s 结语；11.4s/12.8s 新一卷。每段唯一主角。过。
- 动作多样：走纸步进、数字翻牌 130ms、章沉入 180ms、撕纸抽离 650ms、文字停靠 350–420ms；入场（停靠）与退场（抽离）曲线不同。过。
- 无死时间：最长无变化区间 = 13.04s→15.0s 约 2.0s（<3s）；7.28→8.0s 静止 0.7s 是设计的停顿。过。
- 读得完：见完成标准 3。快段中间各行不要求逐行读（意义是"多"），首两行与合计可读。过。
- 落差：谷 = 7.3–8.0s 静止，峰 = 9.1s 盖章（E5，唯一红色、纸被压下 5px）。过。
- 频闪：撕纸最大速度 ≈ 1500×(终速倍数≈1.7)/650ms ≈ 3.9px/ms ≈ 65px/帧，纸长 >1000px，远小于其一半，无需模糊；全片无明暗翻转。过。
- 无坏帧：撕纸前后同一帧交接（T_TEAR 前用实时走纸量，之后冻结为同值 1198，位移从 0 连续开始）；数字翻牌新旧同帧交接。过。
- 结尾：15.0s 停在"结语 + 明天的小票打出第一笔"，最后事件在 12.8–13.04s，收住不拖。过。
- 技术完整：无外部资源；__seek 停止自动播放，ms 夹在 0–15000；自动播放到 15000 停在末帧。过。
- 字高：最小须读字 36px（≥0.033S=35.6px）；日期与"共 12 笔"30px 为次要信息。过。
- 对比度：米白大字 L0.95 对台面 L0.25、热敏字 L0.29 对纸 L0.96，均远超 4.5:1。过。
- 完成标准 1–6：逐条按上判，过。
