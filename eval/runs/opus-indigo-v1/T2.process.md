# T2 过程 · 高质量网页动画

【理解】
原话：「做一个高质量的网页动画。」
合同：网页动画、"高质量"；技术合同 1920×1080、约 10 秒、可循环、`window.__seek(ms)` 可复现、自动播放、无声、单文件无外部库。
维度状态（只列非"已说"的）：
- 题材 / 对象｜空白｜交给发散。
- 受众｜空白｜替定：打开这个网页的普通人，没有任何背景信息。
- 目标反应｜空白｜替定："这个我能一直看下去"——循环作品的成功标准是愿意多看几圈。
- 观看情境｜隐含｜我推断：浏览器全屏或大窗口、无声、会自动循环多遍，因为合同要求"可循环、无声"。
- 材料与事实｜空白｜无给定素材；只用本身就是真的东西（光学投影、机械旋转的物理）。
- "高质量"的标准｜空白｜按观众侧解释：循环接缝看不出、运动有物理原因、静帧也成立。
替你决定的：无文字（另一种可选：动态排版类，靠字撑画面）。

【排除的默认】
默认：表面＝深靛/近黑底 + 紫蓝或青色发光粒子、渐变光球、玻璃卡片，ease-in-out 缓动／构图＝正中一个旋转的发光 3D 几何体或一行渐变大字／结构＝粒子聚成形 → 散开 → 再聚，一条平滑缓动循环。
变体：同样的粒子换成暖橙色；同样的发光几何体换成线框球体。
反面：纯白底上一根黑线慢慢画圆的"极简"动画。

【方向】
① 走马灯：网页动画在互联网出现之前的样子——一盏走马灯，烛火的热气推动内筒旋转，剪纸马的影子投在纸罩上，正面清楚右行、背面隔纸淡淡左行。按"一个物理机关的无尽循环"组织；排除了发光几何体与粒子。——我平时不会这么做。
② 网页自己的事实：一段文字在不断变宽变窄的容器里回流，换行点不停重排，一个词在行间迁徙。按"同一主体的连续形变"组织，只用字。
③ 沙动画：一层沙在玻璃灯台上，手指（不出现）每帧在上一帧上推出新形，10 秒里从一条鱼变成一只鸟再回到鱼。按"每帧由上一帧变形"组织。
④ 等轴测微缩：一个小车站，列车 10 秒绕一圈，信号灯、道岔依次动作。按"孟菲斯式到处有小动作"组织。
距离检查：①（投影光学，旋转机关）vs ②（排版回流，连续形变）vs ③（手工媒介，形变链）vs ④（多焦点微缩场景）——两两在 L1 或 L2 不同。

【选择】
选了①：走马灯——纸罩上的剪纸马影，正面清楚右跑、背面隔纸淡淡左跑，10 秒转一整圈。
契合在于：合同里的"可循环"——走马灯本身就是一种"首尾相接"的机器，循环不是技术妥协而是它的天性；接缝处有物理原因（转了一整圈回到原位），观众不会察觉缝。
放弃了：②（只有字，在无声大屏上第一眼不够"高质量"）；③（沙画的逐帧形变在代码里难做到真的物理，容易变成滤镜冒充媒介）；④（多焦点，违背"每一秒一个主角"）。
被放弃的在以下条件下更好：作品要放在前端开发者社区时选②；有手工逐帧素材时选③；需要展示"系统运转"的产品时选④。
借来的一个元素：从②借"同一主体的连续变化"——马不是 6 匹不同的马，而是同一种剪纸形，靠圆柱投影的前后、远近、正反自己变出层次；其中只有一匹驮着骑手，作为唯一例外，让眼睛能追住"转了一圈"。
方向承诺：拥有的想法——"影子在转"；拒绝的默认——发光粒子/发光几何体/渐变光球。它自己的世界：一屋子暗，只有一盏纸灯是光源；所有运动都由一根轴的旋转产生（马、叶轮影、正反向），只有火苗自己在呼吸。第一眼：一盏暖色纸灯笼占满画面中央，上面黑色的马影在跑。

【简报】
受众：任何打开网页的人｜目标反应："这是走马灯——影子真的在转，后面那层还是反着走的"｜观看情境：浏览器大屏、无声、循环多遍｜格式：1920×1080、10.000 秒一圈、无缝循环、__seek 可复现。
做到什么算完：
1. 第一眼能说出"灯笼 + 马影"。测法：__seek(0) 截一帧看 0.5 秒。失败：说成"一个发光的方块"。
2. 看得出前后两层反向。测法：连续看 3 秒，问"后面那层往哪走"。失败：只看到一层。
3. 循环看不出缝。测法：__seek(9983) 与 __seek(0) 对比：所有周期量（旋转 1 圈、步态 20 步、闪烁频率 7/13/29、流苏 2 摆）都是 10 秒的整数分之一。失败：任何量在 10000ms 处不归位。
4. 运动有重量、有原因。测法：所有位移都能指出驱动源（轴转/火苗）。失败：出现无来由漂移或回弹。
5. 可复现。测法：同一 ms 调两次 __seek，像素一致（纤维用固定种子，无 Math.random、无真实时间）。失败：两次不同。
必保项：正面清楚、背面淡糊且反向；骑手那匹马唯一；火苗是唯一发光体。
失败点：背面影子与正面同样清楚（读不出深度）；马在圆柱边缘被横向压扁到 0 时闪一下（cos 阈值 0.02 处出入）；亮度闪烁过频。
不要：外观——发光粒子、紫靛渐变、青色线框／结构——聚散循环／内容——文字、logo／技术——闪烁、循环跳帧。
反向定位：它不是一个"科技感屏保"，它更像元宵夜里挂在门口的那盏灯。

【自检】
- 默认对照：过。暖纸、剪影、烛光，与"深靛 + 发光粒子 + 旋转几何体"无共同要素。
- 禁用清单：#2 近黑底 + 光晕——命中"暗场 + 一处发光"，理由：灯笼是故事里唯一的真实光源，墙上的暖光是它照出来的，除火芯外无其他发光元素，过；#8 径向光斑——墙面暖光与火芯都是有出处的真实光照，过；#32 大面积不变背景只中间动——灯笼宽 984/1920、高占满，墙面亮度随烛火同步呼吸，过；#36 无理由旋转——旋转是走马灯的工作原理，过；其余无命中。
- 代入测试：换成"旋转木马灯"——影子在纸上前后反向这件事只属于走马灯，过。
- 必保项：背面 alpha 0.30 + blur 9px、正面 alpha 0.84 + blur 1.6px；骑手只在 k=0；发光只在火芯。过。
- 事实：无文字、无数字。过。
- 零错字：无文字。过。
- 第 0 帧：__seek(0) 时正面有 3 匹马（θ=−0.35、0.70、−1.40），构图完整，无淡入。过。
- 主角时序：所有运动由同一轴驱动，属于一组配合者；正面中间那匹是焦点。过。
- 动作多样：大物（马群）匀速旋转、小物（腿）快周期 0.5s、火苗不规则、流苏慢摆 5s 周期，四种节奏。过。
- 无死时间：持续运动，无静止段。过（这是氛围循环，无须读文字）。
- 读得完：无须读文字，不适用。
- 落差：本作是"无峰平台"型氛围循环（写明理由：走马灯没有高潮，它的价值是可以一直看）；落差由正面中央快、边缘压扁变慢的视速度变化提供。过。
- 频闪：正面中央速度 R·ω = 470×0.628 ≈ 295px/s ≈ 4.9px/帧，远小于马身一半（≈150px），无需运动模糊；亮度变化 ±7.5%、最高 2.9Hz 的正弦，不构成明暗翻转。过。
- 无坏帧：马在 cos=±0.02 处切换前后层，此时横向缩放 ≈0.016，宽度 <5px，切换不可见。过。
- 循环接缝：所有周期量为 10 秒整数分之一，速度跨接缝变化 0%。过。
- 技术完整：无外部资源；__seek 停止自动播放并渲染指定 ms；ms 取模 10000。过。
- 完成标准 1–5：逐条按上判，过。
