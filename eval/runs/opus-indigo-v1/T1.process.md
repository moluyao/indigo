# T1 过程 · 手机壁纸

【理解】
原话：「帮我做一张手机壁纸。」
合同：手机壁纸；技术合同 1080×2340 静态、单个自包含 HTML、系统字体、无外部资源。
维度状态（只列非"已说"的）：
- 题材 / 对象｜空白｜交给第 ③ 步发散比较。
- 受众｜隐含｜我推断是"手机的主人自己"，因为壁纸只在本人手机上显示。
- 目标反应｜空白｜替定："看久了还能发现新东西，不腻"。
- 观看情境｜隐含｜我推断：每天解锁几十上百次、每次不到 1 秒；锁屏上方被时钟压、主屏中间被图标网格盖、底部有手势条，因为这是手机系统界面的固定结构。
- 材料与事实｜空白｜用户没给照片或物件；只用本身就是真的东西（几何、材料物理、光的反射）。
- 格式｜已说（技术要求）｜1080×2340 静态。
- 中心想法 / 外观 / 结构｜空白｜发散比较。
- 禁止项 / 好的标准｜空白｜按观看情境推：不能有须读文字；时钟区和图标区不能有抢焦点的东西。
替你决定的：无文字、无品牌；画面"耐看重复型"而非"一眼看完型"（另一种可选：单一大图像海报型，一眼惊艳但第三天就腻）。

【排除的默认】
默认：表面＝蓝紫/粉紫渐变或弥散光斑、星空、玻璃拟态卡片／构图＝画面正中一个发光抽象形或山海剪影，上下留空／结构＝一张图一个焦点放正中。
变体：同样的渐变换成青绿或日落橙；同样的山海换成极光。
反面：纯黑底 + 一条细线的"极简"壁纸（暗与空，同样是没做选择）。

【方向】
① 釉面砖墙：一整面手工切的摩洛哥式釉砖（八角星镶嵌），唯一的光是一扇窗在釉面上的倒影，被一块块砖打碎成不同偏移的碎片。按"一个单元无限铺开 + 一束光"组织；排除了渐变与"正中一个主体"。——我平时不会这么做。
② 时钟让位：从"锁屏时钟必然压在上方"这条事实出发，画面是一张竖向的日晷/影子图，上 1/3 留给系统时钟当"指针"，下方是一根长影子。按"和系统界面合作"组织。
③ 孔版双色套印：荧光橙 + 中蓝两版错位叠出第三色，一个巨大被裁切的单一母题（如一片叶）出血两边。按"单一母题 + 出血"组织。
④ 竖向绘卷：一条竖长的水墨山溪，从顶到底时间连续流动、云遮换景，图标落在留白处。（需求字面画面的方向，只占这一个。）
距离检查：①（材料+光，镶嵌结构）vs ②（与系统界面合作，单影子结构）vs ③（印刷媒介，单母题出血）vs ④（长卷时间结构）——两两在 L1 或 L2 不同。

【选择】
选了①：一面手工釉砖墙，唯一的光是一扇窗的倒影，被砖块打碎。
契合在于：壁纸会被"图标网格"盖住、每天被看上百次——镶嵌图案本身就是网格，图标盖上去不打架；而"每块砖的釉色、倒影偏移都不一样"这件事，正好给"看久了还能发现新东西"提供材料（目标反应）。
放弃了：②的日晷想法（锁屏各家时钟位置/字号不同，合作对象不确定，猜错整张作废）；③的套印（一眼强，但第三天就腻，不符合高频观看）；④的绘卷（图标盖上去会切碎画面主体）。
被放弃的在以下条件下更好：已知用户机型和锁屏样式时选②；用作单次展示的海报而非日常壁纸时选③；用户只用锁屏、不放图标时选④。
借来的一个元素：从②借"让出时钟区"——倒影放在画面中下偏右，时钟所在的上 1/3 只有安静的暗釉。
方向承诺：拥有的想法——"手工釉砖上被打碎的一扇窗"；拒绝的默认——渐变/光斑/正中发光主体。它自己的世界：深绿与钴蓝的手工釉、浅灰水泥缝、每块砖都略不同；唯一的暖色是窗的光，而且是碎的。第一眼：中下部一块被切成很多片的暖色窗影，认出"这是墙上映着的窗"。

【简报】
受众：手机主人｜目标反应："这是瓷砖上映的窗啊——每块砖都不太一样"｜观看情境：每天上百次、每次 <1 秒、被时钟和图标覆盖｜格式：1080×2340 静态，无文字。
做到什么算完：
1. 一瞥认出窗。测法：看 0.5 秒后遮住，问"中间那块亮的是什么"。失败：说成"光斑/抽象图形"。（窗必须有十字窗棂、四格。）
2. 时钟区安静。测法：上 1/3（y<780）内无暖色、明度变化幅度只来自釉色窑变（ΔL ≤ 0.09）。失败：上方出现倒影或高对比元素。
3. 看得出是"手工"而非平铺贴图。测法：任取相邻两块同类砖，釉色明度不同；倒影碎片偏移不一致。失败：所有砖同一色值。
4. 有自己的样子。测法：遮住，问"这能是任何一张壁纸吗"。失败：像渐变/光斑壁纸。
必保项：窗的十字窗棂；倒影按砖块断开、各自偏移；灰缝压在倒影之上（水泥不反光）。
失败点：大面积色带（本作无大渐变）；倒影边缘生硬像贴图（加 3px 模糊）；灰缝与砖边留出缝隙露底（顶点抖动 1.3px < 灰缝半宽 2.5px）。
不要：外观——渐变、光斑、玻璃卡片、发光／结构——正中一个主体／内容——任何文字、logo、伪造的签名／技术——锯齿、色带。
反向定位：它不是一张"抽象氛围图"，它更像你家浴室墙上下午四点的那几分钟。

【自检】
- 默认对照：过。成品是满幅手工砖墙 + 碎窗影，与"渐变/光斑/正中发光"无共同要素。
- 禁用清单：#2 近黑底+光晕——未命中（砖面中等明度，光是有出处的窗倒影、只一处）；#8 光斑/网格渐变——未命中；#31 全屏均匀纹理——检查：砖墙是结构不是滤镜，釉色变化按"每块各烧"的物理来，过；#32 大面积不变背景——壁纸为静态，且每块砖各不同，过；其余无命中。
- 代入测试：把"手机壁纸"换成"桌面壁纸"仍可用——但想法的核心来自"被图标网格覆盖 + 高频短看"，横屏桌面图标稀疏，选择理由不再成立。过（作品层面成立，选择理由属于手机）。
- 必保项：十字窗棂（bar 22px）、按砖块断开偏移（±13/±11px）、灰缝最后绘制——都在。过。
- 事实：无数字、无文字、无标志。过。
- 零错字：无文字。过。
- 一瞥测试：唯一暖色区在中下部，面积约 430×660，十字结构可辨。过。
- 主焦点唯一：只有窗影是暖色和高明度，其余为暗釉。过。
- 模糊测试：模糊后是"暗绿底 + 一块四格亮影"，主次清楚。过。
- 事故区：几何严格，抖动 1.3px 被 5px 灰缝吞掉，不出现"差一点"的错位。过。
- 字高 / 对比度：无文字，不适用。
- 边距与安全区：图案左右边缘正好切过星心，左右对称；窗影 x 范围约 454–976（含斜切），离左右边 ≥ 70px；y 1150–1810 避开顶部时钟和底部手势条。过。
- 颜色剂量：单信号色（暖光）只此一处。过。
- 渲染：无大面积渐变，无色带风险；canvas 原生抗锯齿。过。
- 多尺寸：CSS 按高度等比缩放显示；中心对称图案在 19.5:9 与 20:9 机型裁边时只裁到半颗星。过。
- 完成标准 1–4：逐条按上判，过。
