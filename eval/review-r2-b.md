- **B 组 {T3-3, T3-4, T3-5}：**都用同心不规则圈（年轮或等高线）当主图形；开场都把圈放大或画满画面，再缩到左侧变成图标，右侧横排"山野咖啡"，终帧版式相同。T3-3 和 T3-4 都是"年轮 / 等高线 + 深咖啡色实心圆盘"；T3-3 和 T3-5 都把等高线读作"山"。
- 两组之间不撞；全题只有两种方向。

# 4. 普通观众刷到会停下来看

- **T1 选 T1-4**：满版的粉蓝干涉纹在手机上会"晃眼"，这种视觉振动本身就让拇指停住；停下后读到"你在这里，两边都听得见"，会会心一笑，想转给一起去音乐节的朋友。前提是填空线要先补上。（第二候选是 T1-6：山脊线很好看，但普通人看它就是"一张好看的海报"，未必会停。）
- **T2 选 T2-4**：横条一行行往下掉，越掉越快，红色尾巴越拖越长，看的人会想知道"这个三角最后多大"。数字只有 3 个，不用读完一堆算式就能明白。
- **T3 选 T3-5**：开头 2 秒满屏都是看不出是什么的线，会引起好奇；4 秒时退出全貌，发现中间是一颗豆，好奇得到回报。8 秒刚好讲完一个"谜面加谜底"。

# 5. 整体观察

1. **撞车比质量问题更严重。** 三题都只分成两个方向，每个方向里的作品连细节都撞：T1 有三件都写"早鸟票 ¥380"，两件都是"40+"徽章，阵容名重复；T3 两件的标语几乎同一句话。这一轮作品的多样性很低。
2. **两条路线反复出现。** 一条是"奶油或暗底 + 暖橙强调 + 宽字距英文眉标 + 圆形徽章 + 居中衬线"的高级感模板：T1-2/5/6、T2-1/5/6、T3-1/2/6。这一路信息最全、执行最稳，但在 D3/D8 上被默认味封顶在 L1。另一条是"从题材本身找一个图形想法"：T1-1/4、T2-2/3/4、T3-3/4/5。这一路记忆点强，但收尾粗糙（填空线、裁字、默认字体）。
3. **最可惜的是"想法好、执行掉链子"。** T1-4、T1-1、T2-3 修好以后都有 L3 的上限，现在却因为占位或裁字判 L0。只要补一遍"成品检查"（有没有空线、字有没有出画、两个元素是否相撞），排名会整体重写。
4. **T2 的共同小病是计数器不同步**：T2-1/3/5/6 都在暂停帧里出现"年份标签和数值不同步"；T2-1 还有 ¥1600 数据不准。
5. **全场只有 T2-4 达到 L3**；T1-4、T3-5 是下一批 L3 候选。没有 L4。
