【理解】
原话：「给一个叫"山野咖啡"的品牌做一个 8 秒的 Logo 开场动画。」
合同：品牌名"山野咖啡"（四个字一字不改）；8 秒；Logo 开场动画。技术合同 1920×1080、`window.__seek(ms)`、自动播放、无声。
维度状态（只列非"已说"的）：
- Logo 本身｜事实空白｜用户没给 logo。不冒充"官方 logo"：我做的是一个由名字推出的标志提案（圆形等高线图章 + 字标），在过程里声明。
- 品牌事实（产地、品类、门店、口号）｜事实空白｜一律不写。画面只用名字本身和"咖啡"这个品类里一定为真的物理现象。
- 受众｜隐含｜我推断是品牌视频的观众（门店屏、社交平台片头），因为原话说"开场动画"，即放在品牌内容最前面。
- 观看情境｜隐含｜无声（技术合同）；片头会被看很多遍，所以要经得起重复，结尾锁定的标志要能直接当静帧用。
- 外观 / 结构｜空白｜交给发散。
替你决定的：标志 = 一枚圆形等高线图章 + 横排中文字标，不加英文、不加口号（另一种可选：竖排字标 + 印章，更传统，但与"等高线"图形的方向感冲突）。

【排除的默认】
默认：表面——咖啡棕 + 奶油米色、手写/衬线字、热气白烟曲线、柔光；构图——居中咖啡豆或杯子图标，下方品牌名，背后几座三角形山的剪影；结构——黑场淡入 → 山的剪影升起 → 咖啡豆落下 → logo 缩放弹出 → 口号淡入；声音——（无声，省略）。
变体：换成森林绿 + 木纹、换成扁平插画里一杯冒烟的咖啡放在山顶。
反面：纯黑底只有四个白字。

【方向】
① 手冲俯视即地形图：从正上方看手冲，热水一圈圈螺旋注入，湿掉的粉层隆起、浮起一圈圈浅色泡沫——正是一张"山"的等高线图；镜头拉远，这张地形图被圆形滤杯口切成一枚图章，名字落定。——"我平时不会这么做"
② 木刻印在牛皮纸豆袋上：一块木刻章压下、抬起，留下"山野咖啡"和刀痕里的山；动作是媒介自己的"印"。（物件即画面）
③ 只用字：四个字由极端尺度对比演出——"山"大到出画、"野"散开、"咖啡"两字落回正常尺寸。（动态排版）
④ 一天中的一刻：清晨山脊线从暗到亮，同一条线最后变成杯沿。（光的时间叙事）
距离：①是"一个现象连续形变成标志"，②是"一次印压动作"，③是"字的尺度戏剧"，④是"光的时间推移"，L1/L2 两两不同。

【选择】
选了①：手冲时湿粉层的俯视图 = 山的等高线图，拉远后成为标志。
契合在于：它把名字里的两半——"山野"和"咖啡"——用一个真实存在的物理画面同时说出来：热水注入后咖啡粉层隆起（闷蒸），俯视时一圈圈泡沫纹就是等高线。换成"XX 咖啡"或"山野民宿"都只成立一半，这是代入测试不通过的好结果。
放弃了②木刻（需要可信的刀痕与纸纤维，系统内代码画容易变成滤镜冒充媒介）、③只用字（名字有力量，但"山"与"咖啡"的关系说不出来）、④光的时间（易落进"日出山脊 + 咖啡杯"的符号套餐）。
被放弃的在这些条件下更好：有真实的木刻章或豆袋实拍时选②；品牌已有成熟 logo、只要字标动画时选③。
借来的一个元素：②的"图章"——最后的标志是一个圆形边界里的地形，像一枚盖在豆袋上的章。
方向承诺：拥有的想法是"一杯手冲从上面看就是一座山"；拒绝的默认是"咖啡棕奶油色 + 热气白烟 + 三角山剪影 + logo 缩放弹出"。它自己的世界：干咖啡粉的中棕、被水浸湿后的深棕、浮沫的浅褐等高线三种颜色，全部取自真实的粉层；线有"计曲线"（每第 4 条加粗，地形图的真实规范）；运动只有注水螺旋、闷蒸隆起、镜头拉远三种。去掉字仍能认出是"一张从咖啡里长出来的地形图"。第一眼：中棕的干粉面中央一个注水点，周围刚湿的一小圈深色。

【简报】
受众：品牌片头观众｜目标反应："咖啡粉面上长出了一座山——山野咖啡"｜观看情境：无声、可能重复播放、横屏｜格式：1920×1080，8.000 秒，自动播放、`__seek` 可重复（固定种子）。
做到什么算完：
1. 第 0 帧成立。测法：`__seek(0)`。失败：黑场或空背景。
2. 等高线读得出是"山"。测法：停在 4 秒问"这像什么"。失败：说成"年轮/指纹/水波"——对策：等高线有一侧密一侧疏（陡坡与缓坡），并有加粗计曲线。
3. 名字读得清、停得够。测法：字落定（约 6.2 秒）到片尾 ≥ 4÷9 秒且 ≥ 0.83 秒；字高 ≥ 0.033S。失败：不足或对比 < 4.5:1。
4. 结尾标志可单独当静帧。测法：`__seek(8000)`。失败：标志被裁、字与图形不对齐。
5. 可重复。测法：同一 ms 两次 seek 像素一致。失败：用了 Math.random 或真实时间。
必保项：等高线来自注水过程（不是凭空出现）；计曲线加粗；图章圆边。
失败点：拉远时线宽跟着缩到看不见（对策：线宽按屏幕像素恒定）；等高线互相穿插（对策：相邻等高线形状共用同一组谐波，只让振幅缓慢增长）。
不要：外观——热气烟雾、咖啡豆图标、三角山剪影、奶油米底、光晕；结构——黑场淡入、logo 从 0 缩放弹出、口号收尾；内容——编造口号、产地、"since"年份；技术——随机数不定种子、闪烁。
反向定位：它不是一支咖啡店宣传片头，它更像一张从咖啡里显影出来的测绘图。

时间表（秒）：0–2.8 注水等速螺旋 3 圈、粉层由中心向外湿透，等高线随湿锋逐条绕出｜2.8–3.9 注水停、湿锋自行铺满全画面｜3.0–4.2 闷蒸：整片地形隆起 3% 再落回｜4.2–5.5 镜头拉远（比例 1→0.27，指数插值），地形移到左侧｜4.9–5.75 圆形滤杯边一笔画出，圆外的等高线被裁掉｜5.3–6.2 四个字依次升起（间隔 0.09s）｜6.2–8.0 停留，等高线极慢地形变（地形在呼吸）。

【自检】
- 默认对照：过。无豆子、无杯子、无烟、无三角山；开场不是黑场。
- 禁用清单：过。#3 奶油米 + 赤陶：未用，底色是湿粉深棕、线是浮沫浅褐，均取自粉层；#2 深底：有深色底，但无霓虹、无光晕，深色来自"被水浸湿的咖啡粉"；#23 慢 logo 开场：第 0 帧即有内容，标志在 6 秒前完成；#35 无从 0 缩放的弹出，拉远是镜头运动而非 logo 弹出；#26 未用字母方块或 emoji；#29 无粒子、无光斑；#31 无噪点纹理。
- 代入测试：过。换成"XX 咖啡"缺"山"，换成"山野民宿"缺"咖啡"。
- 必保项：过。等高线由注水点经过后才逐条绕出；每第 4 条线宽 4.2px，其余 2.4px；圆边 4px。
- 事实：过。只出现"山野咖啡"四字，无口号、无英文、无年份；在过程中声明标志为提案。
- 零错字：过。"山""野""咖""啡"。
- 第 0 帧：过。干粉面 + 中心湿圈 + 注水点。
- 主角时序：过。0–3 主角是注水点；3–4.2 是隆起；4.2–5.5 是镜头；5.3–6.2 是字；字开始时镜头已基本落定（剩余 0.2s 为末端减速）。
- 动作多样：过。注水匀速螺旋、闷蒸"沉入"式隆起、镜头"搬运"式两端缓、字"停靠"上升，四种曲线与时长。
- 读得完：过。字落定约 6.2s，停到 8.0s = 1.8s ≥ 0.83s。
- 无死时间：过。最长"无新事件"区间 6.2–8.0 = 1.8s，且等高线仍在极慢形变。

- 技术完整：过。固定种子 mulberry32(20261118)；render(ms) 只依赖 ms。
