【理解】
原话：「帮我做一张音乐节海报。」
合同：音乐节；海报（静态）。技术合同 1080×1350、单 HTML、系统字体、无外部资源。
维度状态（只列非"已说"的）：
- 题材细节｜事实空白｜音乐节名称、日期、地点、阵容都没给。不编造：海报上做成"日期 / 地点 / 阵容"三条待填栏，作品不靠这些信息成立。
- 受众｜空白｜交给方向比较；替定：会去户外音乐节的年轻观众。
- 目标反应｜空白｜替定："这是个有好几个舞台的户外音乐节，我想去站在中间。"
- 观看情境｜隐含｜我推断 4:5 竖图主要在手机信息流里看，因为 1080×1350 是信息流竖图比例。所以第一眼必须在缩略图尺寸成立。
- 材料与事实｜事实空白｜没有照片、logo、乐队名。只用"本身就是真的"东西：音乐节有多个舞台、声音向外扩散、人站在场地里。
- 外观 / 结构｜空白｜交给发散。
替你决定的：两个舞台（主舞台 + 第二舞台）。（另一种可选：单舞台；那就失去"串场/两边都听得见"这个只属于音乐节的事实。）

【排除的默认】
默认：表面——近黑底 + 霓虹紫/洋红光晕、渐变、粗体发光大字；构图——舞台剪影 + 举手人群剪影 + 光束，标题居中顶部，底部阵容名单分级排列；结构——标题 / 主图 / 阵容 / 日期地点四段。
变体：同一东西换成落日橙渐变、换成复古 80 年代合成器网格。
反面：浅色极简、只有一行小字的"空"海报。

【方向】
① 两个舞台的声场：俯视场地，两个舞台各发出一圈圈同心声波，用孔版套印两种专色印，两组声波在场地中间叠出第三色和干涉纹；人站的位置就是两组声波相遇处。（排除了舞台剪影、人群、光束）——"我平时不会这么做"
② 手环即海报：整张就是一条布手环 / 入场腕带的特写，信息织在带子上。（排除了"画一个场景"）
③ 时刻表网格：从中午到午夜的分小时色带，按章节换色，舞台演出时段是色块；一个时段撞车作为唯一例外。（排除了主视觉图）
④ 第二天早上：耳朵里还在响——只画一只耳朵和残留的声纹，情绪是余韵。（排除了现场的热闹）
⑤ 字面：舞台 + 人群 + 灯（只作参照，不进最终）。
距离：①结构是"空间场 + 交汇点"，②是"物件即画面"，③是"网格 + 一个例外"，④是"事后的一个瞬间"，L1/L2 两两不同。

【选择】
选了①：俯视的两组声波，在场地中间叠出第三色，"你在这里"标在交汇处。
契合在于："多个舞台同时开唱、人在中间都听得见"是音乐节独有的事实——换成"演唱会"（只有一个舞台）这张就不成立；而缺失的名称/日期/阵容不会让它失效，正好适配事实空白。
放弃了②手环（需要可信的织物质感，系统字体 + 代码画不真）、③时刻表（没有阵容事实，色块全空会像占位）、④耳朵（情绪对，但"音乐节"信息要靠文字才能读出）。
被放弃的在这些条件下更好：有真实阵容和时段时选③；有实拍手环/实物可扫描时选②。
借来的一个元素：③的"唯一例外"——全图只有一个"你在这里"标记。
方向承诺：拥有的想法是"站在两个舞台之间"；拒绝的默认是"近黑底霓虹光晕 + 舞台人群剪影"。它自己的世界：灰白纸上两种孔版油墨（荧光粉、蓝）印出的同心圆，叠印处变深出第三色，去掉所有字仍能认出是"两个声源在一片地上相遇"。第一眼：一整片粉蓝干涉纹，中间一个深色小点。

【简报】
受众：户外音乐节观众｜目标反应："两个舞台，我站中间"｜观看情境：手机信息流，缩略图先看｜格式：1080×1350 静态，单 HTML。
做到什么算完：
1. 第一眼能说出是"音乐节"。测法：看 0.5 秒遮住。失败：说成"抽象艺术/唱片封面"而不提音乐节——所以标题"音乐节"必须是最大的字。
2. 两个声源可辨。测法：模糊后能指出两个圈心。失败：看成一张随机纹理。
3. 字读得清。测法：最小须读字 ≥ 0.022S = 24px；对比 ≥ 4.5:1。失败：字压在纹理上。
4. 有自己的样子。测法：把"音乐节"遮住，问像不像任何一张活动海报。失败：像霓虹夜场海报。
必保项：两色叠印出第三色（不是第三种独立颜色）；唯一一个"你在这里"。
失败点：干涉纹在小尺寸下变成灰；文字压在条纹上读不清。
不要：外观——紫色渐变、光晕、剪影人群；结构——阵容名单金字塔；内容——编造的乐队名、日期、地点、票价；技术——外部字体。
反向定位：它不是一张夜场演出海报，它更像一张印在音乐节场地地图上的声学示意。

【自检】
- 默认对照：过。无黑底、无光晕、无人群；主图是俯视声场。
- 禁用清单：过。#5 品类色未用（荧光粉+蓝是孔版标准油墨，理由是媒介）；#12 眉标未用；#22 没有装饰刻度；#31 没加噪点纹理，叠印靠真实的 multiply 混合而非滤镜；#28 无编造信息。
- 代入测试：过。换成"演唱会"（单舞台）则两个声源与"你在这里"失去意义。
- 必保项：过。蓝组用 multiply 叠在粉组上，交叠处自然变深；"你在这里"只出现一次。
- 事实：过。名称/日期/地点/阵容全部留空待填，未编造。
- 零错字：过。逐字核对"音乐节 / 主舞台 / 第二舞台 / 你在这里，两边都听得见 / 日期 / 地点 / 阵容"。
- 一瞥 / 主焦点：过。最大墨块是标题"音乐节"（240px），其次是干涉场，标记点最小但是唯一深色实心点。
- 模糊测试：过。上：花纹场；下左：大标题；下右：三行小栏。三组分得开。
- 事故区：过。三条栏目基线 1100/1170/1240，最后一条与标题基线 1240 完全对齐；左边距统一 70。
- 字高：过。最小字 28px ≥ 24px。
- 对比度：过。所有小字用"双色叠印深色"#0b2a7a，对灰白纸约 12:1；小字都放在纸色底框里，不压条纹。
- 边距：过。所有元素距边 ≥ 70px（0.065S）。
- 层级：过。240 / 30 / 28（标题对小字比远大于 √2；30 与 28 属于同一级）；字重 1 种（粗）；字族 1 个。
- 颜色剂量：过。只有两种油墨 + 叠印色，无第四色。
- 渲染：过。全部矢量，无渐变色带。
- 完成标准 1–4：过。
