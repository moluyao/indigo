【理解】
原话：「帮我做一张音乐节海报。」
合同：音乐节；海报（1080×1350 静态，单个自包含 HTML，系统字体，无外部资源）。
维度状态（只列非"已说"的）：
- 受众｜隐含｜可能去现场的年轻人，因为"音乐节"是需要买票到场的活动，海报的用途是招人到场。
- 目标反应｜隐含｜"我想站进那堆人里"，因为海报的用途是让人想去。
- 观看情境｜空白｜替定：手机信息流 + 打印张贴两用，所以第一眼必须在缩略图尺寸可读。
- 材料与事实｜事实空白｜音乐节名称、日期、地点、阵容全缺。处理：不编造，画面只用本身为真的东西（"音乐节"三个字、人群、舞台、灯），底部做成真实印刷传统里的"加印区"（巡演海报的空白套印栏），由主办方填写。
- 中心想法 / 外观 / 结构｜空白｜交给发散。
- 禁止项 /"好"的标准｜空白｜按准则通用标准。
替你决定的：做成"待加印"的通用版（另一种可选：给我名称、日期、阵容后直接排进去，版式不变）。

【排除的默认】
默认：表面——近黑/深紫底 + 霓虹粉青光晕 + 渐变；构图——舞台剪影 + 举手人群剪影在下、大标题居中、阵容名单按字号阶梯排列；结构——标题/日期/阵容/赞助 logo 四段。
变体：同样的剪影换成日落橙或孟菲斯撞色。　反面：极简白底只放一行细字。

【方向】
① 俯视人群：从舞台上方往下看，几千个"两肩一头"全部朝向舞台，越靠前越挤；人群里唯一的例外是一个转圈的空场（circle pit）。结构：严格方向场 + 一个例外。（排除了剪影、仰视、发光）——我平时不会这么做。
② 腕带即海报：整张画面是一根放大的入场腕带，材质、条码、编号、撕口都是腕带自己的。结构：物件即画面。（排除了"画一个演出现场"）
③ 声压分贝刻度：从后排到前排一条声压衰减的刻度尺，海报从上到下就是你离音箱的距离。结构：跨尺度的一条刻度。（排除了图像）
④ 字面：吉他/麦克风巨物 + 丝网三色套印。（字面方向，只占一个）
距离：①方向场+例外 / ②物件 / ③刻度距离，L1 和 L2 都不同。

【选择】
选了①俯视人群。契合在于"音乐节"独有的事实就是成千上万陌生人同一时刻面朝同一个方向——这个方向场换成演唱会以外的活动（展会、市集）就不成立；circle pit 也是只有现场音乐才有的行为。放弃了②腕带（需要真实名称和编号才好看，现在全是事实空白）和③刻度（需要声压数据，无真实来源）。②在拿到主办方名称、日期、票种后更好；③在做声学主题或电子音乐节时更好。
借来的一个元素：从④借"孔版双色套印"——蓝 + 荧光粉两版正片叠底，人在灯里时两墨相乘出第三色，粉版故意错位 3px。
方向承诺：拥有的想法——"从舞台往下看，所有人都朝向你"；拒绝的默认——深色底霓虹光晕 + 仰视剪影人群。它自己的世界：只有两种墨，蓝墨画人、粉墨是舞台灯照到的地面，人和灯重叠处变成深紫；一切都是俯视的小形状。第一眼：一大片朝上挤的小人，上方一条写着"舞台"的蓝条，下方三个巨大的"音乐节"。

【简报】
受众：可能去现场的人｜目标反应："好多人，我也想站进去"｜观看情境：手机缩略图 + 打印｜格式：1080×1350 静态。
做到什么算完：
1. 一瞥能说出"音乐节"。测法：看 0.5 秒遮住。失败：说不出这是音乐活动。
2. 能认出是俯视的人群朝向舞台。测法：问"这些小东西是什么、朝哪"。失败：被读成花纹或细菌。
3. 层级三级：大字 > 人群场（含圆场）> 加印区。测法：模糊测试。失败：圆场和大字争第一。
4. 两墨叠印出第三色可见。测法：灯区内的人是否呈深紫。失败：粉版被蓝版完全盖住或看不出叠印。
5. 不编造任何名称、日期、阵容。失败：出现任何假乐队名或日期。
6. 文字可读：须读字 ≥ 24px（0.022S），对比 ≥ 4.5:1。
必保项：全员朝向舞台的方向场；一个 circle pit；双色叠印。
不要：外观——霓虹、光晕、渐变、深色底；结构——阵容阶梯名单、赞助 logo 栏；内容——假乐队名、假日期；技术——随机数不固定导致每次打开不同。
反向定位：它不是一张"夜店演出宣传图"，它更像一张从灯架上俯拍、用两色丝网印出来的现场纪念海报。

【自检】
- 默认对照：过。无暗底、无光晕、无剪影，视角是俯视。
- 禁用清单：过。第 10 条（系统黑体做展示字）命中——中文系统字库只有黑体系能给到 900 字重，丝网演出海报的传统也是最重的无衬线；做了纵向 1.16 拉长使其成为这张海报的字形。第 26–27 条无。第 31 条：无纸纹噪点，"印刷感"来自真实的正片叠底 + 错版，不是滤镜。
- 代入测试：过。换成展会/市集，"全员朝一个舞台 + 转圈空场"不成立。
- 必保项：过（方向场、pit、叠印都在）。
- 事实：过。只有"音乐节""舞台"和空白加印栏。
- 零错字：过（音乐节、舞台、日期、地点、阵容）。
- 一瞥/主焦点：过。大字占宽 940px、高约 340px，是唯一最大墨块；pit 是第二层。
- 模糊测试：过。大字块 → 上半人群场（粉区内更深）→ 底部细栏。
- 事故区：过。大字与加印栏左边都在 x=70；三字段间距一致。
- 字高：过。加印栏 28px ≥ 24px；舞台字 30px。
- 对比度：过。蓝 #1d2c9c 对纸 #eef0ea 约 10:1；"舞台"为纸色镂空在蓝上，同值。
- 边距：过。文字左右 70px；人群出血属有意。
- 层级：过。300 → 30/28，字重 2 种（900/700），字族 1 个。
- 颜色剂量：过。粉只出现一处（灯区），蓝承担其余全部。
- 渲染：过。无渐变（无色带），人形全部矢量。
- 确定性：过。种子固定 mulberry32(1350)。
- 完成标准 1–6：逐条过；第 2 条的风险是人形太小被读成纹理——每人 22px、头肩之间留 2px 纸隙、灯区内 16% 举手，判断可读。
