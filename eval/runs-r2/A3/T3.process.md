【理解】
原话：「给一个叫"山野咖啡"的品牌做一个 8 秒的 Logo 开场动画。」
合同：品牌名"山野咖啡"（一字不改）；8 秒整；Logo 开场动画。（技术：1920×1080，window.__seek，无声。）
维度状态（只列非"已说"的）：
- 受众｜隐含｜品牌的顾客与门店/社媒观众，因为 Logo 开场用于品牌视频片头。
- 目标反应｜隐含｜记住"山野咖啡"这个名字和标志，因为开场的唯一功能是识别。
- 观看情境｜隐含｜片头、无声（技术要求），可能被反复看 → 不能有重砸式高潮，耐看优先。
- 材料与事实｜事实空白｜没有给现成 Logo、品牌色、产地、门店地址。处理：不编造产地、海拔、年份、口号；只用名字本身——"山""野""咖啡"三个真实语素，标志由名字推出并声明是新设计。
- 中心想法 / 外观 / 结构｜空白｜交给发散。
替你决定的：新设计一个图形标 + 字标（另一种可选：如果已有 Logo，同一套"地图落入杯中"的动作可以改为最后落成你们的现有标志）。

【排除的默认】
默认：表面——深棕/咖啡色底、暖金、蒸汽线条、咖啡豆 + 山形剪影图标、光晕；构图——图标居中，品牌名在下；结构——黑场 → 豆子/山形慢慢浮现 → Logo 缩放弹入 → 微光扫过 → 停。
变体：同样的结构换成墨绿 + 手写体。　反面：纯白底只有一行字淡入。

【方向】
① 等高线落入杯中：开场是一张山的等高线地形图正被一圈圈画出；一个杯沿把山顶圈住，杯外的地图被抽走，咖啡从山顶处漫开，等高线变成咖啡表面的浅色纹，一圈涟漪后静下来——俯视的山 = 俯视的一杯咖啡。地图上山名注记"山野"直接走出来成为字标。结构：一次连续形变。（排除了豆子、蒸汽、剪影）——我平时不会这么做。
② 盖章：一只橡皮章落在牛皮纸咖啡袋上，印出标志，印迹有缺墨。结构：一个瞬间（物件即画面）。（排除了屏幕感）
③ 野地标本签：像博物馆植物标本的采集标签——"品名：山野 / 类别：咖啡"，按标本签的格子排出字标。结构：借用别的品类。
④ 字面：山的剪影 + 冒热气的杯子。（字面方向）
距离：①形变 / ②瞬间 / ③品类借用，L1 与 L2 均两两不同。

【选择】
选了①等高线落入杯中。契合在于名字里"山"和"咖啡"两个词在一个形状上重合：等高线俯视是一圈圈的同心闭合线，一杯咖啡俯视也是同心的圆和液面纹——这只属于"山野咖啡"，换成"海边咖啡""城市咖啡"都不成立。放弃了②盖章（可信、质朴，但换任何咖啡品牌都成立，代入测试不过）和③标本签（"野"的意味强，"山"弱，且信息字多、8 秒内读不完）。②在品牌重点是手作/包装时更好；③在品牌主打产地与采集故事、且有真实产地信息时更好。
借来的一个元素：从③借"注记"——地图上的山名注记本身就是品牌名的前两个字"山野"，带白色压边（地图注记的真实做法）。
方向承诺：拥有的想法——"杯里装着一座山"；拒绝的默认——咖啡豆 + 山形剪影 + 蒸汽 + 深棕底 + 光晕。它自己的世界：地图纸色底，所有线条都是等高线（每第 4 条为加粗计曲线，真实地形图惯例），颜色只取地形图的棕色等高线墨，咖啡就是这根棕线"加深"之后的颜色；运动是绘图笔一圈圈画、杯沿一笔画圆、液体从山顶漫开。第一眼：浅色纸上四圈棕色等高线，里面的线正在被画出来。

【简报】
受众：品牌观众｜目标反应："山野咖啡——杯子里有座山"｜观看情境：片头，无声，可能反复看｜格式：1920×1080，8.0 秒，__seek 可重复。
做到什么算完：
1. 第 0 帧就是一张成立的地形图。测法：__seek(0)。失败：空屏/黑场。
2. 看得出"杯里是山"。测法：__seek(5000) 截停，问"这是什么"。失败：只说"一个圆"或"年轮"。
3. 字标读得完：最后一个字落定（6.75 s）到结束 ≥ 0.83 s。实际 1.25 s。失败：不足。
4. "山野"注记到字标是同一个对象连续移动，不消失再出现。测法：5.6–6.4 s 逐帧看。失败：中途有断帧。
5. 每一秒只有一个主角在动。失败：杯子位移和字落同时满强度。
必保项：等高线（含加粗计曲线）；咖啡从山顶漫开；"山野"注记变字标。
不要：外观——咖啡豆、蒸汽、光晕、金色、深棕满底；结构——黑场淡入、缩放弹入、扫光；内容——编造的产地、海拔、创立年份、口号；技术——随机等高线每次不同。
反向定位：它不是一段"咖啡店宣传片头"，它更像一张地形图被人放进了杯子里。

【自检】
- 默认对照：过。无豆、无蒸汽、无光晕、无黑场；第一眼是地图。
- 禁用清单：第 3 条（浅纸底 + 衬线 + 赤陶）风险——底色为偏冷的地图纸 #eef0ea 而非奶油色；棕色来自地形图等高线的印刷惯例，不是"品味色"；仿宋来自地图注记用字传统（物件同源），且仿宋为低对比细笔，不是高对比展示衬线。判过。第 5 条（按品类选色：咖啡 = 棕）——棕色的出处是地形图，与咖啡重合正是想法本身，过。第 23 条（慢 Logo 开场）——第 0 帧已是完整地图，名字的一半（"山野"）在 2.4 s 已上屏，过。第 30 条：无装饰运动；结尾的慢旋转是液面的真实漂移，速度约 6 px/s，过。第 35 条：无回弹。
- 代入测试：过。"海边咖啡"无山可装。
- 必保项：过。
- 事实：过。无产地、无年份、无口号；画面上只有"山野""山野咖啡"。地形是程序生成的示意地形，不冒充任何真实山体，不标海拔数字。
- 零错字：过（山野咖啡）。
- 第 0 帧：过。
- 主角时序：过。0.05–2.33 等高线逐条画（间隔 0.24 s）→ 2.2 山顶符号 → 2.35 注记 → 2.75–3.45 杯沿 → 3.35–3.95 杯外地图抽走 → 3.55–4.4 咖啡漫开（沉入曲线）→ 4.45–5.4 一圈涟漪 → 5.3–6.0 标志左移（两端缓）→ 5.65–6.35 注记变字标 → 6.2/6.35 "咖""啡"落定（停靠）。相邻事件仅有 0.1–0.35 s 的交接重叠，后者起点晚且幅度不同。
- 动作多样：画线（匀速笔）、画圆（停靠）、抽离、沉入、径向涟漪、搬运、停靠落定——入场与退场非同一动作倒放，过。
- 无死时间：最长静止为结尾 1.25 s（且液面有慢旋），过。
- 读得完：4 字 ÷ 9 = 0.44 s，下限 0.83 s，实际 1.25 s，过。
- 频闪：最大位移为标志左移 408px / 0.7 s，单帧约 20px，远小于标志尺寸一半；无明暗翻转（深色只出现一次并保持），过。
- 字高：注记 46px（最小时 28px，仅在移动途中）、字标 150px ≥ 0.033S，过。
- 对比度：字标 #2b1a10 对 #eef0ea 约 15:1；注记奶色在咖啡上约 11:1，过。
- 事故区：字标四字等距（字距 = 0.16 字高），标志圆心与字标字身中线同在 y≈540，过。
- 构图：锁定后标志 380–760、字标 850–1522，整体中心 ≈ 951（画面中心 960），过。
- 技术完整：种子固定 mulberry32(318)；render(ms) 为纯函数；__seek 可重复，过。
