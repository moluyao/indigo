【理解】
原话：「给一个叫"山野咖啡"的品牌做一个 8 秒的 Logo 开场动画。」
合同：品牌名「山野咖啡」；Logo 开场动画；8 秒整；1920×1080；无声；可 seek、自动播放。
维度状态（只列非"已说"的）：
- 品牌 Logo / 标准色 / 标准字｜事实空白｜没给 Logo。不冒充"他们的 Logo"：只用本身就是真的东西——名字四个字和名字的含义（山、野）、咖啡豆的形状；图形标志作为提案在此声明。
- 品牌故事、产地、海拔、创立年份｜事实空白｜一律不写，不出现任何数字或口号。
- 受众｜隐含｜我推断"在门店屏、视频号片头或发布会上第一次看到这个牌子的人"，因为 Logo 开场的用途是在片子开头建立识别。
- 目标反应｜隐含｜我推断"山野咖啡——山上的咖啡，记住了"，因为开场的唯一任务是让名字和一个图形绑在一起。
- 观看情境｜隐含｜横屏、无声、看一到几遍（片头会被反复看到）。
- 中心想法 / 外观 / 结构｜空白｜交给第 ③ 步。
替你决定的：图形标志 = 等高线围着一颗咖啡豆（山顶是一颗豆）；字标用系统黑体粗体。（另一种可选：给我现有 Logo 文件后，保留"等高线一路往上走到山顶"的运镜，把山顶换成你们的标志。）

【排除的默认】
默认：表面——深咖啡色底、金色衬线字、热气袅袅、豆子旋转、柔光颗粒；构图——杯子或豆子居中、名字在下、副标语一行；结构——黑场淡入 → 豆子/杯子转一圈 → Logo 淡入 → 口号 → 淡出。
变体：同样结构换成奶油底 + 赤陶色、或换成手绘水彩山 + 杯子。
反面：纯白底、只有一条细线画出山形、极简淡入。

【方向】
① 等高线登山：一张地形图的等高线从山脚一圈圈画到山顶，山顶最内圈是一颗咖啡豆；镜头一路从山坡拉到全貌，成标。结构：一次跨尺度旅行。——"我平时不会这么做"
② 咖啡当墨：一滴咖啡落在滤纸上洇开，写出「山」的三笔，干边与晕染；媒介根（墨与纸→咖啡与滤纸）。
③ 字即山野：只用字，「山」字三竖笔升成三座峰、「野」字横向铺开成原野；动态排版。
④ 字面画面：山 + 杯 + 热气（仅作对照，最多占一个）。
查距离：①（L2 跨尺度、L1 "豆长在山上"）与②（L3 媒介）、③（L1 名字字形）根上不同；①与④都有山，但①没有杯、热气，结构是旅行而非摆放，不是近亲。

【选择】
选了①：地形图等高线由外向内画到山顶，山顶是一颗咖啡豆，然后收成"等高线 + 豆"的标志，名字从旁升起。
契合在于"山"字：品牌名的第一个字就是山，而咖啡本来就种在山坡上；等高线是"山"在纸上最准确的样子，豆落在山顶，名字的两半（山野 / 咖啡）就在一个图形里合上了。代入测试：换成"海边咖啡""城市咖啡"不成立。
放弃了②咖啡洒墨、③纯字。
被放弃的在这些条件下更好：②有真实拍摄或高质量流体模拟时（程序化模拟洇墨容易变成滤镜冒充媒介）；③品牌已经有定制字体时。
借来的一个元素：③的"字从一条线下升起"——字标四个字依次从看不见的基线下升出，像等高线一样一层一层到位。
方向承诺：拥有的想法是"山顶是一颗豆"；拒绝的默认是深咖色底 + 金色衬线 + 热气 + 旋转豆子 + 淡入。它自己的世界：灰绿纸色底上只有一种咖啡棕墨，全部是等宽的线（每 5 条一条加粗，地形图惯例），唯一的实心面是山顶那颗豆；镜头一直在"往上走"。第一眼：第 0 帧就是满屏几条地形线从左上斜穿，一条正在被画出。

【简报】
受众：第一次看到这个牌子的人｜目标反应："山野咖啡，山顶上一颗豆"｜观看情境：横屏无声片头｜格式：1920×1080，8.000 s，seek 可重复。
做到什么算完：
1. 第 0 帧成立。测法：截第 0 帧问"这是什么"。失败：空白、黑场，或说不出是线条/地图。
2. 豆的落点看得清。测法：停在 4.3 s 问"中间是什么"。失败：说不出"咖啡豆"。
3. 名字读得完。测法：字落定（6.37 s）到结束 ≥ 4 ÷ 9 s 且 ≥ 0.83 s。失败：不足。（实际 1.6 s）
4. 标志可独立成立。测法：截 8 s 末帧遮住字。失败：剩下的图形说不出"山 + 豆"。
5. 反例：成品更像"豆子旋转 + Logo 淡入"，算失败。
必保项：由外向内画的等高线；山顶实心豆 + 纸色豆缝；加粗计曲线。
不要：外观——深咖色底、金色、热气、光斑、颗粒；结构——黑场淡入开场、结尾口号卡、长淡出；内容——编造的产地、海拔、年份、口号；技术——线头闪烁、豆缝在填墨时跳变。
反向定位：它不是一段咖啡店宣传片头，它更像一张手绘地形图被一笔笔描出来，最后被认出是一枚印章。

【自检】
5.1
- 默认对照：过。无杯、无热气、无旋转、无淡入；主体是等高线与山顶的豆。
- 禁用清单：过。#5 颜色不按品类凭空选：棕色来自咖啡本身，也正是地形图等高线的传统用色；#3 底色是灰绿纸色（L≈0.92、偏绿），未用奶油米黄，无衬线、无赤陶；#10 系统黑体作字标，理由：无外部字体可用，粗黑体与等宽线条同为"无装饰"语法，已声明为提案；#23 首尾夹心——未犯，第 0 帧就有内容，名字出现在 5.5 s 是因为这是 Logo 开场，内容本身就是名字；#29/#30 无粒子、无光斑；#33 入场不是淡入（线是画出来、豆是从中心向外填墨、字是升起），退场的外圈线是"收笔"。
- 代入测试：过。换成别的咖啡牌子（不带"山"）想法不成立。
- 必保项：过。
- 事实：过。无数字、无口号、无产地。
- 零错字：过（山野咖啡）。
- 完成标准：1 过（第 0 帧有 4 条完成/进行中的等高线斜穿左上，含 1 条加粗计曲线）；2 过（豆 2.5–4.0 s 画出、开缝、填墨，4.0–4.6 s 镜头停住给一次呼吸）；3 过；4 过（6 圈等高线 + 实心豆，中心对称，缩小后仍可读）；5 过。
5.2 / 5.3
- 第 0 帧：过。
- 主角时序：过。0–2.5 正在画的那一条线；2.5–4.0 豆；4.6–5.4 外圈收笔；4.8–5.8 标志移位；5.5–6.4 四个字依次。每一刻一个主角。
- 动作多样：过。画线（PEN，先慢后快再收）、镜头（指数缩放 + 两端缓的搬运）、填墨（沉入，从豆心外扩）、收线（抽离）、字（停靠升起），无回弹、无翻转。
- 无死时间：过。最长"几乎不变"是 6.4–8.0 s（1.6 s），镜头以约 1 px/s 呼吸，低于可见位移，等于静止停留，作为末帧读取 + 确认。
- 读得完：过（字落定后 1.6 s ≥ 0.83 s）。
- 落差：过。峰在 3.6–4.0 s 豆被填满（全片唯一实心面出现）；谷在 4.0–4.6 s 停住。
- 频闪与闪烁：过。最大镜头速度出现在约 1.9 s，相邻帧位移远小于线间距的一半；全片无明暗翻转。
- 无坏帧：过。无头脚本按 50 ms 步长跑完 0–8000 ms，无异常、无 NaN。已修一处：初版第 0 帧只有 1–2 条线可见、像没开始——把整套画线时间表提前 0.6 s，豆的三步相应提前，在山顶留出 0.6 s 停顿。
