【理解】
原话：「帮我做一张音乐节海报。」
合同：音乐节；海报（静态）；画幅 1080×1350；单个自包含 HTML、系统字体、无外部资源。
维度状态（只列非"已说"的）：
- 受众｜空白｜交给发散；替定为"路过海报、可能会去的人"。
- 目标反应｜隐含｜我推断"这是个音乐节，我想站在那群人里"，因为海报的用途是招人到场。
- 观看情境｜隐含｜我推断手机竖屏 / 张贴两种，因为 4:5 是信息流与印刷海报的通用比例；只看一眼。
- 音乐节名称、日期、地点、阵容、票价｜事实空白｜不编造。作品只用本身就是真的东西：「音乐节」三个字、人群、天空；日期地点做成"加盖区"——巡演/音乐节海报批量印刷、各场再盖章补信息是真实做法。
- 中心想法 / 外观 / 结构｜空白｜交给第 ③ 步。
- 禁止项 / 好的标准｜空白｜按准则第 3、5 节。
替你决定的：没有阵容与日期时，做成"预热海报 + 加盖区"。（另一种可选：给我名称/日期/阵容后，把加盖区换成真实信息，版式不变。）

【排除的默认】
默认：表面——深紫/近黑底、霓虹粉青、光束与辉光、渐变大字；构图——吉他或舞台灯居中、标题顶部居中、阵容列表在下、日期一条横栏；结构——满屏装饰 + 信息堆砌。
变体：同样的舞台灯光换成橙红夕阳渐变、或换成"手绘涂鸦风"同一构图。
反面：纯白极简，一个小字"音乐节"留大空白。

【方向】
① 双色孔版套印：黄版一颗大太阳、蓝版一整片举手的人群，两版叠出第三色；音乐节 = 很多人在同一片天空下。（排除了舞台、乐器、灯光）——"我平时不会这么做"
② 时间表即海报：整张是一张从中午到散场的演出时刻表网格，块的长短就是演出；结构根。（排除了图像主角）
③ 声音从一个点到很多人：一个喇叭圆心发出的同心圆被一排排人头打断，跨尺度从扬声器到人群。（排除了人物、天空）
④ 手环 / 票根：海报本身是一枚放大的入场手环，"物件即画面"。（排除了插画）
⑤ 字面画面：舞台 + 灯光 + 剪影（仅作对照，最多占一个）。
查距离：①人群/天空（L1 群体）与②时间（L2 网格）、③传播（L2 跨尺度）、④物件（L3）根上不同；无近亲。

【选择】
选了①：黄、蓝两版孔版套印，一颗被裁掉的太阳 + 一片由远及近、有人举手的人群。
契合在于"人群"：音乐节和演唱会、剧场的独有区别是露天、整天、站着的一大片人；人群 + 太阳把这两点直接画出来，而且不需要任何编造的阵容或日期就能成立。
放弃了②时间表、④手环。
被放弃的在有真实阵容与时刻时更好（②能把真实信息变成画面本身；④适合已有品牌视觉的成熟音乐节）。
借来的一个元素：④的"物件"思路——加盖区，像真实印刷品上留给各场盖章的地方。
方向承诺：拥有的想法是"音乐节是天空下的一大片人"；拒绝的默认是深紫霓虹 + 舞台灯光 + 阵容堆砌。它自己的世界：只有两种油墨（黄、蓝），相遇处叠成深绿；人与人之间是纸的缝；版有错位。第一眼：顶部压着太阳的「音乐节」三个大字，下面一大片举手的蓝色人头。

【简报】
受众：路过的人｜目标反应："是个音乐节，好多人，我也想去"｜观看情境：手机一瞥或街头海报｜格式：1080×1350 静态。
做到什么算完：
1. 一眼说出是什么。测法：看 0.5 秒遮住问"这是什么"。失败：说不出"音乐节"。
2. 看得出是人群。测法：只看下半部问"这是什么"。失败：说成"山""波浪""花纹"。
3. 叠色成立。测法：找太阳与人群、太阳与标题相交处。失败：相交处不是第三色（深绿）而是一色盖另一色。
4. 读得清。测法：标题字高与加盖区字高、对比度。失败：加盖区文字 < 0.022S（24px）或对比 < 4.5:1。
5. 反例：成品更像"霓虹舞台海报"，算失败。
必保项：两版叠色出第三色；人与人之间的纸缝。
不要：外观——紫/近黑底、霓虹辉光、渐变字；结构——阵容列表、日期横栏、居中乐器；内容——编造的名称、日期、阵容、票价、赞助 logo；技术——无锯齿以外的瑕疵、文字被裁。
反向定位：它不是一张霓虹舞台海报，它更像一张独立印社用两色孔版机印出来的街头招贴。

【自检】
5.1
- 默认对照：过。没有舞台、灯光、紫黑底；主体是太阳 + 人群 + 叠色。
- 禁用清单：过。#1/#2/#8 不涉及；#10 用系统黑体，理由是海报字需要最重字重、无外部字体可用；#12/#13/#14 无；#16–#19 无；#31 未用纹理冒充印刷，套印效果是真的两版叠底 + 错位；#5 未按品类选色（黄蓝来自"太阳 / 人群"两个对象）。
- 代入测试：部分过。换成"演唱会"会弱（演唱会在室内、无太阳）；换成"运动会"人群不会举手听歌，但仍半成立——原因是题目本身没有任何独有事实，已用加盖区留出接入真实信息的位置。
- 必保项：过（叠色、纸缝都在）。
- 事实：过。没有编造名称/日期/阵容。
- 零错字：过（音乐节、日期、地点）。
- 完成标准：1 过（300px 标题）；2 过（头 + 肩 + 举起的手臂，远小近大 18 排）；3 过（multiply 叠底：黄 × 蓝 ≈ #324D00）；4 过（32px ≥ 24px；蓝 #3255A4 对白约 7:1）；5 过。
5.2
- 一瞥测试：过。主角"音乐节"三字，其次人群。
- 主焦点唯一：过。太阳是低对比大色面，不与标题争。
- 模糊测试：过。墨块依次为：顶部大字 → 底部蓝色人群块 → 黄圆。
- 事故区：过。标题 x=66 与加盖区 x=70 的 4px 差是有意的：300px 字形自带约 4–6px 左侧距，标题视觉左缘因此与加盖区共用 x≈70 这条左边线。
- 字高：过（32px ≥ 24px）。
- 对比度：过（标题蓝 vs 纸约 6.8:1；标题压黄处深绿 vs 黄 > 7:1）。
- 边距：过。文字距左 ≥ 70（0.065S = 70）。太阳与人群出血是有意的。
- 层级：过。两级字号 300 / 32，字重 900 / 700，一个字族。
- 颜色剂量：过。两种油墨 + 一种叠色，无额外强调色。
- 渲染：过（矢量；无渐变色带）。
- 多尺寸：过。缩到 270px 宽仍能认出字和人群。
