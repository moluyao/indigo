# 第 3 轮框架效果测试：结果（2026-11-21）

只用 Opus 5.5。A 组用青出 core v2.1，B 组不用框架，C 组用 core v1；每组计划独立做 3 次。三道新题：社区图书馆周末活动宣传图（1080×1350 静态）、15 秒讲清楚天空为什么是蓝色（1920×1080）、新耳机 6 秒竖屏宣传动画（1080×1920）。三组都允许自己渲染检查。两位独立的 Opus 评审按 `rubric-v2.md` 盲评，评审原文 `review-r3-a.md`、`review-r3-b.md`，编号对照 `blind-key-r3.json`。

## 结果

### 交付时达到 L2（商业合格）的件数

| 组 | 评审 a | 评审 b |
|---|---|---|
| A（v2.1） | **7 / 8** | **5 / 8** |
| B（不用框架） | 0 / 9 | 0 / 9 |
| C（v1） | 0 / 7 | 0 / 7 |

两位评审给出的全部 L2 都出自 A 组；B、C 两组没有一件达到 L2。其余作品都是 L0，原因全是可以修的执行失误（文字停留不够、字太小、空白填写栏、开头静止），没有一件是想法不成立。

|---|---|---|
| 海报 | A（前三名全是 A） | A（前三名全是 A） |
| 科普 | A（前两名都是 A） | C1，A 第 2、3 |

### 平均分（1–5）

| 组 | 创意（a / b） | 执行·修好后上限（a / b） |
|---|---|---|
| A（v2.1） | **3.25 / 3.12** | 3.00 / 3.00 |
| B（不用框架） | 1.89 / 2.22 | 3.11 / 3.56 |
| C（v1） | 3.00 / 3.00 | 2.86 / 3.00 |

"执行·修好后上限"是评审估计的、把底线问题修好之后能到的执行分，不代表交付时的样子；交付时的执行要看上面的 L2 件数。

## 结论

1. **v2.1 达到了两个目标。** 创意分不低于 v1（3.25 / 3.12 对 3.00 / 3.00）；交付时的执行明显高于 v1：A 组 8 件里 7 件（评审 a）、5 件（评审 b）达到商业合格，v1 一件都没有。v1 典型的失误——空白填写栏——在 C 组的三张海报上全部出现，A 组一件都没有。
2. **框架依然明显好过不用框架。** B 组创意分最低（约 2），而且是撞车最集中的一组：三张海报都是奶油底加橙红强调，耳机三件都是"暗底暖光晕加参数三连"，还编了没有标注的产品参数。
3. **A 组也有第二层撞车。** 海报 A1 和 A3 都把"请保持安静"门牌改成"大声"。评审 a 建议把它和"背景被填成结论色""编号三段科普骨架""噪音字满屏 → 只剩安静"一起增补进第二层默认登记表。
4. **A 组仍有执行失误。** A2 的科普动画开头 3.1 秒完全静止，被判 L0。

## 标准需要校准的地方（两位评审独立提出）

- **文字停留公式偏严**：0.5 s + 字数 ÷ 3.5 字/秒，对 6–15 秒的短片判下了 10 件；被判不过的停留多在要求值的 50–70%。这个阈值本来就标"待实验"，本轮数据可以拿来校准。
- **36 px 字高底线**：套到 1080×1350 的静态海报上可能偏严，要区分观看方式。
- **停帧自动检测**：暗底细小运动会误报，需要人工复核。

## 局限

- 样本不齐（见上），A 组有两次做到一半被拒。
- 两位评审都是 Opus，和制作者同一个模型。
- 两位评审都没能全速播放成片，运动类判断依据联系表和逐帧数据，偏保守。
- 没有 L3 标杆、没有不知情测试者，按规则最高只能给 L2。
