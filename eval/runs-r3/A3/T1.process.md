# T1 过程 · 社区图书馆周末活动宣传图

## ① 理解

原话（合同）：「给社区图书馆做一张周末活动的宣传图。」技术合同：1080×1350 静态，自包含 HTML，系统字体。

| 维度 | 状态 | 理由 / 处理 |
|---|---|---|
| 题材 | 已说 | 社区图书馆的周末活动 |
| 受众 | 隐含 | 因为"社区"，所以是步行可达的周边居民，含带孩子的家长 |
| 目标反应 | 空白→替定 | "这周六图书馆居然让大声读书，带孩子去" |
| 观看情境 | 隐含 | 因为 4:5 宣传图 + 社区，所以在手机里看（居民群、朋友圈），满宽显示，静态、看一次，与群聊消息同屏竞争；也可能打印贴馆内 |
| 材料与事实 | 事实空白 | 活动名、时间、地点、报名方式、馆名都没给 |
| 格式 | 已说 | 1080×1350 单图 |
| 中心想法 / 外观 / 结构 | 空白 | 替定，见 ③④ |
| 声音 | 不适用 | 静态 |
| 禁止项 | 空白 | 按 ⑤ |

猜错会作废什么：活动类型猜错 → 文案和主视觉都要换（作废整张图）。没有用户可问 → 替定"亲子大声朗读会"，另一种可选是"读书分享会/手工课"；主视觉绑在"图书馆平时要安静"上，换成任何"出声的活动"（故事会、朗诵、读书分享）都还成立。

来源标签：
- 馆名"梧桐里社区图书馆"〔例〕安排类
- 活动名"亲子大声朗读会"〔例〕安排类
- 日期 11 月 28 日（周六）〔例〕决定类，已核对 2026-11-28 是星期六
- 时间 15:00–16:30〔例〕决定类
- 地点"一楼少儿阅览区"〔例〕决定类
- 报名"到馆服务台登记，免费"〔例〕决定类
- "带一本想读给别人听的书"〔例〕安排类
- 不出现任何证明类内容（往期人数、好评、"已办 N 期"）→ 删。

## ② 两层默认

- 第一层：表面＝暖奶油底、绿或蓝主色、圆体字、扁平插画小人捧书；构图＝居中大标题 + 堆叠书本插图 + 底部信息条；结构＝眉标"周末活动" → 标题 → 三张信息卡（时间/地点/报名）→ 二维码。
- 变体：同构图换成水彩风书架、换成深蓝夜空星星书本。
- 反面：极简白底大字。
- 第二层：①借书卡/还书日期戳单据（命中 3.3-5 单据母题）；②书脊排成书架、每本书脊上写一项信息（换主题测试：换成"社区面馆"就换成碗排一排，仍成立 → 母题来自形式）；③打开的书页做版面（代入测试：任何读书活动都成立 → 品类默认）。

## ③ 方向（取向乙）

最近同类：书店活动、学校读书节、博物馆周末活动。
独有事实（冻结）：
- F1 图书馆平时有"请保持安静"的规矩，墙上挂着牌子；书店、博物馆都不这么强调。
- F2 书是借的，要还，每本书被很多陌生邻居读过。
- F3 社区馆就在楼下，免费，不用买东西也能待一下午。

方向：
1. 【F1】"图书馆墙上那块'请保持安静'的牌子，被人用红笔划掉，改成了'请大声朗读'——这周六可以出声。"换主题：面馆没有安静牌 → 不成立，过。代入：书店不成立，过。没有这份提示我第一次会写出它吗：不会。
2. 【F2】"一本书扉页的借阅记录里，写满了同一个小区不同门牌号——这周六这些人坐到一起。"需要真实借阅记录，编了就是造证明；且近单据母题 → 放弃（落进默认区 + 材料不存在）。
3. 【F3】"一张小区平面图，从每栋楼到图书馆的步数。"步数需真实地图〔无〕→ 放弃（材料不存在）。
4. 【F1 再问】"整张图几乎全是空白，只有角落一行很小的字，后面一行字突然很大"——与 1 同靠 F1、事后描述只差手法 → 近亲，并入 1。
停止点：F1 连续两次无新方向，F2、F3 各一次放弃，事实轮完。写出 4 − 并入 1 = 剩 3，放弃 2，留 1。

## ④ 收拢（自选）

选方向 1。契合：落在"请保持安静"这块牌子上，只有图书馆有；受众一瞥就懂"这次能出声"，对家长和孩子正是邀请理由；材料只要字和一条红笔线，现有工具做得到。放弃 2、3（材料不存在）。前提一变：若真实活动不出声（如安静自习、展览），应换到方向 3 的"就在楼下"。

方向承诺：
| 失守处 | 失守时变成 | 守住的样子 + 怎么查 |
|---|---|---|
| 最难：牌子要像一块真牌子 | 一个圆角白卡片 | 有亚克力厚度边、四颗螺丝、墙面底；看截图能说出"墙上的牌子" |
| 红笔改字 | 规整红色字体 + 直线（像排版）| 用行楷、笔画线有起笔收笔粗细变化、改字略斜（-4° 左右）|
| 强度 | 牌子太小，像插图 | 牌子占画面面积 ≥ 40%；"安静"二字到达字高 ≥ 140 px |
| 小件：信息区 | 塞成三张卡片 | 一列文字，用字号级差分层，不加容器 |
| 小件："示例"标记 | 漏标 | 信息区贴着写"示例信息·发布前替换"，字高 ≥ 24 px |

## ⑤ 简报

1. 变量：受众＝社区居民和家长；目标反应＝"这周六图书馆能大声读书，去"；情境＝手机满宽，s = 1；格式 1080×1350 PNG/HTML。区块出口：牌子＝知道"这次可以出声"；信息区＝知道哪天几点在哪、怎么报名。
2. 替换表见交付说明。
3. 执行要求：流读字到达 ≥ 36 px，目标 48；停读 ≥ 24 px；左右边距 ≥ 72 px；对比度 ≥ 4.5:1（红字作为大号字 ≥ 3:1，实际做到 ≥ 4.5）；无占位、无裁字。
4. 完成标准：
   - 注意到：缩到群聊缩略图（约 1/3）仍看得出"被红笔改过的牌子"。测法：缩图看。失败：看成一张普通标题海报。
   - 读懂：一瞥后说得出"可以大声读"。失败：说不出活动和出声有关。
   - 去做：只看信息区能说出日期、时间、地点、怎么报名。失败：任一项缺。
   - 反例：更像"居中标题 + 书本插图 + 三张信息卡"即失败。
5. 禁止：书本堆叠插图、扁平小人、眉标胶囊、信息卡片三连、二维码占位、借书卡单据；编造参与人数或评价。它不是一张活动海报，它更像一张拍下来的、被改过字的告示牌。
6. 形容词：无。

默认满足测试：默认作品不满足"牌子占 ≥40% 且被红笔改字"，不满足"信息区不加容器"。过。

## ⑥ 制作

墙面取图书馆常见的浅灰绿墙漆（轻染彩度约 0.03），牌子近白亚克力 + 黑字（黑体），唯一信号色是红色马克笔（K=1：只用在改字处 + 信息区日期一处？——不，日期不用红，红只出现在改字这一个关键时刻）。改字用华文行楷，回退楷体。

## 渲染记录（⑦）

第 1 轮渲染：改字"大声朗读！"超出牌子右缘被裁（不合格）。现象 → 目标 → 验证：改字右缘出牌子 → 收进牌子内 ≥ 30 px → DOM 量包围盒。修：去掉"！"，字号 178→160，左移。别动：牌子、信息区。
第 2 轮测量（DOM 包围盒）：牌子 80–1000 × 118–778，占画面 41%（≥40% 过）；改字 314–964（牌子内余 36 px，过）；附注 348–945（过）；印刷字 140–940（过）。
字高：印刷字 160 px、改字 160 px、标题 84 px、信息 48/54 px、示例标 26 px（停读 ≥24 过），无 12–24 px 禁区字。左右边距 80 px ≥ 72 过。对比：黑字/近白牌 ≈ 17:1；红 #d1271d/牌 ≈ 5.3:1；正文 #1f2723/墙 #dfe5df ≈ 12:1；示例标 #4f5a53/墙 ≈ 5.6:1。全过。无占位、无署名。
完成标准：缩图仍见"被红笔改过的牌子"（主视觉占 41%）；信息区四项齐全。反例对照：无书本插图、无卡片、无眉标 → 不像默认。
