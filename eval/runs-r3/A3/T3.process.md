# T3 过程 · 6 秒竖屏耳机宣传动画

## ① 理解

原话（合同）：「给一款新耳机做一个 6 秒的竖屏宣传动画。」技术合同：1080×1920，6 s 整，自包含 HTML，`__seek(ms)`，无声。

| 维度 | 状态 | 理由 / 处理 |
|---|---|---|
| 题材 | 已说 | 一款新耳机 |
| 受众 | 隐含 | 因为"竖屏宣传"，是刷手机信息流的普通消费者 |
| 目标反应 | 替定 | "戴上它，周围一下就安静了" |
| 观看情境 | 隐含 | 因为竖屏，在手机上满屏看，常静音，刷到即走，同屏竞争强 → 第 0 帧就要是完整构图、力度要高 |
| 材料与事实 | 事实空白 | 品名、形态、续航、降噪、价格都没给 |
| 格式 | 已说 | 1080×1920 / 6 s |
| 外观、结构 | 空白 | 替定 |
| 声音 | 已说 | 无声 |

猜错会作废什么：形态（头戴还是入耳）一错，主视觉就作废 → 本该问；没有用户可问 → 替定为**头戴式**，另一种可选是真无线入耳（那就要换方向 B，见 ④）。
来源标签：品名「屿声 Q1」〔例〕安排类，可替换；文案「戴上，世界小声了。」〔例〕，依据的是头戴闭合式罩耳带来的被动隔音（所有罩耳式通用、不算编造的性能）；若产品是开放式，文案要换。续航、降噪深度、价格都是证明类或决定类，用户没给 → **不出现**。

## ② 两层默认

- 第一层：表面＝近黑底 + 产品背后径向光 + 霓虹描边；构图＝居中产品慢转 360°；结构＝logo 淡入 → 参数三连（40h / ANC / 蓝牙）→ 结尾品名 + 购买按钮；变体＝白底苹果式；反面＝高饱和波普。
- 第二层：①声波正弦线被"拉平"成一条直线代表降噪；②耳机外壳爆炸图配参数。换主题测试：①可用于任何"降噪/安静"产品，②可用于任何硬件 → 都排除。

## ③ 方向（取向乙）

独有事实（冻结）：
1. 头戴式的两只耳罩是相对夹合的，中间空着的那块正好是"一颗头"的位置——产品形状由一个缺席的东西定义。
2. 竖屏＝观众手里的手机；画框的左右两边就是观众正握着的边。
3. 戴上的那一下是一个动作：从上往下罩住，接触那一刻外界声音就变闷。

方向：
- A（事实 1+2+3）**画面里到处是跳动的"嘀 轰 嗡 哔"噪声字，一副大耳机从上方落下，两只耳罩正好扣在手机屏幕左右两边——手机屏就是那颗头——扣住的一瞬间，所有噪声字冻住、消失，屏幕变安静，只剩品名和一句话。** 换主题（面馆）不成立；代入同类（耳机广告）：多数是"产品转圈"或"声波拉平"，不是"屏幕被戴上"。没有提示我第一次不会写它。
- B（事实 3）**一只耳朵的特写，耳机罩过来，耳廓轮廓被遮住，背景字声变闷。** 要画写实耳朵，难做好，且容易成人物特写广告。
- C（事实 1）**耳机的头梁弧线当成一道拱门，镜头从拱门里穿过去。** 好看，但讲不出"它给你什么"。
写出 3 − 并入 0 = 3。

## ④ 收拢（自选）

选 A。契合点落在"竖屏"：只有竖屏手机满屏时，耳罩扣住画框左右两边才等于扣住观众手里的东西；6 秒只够一个事件，A 恰好就是一个事件（扣上）。放弃 B（写实耳朵画不好）、C（没有利益点）。前提变化：如果产品是入耳式 → 换 B 的思路（耳朵特写）。

方向承诺：
| 失守处 | 失守时会变成 | 守住的样子 + 怎么查 |
|---|---|---|
| 最难：耳机画得认得出 | 两个圆角块 + 一条弧，像夹子 | 有头梁、滑杆、耳罩、耳垫四个部件；落定帧截图给人看能说出"耳机" |
| 扣上那一下的力度 | 慢慢淡入，没有落点 | 2.4 s 单帧完成底色切换（红→浅灰，相对亮度差 ≥ 0.4），噪声字同帧冻住，0.25 s 内消失 |
| 小件：品名、文案 | 字小或压在耳罩上 | 文案设定 ≥ 80 px，品名 ≥ 120 px，左右边距 ≥ 72 px，放在耳罩下方，不与耳罩重叠 |
| 耳罩不出画 | 耳罩被画框切掉 | 落定时耳罩外缘离左右边 ≥ 72 px |

## ⑤ 简报

1. 变量：信息流用户；目标反应"戴上就安静了"；手机满屏、静音、一次；1080×1920 / 6 s。段落出口：S1（0–2.0）感到"吵"；S2（1.7–2.4）看到耳机罩下来；S3（2.4–6）知道品名 + "戴上，世界小声了"。
2. 替换表（无决定类）：品名「屿声 Q1」〔例〕可替换；文案〔例〕可替换（开放式耳机需改）；形态"头戴式"为替定，须用户确认。
3. 执行要求：流读字 ≥ 48 px（取 80–96 px）；左右边距 ≥ 72 px；底部 20%（y > 1540）不放须读字（平台标题区，没有截图，属于推算不了，远离处理）；S1 文案「到处都在响。」5 字，T ≥ 1.93 s，第 0 帧就完全不透明；S3 文案 8 字 T ≥ 2.79 s（3.0 → 6.0 = 3.0 s）；对比度 ≥ 4.5；末段 3.4 s 之后整帧静止。
4. 完成标准：第 0 帧截图 → 失败：说不出"吵"；2.6 s 帧 → 失败：认不出耳机；末帧 → 失败：读不出品名或文案；首末帧对比说不出"变安静了"。
5. 禁止：黑底径向光、产品转圈、声波拉平、参数三连、编造续航/降噪数字、购买按钮。它不是一支产品转台片，它更像"手机被戴上了耳机"的一个瞬间。

## ⑥ 制作

Canvas 2D。噪声字的位置、大小、字形由 hash(序号) 定，抖动按 12 fps 步进由 hash(序号, 步号) 定，确定性。耳机下落 1.7–2.4 s，用加速下落（重力感，越落越快），在 2.4 s 硬落定，没有回弹。
