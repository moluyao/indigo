【理解】
原话：「给社区图书馆做一张周末活动的宣传图。」
合同：对象是社区图书馆；内容是周末活动；交付是一张宣传图（技术要求：1080×1350 静态 HTML）。
维度状态（只列非"已说"的）：
- 受众｜隐含｜附近居民（家长、老人、学生），因为是"社区"图书馆。
- 目标反应｜隐含｜"这周末图书馆有活动，我去看看"。
- 观看情境｜隐含｜贴在馆门口/公告栏，或转到小区群里手机上看；无声；看一两眼。
- 材料与事实｜事实空白｜馆名、活动名称、日期、时间、地点都没给。处理：不编造，画面只用本身为真的东西（"社区图书馆""周末""周一到周日"），活动/时间/地点做成卡片上的手写空栏，馆员拿笔填。
- 中心想法 / 外观 / 结构｜空白｜交给发散。
- 禁止项｜隐含｜不编造活动和日期。
替你决定的：活动信息留手写空栏（另一种可选：给我活动名称和时间，我直接排进去）。

【排除的默认】
默认：表面——暖米色底 + 衬线大标题 + 赤陶强调，或浅蓝渐变 + 扁平书本插画/小人；构图——居中大标题"周末阅读时光"，下面一排三个图标卡（亲子共读/读书会/手工）；结构——标题→活动卡→底部时间地点条。
变体：同一套换成绿色或手绘风书架插画。反面：黑底霓虹"周末书夜"。

【方向】
① 还书日期卡：整张图就是一张图书馆借书卡，周一到周五的日期章是淡紫色的旧印，最后一枚红章盖着"周末"。（排除了插画和图标卡；物件即画面）〔我平时不会这么做〕
② 书脊排队：一排真实比例的书脊从左到右，书脊上的索书号标签拼出"周六 周日"。（排除平面插画，结构=一排同类+一个例外）
③ 开门时刻：用馆门口营业时间牌的版式，周六周日两行被单独点亮。（借用导视/告示牌品类）
④ 字面画面：阳光照进阅览室，一个孩子在读书的场景插画。（字面方向，只占一个）

【选择】
选了①还书日期卡。
契合在于：借书卡上的"还书日期章"是社区图书馆独有的物件，居民一眼认得；一周日期章从周一盖到周五，再到一枚大红"周末"章，等于把"周末"本身演成那唯一的例外。
放弃了②书脊（索书号拼字识别慢，一瞥测试弱）、③营业牌（像通知不像邀请）、④插画（换成任何书店也成立，过不了代入测试）。
被放弃的在这些条件下更好：②在馆方有真实书单要推时；③在活动是"延长开放"时；④在有真实馆内照片时（应直接用照片）。
借来的一个元素：③的"告示"直白——空栏用馆员手写的方式填，不做假活动。
方向承诺：拥有的想法——"周末"是这一周借书卡上最后、最大的那枚章；拒绝的默认——米底衬线赤陶、图标三卡、扁平小人。它自己的世界：牛皮黄卡纸、深蓝印刷格线、紫色日期章墨、唯一一处朱红印泥；字体是印刷黑体 + 橡皮章数字。第一眼：一枚斜盖的大红"周末"章压在格子上。

【简报】
受众：社区居民｜目标反应："这周末去图书馆看看"｜观看情境：公告栏 A3/手机竖图｜格式：1080×1350 静态。
做到什么算完：
1. 一瞥能说出"图书馆、周末"。测法：看 0.5 秒遮住。失败：说不出"周末"。
2. 认得出是借书卡。测法：问"这像什么"。失败：答"海报/表格"。
3. 空栏能直接手写。测法：空栏行高 ≥ 70px、底色浅。失败：写不下或看不出是空栏。
4. 须读字 ≥ 24px（0.022S），对比 ≥ 4.5:1。失败：任何须读字低于此。
必保项：朱红"周末"大章（全图唯一红色）；周一至周五淡紫旧章。
不要：外观——赤陶强调、衬线展示字、书本/小人插画；结构——标题+三卡+底条；内容——编造活动名、日期、馆名；技术——用噪点滤镜冒充印章。
反向定位：它不是一张活动海报模板，它更像馆员从书后口袋里抽出来的那张卡。

【自检】（渲染后）
- 默认对照：过，更像借书卡而非海报模板。
- 禁用清单：#3 暖底——底色是牛皮卡纸原色（物件同源），无衬线、无赤陶，强调色是印泥朱红，过；#11 等宽字——只用在日期章数字/编号上（橡皮章数字），过；#12 眉标——无；#17 三卡——无。
- 代入测试：换成书店或咖啡馆，借书卡不成立，过。
- 必保项：红章唯一、紫色旧章在，过。
- 事实：无编造活动/日期，馆名只写"社区图书馆"，过。
- 一瞥/主焦点：红章唯一主焦点，过。
- 字高：最小须读字 26px ≥ 24px，过。对比：深蓝 #1F2A5C 于 #E8D6A6 约 10:1，过；紫章是装饰性"旧章"，非须读。
- 边距：内容离边 ≥ 70px，过。
- 颜色剂量：红只一处，过。
- 完成标准 1–4：过（渲染 1 张检查；发现大章下沿压到"活动"栏，已上移 38px）。
