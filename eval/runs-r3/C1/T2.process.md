【理解】
原话：「做一个 15 秒的动画，讲清楚为什么天空是蓝的。」
合同：15 秒整；动画；目标是"讲清楚"原因；对象是天空的蓝色。技术：1920×1080，无声，可 seek。
维度状态（只列非"已说"的）：
- 受众｜空白｜替定：初中水平的普通观众（不懂"瑞利散射"这个词）。
- 目标反应｜隐含｜"哦，原来是空气把蓝光撞到了我眼里"，因为原话是"讲清楚为什么"。
- 观看情境｜隐含｜横屏、无声（技术要求无声），可能只看一遍 → 字幕承担全部信息。
- 材料与事实｜查｜瑞利散射强度 ∝ 1/λ⁴；红光约 700 nm、蓝光约 450 nm → (700/450)⁴ ≈ 5.9；没有大气的月球上白天天空是黑的。均为教科书事实，非编造。
- 中心想法 / 外观 / 结构｜空白｜交给发散。
替你决定的：只讲"蓝"，不展开"为什么不是紫"和"晚霞为什么红"（另一种可选：拿最后 3 秒换成晚霞对照，代价是主线读不完）。

【排除的默认】
默认：表面——深蓝星空底 + 发光的太阳和光线 + 蓝紫光晕粒子；构图——左边地球、右边太阳，中间标"瑞利散射"；结构——标题卡 → 地球大气示意 → 公式 → 结尾金句卡；声音——无。
变体：同样的东西做成扁平矢量 + 小人讲解员。反面：纯白底极简线条，只有一个公式。

【方向】
① 天空被"涂"蓝：开头天空是黑的（没有散射的天空，月球那样），每个空气分子把蓝光撞向你的眼睛，看向哪里，哪里就被涂上蓝，直到满屏蓝。结构＝一个状态变化（黑→蓝），光以真实波长的正弦波画出。〔我平时不会这么做〕
② 弹珠台：阳光是一把彩色弹珠，空气分子是钉子，小的蓝珠总被弹开、大的红珠穿过去。借用游戏品类，排除光的波动画法。
③ 两次对照：同一画面先正午后黄昏，路径变长后蓝被撞光、只剩红——一组对照解释两个现象。
④ 字面画面：地球剖面 + 大气层 + 太阳光箭头 + 公式标注。（字面方向，只占一个）

【选择】
选了①天空被涂蓝。
契合在于："天空本该是黑的"这条事实（月球天空）让观众意识到蓝色是被"送进眼睛"的；屏幕从黑到满屏蓝的状态差就是答案本身，静音也看得懂。
放弃了②弹珠（"小珠弹得开"是错误的粒子直觉，波长才是关键）、③对照（15 秒装两个现象读不完）、④剖面图（换成任何"大气现象"都成立，过不了代入测试）。
被放弃的在这些条件下更好：②给低龄儿童且不在乎物理准确时；③时长 ≥ 30 秒时；④作为课本插图静态印刷时。
借来的一个元素：④的"数"——用 (700÷450)⁴ ≈ 5.9 的两根条把"更容易"量化一次。
方向承诺：拥有的想法——蓝不是天空的颜色，是被空气撞进你眼睛的光；拒绝的默认——星空蓝紫光晕、地球剖面、结尾金句卡。它自己的世界：纯黑无光晕的天空、一枚白色平涂太阳、三条真实波长比例的彩色正弦波、地面是深色条带兼作字幕带；运动是"波向右传播"和"从一点向外扩的圆环"。第一眼：黑天空里白太阳射出三色波，大字问"天空为什么是蓝的？"。

【简报】
受众：普通观众（初中水平）｜目标反应："空气把蓝光撞进了我眼里"｜观看情境：横屏、静音、一遍｜格式：1920×1080，15.000 s，window.__seek。
做到什么算完：
1. 第 0 帧就有完成构图与问题。测法：截第 0 帧。失败：黑场或空画面。
2. 每句字幕读得完。测法：停留 ≥ 字数÷9 s 且 ≥ 0.83 s。失败：任一句不足。
3. 看懂因果：蓝波在分子处向四周散开、红波穿过。测法：截 5 s 帧，只看图说"哪种光被撞开"。失败：说不出蓝。
4. 状态差：首帧天空黑、末帧天空蓝。失败：末帧仍有大块黑。
5. 字高：字幕 ≥ 0.067S≈72px？——字幕定 60px 主字 + 地面带对比，须读字 ≥ 0.033S=36px。失败：须读字 < 36px。
必保项：黑→蓝的整屏变化；三条按 700:550:450 比例的波。
失败点：圆环扩散的闪烁；字幕换句时文字重叠。
不要：外观——光晕、粒子、星空、蓝紫渐变；结构——标题卡开场、结尾居中金句卡；内容——编造数字；技术——用真实时间驱动 seek。
反向定位：它不是一段科普片头，它更像一块被慢慢涂满的黑板。

【自检】
- 默认对照：过，无星空光晕、无剖面图。
- 禁用清单：#2 近黑底——黑来自"没有大气的天空"这一事实，且无光晕、无霓虹，强调靠蓝本身；#4/#5 无；#18 条形——两根条是真实计算值，过；#23 金句卡——末句写在地面字幕带，不居中卡片，过；#29 无粒子；#33 字幕换句用位移 + 透明度，非全片同一动作（波传播、圆环扩散、条增长、涂色扩张各不同）。
- 代入测试：换成"晚霞为什么红"不成立（结局是满屏蓝），过。
- 事实：5.9 = (700/450)⁴ = 5.86，标"约"，过。
- 第 0 帧：太阳、波、问题都在，过。
- 读得完：最长句 18 字停留 3.2 s ≥ 2.0 s，过。
- 字高：问题 110px，字幕 58px，标签 40px ≥ 36px，过。
- 闪烁：圆环为细线、亮度变化平滑，无整屏翻转；黑→蓝只发生一次，过。
- 主角时序：开场=问题；2.9–6.6 s=分子散射；6.6–10 s=条形对比；10–13.6 s=涂色；末段=结论，过。
- 渲染：看 1 张联系表检查。
