【理解】
原话：「给一款新耳机做一个 6 秒的竖屏宣传动画。」
合同：对象是一款新耳机；6 秒整；竖屏；宣传动画。技术：1080×1920，无声，可 seek。
维度状态（只列非"已说"的）：
- 受众｜隐含｜刷手机短视频的人，因为"竖屏"。
- 目标反应｜隐含｜"想戴上试试"，因为是宣传。
- 观看情境｜隐含｜手机竖屏信息流、常静音、只看一遍、上下有平台界面遮挡。
- 材料与事实｜事实空白｜品牌、型号、外观、颜色、降噪/续航等卖点全部没给。处理：不写任何参数和卖点，只用耳机本身为真的东西——头梁、两只耳罩、戴在头上、给一个人听。
- 中心想法 / 外观 / 结构｜空白｜交给发散。
替你决定的：画面写"新耳机"而不写产品名；耳机画成通用头戴式剪影（另一种可选：给我产品名、主色和真实产品图，替换剪影与名字）。

【排除的默认】
默认：表面——近黑底、耳机 3D 渲染缓慢旋转、边缘光 + 霓虹蓝/紫光晕、粒子声波；构图——耳机居中、上方产品名、下方三个卖点图标"降噪 · 续航 · 音质"；结构——黑场淡入 → 旋转展示 → 卖点逐条弹出 → logo 收尾；声音——无。
变体：同样的东西换成白底苹果式极简。反面：满屏花字、快速闪切的"炸裂"风。

【方向】
① 屏幕戴上耳机：整个竖屏就是一颗头。耳机从上方落下，两只耳罩扣在屏幕左右两条边上；扣上的瞬间满屏"吵"字掉出画面，颜色从两只耳罩涌进来。结构＝一个动作（戴上）+ 前后状态差。〔我平时不会这么做〕
② 单线画：一根线画出头梁，线继续走成一段声波，再收回成耳罩。媒介＝单线画。
③ 一个耳罩的特写尺度旅行：镜头从耳罩外壳推进到耳垫纹理再到里面的一首歌。结构＝跨尺度。
④ 字面画面：耳机居中旋转展示 + 卖点。（字面方向，只占一个）

【选择】
选了①屏幕戴上耳机。
契合在于：竖屏手机的"左右两条边"恰好是头戴耳机扣住的位置——观众手里的手机被戴上了耳机，这个动作只有头戴耳机有；静音也看得懂"戴上 → 吵的东西掉光"。
放弃了②单线画（6 秒内线条变形难一眼读出耳机）、③跨尺度（没有真实产品材质可推进，会变成编造细节）、④旋转展示（没有产品图，且任何耳机都成立）。
被放弃的在这些条件下更好：②有品牌线条识别系统时；③有真实产品高清材质时；④有真实 3D 模型且卖点已给时。
借来的一个元素：②的"声波"——扣上之后屏幕中间只留一根细声波线，代表"你的歌"。
方向承诺：拥有的想法——你的手机屏幕被戴上了耳机；拒绝的默认——近黑底旋转产品 + 霓虹光晕 + 卖点图标。它自己的世界：前段灰白底 + 一地抖动的灰色噪音字；后段整屏番茄红平涂 + 哑黑耳机 + 一根黑色声波线；运动是"落下—扣住—掉落"的重力语言，只有扣住那一下有一次压缩。第一眼：灰底上满是乱抖的"喇叭/电钻/报站"小字，中间大字"好吵。"，耳机悬在屏幕上方。

【简报】
受众：刷竖屏信息流的人｜目标反应："戴上就清净了，想要"｜观看情境：手机竖屏、静音、一遍｜格式：1080×1920，6.000 s，window.__seek。
做到什么算完：
1. 第 0 帧成立：能看到"吵"和耳机。测法：截 0 ms。失败：空背景或黑场。
2. 一眼读出"耳罩扣在屏幕两边"。测法：截 2.3 s 帧问"这是什么"。失败：认不出是戴上耳机。
3. 字读得完：每句停留 ≥ 字数÷9 s 且 ≥ 0.83 s。失败：任一句不足。
4. 安全区：须读字离左右边 ≥ 70 px，主文字在 y 400–1500 内（避开平台上下界面）。失败：越界。
5. 状态差：首帧灰乱、末帧红静。失败：末帧仍有噪音字。
必保项：耳罩扣在屏幕边缘这个动作；颜色从耳罩涌入。
失败点：噪音字下落频闪（加拖影）；耳机部件在扣合时错位。
不要：外观——黑底霓虹、光晕、粒子声波、3D 旋转；结构——黑场淡入、卖点图标三连、logo 收尾；内容——编造降噪/续航/音质参数、品牌名；技术——用真实时间驱动 seek。
反向定位：它不是一支产品展示片，它更像一张会动的"戴上耳机"贴纸，贴在你的手机上。

【自检】
- 默认对照：过，无黑底旋转、无卖点。
