# T3 新耳机 6 秒竖屏宣传 · 过程

## ① 理解
原话：「给一款新耳机做一个 6 秒的竖屏宣传动画。」
合同：新耳机；6 秒；竖屏；宣传。统一要求：1080×1920、无声、`__seek`。

| 维度 | 状态 | 说明 |
|---|---|---|
| 题材 | 已说 | 一款新耳机（型号、形态、卖点都没说）|
| 受众 | 空白→替定 | 刷短视频的普通用户 |
| 目标反应 | 空白→替定 | "这副耳机把我圈在中间" |
| 观看情境 | 隐含 | 竖屏 1080 → 手机满屏，s=1.0；无声（统一要求），信息流里同屏竞争强 → 第 0 帧就要是完成构图 |
| 品名 | 事实空白（安排类）| 填示例"听岛 H1"，可替换，屏上贴"示例名" |
| 形态 | 空白→替定 | 头戴式（另一种可选：真无线入耳）；猜错会作废整片画面 → 本应问，无人可问，替定并写进交付说明 |
| 卖点参数（续航、降噪深度、价格）| 证明类/决定类〔无〕| 不编，不出现；价格不出现 |
| 外观 | 示意 | 画的是明显图形化的耳机，不冒充真实产品照 |

## ② 两层默认
- 第一层：表面＝近黑底＋产品背后径向聚光＋金属反光＋霓虹蓝紫声波；构图＝产品居中慢转；结构＝黑场 → 产品转出 → 参数三连闪（"40h 续航 / 主动降噪 / Hi-Res"）→ 品名＋上市；动效＝匀速慢推＋光斑扫过。
- 变体：白底苹果式极简、换成渐变紫。
- 反面：亮色波普，耳机在彩色背景前弹跳。
- 第二层：①声波/均衡器条从耳罩里流出，变成城市天际线；②耳机戴在一颗石膏头像或剪影头上，周围噪音字被"静音"划掉（降噪母题，换主题测试：任何降噪耳机都成立 → 第二层）。

## ③ 方向（取向乙）
最近同类：蓝牙音箱广告、入耳耳机广告、智能手表广告。
独有事实（冻结）：
- F1 头戴耳机的两个耳罩印着 L 和 R：它是唯一一种"分左右、要套在人身上"的音频产品。
- F2 两个耳罩之间留出的那一段空，正好是一颗头的宽度——产品的形状是为"你"留的空位。
- F3 戴上的动作是"张开 → 合拢、轻轻夹住"，耳垫会被压扁一点。

方向：
- D1（F2+F3）耳机从合拢状态张开，中间空出来的地方写着"中间，留给你"，最后耳罩轻轻合拢，正好夹住这几个字。事后描述："耳机张开，中间留了个空写着'留给你'，然后把字夹住了。"换主题测试：换成面馆不成立 ✓；代入测试：音箱、手表没有"中间的空位" ✓。没提示我会写吗？不会 ✓。
- D2（F1）巨大的 L 和 R 分在屏幕两半，像两只耳朵，中间是观众的脸位置。事后描述："屏幕左右一个 L 一个 R。"与 D1 都靠"中间是你"，只差一个元素 → 近亲，并入 D1（借事实 F1：耳罩上印 L/R）。
- D3（F3）耳垫被压扁的特写慢回弹，表现柔软。→ 需要材质真实感（软体 3D），且"柔软"属于卖点承诺，无事实 → 弃。
写出 3，并入 1，弃 1，剩 1。

## ④ 收拢
选 D1。契合：落在"耳罩之间的空"这个只有头戴耳机才有的东西上；无声观众只看形状就懂"给你的"。放弃 D3；D2 只借 F1（L/R 字样，不借分屏版式）。前提一变：若是真无线入耳，换成"两颗耳塞之间隔着一张脸宽"的 D2 版。
方向承诺：
| 失守处 | 失守时 | 守住的样子 + 怎么查 |
|---|---|---|
| 夹住（最难）| 耳机只是张开停住，没有收尾动作 | 3.8–4.4 s 耳垫内侧从 ±230 收到 ±200，与字块边缘距离 ≤25px，测坐标 |
| 强度：耳机占屏 | 小在中间，像图标 | 张开时耳机宽 ≥ 画面宽 75%（≥810px），首帧放大 1.3 倍 |
| 小件：品名与"示例名" | 字小或被遮挡区挡 | 品名 120px，示例名 40px，都在 y≤1500 以上 |
| 小件：首帧 | 黑场或半成品 | 第 0 帧＝合拢的耳机完整构图 |

## ⑤ 简报
1. 受众：信息流用户。目标反应："这副耳机把'我'夹在中间。" 格式 1080×1920，6.000 s。段：0–0.5 合拢（认出耳机，L/R）；0.5–1.5 张开（中间空出来）；1.6 起"中间，留给你"（知道空是给我的）；2.6 起品名（知道叫什么）；3.8–4.4 合拢夹住（记忆点）；4.4–6.0 静止。
2. 事实：无参数。替换表：品名"听岛 H1"〔例〕可替换，非决定类。
3. 执行要求：s=1.0；流读 ≥36px，目标 48；本片字 ≥120px；停读 ≥24；左右边距 ≥72px；底部 y>1500、右侧互动栏区域（x>900, y 900–1600）不放须读字（平台截图不在手，按远离处理）；对比 ≥4.5:1。字卡：「中间，留给你」n=6 → T≥2.21 s；「听岛 H1」n=4 → T≥1.64 s。末帧静止 ≥1.5 s。
4. 完成标准：
   - 注意到：第 0 帧缩略图能认出是耳机。失败：认成别的物件。
   - 读懂：说得出"这是一款新耳机，叫听岛 H1"。失败：说不出名字。
   - 留下：复述含"夹住/中间留给你"。失败：只说"一个耳机广告"。
   - 反例：更像暗底聚光转产品+参数三连即失败。
5. 禁止：近黑底径向聚光、金属扫光、声波/均衡器、参数字卡、上浮淡入、编造续航/降噪数字。它不是一支参数广告，它更像一个"给你留了座位"的手势。
6. 形容词：番茄橙底 #e2532d（整屏色域，让奶白耳机成为唯一浅色大块）；奶白壳 #f3efe6；深棕耳垫 #2a2622。

## ⑥ 制作
canvas 2D，render(t)；耳罩圆角矩形 200×300，内侧耳垫 40px；头梁为二次曲线粗描边，跟随耳罩端点。张开用 ease-out（减速到停，表示手在放），夹住用 ease-in-out（施力再停）。

## ⑦ 自检与回炉
渲染 2 次；看图 1 张（T3.sheet.jpg）。render.json：seek 可复现、冻结、180 帧 0 失败、无外部请求 ✓。
- 回炉 1 处：头梁上的深色内线画在了头梁外侧，读成一条多余的弧 → 删除该线（纯删除，别动：耳罩、文字、时间线）。
- 字高（s=1.0）："中间，/留给你" 120px、"听岛 H1" 120px（≥48 目标）✓；"示例名" 40px 停读 ✓。
- 边距：张开时耳罩外沿 x=110/970 ✓（≥72）；字块 ±180 → x 360–720 ✓；须读字都在 y≤1420，不进底部遮挡区（平台截图未得，推算不了具体值）。
- 夹住强度：合拢后耳垫内侧 ±200，字块边 ±180 → 间隙 20px ≤25 ✓；张开时耳机总宽 860px = 80% 画宽 ≥75% ✓。
- 对比：黑字 #141210/番茄橙 ≈4.0:1（120px 粗体按大号字 ≥3:1 ✓；不足 4.5，若改小字须加深底色）；示例名 #3b140a/橙 ≈3.6:1（40px，大号字 ≥3 ✓）；L/R 深棕/奶白 ≈13:1 ✓。
- 停留：标语 n=6，可读 1.75→6.0，T=4.25 ≥2.21 ✓；品名 n=4，可读 2.75→6.0，T=3.25 ≥1.64 ✓。
- 节奏：可辨变化 4 次——0.5 s 张开（尺度 ×0.77、大位移）、1.6 s 标语、2.6 s 品名、3.8 s 夹住；最长无新事件段 2.75–3.8（1.05 s），4.4–6.0 静止 1.6 s 为声明的结尾（ease-in-out 减速到零）✓。首帧＝合拢耳机完整构图，0–0.5 静止为设计 ✓。无闪烁 ✓。因果：标语在张开结束（1.5）后 0.1 s 出现 ✓。
- 完成标准：注意到 ✓（首帧轮廓即耳机，L/R 可读）；读懂 ✓（品名在屏 3.25 s）；留下（"夹住"复述）需外人测，推算不了；反例：无暗底聚光、无参数卡 ✓。
- 换主题测试：换成面馆，"耳罩之间留给你"不成立 ✓。
