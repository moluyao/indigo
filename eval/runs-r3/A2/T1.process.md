# T1 社区图书馆周末活动宣传图 · 过程

## ① 理解
原话：「给社区图书馆做一张周末活动的宣传图。」
合同：社区图书馆；周末活动；一张宣传图（1080×1350 静态，统一技术要求）。

| 维度 | 状态 | 说明 |
|---|---|---|
| 题材 | 已说 | 社区图书馆周末活动 |
| 受众 | 隐含 | 因为"社区"，所以是附近居民、带孩子的家长、老人 |
| 目标反应 | 空白→替定 | "周六下午拿本旧书去图书馆换一本" |
| 观看情境 | 隐含 | 因为 1080×1350 竖版 4:5，所以是手机满屏（业主群/朋友圈/公众号），静音、一瞥，室内亮度，同屏竞争为聊天消息流 |
| 活动内容 | 事实空白（安排类）| 用户没说什么活动 → 填示例"旧书交换"，可替换 |
| 图书馆名、时间、地点、参与方式 | 事实空白 | 名称为安排类；时间、地点、参与方式为决定类 → 填示例并标"发布前须用户确认" |
| 往期人数、好评 | 证明类〔无〕| 删掉，不出现 |
| 格式 | 已说/隐含 | 1080×1350 单张，HTML 自包含 |
| 中心想法/外观/结构 | 空白 | 自定 |
| 禁止项 | 空白 | 自定 |

猜错会作废什么：活动类型猜错只需换标题和一行说明，不作废版式 → 替定，不问（也无人可问）。

## ② 两层默认
- 第一层：表面＝奶油暖白纸＋衬线大标题＋陶土色强调，或浅底＋默认蓝；构图＝居中大标题＋一摞书/打开的书插画＋底部中点分隔的"时间·地点·费用"；结构＝眉标胶囊"周末活动"→大标题→三张图标信息卡。
- 变体：换成绿色"阅读·成长"配色、换成扁平小人看书插画。
- 反面：深色夜读风，台灯一束暖光照在书上（径向聚光）。
- 第二层：①书脊排成书架当底纹、每本书脊一个字拼出标题（书架母题，换主题测试：换成"社区面馆"就换成碗排一排，成立 → 第二层）；②借书卡/借阅登记表外壳（单据母题 3.3-5）。

## ③ 方向（取向乙）
最近同类：书店促销海报、学校读书节海报、社区文化站活动海报。
独有事实（冻结）：
- F1 图书馆的书是"别人摸过、会被还回去"的：书脊上贴着索书号标签，同一本书在不同人手里流转。
- F2 周末开放和平日不同：家长孩子有空，书架前人多，书被抽出来又插回去的次数最多。
- F3 社区图书馆的空间小：一排书架就是大半个馆，活动在书架之间办。

方向：
- D1（F1）一排书脊里，有一本被抽出半截、斜出书架，它的书脊上印的就是活动名，别的书脊是普通索书号。事后描述："一排书里有一本被抽出来了，书脊上写着这周六的活动。"第二层检查：与默认②"每本书脊一个字"不同——这里只抽出一本，其他是背景；换主题测试：面馆抽不出"一本"，不成立 ✓；代入测试：书店海报也能抽书 → 半成立，用索书号标签和"空出的书位"把它钉在图书馆（书店不贴索书号）。没有这份提示我第一次会写出它吗？不会（会写书堆插画）。
- D2（F1）还书箱的口子：画面是还书口，一本书正塞进去一半。事后描述："一本书塞进还书口。"——表达的是"还"而不是"来参加"，作品读不到它需要的"来"，弃。
- D3（F2）同一格书架两张对照：周五晚整齐满格 / 周六下午空了一半。事后描述："书架被借空了。"——需要证明"周六人多"，属证明类，无事实支持，弃。
- D4（F3）俯视平面图，活动位置在两排书架之间标出。→ 俯视/地图母题接近第二层，且信息浅，并入排除。
写出 4，弃/并 3，剩 1（D1）。停止：F1–F3 各轮一遍。

## ④ 收拢
选 D1。契合：落在"索书号"这个只有图书馆才有的名词上；居民一瞥就看到"被抽出来的那本"＝邀请。放弃 D2、D3。前提一变：若用户说明活动有确定人气数据，可换 D3。
方向承诺：
| 失守处 | 失守时 | 守住的样子 + 怎么查 |
|---|---|---|
| 抽出的书（最难） | 变成平放的一本书插画 | 书脊竖立斜出 ≈8°，底部仍卡在书架格里，旁边留出黑色空位；看渲染图能指出"空位" |
| 强度 | 抽出书与其他书脊一样大，淹没 | 抽出书宽 ≥ 普通书脊 2 倍、颜色是全图唯一的信号色红；面积占画面 ≥ 1/10 |
| 小件：索书号标签 | 乱码文字 | 用真实格式的中图法号（I287 儿童文学等），只当纹理（<12px 不读或 ≥24px） |
| 小件：时间地点 | 小字一行中点串 | 时间行 ≥ 56px，单独一行 |

## ⑤ 简报
1. 受众：社区居民、亲子家庭。目标反应："周六下午拿本旧书去换一本。" 情境：手机竖屏满屏，1080 宽显示 → s=1.0。格式：1080×1350 PNG 级静态。出口条件：上部书架＝"这是图书馆、有一本被拿出来给你"；下部信息＝"什么时候、在哪、要带什么"。
2. 替换表见交付说明。
3. 执行要求：流读字 ≥36px，目标 48px；停读 ≥24px；12–24px 禁区（索书号标签做成 ≥24px 或纯纹理）；左右边距 ≥72px；对比度 ≥4.5:1；无占位。
4. 完成标准：
   - 一瞥：缩到 1/3 看，第一眼落在红色抽出书上。失败：先看到别处或说不出焦点。
   - 读懂：只看图，说得出"什么活动、哪天几点、在哪、要不要报名"。失败：缺一项。
   - 记忆点：外人复述含"抽出来的那本书"。失败：复述成"一张图书馆海报"。
   - 反例：更像奶油纸衬线海报即失败。
5. 禁止：奶油纸＋陶土色；居中大标题＋三张信息卡；胶囊眉标；中点元信息串；编造往期人数；emoji；空白填写栏。它不是一张"阅读推广海报"，它更像站在书架前看见有一本书冒出来。
6. 形容词：深木色书架（明度低 L≈0.25，让红书跳出）；书脊用褪色布面色（彩度低，因为旧书）。
默认满足测试：默认海报不满足"红书斜出、留出空位"，也不满足"禁止中点元信息串" ✓。

## ⑥ 制作
纯 HTML/CSS 绘制：上 760px 书架（深木）＋ 14 本书脊；红书 x≈380 宽 150 旋转 −8°，绕底部轴；空位为深色。下部浅纸灰绿区放标题与信息。

## ⑦ 自检与回炉
渲染 2 次（render.py → T1.png，看图 2 张）。
- 第 1 轮问题：①书脊循环 x=556 落回跳过区间 → 死循环，页面加载超时 → 改跳到 560；②书脊标题 104px 五字超长，"日"被日期标签压住、下方金线穿过"换" → 标题 104→80px、金线下移到标题后。重渲后量：标题末字底 ≈486px（书内坐标），金线 494，标签顶 520，无重叠 ✓。别动：书位置、空位、下部文字。
- 自检（5.1/5.2）：
  1 无占位 ✓（索书号 9px 为纹理，<12px，不需读）；2 无编造事实，馆名/时间/地点为〔例〕，图上贴"样稿：…为示例"26px ✓；3 11/21/2026 为周六，已核 ✓；4 更像"书架里冒出一本书"，不像奶油纸衬线海报 ✓；
  6 字高：标题 70px、时间 56px、地点/免费 42px（偏小档以上，≥36 ✓，未达 48 目标 −6px）、书脊标题 80px、日期标签 40/30px、样稿注 26px 停读 ✓；
  7 左右边距：文字左 84px ≥72 ✓，最长行"带一本旧书，换一本回家"右端 ≈862 → 右距 218 ✓；
  8 无须读内容被裁（左右被画框切的是纹理书脊）✓；9 无遮挡 ✓（修后）；
  10 对比度：#1b1f1a/#dfe4dc ≈14:1；#f6e7c6/#b3261e ≈5.6:1；#4d5249/#dfe4dc ≈6.2:1 ✓；灰度下红书仍比周围亮度差大（红 L≈0.42 vs 深底 0.12）✓；
  11 一瞥一个答案：红书是唯一饱和色、面积 ≈166×640=10.6 万 px² ≈7.3% 画面（低于承诺的 1/10，但叠加唯一信号色、倾斜和空位，焦点仍唯一；记为未达承诺量，见交付说明）。
- 完成标准：一瞥（红书）✓ 自判；读懂四项（活动/时间/地点/报名）都在图上 ✓；记忆点和不知情者测试推算不了（无外人）。
