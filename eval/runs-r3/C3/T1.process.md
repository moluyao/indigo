【理解】
原话：「给社区图书馆做一张周末活动的宣传图。」
合同：社区图书馆；周末活动；宣传图（技术要求：1080×1350 静态，单 HTML，系统字体）。
维度状态（只列非"已说"的）：
- 受众｜隐含｜社区居民（因为"社区"图书馆，宣传对象是附近住户），含带孩子的家长和老人。
- 目标反应｜空白｜替定："这周末可以去图书馆坐坐。"
- 观看情境｜隐含｜打印贴在楼道 / 公告栏，也会转进业主群手机上看（因为"社区"宣传的常见渠道是本地张贴）；远看 2–3 米要认出大字。
- 材料与事实｜事实空白｜活动名称、具体日期、时间、馆名、地址全部没给 → 不编造。处理：海报本身做成一张"借书卡"，日期/活动/时间栏是空的手填格，馆员拿笔填——借书卡本来就是手填/盖章的物件，空格成了作品的一部分。
- 中心想法 / 外观 / 结构｜空白｜交给发散。
- 禁止项｜隐含｜不得编造时间地点；不出现网址账号。
替你决定的：活动内容不写死，用手填栏（另一种可选：你给出活动名和时间后直接印进去）。

【排除的默认】
默认：表面——暖米黄底 + 衬线大标题 + 赤陶色强调，或卡通书本、书架插画、星星；构图——居中大标题"周末阅读时光"+ 插画 + 底部三个图标块写时间地点；结构——标题 / 插图 / 信息栏三段。
变体：同一套换成薄荷绿或蓝色卡通。　反面：纯黑极简大字海报。

【方向】
① 借书卡：整张海报就是一张图书馆借书卡 / 到期日卡，"到期日"栏里盖着红章"周末"，标题"这个周末，借你两天"。物件即画面。（排除了插画和图标信息栏）——我平时不会这么做。
② 书脊墙：画面是一整面书架的书脊，只有一本书脊上写着活动信息，其余书脊空白——网格墙 + 唯一例外。
③ 闭馆时间表反着用：一张门口营业时间牌，把"周六 / 周日"两行放大成主角，其余工作日缩成小字——一组对照。
④ 字面画面：一家人坐在阅览室里读书的插画（字面方向，只占一个）。

【选择】
选了①借书卡／契合在于：借书卡、到期日戳是只有图书馆才有的物件（换成书店、咖啡馆就不成立），居民一眼认出"这是图书馆的东西"；而且手填格正好解决"活动信息是事实空白"的问题——馆员在打印件上手写即用／放弃了②书脊墙和③时间牌／②在需要连续出一系列海报时更好（每期换一本书脊），③在活动就是"周末延长开放"时更好。
借来的一个元素：③的"周六 / 周日"两行对照——卡上的到期日行用周六、周日两个格。
方向承诺：拥有的想法——"图书馆把周末借给你"，用借书卡的语法说；拒绝的默认——米黄底衬线大标题赤陶强调、卡通书本插画、底部图标信息栏；它自己的世界——牛皮纸书袋 + 浅黄卡片 + 蓝黑印刷格线 + 一枚斜盖的红色印泥章，去掉字也认得出是借书卡；第一眼——红章"周末"压在卡片的到期日格上。

【简报】
受众：社区居民｜目标反应："这周末可以去图书馆坐坐。"｜观看情境：楼道公告栏 2–3 米 + 手机群聊缩略图｜格式：1080×1350 静态。
做到什么算完：
1. 一瞥认出"图书馆的周末"——测：0.5 秒遮住问"这是什么的宣传"。失败：说不出"图书馆"或"周末"。
2. 缩略图可读——测：缩到 270 宽，主标题仍可辨。失败：主标题字高 < 画面宽 / 20。
3. 手填栏可写——测：每格高度 ≥ 70px（打印 A4 上约 1.3cm），留白可手写。失败：格子太小写不下。
4. 有自己的样子——测：遮住"图书馆"字样，换成"书店"仍成立吗。失败：成立。
必保项：红章只出现一次且压在到期日格；卡片插在书袋里的结构。
不要：外观——米黄 + 衬线 + 赤陶、卡通书本、星星；结构——居中标题 + 插图 + 三图标信息栏；内容——编造日期、活动名、馆名；技术——字体回退成宋体乱码。
反向定位：它不是一张活动插画海报，它更像图书馆柜台上递给你的一张借书卡。
