# T2 过程

【理解】
原话：「做一个 15 秒的动画，讲清楚为什么天空是蓝色的。」
合同：15 秒；动画；讲清楚"天空为什么是蓝的"；（统一要求：1920×1080、无声、可 seek）。
维度状态（只列非"已说"的）：
- 受众｜隐含｜好奇的普通人/中小学生，因为"讲清楚"意味着非专业。
- 目标反应｜隐含｜"原来是空气把蓝光弹得满天都是"，因为要"讲清楚"原因。
- 观看情境｜隐含｜静音、看一遍，因为无声且 15 秒短片——字幕承担全部信息。
- 事实｜事实空白→查证｜瑞利散射强度 ∝ 1/λ⁴；蓝光约 450 nm、红光约 700 nm，(700/450)⁴ ≈ 5.9，所以"蓝光被弹开的机会约是红光的 5 倍多"是可靠的；日落时光程更长，蓝光在途中被散射掉。紫光问题（太阳紫光少、人眼对紫不敏感）15 秒内不展开，不做错误陈述。
- 外观、结构｜空白｜交给发散。
替你决定的：用"弹开"代替术语"散射"，术语只在小字出现一次（另一种可选：直接讲"瑞利散射"）。

【排除的默认】
默认：表面——蓝天渐变背景、卡通太阳、地球剖面、彩虹色正弦波；构图——左太阳右地球、中间箭头；结构——标题开场→"阳光由七色组成"→波长对比图→"瑞利散射"术语卡→结尾金句；声音（无）。
变体：同结构换深色宇宙背景。反面：纯文字白板解释。

【方向】
① 光子弹珠：阳光是一串彩色小光段横穿画面，空气分子是一颗颗小点；蓝光段撞上就被弹向四面八方，红光直穿；被弹散的蓝光越多，原本漆黑的背景越蓝。结尾太阳斜照、空气变厚，蓝光半路被弹光，只剩红橙到达眼睛。（因果链 + 光即颜色；排除了波形图和术语卡；"我平时不会这么做"）
② 两扇窗对照：正午与傍晚两个同构画面并排，同一束光走不同路径长度。（一组对照；排除了微观视角）
③ 月球 vs 地球：同一个太阳，没空气的月球天是黑的，有空气的地球天是蓝的——证明颜色来自空气。（反面推理）
④ 跨尺度旅行：从眼睛抬头的蓝天一路推进到一个氮分子。（跨尺度；排除平面图解）

【选择】
选了①光子弹珠。契合在于"蓝光被空气分子弹开、红光直穿"这一条事实本身就是一个可以直接看见的动作，静音观众不用读术语也能看懂；背景"从黑变蓝"把"天的颜色 = 被弹散的光"直接演出来。放弃了②③④。被放弃的③在有旁白、时长 ≥30 秒的版本中更好（论证更严密）；④适合大屏沉浸展示。
借来的一个元素：从③借"没有空气，天就是黑的"——片子从黑背景开始。
方向承诺：拥有的想法——"天的颜色就是被弹开的光的颜色"；拒绝的默认——蓝渐变背景 + 正弦波 + 术语卡；它自己的世界——黑空间里彩色短光段在飞、灰白小点是分子、背景亮度完全由被弹散的光决定（光即颜色），无辉光；第一眼——白光束（三色光段混在一起）从左边太阳射入，标题问题在左上。

【简报】
受众｜普通人/学生｜目标反应：「原来是空气把蓝光弹得满天都是」｜观看情境：静音看一遍｜格式：1920×1080，15.000 s，__seek 确定性
做到什么算完：
1. 第 0 帧有问题和光束。测法：看 __seek(0)。失败：黑场或空画面。
2. 字幕读得完。测法：每条字幕停留 ≥ 字数÷9 且 ≥0.83s，字高 ≥ 36px（0.033S）。失败：任一条不够。
3. 看得出"蓝弹红穿"。测法：抽 5s 帧，蓝色光段方向杂乱、红色光段水平。失败：两色运动看不出差别。
4. 看得出背景因蓝光变蓝，傍晚变橙。测法：抽 2s/10s/14.5s 三帧比背景色。失败：三帧背景近似。
5. 有峰：10s 前后满天蓝 + 光线射向眼睛为峰。
必保项：彩色光段、分子点、背景随散射变色。
不要：外观——蓝渐变天、卡通太阳脸、辉光；结构——术语卡、结尾金句卡；内容——编造数字（只用 1/λ⁴ 推出的"约 5 倍多"）；技术——闪烁、相邻帧跳跃无模糊（光段画成拖尾线）。
反向定位：它不是一页科普课件，它更像一台把光子放慢了的观测仪。

【自检】
- 默认对照：过（无蓝渐变、无波形、无术语卡）。
- 禁用清单：#2 近黑底——理由：黑底是"没有散射时的天"，是论证的起点而非装饰，且无霓虹辉光；#24 示意图代替真实——本题是机制讲解，示意即内容；#30 无装饰运动，每个光段都是数据（概率按 1/λ⁴）。过。
- 代入测试：换成"为什么草是绿的"不成立（那是吸收不是弹开）。过。
- 事实：5 倍多 = (700/450)⁴≈5.9；概率参数蓝 0.85、绿 0.38、红 0.15 按 λ⁻⁴ 比例。过。
- 第 0 帧：光子从 t=-2s 起发射，第 0 帧光束已满屏。过。
- 读得完：字幕 4 条，最长 31 字需 3.4s，实际 3.8s。过。
- 字高：字幕 50px，标签 34px≥? 标签 36px。过。
- 频闪：光段画成 46px 拖尾，每帧位移 ~30px（900px/s @30fps）。过。
- 闪烁：背景色缓变，无明暗翻转。过。
