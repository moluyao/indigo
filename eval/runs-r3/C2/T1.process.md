# T1 过程

【理解】
原话：「给社区图书馆做一张周末活动的宣传图。」
合同：社区图书馆；周末活动；宣传图（静态，1080×1350）。
维度状态（只列非"已说"的）：
- 受众｜隐含｜社区居民（含带孩子的家长、老人），因为"社区"图书馆。
- 目标反应｜隐含｜"这周末可以去图书馆坐坐"，因为用途是宣传。
- 观看情境｜隐含｜手机群聊/公众号里看一眼，也可能打印贴在公告栏，因为社区宣传渠道。
- 活动内容｜空白｜替定"亲子共读 + 旧书交换"（另一种可选：讲座、手工课）。
- 具体时间、地址、报名方式｜事实空白｜不编造；画面里用借书卡上本来就有的手填空栏"时间 ____"，由馆方手写/补字。
- 外观、结构｜空白｜交给发散。
替你决定的：活动名"亲子共读 · 旧书交换"、文案口吻（另一种可选：正式通知体）。

【排除的默认】
默认：表面——暖米色纸 + 衬线大标题 + 绿植/书本插画、橙色强调；构图——顶部大标题、中间一摞书或一个读书小人插画、底部时间地点三行；结构——标题→插画→信息块；声音无。
变体：同样版式换成蓝色/卡通字体。反面：深色极简海报，只一行字。

【方向】
① 借书卡：整张图就是一张图书馆借书卡，"还书日期"栏里盖着红色日期章"本周末"，借阅者一栏手写"你"。（排除了插画和信息块；拟物载体，"我平时不会这么做"）
② 书脊墙：满屏书脊严格排列，只有一本被抽出半截，书脊上是活动名。（严格网格 + 一个例外；排除了标题区块）
③ 开门的窗口：孔版双色套印，图书馆窗户亮着灯，窗里是读书的人影，周末夜间感。（场景叙事；排除了文字为主）
④ 只用字：动态排版"嘘——"巨大字体被划掉，改成"这周末可以说话"。（反着用"安静"；排除了图像）

【选择】
选了①借书卡。契合在于"借书卡/还书日期章"只属于图书馆这一个对象，换成书店或社区中心就不成立；居民一眼认得这张卡。放弃了②书脊墙（也很图书馆，但书脊靠细字，手机上一瞥读不清）、④只用字。被放弃的②在大尺寸打印海报、远距离观看时更好。
借来的一个元素：从④借"安静被打破"的口吻做副标题"这个周末，图书馆不用小声"。
方向承诺：拥有的想法——"这个周末的还书日期，盖给你"；拒绝的默认——米色纸+衬线+插画小人；它自己的世界——牛皮纸卡片、印刷表格线、红色日期章、蓝黑圆珠笔手写，放在墨绿桌布上；第一眼——红色大章"本周末"。

【简报】
受众｜社区居民｜目标反应：「这周末去图书馆看看」｜观看情境：手机一瞥 + 打印张贴｜格式：1080×1350 静态 PNG/HTML
做到什么算完：
1. 一瞥认出是图书馆活动。测法：看 0.5 秒遮住问"这是哪儿的什么"。失败：说不出"图书馆"。
2. 主焦点唯一是红章。测法：模糊测试。失败：标题和红章同强度抢。
3. 活动内容读得出。测法：须读字 ≥ 24px（0.022S）。失败：小于或对比不足。
4. 不编造时间地址。测法：逐字核对。失败：出现具体日期/门牌。
必保项：卡片表格线 + 红日期章 + 手写"你"。
不要：外观——米色纸+赤陶强调、插画小人、渐变；结构——标题/插画/三行信息；内容——编造日期、地址、电话；技术——字体回退。
反向定位：它不是一张活动海报，它更像一张递到你手里的借书卡。

【自检】
- 默认对照：过（主体是借书卡实物，不是标题+插画）。
- 禁用清单：#3 牛皮纸底——理由：借书卡本身就是牛皮纸/马尼拉卡，颜色取自物件；强调色是日期章红，不是赤陶，字用宋体（卡片印刷体出处）而非展示衬线。#12 无眉标。#18 无英雄数字。过。
- 代入测试：换成书店/健身房，"还书日期栏"不成立。过。
- 事实：时间留手填空栏，地址只写"社区图书馆"（原话给出）。过。
- 一瞥/焦点：红章面积最大、唯一高饱和色。过（渲染后核对）。
- 字高：最小须读字 26px ≥ 24px。过。
- 对比度：墨 #1b1b1b 对牛皮纸 #e6d2a0 ≈ 13:1；标题米白对墨绿 ≈ 11:1。过。
- 边距：内容离左右边 ≥ 70px。过。
- 字族：宋体 + 黑体 + 楷体（手写）——3 个字族，超出 ≤2。理由：楷体只承担"手写"这一个物件职责，保留。
- 颜色剂量：红色只用在日期章一处。过。
