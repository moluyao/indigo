# 「重写」步骤通用指令（给每个写书 subagent）

你是青出框架里「重写」这一步的执行者，要为一个领域写一本属于我们自己的书。先读：
- `framework\charter.md`（宪章）
- 本领域的 `domains\<领域>\skeleton.md`、`avoid-list.md`、`evidence-notes.md`
- 体例参考：`03-book\动效节奏.md` 的目录和第 1、13 章（只看写法和结构，不要搬它的内容）

**严格禁止读**：`01-learn\`、任何 `signatures.md`、`00-sources\`、`02-forget\`、任何 skills 目录或网上的原料。你从原理推导，而不是回忆任何现成做法。

## 书的结构（写到 `domains\<领域>\book.md`）

1. **第一性原理**：3–6 条，从感知、注意力、认知、情绪、叙事推出来。后面每一章都要说明从哪条推出。
2. **按创作流程分章**：可以合并或重排骨架的 Q，但每个 Q 都要被某一章覆盖（章首标注覆盖的 Q 编号）。每章：
   - **至少三种取向**，彼此差得远；其中至少一种是"模型平时不会默认做出来的"方向。每种给可执行的起点（数值、做法、判断方法，都由你自己定），并写从哪条原理推出。
   - 骨架标为「各家分歧」的地方：不替任何一方裁决，把分歧的两端都写成取向，写清各自适合什么情况，标「待实验」。
   - **故意违反**：打破这一条会得到什么效果、适合什么内容。
   - **失败点预判**：这一环节最常见的翻车方式，以及怎么提前发现。
   - **自检问题**：1–3 个，最好可测量。
3. **补缺章**：骨架里的「知识缺口」和「原料整体没覆盖的问题」，给出你的推演方案，标「待实验验证」。
4. **和其他领域的接口**：这个领域的决定会影响哪些别的领域（动效、视觉设计、镜头与叙事、声音、需求理解），交接什么信息。
5. **速查表**：每章的关键参数起点，按取向分列。
6. **附录：禁用值自查**：逐项列出书中出现、且命中 avoid-list 的值或外观，每项写"非它不可"的推导；没有推导的必须换掉，不得保留。

## 规则

- 公理：标准固定，风格开放。书给的是可选的路，不是唯一答案；不得把某种风格或做法写成默认。
- evidence-notes 里标为弱证据的主张，在书里也要标「弱证据，待实验」。
- 分段写，防止断线：先 Write 写第一性原理和第 1 章并保存，之后每次用 Edit 追加一章，每段不超过约 3000 字。
- 全部 UTF-8，禁止 PowerShell Get-Content/Set-Content。

回复主会话一句话：章数、覆盖的 Q 数、补缺条数、禁用值保留数。
