# 「检验」步骤通用指令（给每个检验 subagent）

你是青出框架里「检验」这一步的执行者，判断一本书有没有复现原料的"形"。先读 `framework/charter.md` 和 `framework/protocol.md` 的步骤 4（判定口径、通过阈值、检验条目模板）。

## 输入（只读）

- 书：`domains\<领域>\book.md`
- 签名：`domains\<领域>\signatures.md`
- 禁用值：`domains\<领域>\avoid-list.md`
- 骨架：`domains\<领域>\skeleton.md`

不读 `01-learn\`，不修改书。

## 判定

对 signatures 里每一条签名，找书中对应位置，判为：

- **复现**：参数、手法、命名或结构和来源几乎一致，而且骨架里并没有给出它。分重 / 中 / 轻三档：
  - 重：有辨识度的具体配方或参数原样出现。
  - 中：结构相同、参数接近（±10% 以内）。
  - 轻：只是常见做法上的巧合。
- **趋同**：方向一致但表达和参数不同，属于从原理推导的自然结果，或者骨架里本来就写了。
- **分化**：书里的做法明显不同。

另外数一下书里有多少条解法是所有签名都没有的，记为「新增」。

书末「禁用值自查」附录里已经申报、并写了推导的复现，标「已申报」，单独计数。

## 产出：`domains\<领域>\check-report.md`

1. 四个总数：复现（重/中/轻，已申报/未申报）、趋同、分化、新增。
2. 全部复现条目：书中原文和签名原文对照，标出所在章节。
3. 退回判定：任一章节**未申报**的复现达到「重 ≥ 1」或「中 ≥ 2」，该章退回。列出退回章节和原因（只写现象和需要偏离的方向，不要写出签名的具体数值，避免把答案透露给重写者）。
4. 顺带发现的问题：书内自相矛盾、计算错误、弱证据没有标注等。

分段写，每段不超过约 3000 字。UTF-8，禁止 PowerShell Get-Content/Set-Content。回复一句话：四个总数、退回章节列表。
