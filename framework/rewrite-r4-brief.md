# 「按收紧后的骨架重写」指令（给每个重写 subagent）

先读 `framework\rewrite-brief.md`，它的规则、体例和禁止读的范围全部适用。本次是修订，不是从零写。

## 可读

- 本领域收紧后的骨架、avoid-list、evidence-notes（路径见主会话给的表）
- 本领域的 **重写清单**（`rewrite-list.md`）：A 节是受骨架收紧影响、需要重写的章节；B 节是书内错误；C 节是离来源过近、需要重新推导或申报的地方。清单只写了"现象和需要偏离的方向"，不含任何来源内容。
- 本领域现行的书（要修改的对象）

**严格禁止读**：`01-learn\`、任何 `signatures.md`、任何 `check-report*.md`、`archive\skeleton-before-tighten.md`、`00-sources\`、任何 skills 或原料目录。

## 步骤

1. 先用 Python 按 UTF-8 把现行的书原样复制到同目录 `archive\`，文件名加 `-before-r4`。
2. 逐条处理重写清单：
   - **A 节**：对应章节从收紧后的骨架和第一性原理重新推导，不参照旧版这一章的结构、分级数、清单和措辞。不要只换说法，要真正重新决定"分几级、按什么分、先做什么"。
   - **B 节**：按「现象 → 目标 → 验证方法」修正；需要计算的用 Python 实际算一遍。
   - **C 节**：重新推导；如果推导结果仍落在原处，在书末附录写明"非它不可"的推导。
3. 保持体例：每章至少三种取向（至少一种是模型平时不会默认做的）、故意违反、失败点预判、自检问题；分歧两端都写成取向并标「待实验」；弱证据标「弱证据，待实验」。
4. **新增要求（来自两轮盲测）**：每章的自检问题里，至少有一条是**可以测量的执行指标**（例如最小字高、离画面边缘的安全距离、须读文字停留时间、元素不遮挡、最长匀速段），不能只有审美判断。
5. 同步更新速查表和书末「禁用值自查」附录；在书首写一行版本说明（r4，2026-11-19，按收紧后的骨架修订）。

分段写，每次 Edit 一章，每段不超过约 3000 字。UTF-8，禁止 PowerShell Get-Content/Set-Content。回复一句话：A/B/C 各处理了几条、新增了几条可测量自检。
