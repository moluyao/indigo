# 声音质量标准 v0 · 青出 / Indigo

> 依据：声音 book r5，2026-11-19（`domains/声音/book.md`，下文简称《书》）。外部规范：ITU-R BT.1359（声画同步可察觉门限）；WCAG 2.2 · 2.3.1（仅用于校准白闪，以 `reference/WCAG-2.3.1-闪烁阈值.md` 为准）。真实失误数据：两轮盲测评审记录（`eval/`）——两轮里没有任何一位评审评过声音，本标准没有来自人耳的校准数据，这一点贯穿全文。
> 回答一个问题：一件有声作品（视频、动画、可交互页面的声音），观众听到的声音，什么叫坏、能用、商业合格、精品、惊艳。
> 本标准评的是**观众一侧听到的效果**，不规定手法。《书》里的取向（克制型、密织型、因果推导型；有曲、无曲；同步、晚到、先闻后见；可懂度先定、存在感先定、时分……）全部并列，任何一种都不加分、不扣分；手法和参数只在《书》里，本标准只判级，并在不达标时指回《书》的章节。
> 《书》里凭记忆写的学术依据（如约 1 LU 的可察觉差、临界频带假设、察觉排序），在本标准里只作"待实验"的阈值依据，不作底线。
> 写成日期：2026-11-20。

## 1. 总则

### 1.1 评什么，不评什么

**评**：观众在实际收听条件下（手机外放、耳机、桌面扬声器；可能静音自动播放）听到的声音——有没有听得出的错（咔哒、削波、断音、掉音、读错、对不上、露馅的剪接），该听见的听不听得见、该听懂的听不听得懂，声音有没有在做事，是不是"铺上去的"，有没有一个属于这件作品的声音想法，细节经不经得住听。

**适用范围**，每条底线和维度都标了适用范围：
- **[声]**：有声轨的作品都适用。
- **[口播]**：有配音、旁白、对白的作品。
- **[乐]**：有音乐的作品。
- **[效]**：有音效的作品。
- **[信息流]**：评审卡写明平台会自动播放、可能静音的作品。
- 作品没有声轨：本标准整份 n/a，不是"未评"；但评审卡写了"有声"而成片没有音轨，按 T-03 记交付未过。

**不评**（交给别的标准）：
- 画面本身：版式、字、色彩（视觉标准）；运动质感（动效标准）；故事、节奏的形状、切点为什么在这里（镜头与叙事标准）。
- 静音时看不看得懂：镜 B-02（静音可懂）。本标准只管"声音在场时听到的"，不替画面兜底；但声音设计若把开场关键信息只放在声音里，静音观众的损失记在镜 B-02，不在这里重复扣。
- 文案写得好不好（写作标准）。
- 制作流程：排程是否只存一处时间、是否做了验证链记账、是否给用户音频做了未经同意的处理——这些是《书》第 6、13、17 章的制作纪律，评审看不到，不评；只评它们在成片里留下的可听结果。

同一件作品可以同时用多份标准评，各报各的。**同一件事被两份标准都管时，只测一次，用同一个阈值**：本标准第 2.3 节列出与动效、镜头与叙事、视觉标准共用的条目，直接引用对方编号，不另设数字。

**不评制作过程**：评审者只看（听）成品和评审卡，不看工程文件、混音工程、缺口账本、对齐表、验证链记录、制作对话。作品自称"已闪避""已对齐""响度达标"，不算证据。

### 1.2 五个级别

| 级别 | 名称 | 观众一侧听到的 |
|---|---|---|
| L0 | 坏 | 有听得出的错：咔哒、削波、断音、意外掉音、读错字、话听不清、声画对不上、剪接绊一下、该听见的那一下没听见……任一观众可感层底线（B 或共用 S）没过 |
| L1 | 能用 | 没有错，但声音是"铺上去的"：一条无害的背景曲从头垫到尾，音效库默认声每处都上，配音像念稿 |
| L2 | 商业合格 | 可以交给付费客户：话听得清、该听见的都听得见、层次清楚、落点贴、开头结尾干净，挑不出硬伤 |
| L3 | 精品 | 每个声音都说得出它在做什么，删掉一个会少点什么；声音世界属于这件作品；至少一处靠声音被记住的时刻 |
| L4 | 惊艳 | 意外但正确：一次静默、一个声音母题、一次先闻后见，让人事后觉得只能这样；有人会因为"听起来"转给别人 |

- L0 与 L1 的界线是"错"，靠第 2 节的底线判；其中一部分能用脚本从音频文件测，另一部分只能人听（第 2.5 节分表）。
- L1 与 L2 的界线是"默认"，靠第 3 节各维度的"典型 AI 低级感"逐条勾选。
- L2 以上写不成规则，只描述"听到什么"，并靠标杆比较确认（第 4、6 节）。本标准对 L3、L4 不给配方。

### 1.3 三层

| 层 | 管什么 | 不过怎么办 |
|---|---|---|
| 交付技术层 T | 导出时机械可修的：整体响度与交付值、真峰值、音频流参数、音画流对齐、校准段残留、交付形式齐套 | 记"交付未过"，附修复方法；**不判 L0**，不影响上限评审；交付未过不得发布 |
| 观众可感层 B | 观众听得出的错 | 任一未过判 **L0**；维度照评，写成"修好后的上限" |
| 上限维度 D | 好不好、声音有没有在做事、记不记得住、做得细不细 | 给级别与证据（时间码），指回《书》 |

判别一项属于 T 还是 B：问"不改声音设计，只改导出参数、对整条混音施加一个恒定增益、或重新封装一次，能不能修好？"能 → T；不能 → B。例：整体响度偏低，加恒定增益即可 → T；人声被音乐盖住，要回混音改 → B。恒定增益会让真峰值超限、只能靠快速限幅才能到目标值时，《书》15.4 规定回混音，这时 T-01 标"需回工程"，仍不判 L0。

### 1.4 评审卡

做作品的人交付时附一张评审卡（≤ 14 行）。评审者只读这张卡和成品。和动效、镜头与叙事、视觉标准同评时，几份卡合成一张，同名字段只写一次。

| 字段 | 写什么 | 用于 |
|---|---|---|
| 目标级别 | 例："L2，声 D8 争取 L3"；不得低于 L2 | 第 4 节对照 |
| 片种、时长、帧率 | 讲解 / 口播 / 发布 / 故事 / 氛围 / 界面演示 / 循环；目标时长；帧率（换算 1 帧的毫秒数） | 条件条目、M 项换算 |
| 平台与收听条件 | 投放平台；是否自动播放、是否可能静音、是否循环；预计收听设备（手机外放 / 耳机 / 桌面 / 大屏）；未知的写"未知" | [信息流]、声 B-05、D9 |
| 交付响度依据 | 本片交付的积分响度值、真峰值上限，以及它们**来自哪次平台实测、哪一天**（求法见 T-01）；没实测过就写"未实测" | T-01、T-02 |
| 声音构成 | 有无配音、音乐、音效、环境声；配音是合成还是真人；音乐是否剪过 | 条件标签 |
| 核心信息一句话 | 观众听完看完应带走的一句，可附 ≤ 2 条次要信息 | 共用 S-08 复述 |
| 配音稿与词时间 | 口播稿全文（读法稿与字幕稿分开时两份都附）；有字级时间戳的附上 | 共用 S-03、S-04、S-06 |
| 必须听到的声音 | 承担信息的那几个声音（揭示的一下、提示音、画外声、设计静默），各写时间码和任务（"作为事件被听见"或"作为一层质感被听见"，《书》13.4） | 声 B-04、B-05 |
| 设计静默与有意偏移 | 有意的静默、有意的先闻后见或晚到、有意的戛然而止，各写时间码 | 声 B-03、声 B-07、S-10 的例外 |
| 交付形式 | 混音成品 / 无旁白版 / 分轨 / 多语言版 | T-06 |
| 分轨（可选） | 人声、音乐、音效分轨文件。有分轨时，B-04 和若干 M 项可以从"可定位"升到"可判"（2.5 节） | 声 B-04、M 项 |
| 评审能否听 | 评审环境能否放声音、用什么设备听 | 第 4.4 节 |
| 样稿示例内容清单 | 示例配音稿里哪些名称、日期、价格、数字是示例（第 5 节） | 共用 S-09 |
| 有意说明（密封） | 对第 7.2 节测量数据里可能显得反常之处的说明（例如"全片短时响度几乎不动是有意的平高型"） | 评审结束后才打开 |

- 评审卡缺失时，评审者从成品推断各字段，逐项标"（推断）"；推断不能用来豁免任何底线。"必须听到的声音"无法推断时，评审者自己写出"不听到就看不懂或感受不到的三个声音"，按它们测，并在报告里列出。"交付响度依据"不能推断，T-01 记"交付未过：缺实测依据"。
- "设计静默与有意偏移"只能由卡写明，不能推断；卡上没写的静默、偏移，一律按非设计测。
- 有意说明只在评审结束后打开，只能解释第 7.2 节的测量数据，不能改变维度级别，也不能豁免 B 层。

### 1.5 评审者与材料

- 评审者不是制作者，是独立会话；不知道作品出自谁。复述测试的测试者也必须没看过、没听过这件作品。
- **材料**：成片文件（不是混音工程）；评审卡；脚本输出（第 7 节：响度与真峰值、短时响度曲线、静音区间、削波段、起音时刻、ASR 逐词时间戳与置信度、声画偏移表、单声道折叠结果）；有分轨时附分轨。
- **听的条件**：至少听两遍，一遍用评审卡写的主要收听设备（多为手机外放；手机外放会压缩层次差，《书》7.2），一遍用耳机（听底噪、咔哒、齿音、剪接）。只有一种设备时注明。
- **评审顺序**：
  1. 全速、有声看一遍，写下：记住的声音时刻（≤ 3 条）、一句话复述、"哪一刻声音在做事"，封存。
  2. 跑 T 层和脚本可判的 B 层。
  3. 带着脚本给出的候选时刻（咔哒、掉音、剪接、低置信度词）逐个回听确认。
  4. 逐维度定级。测量只能补充和修正第 1 步的整体判断（《书》13.1：最危险的是把"测过"写成"听过"，把"听过"写成"好"）。
- **证据用途档**（《书》13.2）：每条脚本结论在报告里标明它的用途——**可放行**（能让一项检查通过）、**可判失败**（能判未过）、**可定位**（只决定下一步听哪里）、**交人耳**。同一种测量在不同条件下档位不同（例如起音检测在分轨上可判、在混音上只可定位），档位记在每一次使用上。不得用"可定位"的结果放行，不得用"交人耳"的项做任何判定。

## 2. 底线

每条写：指标 / 阈值 / 测量方法 / 依据 / 回炉。依据里的"待实验"表示这个数目前只有推导、没有人耳实测，评审照用，但第 6、8 节的校准数据可以改它。本领域两轮盲测零人耳数据，所以凡不是规范原文或定义的数，一律待实验。

### 2.1 交付技术层 T（不判 L0，记"交付未过"）

| ID | 指标 | 未过判定 | 测量 | 依据 | 修复 |
|---|---|---|---|---|---|
| 声 T-01 | 整体响度与交付值 | ①评审卡没有带实测日期的交付值（写"未实测"或缺）；②成片积分响度 I 与卡上交付值之差 > 1 LU | `ffmpeg -i f -af ebur128=peak=true -f null -`，读 I（ITU-R BS.1770 门限积分） | **平台响度不写具体数**，交付值只能用《书》15.4 取向 A 的求法得到（见下方"平台实测求法"）；《书》15.3"不凭记忆写任何平台的数值"。1 LU 来自《书》10.3 的约 1 LU 可察觉差（凭记忆、弱证据），**待实验** | ①先做平台实测，再定值（需回工程，但不改设计）；②全片恒定增益（可自动）；恒定增益让真峰值超过 T-02 上限时，按《书》15.4 第 2、3 步只对顶住的少数瞬态逐事件降、或回混音，**不在母带上加快速限幅**（需回工程） |
| 声 T-02 | 真峰值 | 成片解码后的真峰值（4 倍过采样）> 卡上的上限 c；卡没给 c 时，> 0 dBTP 一律未过（超过满幅，播放端必削波），其余记"缺上限依据" | 同上 `peak=true`；必须测**交付文件解码后**的真峰值，不测编码前的混音；不得用采样峰值代替（《书》15.3、15.8） | 0 dBTP 为满幅定义；c 按《书》15.4 取向 B：c = −(max(oᵢ) + 2·sd(oᵢ))，oᵢ 是本条编码链路实测的上冲，2·sd **待实验** | 同 T-01 |
| 声 T-03 | 音频流存在与参数 | 卡写"有声"而成片无音轨；或音频编码、采样率、声道不在平台接受范围 | `ffprobe -show_streams` | 规格核对；参数口径同动效 T-06，本标准不另设 | 按动效 T-06；缺音轨需重新合成 |
| 声 T-04 | 音画流整体偏移 | 音频流与视频流起点或时长差 > 1 帧 | 按动效 T-05 执行 | = 动效 T-05 = 镜 T-02，同口径只测一次 | 平移音频流后重封装（可自动），修复后重测共用 S-05 |
| 声 T-05 | 校准段残留 | 成片时长与预期片长差 > 1 帧；或成片前 1 秒内有相对亮度 ≥ 0.9 的全屏单帧、或孤立单采样脉冲 | `ffprobe format=duration`；逐帧平均相对亮度；音频首 1 秒找单采样尖峰 | 《书》6.3 取向 A/B 的校准白闪 + 脉冲必须裁掉（书中【可测】条） | 裁掉校准段重导（可自动）。校准闪本身的闪烁计数按视觉 B-17 |
| 声 T-06 | 交付形式齐套 | 评审卡列出的交付形式（混音、无旁白版、分轨、各语言版）缺任何一个；或混音成品冒充分轨 | 清点文件；"分轨"逐个检查是否只含一层（与其他轨相减不应近似为零） | 《书》15.4"交付形式分清，混音成品不能冒充分轨" | 从工程重导（需回工程，不改设计） |

**平台实测求法**（声 T-01 的交付值从这里来，《书》15.4 取向 A）：
1. 准备一组测试片：同一段内容做成几段已知积分响度的版本（覆盖比预计目标高和低的几档），真峰值都留足余量。
2. 按正式发布的方式上传到目标平台，在目标设备上播放；下载平台转码后的文件，或用数字回录。
3. 测每段播放结果的积分响度，判断：平台是否做了归一化；归一化到多少；是只往下调还是上下都调；调大时有没有限幅（看真峰值和关键瞬态是否被压扁）。
4. 交付值取实测结果，写进项目文件和评审卡，**并写测试日期**；平台规格会变，过期或平台更新后重测（期限由项目自定，本标准不设数）。
5. 多平台投放时，每个平台各测；选统一值（《书》15.4 取向 C）也必须先在主要平台实测一次。
6. 多语言版本按积分响度对齐，不按峰值对齐（《书》15.4）。
- 动效标准 T-02 写了具体的网络平台响度数值，与本条"不写具体数"冲突，见第 8.2 节。两份同评时按本条求法判，并请动效标准下次修订对齐。

- T 层全部未过项合并成一份修复说明；修复后重测 T-01、T-02，并重测共用 S-01（限幅可能新引入削波感）。

### 2.2 观众可感层 B（任一未过判 L0）

以下是本标准自有的条目。与其他标准同一件事的条目见 2.3 节（共用 S），同样任一未过判 L0。

**声 B-01 咔哒与突变** [声]
- 指标：片头第一个声音、片尾最后一个声音、每个剪接点、每个声音片段的首尾，有没有听得出的"咔"（波形台阶展开成的宽带突发）。
- 阈值：人耳在耳机上确认听得出咔哒，未过。有意的硬切（评审卡"有意偏移"一栏写明的戛然而止）只要听起来是"切"而不是"咔"，不算。
- 测量：脚本给候选——①片段首尾样本绝对值 > 0.05 满幅且无淡入淡出（口径同动效 B-29 的咔哒候选）；②开头和每个剪点后长 2E 的一小段（E 见 7.2 节）里，高频能量相对随后一段突增（《书》14.1、14.7 第 1 问）。候选逐个回听，人耳确认才判未过。
- 依据：《书》14.1（突变噪声与进入力度的权衡）、8.1"余音被截"。脚本候选的门槛为起点，**待实验**；判定靠人耳，用途档为"交人耳"，脚本只"可定位"。
- 回炉：《书》14.1（斜坡长度不超过这个声音本来的起音时间；到上限仍有咔哒就换截入点）、8.1 第 3 条、10.4（剪点放在过零点）。

**声 B-02 剪接露馅** [乐]
- 指标：音乐被剪短或拼接的地方，观众听不听得出"绊了一下"或"被截断"。
- 阈值：人耳确认接缝处听得出节拍错位（下一拍没在预期的时刻来）、余音被一刀切掉、旋律句中途被切走，任一即未过。片尾音乐在乐句中途被截断，按共用 S-10（动效 B-06）判，不在本条重复。
- 测量：脚本给候选——对每个接缝，接缝前最后一个拍点到接缝后第一个拍点的间距与本片拍长 b 之差 > E；接缝前后各长 2E 两段的频谱距离显著高于本曲相邻两段的典型距离；接缝时刻包络在高位。拍点从节拍检测得到（《书》3.5）。候选回听确认。
- 依据：《书》8.1（节拍相位是"不参与权衡的硬条件"；敏感度排序是书的推断，**待实验**）。候选门槛 E 来自《书》4.4，是制作容差，**待实验**是否等于观众可察觉的量；所以只作候选，判定交人耳。
- 回炉：《书》8.1（删掉的长度必须是整拍数；接缝落在包络低位）、8.2（能一块删完不分两块）、8.4。

**声 B-03 意外掉音** [声]
- 指标：一段持续的声层（音乐床、环境声、配音句中）在没有设计的地方突然掉到本底以下又回来；或画面空隙造成的"黑帧 + 静音"。
- 阈值：成片里低于本片房间音（本底）、长度 ≥ 0.15 s 的区间，落在同一声层的中间（前后同一层都在），且评审卡"设计静默"一栏没有它，经人耳确认"像断了"，未过。落在某个词内部的静音按共用 S-01（动效 B-29 断音）判。
- 测量：`silencedetect` 以本片房间音电平为门限（本底从全片最安静的有声段估计）列出全部低于本底的区间；与评审卡设计静默逐条对照（《书》9.7、9.8 第 3 问"账本外的、低于本底的静音区间"）；剩下的回听。
- 依据：《书》9.7（时间线空隙造成的黑帧加静音）、9.2（静默要被读成有意，须明显长于此前最长的自然停顿；没写进设计的就是事故）。0.15 s 取自动效 B-29 断音检测的最短时长，保持两份标准同一口径，**待实验**。
- 回炉：《书》9.2、9.8；第 10.4 节（剪出的空隙用同一录音最近的本底填）。

**声 B-04 必须听到的声音没被听见** [声；有评审卡"必须听到的声音"时]
- 指标：评审卡列出的每个"必须听到的声音"，在成片混音里是否可闻。
- 阈值：任一个人耳确认听不见（或听成了别的声音），未过。只要缺口陈述最重的那一个没被听见，就未过，不论其余听见多少（《书》13.4 汇总口径）。
- 测量：
  - 有分轨时，按《书》13.4 两个判据：**事件型**——在命中点 ±E 内，有它那版的分频段起音上升速率是否高于"其余全部"在前后一个被跟踪层单位内的第 90 百分位；**质感型**——它持续期间，是否至少在一个听觉频带（ERB 或 1/3 倍频程）里能量不低于其余全部；背景几乎为零时改用绝对判据（命中窗内短时响度是否高于本片最轻的有意元素）。两个判据都判"不可闻"时，脚本可判未过（用途档"可判失败"）；判"可闻"只作"可定位"，不能放行，仍需人耳。
  - 只有混音时：脚本只能"可定位"（混音上的起音检测会把音乐每个重拍都当命中，《书》13.4），判定全靠人耳。
- 依据：《书》13.4、13.6 验证链环节③。第 90 百分位和"不低于"都是起点；质感判据借用临界频带假设，那是纯音在噪声中的察觉研究，《书》自己注明不能直接搬用，**待实验**。
- 回炉：《书》13.4、7.1（窗口预算：需要被听见又能挪的音效多于空隙窗时，回去改稿或改画面）、7.4、5.4。

**声 B-05 单声道折叠后丢失** [口播，或有"必须听到的声音"；收听设备含手机外放或未知时必测]
- 指标：把成片折叠成单声道（L+R）后，语言和必须听到的声音是否还在。
- 阈值：折叠后，人声段按共用 S-02 的同一口径重测可懂度不过；或任一"必须听到的声音"按声 B-04 重测不可闻，未过。不另设电平下降的数。
- 测量：`-af pan=mono|c0=0.5*c0+0.5*c1` 生成折叠版，对折叠版重跑 ASR 和 B-04；同时记录指向类、语言类声音折叠前后的电平下降量（M 项，《书》15.9 第 3 问）。
- 依据：《书》15.5（手机外放常为单声道；用相位做出的加宽折叠后可能抵消；传递语言的声音单声道下绝不能丢）、15.8。
- 回炉：《书》15.5、15.6。

**声 B-06 非作品声音外露** [声]
- 指标：观众不该听到的声音出现在成片里：校准脉冲、测试音、录屏带进来的系统提示音或通知音、工具的水印音、口播里念出的括号提示语或文件名、明显的临时配音（说话人与终稿不同），以及别的项目残留的音轨。
- 阈值：任一即未过。临时配音、"此处配音"占位音轨同时按共用 S-07 判。
- 测量：人工通听；ASR 全文搜括号、"此处""待补""TODO"、文件名样式；音频首尾和每段边界找孤立的单采样脉冲或正弦测试音（频谱上单一窄峰、恒定）。
- 依据：与视觉 B-09（非作品信息外露）同一类错，声音一侧的读法；《书》6.3（校准段混进交付片）。
- 回炉：《书》6.3 第 5 条、13.6 环节②。

**声 B-07 声画同步** [有声；共用条目持有方，镜 B-07、动效 B-22 / B-23 引用本编号]
- 指标：应当"同一时刻"的声画事件——可见发声（嘴、撞击、按键、落地）、音效对应的画面落点、口播锚定的画面事件（说到某词时对应元素出现、高亮、变化）——声音相对画面的时间差。画面取兑现帧（预测被确认的那一帧，《书》4.1），声音取命中点（能量包络算出的那一刻，不是文件起点，《书》4.2）；口播锚定的画面事件按词起点测，记在镜 B-07。
- 阈值：**ITU-R BT.1359 可察觉门限**：声音领先画面 > 45 ms，或落后画面 > 125 ms，未过。例外：有意的"声音先行"，领先量 ≥ L 时观众读作一个独立的先行事件，不算不同步；L = max(视听捆绑窗, 这个声音的辨认时长, t)，短促敲击约为 t = 0.25 s，人声或呼吸取它自身被认出所需的时长。领先量落在 (45 ms, L) 之间仍未过——这是"像没对齐"的区间（镜头与叙事书 4.3）。
- 测量：音频瞬态检测或稿件强制对齐得到命中点 / 词起点；画面事件帧取差分突变帧或元素出现帧，按 ms 输出差值。30 fps 下 1 帧 ≈ 33 ms，领先 45 ms ≈ 1.35 帧。画面事件检测不出兑现帧（慢溶解、无尖锐事件）时降为"可定位"（《书》13.5）。
- 依据：ITU-R BT.1359（经镜头与叙事书 E1 引用）；L 的三项为镜头与叙事书 4.3 弱证据，**待实验**（该书 18.2 X5）。《书》4.4 的 E = ¾ 帧、卡点类 ± min(u/4, …) 是**制作容差**，比门限严，只作 M-04 证据，不判 L0。BT.1359 测于以对白为主的广播节目，对冲击、卡点是否同样宽松**待实验**（《书》4.4、6.3），在校准前照用规范值。2026-11-20 共用条目对齐起由本标准持有（原写在镜 B-07 与本标准声 S-05）。
- 回炉：《书》4.1、4.2、4.4；镜头与叙事书 16.4、4.3、5.4（取整只做一次，与声音相关的画面事件向早取整）。

### 2.5 哪些能从音频文件测，哪些必须人听

两轮盲测里所有评审都没有评声音。为了让"听不了"也能交出一份诚实的报告，每一项先归类：

| 类别 | 条目 | 说明 |
|---|---|---|
| **脚本可放行也可判失败**（量本身就是要判的东西） | 声 T-01 积分响度、T-02 真峰值、T-03 音频流、T-04 音画流偏移、T-05 校准段残留；声 S-01 削波段计数；声 S-11 尾巴；声 B-07 声画偏移（画面兑现帧与声音命中点都能检测到时） | 不需要耳朵。B-07 在画面事件检测不出兑现帧（慢溶解、无尖锐事件）时降为"可定位"（《书》13.5：优先用画面代码的事件表） |
| **脚本可判失败，放行要人耳** | 声 S-02 可懂（ASR 不过可判失败）、声 B-04（分轨上两个判据都判不可闻）、声 B-05、声 S-01 断音、声 S-06、声 S-12、声 S-13 | 脚本说"坏"可信，说"好"不够 |
| **脚本只能定位，判定要人耳** | 声 B-01 咔哒、B-02 剪接、B-03 掉音、B-04（只有混音时）、B-06、声 S-03 错读、S-04 底噪、S-10 片尾硬断 | 脚本给候选时刻表，评审逐个回听 |
| **只能人听或人测** | 声 S-07 临时配音（说话人是否同一个）、声 S-08 复述测试；第 3 节全部维度 | 测量可作证据，不能定级 |

**能从音频文件测的量**（第 7 节自动项）：积分响度、短时与瞬时响度曲线、LRA、真峰值、静音区间、削波段、声音起音与命中点、声画同步偏差、ASR 逐词时间戳与置信度、单声道折叠前后差、闪避量（说话时段内人声与音乐的短时响度差，**需要分轨**；只有混音时用分离模型估计，只作"可定位"）。

## 3. 上限维度

每个维度写：判断问题、L1→L4 各级"听到什么"（写现象，不写手法和参数）、典型 AI 低级感、回炉指向、证据来源。所有维度都必须有人听才能定级；"证据来源"一行写的是脚本能提供哪些辅助证据。

**L2 的计数口径**：一个维度命中"典型 AI 低级感"≥ 2 条，该维度最高 L1；命中 1 条，最高 L2 且必须在报告里写出是哪一条。命中只扣对应维度，不判 L0。

### 声 D1 职责：每个声音在做什么 [声]

**判断问题**：删掉某一个声音，观众在那一刻会少知道什么、少感到什么，说得出来吗？声音是在做画面做不到的事（交代画外、标记时刻、给出材质和重量、托住情绪、建立地方），还是只把画面已经说清楚的事再说一遍？有没有哪一段，最不能被压缩的那条线（配音、音乐、画面动作）在决定时间，而别的线跟着它？

| 级别 | 听到什么 |
|---|---|
| L1 | 声音是"铺上去的"：一层背景曲从头到尾，换到别的片子上也一样；音效只是把画面上已经看得到的动作再响一遍；关掉声音，什么都没少 |
| L2 | 大多数声音说得出它在做什么；关掉声音会少一些东西（落点、材质、情绪的方向）；没有明显多余的声音 |
| L3 | 每个声音都在做事，删掉哪一个都会少点什么；声音交代了画面没交代的东西（画外、重量、地方、下一秒要来的事）；时间由最该决定时间的那条线决定，其余跟得自然 |
| L4 | 声音承担了一件只有声音能做的事，而且这件事是这支片的关键——没有它，片子讲不成 |

**典型 AI 低级感**：同一首无害的轻快背景曲；每个画面动作都配一个声；"增强氛围""提供反馈"式的声音，删了也没人察觉；口播片里音乐、音效、人声同时在抢；画面按估计秒数做完，声音塞进去，处处差一点。

**回炉**：《书》第 1 章（缺口陈述、领拍者的压缩测试、减法收尾）。

**证据来源**：人听；复述测试（共用 S-08）里缺掉的信息可作证据。

### 声 D2 声音世界 [声]

**判断问题**：用一句话说得出这支片"听起来是什么世界"吗（什么材质、什么空间、声音从哪来）？声音像是同一个地方、同一种材质族里的，还是每个事件换一套音色？只播声音轨，听的人会把它归到哪一类片子（广告、游戏、纪录、梦）？和片子实际的类型一致吗？如果是反差世界，反差有理由吗？

| 级别 | 听到什么 |
|---|---|
| L1 | 音色各自为政：合成的嗖、录音的叮、管弦的铺底各在各的空间；或者只播声音轨，听起来是另一类东西（产品片听成游戏）；曲子换到风格完全不同的片子上也"挺合适" |
| L2 | 声音听起来属于同一个世界；类型对得上；曲子为本片选过，换到别的片子会别扭 |
| L3 | 声音世界和画面的材质、空间一致到能互相证明（软的听起来软、重的听起来沉、远的听起来远）；或一个有理由的反差，一句话就说得清 |
| L4 | 声音世界本身成为这件作品的识别：只听几秒就知道是它 |

**典型 AI 低级感**：万能轻松背景曲；提示音、金币声让非游戏内容听成游戏；"未来感"一律纯正弦扫频；有音高的音效和曲子不在一个调上；合成声和录音声混在一起没有放进同一个空间。

**回炉**：《书》第 2 章（材质推导、一件乐器的世界、反差世界、无曲）、第 11 章 11.2、第 15 章 15.5–15.6（空间）。

**证据来源**：人听；M-12（有音高音效与和弦的冲突数）、M-13（材质族数、混响数）只作提示。

### 声 D3 音乐结构与画面的关系 [乐]

**判断问题**：音乐的层次（拍、小节、乐句、段落）和画面的层次（小动作、元素、段落）对得上吗？对上的方式是有意的（重配重、轻配轻；只跟一层；故意错开再兑现），还是"每一拍切一刀"或"完全没关系"？最大的画面变化落在音乐最大的边界上，还是落在一个响但不重要的鼓点上？

| 级别 | 听到什么 |
|---|---|
| L1 | 音乐只是垫底，和画面没有关系；或机械卡点，每一拍都切；或所有卡点都落在弱拍上，看起来总是"差一点" |
| L2 | 段落边界落在乐句边界上；重要的画面变化有音乐托住；没有明显的"差一点" |
| L3 | 音乐的层级和画面的层级一一对应，听得出哪一下是段落、哪一下只是点缀；有意的错开在下一个落点兑现 |
| L4 | 音乐和画面像一个通道：一次抢拍或一次落空，让观众在那一刻屏住 |

**典型 AI 低级感**：画面随电平抖动像循环动画；画面变化等距；把最响的一下当成最大的边界；换了曲子画面没跟着改。

**回炉**：《书》第 3 章（层级从这首曲子里测出来、强度配对、选一层、对位）、第 8 章（剪曲）。

**证据来源**：人听；M-05（命中率在两种基线下的百分位）、M-06（切点落在重拍 ±1 帧内的比例，接近 0 或接近 100% 都只作提示）。

### 声 D4 分层与让位 [声；口播作品必评]

**判断问题**：任何时刻，都清楚此刻谁是前景吗（人声、音乐、一个音效，或静默）？人声在说关键句时，其他声音退到哪里了，退得听不出痕迹吗？配音停下、画面在演示时，音乐有没有接过前景？需要被听见的音效，是落在说话的空隙里，还是被说话盖住了？让位的电平变化本身被听出来了吗（一抽一抽）？

| 级别 | 听到什么 |
|---|---|
| L1 | 音乐全程同一电平压着人声；或压得太低，像没配乐；音效全在场、全被人声盖住；闪避一抽一抽 |
| L2 | 说话时人声清楚，音乐在下面但听得出它在；停顿处音乐回来；需要听见的音效都听得见；让位没有痕迹 |
| L3 | 前景按时刻换得自然：说关键句时只剩人声，演示时音乐接手，揭示时让给一个音效或静默；层次在手机外放上也分得清 |
| L4 | 前景的交接本身成为节奏：一句话说完、音乐恰好涌上来，观众记住的是那一刻 |

**典型 AI 低级感**：音乐从头到尾一个电平；人声段和非人声段的音乐电平无差别；转场声压在说话上；电平变化不和任何起音重合，听得见音量在动；音效统一一个比例地摆在音乐上面。

**回炉**：《书》第 7 章（按时刻定前景、空隙窗与窗口预算、旁白下音乐压多少的三种取向、让位的形状、音效相对音乐的电平）、第 12 章 12.6。

**证据来源**：人听（必须含手机外放）；M-07（闪避量：说话时段内人声与音乐的短时响度差，需分轨）、M-08（与起音不重合的增益变化数）、共用 S-02 可懂度。

### 声 D5 配音 [口播]

**判断问题**：配音像一个人在对你说话，还是在念稿？重音落在关键词上吗？停顿跟着意思走吗——句内短、句间长，观众分得出逗号和句号吗？句与句之间有没有"这句突然远了"？语速改过的地方，理解来得及吗？音色和空间与片子的叙事位置相称吗？

| 级别 | 听到什么 |
|---|---|
| L1 | 能听懂，但平直：每句同一语调，句尾统一下坠；停顿等长；重音落在虚词上；为凑时长把句子拉开或整体加速 |
| L2 | 语气自然；重音在关键词上；停顿有层次；句与句之间听不出忽远忽近；干净（无齿音刺耳、无喷麦、无发闷） |
| L3 | 语气随内容起伏，停顿有呼吸，停顿的长度给了画面揭示时间；音色本身在说话者是谁、在哪里、和观众什么关系上传达了信息 |
| L4 | 一句话的语气转折成为全片的记忆点 |

**典型 AI 低级感**：合成配音的念稿腔；句末一律下坠或一律上扬像疑问；数字、英文、多音字读法生硬；句间停顿全片一样长；为对齐画面在一句话中间硬插停顿；配音和画面空间不符（大空间画面配贴耳干声，且不是有意的）。

**回炉**：《书》第 10 章（校对、先列听感问题再决定动不动、句间齐平、有意着色、剪辑与停顿、语速与停顿的缩放关系）。

**证据来源**：人听；共用 S-02、S-03；M-03（逐句短时响度极差）。

### 声 D6 音效的质感与重复 [效]

**判断问题**：音效听起来像它对应的那个东西吗（大小、重量、材质、距离）？同一个动作反复出现时，是同一个物体发出的几次声音，还是被听出"同一个文件又放了一遍"？变化大到像换了个物体吗？同类动作里，有的有声有的没声，有理由吗？

| 级别 | 听到什么 |
|---|---|
| L1 | 音效库默认的"嗖、叮、咚"每处都上；同一个文件在短时间里一模一样地重复；更响的那一次反而更暗，像两个东西；同类动作有声无声随机 |
| L2 | 音效贴合对应物的材质和大小；重复处有自然的变化又认得出是同一个东西；同类动作处理一致 |
| L3 | 音效的质感和画面互相证明（软的软、沉的沉）；重复本身成了节奏或母题；冲击的分量和它在内容里的分量相称 |
| L4 | 一个音效成为作品的记忆点，事后想起片子先想起这个声音 |

**典型 AI 低级感**：每个切点一个噪声掠过；代码或界面片什么都响；单层合成的扫频和白噪声当"科技感"；音效贴在动画起始帧，声音结束时动作还没落定；相机随拍抖动，次数远多于稿子的重点。

**回炉**：《书》第 5 章（覆盖面、密度跟着信息负担走、冲击与随动）、第 11 章（声源、重复与变化）。

**证据来源**：人听；M-14（同一文件在短窗内连续出现、同类变体的电平与亮度相关、转场声去重数）。

### 声 D7 静默、转折与峰值 [声]

**判断问题**：全片最响、最满的那一刻在哪里？那里是内容最重要的点吗？那个点需要被"感到"还是被"读到 / 听懂"——峰值和它的关系对吗（叠在一起，还是让开给理解）？有静默吗？静默听起来是有意的（比此前任何自然停顿都明显长、落在结构点上），还是像断了？静默之后来的第一个声音配得上这个位置吗？转折是在少数几个维度上一起变，还是靠一串渐起加打击？

| 级别 | 听到什么 |
|---|---|
| L1 | 每一段同样的力度，处处是高潮所以没有高潮；或最响的地方是标志或片尾；转折靠音效叠出来；静默太短听不出是有意的 |
| L2 | 有一个听得出的峰值，落在合理的位置；转折数和内容转折数相当；如有静默，听得出是有意的 |
| L3 | 峰值的位置和内容的需要对上（要感到的叠上去，要听懂的让开）；静默保住了该保住的东西（空间、调性或节拍），回来那一下是兑现；转折干净，一两个维度在变，其余让开 |
| L4 | 一次静默或一次撤空成为全片最有分量的时刻 |

**典型 AI 低级感**：每个场景都有渐起和打击；中段一声闪白配重击当高潮；静默之后接一个无关的提示音；全片短时响度最大值落在结尾标志上；长片电平全程平到让人走神，或忽高忽低让人想调音量。

**回炉**：《书》第 9 章（静默的材质、长度、之后接什么；转折怎么搭）、第 15 章 15.1–15.2（弧线、峰值放在哪里）。

**证据来源**：人听；M-02（相邻段落响度差）、M-11（全片最响时刻落在哪个事件）、M-15（设计静默与此前最长自然停顿之比）。

### 声 D8 开场与结尾 [声]

**判断问题**：第一个声音来得及时吗，还是前面有一段没理由的空？开场电平的选择（一开始到位 / 留出抬升 / 环境先行）和片种相称吗？如果是信息流作品，开场的关键信息有没有只放在声音里？结尾听得出"结束了"吗——张力在它攒的那个维度上被释放了吗（调性、节奏、密度、空间）？还是一段长淡出、一记重砸、一段死寂？循环作品，接缝处听得出"又从头了"的跳吗？

| 级别 | 听到什么 |
|---|---|
| L1 | 开头音乐满电平突然闯入，或迟迟没有声音；结尾长淡出、和画面无关；或标志处一记重砸加镲片成了全片最响；循环接缝处声音跳 |
| L2 | 开头干净、及时；结尾听得出结束，和画面最后一个事件对得上；循环接缝不跳 |
| L3 | 结尾释放的维度正是全片攒张力的维度，结束得"只能这样"；开场的第一个声音就在交代这个世界 |
| L4 | 最后一个声音（或最后那段无声）让人回味，想再看一遍 |

**典型 AI 低级感**：开头 1–2 秒冷场又不是有意的冷开场；音乐被一刀截断而画面没有戛然而止的理由（硬错按共用 S-10）；"片尾标志 + 闪光声"；尾音还在走视频就切了，或尾音早停了画面还挂着。

**回炉**：《书》第 14 章（开场、开场电平、结尾按释放的维度分、循环接缝）、第 8 章 8.2（怎么结束）。

**证据来源**：人听；M-09（第一个高于房间音的声音在第几帧）、M-10（声音结束后视频还有几帧）、M-11、M-18（循环首末电平差）。

### 声 D9 跨越剪辑点：转场与连续 [多镜作品]

**判断问题**：每个切点，声音让观众感到的是"继续"还是"换了"？和画面想要的一致吗？要继续时，靠什么连起来（声音提前进入或延后退出、一个反复出现的母题、一层不断的环境）？要换时，换得干脆吗？转场声的位置和它的任务对得上吗（要"标记"切点的声音，是在切点上涨到最高，还是切点前就涨完了）？转场声有没有压在说话上？

| 级别 | 听到什么 |
|---|---|
| L1 | 每个转场同一个"嗖"；或每个切点都一样的短交叉淡化配通用转场音；声音在切点处随画面一起断，空间每切一次就塌一次 |
| L2 | 切点处的声音处理和画面的意图一致；该连的连上了，该断的断得干净；转场声不压人声 |
| L3 | 声音把画面没说清的切点说清了（这是同一个地方 / 这已经是另一个世界）；母题出现得够多，观众开始等它 |
| L4 | 一次声音转场本身成了片子的一个想法 |

**典型 AI 低级感**：转场声文件去重后只剩一两个；每个切点都加转场声；母题只出现一两次，观众还没认出就没了；切点处声像宽度忽变，像换了空间又不是有意的。

**回炉**：《书》第 12 章（错位进出、母题桥、环境床连续、硬断；转场声放在哪里由任务决定）、15.5（跨切点宽度不变）。

**证据来源**：人听；M-14（转场声去重数）。

### 声 D10 创意与新鲜度 [声]（单独打分）

**判断问题**：这支片的声音有没有一个属于它自己的想法——一种声音世界、一次静默、一个母题、一种声画关系——换一个题目就不成立？如果把同一题目的另外几件作品的声音轨放在一起盲听，认得出哪条是它吗？声音是在"配"画面，还是给了画面一个画面自己没有的维度？

| 级别 | 听到什么 |
|---|---|
| L1 | 第一层默认：轻快无害的背景曲 + 音效库默认声 + 念稿配音；声音轨可以原样挪到另一支片 |
| L2 | 声音为这支片选过，有一两处贴着内容的处理；但整体是同类片常见的做法 |
| L3 | 有一个说得出的声音想法，贴着这个内容长出来，换题就不成立；同批盲听认得出 |
| L4 | 声音想法意外又正确，事后觉得只能这样；有人会因为它转发 |

**第二层默认识别**（命中只扣本维度，不判错，不影响其余维度）：
- 定义：避开第一层默认之后，模型会稳定落到同一批"聪明的第二选择"。在声音里，《书》标为"模型平时不会默认这样做"的取向（一件乐器的世界、对位、先闻后见、时分让位、环境先行、密度释放、空间释放、硬断、母题桥……）本身都是合法取向，**用了不扣分**；只有当它被用成固定套路——同一个取向在同批作品里反复出现、而且换题也成立——才算第二层默认。
- 识别方法：①同批（同一题目或同一时期）作品的声音轨两两盲听，在"声音世界、开场方式、峰值承担者、结尾方式、静默位置"五层里撞了 ≥ 2 层的，两件都记命中；②问"这个选择是从这件内容里推出来的吗"：说得出内容上的理由（这个材质、这个空间、这个转折只有这件片子有），不算命中；只说得出"这样更高级、更克制、更有设计感"，算命中。
- 两轮盲测没有声音数据，本标准**还没有观察到的第二层默认清单**；第 3 轮起有声作品的同批撞车记录写入第 6 节标杆库的反例，累积后收进五份标准共用的登记表 `standards/第二层默认登记表.md`（声音层一节）。
- 命中 1 条：本维度最高 L2；命中后若作品在这个取向上多走了一步、让它只属于这件内容（例如母题的音色本身就是片中那个物体的声音），两位评审都认可时可到 L3，并写明理由。

**典型 AI 低级感**：第一层默认三件套（无害背景曲、库默认音效、念稿配音）；"声波可视化"式的声画关系（画面随电平跳）；把"克制"当作想法本身，留下一片空却说不出空在哪里有用。

**回炉**：《书》第 1、2 章（从缺口和材质推出声音，而不是从清单里挑）、各章"取向"和"故意违反"小节；第 18 章 G29（系列声音签名只固定一个点，其余每集重新设计）。

**证据来源**：人听，同批盲听比较。脚本不提供证据。

### 声 D11 执行与完成度 [声]（单独打分）

**判断问题**：声音的每一处是"决定过的"，还是"差一点"？落点贴在兑现那一帧，还是贴在动作起点？剪接、闪避、电平变化都听不出痕迹吗？配音稿、字幕、实际说出的话三者一致吗？后半段和前半段一样细吗？交付文件的响度、峰值、形式和评审卡一致吗？

| 级别 | 听到什么 |
|---|---|
| L1 | 处处差一点：落点系统性晚半拍（对着动作起点）；剪接、闪避听得出；后半段明显比前半段粗；未到 B 层但已经让人皱眉的瑕疵不止一处 |
| L2 | 挑不出可闻的瑕疵；落点贴；剪接、让位不露痕迹；前后一样细 |
| L3 | 细到经得起耳机反复听：尾音长度和空间一致，重复声音的微变化自然，每次电平变化都藏在另一个变化里 |
| L4 | 执行精度本身让人注意到"做得好"——在手机外放上和耳机上都成立 |

**典型 AI 低级感**：手填秒数造成的系统性错位；打完时间戳又剪了音频，后半段全体错位；文件起点对事件、带前导静音的音效全都晚到；母带快速限幅压扁了关键一击；整体调小音量冒充修好了刺耳；改了几轮，每轮修好的和新引入的一样多。

**回炉**：《书》第 4 章（兑现帧、命中点）、第 6 章（一个时钟、成片回测）、10.5（时间戳与变换链）、15.4（增益随时间怎么变）、第 16 章（对照、修刺耳、何时停）。

**证据来源**：人听；M-04（声画偏移分布与制作容差 E 的比较）、M-08、M-17（母带前后关键事件的峰值与前后短时响度之比变化）、T 层结果。

## 4. 判级规则

### 4.1 判级顺序

1. 有声全速看一遍，写下记住的声音时刻（≤ 3 条）、一句话复述、"哪一刻声音在做事"，封存（1.5 节）。
2. 跑 T 层（第 7 节 A-T 项）。未过项列入"交付未过"，附修复方法；不中断评审。
3. 跑 B 层：本标准 B-01～B-06，加共用 S-01～S-13。先跑脚本，再按 2.5 节逐项回听候选。任一未过 → 整件 **L0**；列出全部未过项及证据（时间码、测量值、回听结论、测试者原话）；维度照评，写成"修好后的上限"。
4. 逐维度定级（L1～L4、n/a 或未评），每级附时间码证据；先回答判断问题，再按第 3 节的计数口径勾选低级感。
5. 按 4.2 合成整件级别。
6. L3、L4 候选做两两比较（4.3）；标杆不足时停在"候选"，按 L2 合成。本标准目前没有任何标杆（6.3），所以**现阶段声音的 L3 只能写"L3 候选"**。
7. 有前一版本时，输出维度差分表（4.5）。
8. 评审结束后打开评审卡的有意说明，只用来解释第 7.2 节 M 项，不改级别。

### 4.2 合成

| 声音级别 | 条件（全部满足） |
|---|---|
| L0 | 任一 B 层（含共用 S）未过 |
| L1 | B 层全过，但不满足 L2 |
| L2 | 全部适用维度 ≥ L2；声 D10 可以是 L1 |
| L3 | 全部适用维度 ≥ L2；声 D10 ≥ L3；声 D1 ≥ L3；L3 及以上的维度 ≥ 适用维度数的一半；两两比较确认 |
| L4 | 满足 L3；声 D10 = L4，且另有至少 1 个维度 L4；两两比较确认；用户本人确认"惊艳"。缺用户确认时记"L4 候选" |

**短板与封顶**
- 声 D1 为 L1 → 声音最高 L1：声音在做什么都说不出，不是商业合格。
- 声 D4 为 L1 且作品是 [口播] → 声音最高 L1：口播作品里人声被压、层次混乱，观众的主要通道就坏了。
- 声 D10 为 L1 → 声音最高 L2，不进 L3 候选。
- 除 D10 在 L1 时的豁免外，声音级别不高于"最低适用维度 + 1"。
- T 层不进合成，只在抬头单列。

**报告抬头必须并列四件事**：交付层状态；观众层状态（通过 / 未过：列 ID / 通过（某某未测））；声音级别；**创意与新鲜度（声 D10）和执行与完成度（声 D11）各自的级别**。例："声音 L0（修好后上限 L2）｜观众层未过 声 B-02｜交付未过：声 T-01 缺实测依据｜D10 L2 / D11 L1"。

**和其他标准合成整件**：一件有声作品同时用视觉、动效、镜头与叙事、声音几份标准评时，各份各报一个级别，整件级别取各份的最低值（任一份 L0 即整件 L0）。声音只能拉低整件，不能把画面不够的作品抬上去。

### 4.3 两两比较

- 一次只比两件、一次只问一个维度："在声 Dx 上哪一件更好？证据在哪个时间码？"对标杆的盲比必须二选一。
- **比较前两件先做响度匹配**（积分响度差 ≤ 0.2 LU，《书》16.2；0.2 来自"远小于约 1 LU 的可察觉差"，该可察觉差凭记忆，**待实验**），否则更响的那件几乎总会被听成"更好"。
- 两版只能差在被比较的那一层：比"有没有这个音效"时，源区间、裁切、基础电平、播放设备都相同（《书》16.2、16.7）。
- L3 候选对照 3 件 L3 标杆，胜 ≥ 2/3 确认；L4 候选对照 3 件 L3 标杆全胜，并对 L4 标杆不输。对照从同片种（口播讲解、发布、故事、氛围、界面演示）、同收听条件里取。
- 两名评审差一级取低者；差两级及以上，加第三名评审，取中位。

### 4.4 评审听不了声音时

两轮盲测里所有评审都没有评声音。这是常态，不是例外，规则如下：

- **T 层照跑**，全部由脚本判定，结论有效。
- **B 层按 2.5 节分开写**：
  - "脚本可放行也可判失败"的条目照判，结论有效。
  - "脚本可判失败、放行要人耳"的条目：脚本判未过 → 未过有效，整件 L0；脚本未判出问题 → 写"未测（脚本未见问题）"，**不写通过**。
  - "脚本只能定位"和"只能人听"的条目写"未测"，附脚本候选时刻。
  - 观众层状态写成"通过（声 B-01、B-02、B-03、B-06、S-03、S-04、S-07、S-08、S-10 未测）"之类，不得写成"通过"。
- **维度全部写"未评"**，写原因"评审听不了声音"；可以附测量提示（例如"M-02 相邻段落差最大 7 LU，补评重点"），提示不进入合成，不得估级。
- **声音级别的写法**：
  - 脚本已判出 B 层未过 → "声音 L0（声音维度未评）"，L0 有效。
  - 否则 → **"声音未评（脚本底线：未见问题），待声音补评"**。
- **整件级别的写法**：整件写成 **"≤X，待声音补评"**，X 是其余几份标准合成出的级别（声音只能拉低、不能抬高，所以 X 是上限）。例："整件 ≤L2，待声音补评"。声音补评之前，整件不得给出 L3 及以上的结论，只能写"L3 候选（待声音补评）"——声音没听，"惊艳"无从确认。
- **必须附一份待试听清单**（《书》13.3 取向 C）：按风险从高到低列出时刻、要听什么、怎么判断（例："0:12.3，揭示处的静默，判断：是悬念还是像断了"；"0:07.0，剪接点，判断：有没有绊一下"）。清单至少包含：全部脚本候选（B-01～B-03）、评审卡"必须听到的声音"、全片最响时刻、开场前 2 秒和结尾最后 2 秒。补评者按清单听，补完后重新合成。
- 不得因为听不到而把声音承担的转折判成"没有转折"（同镜头与叙事 4.4）。
- 评审能听、但只有一种设备时：维度照评，在证据里注明"仅耳机"或"仅外放"；评审卡写主要收听设备是手机外放而只用耳机听过的，声 D4 最高给 L2 候选，待外放补听。

### 4.5 版本对比：维度差分表

| 维度 | 旧版 | 新版 | 变化 | 证据（时间码） |
|---|---|---|---|---|
| 声 Dn | L? | L? | 升 / 降 / 平 / 平（同级改进） | … |

- 允许"平"。4.3 的"必须二选一"只用于对标杆的盲比，不用于版本对比。
- 两版先做响度匹配再比（4.3）。
- 另列三行：B 层未过项的增减、T 层未过项的增减、**这一轮修好了几个问题、新引入了几个问题**（《书》16.3：新引入数不再明显少于修好数时，停止在混音里修，回到输入）。
- 结论写清：哪几个维度变好、哪几个没动、级别为什么动或不动。D10 和 D11 的变化分开写。

## 5. 样稿内容口径

与视觉标准第 5 节（持有方）、镜头与叙事标准第 5 节同一口径，这里只补声音特有的情况。

- **事实不编，样稿要填**。真实世界的事实（真实品牌的数据、真实人物说过的话、真实产品的声音标识）不得编造或冒充，编造按共用 S-09 判 L0；用生成的人声冒充一位真实存在的人说话，按视觉 B-11（冒充）判 L0。
- **明显是示例的虚构内容不算编造**：示例口播稿里的虚构品牌、人名、日期、价格、数字，只要不冒充真实对象，都算样稿内容，在评审卡"样稿示例内容清单"列出即可。缺配音稿时，写一份明显合理的示例稿配出来，不要留空。
- **留空的算未完成**："此处配音"的占位音轨、空着的音乐位、明显的临时配音（说话人与终稿不同、念着括号里的提示语）、测试音，按共用 S-07 判 L0（评审卡注明"内部稿"且空位写明"待补"的除外）。找不到合适的曲子时如实标"未完成项"，不得包装成"无曲型"取向（《书》2.5 的无曲是一种选择，要说得出画面里什么承担了音乐的职责）。
- **决定类内容**（范围与判别问按需求理解标准需 B-06）在口播里念出来时，即使是示例，也要在评审卡"发布前须用户确认"一栏列出；评审者在报告末尾照录。未列出的，评审者补列，不扣分。口播与上屏的决定类内容必须一致（共用 S-09）。
- **声源权利**不在评审里判级，但属于发布前必须确认的事：成片里每一个非自制的声源（曲子、音效、采样）都要有许可记录；许可要求署名的，不得混进不允许署名的投放场景（《书》17.4）。评审者发现来源可疑的声源，在报告末尾"发布前须用户确认"里列出。
- **用户提供的音频**：对用户录音做过的改变原声性质的操作（《书》17.2 的 ③④ 类，包括剪辑），交付说明里要逐条列出并有用户同意；评审看不到过程，只在成品里听出明显改写（音色、语速、内容被剪）而评审卡没有说明时，列入"发布前须用户确认"。

## 6. 标杆库规范

### 6.1 规则

- 标杆只给评审看，不给做作品的人看。存放位置：`standards/标杆/声音.md`（待建）。
- 每件标杆一条记录：ID（`S-<级别>-<序号>`）；来源（只作内部记录，任何作品、封面、文案里不得出现来源或作者 ID）；片种 / 时长 / 收听条件 / 声音构成；声音级别与各维度级别（未评留空）；**为什么是这个级别**（必须指向时间码上的可听现象，不允许只写"好听""高级""有氛围"）；正例或反例；入库人、日期、评审用什么设备听的、是否经用户确认。
- 标杆文件按交付响度做好匹配后存放（4.3），避免"更响的更好"混进标杆。
- 正例尽量配一件同片种的反例，组成比较对；最好的比较对是**同一画面配两版声音**，只差一层（《书》16.2）。
- 另收**维度切片**：整件 L2 的作品若某一段在某个维度达到 L3 或 L4（一次静默、一个转场、一个结尾），截取该段作为单项标杆，记起止时间码。
- 只收成片音视频，不收波形截图或文字描述。画面方面的级别交给视觉、动效、镜头与叙事标准的标杆库。
- 用户亲口说"好听""这个声音对了""惊艳"的，原话直接入库为对应级别，是最高级别的校准数据；标准判级与用户判断冲突时用户胜，记录冲突，找出标准漏掉的观察，进入修订。用户说"吵""累""没感觉"的同样入库，作 L1 / L2 或 B 层校准。

### 6.2 每级放什么

| 级别 | 放什么 | 标注重点 |
|---|---|---|
| L0 | 每条 B 底线（含共用 S）至少一件实例，尤其是只能人耳判定的几条（咔哒、剪接、掉音、没被听见） | 哪条底线、时间码、脚本测量值和人耳回听结论；脚本漏报或误报的也要记 |
| L1 | 无错但"铺上去的"作品，含同批声音撞车组 | 命中哪些维度的哪几条低级感；撞车对象和撞在哪一层（世界、开场、峰值承担者、结尾、静默位置） |
| L2 | 挑不出错、层次清楚，但说不出"那一声"的作品 | 为什么挑不出错；离 L3 差什么 |
| L3 | 能复述出某一个声音时刻、换题就不成立的作品 | "那一声"的时间码；删掉或换掉它为什么会变差 |
| L4 | 用户确认的惊艳作品 | 意外在哪里；为什么事后觉得是对的；用户原话 |

### 6.3 第一批锚点

**空缺。** 第一批锚点应来自两轮盲测里两位评审意见一致的作品，但两轮盲测里所有评审都没有评声音（有一份评审记录明写"无声音题目，声音项全部 n/a"），没有一件作品有两位评审一致的声音级别。本标准不从画面评审的结论里推断声音级别，也不用制作者自评充数。

**补齐方法**：
1. 第 3 轮起，有声作品至少安排一位能听的评审；两位能听的评审意见一致的作品（两位都给 L3 的作正例，两位都判"默认模板"的作反例），只写作品编号（轮次-题号-作品号）和理由，按 6.1 入库。
2. 在锚点到位之前，先建 **L0 实例库**：B 层脚本候选经人耳确认为真的、和被人耳否掉的，各存一例，用来校准脚本候选的门槛（第 8.1 节）。
3. 用户对任何有声作品说出的声音判断，按 6.1 最后一条直接入库，优先于评审一致样本。

**校准备注**（作为"必须测、不能靠印象"的证据）：两轮里评审对画面的停留时间、遮挡等，凡是靠看而没有测的，两位评审都出现了不一致（见镜头与叙事标准 6.3）。声音比画面更难凭印象判断，所以本标准里凡能测的项（T 层、2.5 节前两类）一律先测再听，测出来的结果不得被"听着还行"推翻；反过来，测量"未见问题"也不得写成"听过、没问题"。

## 8. 待实验阈值、跨标准对应与修订

### 8.1 待实验阈值一览

**底线里标"待实验"的阈值（7 个）**：声 T-01 的 1 LU（与交付值之差）；声 T-02 的 2·sd 余量；声 B-01 的脚本候选门槛（首尾样本 0.05 与高频突增）；声 B-02 以 E 作剪接候选门槛；声 B-03 的 0.15 s；声 B-04 的第 90 百分位；声 B-04 质感判据的"不低于"。另有判级规则里 1 个：4.3 的响度匹配 0.2 LU。声 B-01～B-04 的判定本身靠人耳，门槛只决定候选清单的宽窄，定错的代价是漏听或多听，不是错判。

**规范值但适用性待实验（1 项）**：声 B-07 采用 ITU-R BT.1359 的 45 / 125 ms。规范在以对白为主的广播节目上测得，对短视频里的冲击、卡点是否同样宽松未知（《书》4.4、6.3）；校准前照用规范值，不自行收紧或放宽。

**只作证据的待实验数（M 项 6 个）**：M-02 的 4 LU / 6 LU、M-03 的 1.5 LU、M-07 的每百字 1 个、M-09 的"越早越好"假设、M-15 的 1.5 倍、M-18 的循环接缝。

**这些数共同依赖的那个前提**：《书》10.3 的"响度最小可察觉差约 1 LU"是凭记忆写的、没有出处，它同时撑着 T-01 的 1 LU、4.3 的 0.2 LU、M-02、M-03。若实测可察觉差更小，T-01 和 4.3 偏宽，需要收紧；M-02、M-03 的台阶则偏大。它是第一优先的校准对象。

**校准顺序**：① 约 1 LU 的可察觉差（同一片段做 0.5 / 1 / 2 LU 三档差，在手机外放和耳机上各做 ABX）；② 声 B-01～B-03 的候选门槛（用 6.3 的 L0 实例库算脚本的漏报与误报）；③ 声 B-04 两个可闻判据（同一混音删掉 / 保留目标音效，人耳盲听对照脚本判定）；④ 声 B-07 对冲击与卡点的门限（《书》4.4：同一片子做三版，盲评"抢""拖""对"的比例）；⑤ 平台响度：按 T-01 的求法对每个投放平台实测并记日期（《书》18.2 G25）。

**校准来源**：能听的评审数据（两位一致的判断）、用户的听感判断、平台实测、播放数据（开场与结尾处的留存斜率，《书》18.2 G24）。单条数据不直接改阈值，累积成证据后按 `protocol.md` 修订；改动记入 `CHANGELOG.md`，旧版存入 `standards/archive/`。
