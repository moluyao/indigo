# 镜头与叙事质量标准 v0 · 青出 / Indigo

> 依据：镜头与叙事 book r5，2026-11-19（`domains/镜头与叙事/book.md`，下文简称《书》）。外部规范：WCAG 2.2 · 2.3.1（闪烁，以 `reference/WCAG-2.3.1-闪烁阈值.md` 为准）、WCAG 2.2 · 1.4.3（对比度）、ITU-R BT.1359（声画同步可察觉门限）。真实失误数据：两轮盲测评审记录（`eval/`）。
> 对齐对象：`standards/视觉设计.md` v0（下文简称"视觉标准"）、`standards/动效.md` v1（下文简称"动效标准"）。同一件事在两份标准里只有一个阈值；共用条目见 2.3 节，跨标准的分歧和处理见 8.2 节。
> 回答一个问题：一支动态作品（短视频、动画、发布片、讲解片、循环动图、界面演示）在"讲了什么、怎么展开、镜头怎么组织"上，什么叫坏、能用、商业合格、精品、惊艳。
> 本标准评的是**观众一侧看到、听到的效果**，不规定手法。《书》里每一章的取向全部并列，任何一种取向都不加分、不扣分；手法和参数只在《书》里，本标准只判级，并在不达标时指回《书》的章节。
> 写成日期：2026-11-20。

## 1. 总则

### 1.1 评什么，不评什么

**评**：观众看一遍（全速、可能静音、随时可能划走）之后——
- 能不能说出"什么变成了什么"，开场有没有让人留下，结尾是不是讲完了；
- 每一镜读不读得完，因果看不看得出，焦点有没有被抢、被挡、被甩出画；
- 全片有没有形状（起伏、转折、峰值、静止），还是一页一页地翻；
- 镜与镜之间是"继续"还是"换了"，观众是否每次都知道为什么；
- 讲解、证据、表演让观众相信了什么，有没有让他搭出错的结构；
- 这件作品的展开方式是不是属于它自己，还是又一套熟悉的骨架；做得细不细。

**适用范围**：本标准只评动态作品。条目上标的条件：
- **[通]**：所有动态作品。
- **[信息流]**：评审卡写明平台会自动播放、可能静音、以首帧或某帧作缩略的。
- **[循环]**：评审卡写明循环播放的作品。
- **[有声]**：作品有声轨且评审能听。听不了时写"未测"，不估。
- **[讲解]**：有口播、字幕论证、证据素材或界面演示的作品。
- **[角色]**：画面里有人、角色或被赋予意图的物。

**不评**（交给别的标准）：单帧的版式、字体、色彩、画质（视觉标准）；运动曲线、速度质感、转场本身的做工、配音与混音（动效标准）；文案本身好不好（写作标准）。同一件作品可以同时用几份标准评，各报各的。同一件事被两份标准都管时，只测一次，用 2.3 节写明的口径，并在报告里写明用的是哪个编号。

**本标准和动效标准的分工**：两份都谈节奏、转场、声画同步。动效标准看"动得好不好"（速度、曲线、过渡的做工）；本标准看"为什么在这里动、在这里换、在这里停"——节奏的形状从哪来、边界有没有理由、转折落在谁身上。一个硬伤只记在一份标准里（2.3 节列出归属）。

**不评制作过程**：评审者只看成品和评审卡，不看提示词、阐述、时间表、工程文件、方向列表、自检记录、制作对话。作品自称做到了什么，不算证据。《书》里的〔测〕项，制作者可以用来自检；评审时只有在能从成品上重新测出来的情况下才用（第 7 节）。

**编号**：本标准的条目在报告里写成"镜 B-01""镜 D3"，以免与视觉标准、动效标准的同号条目混淆。

### 1.2 五个级别

| 级别 | 名称 | 观众一侧看到的 |
|---|---|---|
| L0 | 坏 | 有看得见、听得见的错：首帧是半成品、必须看懂的那一镜读不完、答案一闪而过、主体被甩出画、接缝跳、声画对不上、闪烁超限……任一观众可感层底线（B）没过 |
| L1 | 能用 | 没有错，但展开方式是没被决定过的：一页一页翻、等间隔、处处同样的推镜、结尾一张金句卡；说得出"讲了什么"，说不出"什么变成了什么" |
| L2 | 商业合格 | 可以交给付费客户：看一遍就懂，开场留得住人，结尾讲完了，节奏有形状，挑不出硬伤 |
| L3 | 精品 | 每一处时间上的安排都说得出理由，挪动一处会变差；至少有一个"那一下"只属于这件内容（一次转折、一个承接、一个结尾），换题就不成立 |
| L4 | 惊艳 | 意外但正确：没料到它这样展开，看完又觉得只能这样；有人会把那一段转给别人 |

- L0 与 L1 的界线是"错"，靠第 2 节的底线判，可测量或可做人工测试。
- L1 与 L2 的界线是"默认"，靠第 3 节各维度的"典型 AI 低级感"逐条勾选。
- L2 以上写不成规则，只描述"看到什么"，并靠标杆比较确认（第 4、6 节）。本标准对 L3、L4 不给配方。

### 1.3 三层

| 层 | 管什么 | 不过怎么办 |
|---|---|---|
| 交付技术层 T | 导出时机械可修的：帧率、时长规格、音画流起点、循环文件首尾重复帧、导出前导帧、代表帧导出 | 记"交付未过"，附修复方法；**不判 L0**，不影响上限评审；交付未过不得发布 |
| 观众可感层 B | 观众看得见、听得见的错 | 任一未过判 **L0**；维度照评，写成"修好后的上限" |
| 上限维度 D | 好不好、有没有意图、记不记得住、做得细不细 | 给级别与证据（时间码），指回《书》 |

判别一项属于 T 还是 B：问"不改片子的任何镜头、时间和内容，只改导出设置或重新导出一次，能不能修好？"能 → T；不能 → B。

### 1.4 评审卡

做作品的人交付时附一张评审卡（≤ 14 行）。评审者只读这张卡和成品。和视觉标准、动效标准同评时，三份卡合成一张，同名字段只写一次。

| 字段 | 写什么 | 用于 |
|---|---|---|
| 目标级别 | 例："L2，镜 D3 争取 L3"；不得低于 L2 | 第 4 节对照 |
| 片种与目的 | 讲解 / 故事 / 产品展示 / 界面演示 / 氛围 / 发布开场 / 其他；是否循环播放 | 条件条目、维度适用性 |
| 画幅、帧率、目标时长 | 宽×高、帧率、目标时长 | 镜 T-01，镜 B-07 换算 |
| 平台与观看方式 | 是否自动播放、是否可能静音、缩略取哪一帧、是否循环、是否小窗、可能的观看设备与距离（手机 / 桌面 / 大屏）；未知的写"未知" | [信息流][循环] 条件，镜 B-09～B-11 换算 |
| 核心信息一句话 | 观众看完应带走的一句，可附 ≤ 2 条次要信息 | 镜 B-02、镜 D1 |
| 首末一句 | "开场看见 X → 最后看见 Y"（片子里什么变成了什么）；氛围片写"什么在一路变" | 镜 D1、镜 D5 |
| 必须看懂的事件 | 观众不看懂就带不走核心信息的那几个事件（答案、结果、名称、转折的落点），各写时间码 | 镜 B-03、镜 B-04 |
| 须读文字范围 | 流读 / 停读 / 纹理，口径同视觉标准 1.4 | 共用 S-01、S-09 |
| 代表帧 | 封面帧、关键帧的时间码，以及它们会落进哪种场合 | 共用 S-02、镜 D2 |
| 声音 | 有无口播、音乐、音效；评审能否听；口播稿或词时间（如有） | [有声] 条件，镜 B-07 |
| 样稿示例内容清单 | 哪些名称、日期、价格、数据是示例（第 5 节） | 共用 S-07、S-10 |
| 发布前须用户确认 | 决定类内容（范围与判别问按需求理解标准需 B-06） | 第 5 节 |
| 有意说明（密封） | 对第 7 节测量数据里可能显得反常之处的说明（例如"全片等长镜头是有意的机械感"） | 评审结束后才打开 |

- 评审卡缺失时，评审者从成品推断各字段，逐项标"（推断）"；推断不能用来豁免任何底线。平台无法推断时，按 [信息流] 处理（最严）；"必须看懂的事件"无法推断时，评审者自己写出"看完必须知道的三件事"再按它们测，并在报告里列出。
- 有意说明只在评审结束后打开，只能解释第 7.2 节的测量数据，不能改变维度级别，也不能豁免 B 层。

### 1.5 评审者与材料

- 评审者不是制作者，是独立会话；不知道作品出自谁。人工测试（首看暂停、静音复述、代表帧测试）的测试者也必须没看过这件作品；用 agent 当测试者时，每个测试只用一个新会话，不给它评审卡以外的任何信息。
- **材料**：成片或可确定性重放的运行版本（只看截图不够）；每秒 1 帧联系表；镜头切点表（用场景切换检测找，不按固定间隔抽帧，《书》2.1）；每镜的落定帧；逐帧画面差分曲线（"动的量"随时间）；有声时的音频波形与强音位置；须读文字事件表（出现、可读、退场时间码）。
- **评审顺序**：
  1. 全速、静音看一遍（[信息流] 作品必须先静音看），写下：记住的画面（≤ 3 条）、一句话复述、"它在什么时候变了"，封存。
  2. 有声时再全速看一遍，补写听到声音后多出来的理解。
  3. 再做测量和人工测试。测量只能补充和修正整体判断，不能代替第 1 步（《书》1.3：比较的是观众看完留下了什么）。

## 2. 底线

每条写：指标 / 阈值 / 测量方法 / 依据 / 回炉。依据里的"待实验"表示这个数目前只有推导，没有人类实测，评审照用，但第 6 节的校准数据可以改它。

### 2.1 交付技术层 T（不判 L0，记"交付未过"）

| ID | 范围 | 指标 | 未过判定 | 测量 | 依据 | 修复 |
|---|---|---|---|---|---|---|
| 镜 T-01 | 通 | 帧率、时长、画幅 | 与评审卡不符；帧率不恒定 | 按动效标准 T-04、T-07、T-08 执行，本标准不重复 | 动效标准 6.1 | 按动效标准。注意：换帧率重导出后，镜 B-07 和第 7.2 节 M-12 的落点要按毫秒重测（《书》16.4"换帧率时按毫秒重算"） |
| 镜 T-02 | 有声 | 音画流整体偏移 | 音频流与视频流起点或时长差 > 1 帧（全片所有落点一起早或晚同一个量） | 按动效标准 T-05 执行 | 《书》2.2"整体平移只是起点不同"；动效标准 T-05 | 可自动：平移音频流后重封装。修复后重测镜 B-07 |
| 镜 T-03 | 循环 | 循环文件首尾重复帧 | 末帧与首帧逐像素相同（导出时把接缝帧导了两次），循环播放时接缝处多停一帧 | 首帧与末帧求像素差，差为 0 即未过 | 《书》7.3 接缝检查法（循环的接缝要像"同一个世界在继续"，重复帧在接缝处形成一次单帧冻结） | 可自动：去掉末帧重新封装。修复后重测镜 B-06 |
| 镜 T-04 | 通 | 导出前导帧 | 工程第 0 帧是完成的画面，但交付文件开头多出黑帧、空帧或编码预滚帧 | 对照工程第 0 帧与文件第 0 帧；`ffprobe -show_frames` 看首个显示帧的时间戳和编辑列表 | 《书》6.1 共用底线（首帧就是一张完成的构图）；区分"工程里就空"（镜 B-01）与"导出多出来"（本条） | 可自动：裁掉前导帧或去掉编辑列表后重封装 |

- 镜 T-02 与动效标准 T-05 是同一项，两份同评时只测一次。

### 2.2 观众可感层 B（任一未过判 L0）

本节是本标准自己的条目。和视觉标准、动效标准共用的条目在 2.3 节，同样任一未过判 L0。

**开场与理解类**

**镜 B-01 首帧不是半成品** [信息流]
- 阈值：去掉导出前导帧（镜 T-04）之后的第 0 帧出现以下任一，未过：① 全黑、纯色或空底，没有任何可识别的物；② 任一可见元素处于入场中途——它在第一眼窗口（0.75 s，《书》6.1 的约 3 次注视）里一直单向朝落定状态变化（不透明度上升、缩放或位置趋近落定值），而第 0 帧的它单独看读不出是什么。
- 不算：动作做到一半而构图完整（"动作悬空"）、只露局部或剪影（"主体留白"）、临界帧——这些是《书》6.2、6.3 的取向，首帧本身仍是完成的构图。
- 测量：有工程时读第 0 帧所有元素的不透明度和缩放（《书》6.6〔测〕）；无工程时，单独把第 0 帧给一名没看过的测试者，问"这是一张完成的画面吗，画的是什么"，并用逐帧差分列出 0.75 s 内持续单向变化的元素，交人工确认。
- 依据：《书》6.1 共用底线、6.5、附录第 67 条（第 0 帧可能就是观众看到的全部）。非 [信息流] 作品（有声、专注观看，如发布会现场）本条 n/a，"全黑首帧靠声音开场"是《书》6.4 认可的做法。与动效标准 B-02（首个有内容帧 ≤ 1.0 s）的关系：[信息流] 作品本条更严，过了本条即过了动效 B-02；其余作品照测动效 B-02。
- 回炉：《书》6.1、6.3、6.5。

**镜 B-02 静音可懂** [信息流，且评审卡写明可能静音]
- 指标：两名没看过的测试者静音全速看一遍，各写 30 字以内复述；数复述里命中评审卡"核心信息一句话"关键实词（名词、动词）的比例。
- 阈值：两人命中率的平均 < 1/2，未过。
- 测量：测试者只看成片，不给评审卡；用 agent 时每人一个新会话。
- 依据：《书》6.1（开场的意思不能只在声音里）、15.3（讲解与新闻类片，文字是静音观众唯一的通道）、15.5。阈值与动效标准 B-36（有声复述，命中不足一半）同口径；两条都测，本条是静音版。人数与 1/2 **待实验**。
- 回炉：《书》6.2（静音一栏）、15.3、16.2。

**镜 B-03 必须看懂的事件读得完（首看暂停测试）** [通]
- 指标：对评审卡"必须看懂的事件"所在的每一镜，测试者第一次全速看（[信息流] 作品静音），在该镜切点前一帧暂停，问"这一镜发生了什么"。不能回看。
- 阈值：任一必须看懂的事件，两名测试者都答不出或答错，未过。
- 测量：每个事件换一对新测试者（或新会话），避免前面的暂停提示了后面。无法安排测试者时写"未测"，第 7.2 节 M-02（镜长 ÷ ΣR）只作候选，不代替本条。
- 依据：《书》9.1（作者系统性低估读取时间；"测量代替估算"）、9.5〔测〕（答不出的镜应为 0）、7.5（结尾的理解单元被压进极短时间）。两轮盲测：结尾的总结、答案在最后 1–1.5 s 里挤进来，是评审抓到最多的执行失误之一。人数 **待实验**。
- 回炉：《书》9.1、9.2（主轴给定型：删内容而不是加速）、7.5、11.4。

**镜 B-04 结果被吞（出点保护）** [通]
- 指标：每个必须看懂的事件，从结果**落定**（停止变化、完整可见）起，到它被遮挡、出画、切走或开始退场为止的时长 T_出。结果以须读文字为主时按共用 S-01 测，本条只测非文字的结果（状态、图形、物、动作的终态、数值图形）。
- 阈值：T_出 < (落眼数 + 1) × t × c，未过。t = 0.25 s；c = 1.5（必须看懂的事件按"关键信息"计）；落眼数：结果出现在观众此刻注视处为 0，在别处为 1，同时另有一组在动再加 1。例：出现在别处、无竞争 → 0.75 s；出现在注视处 → 0.375 s。结果在落定之前就已被遮住或切走（从未完整可见），直接未过。
- 测量：须读事件表 + 逐帧差分（落定帧 = 结果区域差分降到持续动态区以下的第一帧）；落眼数由评审在联系表上判定。
- 依据：《书》11.4 出点保护、9.1 R 公式（t、c 弱证据，**待实验**）。两轮盲测：一件作品作为答案的元素被外壳挡住下半、不到 0.5 s 出画，一位评审据此判 L0（另一位未测，见 6.3 校准备注）。
- 回炉：《书》11.4、9.1、7.5、8.3（原因不要遮住结果）。

**画框与连续类**

**镜 B-05 事件进行中焦点被甩出画** [通]
- 阈值：一个事件进行中（从原因开始，到结果落定后的出点保护结束），事件主体或结果的**识别部分**有任何一帧落在画框外，未过。识别部分 = 观众靠它认出"是什么、发生了什么"的部分：须读字、可操作的控件和它的目标、结果、带信息的边缘（图表轴端、一段文字的最后一个字、决定物体是什么的那段轮廓）。
- 不算：主体以一个完成的动作离开画框（《书》7.2 主动离场）；有意的大主体出画（《书》15.2），被裁掉的只是观众猜得出的部分（重复、对称、熟悉形状、填充物）。判据：被裁掉的那部分，观众能不能准确说出它是什么样。
- 测量：逐帧跟踪主体包围盒与画框求交（有工程时读坐标；无工程时联系表加 0.1 s 步长抽帧，人工逐帧看）。
- 依据：《书》14.3 三条前提之三（主体不出画，"这项常被其他检查漏掉"）、15.2 不可裁清单、13.7（连续世界中主体被甩出画外）。静止状态下的裁切归共用 S-05（视觉标准 B-05）；本条管运动和相机造成的出画。
- 回炉：《书》14.3、14.2（素材自身在动时相机让位）、15.2、13.4。

**镜 B-06 循环接缝跳变** [循环]
- 指标：把末尾几帧和开头几帧拼成一条连续帧带，逐元素算跨接缝的位置和速度变化（《书》7.3 接缝检查法）。先按镜 T-03 去掉重复帧。
- 阈值：接缝处任一可见元素位置跳变 > 1 px，或速度变化 > 15%，而画面里没有让它回来的可见原因，未过。有可见原因的跳变（遮挡物经过、一个事件把它带回、全屏的光——《书》7.3"给它原因"）不算；但遮挡露缝按镜 B-12，用光遮挡要过共用 S-03。
- 测量：跨接缝逐元素光流或包围盒位移；分不出元素时，先用首帧与末帧的差分图找跳变区域，再交人工。
- 依据：《书》7.3、7.6〔测〕。1 px 为《书》圆环式、流动式的接缝要求；15% 取速度辨别韦伯分数一到二成的中间，弱证据，**待实验**。两轮盲测：一位评审把两件作品"首尾不接"判为该维度 L0，另一位没有单独测接缝（见 6.3），说明本条必须测，不能靠看一遍。
- 回炉：《书》7.3。

**镜 B-12 边界穿帮** [通]
- 阈值：转场或切点前后出现以下任一，未过：① 非设计的空白帧（整帧无内容或只剩底色，且不是作品其他地方也在用的、有意的黑场或白场）；② 用来藏切点的遮挡没有完全覆盖，露出了正在被替换的画面；③ 切点处已退场的元素残留一两帧，或下一镜的元素提前一两帧出现在上一镜里。
- 测量：每个切点 ±10 帧逐帧看；软转场取过渡区间起、中、止三帧和最糊的一帧；遮挡转场逐帧检查遮挡物边缘外是否有变化像素。
- 依据：《书》13.3（"转场里不许出现空白帧"；"必须真的完全覆盖，露缝即穿帮"）、13.7。与动效标准 B-10（边界穿帮）、B-19（非设计黑闪）是同一件事，两份同评时只测一次、记在动效编号下；只评本标准时记在本编号下。
- 回炉：《书》13.3、13.2（不该承接时直接切）。
（编号说明：本条放在这一组里读，编号排在最后，是为了让 B-07～B-11 与第 7 节自动项一一对应。）

**声画类**

**镜 B-07 声画同步** [有声]（= 声 B-07）
- 指标：应当"同一时刻"的声画事件——可见发声（嘴、撞击、按键、落地）、音效对应的画面落点、口播锚定的画面事件（说到某词时对应元素出现、高亮、变化）——声音相对画面的时间差。
- 阈值：门限、有意"声音先行"的例外和"像没对齐"区间，一律按声音标准声 B-07（共用条目持有方），本标准不另设数。本领域的读法：口播锚定的画面事件（说到某词时对应元素出现、高亮、变化）按**词起点**测，阈值同声 B-07（《书》4.3）。
- 测量：音频瞬态检测或稿件强制对齐得到词起点；画面事件帧取差分突变帧或元素出现帧。
- 依据：声 B-07；《书》E1、4.3（声音先行的 L，《书》18.2 X5）。与动效标准 B-22、B-23 是同一件事，同评时只测一次、记在声 B-07 下；口播锚定的画面事件，动效标准只管到"晚于对应句结束"（动效 B-24），按词起点的测法记在本编号下。
- 说明：《书》16.4 的落点窗口（30 fps：词起点前 2 帧到前 0 帧；60 fps：前 6 帧到后 1 帧）在本条阈值上各扣了一帧抖动余量，是制作容差，不是观众门限；超出窗口的锚点数只作第 7.2 节 M-12 证据。
- 回炉：《书》16.4、4.3、5.4（取整只做一次，与声音相关的画面事件向早取整）。

**讲解与取景类**

**镜 B-08 标注指错** [讲解]
- 阈值：一个标注（圈、框、箭头、指示线、高亮、光标停靠）在它可读的任一帧上没有落在它说的目标上，未过：目标的识别部分不在圈框内；箭头或指示线的延长线不经过目标；高亮落在相邻一项上；内容滚动或移动之后标注留在原地（该钉在内容坐标上却钉在了屏幕坐标上）。
- 测量：脚本候选——标注中心与目标中心的偏差 > 镜 B-09 换算出的最小必读高度，或目标包围盒与标注区域交集为 0；最终由人工判：单独给测试者看该帧，问"标注指的是哪一个"，指到别的东西即未过。
- 依据：《书》16.2（先认出参照系 → 再指 → 再说指的是什么）、16.3（标注按所指选坐标，"标注位置从素材实测，不目测"）、16.7（标注圈偏；页面滚了标注没动）、16.8〔测〕（偏差起点 ≤ 最小必读高度，**待实验**）。
- 回炉：《书》16.2、16.3。

**镜 B-09 必读细节的到达视角** [通]（文字部分 = 视觉 B-01）
- 指标：流读文字，以及看不清就读不懂事件的最小细节（按钮上的字、表情、指针、刻度、结果上的数字），在目标显示上的到达物理高度；倾斜、仰俯机位按压缩后算（乘倾角余弦）。
- 阈值：流读文字按视觉标准 B-01（底线、"偏小"档、目标值与按画幅和观看距离的换算算法，都以该条为准），本标准不另设数。看不清就读不懂事件的非文字细节，按视觉 B-01 换算算法里的同一视角和同一档位判，以细节的识别高度代替字高。停读文字和纹理不适用本条，按共用 S-09（视觉标准 B-01）。
- 测量：OCR 包围框取字高（中文取墨迹框高、纯拉丁或数字行取大写或数字高 ÷ 0.8，与视觉标准 B-01 同法）；非文字细节人工框出；动态作品取它需要被读的那段时间里最小的一帧。
- 依据：《书》15.1（细节可辨认的视角）、15.2（细节决定尺度）、15.6〔测〕；视角推导已并入视觉 B-01 的换算算法（2026-11-20 共用条目对齐），**待实验**。
- 与视觉标准 B-01 的关系：同一件事。两份同评时只测一次，记在视觉 B-01 下。
- 回炉：《书》15.1、15.2；排不下时的顺序按视觉标准 B-01 的回炉（删字 → 降为停读 → 拆到下一镜 → 最后才缩字）；镜头内放不下时按《书》9.2 删事项、11.2 减组。

**镜 B-10 左右安全距离** [通；竖屏手机作品必测]
- 阈值：须读文字和必读元素离左右边的距离按视觉标准 B-06（侧边距与平台裁切量取较大者，以该条为准），本标准不另设数。上下边按平台界面遮挡区实测，归共用 S-06。
- 测量：量文字和必读元素包围框到左右边的距离；平台裁切量的算法同视觉标准 B-05、B-06。
- 依据：《书》15.1（手机圆角、手指与保护壳遮挡；推导已并入视觉 B-06，2026-11-20 共用条目对齐）。
- 与视觉标准 B-06 的关系：同一件事。两份同评时只测一次，记在视觉 B-06 下。
- 回炉：《书》15.1、15.2（竖屏：主体重心在上半到中部）。

**镜 B-11 钩子字一瞥可读** [信息流，且开场由文字承担钩子]
- 指标：第一眼窗口（0.75 s）里承担钩子的那行字的到达物理字高。哪行是钩子以评审卡为准；卡上没写时，取 0.75 s 内最大的那行须读字。
- 阈值：< 4 mm，未过（一瞥可读约 0.7°，手机 30–35 cm）。竖屏手机满屏时即 W/15（1080 宽 72 px）——按最窄屏 62 mm 推出，68 mm 屏上约 4.5 mm。横屏在手机上横放时，以长边毫米数按同法重算。
- 对比度：按共用 S-08（视觉标准 B-03，WCAG 原文）。钩子字在常见手机上属于大号字，底线按视觉 B-03 的大号字档；《书》6.2 对钩子字更严的要求只作镜 D2 的证据。
- 依据：《书》6.2 钩子字的大小、附录 E-1 复算；弱证据，**待实验**。钩子由画面或声音承担时（《书》6.2 其他取向）本条 n/a。
- 回炉：《书》6.2、6.1。

## 3. 上限维度

每个维度：判断问题 → L1～L4 看到什么 → 典型 AI 低级感 → 回炉。级别描述只写现象，不写手法；《书》里每一章的任何取向（有峰或无峰、硬切或承接、相机动或不动、有字或无字、真冻结或微动、单焦点或满屏探索、闭合或不闭合）都可以到 L4。故事结构、转折、钩子、节奏起伏这些靠人判断的维度，评审要回答判断问题并给出时间码证据，不靠数字定级；第 7.2 节的测量数据只用来找证据、指位置。

**低级感清单的用法**（与视觉标准同一口径）：每条命中标"局部"（一处，或累计 ≤ 1/3 片长）或"贯穿"（> 1/3）。能从片子里看出它是从这件内容推出来的（例如题材本身就是监控画面，所以全片等长镜头），不计，并在证据里写明。判 L2 须同时满足：该维度无贯穿命中；局部命中 ≤ 2；能写出 ≥ 2 条带时间码证据的 L2 现象。任一不满足，该维度 ≤ L1。

### 镜 D1 故事与状态差 [通]

**判断问题**：首帧和末帧并排给没看过的人，他能一句话说出"什么变成了什么"吗？每一镜写得出"某物 + 做了什么 + 结果"吗？状态差挂在什么上——一个东西、两者的关系、一群东西的排列、环境本身，还是观众的理解？片里被特意强调过的东西，后来用到了吗？没有故事的片（氛围、陈列）靠什么维持注意：有没有一个一路朝一个方向变的可见量，和间隔不均匀的微事件？

| 级别 | 看到什么 |
|---|---|
| L1 | 说得出"讲的是什么"（品类），说不出"什么变了"；多数镜头是"展示""呈现"，有运动没有状态差，像屏保；强调过的东西没下文；角色站着微笑、界面自己在变 |
| L2 | 首末帧测试通过；每一镜有事件；预期、阻力、代价、见证者这些放大器用得和片长相称；被强调的都兑现了 |
| L3 | 状态差的主语和展开方式属于这件内容，换一个对象这个故事就不成立；回看时线索一直都在；变化本身就是要讲的结论 |
| L4 | 观众自己"看出来"了变化，并在最后一刻重新理解了前面的一切；会把这个变化讲给别人 |

**典型 AI 低级感**：只有情绪形容词（"展现温暖""体现专业"）没有状态差；没有天然主角的内容硬造一个"想要什么"的角色；"痛点 → 三个卖点 → 品牌"三段拼接，没有一个东西从头变到尾；两个包袱相邻，第二个吃掉第一个的确认时间；讲解中插笑点打断论证。

**回炉**：《书》第 3 章（3.1 最小单位、3.2–3.6 五种取向、3.7 笑点）、第 8 章（事件与主语）、18.1 C1（无故事片）、18.3 D1（情节类型）。

### 镜 D2 开场与代表帧 [通]

**判断问题**：静音、只看前 0.75 s，说得出这支片要给我什么吗？第一眼抓住的是一个主体，还是一团？观众为什么会留下——留着没解开的那个问题是什么，他能估出要等多久吗？解开之后有没有接上下一个问题？代表帧单独给没看过的人，"这里发生了什么"的回答和核心一句话一致吗？封面的主物与主动作和代表帧一致吗？

| 级别 | 看到什么 |
|---|---|
| L1 | 开场是标题页、居中问句或标志淡入，前 0.75 s 没有一个在动的具体物；首帧里几个主体同时抢第一眼；静音时开场说不清；代表帧是过程中途，或只是一张"好看"的图，复述不出发生了什么 |
| L2 | 第一眼一件事；留着的问题清楚；静音能懂；代表帧测试通过；封面与代表帧一致 |
| L3 | 开场的问题从这件内容里长出来，换题就不成立；等待长短与解开的时机配得上；代表帧本身就是这支片的"那一下" |
| L4 | 开场让人停住，回看时发现它已经埋下了全片的答案；代表帧会被单独截下转发 |

**典型 AI 低级感**：前 2–3 s 只有标题；"你是否也……"式痛点问句开场；静音平台上靠声音开场；入场一个个淡入、0.5 s 后才有完整画面（未到镜 B-01 的轻度）；悬空动作落地后没有第二个未解开的东西，观众在落地那一刻走掉。

**回炉**：《书》第 6 章（6.1 第一眼容量、6.2 六种开场、6.3 代表帧）、3.4（看法翻了）。

### 镜 D3 能量弧：峰值与转折 [通]

**判断问题**：全片一直守着哪些范围（尺度、速度、数量、声音的厚度、视点、被揭示的程度、颜色）？峰值处突破了其中哪一个、朝哪个方向（最多还是只剩一个，最厚还是全空，最近还是最远）？这个维度在峰值之前有没有已经被突破过？峰值的位置能说出理由吗（余波倒算、尽早、峰即终点、多次释放）？每次转折打破的是"接下来是什么"还是"什么时候来"，观众有没有被预告？落点那一刻是一个通道在承担、其余让开，还是所有通道同时在高位？有几次大转折，观众分得出哪一次是"那一次"吗？选了无峰时，有没有一个让人感到"到了"的转向点？

| 级别 | 看到什么 |
|---|---|
| L1 | 曲线平或锯齿，处处同一强度；或峰值提前花掉，后面再无更大的；转折靠所有通道一起加大（闪白、震动、音效、大字同时来）；无意地把每个接缝都做成转折 |
| L2 | 认得出一个峰（或一个有意的无峰加转向点）；转折之前有预期，之后有读完后果的时间；落点那一刻只有一个通道在高位 |
| L3 | 被突破的那个量和情绪变化之间有因果关系，不是外加的；转折的形状（预告后换、突袭、不按时、提前落）和内容咬合；多次转折的幅度分得出级 |
| L4 | 峰值或转折的方式出乎意料又只能如此，成为全片被记住的那一下 |

**典型 AI 低级感**：结尾标志出现就算"峰"；中段一次全屏闪白当高潮；每一段同样力度的"砸"；"钩子 → 升级 → 后段高潮 → 定格"的标准弧，而峰值突破的是哪个维度说不出；同一种承担者（一记重音效、一次推近）连用三次以上。

**回炉**：《书》第 4 章（4.1 可见量、4.2 峰值、4.3 转折与上限）、18.1 C2（氛围片的转向点）、C4。

### 镜 D4 节奏、镜长与静止 [通]

**判断问题**：把全片的夺眼（让视线重新落脚、或让注意重新收紧的变化）按时间列出来，间隔序列有形状吗？形状是从内容来的（一句话说完、问题被答上、乐句收住、过程到终点），还是从时钟来的？画面里动的东西多而夺眼少吗？每一次夺眼带来了什么？静止的时候，观众知道自己在等什么、在看什么吗？必须看懂的地方停得够、不必要的地方不拖吗？镜头的收尾方式有没有变化？

| 级别 | 看到什么 |
|---|---|
| L1 | 等间隔，每隔一会儿换一次，像计时器；全程一个转速、一个推速；夺眼几乎都是装饰性运动；静止像死机，或者处处在微微呼吸、没有真休息；开头空等 |
| L2 | 间隔有长有短，长短跟着内容；至少一处可感的收紧、至少一处喘息（选了单调渐变的，那条单向变化清楚可感）；静止都是"在等什么"或"让它落地"；镜长和要读的量相称 |
| L3 | 快慢本身在讲这件事的形状；静止和密集互相衬托；镜头的收尾方式也在轮换 |
| L4 | 某一处的快慢或停顿成为全片最被记住的时刻 |

**典型 AI 低级感**：无理由的全片等长段落；一句一个元素的等拍出现；光晕脉动、扫光、背景漂浮让口播片发抖；每镜都淡出收尾；为凑时长拉开句间停顿；作者看多了嫌慢而整体提速，最后几件挤在一起（未到镜 B-03 的轻度）。两轮盲测里，创意到位的作品最常丢的就是这一项（"全程匀速""开头 2–3 s 静止、事件等间隔"）。

**回炉**：《书》第 9 章（读取时长与四种镜长取向）、第 10 章（10.1 夺眼、10.2 五种节奏与布局大变化、10.3 静止）、5.3（主轴）、18.1 C7、C8。

### 镜 D5 结尾与循环 [通；循环作品另看接缝]

**判断问题**：观众在哪一刻确信"后面没有了"？这份把握来自哪里——结构对称、账清了、发动机停了、装进一句话、约定的终止信号，还是有意不闭合（问题在片中被清楚建立过吗）？片里开过的每一个"等着看"都有下文吗？停住的画面看得出"停是有意的"吗（最后一个运动自己减速到零、声音余响还在走、有东西离开或熄灭）？结尾落在对象身上，还是一张换题也能用的卡？循环作品：接缝处观众会不会认出"倒带"——辨识度最高的那个元素在一个循环里被看到几次？

| 级别 | 看到什么 |
|---|---|
| L1 | 结尾是居中金句加标志，与片子内容无关；最后一个运动被半路截停，像卡住；欠着的期待没下文；或拖尾——讲完后还在空转；循环片在接缝处像倒带 |
| L2 | 闭合的来源清楚；最后一个理解单元有时间落地；停留有"有意"的证据；结尾落在对象上 |
| L3 | 结尾与开头构成一次"认出同一个、比出不一样"，或最早开出的期待在最后兑现；那句话（若有）是论证的结论而不是口号；循环无缝而且有理由 |
| L4 | 结尾让人想回头重看；或循环本身成为内容的一部分（转一圈就是意义） |

**典型 AI 低级感**：口号式结尾句卡；标志从小飞到居中；借来的终止信号用得太显眼（模板式黑场落款）；最后 1 s 塞进三行字（未到 S-01 的轻度）；循环片首尾两个不同形状硬接。两轮盲测：做出了专属画面的几件作品，结尾都没有落到对象（名称、标志）上。

**回炉**：《书》第 7 章（7.1 闭合的五种来源、7.2 六种结尾与结尾停留、7.3 循环接缝）。

### 镜 D6 镜内注意与因果 [通]

**判断问题**：每一刻该看哪里，一眼知道吗？同时在动的有几组，它们是一起服务焦点，还是在抢？冻结测试：把某个动作冻住重看，观众失去了什么必须知道的东西吗？每个变化问一句"谁做的"，答得出画面里的某个东西吗？原因是不是先于结果出现、并在结果发生前停稳？新元素挂在论点的开头进场，还是一句一个往上堆？说到后面，满屏静物有没有人退场？字幕有没有早于它描述的画面事件消失、把眼睛先带走？

| 级别 | 看到什么 |
|---|---|
| L1 | 满屏同时弹入；元素一句一个堆积，后面无人退场；界面自己在变、没有触发者；原因与结果同时发生，观众只看到一个；聚光圈、高亮框冒充"谁做的"；背景比主体热闹 |
| L2 | 焦点清楚、交接干净，旧焦点退到一边不抢；每个变化有看得见的原因；进场挂在论点或上一步的完成上 |
| L3 | 视线被带着走，原因自然把眼睛引向结果；画面的单位和论证的单位对得上，观众几乎不用找 |
| L4 | 一镜之内的注意调度本身成为享受：眼睛被精确地带到答案出现的地方 |

多焦点对照、群体当一块、满屏探索都可以到 L3，只要入口清楚、观众知道从哪看起（《书》11.2）。

**典型 AI 低级感**：每张卡片同一条曲线依次上浮淡入；数字滚动、图标弹跳、背景粒子同时进行；"展示 / 呈现"式镜头；结果出现时手或光标还在动；结果卡先空着出现再填内容（未到 S-07 的轻度）。

**回炉**：《书》第 11 章（11.1 三种角色与冻结测试、11.2 预算、11.3 进场、11.4 离场）、第 8 章 8.3（原因）、17.4（附属元素怎么到达）。

### 镜 D7 边界、转场与空间 [通]

**判断问题**：每个边界，观众感到的是"继续"还是"换了"？作品想要的是哪一个？要继续时，观众凭什么在两侧认出"同一个"——同一个物、同一个运动、同一个形状、一个后果，还是同一个声音？要换时，换本身有意义吗？强烈的转场用在全片最大的边界、或物理含义与内容含义对得上的地方了吗？想藏住的切点藏住了，想标出的切点标出了吗？换空间的频率和每个想法分到的时间相称吗，观众来得及重新定位吗？连续空间里，相邻一站的字有没有半读得出、把眼睛拉走？屏幕方向一致吗，翻转时有可见的理由吗？

| 级别 | 看到什么 |
|---|---|
| L1 | 每个接缝都是同一种通用淡化或推拉；或者手法轮番上，读作炫技；一个接缝叠好几种手法；很短的想法也换新空间，观众一直在找；左右反复越轴 |
| L2 | 每个边界都说得出理由；硬切和承接各在该在的地方；转场不挤占读取时间；空间组织让人不迷路 |
| L3 | 承接物在边界两侧换了角色（上一镜的东西成了这一镜的舞台），读来是一件连续的事；转场的物理含义与内容含义一致 |
| L4 | 某个边界的处理成为全片的签名，观众记得"从那里是怎么到这里的" |

**典型 AI 低级感**：每个切点都用同一个无含义的缩放或滑动；闪白、震动、呼啸音效叠在一起；为了"不像幻灯片"每镜都硬加承接，追踪得累；几个小碎片一起跨边界，没人读得出是承接。

**回炉**：《书》第 13 章（13.2 承接、13.3 转场、13.4 一镜到底、13.5 多场景与屏幕方向）、5.1–5.2（重定位成本与换不换空间）。

### 镜 D8 全片轮换与"不像幻灯片" [多镜作品]

**判断问题**：把每镜的中间帧排成一排打乱，没看过的人排得回去吗？排布（主物位置、尺度、画面分区）的变化跟着内容关系走，还是复印同一个骨架，或者随机换？只看身份层（缩小模糊到只剩材料和颜色），这一排像一个系列吗？观众若说"像 PPT"，最像的是哪一刻：整页被替换、外部触发且间隔均匀、页框固定、东西加上去就不再变、讲的人在页外、画面只有字和示意图——作品对每一条做了什么？

| 级别 | 看到什么 |
|---|---|
| L1 | 连续多镜同一个骨架（"标题 + 三卡"，"人物在角落、素材在中间、文字在一侧"）；或者每镜换一种画风，像拼起来的；六个成分全部在场，看不出是有意的 |
| L2 | 排布随内容关系变，观众知道自己在哪；身份统一；"像幻灯片"的成分要么去掉了，要么看得出保留它的理由 |
| L3 | 排布与关系绑定，观众学会"这种排布意味着这种关系"后读得更快；或一个母题在内部持续变化；变化的幅度分级，重的地方才大变 |
| L4 | 某一次排布或观看方式的变化成为全片最被记住的时刻，前面的统一都在为它铺垫 |

有意做成幻灯片（《书》12.5 的戏仿）按效果评：做得比真幻灯片更"标准"、观众读得出是故意的，可以到 L3。单镜到底的作品本维度只评身份层与观看层，排布部分 n/a。

**典型 AI 低级感**：01 / 02 / 03 编号段落；每段"眉标 + 标题 + 变色词"；左字右图连做三段；同一个缓推贯穿全片。

**回炉**：《书》第 12 章（12.2 三层与三种检查、12.3 六个成分、12.4 对症治法与偏统一或偏变化的四条件）、18.3 D4（景别）。

### 镜 D9 相机与取景 [通；相机全片不动时只评取景]

**判断问题**：每一次相机运动，把相机锁死重看，观众失去了什么（看不清、不知道两者的关系、跟丢主体）？什么都没失去的运动还在吗？揭示和读字的时刻相机停稳了吗？有没有推近后立刻拉回、同向同类运动无理由地连着来？画框若在"代表一个人"，观众读得出他的心（在看谁、预判了什么、在意构图）和身体（有重量、站在人能到的地方）吗，这和片子要的掌镜者一致吗？取景装得下当前这个关系的全部参与者吗？主体的大小是由必须看清的细节和这一刻要的感受定的，还是随手的？

| 级别 | 看到什么 |
|---|---|
| L1 | 每镜匀速慢推；念到一个名词就推一次；推近马上拉回，像晃了一下；停留时还在漂；想表达人的情绪，掌镜却像轨道；关系的一方在画外；倾斜机位把必读的东西压扁（未到镜 B-09 的轻度） |
| L2 | 每一次运动都说得出锁机后会失去什么；读的时候稳，换的时候带；取景按关系选档，主体大小说得出理由 |
| L3 | 相机的距离、高度、陪不陪主体在承载情绪，并和峰值同一个维度、同一个方向；掌镜者有性格 |
| L4 | 一次相机动作成为全片的重音，事后觉得只能这样看 |

"不动相机""只在边界动""相机即叙述者"都可以到 L3。

**典型 AI 低级感**：无理由的环绕；全片同一缓推；周期性的正弦漂浮当"手持感"；空背景上运镜（没有参照，看不出在动）；每个拍点整画面震一下。

**回炉**：《书》第 14 章（14.2 锁机对照与密度、14.3 掌镜感、14.4 拍点承载、14.5 情绪）、第 15 章 15.1–15.2（取景与主体大小）、18.3 D3（真人出镜）、D4（景别）。

### 镜 D10 讲解、证据与演示 [讲解]

**判断问题**：每一段，观众在脑子里搭的是什么（先后、依赖、多少、组成、归类、真假）？画法和它同构吗？画面里有没有一个没打算用的性质（出场先后、同框、同色、面积）让观众搭出了错的结构？证据位上是真截图、照片、录像，还是"像截图的东西"？口播要观众的眼睛做什么（找、比、跟、停、量、回看），画面让眼睛做到了吗？画面有没有说出口播没说的那一半——静音看得到一部分、闭眼听也只得到一部分？术语是在名字和概念同时在场时挂上的吗？界面演示打消了观众心里最可能的那个怀疑吗？

| 级别 | 看到什么 |
|---|---|
| L1 | 画面是口播的插图，闭眼听就够；示意图坐在证据位上；同一段混用两套读法；截图贴在屏幕上不动；一句一个关键词飞入；演示只是把流程播一遍，没打消任何怀疑 |
| L2 | 每段的语法清楚；证据位用真东西；先认出参照系再指；口播和画面各管一半；术语挂得上 |
| L3 | 画面自己把关系讲清楚，观众是"看见"而不是"读到"；演示的故事形状正对一个怀疑；数据的形状就是结论 |
| L4 | 观众看完能自己画出那个关系、讲给别人 |

**典型 AI 低级感**：手画浏览器栏冒充截图；"三步走"编号卡；图标 + 两行字的卖点卡连三张；为了讲更多塞进第二台设备；光标直线匀速移动、不停靠、不换形；示意图带照片质感（若因此改变观众带走的结论，按 S-11 判 L0）。

**回炉**：《书》第 16 章（16.2 解释语法、16.3 证据拍法、16.4 对齐、16.5 术语）、17.4（界面演示）、15.3（意思靠画面还是文字）、18.1 C18–C20。

### 镜 D11 表演 [角色]

**判断问题**：情绪由至少两个通道（姿态、节奏、趋避、脸、声音）一起说吗？情绪切换时，看得到"旧状态被打断"和"新状态停住"两处吗？"在想"看得见吗（刺激和反应之间那段延迟）？眼睛（或物的朝向）先到、身体后动吗？左右肢、群体有错相吗？缩到手机小窗里，姿态变化还认得出吗？角色的精细度够得上它承担的表演，还是粗到让人一眼归为生成内容？字和表演是在说同一件事（字替观众读完了），还是各补对方给不出的？

| 级别 | 看到什么 |
|---|---|
| L1 | 一帧瞬切换表情，像换贴图；双臂镜像、群体同步；圆头大眼讲解员；举牌写情绪；字幕把表演正在演的情绪念了一遍 |
| L2 | 情绪读得出，切换干净，错相自然；字只补表演给不出的东西（名字、数字、时间、出处） |
| L3 | 观众自己从身体（或物的趋避）里读出情绪；一处思考的延迟或一次退缩让人记住 |
| L4 | 一个没有台词的反应成为全片被转发的那一下 |

画不到位时退到局部角色、物即角色或无角色，是《书》17.3 的正当做法，按效果评，不扣分。

**典型 AI 低级感**：所有部件同时、同曲线、同幅度运动；反应不停留；没有天然主角的内容硬造角色；物被加上一张脸。

**回炉**：《书》第 17 章 17.1–17.3、15.3（文字与表演）、3.7（见证者确认）。

### 镜 D12 创意与新鲜度 [通]（单独打分）

**判断问题**：这支片的展开方式有没有一个想法？这个想法属于这件内容，还是属于品类？观众会在哪一层认出"又是那一套"——**物**（最后变成了什么）、**序**（事情按什么规则展开）、**调**（谁在对谁说、什么姿态）、**形**（外观和运动手法）？它在哪一层离开了最常见的那个值？它是不是"不费力就会做成的那个样子"，或者是排除了第一层默认之后人人都会落到的"聪明的第二选择"？

**三个测试**（评审执行，结果写进证据）
- **代入测试**：把最近的同类对象代进这支片的展开（开场 → 转折 → 结尾），几乎不用改 → 本维度最高 L2（《书》1.2 物层：雷同最先在终态上被认出）。
- **结构同构检查**：把这支片和一支已知的片（或同批另一件）都抽象成"每镜的物 + 动作"一列文字，对应行有一半以上可以互换而不改意思 → 结构同构，本维度最高 L1，注明对照对象（《书》2.4 抄袭边界的可操作判据，「待实验验证」）。
- **同批差异**：同一批独立作品两两跑《书》1.3 的三项——复述重合（共有实词 ÷ 较短一段的实词数 > 1/3）、画面错认（各取 5 张等距截帧打乱分堆，分错 ≥ 2 张）、时间感（最大变化发生的位置相差 < 15 个百分点、且靠同一种手段）。三中二 → 记"同批结构撞车"，进入下面第二层默认识别的第 2 条。三项阈值为《书》的推演，**待实验**。

| 级别 | 看到什么 |
|---|---|
| L1 | 一眼是模板或机器的默认骨架；或与已知片结构同构；或命中贯穿的第一层默认（D1～D11 各清单里的那些） |
| L2 | 没有明显默认味，看得出做过选择；但展开方式是这一类片常见的那几种之一，或命中第二层默认 |
| L3 | 展开方式少见而且成立：观众预料不到，它又明显属于这个对象，换成同类另一个对象就不成立 |
| L4 | 展开方式本身让人惊讶，第一次见到这样讲这件事，又觉得再合适不过；可以成为别人的参照 |

**第二层默认（命中只扣本维度，不判错）**
- 定义：排除了第一层默认之后，模型稳定落到的同一批"聪明的第二选择"。它们不是错，单独看可能做得好，问题是**不新鲜**：在同一批独立作品里反复出现。
- 识别方式，两条任一成立即算命中：
  1. 落在第二层默认登记表的"叙事层"一节里（五份标准共用一张：`standards/第二层默认登记表.md`；随评审数据增补）。本标准的初始条目来自两轮盲测里青出组作品之间的撞车，在登记表正式收录前照此识别：
     - **逐个单位累积的讲解骨架**：先慢讲第一个单位的增量，再一行一行加速倍增，最后停在整体形状上（同批三件连开场、配色逻辑、节奏走向都相同）。
     - **实物载体的"写满 → 清空 → 重来"**：一个日常实物（纸、票据、本子）被一行行吐出或写满，满了被撕下、抽走，新一轮重新开始（两轮里不同题目反复落到"票据 / 账页当载体"）。
  2. 同一批独立作品里，有 ≥ 2 件和它"同批结构撞车"（上面的同批差异测试），或在三层印象（标志层、一瞥层、结构层）上被并排分组测试分进同一组。
- 处理：命中时本维度最高 L2；能写出它在这件作品里多走了的那一步（使它只属于这件内容），且两位评审都认可时，可到 L3，并把这一步写进证据。
- 不得因为命中第二层默认而降低镜 D13 或任何其他维度，也不进 B 层。
- 登记表是评审工具；做作品的人能不能看、怎么用，由框架流程决定，本标准不规定。登记表一旦被当成禁用清单，新的重复会出现在别处，所以第 2 条"同批撞车"始终要做，不能只查表。

**回炉**：《书》第 1 章（1.2 按"物、序、调、形"四层放开方向、1.3 和上一支片比）、第 2 章（参考片：学手法、原创借形、反着学）、18.3 D1（情节类型）、D6（系列化：母题同、结构异）。

### 镜 D13 执行与完成度 [通]（单独打分）

**判断问题**：时间上的每一处是"决定过的"，还是"差一点"？画面落点和词、和拍对得上吗？出点、开镜、字和画的收尾留够了吗？承接物在边界两侧的位置、方向、速度连贯吗？遮挡、接缝干净吗？光标、手、角色的每一次移动都有目标吗？同一类事件用同一种做法吗？计数、数值、口播、上屏四者一致吗？后半段和前半段一样细吗？

| 级别 | 看到什么 |
|---|---|
| L1 | 能交差但粗：落点普遍晚一点；承接物两侧错开几像素；转场多一帧脏帧；计数与数值短暂对不上；光标漂移；同类事件做法不一；明显只打磨了开头 |
| L2 | 时间上干净：落点都在窗口内，出点留够，接缝连贯，没有看得出的事故帧；前后一样细 |
| L3 | 逐帧看仍精确：每个承接、每个落点、每个停稳都像被单独打磨过 |
| L4 | 精度本身被观众感到："这是怎么对得这么准的"；细处有第二遍才发现的完成 |

**典型 AI 低级感**：手敲秒数造成的系统性晚一点；打完时间戳后又剪了音频，后半段全体错位；页面滚了标注没跟（若指错按镜 B-08 判 L0）；同一道具两场画得不一样；接缝处的空白比平均事件间隔还长。

**与镜 D12 分开看**：两轮盲测里，两位评审一致发现框架组把创意分抬高了约 1.3 分（5 分制），执行分没有提高、甚至略低，L0 全部来自可修的执行失误。评审必须分别给镜 D12、镜 D13 级别，并在报告抬头并列；不得因为其中一项高而拉高另一项。

**回炉**：《书》5.4（时间表：离实测锚点一层、取整只做一次）、16.4（口播对齐流程与机器对账）、11.4（出点与开镜）、7.3（接缝检查法）、13.5（多场景一致性）、14.3（三条前提）、17.4（光标是一个人的意图）。

## 4. 判级规则

### 4.1 判级顺序

1. 静音全速看一遍，写下记住的画面（≤ 3 条）、一句话复述、"它在什么时候变了"，封存；有声时再看一遍补写（1.5 节）。
2. 跑 T 层（第 7 节自动项）。未过项列入"交付未过"，附修复方法；不中断评审。
3. 跑 B 层：本标准 B-01～B-12，加共用 S-01～S-11。任一未过 → 整件 **L0**；列出全部未过项及证据（时间码、测量值、测试者原话）；维度照评，写成"修好后的上限"。
4. 逐维度定级（L1～L4、n/a 或未评），每级附时间码证据；按第 3 节开头的计数口径判 L2。靠人判断的维度（D1～D5、D12）先回答判断问题，再定级。
5. 按 4.2 合成整件级别。
6. L3、L4 候选做两两比较（4.3）；标杆不足时停在"候选"，按 L2 合成。
7. 有前一版本时，输出维度差分表（4.5）。
8. 评审结束后打开评审卡的有意说明，只用来解释第 7.2 节 M 项测量数据，不改级别。

### 4.2 合成

| 整件级别 | 条件（全部满足） |
|---|---|
| L0 | 任一 B 层（含共用 S）未过 |
| L1 | B 层全过，但不满足 L2 |
| L2 | 全部适用维度 ≥ L2；镜 D12 可以是 L1 |
| L3 | 全部适用维度 ≥ L2；镜 D12 ≥ L3；镜 D1 ≥ L3；L3 及以上的维度 ≥ 适用维度数的一半；两两比较确认 |
| L4 | 满足 L3；镜 D12 = L4，且另有至少 1 个维度 L4；两两比较确认；用户本人确认"惊艳"。缺用户确认时记"L4 候选" |

**短板与封顶**（优先于任何平均印象）
- 镜 D1 为 L1 → 整件最高 L1：说不出"什么变成了什么"的片子不是商业合格（无故事的氛围片按 D1 判断问题里的"一路在变的可见量 + 微事件"评，不因没有角色或冲突落到 L1）。
- 镜 D12 为 L1 → 整件最高 L2，且不进 L3 候选。
- 代表帧测试未过（镜 D2 判断问题，回答与核心一句话不一致）→ 整件最高 L2（《书》6.3：找不到能过测试的帧，说明想法还没落到画面上）。
- 除 D12 在 L1 时的豁免外，整件级别不高于"最低适用维度 + 1"。
- T 层不进合成，只在抬头单列。

**报告抬头必须并列四件事**：交付层状态（通过 / 未过：可自动修复 / 未过：需回工程）；观众层状态（通过 / 未过：列 ID / 通过（某某未测））；整件级别；**创意与新鲜度（镜 D12）和执行与完成度（镜 D13）各自的级别**。例："整件 L0（修好后上限 L2）｜观众层未过 镜 B-04｜交付未过：镜 T-03 可自动修复｜D12 L3 / D13 L1"。

### 4.3 两两比较

- 一次只比两件、一次只问一个维度："在镜 Dx 上哪一件更好？证据在哪个时间码？"对标杆的盲比必须二选一，不允许"差不多"。
- L3 候选对照 3 件 L3 标杆，胜 ≥ 2/3 确认；L4 候选对照 3 件 L3 标杆全胜，并对 L4 标杆不输。
- 对照从同片种（讲解、故事、展示、演示、氛围、开场）、同平台条件（信息流 / 专注观看、是否循环）里取。
- 两名评审差一级取低者；差两级及以上，加第三名评审，取中位。

### 4.4 某个维度或某条底线无法评

- 评不了的维度写"未评"，并写原因（例如"只拿到联系表，看不到时间过程""评审听不了声音，D10 的口播部分无法评""没有角色"写 n/a 而不是未评）。不估级。
- 未评维度不限制上限，整件写成"≤X（待镜 Dn 补评）"；未评的是 D1 或 D12 时，不得给出 L3 及以上的结论，只能写"L3 候选（待补评）"。
- 听不了声音时：镜 B-07、镜 T-02 写"未测"；D3（声音承担的转折）、D4（以音乐为主轴的段落）、D7（声音承接与声音转场）只按画面评，并在证据里注明"仅画面"；不得因听不到而把声音承担的转折判成"没有转折"。
- 人工测试（镜 B-02、B-03、B-08 的人工判、D2 代表帧测试）安排不了时写"未测"。观众层状态写"通过（镜 B-03 未测）"，不得写成"通过"；未测的是 B-03 时，整件不得给 L3 及以上的结论。
- 依赖评审卡而卡缺失的项（平台条件、必须看懂的事件），按 1.4 的推断口径评，标"（推断）"，不写成未评。

### 4.5 版本对比：维度差分表

整件级别常常因为封顶和短板不动，所以维度差分表是正式输出。

| 维度 | 旧版 | 新版 | 变化 | 证据（时间码） |
|---|---|---|---|---|
| 镜 Dn | L? | L? | 升 / 降 / 平 / 平（同级改进） | … |

- 允许"平"。4.3 的"不允许差不多"只用于对标杆的盲比，不用于版本对比。
- 另列两行：B 层未过项的增减、T 层未过项的增减。
- 结论写清：哪几个维度变好、哪几个没动、整件级别为什么动或不动。D12 和 D13 的变化分开写。
- 两版都跑一次《书》1.3 的复述重合与画面错认（第 7.2 节 M-01），用来说明新版是"改好了"还是"换了一支片"。

## 5. 样稿内容口径

与视觉标准第 5 节同一口径（持有方），这里只补镜头与叙事特有的情况。

- **事实不编，样稿要填**。真实世界的事实（真实品牌的数据、真实人物、真实客户、真实证言、真实产品能做到什么）不得编造，编造按共用 S-10、S-11 判 L0。
- **明显是示例的虚构内容不算编造**：虚构的角色、品牌、账户、人名、日期、价格、演示数据、示例口播稿，只要不冒充真实存在的对象，都算样稿内容，在评审卡"样稿示例内容清单"列出即可。界面演示里虚构的用户名、消息、数据同此。
- **留空的算未完成**：空白填写栏、占位线、"此处放素材"、空着的证据框、"此处配音"的占位音轨或明显的临时配音（与终稿说话人不同、念着括号里的提示语），按共用 S-07 判 L0（评审卡注明"内部稿"且空位写明"待补"的除外）。找不到真素材时如实标"未完成项"，不得包装成"极简风格不用素材"（《书》16.3）。
- **决定类内容**（范围与判别问按需求理解标准需 B-06）即使填了示例，也要在评审卡"发布前须用户确认"一栏列出；评审者在报告末尾照录。未列出的决定类内容，评审者补列，不扣分。
- 示例内容同样受共用 S-10 约束：日期与星期对得上，算式算对，计数器的终值与画面上写的总数一致，口播念的数与上屏的数一致。
- **演示他人产品只借交互、不借身份**（《书》17.4、18.1 C22）：不得使用对方的商标、品牌色、标志性外观；用了的，按共用 S-11（冒充）判。

## 6. 标杆库规范

### 6.1 规则

- 标杆只给评审看，不给做作品的人看。存放位置：`standards/标杆/镜头与叙事.md`（待建）。
- 每件标杆一条记录：ID（`N-<级别>-<序号>`）；来源（只作内部记录，任何作品、封面、文案里不得出现来源或作者 ID）；片种 / 画幅 / 时长 / 平台条件；整件级别与各维度级别（未评留空）；**为什么是这个级别**（必须指向时间码上的可观察现象，不允许只写"有张力""节奏好"）；正例或反例；入库人、日期、是否经用户确认。
- 正例尽量配一件同片种的反例，组成比较对。
- 另收**维度切片**：整件 L2 的作品若某一段在某个维度达到 L3 或 L4（一次转折、一个承接、一个结尾），截取该段作为单项标杆，记起止时间码。
- 只收成片或可重放版本，不收截图。静帧、版式方面的级别交给视觉标准的标杆库，运动质感交给动效标准的标杆库。
- 用户亲口说"惊艳""这个好"的，原话直接入库为 L4（或对应维度 L4），是最高级别的校准数据；标准判级与用户判断冲突时用户胜，记录冲突，找出标准漏掉的观察，进入修订。用户说"一般""没感觉"的同样入库，作 L1 / L2 校准。

### 6.2 每级放什么

| 级别 | 放什么 | 标注重点 |
|---|---|---|
| L0 | 每条 B 底线（含共用 S）至少一件实例 | 哪条底线、时间码、测量值或测试者原话 |
| L1 | 无错但默认的作品，含同批结构撞车组 | 命中哪些维度的哪几条低级感；撞车对象和撞在哪一层（物、序、调、形） |
| L2 | 挑不出错、看一遍就懂，但说不出"那一下"的作品 | 为什么挑不出错；离 L3 差什么 |
| L3 | 能复述出某一个时刻、换题就不成立的作品 | "那一下"的时间码；挪动或删掉它为什么会变差 |
| L4 | 用户确认的惊艳作品 | 意外在哪里；为什么事后看是对的；用户原话 |

### 6.3 第一批锚点（来自两轮盲测，两位评审意见一致的作品）

编号格式：轮次-题号-作品号，例如 R2-T2-4 = 第 2 轮盲测、该轮题号 T2、作品 4。只写编号和理由。

**正例（两位评审都给 L3）**

| 编号 | 维度 | 为什么 |
|---|---|---|
| R1-T2-A | 镜 D1、D4、D5 | 文字讲出画面、画面演出文字，状态差（离开 → 最乱 → 回位）首末帧一眼可说；有加速、减速和停顿，峰在中段；首尾各有停顿，循环无缝。两位都指出的扣分：正文太长、一轮读不完，只能按可略读处理 |
| R2-T2-4 | 镜 D3、D4、D1 | 前段慢讲、中段加速倍增是峰、最后停在结论上；快慢本身就是要讲的那件事的形状；最后的整体形状就是结论。镜 D12 上它命中第二层默认第一条（同批三件同骨架），但两位评审都认可它多走的一步——让整体形状一眼可见——所以可到 L3，是 3 节"处理"规则的范例 |

**维度切片反例（两位评审一致）**

| 编号 | 维度 | 为什么 |
|---|---|---|
| R1-T2-D | 镜 D4 L1 | 题材和记忆点都好，但全片同一转速，无一次加速或停顿，说不出高潮；两位都给 L1、修好节奏后上限 L2。是"创意到位、节奏平"（D12 与 D4 分开看）的标准样本 |

**反例（两位评审都判"默认模板"）**

| 编号 | 命中 | 为什么 |
|---|---|---|
| R1-T3-B、R1-T3-C、R1-T3-E | 镜 D8、D5、D12 | 同一条"痛点问句 → 左字右机 × 3 段 → 结尾标志 + 金句"骨架，两件连开场问句和结尾标语都相同；排布不随内容变，结尾不落在对象上 |
| R2-T2-1、R2-T2-5、R2-T2-6 | 镜 D8、D12、D2、D5 | 同一条"标题页 → 定义 → 短期对比 → 长期曲线 → 编号要点卡"的段落序列；开场 3 s 是标题页；结尾是要点卡或金句 |
| R1-T2-C、R1-T2-E | 镜 D4、D12 | 同一套"变形 → 停 → 变形"的形态序列，段落等长、无峰；两件连形态顺序都撞 |

**L0 实例（两位评审都判该项未过）**

| 编号 | 底线 | 现象 |
|---|---|---|
| R2-T2-3 | 镜 S-05（= 视觉 B-05） | 须读标签被画面右边裁掉 |

本标准自己的 B 条目，两轮里没有两位评审一致的 L0 样本，见下面的校准备注。

**校准备注**（两位评审意见不一致，不作锚点，作为"必须测、不能靠看"的证据）
- R1-T3-A：一位评审判 L0（作为答案的元素被外壳遮住、不到 0.5 s 出画），另一位给 L3、未测这一点。→ 镜 B-04 必须逐帧测。
- R2-T2-1、R2-T2-5：一位评审按停留时间测出结尾总结句读不完判 L0，另一位判 L1、未按时间测。两位用的读速口径也不同（一位 9 字/秒）。→ 共用 S-01 一律按视觉标准 B-15 测，不凭印象。
- R1-T2-C、R1-T2-E：一位评审判"首尾不接、接缝跳变"，另一位未单独测接缝。→ 镜 B-06 必须拼帧带测。
- 两轮评审对须读字高用的是 24–27 px（1080 宽）口径；按视觉 B-01 的现行两档，当时多件判"字高足够"（约 30 px）的作品会未过或落在"偏小"档。这是本标准与已有评审数据差距最大的一处，列为第一优先的校准对象（8.1）。

### 7.2 测量数据项 M（只作维度证据，不判级，不要求说明）

都来自《书》各章的〔测〕。只对某一种取向成立的项，作品明显选了那种取向时才算，其余写 n/a。

| ID | 测什么 | 方法 | 给哪个维度 | 依据 |
|---|---|---|---|---|
| M-01 | 与上一支片 / 同批作品的差异 | 复述重合（共有实词比）、画面错认（5 帧打乱分堆）、最大变化位置差 | D12、4.5 | 《书》1.3（待实验） |

| M-04 | 布局大变化 | 每次布局大变化前一次注视内有无内容信号；≥ 3 次时相邻间隔比 < 1.2 是否连续出现两次（像计时器） | D4、D8 | 《书》10.2（1.2 弱证据） |

| M-06 | 转折 | 空隙预告时空隙 ≥ max(1.2Ī + t, 2t)；大转折数 vs min(N_时, N_段, N_道)；同一承担者使用次数（≤ 2）；落点 ±0.5 s 内运动量、响度、字幕三条中在高位的条数 | D3 | 《书》4.3、4.6（弱证据） |
| M-07 | 镜内组数 | 每一时刻在动的组数、在场的组数（单焦点接力参考在动 = 1、在场 ≤ 4） | D6 | 《书》11.2、11.7（4 待实验） |
| M-08 | 开镜与收尾 | 开镜第一个事件 ≤ r = 0.75 s；字幕早于对应画面事件消失的次数 | D6、D13 | 《书》11.4 |
| M-09 | 换空间 | 分到时长 d < 3r（≈ 2.25 s）却换了新空间的想法数（逐想法判定取向） | D7 | 《书》5.2（弱证据） |
| M-10 | 因果时序 | 原因停稳时刻 ≤ 结果起点；操作者与目标包围盒重叠面积；附属元素先于触发动作出现的次数 | D6、D13 | 《书》8.6、17.7 |
| M-11 | 相机 | 相邻运动净位移 < 两者之和 1/5 的对数；同向同类运动连续次数；揭示与读字时刻相机速度；连续空间里需读时相机速度 vs 约 1 屏宽 / 秒 | D9、D7 | 《书》14.2、14.8、13.4（弱证据） |
| M-12 | 落点窗口 | 口播锚点相对词起点的偏移：30 fps 窗口 [−2, 0] 帧、60 fps [−6, +1] 帧，超窗锚点数 | D13、D10 | 《书》16.4（制作容差，比镜 B-07 严一帧） |
| M-13 | 打乱重排与排布栏 | 中间帧打乱重排的错位率（起点 ≤ 1/4）；相邻镜排布同值的次数；占比上限 2/k（只对占比上限取向） | D8 | 《书》12.2、12.7 |
| M-14 | 静止与呼吸 | 静止段内像素差（真静止取向应为 0）；层间相对速度（极缓呼吸取向参考 ≤ 1 px/s @1080 宽）；环境层能量是否高于主体 | D4 | 《书》10.3、10.6（待实验） |
| M-15 | 结尾与接缝 | 真冻结：最后运动是否减速到零、末帧静止 ≥ R + 0.5 s、余响是否在走；循环：接缝空白 vs 平均事件间隔；高辨识元素一轮被看到的次数 | D5 | 《书》7.2、7.6（弱证据） |
| M-16 | 表演与术语 | 情绪新状态停留 ≥ 其 R；术语上屏 ≥ 名字的 R；第二主体出现 ≥ 首帧后 0.25 s | D11、D10、D2 | 《书》17.7、16.8、6.6 |

## 8. 待实验阈值、跨标准对应与修订

### 8.1 待实验阈值一览

**底线里标"待实验"的阈值（7 个）**：镜 B-02 测试人数与命中 1/2；镜 B-03 测试人数；镜 B-04 的 t = 0.25 s 与 c = 1.5；镜 B-06 速度变化 15%；镜 B-08 脚本候选偏差起点（最小必读高度）；镜 B-11 的 0.7° / 4 mm。（B-04 的 t、c 计两个，其余各一个，共 7 个。）声音先行的 L 与必读细节的视角已在 2026-11-20 共用条目对齐中分别归声 B-07、视觉 B-01 持有，在那两份标准里计。

**维度测试里的待实验数**：镜 D12 同批差异三项（1/3、2 张、15 个百分点）、结构同构的"一半可互换"。M 项另有 R 公式系数、档位比 1.4、计时器比 1.2、空隙公式、在场组数 4、3r、1/5、相机速度、1 px/s、R + 0.5 s 等，只作证据。

**校准顺序**（按与已有评审数据的冲突大小）：① 视觉 B-01 的字高两档（与两轮评审实际用的口径差最大，6.3 校准备注；由视觉标准持有，镜 B-09 随之）；② 镜 B-04、B-03（盲测里抓到最多的是结尾和答案读不完）；③ 声 B-07 的 L（由声音标准持有，《书》18.2 X5）；④ 镜 B-06（X 系列外，按《书》7.3 做速度差 5% / 15% / 30% 三版）。

**校准来源**：评审数据（两位评审一致的判断）、用户的审美判断、播放数据（留存曲线在开场、峰值、结尾处的斜率，《书》18.1 C3、18.3 D9）。单条数据不直接改阈值，累积成证据后按 `protocol.md` 修订；改动记入 `CHANGELOG.md`，旧版存入 `standards/archive/`。
