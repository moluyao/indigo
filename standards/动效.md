## 1. 总则与用法

### 1.1 评什么，不评什么

**评**：观众看一遍（全速、可能在手机上、可能静音）之后——东西动起来像不像有重量、有原因；快慢有没有形状、形状是不是从内容来的；每一下落在哪、和声音对不对得上；该读的读不读得完、看不看得见；停住时观众知道自己在看什么、在等什么；有没有一个属于这条片的动法；做得细不细。

**不评**（交给别的标准，同评时各报各的）：单帧的版式、字体、色彩、画质（视觉标准）；讲了什么、为什么在这里换镜、相机与取景、叙事结构（镜头标准；分工见镜头标准 1.1"本标准和动效标准的分工"）；配音与混音的做工细节（声音标准，本标准 D7 只评声音与运动的配合）；文案本身好不好（写作标准）。

**不评制作过程**：评审者只看成片和评审卡，不看提示词、脚本、工程文件、方向列表、自检记录、制作对话。作品自称做到了什么，不算证据。

### 1.2 五个级别

| 级别 | 名称 | 一句话 | 观众的反应 |
|---|---|---|---|
| L0 | 坏 | 有观众看得见/听得出的错误：任一**观众可感层**底线没过 | 出戏、皱眉、划走，或根本读不完、听不清 |
| L1 | 能用 | 没有错误，但处处是"没被决定过"的样子，一眼能认出是机器或模板做的 | 看完了，没感觉，说不出它和别的片有什么区别 |
| L2 | 商业合格 | 可以交付给付费客户：信息清楚、快慢与内容相称、做工干净，挑不出硬伤 | "挺专业的" |
| L3 | 精品 | 每个选择都说得出理由，删掉或换掉任何一处都会变差；至少有一个记忆点 | 看完能复述出某一个画面或某一下 |
| L4 | 惊艳 | 意外但正确：出现了观众没预料到、事后又觉得"只能这样"的处理 | "这个怎么做的？"、回看、转发给别人看那一下 |

- **L0 与 L1 的界线是"错"**，靠第 7 节的底线判，可测量。只有观众可感层的错才判 L0；交付技术层不达标记"交付未过"，与作品级别分开报告。
- **L1 与 L2 的界线是"默认"**，靠各维度的"典型 AI 低级感"逐条勾选，计数口径见 3.1 第 5 步。
- **L2 以上写不成规则**，只描述"看到什么"，靠标杆参照与两两比较确认（3.3、第 6 节）。本标准对 L3、L4 不给配方；给了配方，它就会变成下一个 L1。
- 任何取向（全片匀速或起伏剧烈、整屏完全静止或没有一帧完全静止、单一焦点或多焦点、全片一套运动规则或每段换一套）都可以到 L4，也都可以停在 L1；区别只在观众看到的效果。

### 1.3 三层与测量数据

| 层 | 管什么 | 怎么判 | 不过怎么办 |
|---|---|---|---|
| 交付技术层（T-xx） | 导出参数：色彩元数据、整体响度、真峰值、帧率、音视频流对齐、编码与封装、时长/画幅规格 | 脚本机械判定（`tools/check_floor.py` 的 `delivery` 段） | 记**"交付未过"**，标"可自动修复"或"需回工程"，附修复方法。**不判 L0**，不影响上限评审；交付未过的片不得发布 |
| 观众可感层（B-xx） | 观众看得见、听得出的错 | 脚本 + 抽帧 + ASR/OCR + 人工 | 判 **L0**；维度照评，写成"修好后的上限" |
| 上限维度（D1–D15） | 好不好、有没有意图、记不记得住、做得细不细 | 标杆参照 + 两两比较 + 评审陈述证据 | 给出级别与证据，指回《书》章节 |
| 测量数据（M-xx） | 可测、但数值本身不说明好坏的量（能量曲线、最长匀速段、静止区间、转场种类数……） | 脚本或评审在联系表上数 | **只作维度证据，不判级，不要求说明**；评审用它找位置、写证据 |

**判别一项检查属于 T 还是 B**：问"不重新做画面/声音设计，只改导出参数或跑一条命令能不能修好？"能 → T；不能 → B。超目标时长（T-07）、画幅不符（T-08）虽不能自动修复，也是对规格的核对，归 T 并标"需回工程"。

**判别一项属于 B 还是 M**：问"这个数超了，观众一侧是不是在任何取向下都看到了错？"是 → B；"只在某种取向下才算问题"（例如整屏完全静止、全片一个速度、同屏几个焦点）→ M。v1 的"预警项 + 有意说明，写不出理由按底线未过"作废：那套机制让选了某种取向的作品必须为取向辩护，等于替另一种取向判分。

报告抬头必须并列五件事：**交付层状态**（通过 / 未过：可自动修复 / 未过：需回工程）、**观众层状态**（通过 / 未过：列 ID / 通过（某条未测））、**整片级别**、**D14 创意与新鲜度**和 **D15 执行与完成度**各自的级别。例："整片 L0（修好后上限 L2）｜观众层未过 B-40｜交付未过（T-01，可自动修复）｜D14 L3 / D15 L1"。

### 1.4 评审卡：做片前定目标，交付时附卡

制作者交付成片时附一张**评审卡**（`card.json` 或卡片式 markdown，≤ 14 行）。评审者只读这张卡和成片。

| 字段 | 说明 | 用于 |
|---|---|---|
| 目标级别 | 例："L2，D11 争取 L3"；不得低于 L2（L1 片只用于内部草稿） | 3.2 与目标对照 |
| 目标时长、画幅 | 秒（可写区间）；宽×高 | T-07、T-08 |
| 平台 / 形态 | 平台与显示方式（横屏满屏、竖屏信息流、网页、广播……）+ 形态（解说片 / 口播片 / 角色片 / 动态海报·循环 / 发布片……）；是否可能静音自动播放 | B-17、B-14P、D12 |
| 交付响度值与真峰值上限 | 按声 T-01、声 T-02 的求法实测得到的值，**附实测日期**；没测写"未实测" | T-02、T-03 |
| 核心信息一句话 | 观众看完应带走的 1 句（可附 ≤ 2 条次要信息） | B-36、D10 |
| 须读文字范围 | 哪些是流读、哪些是停读、哪些是纹理（1.6） | B-13、B-14、B-14P、B-16、B-18 |
| **节奏意图** | 一句话写这条片的快慢打算：例如"有起伏，主峰约在 06 s""全片刻意匀速（内容就是重复劳动）""全平，循环背景""单调渐快到结尾"；可附声明的峰、停顿时间码 | B-42、D1 |
| 设计静止 / 设计停留 | 有意的完全静止或长停留的时间码（例如"峰前 04.0–05.2 s 完全静止"） | B-04、B-05、M-08 |
| 样稿示例内容清单 | 哪些名称、日期、价格、数据是示例（第 5 节） | B-13、B-43 |
| 发布前须用户确认 | 决定类内容（范围与判别问按需求理解标准需 B-06） | 第 5 节 |
| 代表帧 | 封面帧、关键帧的时间码 | 视觉 B-16（同评时） |
| 有意说明（密封） | 对 M 项里可能显得反常之处的说明 | 评审结束后才打开（1.5） |

- 一条片不必每个维度都冲高；但**任一维度低于目标级别一级以上**，整片不得按目标级别验收（3.2）。
- **评审卡缺失时**：评审者从成片推断各字段，逐项标"（推断）"；推断不得用于豁免任何底线。须读文字范围推断不了时，画面里所有文字一律按流读测。目标时长推断不了时 T-07 记"仅报实测"。**节奏意图不推断**：缺这一栏时 B-42 记"未测（缺意图声明）"，最长匀速段等数据只作 D1 证据。
- 节奏意图、设计静止只用来核对"成片是否做到了声明的意图"，不能改变维度级别。

### 1.5 评审者与制作者分离

- 评审者不是制作者，**只看成片 + 评审卡**，不听制作者额外解释。意图只能通过画面、声音和这张卡传达；评审时解释不了的东西，观众也接收不到。
- 评审者为 agent 时，必须是独立会话，不继承制作会话的上下文，不知道作品出自谁。
- 评审顺序：先看一遍、写下记住的画面（≤ 3 条）并封存（D11 协议），再跑脚本，再做人工项，再逐维度判级。
- "有意说明"在评审**结束后**才打开，只能解释 M 项测量数据，不能改变任何维度级别，也不能豁免 B 层。

### 1.6 评审只看三件材料

评审者从成片生成以下三件材料，全部判断都要能指回其中某一处（时间码或帧号）：

1. **抽帧联系表**：每秒 1 帧 + 每个**段落边界**前后各 1 帧。
   `ffmpeg -i in.mp4 -vf "fps=1,scale=320:-1,tile=6x5" -vsync vfr sheet_%02d.png`
   段落边界 = 硬切点 ∪ 软边界。硬切点用帧差尖峰或 `select='gt(scene,0.3)'`；软边界（虚化、推拉、溶解、镜头运动换版）用 0.5 s 间隔帧差 `|y(t) − y(t−0.5 s)|` 的局部峰（`check_floor.py` 输出 `meta.boundaries`，type=hard/soft，软边界附过渡区间起止）。检不出时以时间线表人工标注为准。
2. **逐段时间线**：行 = 段落；列 = 起止时间码、本段一句话信息、画面事件（边界、新文字、新元素）、语音（ASR 逐词时间戳）、音乐/音效落点、能量变化（用《书》〇.3"能量"一组术语：辨步、跃升、渐升、平段；v1 的 E0–E5 六级在 r5 已删）。
3. **音频测量**：整体响度、短时响度曲线、LRA、真峰值、静音区间、声音瞬态、人声与音乐的分轨或估计电平。

**必备工具**：ffmpeg/ffprobe、`check_floor.py`、**带词级时间戳的 ASR**、OCR、闪烁扫描脚本（`03-book/scripts/flash_check.py`，口径见 B-31）。缺 ASR 时依赖"新词"的检查（B-04、B-24、B-27、B-28）记"未测"，不得用静音代替后判通过。

### 1.7 文字的三类与形态条款

**三类**：沿用视觉标准 1.4 的叫法，v1 的叫法对应如下。字高、对比度、停留的阈值全部按视觉标准对应条目，本标准不另设。

| 类别（v2） | v1 叫法 | 定义 | 适用 |
|---|---|---|---|
| **流读** | 须读 | 观众不读它就带不走核心信息，或会误解：标题、要点、结论、关键数字与单位、字幕、对比框的判断词、改变理解的限定语 | B-13、B-14、B-16、B-17、B-18、B-40、B-41 全部适用 |
| **停读** | 可略读 | 读了更好、不读也不误解核心信息：图内标注、图例细项、脚注、出处、进度小标签、计数器 | B-13 不得有错；字高、对比度按视觉 B-01、B-03 的停读口径；不计入 B-14 |
| **纹理** | 装饰 | 不预期被读：背景字纹、排版肌理、标志字形 | 只查无错字（若可辨认）；不得被做成"想读又读不清"（视觉 B-02） |

**判别（遮住测试）**：在代表帧上遮住这块文字，问"只看剩下的，复述还能命中核心信息吗？会不会误解？"命中且不误解 → 停读；否则 → 流读。评审卡写了范围时先按卡；评审者发现卡上标"停读"的文字其实承载核心信息，按流读测并在报告写明。

**形态条款**：
- **时序文字**（解说片、口播片、发布片的多数文字）：按 B-14（= 视觉 B-15）逐块测停留。
- **常驻文字**（"动态海报 / 循环"形态：全片单镜头或少数镜头、文字整片常驻、平台自动循环）：不按单块停留判，按读负荷判（B-14P）。形态必须写在评审卡里；有配音、有段落推进的片不得以"海报"形态申请本条款。

### 1.8 未评与未测

- 评审者拿不到某维度的证据时（例如听不了声音、没有 ASR），该维度记**"未评"**并写原因，不估级。可附测量提示，但提示不进入合成。
- 合成时未评维度视为"不限制上限"，整片写 **"≤X（待 Dn 补评）"**；补评后按 3.2 重新合成，只可能等于或低于 X。"≤X"与目标对照只算"有条件达标"，发布前必须补评。未评的是 D10、D14 时，不得给 L3 及以上的结论，只能写"L3 候选（待补评）"。
- B 层某条测不了（没有 ASR、没有平台界面截图、缺节奏意图声明），写"未测"，观众层状态写"通过（B-xx 未测）"，不得写成"通过"。
- agent 评审的最低声音证据：整体/短时响度、LRA、静音区间、声音瞬态、ASR 词级时间戳与置信度。有这些可测 B-24、B-27 和 D6 中"内容错位"一项；咔哒（B-44）、语气、音色、混音层次仍需能听的评审者（声音标准 2.5、4.4）。

### 1.9 与其他三份标准共用的条目

下面这些是 L0 级的错，阈值和测法写在别的标准里。本标准**不另设数字**，照原条目测；报告里写"动效 B-xx（= 视觉 B-yy）"。只评本标准时也要测。几份同评时只测一次，记在下表"记在哪个编号下"一栏。

| 本标准 ID | = 原条目 | 名称 | 记在哪个编号下 | 本领域的读法（测在哪些时刻） |
|---|---|---|---|---|
| T-02 | 声 T-01 | 整体响度 | 声 T-01 | 不写平台数值；交付值按声 T-01 的"平台实测求法"得到并带实测日期 |
| T-03 | 声 T-02 | 真峰值 | 声 T-02 | 上限 c 与卡没给 c 时的判法都按声 T-02 |
| B-13 | 视觉 B-10 | 错字、错数、事实 | 视觉 B-10 | 高发处：计数器滚动中与终值对不上、口播与上屏不一致（镜 S-10） |
| B-14 | 视觉 B-15（= 镜 S-01、声 S-13） | 流读文字停留够读 | 视觉 B-15 | 停留从文字**变得可读**起算（入场动画结束、对比达标、运动停止或足够慢），到开始退场止；动效里最常见的是入场还没落定就开始计时、退场提前 |
| B-16 | 视觉 B-03（= 镜 S-08） | 对比度 | 视觉 B-03 | 动态底取文字可读期间最差的一帧；大号字条件按视觉 B-03 |
| B-17 | 视觉 B-06（= 镜 S-06、镜 B-10） | 平台遮挡区与左右安全距离 | 视觉 B-06 | 每个流读时刻的落定帧叠目标平台实拍界面；侧边距按视觉 B-06 |
| B-18 | 视觉 B-01（= 镜 B-09、镜 S-09） | 流读文字到达字高 | 视觉 B-01 | 取文字需要被读的那段时间里最小的一帧（推拉、缩放中最小处）；"偏小"档在本标准 D4 扣分 |
| B-22 | 声 B-07（= 镜 B-07） | 可见发声同步 | 声 B-07 | 画面撞击帧 / 口型闭合帧 vs 音频瞬态起点 |

## 2. 上限维度

每个维度按同一结构写：**判断问题 → 相关底线与测量数据（指针）→ L1–L4 看到什么 → 典型 AI 低级感 → 回炉（《书》r5 节号）**。级别只写现象，不写手法和参数。底线的完整写法在第 7 节，维度里只留指针。

**低级感清单的用法**：每条命中标"局部"（一处，或累计 ≤ 1/3 片长）或"贯穿"（> 1/3）。以下两种情况不计：① 能从成片看出它是从这条片的内容推出来的（例如内容本身就是流水线，于是匀速）；② 评审卡"节奏意图"声明了对应的取向，而且成片从头到尾贯彻了它（贯彻与否由 B-42 核）。不计的写进证据。判 L2 须同时满足：该维度无贯穿命中；局部命中 ≤ 2；能写出 ≥ 2 条带时间码的 L2 现象。任一不满足，该维度 ≤ L1。

### D1 节奏与时长

**判断问题**
1. 每一段是否在它的信息讲完后就离开——既不拖，也不在没讲完时就走？
2. 全片的快慢有形状吗？这个形状是从内容来的，还是从时钟来的？闭眼回想，说得出哪里重、哪里轻吗？（选了"刻意的平""全平"的片，问的是：观众读得出这是有意的平，而不是没做完吗？）
3. 开场窗口内，观众是否已经知道"这是什么、为什么要看下去"？
4. 有没有观众不知道自己在等什么的时间？

**相关底线**：B-02 开头窗口、B-03 开头冻结、B-04 死时间、B-05 片尾尾巴、B-06 音乐硬断、B-42 节奏与声明意图不符；T-07 时长。
**测量数据**：M-01 运动能量曲线、M-02 最长匀速段、M-03 起伏次数、M-04 平段、M-05 段落时长变异系数、M-08 静止区间。

**各级看到什么**
- **L1**：快慢和内容无关：段落一段接一段、长短差不多，每句话配一个画面变化，句句一样；或者处处都是高潮，于是没有一处是重点；说不出哪里重；或者平了一半、起了一半，读作没做完。
- **L2**：快慢跟着内容走：重的地方观众感到了（变快、变密、停住、变空，取哪一种都行）；没有拖沓段；开头很快进入正题；结尾收得住。选了平的片，从头平到尾，观众读得出"这是刻意的平"。
- **L3**：快慢的形状本身在讲这件事——最重要的信息落在最显著的时刻，喘息出现在观众需要消化的地方；时长恰好，删掉任何一段都会断。
- **L4**：节奏本身制造了意义——一次出乎预料的停顿、提前或落空，让观众在那一刻被抓住；回看时发现整片的能量形状是为这一刻铺的。

**典型 AI 低级感**
- 每段等长，每段都是"标题入场 → 停留 → 退场"同一套流程。
- 全片同一速度，而内容有轻有重（不是"刻意的平"）。
- 开头标题或标志慢慢淡入，前几秒没有信息。
- 结尾"感谢观看 / 关注我"淡出，或内容讲完画面直接停在最后一帧。
- 处处都是高潮：每一句都配冲击音效和放大。
- 列表式内容每一条用完全相同的时长和动作，第三条时观众已能预测一切。
- 成批同类元素等间隔进场，几次之后间隔被预测吃掉，读不出快。

**回炉**
- 时间从哪来、改动怎么传播 → 《书》第 1 章（1.1、1.2 先选时基、1.3 校准）
- 全片没形状 → 第 2 章（2.1 推导、2.2 取向，含"全平""先顶后落"两种故意违反）、第 3 章（3.1 落差由哪几维构成、3.2 取向、"过度与边界"的平段判据、故意违反"刻意的平"）
- 开场 → 第 4 章（4.1、4.2）
- 死时间、空转 → 第 5 章（5.1 推导、5.2–5.5 取向）
- 想更快 → 第 6 章（速度级、取向一"只加起音"、取向二）
- 切得太碎或太闷、同类连成串 → 第 8 章（8.1 第 6、7 条）
- 高潮没力量 → 第 9 章（9.1 推导、9.2–9.5）、第 10 章（10.1–10.5）
- 段落之间分不开 → 第 11 章（11.1）
- 结尾 → 第 20 章（20.1–20.4）
- 一个动作内部的快慢 → 第 25 章

### D2 运动质感

**判断问题**
1. 东西动起来像有重量、有材质、有原因吗？大的和小的、重的和轻的，动起来有区别吗？
2. 每一次运动，评审说得出"它像什么在动"（被推、落下、被拉走、沉入……）吗？
3. 停下时是"落定"，还是"卡住"、"抖完才停"、"落定后又被挪正"？
4. 画面停住时，观众读到的是"落地了 / 在等 / 对比底"，还是"卡住了 / 死机了"？

**相关底线**：B-08 运动卡顿、B-09 闪帧坏帧、B-10 穿帮、B-40 遮挡与出画。
**测量数据**：M-06 入场时长与元素尺寸、M-07 速度形状种类、M-08 静止区间、M-21 位置频闪。

**各级看到什么**
- **L1**：运动无错误，但所有元素像在同一条轨道上滑，起停方式一样、时长一样；或者每个元素都弹一下；说不出它像什么在动；停住处被读成卡住，或动个不停却说不出为什么动。
- **L2**：主角与配角、大与小的运动看得出区别；落定干净；入场和退场不是同一个动作倒放；每次停住观众都知道是"落地"还是"在等"。
- **L3**：观众看几次就学会了这个画面里的"物理"，并能用它预测下一下；每一种运动都在说一件事（出现、让位、被推开），没有为动而动；细小处（停住后的余波、跟随、被带动）都在。若片子有意让不同段落各用一套规则，观众读得出换规则的原因。
- **L4**：观众记住的是某个东西"怎么动的"；运动本身成为表达，换一种动法这个画面就不成立。

**典型 AI 低级感**
- 匀速直线位移，起停无加减速，而内容不是机械、传送一类。
- 全片一条通用对称 S 曲线、一个时长，所有元素一模一样地"上浮加淡入"。
- 处处回弹：每个卡片、每个字都过冲一下。
- 从 0 缩放到 1 的"弹出"，无论元素大小；放大用同增量插值，末段突然变快。
- 无动机的旋转入场、3D 翻转。
- 整屏持续缓慢放大，从头放到尾，与内容无关。
- 停住被读成卡住（之前没有建立"下一下何时来"的预期）；或者所有元素无意义地漂浮、晃动。
- 粒子、光斑在背景里持续飘，与内容无关。
- 入场与退场是同一动作倒放。

**回炉**
- 入场的性格 → 《书》第 13 章（13.1 性格由三个量决定、13.3 速度集中在哪一端、13.4 时长、13.5 按受力清点物理身份、13.6–13.8 三种取向）
- 全片怎样统一、复用调好的运动 → 13.2
- 退场 → 第 14 章（14.1、14.2）
- 多元素一起动时乱 → 第 15 章
- 停住时 → 第 18 章（18.1 速度窗、18.2 三端分歧、18.3 允许多少东西在动、18.4、18.5）
- 动作内部的预测过程 → 第 25 章；距离、路径、缩放插值、运动模糊 → 第 26 章（26.1–26.5）
- 凭空出现、落定后又被挪正 → 第 27 章（27.2、27.4）
- 重量、碰撞、群体运动 → 第 22 章（22.1–22.3）
- 逐格检查与扫描 → 第 31 章（31.3、31.6）；参数自查 → 第 23 章速查表、附录"禁用值自查"
- 角色的动作与反应 → 不在本维度，见 D13

### D3 注意与视线引导

**判断问题**
1. 任取一帧：观众第一眼落在哪、第二眼落在哪？与这段要传达的东西一致吗？
2. 同一时刻有几处在争注意？是一处，还是有意的几处（对照、并列、群像）？是几处时，观众读得出它们之间的关系吗，还是只觉得乱、哪样都没看清？
3. 新元素出现时，眼睛来得及到达吗？还是出现在视线刚离开的地方？
4. 强调是否稀缺——重点是不是真的比别处显著？

**相关底线**：B-11 三秒注视测试、B-40 遮挡。（v1 的 B-12"主焦点唯一"已删：单焦点和多焦点都是取向，《书》24.3 两端并列。）
**测量数据**：M-09 同时启动的运动对象数与强调手段数、M-10 视线跨距。

**各级看到什么**
- **L1**：信息都在，但平铺；每个元素同等大小、同等亮度，或者每个都被强调；眼睛要自己找；几处同时在动，观众说不出该看哪、也说不出它们是什么关系。
- **L2**：任一时刻观众都知道该看什么——一处，或者读得出关系的几处；眼睛按设计的顺序走，不迷路；强调只给真正的重点。
- **L3**：视线被"带着走"——上一个落点的位置和方向自然引向下一个；元素出现的先后就是阅读的先后；同时在动的几样东西，强弱、先后分得清，观众不觉得被抢。
- **L4**：视线引导制造了惊喜——眼睛被精确地带到一个位置，然后答案在那里出现（或刚好在别处出现）。

**典型 AI 低级感**
- 所有元素在同一时刻一起淡入。
- 处处发光、处处描边、处处渐变，于是没有重点。
- 卡片网格平铺，全部同尺寸、同色、同时出现。
- 一个重点同时加颜色、发光、放大、抖动四重强调。
- 装饰粒子、光效、背景纹理比主体还抢眼。
- 新元素出现在与上一个落点相反的角落，视线左右横跳。

**回炉**
- 第 0 帧没有落脚点 → 《书》第 4 章（4.1）
- 读项与感项、预算、层序 → 第 24 章（24.1、24.2、24.3 两端取向）、〇 P2（注意力预算与串行律）
- 多元素出现顺序 → 第 15 章（15.1、15.2）
- 视线到达时长 → 〇.1（G）、13.3（"发现 / 确认"两刻）
- 画面与声音谁先吸引注意 → 第 16 章（16.1）
- 动效总量与被设计过的时刻 → 第 28 章（28.2、28.4）

### D4 文字的出现与停留

**判断问题**
1. 每一块流读文字，普通观众在它停留的时间里能不能读完？停留是从"可读"算起的吗？
2. 入场、退场的过渡里，文字是不是"看得见却读不了"？
3. 文字的出现方式（整块、逐词、逐字）与意义单元对得上吗？
4. 屏幕文字与配音在互相帮忙，还是在抢同一份注意力？

**相关底线**：B-13 错字（= 视觉 B-10）、B-14 停留（= 视觉 B-15）、B-14P 读负荷、B-15 字幕行长、B-16 对比度（= 视觉 B-03）、B-17 遮挡区与侧边（= 视觉 B-06）、B-18 字高（= 视觉 B-01；"偏小"档在本维度扣分）、B-20 转场抢文字、B-41 过渡态可见不可读。
**测量数据**：M-11 同屏须读字数与信息块数、M-22 过渡态时长。

**各级看到什么**
- **L1**：读得完、看得清，但文字是"放上去的"，与画面的运动无关；配音说什么屏幕就写什么；文字一律同一种出现方式。
- **L2**：每块文字在落定后才需要读，读完才走；出现方式与意义单元对得上；屏幕给关键词，配音给完整句（或反过来，分工清楚）。
- **L3**：文字的出现方式带着这条片的性格；读的节奏就是看的节奏；观众不觉得自己在"读"。
- **L4**：一处文字的出现、变形或位置本身在说话，读到那一刻产生"原来如此"。

**典型 AI 低级感**
- 每个字逐个打字机出现，无论内容长短。
- 文字一出现就开始漂浮、晃动，读的时候还在动。
- 关键词逐字跳动、逐字变色。
- 把配音稿全文照抄到屏幕上。
- 一句话读到一半就退场，或退场与下一句入场挤在一起；结尾总结句挤进最后一两秒。
- 半透明字先于衬底出现，过渡里叠成一团。

**回炉**
- 停留时长、读速、起步成本 → 《书》第 17 章（17.1 推导、17.2–17.5 取向）、〇.1（τ_f、r₀ 未标定，见"未标定期间"）
- 文字逐步出现的单位 → 13.9（r5 重推：下限由注视、上限由意义单元推出）
- 文字与配音谁先 → 第 16 章（16.1、16.2）
- 同屏单元上限 → 第 6 章（Σ T_read ≤ T_hold）
- 口播片文字包装多少 → 第 19 章（19.1–19.4）
- 小屏字高、安全区 → 30.1 第 5、6 条（数值按视觉、镜头标准，见附录 B）

### D5 转场

**判断问题**
1. 每一个转场都在说"这里换了一件事"吗？转场的幅度与内容变化的幅度相称吗？
2. 转场有没有占用观众本该用来看内容的时间？
3. 转场后眼睛要花多久才找回落点？上一段的落点交接给下一段了吗？

**相关底线**：B-10 边界穿帮、B-19 非设计黑闪、B-20 转场抢文字、B-31 闪烁。全片无段落边界（单镜头海报）时 D5 记 n/a。
**测量数据**：M-12 转场种类数、总时长占比、同一转场声的重复。

**各级看到什么**
- **L1**：转场无错，但全是同一种（交叉淡化或同一种滑动），无论内容变化大小；或者每次换一种花式，像在展示转场库。
- **L2**：小的内容变化用小的转场或直接切，大的段落变化用更明显的转场；转场短而干脆；转场后视线不迷路。
- **L3**：转场由内容长出来——上一段的某个元素变成下一段的开头，退场的去向就是下一个入场的位置；观众感觉不到"转场"，只感觉内容在流动。
- **L4**：一个转场本身就是一句话：两个画面之间的连接制造了新意义（对比、因果、反转）。

**典型 AI 低级感**
- 所有段落之间都是交叉淡化，或所有转场同一时长、同一方向。
- 每次换一种花式：翻页、百叶窗、旋转缩放、故障风轮流上。
- 白闪转场、整屏黑场过渡反复出现。
- 每次转场都配同一个"嗖"。
- 故障风、色散、RGB 分离当作万能转场。

**回炉**
- 何时转、靠什么接、多长 → 《书》第 12 章（12.1 推导、12.3 取向，取向一 r5 重推：承载物与"找回帧数"）
- 硬切的明暗核查 → 12.2（口径按 30.2）
- 段落边界要变多少 → 第 11 章（11.1，第 4 条 r5 重推：搜索代价三档）
- 退场与下一个入场的衔接 → 14.1 第 5 条（末速度与初速度）、第 9 条（有意义的退场给下一个入场指路）、13.3"例外：被下一个入场撞走"
- 交接处跳变、身份连续 → 第 27 章（27.3、27.4）

### D6 声画同步

**判断问题**
1. 声音说到、响起的那一刻，画面上对应的东西是否正好"落"在那里？
2. 音乐的重拍和乐句边界，与画面的落点、段落边界是什么关系？对不上的地方，观众读得出是有意错开吗？
3. 音效贴在动作的落点帧，还是贴在起始帧？

**相关底线**：B-22 可见发声同步、B-23 音效落点、B-24 内容错位（B-22、B-23 = 声 B-07；B-24 = 声 S-06）；T-05 流对齐。评审听不了声音时按 1.8 记"未评"。
**测量数据**：M-13 切点落拍比例、关键词落点相对配音的系统性偏移。

**各级看到什么**
- **L1**：音乐只是垫底，与画面没有关系；或每一拍切一刀的机械卡点；音效有，但位置随意。
- **L2**：段落边界与乐句的关系看得出是安排过的；重要落点有声音托住；配音说到哪画面就到哪；没有可察觉的错位。
- **L3**：声音与画面像一个通道——音乐的不同层级分别对应画面的不同层级；有意的错开制造张力，并在下一个落点兑现。
- **L4**：声画关系本身制造了惊喜：一次所有通道同时落空的静默、一次画面先于声音的抢拍，让观众在那一刻屏住。

**典型 AI 低级感**
- 音乐从头到尾同一首同一能量，与画面毫无关系。
- 每一拍都切一刀，或每一拍都让元素跳一下。
- 音效贴在动画起始帧，声音结束时动作还没落定。
- 配音讲到第三点，画面还在第二点。
- 每个元素入场都配同一个"叮"。
- 片尾音乐比画面早停或晚停一截。

**回炉**
- 时间以谁为准、漂移 → 《书》第 1 章（1.2、1.3）
- 内容轻重对上音乐轻重 → 第 7 章（7.1–7.5）
- 画面、配音、音效谁先 → 第 16 章（16.1，第 2、3 条 r5 重推：三种显著时刻；16.2）
- 爆发段切点与落地 → 第 9 章（9.4 取向三：飞轮起转、刹停收尾）
- 蓄力与冲击的声画叠加 → 第 10 章（10.3 多通道撤除）
- 落点偏差的扫描 → 31.6"落点偏差"

### D7 声音与运动的配合

> 与声音标准同评时，配音、混音、音效质感的分级以声音标准的维度为准（声 D1–D11），本维度只评"声音与画面运动的配合"；只评本标准时，本维度按下面全部判断问题评。

**判断问题**
1. 配音像一个人在对你说话，还是在念稿？句间停顿是跟着意思走，还是机械等长？
2. 人声、音乐、音效三者，任何时刻都清楚谁是主角吗？人声始终听得清吗？
3. 声音的轻重、软硬与画面运动的轻重、软硬一致吗？
4. 整体响度有没有忽大忽小？

**相关底线**：B-27 人声可懂、B-28 错读、B-29 削波与断音、B-30 底噪、B-44 咔哒（= 声 B-01）；T-02、T-03 响度与真峰值（= 声 T-01、声 T-02）。评审听不了声音时按 1.8 记"未评"；无配音的片（纯配乐动态海报等）本维度评"声音设计"：配乐与音效是否有层次、有落点、给画面让路。
**测量数据**：M-14 句间停顿变异系数、语速、闪避量、相邻同类段落短时响度跳变（只作证据；与声音标准 M-02 同一件事，数值待校准后统一，见声音标准 8.2）。

**各级看到什么**
- **L1**：能听懂，但平直：每句同一语调、结尾同样下坠，停顿等长；音乐全程一样大；音效的轻重与动作的轻重无关。
- **L2**：语气自然，重音落在关键词上；音乐在人声出现时让路；音效克制而贴位；响度全片平稳。
- **L3**：声音有设计——软的东西声音软，重的东西声音沉；停顿有呼吸；层次在耳机里清楚可分。
- **L4**：声音成为记忆点——一个声音母题、一次精确的静默、一句语气的转折，让观众记住这条片"听起来"是什么样。

**典型 AI 低级感**
- 配音像念稿：每句同一语调，句尾统一下坠；句间停顿一样长。
- 情绪词被夸张地读。
- 音乐全程同一电平压着人声。
- 音效库默认的"嗖、叮、咚"每处都上，与动作质感无关。
- 开头音乐满电平突然进入；结尾音乐被一刀切断。

**回炉**
- 口播作为时基、换气 → 《书》第 1 章（1.2）
- 人声与画面、音效的先后 → 第 16 章
- 口播片的包装密度 → 第 19 章
- 音乐层级 → 第 7 章
- 余韵与尾音 → 第 20 章（20.2 静收、20.3 一击收）
- 《书》未覆盖配音导演与混音：回炉指向声音标准对应维度（声 D4 分层与让位、声 D5 配音、声 D6 音效的质感与重复）的回炉章节。

### D8 色彩与质感在时间里的变化

> 单帧的配色、明暗、表面质感由视觉标准 D4 评；本维度只评它们**在时间里怎么变**——变化是否参与节奏与叙事。

**判断问题**
1. 明暗与色彩的变化是在帮助区分段落、标出峰值，还是随意在变（或从头到尾一点没变而内容在变）？
2. 材质（平面、纸、玻璃、金属、颗粒……）在运动中表现一致吗？动起来时质感有没有露馅（塑料感、贴图滑动）？
3. 亮度的跳变对冲击强度的放大，是被控制过的吗？有没有刺眼、可能诱发不适的变化？

**相关底线**：B-31 闪烁（= 视觉 B-17）、B-33 色带块效应（= 视觉 B-13）；T-01 色彩元数据。
**测量数据**：M-15 逐帧平均相对亮度与饱和度曲线、同屏主色数。

**各级看到什么**
- **L1**：颜色无错，但"默认的科技感"或"默认的清新感"；色彩变化与内容无关，或每段换一套颜色而无理由；材质在动时像渲染器默认。
- **L2**：明暗与色彩的变化克制而有用：段落换色有理由，强调色只给重点；材质在运动中一致；在手机上看舒服。
- **L3**：色彩与质感的变化参与叙事——峰值处的明暗或色彩落差最大，或者有意不变而让别的维度承担落差；细节质感（颗粒、纸纹、光的方向）在运动中一致而不喧宾夺主。
- **L4**：一处色彩或质感的变化让人记住，并且与内容意义咬合——观众看到那个颜色就想起那个意思。

**典型 AI 低级感**
- 深蓝紫渐变背景 + 青紫霓虹发光，作为"科技感"的万能解。
- 处处毛玻璃卡片、处处发光描边。
- 高饱和彩虹渐变，或每段换一套颜色而无理由。
- 全屏均匀噪点颗粒，与内容无关。
- 3D 物体塑料质感、默认布光，转起来高光滑动。
- 纯白全屏闪当万能冲击。

**回炉**
- 《书》没有色彩专章。相关处：第 3 章（3.1 第一步"明度与色彩的整体水平"是落差的一维）、第 2 章（2.1 能量形状）、第 11 章（11.1 换色是边界变化的一种）、第 18 章（18.4 环境层慢移）、30.1 第 3 条（亮度对冲击的放大）、12.2（硬切的明暗核查）。
- 单帧配色与表面 → 视觉标准 D4 的回炉。

### D9 运动语法

**判断问题**
1. 同一类东西（标题、要点、数据、强调、注释）在全片是不是同一种动法？观众能不能很快学会"这种动法 = 这类信息"？
2. 全片是否属于同一个世界？有没有某一段的运动像从别的片里贴过来的？
3. 规则变化的地方（若有），观众读得出原因吗——它对应一个内容上的变化，还是只是没统一？

**相关底线**：无单独底线（同类元素的样式不一致归 D15 执行与完成度；技术参数一致归 T-01、T-04、T-08；低清素材归 B-35）。
**测量数据**：M-16 同类元素的运动方式与样式并排比对、M-18 重复深度。

**各级看到什么**
- **L1**：要么"一致"只是因为套了同一个默认模板（一致但没有性格），要么各段运动拼贴、同类信息一会儿这样动一会儿那样动，读不出原因。
- **L2**：一套运动语法贯穿全片：同类元素同动法，观众很快学会"这种动法 = 这类信息"；规则变化的地方都对应内容变化。
- **L3**：语法有性格，环境的"物理"统一而施力者各异；规则的变化（若有）恰好落在内容的关键处，因为前面的一致而格外有力。
- **L4**：语法本身成为记忆点——观众事后意识到，这套动法就是这条片的身份。

**典型 AI 低级感**
- 一致只靠同一个模板，换题材也一样。
- 前半扁平、后半 3D 写实，没有理由。
- 同一类要点一会儿从左滑入、一会儿从下弹出，内容并无变化。
- 同一种入场铺满全片，每块都是同一个上浮加淡入。

**回炉**
- 一致建立预期、变化才被读出 → 《书》〇 P3（预期律）
- 世界统一、施力者各异；复用 → 13.2
- 同一运动形式的重复上限 → 8.1 第 6 条、第 28 章（28.2 三个计量、28.7 失败点第 1 条）
- 段落边界变多少 → 第 11 章
- 同一角色同一参数 → 第 23 章速查表

### D10 信息清晰度

**判断问题**
1. 看完一遍，观众能复述出这条片要说的 1–3 件事吗？
2. 每一个画面变化是否都对应一个新意思？有没有不带信息的动作？
3. 任何时刻，观众知道"现在在讲什么、讲到哪了"吗？
4. 图表、数据、示意是否一眼看懂，不需要暂停？变化有原因吗？

**相关底线**：B-36 有声复述、B-37 事实与图表（= 视觉 B-10、B-11）、B-38 有结论（评审卡声明为判断类时）。静音可懂按镜 B-02。
**测量数据**：M-17 无新意义的画面变化占比、一屏同时比较的数据组数。

**各级看到什么**
- **L1**：信息都在，但每条权重一样、平铺直叙；包装和信息分不开，看完记得"挺炫"但说不清讲了什么。
- **L2**：一遍看懂；观众知道讲到第几点；重点信息得到更多时间和更显著的落点；数据一眼看懂。
- **L3**：展开方式本身让理解更容易——用变化、对比、拆解把一个难点"演"出来；每个动作都在传递意思，变化都有看得见的原因。
- **L4**：一个可视化或一次揭示让观众真正"看见"了原本抽象的东西；看完会想把这个解释讲给别人听。

**典型 AI 低级感**
- 信息被包装淹没：一句话藏在粒子、光效和 3D 旋转里。
- 堆空词："赋能""全面""生态""颠覆"。
- 数字没有比较对象。
- 图表装饰化：3D 饼图、发光柱、无刻度。
- 开头"今天我们来聊聊……"，前几秒没有信息。
- 字幕、画面大字、配音三处重复同一句。
- 结尾不给结论，或给一句放之四海皆准的套话。

**回炉**
- 注意力预算、意义单元 → 《书》〇 P2、P5
- 事件要被登记、空转 → 第 5 章（5.1）、第 28 章（28.4 被设计过的时刻）
- 变化要有原因 → 〇 P6、第 27 章（27.1–27.5）
- 开场先给什么 → 第 4 章
- 读得完 → 第 17 章
- 口播片包装多少 → 第 19 章
- 关键信息不能只靠运动传达 → 30.1 第 2 条
- 结尾落在哪 → 第 20 章

### D11 记忆点

**判断问题**
1. 看完一段时间后，评审还记得哪一个画面或哪一下？能用一句话描述吗？
2. 被记住的是信息层（内容的某一刻），还是装饰层（一个特效）？
3. 把这个处理移到一条无关的片上还成立吗？（成立 = 通用花招，不是这条片的记忆点）

**底线**：本维度没有判 L0 的底线（没有记忆点不是错误）。
- **零记忆点检查**：评审看完一遍，间隔 ≥ 30 分钟后写下记得的画面。写不出任何一个 → 本维度 L1。
- **agent 的替代协议**（agent 无法真正间隔 30 分钟）：
  1. **先写后查**：评审 agent 看完一遍后，在做任何维度判级之前，不回看材料，写下记得的画面（≤ 3 条）并封存；完成全部其他工作后才拆封核对。
  2. **第二 agent 冷回想**：另起一个不继承上下文的 agent，只给每秒 1 帧的联系表按顺序快速过一遍（不许回翻），先做一个无关的干扰任务，再问"记得哪一个画面"。
  3. 两者交集 = 记忆点；只出现在一方的记"弱记忆点"。交集为空 → 本维度 L1。
  4. 核对：记忆点能否在联系表中找到时间码？换一个主题它还成立吗？
- 同构与新鲜度的检查移到 D14；本维度只问"记不记得住、记住的是不是这条片的东西"。

**各级看到什么**
- **L1**：没有记忆点；或者记得的是通用炫技（粒子爆炸、镜头光晕、旋转标志）。
- **L2**：有识别度——看一帧能认出是这条片或这个系列；但说不出具体哪一刻。
- **L3**：至少一个被记住的时刻，并且它从这条片的内容里长出来——换一个主题它就不成立。
- **L4**：被记住的那一刻让观众回看、截图、转发。

**典型 AI 低级感**
- 用"炫"代替记忆点：粒子爆炸、镜头光晕、3D 旋转标志、故障风。
- 结尾套话式互动引导（"你最想……？评论区聊聊"之类）。
- 全片的"亮点"都集中在前 3 秒，之后一处也没有。
- 把"惊艳"理解为堆量：更多元素、更多特效、更快更响。

**回炉**
- 对比与落差 → 《书》第 3 章（3.1、3.2）
- 蓄力与兑现 → 第 10 章（10.1–10.5）
- 有意违反规则 → 各章"故意违反"小节（r5 每章都有；与节奏最相关的是第 2、3、4、9、17、18 章）
- 预期与落空 → 〇 P3
- 最容易被记住的两个位置 → 第 4 章（开场）、第 20 章（结尾）
- 被设计过的时刻放在哪 → 28.4

### D12 形态与平台适配 / 信息负荷

**判断问题**
1. 这条片的形态（解说、口播、角色片、动态海报·循环、发布片）与平台的观看方式对得上吗？竖屏信息流里划到它的人，第一轮能拿到什么？
2. 单屏、单段的信息负荷是否与停留时间相称？流读、停读、纹理在视觉上拉得开吗？
3. 画面是否利用了平台的物理条件：手机竖屏的视距、平台界面占掉的区域、自动循环、静音自动播放？
4. 时长是否符合这个平台、这种形态的观看习惯？

**相关底线**：B-14P 常驻文字读负荷、B-17 平台遮挡区（= 视觉 B-06）、T-07 时长、T-08 画幅；循环接缝按镜 B-06；静音可懂按镜 B-02。本维度不另设 L0 线。
**测量数据**：M-11 单屏独立信息块数、M-19 循环首末帧差。

**各级看到什么**
- **L1**：形态是"拿来的"——横屏思路直接竖排、长文海报直接做成视频；所有信息同一强度一次给出，观众不知道先看哪；静音时核心信息只在声音里。
- **L2**：形态与平台匹配：竖屏信息流里第一轮就能拿到核心一句；信息分层清楚；平台界面区域被主动留空或只放停读内容；时长符合形态。
- **L3**：形态本身在帮信息：循环被利用（第二轮看到第一轮没注意的东西）、竖屏的高度被用来表达顺序或量级、静音时画面独立成立。
- **L4**：形态的选择本身成为记忆点——一次对平台机制（循环、竖向滑动、界面元素）的意外而正确的利用。

**典型 AI 低级感**
- 把一页 PPT 或长图文原样放进 9:16，满屏小字。
- 所有信息块同时出现、同一强度，没有"第一轮看什么"。
- 循环片的末帧与首帧毫无关系，接缝处跳一下。
- 横屏解说片的节奏直接搬到 10 s 竖屏。

**回炉**
- 第一轮先给什么 → 《书》第 4 章
- 注意力预算、信息分层 → 〇 P2、P5，第 24 章
- 读得完、单屏字数 → 第 17 章、第 6 章（同屏单元上限）
- 包装密度 → 第 19 章
- 循环收尾与接缝 → 20.4（循环收尾）
- 观看条件、安全区、小屏 → 第 30 章（30.1 第 4–6 条、30.4 取向）

### D13 角色表演（条件维度）

> 只在片中有拟人角色或人物（主持角色、吉祥物、演示者、拟人化的物体）且出场 ≥ 全片 1/4 时评；否则 n/a。v1 试行，证据 1 条片；v2 仍为试行，按 6.5 累计 ≥ 3 条片证据后转正。与镜头标准同评时，"表演在讲什么"由镜 D11 评，本维度只评"动作本身做得怎样"。

**判断问题**
1. 角色在"演"吗？讲到、指到、被反驳、做判断时，它的身体、视线、表情有对应反应吗？
2. 角色的注意力在哪里，观众的注意力就被带到哪里吗？
3. 动作是从一个起因带动开来的（先动的部位、后跟的部位分得清），还是全身同时同形同幅地动？
4. 接触处（脚踩地、手握物）稳吗？

**相关底线**：角色造成的遮挡、穿帮、口型不同步分别由 B-40、B-10、B-22 判。
**测量数据**：M-20 角色最长无动作时长、角色在代表帧中是第一注视点的比例。

**各级看到什么**
- **L1**：站桩：角色只是一个会换表情的贴图；或者全身同时同形同幅地抖动；讲到重点时身体不动；视线不看它讲的东西。
- **L2**：角色对内容有反应：讲到什么就看向/指向什么；动作有起因和先后；接触处不滑；不讲话时退到次要位置。
- **L3**：角色有性格：同一个"人"的动作习惯贯穿全片；它的反应本身传递信息；观众通过它的反应知道"这里要注意"。
- **L4**：一次表演成为记忆点——一个反应、一个停顿、一次看向观众，让信息在那一刻落地。

**典型 AI 低级感**
- 角色全程站在固定位置，只切换表情贴图。
- 嘴型或身体随音量机械抖动，与语义无关。
- 所有部位同一时刻起、同一时长、同一缓动，像在滑动而不是在动。
- 脚底或手与物体的接触点在动作中漂移。
- 无动机的挥手、跳跃、循环待机动作。

**回炉**
- 机械感的病根、带动链 → 《书》第 29 章（29.1、29.2，r5：带动顺序按动作起因分三种）
- 情绪怎样换 → 29.3；接触处 → 29.4；夸张的下限 → 29.5；媒介一致 → 29.6；做不好角色时 → 29.7；取向 → 29.8
- 动作的预备与落定 → 第 10 章、第 25 章
- 待机时的呼吸与微动 → 18.2 第三端、18.4、18.5
- 物理承载的跟随与余波 → 第 22 章

### D14 创意与新鲜度（单独打分）

**判断问题**：这条片的动法与快慢有没有一个想法？这个想法属于这件内容，还是属于品类？它是不是"不费力就会做出来的那个样子"，或者是排除第一层默认之后人人都会落到的"聪明的第二选择"？

**三个测试**（评审执行，结果写进证据）
- **代入测试**：把最近的同类对象代进这条片的运动设计（它怎么出现、怎么变、怎么停），几乎不用改 → 本维度最高 L2。
- **同构检查**：核心的动法或节奏形状与一个常见模板、一件广为人知的作品、或标杆库与已发布片中的某一处同构（同一想法换皮）→ 本维度最高 L1，注明对照出处。
- **第二层默认识别**：见下。

| 级别 | 看到什么 |
|---|---|
| L1 | 一眼是模板或机器的默认动法；或核心想法与已知作品同构；或命中贯穿的第一层默认（D1–D10、D12、D13 各清单里的那些） |
| L2 | 没有明显默认味，看得出做过选择；但方向本身是这一类片常见的那几种之一，或命中第二层默认 |
| L3 | 方向少见且成立：观众预料不到，而它明显属于这个对象，换成同类另一个对象就不成立 |
| L4 | 方向本身让人惊讶，第一次见到这种动法用在这里，又觉得再合适不过；可以成为别人的参照 |

**第二层默认（命中只扣本维度，不判错）**
- 定义：排除了第一层默认之后，模型稳定落到的同一批"聪明的第二选择"。它们不是错，单独看甚至可能做得好，问题是**不新鲜**：在同一批独立作品里反复出现。
- 识别方式，两条任一成立即算命中：
  1. 落在第二层默认登记表的"动效层"一节里。**五份标准共用同一份登记表** `standards/第二层默认登记表.md`（分层分节，随评审数据增补）。动效层的初始条目来自两轮盲测里的撞车：
     - **"变形 → 停 → 变形"的等长形态序列**：一个主体在几种形态之间轮流变形，每次变形之间停一拍，各段等长、无峰（同批两件连形态的先后顺序都相同）。
  2. 同一批独立作品里，有 ≥ 2 件和它在"动法 + 快慢形状"上被并排分组测试分进同一组（做法：各取每秒 1 帧联系表和 M-01 能量曲线，打乱后请评审分组）；或按镜头标准镜 D12 的"同批差异"三项记为同批结构撞车。
- 处理：命中时本维度最高 L2；能写出它在这件作品里多走了的那一步（使它只属于这件内容），且两位评审都认可时，可到 L3，并把这一步写进证据。
- 不得因为命中第二层默认而降低 D15 或任何其他维度，也不进 B 层。
- 登记表是评审工具；做作品的人能不能看、怎么用，由框架流程决定，本标准不规定。登记表一旦被当成禁用清单，新的重复会出现在别处，所以第 2 条"同批撞车"始终要做，不能只查表。

**回炉**：《书》各章"非默认"取向与"故意违反"小节（它们写的是模型平时不会主动做出来的方向）；第 13 章"出厂味"（13.2 末段）；附录"禁用值自查"。

### D15 执行与完成度（单独打分）

**判断问题**：时间和运动上的每一处是"决定过的"，还是"差一点"？落点和拍、和词对得上吗？停住的位置准吗，有没有落定后又被挪正？同类元素同样子吗？逐格看有没有频闪、跳变、漂移？后半段和前半段一样细吗？

| 级别 | 看到什么 |
|---|---|
| L1 | 能交差但粗：落点普遍晚一点；同类元素样式或动法差一点又不像故意；交接处跳一下；快速位移处逐格看有频闪；明显只打磨了开头 |
| L2 | 时间上和运动上都干净：落点在窗口内，停位准，交接连贯，没有看得出的事故帧；前后一样细 |
| L3 | 逐帧看仍精确：每个承接、每个落点、每个停稳都像被单独打磨过；运动模糊、余波、被带动的细处都在 |
| L4 | 精度本身被观众感到："这是怎么对得这么准的"；细处有第二遍才发现的完成 |

**典型 AI 低级感**：手写时间造成的系统性晚一点；打完时间戳后又剪了音频，后半段全体错位；同一类标题字号或位置差几个像素；复用的组件和原件动法走样；快速位移没有运动模糊而出现重影；接触点在动作中漂移。

**与 D14 分开看**：两轮盲测里两位评审一致发现，"想法好、执行掉链子"和"执行稳、想法默认"经常分在两组作品里，L0 几乎全部来自可修的执行失误。评审必须分别给 D14、D15 级别，并在报告抬头并列；不得因为其中一项高而拉高另一项。

**回炉**：《书》第 31 章（31.2 选哪些时刻、31.3 逐格检查、31.6 机器扫描清单）、22.4（r5 重推：从看得见的错误推出的七条确定性检查）、13.2（复用走样）、26.5（何时要模糊）、27.4（落定后又被挪正）、29.4（接触漂移）、16.1（落点）。

## 3. 判级规则

### 3.1 判级顺序

1. 看一遍，写下记住的画面（≤ 3 条）并封存（D11 协议）。
2. **跑交付技术层**（7.1，全自动）。未过项列入"交付未过"，附修复方法；不中断评审。
3. **跑观众可感层**（7.2，含 1.9 的共用条目）。任一未过 → 整片 **L0**。列出全部未过项与证据；维度继续评，写作"修好后的上限"。
4. **生成测量数据**（7.5 的 M 项），只作证据。
5. **逐维度判级**（L1–L4，或 n/a、未评），每个级别必须附证据时间码。L1/L2 计数口径见第 2 节开头。
6. **按 3.2 合成整片级别**。
7. **L3/L4 候选做两两比较**（3.3）。标杆库不足时停在"候选"，按 L2 合成。
8. **有前一版本时，输出维度差分表**（3.4）。
9. 评审结束后打开评审卡的有意说明，只用来解释 M 项，不改级别。

### 3.2 合成规则

| 整片级别 | 条件（全部满足） |
|---|---|
| L0 | 任一观众可感层底线未过 |
| L1 | 观众可感层全过，但不满足 L2 |
| L2 | 全部适用维度 ≥ L2；D11、D14 可以是 L1 |
| L3 | 全部适用维度 ≥ L2；D14 ≥ L3；D11 ≥ L3；L3 及以上的维度 ≥ 适用维度数的一半；两两比较确认（3.3） |
| L4 | 满足 L3；D14 = L4，且至少再有 1 个维度 L4；两两比较确认；用户本人确认"惊艳"（6.3）。缺用户确认时只记"L4 候选" |

补充规则（优先于任何平均印象）：
- **交付层不进合成**：只在抬头单列。
- **n/a**：不适用的维度（单镜头片的 D5、无角色片的 D13、无声片的 D6/D7）不参与合成，也不计入适用维度数。
- **未评**：按 1.8，整片写 "≤X（待 Dn 补评）"。
- **候选**：L3/L4 候选在合成中按 L2 计。
- **短板封顶**：D4 或 D10 任一为 L1 → 整片最高 L1（看不懂、读不完的片不是商业合格）。D14 为 L1 → 整片最高 L2，且不进 L3 候选。
- **最低级决定上限**：除 D11、D14 在 L1 时的豁免外，整片级别不高于"最低适用维度 + 1"。
- **D15 不豁免**：执行与完成度为 L1 时照常适用"最低 + 1"，整片最高 L2；不得因创意高而抬高。
- **与目标对照**：整片级别 < 评审卡目标级别 → 回炉。回炉单只列"拖住目标级别"的维度，按差距从大到小排列。"≤X" ≥ 目标时记"有条件达标，待补评"。

### 3.3 两两比较

- **对照选取**：从标杆库取同形态、同时长档（±50%）、同平台的片；L3 候选对照 3 条 L3 标杆，L4 候选对照 3 条 L3 标杆 + 至少 1 条 L4 标杆。
- **盲比**：去掉片头片尾标识，随机左右顺序。
- **一次只问一个维度**："在 Dx 上哪一条更好？证据时间码是？"对标杆的盲比必须二选一，不允许"差不多"。
- **确认口径**：L3 = 对 L3 标杆胜 ≥ 2/3；L4 = 对 L3 标杆全胜，且对 L4 标杆不输。
- **评审分歧**：两名评审差一级取低者；差两级及以上，引入第三名评审，取中位。

### 3.4 版本对比：维度差分表

整片级别常常因为封顶和短板不动，所以**维度差分表是正式输出**，与整片级别并列。

| 维度 | 旧版 | 新版 | 变化 | 证据（时间码） |
|---|---|---|---|---|
| Dn | L? | L? | 升 / 降 / 平 / 平（同级改进） | … |

- 允许"平"。3.3 的"不允许差不多"只用于对标杆的盲比，不用于版本对比。
- 另列两行：观众可感层未过项的增减、交付技术层未过项的增减。
- 结论写清：哪几个维度变好、哪几个没动、整片级别为什么动或不动。D14 和 D15 的变化分开写。

## 5. 样稿内容口径

与视觉标准第 5 节（持有方）、镜头标准第 5 节同一口径，本标准不另设，这里只列要点和动效特有的情况：

- **事实不编，样稿要填**：真实品牌的数据、真实人物、真实客户、真实证言、真实产品能做到什么，不得编造；编造按 B-13（= 视觉 B-10）、B-37（= 视觉 B-11）判 L0。
- **明显是示例的虚构内容不算编造**：虚构的名称、日期、价格、演示数据，只要不冒充真实对象，都算样稿内容，在评审卡"样稿示例内容清单"列出即可。
- **留空的算未完成**：空白填写栏、占位线、"此处放素材"、空着的证据框、占位音轨，按 B-43（= 视觉 B-08）判 L0（评审卡注明"内部稿"且空位写明"待补"的除外）。
- **决定类内容**（范围与判别问按需求理解标准需 B-06）即使填了示例，也要在评审卡"发布前须用户确认"一栏列出；评审者在报告末尾照录，未列出的补列，不扣分。
- **动效特有**：计数器、进度条、生长动画的终值必须与画面上写的数一致，中途值与终值的比例关系不得误导（B-37）；示例数据在动画中途被截图时也要读得出是示例（标注按视觉标准第 5 节"贴着数据本身"）。

## 6. 标杆库规范与标准修订

### 6.1 规则

- 标杆**只给评审看，不给做作品的人看**。存放：`standards/标杆/动效.md`（待建）。
- 每件标杆一条记录：ID（`A-<级别>-<序号>`）；来源（只作内部记录，任何成片、封面、文案中不得出现来源或作者 ID）；形态 / 平台 / 时长 / 画幅；整片级别 + 各维度级别（未评留空）；**为什么是这个级别**（必须指向时间码上的可观察现象，例如"00:14 三个数字依次从同一个点长出，读的顺序就是出现顺序"；不允许只写"高级""有质感""节奏好"）；正例或反例；入库人 / 日期 / 是否经用户确认。
- 正例尽量配一件同形态的反例，组成比较对。
- 另收**维度切片**：整体 L2 的片，若某一段在某个维度达到 L3/L4，截取该段作为单项标杆，记起止时间码。
- 只收成片或可重放版本，不收截图。单帧版式交给视觉标准的标杆库，叙事结构交给镜头标准的标杆库。
- 标杆里的取向要分散：同一级别的锚点不得都落在同一种取向上（例如 L3 正例全是"有起伏"的、没有一件是"刻意的平"或"全平"做成的），否则标杆本身会替一种取向判分；暂时凑不齐时在库首写明"某取向缺锚点"。

### 6.2 每级放什么

| 级别 | 放什么 | 最少条数 | 标注重点 |
|---|---|---|---|
| L0 | 每条 B 底线（含共用条目）的实例 | 每条 ≥ 1 | 哪条底线、时间码、测量值 |
| L1 | 无错但默认的片，含同批撞车组 | ≥ 5 | 命中了哪些维度的哪几条低级感；撞车对象 |
| L2 | 挑不出错、看一遍就懂、说不出"那一下"的片 | ≥ 5 | 为什么挑不出错；离 L3 差什么 |
| L3 | 能复述出某一个时刻、换题就不成立的片 | ≥ 5 | 记忆点时间码；挪动或删掉它为什么会变差 |
| L4 | 用户亲口说"惊艳"的片段 | ≥ 3 | 意外在哪里；为什么事后看是对的；用户原话 |

### 6.3 用户判断与第一批锚点

- 用户说"惊艳""这个好"的片段，原话 + 时间码直接入库为 L4（或对应维度 L4），不需要用户给理由；标准判级与用户判断冲突时**用户判断胜**，记录冲突，找出标准漏掉的观察，进入修订（6.5）。用户说"一般""没感觉"的同样入库，作 L1/L2 校准。

### 6.4 爆款数据轴（独立于质量分级）

"爆款"由选题、钩子、发布时机、平台分发决定，**不混入质量级别**：不因为爆了升级，也不因为没爆降级，只用来校准质量标准是否看漏了东西。
- **采集**（发布后 7 天）：播放量、平均观看时长 ÷ 片长、3 s / 5 s 留存、留存曲线、完播率、互动率、涨粉 ÷ 播放；B 站另记弹幕密集时间码。
- **校准用法**：① 留存断崖时间码对到时间线表，断崖处所有维度都判"没问题"→ 标准漏项；② 回看点、弹幕密集点 ↔ D11 记忆点；③ 同账号同题材 ≥ 5 条样本后，才比较级别与观看时长比；④ 任何从数据得出的修订，必须能写成"观众看到了什么"，不得写成"某种取向的数据更好，所以要求它"。

### 6.5 修订流程

1. **记录**：每次评审输出、每次用户判断、每条片的 7 天数据，存入评审日志。
2. **触发**：累计 10 条新评审；用户推翻判级 ≥ 2 次；数据校准发现漏项；同一种新的 AI 低级感在 ≥ 3 条片中出现；《书》升版（节号过期，按流程纪律第 8 条拿映射表更新回炉）；任一共用条目的原标准改了阈值（同轮对齐，流程纪律第 5 条）。
3. **修订内容**：补充或改写 L 级现象、低级感清单、M 项；"待实验"阈值有 ≥ 5 条证据时可改为"校准值"并注明证据；新增维度需 ≥ 3 条片证据。
4. **版本**：改前先用脚本把旧版复制到 `standards/archive/动效-<版本>-<日期>.md`；文件头写依据的《书》版本；文末修订记录写明改了什么、依据什么。改动记入 `framework/CHANGELOG.md`。
5. **不变的东西**：标准始终只评观众一侧的效果；任何修订若开始规定手法或参数，或开始给某一种取向加分扣分，退回改写。
