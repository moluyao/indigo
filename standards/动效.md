# 动效视频质量标准 v1 · 青出 / Indigo

> 回答一个问题：一条动效/动画视频，什么叫坏、能用、商业合格、精品、惊艳。
> 本标准评的是**观众这一侧的效果**，不规定手法和参数。手法和参数的出处是《动效节奏》（`craft-lib/03-book/动效节奏.md`，下文简称《书》），本标准只负责判级，并在不达标时把人指回《书》的章节。
> v1 依据 4 条片的试评（`standards/trial/summary.md`）修订，逐条改动见文末"v1 修订记录"；v0 原文存于 `standards/archive/动效-v0.md`。

---

## 1. 总则与用法

### 1.1 五个级别

| 级别 | 名称 | 一句话 | 观众的反应 |
|---|---|---|---|
| L0 | 坏 | 有观众看得见/听得出的错误：任一**观众可感层**底线没过 | 出戏、皱眉、划走，或根本读不完、听不清 |
| L1 | 能用 | 没有错误，但处处是"默认值"，一眼能认出是机器/模板做的 | 看完了，没感觉，说不出它和别的片有什么区别 |
| L2 | 商业合格 | 可以交付给付费客户：信息清楚、节奏不拖、质感统一，挑不出硬伤 | "挺专业的" |
| L3 | 精品 | 每个选择都是有意的，删掉或换掉任何一处都会变差；至少有一个记忆点 | 看完能复述出某一个画面或某一下 |
| L4 | 惊艳 | 意外但正确：出现了观众没预料到、事后又觉得"只能这样"的处理 | "这个怎么做的？"、回看、转发给别人看那一下 |

- **L0 与 L1 的界线是"错"**，可用脚本和抽帧判定（第 6 节）。只有观众可感层的错才判 L0；交付技术层（色彩标签、响度、编码……）不达标记"交付未过"，与作品级别分开报告（1.2）。
- **L1 与 L2 的界线是"默认"**，靠每维度的"AI 低级感清单"逐条勾选判定，计数口径见 3.1 第 4 步。
- **L2 以上无法写成规则**，只能用标杆片参照 + 两两比较判定（第 3、5 节）。本标准对 L3/L4 只描述"看到什么"，不给配方；给了配方，它就会变成下一个 L1。

### 1.2 三层：交付技术层、观众可感层、上限层

| 层 | 管什么 | 怎么判 | 不过怎么办 |
|---|---|---|---|
| 交付技术层（T-xx） | 导出参数：色彩元数据、整体响度、真峰值、帧率、音视频流对齐、编码与封装、时长/画幅规格 | 全部脚本机械判定（`tools/check_floor.py` 的 `delivery` 段） | 记**"交付未过"**，并标明"可自动修复"或"需回工程"；脚本给出 ffmpeg 修复命令。**不把作品质量判为 L0**，不影响上限层评审；但交付未过的片不得发布 |
| 观众可感层（B-xx） | 观众看得见、听得出的错：读不完、看不见、被遮挡、穿帮、不同步、闪烁、削波、空开头、拖尾…… | 脚本 + 抽帧 + ASR/OCR + 人工 | 判 **L0**，回炉；上限层仍可评，作为"修好后的上限"写进报告 |
| 上限层（D1–D13） | 好不好、有没有意图、记不记得住 | 标杆参照 + 两两比较 + 评审者陈述证据 | 给出级别与差距，指回《书》章节 |

**判别一项检查属于哪层**：问"不重新做画面/声音设计，只改导出参数或跑一条命令能不能修好？"能 → 交付技术层；不能 → 观众可感层。超目标时长（T-07）、画幅不符（T-08）虽不能自动修复，也是对规格的核对而非观众可感的错，归交付层并标"需回工程"。

报告抬头必须同时写三件事：**交付层状态**（通过 / 未过：可自动修复 / 未过：需回工程）、**观众层状态**（通过 / 未过）、**整片级别**。例："整片 ≤L2（待 D6/D7 补评）｜观众层通过｜交付未过（T-01，可自动修复）"。

每个维度另有**预警项**：可测，但超标不一定是错（可能是有意为之）。预警项触发时，制作者须在评审卡附带的"有意说明"里写一句"这是有意的，因为……"；写不出理由即按观众可感层底线未过处理。

### 1.3 评审卡：做片前定目标，交付时附卡

制作者交付成片时附一张**评审卡**（`card.json` 或卡片式 markdown，≤ 10 行）。评审者只读这张卡，不读脚本、工程、制作对话。

| 字段 | 说明 | 用于 |
|---|---|---|
| 目标级别 | 例："L2，D11 争取 L3" | 3.2 与目标对照；决定评审强度（L2 只需底线 + 清单；L3 以上必须两两比较） |
| 目标时长 | 秒；可写区间 | T-07 |
| 平台 / 形态 | 平台（B 站横屏、视频号竖屏、网页、广播……）+ 形态（解说片 / 口播片 / 角色片 / 动态海报·循环 / 发布片……） | T-02 响度目标、T-08 画幅、B-17 平台蒙版、B-14 读速口径（1.7）、D12 |
| 核心信息一句话 | 观众看完应带走的 1 句（可附 ≤ 2 条次要信息） | B-36 复述测试、D10 |
| 需读文字范围 | 哪些文字是"须读"、哪些是"可略读"（1.6） | B-13/14/16/18、D4 |
| 有意说明（密封） | 对可能触发的预警项的说明 | 评审结束后才打开（1.4） |

- **目标级别不能低于 L2 交付**。L1 片只用于内部草稿。
- 一条片不必每个维度都冲高；但**任一维度低于目标级别一级以上**，整片不得按目标级别验收（见第 3 节）。
- **评审卡缺失时**：评审者从成片内容推断各字段，逐项标"（推断）"，并在报告中单列"推断的评审卡"；推断不得用于豁免任何底线（例如不能推断"这是有意的"）。目标时长无法推断，T-07 记"人工/仅报实测"。

### 1.4 评审者与制作者分离

- 评审者不是制作者，**只看成片 + 评审卡**，不看脚本、工程文件、制作过程，不听制作者额外解释。制作者的意图只能通过画面、声音和这张卡传达；评审时解释不了的东西，观众也接收不到。
- 评审者为 agent 时，必须是独立会话/独立 agent，不继承制作会话的上下文。
- 评审卡中的"有意说明"在评审**结束后**才打开，用于判断预警项是否豁免，不得用于改变上限层的级别判断。

### 1.5 评审只看三件材料

评审者从成片生成以下三件材料，全部判断都要能指回其中某一处（时间码或帧号）：

1. **抽帧联系表**：每秒 1 帧 + 每个**段落边界**前后各 1 帧，平铺成图。
   `ffmpeg -i in.mp4 -vf "fps=1,scale=320:-1,tile=6x5" -vsync vfr sheet_%02d.png`
   段落边界 = 硬切点 ∪ 软边界。硬切点用帧差尖峰或 `select='gt(scene,0.3)'`；软边界（虚化、推拉、溶解、镜头运动换版）用 0.5 s 间隔帧差 `|y(t) − y(t−0.5 s)|` 的局部峰（`check_floor.py` 输出 `meta.boundaries`，type=hard/soft，软边界附过渡区间起止）。场景检测检不出边界时，以时间线表人工标注的段落边界为准。
2. **逐段时间线**：一张表，行 = 段落，列 = 起止时间码、本段一句话信息、画面事件（边界、新文字、新元素）、语音（ASR 逐词时间戳）、音乐/音效落点、能量粗估（E0–E5，见《书》〇节术语）。
3. **音频测量**：整体响度、短时响度曲线、真峰值、静音区间、声音瞬态时刻、人声与音乐的分轨或估计电平（命令见 D7）。

**必备工具**：ffmpeg/ffprobe、`check_floor.py`、**带词级时间戳的 ASR**（如 whisper 词级时间戳）、OCR。缺 ASR 时，依赖"新词"的检查（B-04、B-24、B-27、B-28）记"未评"，不得用静音代替后判通过。

评审先跑脚本（交付层 + 观众层自动项），再做观众层人工项，再逐维度判级，最后按第 3 节综合判级，输出第 4 节模板。

### 1.6 文字的三类："须读 / 可略读 / 装饰"

B-13、B-14、B-16、B-17、B-18、D4 都依赖"须阅读文字"。v1 定义如下：

| 类别 | 定义 | 典型 | 适用检查 |
|---|---|---|---|
| **须读** | 观众不读它就带不走核心信息，或会误解 | 标题、要点、结论、关键数字与其单位、字幕、对比框的判断词、免责/"还不是药"这类改变理解的限定语 | B-13、B-14、B-16（≥4.5:1，大字 ≥3:1）、B-17、B-18（≥ 短边 2.5%）、B-40 遮挡即未过 |
| **可略读** | 读了更好、不读也不误解核心信息 | 图内标注、图例细项、英文眉标、脚注、出处、进度节点小标签、计数器 | B-13（不得有错）、B-16（≥3:1）、B-18（≥ 短边 1.8%，起点值）；不计入 B-14 读速；被遮挡/裁切记预警 |
| **装饰** | 不预期被读，作为纹理或造型 | 背景字纹、大面积排版肌理、logo 字形 | 只查不抢主焦点（D3）与无错字（若可辨认） |

**判别方法（遮住测试）**：在代表帧上遮住这块文字，问"只看剩下的，复述测试还能命中核心信息吗？会不会误解？"命中且不误解 → 可略读；否则 → 须读。评审卡写了"需读文字范围"时先按卡执行；评审者若用遮住测试发现卡上标"可略读"的文字其实承载核心信息，按须读处理并在报告中写明。

### 1.7 形态条款：时序文字与常驻文字

- **时序文字**（解说片、口播片、发布片的多数文字）：按 B-14 的停留时长口径（落定帧 → 退场开始帧 ≥ 字数 ÷ 9 字/s，且 ≥ 5/6 s）。
- **常驻文字**（"动态海报 / 循环"形态：全片单镜头或少数镜头、文字整片常驻、平台自动循环）：不按单块停留判，改按**读负荷**判（B-14P）：
  1. **首轮核心**：标题与核心判断等"首轮须读"文字 ≤ 7 字/s × 片长（起点值；7 字/s 取 Netflix 儿童读速，用来抵消海报文字"要先找到"的成本），且在第一轮内处于最高视觉层级、无遮挡。
  2. **总须读**：全部须读文字 ≤ 7 字/s × 片长 × 2（起点值；假设信息流里观众最多看第二遍）。
  3. 可略读文字不计入，但必须在视觉上明显低于须读层（字号、字重或色彩至少一项拉开）；拉不开 → 视为须读。
  - 形态必须写在评审卡里；卡缺失时评审者按成片推断并标"（推断）"。一条有配音、有段落推进的片，不得以"海报"形态申请本条款。

### 1.8 未评维度

- 评审者无法取得某维度的证据时（例如 agent 不能听声音、没有 ASR），该维度记**"未评"**，不得估级（v0 的"估 L2"作废）。可附"测量提示"（如"LRA 0.3，配乐能量恒定，补评重点"），但提示不进入合成。
- 合成时把未评维度视为"不限制上限"，按其余维度算出 X，整片写成 **"≤X（待 Dn 补评）"**。补评后按 3.2 重新合成，只可能等于或低于 X。
- 与目标对照时，"≤X" 只算"有条件达标"：发布前必须补评。
- agent 评审的最低声音证据：整体/短时响度、LRA、静音区间、声音瞬态、ASR 词级时间戳与置信度。有这些可评 B-24、B-27 和 D6 中"内容错位"一项；语气、音色、混音层次仍需能听的评审者。

## 2. 维度

每个维度按同一结构写：**判断问题 → 底线阈值（含测量方法）→ 预警项 → L1–L4 可观察特征 → 典型 AI 低级感 → 回炉方向（《书》章节）**。阈值中标注"起点值"的，是自定、待标杆片与播放数据校准的数；标注出处的，是外部客观规范。底线阈值中凡属导出参数的，v1 已移入第 6.1 节交付技术层（T-xx），维度内只留指针。v1 新增 D12（形态与平台适配 / 信息负荷）与 D13（角色表演，条件维度：片中有角色才评）。

### D1 节奏与时长

**判断问题**
1. 每一段是否在它的信息讲完后就离开——既不拖，也不在没讲完时就走？
2. 全片有没有落差？看完闭眼回想，能否指出哪里是峰、哪里是谷？
3. 开场窗口内，观众是否已经知道"这是什么、为什么要看下去"？
4. 有没有"什么都没发生"的时间？

**底线阈值**
- **时长不超目标**：属交付层规格核对，见 T-07（不判 L0；超时回工程）。
- **开头窗口有内容**（B-02）：首个"有内容帧"（非纯色：亮度标准差 ≥ 4 @96 px 缩略，或与第 0 帧差异 ≥ 2）出现在 **0.5 s 内**通过；0.5–1.0 s 预警（须有意说明）；> 1.0 s 未过（起点值）。从 0 开始的黑场按同一窗口计。第 0 帧本身为空、但窗口内出现内容的，不再判未过（第 0 帧作封面的问题归封面，不归成片）。
- **开头不冻结**（B-03）：`freezedetect` 不得报告从 0 开始、长于 1 s 的静止区间（起点值）。
- **无死时间**（B-04）：死时间 = 画面无变化（`freezedetect=n=0.003:d=0.5`）且同时无新语音（ASR 无新词）的区间。未过 = 任一死时间 > 全片平均事件间隔 × 2，**或 > 3 s（绝对上限，起点值，防止幻灯片式片子用长停留拉大平均间隔而自我放宽）**。事件 = 段落边界 ∪ 新文字出现 ∪ 新元素出现 ∪ 新句起点，从时间线表统计（口径同《书》第 5 章）。时间线上标注为"有意停留"且该停留后紧接一个落点的，转为预警项。无 ASR 时脚本只给"冻结 ∩ 静音 ≥ 1 s"与"冻结 ≥ 3 s"两类候选，正式判定记"未评"。
- **结尾无尾巴**（B-05）：片尾"黑场 ∩ 静音"> 0.5 s 未过；片尾"停帧（任意底色）∩ 静音"> 2.0 s 未过、0.5–2.0 s 预警（起点值）。末屏有须读文字且其 B-14 读时尚未满足的，停帧中用于读完的部分不计入。
- **音乐不被硬断**（B-06）：有配乐时，片尾音乐不得在乐句中途被截断（人工听最后 3 s；或检测末 50 ms 内 RMS 骤降而无淡出/尾音）。

**预警项**
- 段落时长的变异系数过低（各段几乎等长）。
- 全片运动能量曲线（逐帧帧差均值：`ffmpeg -i in.mp4 -vf "tblend=all_mode=difference,signalstats,metadata=print:key=lavfi.signalstats.YAVG" -f null -`）几乎是一条平线，或者处处都是峰。
- 开场窗口内没有出现第一个信息落点。

**各级可观察特征**
- **L1**：段落一段接一段，长短差不多；每句话配一个画面变化，句句一样；能看完，但说不出哪里是高潮。
- **L2**：有明显的起伏，至少一个峰、一处喘息；没有拖沓段；开头几秒就进入正题；结尾收得住，不是"内容讲完了就停"。
- **L3**：起伏的位置与内容的重量对齐——最重要的信息落在峰上，喘息出现在观众需要消化的地方；快慢对比让观众"感到"节奏，而不只是"看到"剪辑；时长恰好，删掉任何一段都会断。
- **L4**：节奏本身制造了意义——一次出乎预料的停顿、提前或落空，让观众在那一刻被抓住；回看时发现整片的能量形状是为这一刻铺的。

**典型 AI 低级感**
- 每段等长、每段都是"标题入场 → 停留 → 退场"同一套流程。
- 全片同一速度，无论内容轻重。
- 开头标题或 logo 慢慢淡入，前几秒没有信息。
- 结尾"感谢观看 / 关注我"淡出，或者内容讲完画面直接停在最后一帧。
- 处处都是高潮：每一句都配冲击音效和放大，于是没有一句是重点。
- 音乐从头到尾同一能量，片子在音乐中途硬断。
- 列表式内容（第一、第二、第三……）每一条用完全相同的时长和动作，第三条时观众已经能预测一切。

**回炉方向**
- 不知道时间从哪来、节奏飘 → 《书》第 1 章（主时钟）
- 全片平、没峰没谷 → 第 2 章（整片能量形状）、第 3 章（对比）
- 开场慢、留不住人 → 第 4 章（开场窗口）
- 死时间、拖 → 第 5 章（死时间与事件计数）、第 6 章（让片子更快）
- 切得太碎或太闷 → 第 8 章（剪辑频率）
- 高潮没力量 → 第 9 章（爆发段内部）、第 10 章（蓄力与冲击）
- 段落之间没有区分 → 第 11 章（段落边界要变多少）
- 结尾收不住 → 第 20 章（结尾）

### D2 运动质感

**判断问题**
1. 东西动起来像有重量、有材质吗？大的和小的、重的和轻的，动起来有区别吗？
2. 每一次运动，评审能不能说出"它像什么在动"（被推、落下、被拉走、沉入……）？
3. 停下时是"落定"，还是"卡住"、"抖完才停"？
4. 画面静止时，是在呼吸，还是死成一张 PPT？

**底线阈值**
- **帧率恒定**：属交付层，见 T-04。
- **运动中无卡顿**（B-08）：在时间线标为运动的区间内，`ffmpeg -i in.mp4 -vf "mpdecimate,showinfo" -f null -` 统计被判为重复的帧；连续运动中出现 ≥ 2 次单帧冻结（前后帧都有位移、中间一帧不动）→ 未过。
- **无闪帧/坏帧**（B-09）：逐帧帧差序列中出现孤立尖峰（某一帧帧差远高于前后各 2 帧，且该处不是段落边界）→ 抽出该帧人工确认；确认为渲染瑕疵（元素缺失、错位一帧、透明边闪烁、半帧残影）即未过。**冲击帧豁免**：同时满足 ①突变帧 ±0.25 s 内有声音瞬态、②人工一眼确认该帧是落点元素的冲击（砸下、闪白、震屏、放大一帧），记"冲击帧"、不算坏帧，无需等 B-39 有意说明；该瞬态与冲击帧的时差另交 B-23 判同步。
- **无渲染硬伤**（B-10、B-40）：联系表与边界帧中不得出现锯齿边、被裁掉一半的元素、元素意外穿插遮挡、纹理拉伸。静态遮挡与裁切统一登记为 B-40。

**预警项**
- 不同尺寸元素的入场时长几乎相同。
- 全片只出现一种缓动形状（评审观察：所有运动都是"慢起慢停"或都是"弹一下"）。
- 运动段落结束后整屏长时间完全静止（帧差为 0）。

**各级可观察特征**
- **L1**：运动无错误，但所有元素像在同一条轨道上滑，起停方式一样、时长一样；或者每个元素都弹一下。
- **L2**：大元素与小元素、主角与配角的运动明显不同；落定干净，没有多余的抖；入场和退场不是同一个动作倒放；静止时画面不死。
- **L3**：全片有一致的"物理人格"——观众能感到这个世界里的东西有统一的重量与阻力；每一种运动都在说一件事（出现、让位、被推开），没有为动而动；细小处（停住后的微动、跟随、余波）都在。
- **L4**：观众记住的是某个东西"怎么动的"；运动本身成为表达，换一种动法这个画面就不成立。

**典型 AI 低级感**
- 匀速直线位移，起停无加减速。
- 全片一条缓动曲线、一个时长，所有元素一模一样地"滑入"。
- 处处回弹：每个卡片、每个字都弹一下过冲。
- 从 0 缩放到 1 的"弹出"，无论元素大小。
- 无动机的旋转入场、无动机的 3D 翻转。
- 整屏持续缓慢放大，从头放到尾。
- 停下后完全静止，像幻灯片翻页；或者反过来，所有元素都在无意义地漂浮、晃动。
- 粒子、光斑在背景里持续飘，与内容无关。
- 入场与退场是同一动作倒放。

**回炉方向**
- 入场语气、曲线、时长 → 《书》第 13 章（13.1 先推什么、13.2–13.4 三种取向）
- 退场 → 第 14 章
- 多元素一起动时乱 → 第 15 章（错峰）
- 停住时死或乱动 → 第 18 章（呼吸，含 18.5 分层流畅度）
- 需要重量、碰撞、群体运动 → 第 22 章（物理与生成）
- 参数自查 → 第 23 章速查表、附录禁用值自查
- 拟人角色、人物的动作与反应 → 不在本维度，见 D13

### D3 层级与视线引导

**判断问题**
1. 任取一帧：观众第一眼落在哪、第二眼落在哪？与这段要传达的东西一致吗？
2. 同一时刻，是不是只有一个"主角"在争取注意？
3. 新元素出现时，眼睛来得及到达吗？还是出现在视线刚离开的地方？
4. 强调手段是否稀缺——重点是不是真的比别处突出？

**底线阈值**
- **三秒注视测试**：从联系表取每段代表帧，给 1 名未看过脚本的测试者每张看 1 s 后遮住，问"你先看到了什么"。与该段意图焦点不一致的段落 ≥ 1/3 → 未过。（agent 评审时：由独立 agent 只看单帧回答，同口径计数。）
- **主焦点唯一**：联系表上每个镜头都能指出一个主视觉焦点；有任何镜头评审者指不出（两个以上同等强度的焦点争夺）→ 未过。
- **关键元素不被遮挡**（B-40）：主焦点与须读文字不得被装饰元素、印章、图例、字幕、画框裁切或平台界面遮挡（平台界面见 D4、D12）。可略读文字被压记预警。

**预警项**
- 同一帧内使用 ≥ 3 种强调手段（颜色 + 发光 + 放大 + 抖动……）叠在同一元素上。
- 同一时刻启动的独立运动对象过多（帧差热区数量突增）。
- 视线跨越距离过大：相邻两个落点分别在画面两端且间隔很短。

**各级可观察特征**
- **L1**：信息都在，但平铺；每个元素同等大小、同等亮度，或者每个都被强调；眼睛要自己找。
- **L2**：每一帧都有清楚的主次；眼睛按设计的顺序走，不迷路；强调只给真正的重点。
- **L3**：视线被"带着走"——上一个落点的位置和方向自然引向下一个；元素出现的先后就是阅读的先后；画面留白在帮忙指路。
- **L4**：视线引导制造了惊喜——观众的眼睛被精确地带到一个位置，然后答案在那里出现（或刚好在别处出现）；回看时发现每一处构图都在为这一刻服务。

**典型 AI 低级感**
- 所有元素在同一时刻一起淡入。
- 处处发光、处处描边、处处渐变，于是没有重点。
- 卡片网格平铺，全部同尺寸、同色、同时出现。
- 字号只有两档（大标题 + 小正文），中间层级缺失。
- 装饰粒子、光效、背景纹理比主体还抢眼。
- 一个重点同时加颜色、发光、放大、抖动四重强调。
- 新元素出现在与上一个落点相反的角落，视线左右横跳。

**回炉方向**
- 第 0 帧没有落脚点 → 《书》第 4 章
- 视线到达、落点时间、主次与组织 → 第 13.1 节、第 13.5 节
- 多元素出现顺序 → 第 15 章（错峰）
- 画面与声音谁先吸引注意 → 第 16 章

### D4 文字可读性

**判断问题**
1. 每一块文字，普通观众在它停留的时间里能不能读完？
2. 在手机屏幕上、在它实际的背景上，看得清吗？
3. 文字有没有被平台界面、字幕、装饰挡住？
4. 屏幕文字与配音是在互相帮忙，还是在抢同一份注意力？

**底线阈值**（"须读 / 可略读"按 1.6 判别）
- **零错字**（B-13）：OCR 全片文字（每 0.5 s 抽 1 帧）+ 人工校对；须读与可略读文字中的错别字、错数字、事实错误任一处 → 未过。
- **停留够读**（B-14）：时序文字——每一块须读文字，从**落定帧**（入场动画结束、不再移动）到**退场开始帧**的时长 ≥ 字数 ÷ 9 字/秒，且 ≥ 5/6 s。依据：Netflix 简体中文字幕规范的成人读速上限 9 字/秒、单条最短显示 5/6 s。动效文字通常还要先被找到（无固定位置），所以这是底线而非目标；设计值按《书》第 17 章算。测量：OCR 逐帧求每块文字的出现与消失时间（或由评审卡附文字事件表，评审者抽查）。常驻文字 / 动态海报形态按 1.7 的读负荷口径（B-14P）。
- **字幕行长**（B-15，仅字幕类文字）：简中每行 ≤ 16 字（Netflix 简中规范）。
- **对比度**（B-16）：须读文字色与其实际背后像素的对比度 ≥ 4.5:1，大字（≥ 24px 常规或 ≥ 18.66px 粗体的等价尺寸）≥ 3:1（WCAG 2 SC 1.4.3）；可略读文字 ≥ 3:1。动态背景取文字**停留期**内最差的一帧。测量：取文字 bbox，分离笔画像素与背景像素，各取亮度中位数算相对亮度比。
- **过渡态可见不可读**（B-41）：入场/退场过程中，文字已可见但不可读（先于衬底出现、白字压浅底、半透明叠在另一段文字上）的持续时长。≥ 3 帧记预警（D4 扣分）；> 0.5 s，或过渡态里出现可读但错位/重叠成乱码的文字 → 未过。停留期从"可读"开始计，不从"可见"开始计。
- **安全区**（B-17）：须读文字与关键图形全部落在 EBU R95 图形安全区内（16:9 每边 5%；1920×1080 下约左右 96 px、上下 54 px）。竖屏或在带界面的平台发布时，另用目标平台播放界面截图做遮挡蒙版，须读文字不得落在标题栏、按钮列、评论/字幕区内（平台无公开规范，蒙版以实测截图为准，每季度更新一次）。
- **最小字高**（B-18）：须读文字字高 ≥ 画面短边的 2.5%（约 27 px @1080）；可略读文字 ≥ 1.8%（约 19 px @1080）（均为起点值，以手机实机观看校准）。

**预警项**
- 同屏须阅读字数过多（起点值：> 2 行或 > 30 字）。
- 文字在运动未落定时就承载了必须读的信息。
- 屏幕文字与此刻配音内容不同但都需要理解（双通道冲突）。
- 字幕与画面大字重复同一句话。

**各级可观察特征**
- **L1**：读得完、看得清，但字体、字重、排版是默认的；文字是"放上去的"，与画面无关系；配音说什么屏幕就写什么。
- **L2**：层级清楚（标题、要点、注释一眼可分）；每块文字在落定后才需要读，读完才走；关键词被恰当突出；与配音分工——屏幕给关键词，配音给完整句。
- **L3**：文字本身是画面的一部分：排版、字体、出现方式都带着这条片的性格；读的节奏就是看的节奏；观众不觉得自己在"读"。
- **L4**：一处文字处理让人记住——字的出现、变形或位置本身在说话，读到的那一刻产生"原来如此"。

**典型 AI 低级感**
- 每个字逐个打字机出现，无论内容长短。
- 文字一出现就开始漂浮、晃动，读的时候还在动。
- 半透明白字压在亮背景或花背景上。
- 渐变色字 + 描边 + 投影 + 发光叠满。
- 把配音稿全文照抄到屏幕上。
- 中英文、数字字体不统一，或全片只有一种默认黑体常规体。
- 一句话读到一半就退场，或退场与下一句入场挤在一起。
- 关键词逐字跳动、逐字变色。

**回炉方向**
- 停留时长、读速、起步成本 → 《书》第 17 章（读得完的停留）
- 字高与位移尺度 → 第 13.1 节（字高 h）
- 文字与配音谁先 → 第 16 章
- 口播片文字包装多少 → 第 19 章（口播片的包装密度）

### D5 转场

**判断问题**
1. 每一个转场都在说"这里换了一件事"吗？转场的幅度与内容变化的幅度相称吗？
2. 转场有没有占用观众本该用来看内容的时间？
3. 转场是否把上一段的视线落点交接给下一段，而不是让眼睛重新找？

**底线阈值**（检查对象是**段落边界** = 硬切点 ∪ 软边界，见 1.5）
- **无穿帮**（B-10）：硬切取切点前后各 10 帧逐帧检查；软转场（虚化、推拉、溶解、镜头运动换版）取过渡区间的**起、中、止三帧 + 区间内最糊/最乱的一帧**检查，并把过渡区间按 0.1 s 步长抽一条小联系表。不得出现空白帧、元素未加载、上一镜头残留、错位一帧、过渡中途出现不该出现的层。
- **无非设计黑闪**（B-19）：`ffmpeg -i in.mp4 -vf "blackdetect=d=0.02:pix_th=0.10" -an -f null -` 报告的黑场若落在任一段落边界 ±0.5 s 内且时间线未标注为有意设计 → 未过。
- **不抢走文字**（B-20）：过渡开始时（软转场取过渡区间起点），画面中须读文字已满足 D4 停留时长；不满足 → 未过（D4 与 D5 同时记录）。
- **闪烁安全**：见 D8（转场是闪烁超标最常见的位置）。
- 全片无任何段落边界（单镜头海报）时，D5 记 n/a。

**预警项**
- 全片转场只有一种，且为交叉淡化。
- 转场种类数 > 段落数的一半（花样过多）。
- 转场总时长占全片比例过高（起点值 > 10%）。
- 每个转场都配同一个"嗖"声。

**各级可观察特征**
- **L1**：转场无错，但全是交叉淡化或全是同一种滑动；或者每次换一种花式，像在展示转场库。
- **L2**：小的内容变化用小的转场或直接切，大的段落变化用更明显的转场；转场短而干脆，不拖内容时间；视线在转场后不迷路。
- **L3**：转场由内容长出来——上一段的某个元素变成下一段的开头，退场就是下一个入场；观众感觉不到"转场"，只感觉内容在流动。
- **L4**：一个转场本身就是一句话：两个画面之间的连接制造了新意义（对比、因果、反转），观众在转场那一刻"明白了"。

**典型 AI 低级感**
- 所有段落之间都是交叉淡化。
- 每次换一种花式：翻页、百叶窗、旋转缩放、故障风轮流上。
- 所有转场同一时长、同一方向。
- 白闪转场、整屏黑场过渡反复出现。
- 每次转场都配同一个"嗖"。
- 故障风、色散、RGB 分离当作万能转场。

**回炉方向**
- 何时转、何种、多长 → 《书》第 12 章（转场）
- 段落边界要变多少 → 第 11 章
- 退场与下一个入场的衔接 → 第 14.4 节

### D6 声画同步

**判断问题**
1. 声音说到、响起的那一刻，画面上对应的东西是否正好"落"在那里？
2. 音乐的重拍和乐句边界，是否与画面的落点、段落边界对得上？对不上的地方是有意错开吗？
3. 音效是贴在动作的落点帧，还是贴在动作的起始帧？

**底线阈值**
- **容器层不偏移**：属交付层，见 T-05。
- **可见发声源同步**（B-22，有口型、敲击、碰撞等可见发声时）：声音相对画面超前 ≤ 45 ms、滞后 ≤ 125 ms（ITU-R BT.1359 的可察觉阈值）。测量：取画面撞击帧/口型闭合帧，对比音频瞬态起点。
- **音效落点**（B-23）：冲击类音效的瞬态起点与对应画面落点帧之差，按同一阈值（超前 ≤ 45 ms、滞后 ≤ 125 ms）检查。脚本在 B-09 冲击帧旁给出最近瞬态的时差（`audio_lead_ms`），超阈值者必须由能听的评审者确认该瞬态是否就是该音效。
- **内容不错位**（B-24）：配音讲第 N 点时，画面不得仍停在第 N−1 点或已跳到第 N+1 点。测量：ASR 逐词时间戳 × 逐帧 OCR/元素事件表，对齐每个被画面强调的关键词；画面落点晚于该词所在句结束 → 未过。
- **同时结束**：片尾音乐与画面结束时间差 ≤ 1 拍或有设计的余韵（时间线标注）。
- 评审者不能听声音时，本维度按 1.8 记"未评"。

**预警项**
- 切点落在音乐重拍 ±1 帧内的比例：接近 0（音乐与画面无关）或接近 100%（机械卡点）都预警。
- 画面关键词落点系统性地晚于配音（说完才出字）。

**各级可观察特征**
- **L1**：音乐只是垫底，与画面没有关系；或者每一拍切一刀的机械卡点；音效有，但位置随意。
- **L2**：段落边界落在乐句边界上；重要落点有声音托住；配音说到哪画面就到哪；没有可察觉的错位。
- **L3**：声音与画面像一个通道——音乐的层级（拍、小节、乐句）分别对应画面的不同层级（微动、元素、段落）；有意的错开制造张力，并在下一个落点兑现。
- **L4**：声画关系本身制造了惊喜：一次所有通道同时落空的静默、一次画面先于声音的抢拍，让观众在那一刻屏住。

**典型 AI 低级感**
- 音乐从头到尾同一首同一能量，与画面毫无关系。
- 每一个拍都切一刀，或每一个拍都让元素跳一下。
- 音效贴在动画起始帧，声音结束时动作还没落定。
- 配音讲到第三点，画面还在第二点。
- 每个元素入场都配同一个"叮"。
- 片尾音乐比画面早停或晚停一截。

**回炉方向**
- 时间以谁为准、漂移校正 → 《书》第 1 章（主时钟）
- 内容层级与音乐层级的对应 → 第 7 章
- 画面、配音、音效谁先谁后 → 第 16 章
- 爆发段切点与落地 → 第 9 章（物理驱动型：切点 = 落地时刻）
- 蓄力与冲击的声画叠加 → 第 10 章

### D7 配音与声音

**判断问题**
1. 配音像一个人在对你说话，还是在念稿？
2. 人声、音乐、音效三者，任何时刻都清楚谁是主角吗？人声始终听得清吗？
3. 句与句之间的停顿，是跟着意思走，还是机械等长？
4. 整体响度在目标平台上合适吗？有没有忽大忽小？

**底线阈值**
- **整体响度与真峰值**：属交付层，见 T-02、T-03（网络平台 −14 LUFS ± 1 LU、真峰值 ≤ −1 dBTP；广播按 EBU R128）。响度不达标在 v1 记"交付未过（可自动修复）"，不再判作品 L0；但响度修正无法弥补的问题（人声被音乐压住、忽大忽小）仍在本维度和下列各项判。
- **人声可懂**（B-27）：对成片做 ASR，与配音稿比对，字错误率 ≤ 3%（起点值）。评审卡不附配音稿时，用 ASR 低置信度词占比 ≤ 3% 代替。ASR 听不清的地方，观众大概率也听不清。有分轨时另测人声段内"人声短时响度 − 背景短时响度"，作为回炉定位依据。
- **零错读**（B-28）：多音字、数字、单位、英文缩写、专有名词读错任一处 → 未过（ASR 回写比对 + 人工听全部专名）。
- **无削波、爆音、断音**（B-29）：**削波** = 任一声道连续 ≥ 3 个样本 ≥ 满幅 0.999，≥ 10 段 → 未过，1–9 段预警人工听（v0 的"相邻样本差 > 0.5 满幅"作废——它把设计的打击瞬态都当成了爆音）；片段首尾样本绝对值 > 0.05 且无淡入淡出记预警（咔哒候选）；`silencedetect=n=-50dB:d=0.15` 报告的静音若落在 ASR 某个词的内部 → 未过。
- **无底噪与电流声**（B-30）：非人声段的噪声底（`astats` 的 RMS/噪声底估计）不得明显可闻；人工戴耳机听一遍。
- 评审者不能听声音时，本维度按 1.8 记"未评"；无配音的片（纯配乐动态海报等），本维度评"声音设计"：配乐与音效是否有层次、有落点、给画面让路。

**预警项**
- 句间停顿时长几乎相等（由 ASR 词时间戳算停顿的变异系数）。
- 语速全片恒定。
- 人声段与非人声段的音乐电平无差别（音乐没有给人声让路）。
- 短时响度曲线（ebur128 的 S 值）在同类段落之间跳变过大（起点值 > 6 LU）且未标注为设计。

**各级可观察特征**
- **L1**：能听懂，但平直：每句同一语调、结尾同样下坠，停顿等长，重音落在虚词上；音乐全程一样大。
- **L2**：语气自然，重音落在关键词上，停顿跟着意思走；音乐在人声出现时让路；音效克制而贴位；响度达标、全片平稳。
- **L3**：声音有设计——语气随内容起伏，停顿有呼吸；音效的质感与画面材质一致（软的东西声音软，重的东西声音沉）；声音层次在耳机里清楚可分。
- **L4**：声音成为记忆点——一个声音母题、一次精确的静默、一句语气的转折，让观众记住这条片"听起来"是什么样。

**典型 AI 低级感**
- 配音像念稿：每句同一语调，句尾统一下坠。
- 句间停顿一样长，像按标点切开再拼起来。
- 数字、英文、多音字读错。
- 情绪词被夸张地读（"震撼！""颠覆！"）。
- 音乐全程同一电平压着人声。
- 音效库默认的"嗖、叮、咚"每处都上。
- 开头音乐满电平突然进入；结尾音乐被一刀切断。
- 人声有齿音、喷麦或电流底噪。

**回炉方向**
- 口播作为主时钟、换气 → 《书》第 1 章
- 人声与画面、音效的先后 → 第 16 章
- 口播片的包装密度 → 第 19 章
- 音乐层级 → 第 7 章
- 余韵与尾音 → 第 20 章
- 《书》未覆盖：配音导演（语气、重音标注）与混音（闪避、频段让位）。v1 需补章；补章前回炉以本维度的 L2 特征为准。

### D8 色彩与质感

**判断问题**
1. 色彩是否在帮助区分主次与段落，而不只是"好看"？
2. 画面的材质（平面、纸、玻璃、金属、颗粒……）是否统一，且与内容性格相称？
3. 在手机上、在暗处观看时，有没有刺眼、偏色、色带、糊块？
4. 有没有可能诱发不适的闪烁？

**底线阈值**
- **闪烁安全**：任一 1 秒窗口内，一般闪烁与红闪各不超过 3 次，或闪烁低于亮度/面积阈值（WCAG 2 SC 2.3.1）。一般闪烁 = 一对方向相反、幅度 ≥ 最大相对亮度 10% 的变化，且较暗一态的相对亮度 < 0.80；红闪 = 涉及饱和红（R/(R+G+B) ≥ 0.8）的一对相反变化；面积阈值 = 同时闪烁面积不超过任一 10° 视场的 25%（W3C 以 1024×768 屏、典型观看距离折算为约 341×256 px 的区域）。测量：脚本逐帧把画面切成按该面积比例换算的区块，算每区块平均相对亮度与红比例，统计每个 1 s 滑动窗口内的相反变化对数；超标处再用专用闪烁分析工具复核。超标 → 未过，无豁免。
- **色彩元数据正确**：属交付层，见 T-01（缺失或不一致记"交付未过（可自动修复）"，不判作品 L0）。
- **无可见色带**（B-33）：大面积渐变背景在手机实机与 100% 放大抽帧上不得出现可见色阶断层。
- **无压缩糊块**（B-33）：暗部、渐变、快速运动段抽帧，不得出现可见块效应或马赛克（码率不足的信号）。

**预警项**
- 同屏主色（面积 > 5% 的色相簇）数量过多（起点值 > 5）。
- 全片平均饱和度极高，或大面积纯白背景（暗处观看刺眼）。
- `signalstats` 的 YMIN/YMAX 显示大面积死黑、死白。

**各级可观察特征**
- **L1**：颜色无错，但是"默认的科技感"或"默认的清新感"；材质是渲染器默认的；任何主题都会是这套颜色。
- **L2**：配色克制，主色与强调色分明，强调色只给重点；材质统一；手机上看舒服。
- **L3**：色彩与质感是这条片性格的一部分——换一个主题就不该用这套颜色；色彩变化参与叙事（段落换色有理由、峰值处色彩落差最大）；细节质感（颗粒、纸纹、光的方向）一致而不喧宾夺主。
- **L4**：一处色彩或质感的处理让人记住，并且与内容意义咬合——观众看到那个颜色就想起那个意思。

**典型 AI 低级感**
- 深蓝紫渐变背景 + 青紫霓虹发光，作为"科技感"的万能解。
- 处处毛玻璃卡片、处处发光描边。
- 高饱和彩虹渐变，或每段换一套颜色而无理由。
- 所有阴影同一方向、同一模糊，像一键生成。
- 全屏均匀噪点颗粒，与内容无关。
- 3D 物体塑料质感、默认布光。
- 纯黑底白字通篇，没有任何质感层次。

**回炉方向**
- 《书》暂无色彩专章。相关处：第 2 章（能量形状——亮度与色彩落差也是能量）、第 11 章（段落边界要变多少——换色是边界变化的一种）、第 18 章（环境层慢移）。
- v1 需补章：色彩层级与质感一致性。补章前回炉以本维度 L2 特征为准。

### D9 一致性

**判断问题**
1. 同一类东西（标题、要点、数据、强调、注释）在全片是不是同一种样子、同一种动法？
2. 全片是否属于同一个世界？有没有某一段像从别的片里贴过来的？
3. 打破一致的地方是不是有意的——对应一个重要时刻？

**底线阈值**
- **同类元素样式一致**：从联系表裁出全部同类元素（例如所有要点标题）并排比对字体、字号、字重、颜色、相对位置。任一处不一致且评审说不出它对应什么内容变化 → 未过。
- **技术参数一致**：单一帧率、分辨率、色彩空间属交付层（T-01、T-04、T-08）；混入低分辨率放大素材属观众可感层（B-35：抽帧检查清晰度，同类镜头间拉普拉斯方差骤降处人工确认）。
- **系列规范**：若该系列有成文规范（如固定角标位置），必须符合；没有成文规范的，不拿别的片的样子来要求（每条片可以有自己的版式）。

**预警项**
- 同一类元素出现 ≥ 2 种运动方式。
- 图标、插画风格混用（线性 / 面性 / emoji / 写实图混在一屏）。
- 字体家族 > 2 种（不含数字专用字体）。

**各级可观察特征**
- **L1**：要么"一致"只是因为套了同一个默认模板（一致但没有性格），要么各段风格拼贴。
- **L2**：一套视觉语法贯穿全片：同类元素同样子、同动法，观众很快学会"这种样子 = 这类信息"。
- **L3**：语法有性格，并在最关键的一刻被有意打破一次——那一下因为前面的一致而格外有力。
- **L4**：规则被打破的那一刻成为全片记忆点，观众事后意识到前面所有的一致都在为它铺垫。

**典型 AI 低级感**
- 一致只靠同一个模板，换题材也一样。
- 前半扁平插画、后半 3D 写实，没有理由。
- 同一类要点一会儿在左、一会儿在右。
- 线性图标、面性图标、emoji 混用。
- 三四种字体混用。
- 每段配色或转场方式都不同，而内容并无变化。

**回炉方向**
- 一致建立预期、打破才有意义 → 《书》〇节 P3（预期律）
- 对比从一致中生出来 → 第 3 章
- 主次与组织 → 第 13.5 节
- 段落边界变多少 → 第 11 章
- 同一角色同一参数 → 第 23 章速查表

### D10 信息清晰度

**判断问题**
1. 看完一遍，观众能复述出这条片要说的 1–3 件事吗？
2. 每一个画面变化是否都对应一个新意思？有没有不带信息的动作？
3. 任何时刻，观众知道"现在在讲什么、讲到哪了"吗？
4. 图表、数据、示意是否一眼看懂，不需要暂停？

**底线阈值**
- **复述测试**（B-36）：评审卡写明核心信息（一句话，附 ≤ 2 条次要）。1 名未看过脚本的测试者看一遍成片后写下"这条片说了什么"；命中核心信息不足一半 → 未过。人测优先；agent 评审时，由独立 agent 只看成片（视频帧 + 音频/ASR），不给评审卡、脚本和配音稿。
- **事实正确**：数据、名称、日期、引语逐条与来源核对，任一错误 → 未过。
- **图表不误导**：柱高/面积与数值成比例；坐标轴起点不制造夸大；百分比合计正确；比较的两项单位一致。任一不满足 → 未过。
- **有结论**：需要给判断的片（评测、比较、观点类），结尾必须落在一个明确的判断上；只罗列不站队 → 未过。

**预警项**
- 时间线上"无新意义的画面变化"（装饰性动作、无内容的转场、空镜）占比过高。
- 一屏同时出现 > 1 组需要比较的数据。
- 数字没有参照物（"提升 300%"但不说相对什么）。

**各级可观察特征**
- **L1**：信息都在，但每条权重一样、平铺直叙；包装和信息分不开，看完记得"挺炫"但说不清讲了什么。
- **L2**：一遍看懂；结构清楚（观众知道讲到第几点）；重点信息得到更多时间和更强的落点；数据一眼看懂。
- **L3**：展开方式本身让理解更容易——用变化、对比、拆解把一个难点"演"出来，观众不用想就懂了；每个动作都在传递意思。
- **L4**：一个可视化或一次揭示让观众真正"看见"了原本抽象的东西，理解发生的那一刻带来快感；看完会想把这个解释讲给别人听。

**典型 AI 低级感**
- 信息被包装淹没：一句话藏在粒子、光效和 3D 旋转里。
- 堆空词："赋能""全面""生态""颠覆"。
- 数字没有比较对象。
- 图表装饰化：3D 饼图、发光柱、无刻度。
- 开头"今天我们来聊聊……"，前几秒没有信息。
- 字幕、画面大字、配音三处重复同一句。
- 结尾不给结论，或给一句放之四海皆准的套话。

**回炉方向**
- 注意力预算、意义单元 → 《书》〇节 P2、P5
- 事件要有意义、空动作 → 第 5 章
- 开场先给什么 → 第 4 章
- 读得完 → 第 17 章
- 口播片包装多少 → 第 19 章
- 结尾落在结论 → 第 20 章

### D11 记忆点与创造性

**判断问题**
1. 看完 30 分钟后，评审还记得哪一个画面或哪一下？能用一句话描述吗？
2. 有没有一个选择是评审没有预料到的？事后看它"对"吗——服务于内容，而不只是新奇？
3. 把这个处理移到一条无关的片上还成立吗？（成立 = 通用花招，不是这条片的记忆点）
4. 与同题材标杆片两两比较，它赢在哪里？

**底线阈值**
- 本维度没有判 L0 的底线（没有记忆点不是错误）。
- **零记忆点检查**：评审看完一遍，间隔 ≥ 30 分钟后写下记得的画面。写不出任何一个 → 本维度定为 L1。
- **agent 的替代协议**（agent 无法真正间隔 30 分钟）：
  1. **先写后查**：评审 agent 看完一遍联系表/成片后，**在做任何维度判级之前**，不回看材料，写下记得的画面（≤ 3 条，每条一句话）并封存；完成全部其他维度工作后才拆封核对。
  2. **第二 agent 冷回想**：另起一个不继承上下文的 agent，只给每秒 1 帧的联系表按顺序快速过一遍（每帧 ≤ 1 s 等价的浏览，不允许回翻），随后先做一个无关的干扰任务（例如复述 D1–D10 的判断问题），再问"记得哪一个画面"。
  3. 两者交集 = 记忆点；只出现在一方的记"弱记忆点"。交集为空 → 本维度 L1。
  4. 核对：记忆点能否在联系表中找到时间码？换一个主题它还成立吗（成立 = 通用花招，见下一条）？
- **同构检查**：记忆点若与标杆库或已发布片中的某一处理同构（同一想法换皮）→ 本维度最高 L1，并在评审中注明对照出处。
- **标杆库为空或不足时**：L3/L4 只能记"**L3 候选 / L4 候选**"，合成时按 L2 计（适用于所有维度，不只 D11），直到完成 3.3 两两比较。

**预警项**
- 记忆点出现在装饰层而不是信息层（记住的是特效，不是内容）。
- 全片的"亮点"都集中在前 3 秒，之后一处也没有。

**各级可观察特征**
- **L1**：没有记忆点；或者记得的是通用炫技（粒子爆炸、镜头光晕、旋转 logo）。
- **L2**：有识别度——看一帧能认出是这条片或这个系列；但说不出具体哪一刻。
- **L3**：至少一个被记住的时刻，并且它从这条片的内容里长出来——换一个主题它就不成立。
- **L4**：意外但正确：评审第一次看到时没有预料到，回想时又觉得只能这样；它让观众回看、截图、转发那一下。

**典型 AI 低级感**
- 用"炫"代替记忆点：粒子爆炸、镜头光晕、3D 旋转 logo、故障风。
- 用滥的梗图、表情包、网络热词。
- 结尾套话式互动引导（"你最想……？评论区聊聊"之类）。
- 每条片同一个开场套路。
- 热门模板动效照搬。
- 把"惊艳"理解为堆量：更多元素、更多特效、更快更响。

**回炉方向**
- 对比与落差 → 《书》第 3 章（无聊的形状）
- 蓄力与兑现 → 第 10 章
- 有意违反规则 → 第 2、4、9、17 章的"故意违反"小节
- 预期与落空 → 〇节 P3
- 最容易被记住的两个位置 → 第 4 章（开场）、第 20 章（结尾）

### D12 形态与平台适配 / 信息负荷

**判断问题**
1. 这条片的形态（解说、口播、角色片、动态海报·循环、发布片）与平台的观看方式对得上吗？竖屏信息流里划到它的人，第一轮能拿到什么？
2. 单屏、单段的信息负荷是否与停留时间相称？信息有没有分层——首轮须读的、二遍可略读的、装饰的，在视觉上拉得开吗？
3. 画面是否利用了平台的物理条件：手机竖屏的视距、平台界面占掉的区域、自动循环、静音自动播放？
4. 时长是否符合这个平台、这种形态的观看习惯？

**底线阈值**
- 本维度的硬错已分散在其他检查中：平台界面遮挡（B-17）、常驻文字读负荷（B-14P）、画幅规格（T-08）、时长规格（T-07）。本维度不另设 L0 线，只判级。

**预警项**
- 竖屏片中，须读文字或主焦点落入平台界面蒙版区（按 B-17 蒙版）的面积比例 > 0。
- 动态海报 / 循环形态：首帧与末帧差异过大，循环接缝可见。
- 单屏同时出现的独立信息块 > 5 个（起点值：标题、主图、图例、对比框、进度条、脚注各算一块）。
- 静音自动播放平台上，核心信息只在声音里。

**各级可观察特征**
- **L1**：形态是"拿来的"——横屏思路直接竖排、长文海报直接做成视频；所有信息同一强度一次给出，观众不知道先看哪；平台界面压住内容或留白位置无意义。
- **L2**：形态与平台匹配：竖屏信息流里第一轮就能拿到核心一句；信息分层清楚（须读层大而少，可略读层明显退后）；平台界面区域被主动留空或只放可略读内容；时长符合形态。
- **L3**：形态本身在帮信息：循环被利用（第二轮看到第一轮没注意的东西）、竖屏的高度被用来表达顺序或量级、静音时画面独立成立；观众觉得"这东西就该在手机上这样看"。
- **L4**：形态的选择本身成为记忆点——一次对平台机制（循环、竖向滑动、界面元素）的意外而正确的利用。

**典型 AI 低级感**
- 把一页 PPT 或长图文原样放进 9:16，满屏小字。
- 所有信息块同时出现、同一强度，没有"第一轮看什么"。
- 底部 15–20% 被平台界面覆盖处放着须读文字。
- 循环片的末帧与首帧毫无关系，接缝处跳一下。
- 横屏解说片的节奏直接搬到 10 s 竖屏。

**回炉方向**
- 第一轮先给什么、开场窗口 → 《书》第 4 章
- 注意力预算、信息分层 → 〇节 P2、P5，第 13.5 节（主次与组织）
- 读得完、单屏字数 → 第 17 章
- 包装密度 → 第 19 章
- 循环接缝 → 第 20 章（结尾）、第 14.4 节（退场即下一个入场）
- 《书》未覆盖：平台界面蒙版与竖屏构图。补章前回炉以本维度 L2 特征为准。

### D13 角色表演（条件维度）

> 只在片中有**拟人角色或人物**（主持角色、吉祥物、演示者、拟人化的物体）且其出场时间 ≥ 全片 1/4 时评；否则记 n/a。v1 试行，证据 1 条片（ep05），按 5.5 需累计 ≥ 3 条片证据后转正。

**判断问题**
1. 角色在"演"吗？讲到、指到、被反驳、做判断时，它的身体、视线、表情有对应反应吗？还是全程站桩只换表情？
2. 角色的注意力在哪里，观众的注意力就被带到哪里吗（视线引导）？
3. 动作有预备、有主动作、有余波吗？还是从一个姿势跳到另一个姿势？
4. 角色是在帮内容，还是在每一帧抢第一眼？

**底线阈值**
- 本维度没有单独的 L0 线；角色造成的遮挡、穿帮、口型不同步分别由 B-40、B-10、B-22 判。

**预警项**
- 角色出场期间连续 > 5 s 无任何肢体或视线变化（起点值；表情贴图切换不算肢体变化）。
- 角色在全部代表帧中都是第一注视点（B-11 三秒注视测试统计）。

**各级可观察特征**
- **L1**：站桩：角色只是一个会换表情的贴图；讲到重点、盖章、反转时身体不动；视线不看它讲的东西。
- **L2**：角色对内容有反应：讲到什么就看向/指向什么；重要时刻有预备动作和落点；不讲话时退到次焦点，不抢板书。
- **L3**：角色有性格：同一个"人"的动作习惯贯穿全片；它的反应本身传递信息（犹豫、确信、被自己的结论刺一下）；观众通过它的反应知道"这里要注意"。
- **L4**：一次表演成为记忆点——一个反应、一个停顿、一次看向观众，让信息在那一刻落地。

**典型 AI 低级感**
- 角色全程站在固定位置，只切换表情贴图。
- 嘴型或身体随音量机械抖动，与语义无关。
- 所有动作同一时长、同一缓动，像在滑动而不是在动。
- 角色每一帧都在画面最亮最饱和处，抢走主信息。
- 无动机的挥手、跳跃、循环待机动作。

**回炉方向**
- 动作的语气、预备与落定 → 《书》第 13 章（入场语气）、第 10 章（蓄力与冲击）
- 多部位错峰（头先动、身体跟、手最后） → 第 15 章
- 动作、配音、音效谁先 → 第 16 章
- 待机时的呼吸与微动 → 第 18 章（18.4 噪声驱动、弹簧承载）
- 物理承载的跟随与余波 → 第 22 章
- 角色主次 → 第 13.5 节
- 《书》未覆盖：表演（视线、反应、性格化动作习惯）。补章前回炉以本维度 L2 特征为准。

## 3. 综合判级规则

### 3.1 判级顺序

1. **跑交付技术层**（6.1，全自动）。未过项列入"交付未过"，附脚本给出的修复命令；**不中断评审**。
2. **跑观众可感层**（6.2）。任一未过 → 整片 **L0**。列出全部未过项；上限层继续评，结果写作"修好后的上限"。
3. **核对预警项**。打开评审卡里的"有意说明"：没有说明、或说明与成片对不上 → 该预警按观众可感层未过处理。
4. **逐维度判级**（L1–L4，或 n/a、未评），每个级别必须附证据时间码。**L1/L2 计数口径**：逐条勾选该维度的"典型 AI 低级感"，每条命中标范围——局部（累计 ≤ 1/3 片长）或贯穿（> 1/3）。判 L2 必须同时满足：①无贯穿项；②局部项 ≤ 2；③能写出 ≥ 2 条带时间码的 L2 可观察特征。任一不满足 → 该维度 ≤ L1。
5. **按 3.2 合成整片级别**（含未评与候选规则）。
6. **L3/L4 候选做两两比较**（3.3）。标杆库不足时停在"候选"，按 L2 合成。
7. **有前一版本时，输出维度差分表**（3.4）。

### 3.2 合成规则

| 整片级别 | 条件（全部满足） |
|---|---|
| L0 | 任一观众可感层底线未过 |
| L1 | 观众可感层全过，但不满足 L2 |
| L2 | D1–D10、D12、D13（适用时）全部 ≥ L2（D11 可为 L1） |
| L3 | 全部适用维度 ≥ L2；D11 ≥ L3；L3 及以上维度 ≥ 6 个（不足 13 个适用维度时按比例：≥ 一半）；两两比较确认（3.3） |
| L4 | 满足 L3；D11 = L4，且至少再有 1 个维度 L4；两两比较确认；用户主观确认"惊艳"（5.3）。缺用户确认时只记为"L4 候选" |

补充规则：
- **交付层不进合成**：交付未过不改变整片级别，只在抬头单列（1.2）。
- **n/a**：不适用的维度（单镜头片的 D5、无角色片的 D13）不参与合成，也不计入"L3 维度数"。
- **未评**：按 1.8，未评维度视为不限制上限，整片写 "≤X（待 Dn 补评）"。
- **候选**：L3/L4 候选在合成中按 L2 计。
- **短板封顶**：D4 文字可读性或 D10 信息清晰度任一为 L1 → 整片最高 L1（看不懂的片不是商业合格）。
- **最低级决定上限**：除 D11 在 L2 档的豁免外，整片级别不高于"最低维度级别 + 1"。
- **与目标对照**：整片级别 < 评审卡目标级别 → 回炉。回炉单只列"拖住目标级别"的维度，按差距从大到小排列。"≤X" ≥ 目标时记"有条件达标，待补评"。

### 3.3 两两比较

L2 以上无法用规则证明，只能比较。
- **对照选取**：从标杆库取同题材、同时长档（±50%）、同平台的片；L3 候选对照 3 条 L3 标杆，L4 候选对照 3 条 L3 标杆 + 至少 1 条 L4 标杆。
- **盲比**：去掉片头片尾标识，随机左右顺序。
- **一次只问一个维度**："在 Dx 上哪一条更好？证据时间码是？"不允许回答"差不多"，必须二选一。
- **确认口径**：L3 = 对 L3 标杆胜 ≥ 2/3；L4 = 对 L3 标杆全胜，且对 L4 标杆不输（评审说不出 L4 标杆赢在哪）。
- **评审分歧**：两名评审差一级取低者；差两级及以上，引入第三名评审，取中位。

### 3.4 版本对比：维度差分表

同一条片的两个版本（或同题的两个方案）对比时，整片级别常常不动（短板封顶、最低级 +1），所以**维度差分表是正式输出**，与整片级别并列。

- 逐维度写两个版本的级别和变化：**升 / 降 / 平**；级别相同但同级内有可指认的改进，写"平（同级改进）"并给时间码。
- 允许"平"。3.3 的"不允许差不多"只用于对标杆的盲比；版本对比不强迫二选一。
- 另列两行：观众可感层（未过项的增减）、交付技术层（未过项的增减）。
- 结论写"新版在哪几个维度更好、哪几个没动、整片级别为什么动/不动"。

| 维度 | 旧版 | 新版 | 变化 | 证据（时间码） |
|---|---|---|---|---|
| D1 | L1 | L2 | 升 | 新版 00:01.5 拉远、00:06.3 推近形成起伏 |
| D7 | 未评 | 未评 | 平 | — |

## 5. 标杆片库规范与标准修订

### 5.1 每级收什么

| 级别 | 收什么 | 最少条数（v0） | 标注重点 |
|---|---|---|---|
| L0 | 各类底线错误的实例（含我们自己被回炉的版本） | 每条底线 ≥ 1 | 哪条底线、时间码、测量值 |
| L1 | 典型"AI 默认味"片：无错但处处默认 | ≥ 5 | 命中了哪些维度的哪几条低级感清单项 |
| L2 | 成熟机构、产品团队的商业解说/发布片 | ≥ 5 | 为什么挑不出错；为什么记不住（它离 L3 差什么） |
| L3 | 被反复引用、能复述出某一画面的精品 | ≥ 5 | 记忆点时间码；删掉或换掉它为什么会变差 |
| L4 | 用户亲口说"惊艳"的片段 | ≥ 3 | 意外在哪里；为什么事后看是对的；用户原话 |

另收**维度切片**：一条整体 L2 的片，若某一段在某个维度达到 L3/L4，可截取该段作为该维度的单项标杆。

### 5.2 每条参照怎么标注

每条标杆一条记录（存于 `craft-lib/standards/标杆/动效.md` 或同名表格，v0 先用 markdown 表）：

| 字段 | 说明 |
|---|---|
| ID | `A-<级别>-<序号>`，如 A-L3-004 |
| 来源 | 链接或本地路径（仅内部记录，任何成片、封面、文案中不得出现来源或作者 ID） |
| 题材 / 平台 / 时长 / 画幅 | 用于两两比较时匹配对照 |
| 整片级别 + 各维度级别 | 未评维度留空 |
| 为什么是这个级别 | 必须指向时间码与可观察现象，例如"00:14 三个数字依次从同一个点长出，读的顺序就是出现顺序"；不允许只写"高级""有质感" |
| 正例 / 反例 | 正例说明"这样对"；反例说明"这样不对"。每条正例尽量配一条同题材反例，组成比较对 |
| 入库人 / 日期 / 用户确认 | 用户确认过的标注为最高可信度 |

### 5.3 用户主观"惊艳"是最高校准数据

- 用户说"惊艳""这个好"的片段，原话 + 时间码直接入库为 L4（或对应维度 L4），不需要用户给理由。
- 评审者事后尝试把它写成可观察特征，补进对应维度的 L4 描述；写不出来的，保留为"未解释的 L4 样本"。
- 标准判级与用户判断冲突时，**用户判断胜**：记录冲突，找出标准漏掉的观察，进入修订（5.5）。
- 用户说"一般""没感觉"的，同样记录，作为 L1/L2 的校准。

### 5.4 爆款数据轴（独立于质量分级）

"爆款"是另一根轴，由选题、钩子、发布时机、平台分发决定，**不混入质量级别**：不因为爆了升级，也不因为没爆降级。它只用来校准质量标准是否看漏了东西。

**采集**（每条片发布后 7 天读一次平台后台）：播放量、平均观看时长 ÷ 片长、开头留存（3 s / 5 s）、留存曲线、完播率、互动率（赞+评+转 ÷ 播放）、涨粉 ÷ 播放；B 站另记弹幕密集时间码。

**四象限**

| | 数据好 | 数据差 |
|---|---|---|
| 质量 ≥ L3 | 标杆候选，优先入库 | 先查选题与钩子；不改质量级别 |
| 质量 ≤ L2 | 选题红利：记录选题与钩子，不入质量标杆 | 正常；按回炉单改进 |

**校准用法**
1. **留存断崖 ↔ 时间线**：留存曲线上的断崖时间码对到时间线表。若断崖处所有维度都被判"没问题"，说明标准漏项，进入修订。
2. **开头留存 ↔ D1 开场窗口**：同题材片中，D1 判级高的片开头留存应不低于判级低的；长期相反 → 复查 D1 的 L 级描述。
3. **回看点、弹幕密集点 ↔ D11**：观众自发回看或刷弹幕的时间码，是记忆点候选；与评审写下的记忆点对照，不一致处说明评审看漏或判错。
4. **级别与观看时长比的相关**：同账号、同题材、同发布时段 ≥ 5 条样本后才比较；L3 片的平均观看时长比长期不优于 L2 片 → 复查 L3 判定是否过宽。
5. 数据只校准标准，不直接生成规则：任何从数据得出的修订，必须能写成"观众看到了什么"。

### 5.5 修订流程

1. **记录**：每次评审输出（第 4 节）、每次用户判断、每条片的 7 天数据，存入评审日志。
2. **触发**：满足任一条即发起修订：累计 10 条新评审；用户推翻判级 ≥ 2 次；数据校准发现漏项；同一种新的 AI 低级感在 ≥ 3 条片中出现。
3. **修订内容**：补充或改写 L 级可观察特征、低级感清单、预警项；"起点值"阈值有 ≥ 5 条证据时可改为"校准值"并注明证据；新增维度需 ≥ 3 条片证据。
4. **版本**：文件头部维护版本号（v0 → v0.1 …），文末修订记录写明：改了什么、依据哪几条评审/数据/用户判断。

### 6.1 交付技术层（T-xx）——不判 L0，记"交付未过"
