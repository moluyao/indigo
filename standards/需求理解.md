## 1. 总则

### 1.1 评什么，不评什么

**这一领域的"观众"是谁。** 宪章公理 2 说标准评的是观众一侧的效果。简报的读者有两类：**用户**（他要能看见哪些是替他定的、能用一句话否决）和**下游执行者**（他要能照着做、照着验）。最终观众通过成品间接进来：简报说过的东西有没有在成品里兑现。本标准就评这三方各自拿到的东西。

**评**：
- 空白有没有被看见、写下；推断有没有理由；事实和示例有没有分对。
- 默认答案（包括第二层默认）有没有被写出来并排除。
- 方向是不是真的彼此差得远、各自扎在题材的独有事实上。
- 收拢理由能不能被别人核对；前提一变知不知道换到哪。
- 简报能不能执行、能不能验收；每句话挡不挡得住默认。
- 哪些决定是替用户做的，用户能不能一眼看见并否决。
- 成品有没有违背简报。

**不评**：
- 成品本身的观众侧质量（字高、对比、停留、节奏、构图、声音），交给对应标准。
- 选了哪种取向（见文件头）；方向写了几个；完成标准写了几条；问了几个问题；过程写了多长。篇幅长不加分。
- 文风。

**读过程，但不信自称。** 《protocol》步骤 6 第 5 条规定评审不读制作过程的自我说明；本领域的过程就是作品本身，所以评审要读交付的过程文件（按用户 2026-11-20 的指令）。但两件事不变：
1. 评审不知道作品出自谁，不读制作对话、提示词、工程文件，只读 1.4 列出的交付物。
2. 过程文件里写的"已通过近亲判定""已排除默认""自检全过"不算证据。凡是底线条目，评审都**自己重做一遍关键测试**：事实 / 样稿三问（《书》1.2）、替换测试（5.1 动作 2）、近亲判定（5.1 动作 4）、默认满足测试（7.1）、返工测试抽查（2.1）。

### 1.2 五个级别

| 级别 | 名称 | 用户和下游拿到的 |
|---|---|---|
| L0 | 坏 | 有判断层的错：默认没写、方向是近亲、编了事实、样稿留空栏、决定类没标、完成标准不会失败、成品违背简报……任一判断层底线（B）没过 |
| L1 | 能用 | 流程走完、没有硬伤，但每一步都像照模板填：默认写得泛，方向之间只差外观，理由靠形容词，用户读完不知道哪里可以否决 |
| L2 | 商业合格 | 可以交给用户和下游：空白都被看见，方向确实不同，理由可核对，简报能执行能验收；但方向落在同行能想到的范围里 |
| L3 | 精品 | 至少一个方向同行不会写出、又牢牢扎在这件题材独有的事实上；收拢理由写出了真正承重的前提；简报短，每句都在挡默认 |
| L4 | 惊艳 | 用户读完方向会说"没想到可以这样，但这就是我要的"；须用户本人确认 |

- L0 与 L1 的界线是"错"，靠第 2 节判，尽量可测。
- L1 与 L2 的界线是"默认"，靠第 3 节各维度的低级感清单。
- L2 以上只描述"看到什么"，靠标杆比较确认（第 4、6 节），不给配方。

### 1.3 三层

| 层 | 管什么 | 不过怎么办 |
|---|---|---|
| 交付整理层 T | 不改任何判断就能修好的：编码、栏目位置、排序、算术和编号笔误、抽取参数漏写 | 记"交付未过"，附修复方法；**不判 L0**；修好前不交给用户和下游 |
| 判断层 B | 判断本身错了或没做：用户和下游会被它误导 | 任一未过判 **L0**；维度照评，写成"修好后的上限" |
| 上限维度 D | 判断做得好不好、新不新、能不能执行 | 给级别与证据，指回《书》 |

判别一项属于 T 还是 B：问"**不改动任何一个判断**（状态、分类、默认、方向、理由、标准内容），只重排、补标签、改笔误、换编码，能不能修好？"能 → T；不能 → B。

### 1.5 评审者与材料

- 评审者不是制作者，是独立会话，不知道作品出自谁。
- **评审顺序**：
  1. 只读原话①，自己写下两句并封存：我不费力就会做的那个作品（评审的第一层默认）；排除它之后我最得意的点子（评审的第二层默认）。这两句是 D3 的独立对照，不用来判 B 层。
  2. 读②～⑥，跑 T 层和 B 层。
  3. 读⑧，跑 B-13，再评 D5、D9 的成品部分。
  4. 逐维度定级。
- 需要"不知情测试者"的项（B-13 (d)、D10）：测试者不读任何过程文件，每项两人（人数与镜头标准镜 B-02 相同，**待实验**）。

### 2.2 判断层 B（任一未过判 L0）

**理解类**

**需 B-01 合同照录，约束可追溯**
- 指标：简报里的原话与用户原文是否一致；简报里每一条约束能否指回原话。
- 阈值：(a) 简报第 1 栏的原话与主控提供的原文①逐字比对，字符差异 = 0（只差空白符的不计）；(b) 简报里每条约束能指回原话里的一个词，或带"推断"标记，两样都没有的 = 0；(c) 用户指定要上屏、要念出或要照用的文字（他给的店名、口号、一句原话），在简报里逐字照录，差异 = 0。
- 测量：A-01 逐字比对；评审把简报第 3–9 栏里的约束逐条标"原话词 / 推断 / 无出处"，数"无出处"。
- 依据：《书》1.2（原话是合同的全部来源）、1.6"把推断写成已说"、1.7 可测量（指回比例 100%、字符差异 0）。
- 回炉：《书》1.2、1.6。

**需 B-02 范围没有被替换**
- 指标：题材、对象、受众、交付形态有没有被悄悄扩大或换掉。
- 阈值：任一被替换或扩大，又没有作为"替你做的决定"写进第 3 栏供用户否决 → 未过。用户明说的约束被某条风格规则改写（而不是"照用，再设法融进作品"）→ 未过。
- 测量：把原话与简报第 1、2、5 栏的题材、对象、受众、格式逐项对照。
- 依据：《书》1.6"把空白当授权"、1.2"已说 → 照用"、1.3 乙层（只有委托方能覆盖）。
- 回炉：《书》1.2、1.3、2.3。

**需 B-03 不替用户补审美类空白（决定必须留痕）**
- 指标：审美类维度（中心想法、外观方向、结构、色彩与字体、声音、"好"的标准里属于口味的部分）处于空白时，是不是被悄悄定死了。
- 阈值：这类空白只允许三种处理——问；交给发散，再经收拢写出可核对理由；替定并写进第 3 栏（"我替你决定了……，理由……，可选的另一种是……"）。直接写进简报当成已定、没有任何一种标记的审美决定数 = 0。另外两条：维度表里标"隐含"的项，"因为"后面只有"通常 / 一般 / 大多 / 常见 / 行业惯例"或制作者自己的偏好 → 它其实是空白冒充推断，这类项数 = 0；第 3 栏"替你做的决定"条数 ≥ 维度表"替定"条数。
- 测量：评审逐条读简报第 4–9 栏里出现的审美决定，查它在第 3 栏或收拢理由里有没有出处；A-03 搜"因为"子句里的惯例词。
- 用户给了空泛授权（"放开做""给我惊喜"）不改变本条：授权要补成三件事（开放范围、怎样算赢、能承受往哪边错，《书》2.3），替定的照样留痕。
- 依据：宪章公理 3"用户没说的，不替用户决定"；《书》R1、1.2 状态判定规则（"通常"不是推断）、2.6 可测量。
- 回炉：《书》1.2、2.1、2.3。

**事实与样稿类**

**需 B-04 事实不编**
- 指标：关于真实世界的断言（真实品牌或产品的数据与功能、真实人物的话、统计、史实、"多少人用过 / 评价多高"这类证明）有没有被编出来，或被当作示例填上。
- 阈值：(a) 维度表里事实空白的处理写着"替定"或"填示例"的 = 0；(b) 证明类内容（用户数、评分、获奖、"老店""最受欢迎"、他人证言）被标成〔例〕的 = 0；(c) 简报和成品里出现、却不在事实清单（或就地出处）里的真实世界数字和说法 = 0；(d) 措辞比事实清单上的把握程度更强的（把"推测"写成定论）= 0。
- 测量：评审对每一条〔例〕和每一条"替定"重跑《书》1.2 的三问（替第三方作证吗？在证明它好吗？描述的是用户一句话定不下来的现状吗？），任一答"是"即为事实，按 (a)(b) 判；A-04 抽出简报与成品里的数字，与事实清单比对。
- 明显是示例的虚构内容不算编造，口径见第 5 节。
- 依据：《书》1.2 三问、1.3 甲层（谁都不能覆盖，包括用户）、4.2 把握程度、4.7 可测量。成品一侧与视觉 B-10、镜 S-10、声音 S-09 是同一件事，见 2.3。
- 回炉：《书》1.2、4.1、4.2。

**需 B-05 样稿空白填了示例，不留占位**
- 指标：样稿里用户日后会换掉的安排类内容（活动名、日期、地点、阵容、价格、栏目名、文案），有没有被填成明显合理的示例。
- 阈值：(a) 维度表里样稿空白的处理都是"填示例"；把样稿空白归成事实空白、因而留空的 → 未过；(b) 替换表条数 = 〔例〕条数 = 维度表"填示例"条数；(c) 简报的样稿内容和成品里，空白填写栏、占位线、"XXX / 待定 / 此处填写"、没有内容的框 = 0（成品一侧与视觉 B-08 同一测法，只测一次）；(d) 示例彼此不矛盾：日期与星期对得上、价格与档次相称（日期与星期按视觉 B-10 测）。
- 豁免（与视觉、镜头、声音标准第 5 节相同）：评审信息注明"内部稿"且空位写明"待补"；《书》4.5"故意让缺失可见"，缺失本身就是作品的论点，且过程里写明了理由。
- 测量：A-05（成品一侧调用视觉 A-08）；评审对每条事实空白重跑三问，查有没有本该是样稿空白的。
- 依据：《书》1.2"事实空白和样稿空白怎么分"、1.6 反向失败、1.7、4.6、4.7。两轮盲测：第 2 轮 T1 题框架组三件都把安排类内容归成事实空白、留了空白填写栏，两位评审都判 L0（`eval/round2-results.md`）。
- 回炉：《书》1.2、4.6。

**需 B-06 决定类内容标"发布前须用户确认"**
- 指标：观众会据此花钱、花时间或赶到某处的示例内容，有没有被标出来交给用户确认。
- 判别（《书》1.2）："观众照着这一项去做，示例值错了，他会白跑一趟或多花钱吗？"会 → 决定类。常见的有价格、时间、地点、报名或预约方式、联系方式、优惠条件、上线日期。本条是五份标准共用的决定类范围与判别问的持有方，其他标准第 5 节与评审卡引用本编号（2026-11-20 共用条目对齐）。
- 阈值：替换表里每一条决定类行都标"决定类：发布前必须由用户确认"，漏标 = 0；交付说明写明"未逐行确认之前只能当样稿，不发布"。排位问题归 T-03。
- 与其他标准的关系：视觉、镜头、声音标准评成品时，决定类没列出由评审者补列、不扣分，因为那里评的是画面和声音；本标准评的是制作者有没有做这个判断，这是需求理解这一步的职责，漏标判 L0。判别问和范围相同，只是责任落在这里。
- 依据：《书》1.2 决定类三条约束、1.3 甲层（错了由观众承担）、9.2。
- 回炉：《书》1.2、4.6、9.2。

**发散与收拢类**

**需 B-07 两层默认写出并排除**
- 指标：不费力就会做出来的那个作品（第一层默认），以及排除它之后同行最可能拿出的"聪明的第二选择"（第二层默认），有没有被写出来。
- 阈值（全部满足才过）：
  - (a) 第一层默认按"这个媒介要做哪几类决定"逐层各写一句。层由媒介推，不套固定层表；但《书》5.1 动作 1 写明的"至少"那几层不能缺（静止画面：画什么、怎么摆、什么色与光、有什么字；会动的再加时间怎么组织、东西怎么动、有什么声音；能交互的再加观众做什么、作品怎么回应）。
  - (b) 第二层默认至少写出一个，而且它不是第一层默认某一层上换一个值（那只是近邻）。
  - (c) 每条默认具体到能拿去对照成品：评审读完能判断"某个成品是不是它"。只有形容词或品类词（"俗套""常见的科技感""一般的宣传片"）的不算写了。
  - (d) 连续作品（评审信息注明）：最近一支的眼熟记录并入了默认（《书》10.1、10.5）。
  - "排除"的另一半——剩下的方向不能是这些默认的近亲——由 B-08 测。
- 不归本条：评审自己封存的默认，制作者没写到，不判 B 未过（各人的默认不必相同），记入 D3 证据。
- 测量：人工；A-07 只查栏目和层数是否齐。
- 依据：《书》R4 固着律、5.1 动作 1、5.6；两轮盲测：排除第一层默认之后，作品稳定落到同一批"聪明的第二选择"（`eval/analysis-r1r2.md` 第 4 条）。
- 回炉：《书》5.1 动作 1、5.6。

**需 B-08 方向彼此差得远，也不是默认的近亲**
- 判定方法（照《书》5.1 动作 4，**评审自己重做，不采信制作者的判定**）。对剩下的每一对方向，以及每个方向对每一条默认，按顺序判，判到有结论就停：
  1. **事后描述能互换吗？** 拿 A 的事后描述去描述 B 做成后的样子，一个不知情的观众会点头吗？操作：把 A 那句里的主体事件和主体名词原样搬到 B 上读一遍，句子对 B 仍然成立 → 近亲。
  2. **同一条事实，而且事后描述之间只差一个值**（换了一个物件、一种材质、一个地点、一个颜色、取了个反）→ 近亲：差别只在怎么包装同一件事。
  3. 其余 → 不同。
- 阈值（全部满足才过）：未合并的近亲对 = 0；与任一条默认近亲而没有被排除的方向 = 0；合并只能并入当时已经写下的方向或默认，违反 = 0；需求的字面画面最多占一个方向；剩下的方向 ≥ 2，其中至少一个对"只给我原话，我第一次会写出它吗"答"不会"（《书》5.1 动作 5 与停止规则"最少要留下"）。
- 豁免：《书》5.4 对已有体系的局部扩展（不发散）；5.5 故意违反"只写一个方向，但把默认版本也做出来对照"。过程里必须写明属于哪一条、它的前提为什么成立；写不出的不豁免。
- 测量：人工逐对填表（n 个方向 → n(n−1)/2 对，加上 n × 默认条数）；A-08 查合并顺序、方向数、字面画面计数的候选。
- 依据：《书》术语"近亲"、5.1 动作 4–5、5.6"几个方向是同一个方向换皮"、R4（差异必须发生在根上）。
- 回炉：《书》5.1 动作 2–5、5.6。

**需 B-09 方向扎根于独有事实**
- 指标：每个方向是不是靠一条只属于这件题材的事实站住。
- 阈值：(a) 每个剩下的方向都指回一条事实编号，指不回的 = 0；(b) 被方向引用的每条事实都过替换测试——评审把题材名换成制作者写下的最近同类，句子仍然成立，这条事实就不成立，靠它的方向视同指不回；(c) 第一个方向写出之后，事实列表没有被增删改，或者每次补充都有"第几次补、补了什么"的记录；(d) 过了替换测试的事实少于两条时，过程里有《书》5.1 动作 2 的补救（问用户一个"只有你知道"的问题，或走 4.3 取向 C）。
- 测量：评审对**所有被引用的事实**做替换测试；A-09 查编号存在性与冻结时序。
- 依据：《书》5.1 动作 2（替换测试、冻结）、5.7 可测量（指不回的 = 0）。
- 回炉：《书》5.1 动作 2、4.3。

**需 B-10 所选发散取向的记录如实**
- 原则：三种取向一视同仁，每种只查它**自己的**记录义务（《书》5.1 动作 3）。选哪一种、方向是抽出来的还是写出来的，都不加分不扣分。
- 阈值：
  - 选了取向甲（外部随机抽值）：每个方向都能在抽取记录里找到对应的一次抽取；抽取有种子或骰子结果，按记录的函数和区间复跑，值与记录一致；"模型自己说随机选了一个"或抽到不顺手的就换而没写理由 → 未过（《书》5.6"假随机"）。
  - 选了取向乙（从事实直写）：记录了每条事实上写了几次、哪次并入或放弃及理由；声称所有事实都轮过，而有事实是 0 次 → 未过（《书》5.6"事实挤兑"）。
  - 选了取向丙（借别的生成者扩大排除）：记录了借了谁、拿回几个、几个与两层默认重合；借来的答案出现在候选方向里而不是排除表里 → 未过（《书》5.1 取向丙"只能用来排除"）。
  - 各取向通用：放弃理由指向可核对的事实（材料不存在、落在默认区、与已写下的默认重合、作品读不到它需要的东西），"不太合适""感觉不对"这类理由 = 0；所选取向的停止规则在记录里可见，停止之后没有再写方向（违反 = 0，《书》5.7）。
- 不归本条：弃用率高低（甲取向超过一半只触发复查，不判级）；方向数量。
- 测量：A-10（复跑种子、数每条事实的次数、搜"感觉""不太合适"）。
- 依据：《书》5.1 动作 3 三种取向的记录义务与共同底线、停止规则，5.6、5.7。
- 回炉：《书》5.1 动作 3。

**需 B-11 收拢有可核对的依据**
- 指标：选定方向的理由里，有没有至少一样别人能核对的东西。
- 阈值：收拢理由的"依据"一栏至少有一条可核对依据——一条受众描述、一条独有事实编号、一个观看情境、或一次小样比较的结果；依据一栏为空，或只有"最安全 / 最稳 / 最不会出错 / 更高级 / 更有质感"这类词 → 未过。收拢方式是"让用户挑"时，记录了用户的选择；用户还没选时，给出的推荐理由同样受本条约束。
- 理由写得好不好（前提 → 换到、在哪一问胜出）归 D4，本条只管"有没有"。
- 测量：A-11 列出"依据"栏的名词与禁用判据词，人工确认。
- 依据：《书》6.4 禁止的判据、6.5 理由的写法、6.8"收拢理由只有形容词"；《书》1.1 第 ③ 步门槛。
- 回炉：《书》6.4、6.5。

**简报与成品类**

**需 B-12 完成标准可以验证**
- 指标：简报第 7 栏的每条完成标准，验收时会不会真的失败。
- 阈值：(a) 每条都写成"观众侧现象 + 测法 + 怎样算失败"，"失败"是一个读数或一个是 / 否判定，写不出失败的条数 = 0；(b) 至少一条是观众侧的（不是尺寸、格式这类交付侧检查）；(c) 不可判的条目（"不够好就重做""让人满意"）和手法条目（"必须用某种转场"）= 0；(d) 必保项（方向承诺里"最难的元素"和"强度"两行）列出来了。
- **条数不判**。完成标准的数量以 `framework/protocol.md` 现行写法为准：少量、可验证，条数由作品定（protocol 写的起点为 3–6 条，待实验）。条数落在起点之外不扣分；够不够、多不多由 D7 按《书》8.1 的两个测试看。
- 测量：评审把每条拆成三段，缺段的计数；A-12 搜不可判词与手法词。
- 依据：《书》R6 可判律、1.1 第 ④ 步门槛、8.1、8.5、8.7；`protocol.md` 步骤 7 第 0 条。
- 回炉：《书》第 8 章。

**需 B-13 成品没有违背简报**［成品已做时］
- 指标：简报说过的，成品里有没有被违反或悄悄磨平。
- 阈值（任一未过即未过）：
  - (a) 合同文字：用户指定要上屏、念出或照用的文字，在成品里逐字出现，字符差异 = 0（错一个字就算未过）。
  - (b) 禁止项：简报第 8 栏的条目在成品里被触发的 = 0；第 3 栏里有用户同意推翻某条的记录的，那一条除外。
  - (c) 方向承诺：写成"量与下限"的那几行，在成品上实测都达到下限；"小件"一行点名的小件，用了现成组件默认样子的件数 = 0。
  - (d) 没被磨平成默认：把成品和"选定方向的事后描述""两层默认的事后描述"一起交给两名不知情测试者，问"它更像哪一个"；两人都选了某条默认 → 未过。只有一人选默认，记作 D9 证据。测试人数**待实验**。
  - (e) 示例值一致：成品上的示例值与替换表逐字相同；成品里出现替换表里没有的示例，回到 B-05 (b) 判。
- 不归本条：成品的观众侧底线（字高、对比、停留、遮挡、闪烁……）由视觉、动效、镜头、声音标准测；简报里写的阈值比这些标准宽时，成品仍按那些标准判，简报的宽阈值记入 D7 证据。
- 成品未做：写"未测"，判断层状态写"通过（B-13 未测）"，不得写成"通过"。
- 测量：A-13（合同文字逐字比对、禁止项关键词候选、承诺量实测）；(d) 只能人工。
- 依据：《书》1.7 可测量（字符差异 0）、6.6 方向承诺、6.8"方向在实现中被磨平"、6.9 可测量、7.8 禁止项、8.4 取向 C 的测法。
- 回炉：承诺本身写得查不了 → 《书》6.6；承诺写好了而实现失守 → 交回制作，按《书》9.3 写修改意见（现象 → 目标 → 验证方法，以 `protocol.md` 为准）。

## 3. 上限维度

每个维度：判断问题 → L1～L4 看到什么 → 典型 AI 低级感 → 回炉。级别描述只写评审在过程文件和成品里**看得到的现象**，不写该用哪种取向。

**低级感清单的用法**（与视觉标准第 3 节同一计数口径）：每条命中标"局部"（一处）或"贯穿"（过程文件里同类问题出现在一半以上的栏目或条目中）。判 L2 须同时满足：该维度无贯穿命中；局部命中 ≤ 2；能写出 ≥ 2 条指向具体栏目和行的 L2 现象。任一不满足，该维度 ≤ L1。

### D1 理解：空白、受众与目标反应 [通]

**判断问题**：一句话里没被约束的地方，看见了多少？受众描述能不能在两个候选方向之间判出胜负？目标反应写成能检验的样子了吗？

| 级别 | 看到什么 |
|---|---|
| L1 | 维度表各行都填了，但多数空白直接"替定"、没有理由；受众是"年轻人""大众""某平台用户"；目标反应是"印象深刻""有感染力"；观看情境写"各平台" |
| L2 | 每个维度的状态都有依据，推断都有"因为"；受众描述能拿去在两个方向之间判胜负（《书》3.1）；目标反应按主目的写成可检验的形态并附检验方法（3.2）；观看情境写清了在哪看、有没有声音、看几遍 |
| L3 | 找出了"看起来已经说清、其实藏着默认"的维度（表外的维度被"说不出是谁决定的"那一问找了出来）；受众和情境把好几个空白变成了可否决的推断，少问而不少知；需求本身有矛盾时（例如时长装不下内容）写成选择题交还，而不是默默删内容（13.2 第 1 条） |
| L4 | 理解本身让用户重新看清了自己的需求，用户确认"这就是我没说出来的" |

**典型 AI 低级感**：维度表行数与《书》示例表完全一致、一行不增不减；"受众：对 X 感兴趣的人"；"目标反应：留下深刻印象"；把平台当受众；需求方和终端观众混成一个人（3.6）。

**回炉**：《书》第 1 章 1.2、1.4；第 3 章；13.2。

### D2 事实与材料 [通]

**判断问题**：每条主张知不知道从哪来、有多确定？缺的东西是被处理了，还是被包装了？

| 级别 | 看到什么 |
|---|---|
| L1 | 事实和示例分开了，但只有标签没有出处；缺的东西靠"简约风格"省略，说不出是选择还是做不到 |
| L2 | 每条主张有来源标签和处理；把握程度写清、措辞跟着降级；示意的东西写明了声明出现在哪一刻、哪一块画面（《书》4.2）；授权与告知写明；每项省略答得出"时间材料给足还会这样做吗"（4.6） |
| L3 | 风险边界从这件题材推出（错了第一个受损的是谁、观众会不会据此做决定），而不是抄一张通用清单；用户给了材料时，交还的方面正好对应下游要靠它做的决定（4.3 取向 B） |
| L4 | "真"或"缺"本身成了这件作品站得住的理由，用户确认 |

**典型 AI 低级感**："来源：网络公开资料"；把"数据仅供参考"当万能声明；凭记忆画的真实界面写成"还原"；事实清单只有一列。

**回炉**：《书》第 4 章。

### D3 方向的新鲜度与跨度 [通]（单独打分，即"创意与新鲜度"）

**判断问题**：默认写得够具体、够深吗？剩下的方向彼此离多远？有没有一个同行不会写出、又只属于这件题材的方向？

**三个测试**（评审执行，结果写进证据）
- **跨度**：剩下的方向是不是扎在不同的事实上、事后描述里的主体事件是不是不同。所有方向只在外观上不同（同一件事换色、换材质、换场景）→ 本维度最高 L1。跨度只看结果，不看方向是抽出来的还是写出来的。
- **代入**：把选定方向里的题材换成最近的同类，方向几乎不用改 → 本维度最高 L2。
- **第二层默认识别**：见下。

| 级别 | 看到什么 |
|---|---|
| L1 | 方向数够，但差别只在外观一层；或默认写得泛，选定方向和评审封存的第一层默认是近亲 |
| L2 | 方向确实根上不同，各有事实；但都在同行能想到的范围里，或选定方向命中第二层默认 |
| L3 | 至少一个方向同行不会写出（评审封存的两层默认和登记表里都没有），扎在一条只属于这件题材的事实上，换成同类就不成立；它没有为了"怪"丢掉目标反应 |
| L4 | 方向本身让用户惊讶，又觉得只能这样；可以成为别人的参照；用户确认 |

**第二层默认识别（命中只扣本维度，不判错）**
- 以下任一成立即为命中：
  1. 选定方向（用户挑时为推荐方向）与第二层默认登记表里某一条是近亲（按 B-08 的判定步骤）。登记表五份标准共用一张：`standards/第二层默认登记表.md`，随评审数据增补。
  2. 同一需求的几次独立运行里，≥ 2 份的选定方向互为近亲（同批撞车）。
  3. 与评审封存的第二层默认是近亲。
- 处理：命中时本维度最高 L2；写得出它在这件作品里多走了的那一步（使它只属于这件内容），且两位评审都认可，可到 L3，并把这一步写进证据。
- 不进 B 层，不降低其他维度。B-07、B-08 只管制作者**自己写下的**默认；他没写到的第二层默认，由这里管——漏写是不新鲜，不是错。
- 登记表是评审工具；登记表一旦被拿去当禁用清单，新的重复会出现在别处，所以第 2 条"同批撞车"始终要做。

**随机中立**：用取向甲抽出来的方向和用乙、丙写出来的方向，用同一把尺子量。"有抽取记录"不证明新鲜，"没有抽取"也不证明不新鲜。

**典型 AI 低级感**：方向是"极简版 / 科技版 / 温馨版"；方向名就是风格词；需求的字面画面占了两个以上方向；"把题材里的 X 变成 Y"的现成双关；所有方向都是受众天天用的那类工具的样子（《书》5.6"工具的戏服"）；参照用的是人人都在用的那一个（5.2）。

**回炉**：《书》第 5 章（动作 1、2、5，5.2，5.6）、10.1。

### D4 收拢理由的质量 [通]

**判断问题**：选它的理由别人能核对吗？前提一变，知道换到哪个方向吗？收拢方式是按这一次的情况选的吗？

**"最稳妥"不算理由**：依据里出现"最稳 / 最安全 / 最不会出错 / 最平衡 / 综合最优"，而没有写出它在哪一问（《书》6.4 三问）上胜过非默认方向 → 本维度最高 L1。完全没有可核对依据的情况由 B-11 管。

| 级别 | 看到什么 |
|---|---|
| L1 | 依据里有一样具体的东西，但主要靠形容词；"前提 → 换到"缺失或只有一行套话；推荐的就是离默认最近的那个 |
| L2 | 依据都能核对；"前提 → 若变 → 换到"逐条写，每个落选方向都能被某个前提换回来（《书》6.5）；收拢方式按 6.1 判定表选；最契合的恰好最保守时，写了它在哪一问胜出（6.4）；用了组合时，每次淘汰的依据类型（事实 / 观感）和所在的层（文字 / 小样）对得上 |
| L3 | 理由暴露了真正承重的那个前提（换掉它整个选择就翻转），而且这个前提用户一句话就能改；从落选方向借了一个元素，并融得进选定方向 |
| L4 | 用户读完理由主动改了一个前提，因此换到了更好的方向，用户确认 |

**典型 AI 低级感**："综合考虑，方向二最平衡""最符合品牌调性"；"前提：预算充足 → 若变 → 简化"；所有落选方向在任何前提下都换不回来（说明它们本来就不该进候选，《书》6.5）。

**回炉**：《书》6.1–6.5。

### D5 方向承诺与防磨平 [通；成品未做时只评承诺本身]

**判断问题**：承诺锁住了实现时最可能失守的地方吗？"守住的样子"能查吗？成品守住了吗？

| 级别 | 看到什么 |
|---|---|
| L1 | 承诺读起来是一种情绪（"温暖而有力量"）；只写了最难的元素，小件和强度缺 |
| L2 | 按这件作品实际的失守处逐行写，三列齐；强度写成带下限的量；小件逐件点名；成品逐行兑现 |
| L3 | 预判出了别人想不到的失守处，查法便宜而确定；成品连承诺之外的小件也用了方向的语言 |
| L4 | 下游或用户确认：承诺让一个本会被磨掉的东西在实现中留了下来 |

**典型 AI 低级感**：承诺表照抄模板三行；"小件：字幕等"；"强度：保持张力"；查法写"整体检查"。

**回炉**：《书》6.6、6.8。

### D6 简报的可执行性 [通]

**判断问题**：下游拿到能不能直接动手、直接验收，同时又没被替他定死手法？简报里的句子挡得住默认吗？

**默认满足测试**（评审执行，《书》7.1）：拿 B-07 的两层默认，逐句问简报"默认作品也满足这一句吗？"，数出方向栏和禁止项栏里"默认作品不满足"的句子。两栏都是 0 → 本维度最高 L1。

| 级别 | 看到什么 |
|---|---|
| L1 | 规格写满、想法空着；形容词堆积；禁止项泛（"不要俗套"）；变量散在正文 |
| L2 | 默认满足测试两栏各有至少一句不被满足；每个形容词后面跟了意图、参数或参照；格式数字都在完成标准或底线检查里找得到对应检查（7.2）；禁止项具体到能在成品里查到、标了来源、按可能性排序（7.8）；变量集中一处（7.9）；结构写了每段的出口条件（7.3）；第一个中间产物、它回答的问题、谁来看都写明（9.1、9.2） |
| L3 | 简报短而句句承重：删掉任何一句，下游都可能做回默认；写到哪一档（意图 / 参数 / 参照）与"谁执行、要不要一致"相符；工具会失败的维度事先绕开了（7.2） |
| L4 | 两个互不知情的执行者照这份简报各做一次，结果都在选定方向里、都不是默认，彼此又不相同 |

**典型 AI 低级感**："风格：高级、现代、有科技感"；"你是顶级导演"这类人设写进简报；曲线、帧数、色值顺手写死（7.11）；把上一份简报换皮复用（7.9 提醒）。

**回炉**：《书》第 7 章、9.1–9.2、第 11 章。

### D7 完成标准的质量 [通]

**判断问题**：这几条标准会不会真的失败？管住的是不是这一件作品最可能卡住的地方？

**够不够、多不多**（《书》8.1，不落成数字）：把这件作品要在观众身上起的几类效果列出来，每一类有没有至少一条能失败的标准管着；两条标准是否互相拉扯又说不出谁优先，执行者能不能复述全部。条数本身不判。

| 级别 | 看到什么 |
|---|---|
| L1 | 每条都能失败，但都是放到任何作品上都成立的通用项；或者观众侧只有一条，其余全是交付侧 |
| L2 | 观众侧为主，按观众接触作品的顺序预演出来（8.3）；每类效果都有一条管着；必保项、差异项另列；测法写得出谁来测、怎么测 |
| L3 | 至少一条只有这件作品才会失败，正对着方向最可能失守的地方；没有一条在测同一件事 |
| L4 | 有记录表明某条标准在实现中真的拦下了一次退回默认 |

**典型 AI 低级感**："画面精美、节奏流畅""用户满意"；把《书》8.2 的举例表六行原样抄进来；简报自己写的阈值比共用标准宽（例如读速、字高），见 8.2 节。

**回炉**：《书》第 8 章。

### D8 对用户的透明度 [通]

**判断问题**：用户读完能不能一眼分清哪些是他说的、哪些是推出来的、哪些是替他定的？否决一项要花多少力气？

| 级别 | 看到什么 |
|---|---|
| L1 | 推断和决定混在正文里；问题没有推荐答案和猜错后果；"做不到"被写成"风格选择" |
| L2 | 第 3 栏完整：推断带"因为"和"不对会影响什么"，替定带"另一种是"；问题只列通过返工测试的、按返工代价排、附推荐答案和猜错后果（用户在场时；全自主时只记进过程，《书》2.1）；替换表在交付说明第一项；越过丙层规则的地方记了一行理由（1.3） |
| L3 | 用户读一页就能做完所有否决；最贵的一两个问题排在最前，其余不答也能按推荐走；空泛授权被补成三件事（2.3） |
| L4 | 用户确认"不用来回问就定下来了" |

**典型 AI 低级感**：十个礼貌性问题；"如有需要可随时调整"；替换表埋在附录；"已按最佳实践处理"。

**回炉**：《书》1.3、第 2 章、4.6、9.2。

### D9 执行与完成度 [通]（单独打分）

**判断问题**：流程是不是真的走完了、各部分互相对得上？成品兑现了简报多少？

| 级别 | 看到什么 |
|---|---|
| L1 | 各栏都填了，但互相对不上：方向引用的事实不在事实表里，承诺里的小件和成品的小件不是一批；自检只写"已通过"、没有读数 |
| L2 | 《书》1.1 门槛表逐步有据；各栏交叉引用一致；书里的"可测量"自检逐项有读数；成品逐条对照简报，没有偏离 |
| L3 | 记录可复核：另一个人照记录重做关键判断（复跑抽取、重做近亲判定、重做替换测试）得到同样结果；成品在简报没写到的地方也没有退回默认 |
| L4 | 独立复核找不到一处与记录不符，成品与简报零偏离，且有一处做到了简报没要求、用户确认想要的程度 |

**与 D3 分开看**：两轮盲测里"想法好、执行掉链子"和"执行稳、想法默认"经常分在两组作品里（`eval/analysis-r1r2.md`）。评审必须分别给 D3、D9 级别，并在报告抬头并列；不得因为其中一项高而拉高另一项。

**典型 AI 低级感**：自检全部打勾、没有数；"同上""略"；编号前后不一；B-13 (d) 只有一名测试者认作默认。

**回炉**：《书》1.1 门槛表、第 9 章、第 11 章。

### D10 连续作品的差异 [条件维度：同类需求连续出现；用户要的就是系列统一的除外]

**判断问题**：这一支和最近几支，观众会不会觉得"又是这个"？

| 级别 | 看到什么 |
|---|---|
| L1 | 发散时没并入上一支的眼熟记录；这一支的事后描述能和上一支互换 |
| L2 | 眼熟记录写了、并入了排除；事后描述不能互换；三帧缩略并排盲测，被认成"同一系列"的比例低于一半（《书》10.5） |
| L3 | 差异发生在骨架动作上，不只在外观；复用只发生在观众感知不到的部分（代码、流程、测量方法，10.1） |
| L4 | 这一支在系列里被单独记住，有用户确认或数据为证 |

**典型 AI 低级感**：上一支的简报换了名字和数字直接用；"保持系列风格统一"而用户并没有要求。

**回炉**：《书》第 10 章。

## 4. 判级规则

### 4.1 判级顺序

1. 只读原话，封存评审自己的两层默认（1.5）。
2. 跑 T 层（第 7 节 A-T 项）。未过项列入"交付未过"，附修复方法；不中断评审。
3. 跑 B 层。任一未过 → 整件 **L0**；列出全部未过项及证据（文件、栏目、行，或成品的位置与时间码）；维度照评，写成"修好后的上限"。
4. 逐维度定级（L1～L4、n/a 或未评），每级附指向栏目和行的证据；按第 3 节开头的计数口径判 L2。
5. 按 4.2 合成。
6. L3、L4 候选做两两比较（4.3）；标杆不足时停在"候选"，按 L2 合成。
7. 有前一版本时，输出维度差分表（4.5）。
8. 打开评审信息里的有意说明，只用来解释测量数据，不改级别。

### 4.2 合成

| 整件级别 | 条件（全部满足） |
|---|---|
| L0 | 任一 B 层未过 |
| L1 | B 层全过，但不满足 L2 |
| L2 | 全部适用维度 ≥ L2；D3 可以是 L1 |
| L3 | 全部适用维度 ≥ L2；D3 ≥ L3；D4 ≥ L3；L3 及以上的维度 ≥ 适用维度数的一半；两两比较确认 |
| L4 | 满足 L3；D3 = L4，且另有至少 1 个维度 L4；两两比较确认；用户本人确认"惊艳"。缺用户确认时记"L4 候选" |

**短板与封顶**（优先于任何平均印象）
- D1 理解为 L1 → 整件最高 L1（理解偏了的简报，后面做得再好也是在错的方向里好）。
- D3 为 L1 → 整件最高 L2，且不进 L3 候选（宪章公理 3"先放开"没做到）。
- 除 D3 在 L1 时的豁免外，整件级别不高于"最低适用维度 + 1"。
- T 层不进合成，只在抬头单列。

**报告抬头必须并列四件事**：交付整理层状态（通过 / 未过：列 ID）；判断层状态（通过 / 未过：列 ID / 通过（B-13 未测））；整件级别；**D3 方向的新鲜度与跨度、D9 执行与完成度各自的级别**。例："整件 L0（修好后上限 L2）｜判断层未过 需 B-05、需 B-07｜交付整理层通过｜D3 L2 / D9 L1"。

### 4.3 两两比较

- 一次只比两份、一次只问一个维度："在 Dx 上哪一份更好？证据在哪一栏哪一行？"对标杆的盲比必须二选一，不允许"差不多"。
- L3 候选对照 3 份 L3 标杆，胜 ≥ 2/3 确认；L4 候选对照 3 份 L3 标杆全胜，并对 L4 标杆不输。
- 对照从同类条件里取：同一媒介（静态 / 动态 / 交互）、同一收拢方式下用户在场与否、同为单件或同为连续作品。不同发散取向之间可以直接比，不分组。
- 两名评审差一级取低者；差两级及以上，加第三名评审，取中位。

### 4.4 某个维度或某条底线无法评

- 评不了的维度写"未评"，并写原因（例如"成品未做""没有上一支的眼熟记录"）。不估级。
- 未评维度不限制上限，整件写成"≤X（待 Dn 补评）"；未评的是 D1 或 D3 时，不得给出 L3 及以上的结论，只能写"L3 候选（待补评）"。
- **成品未做**：B-13 写"未测"，判断层状态写"通过（B-13 未测）"；D5、D9 只评过程部分，标"（过程部分）"；成品做出后补测 B-13 并补评。
- **没有不知情测试者**：B-13 (d) 写"未测"，按上一条处理；D10 的缩略盲测同理。
- **用户不在场**：凡需要"用户确认"的 L4 只能记"L4 候选"；D8 照评（透明度对之后看到简报的用户同样成立）。

### 4.5 版本对比：维度差分表

整件级别常因封顶和短板不动，所以维度差分表是正式输出。

| 维度 | 旧版 | 新版 | 变化 | 证据（栏目与行） |
|---|---|---|---|---|
| Dn | L? | L? | 升 / 降 / 平 / 平（同级改进） | … |

- 允许"平"。4.3 的"不允许差不多"只用于对标杆的盲比，不用于版本对比。
- 另列两行：B 层未过项的增减、T 层未过项的增减。
- 结论写清：哪几个维度变好、哪几个没动、整件级别为什么动或不动。D3 和 D9 的变化分开写。

## 5. 样稿内容口径

与视觉标准第 5 节（样稿内容口径的持有方）同一口径，镜头、声音、动效标准第 5 节也引用它。区别只在于：那三份标准在成品上看结果，本标准看制作者在过程里有没有**分对、标对**。

- **事实不编，样稿要填**。分法照《书》1.2 的三问：替用户以外的人或公共世界作证的、用来证明"它好 / 可信 / 有人认可"的、描述用户一句话定不下来的现状的——任一是，就是事实，只能问、查或标缺失（B-04）；三问都否的是安排类内容，要填示例（B-05）。一句话里既有安排又有现状的，拆开分别判。
- **明显是示例的虚构内容不算编造**：虚构的活动名、品牌名、人名、日期、价格、阵容、栏目名、文案、演示数据，只要不冒充真实存在的对象，都算样稿内容；在过程记录里逐条注明"示例，可替换"，全部列进替换表。
- **证明类内容不能用示例**（本领域特有，《书》1.2 第 2 问）：用户数、评分、获奖、"老店"这类，即使是用户自己的品牌，也不能填示例值；缺了就删掉，或换一个不需要它的主张（《书》4.6）。
- **留空的算未完成**：空白填写栏、占位线、"XXX / 待定 / 此处填写"、空框，按 B-05 判 L0；豁免与其他标准相同（"内部稿"且写明"待补"；或缺失本身就是作品论点，《书》4.5）。
- **决定类内容**（范围与判别问见需 B-06）即使填了示例，替换表里也必须标"决定类：发布前必须由用户确认"，漏标按 B-06 判 L0。评审者在报告末尾照录全部决定类行。
- 示例同样要对：日期与星期对得上、算式算对、价格与档次相称、彼此不矛盾（按共用 需 S-02 测）。
- **发布门**：替换表逐行由用户勾"已换 / 就用它"，决定类没勾的不发布；发布前再核一次成品里的值与用户确认的值逐字一致（《书》1.2、4.6）。这一步发生在评审之后，评审只检查交付说明里有没有写明这道门。

## 6. 标杆库规范

### 6.1 规则

- 标杆只给评审看，不给做作品的人看。尤其不得把标杆里的方向放进制作者的发散输入——它会变成新的中心（《书》R1）。存放位置：`standards/标杆/需求理解.md`（待建）。
- 每件标杆一条记录：ID（`R-<级别>-<序号>`）；来源（只作内部记录）；全套过程文件（1.4 的②～⑥）与成品（若有）；媒介、收拢方式、用户是否在场；整件级别与各维度级别（未评留空）；**为什么是这个级别**（必须指向某一栏某一行的可观察现象，不允许只写"思路清晰""很有创意"）；正例或反例；入库人、日期、是否经用户确认。
- 正例尽量配一件同条件的反例，组成比较对。
- 另收**维度切片**：整体 L2 的过程里，某一栏（例如收拢理由、方向承诺、完成标准）达到 L3 或 L4，可单独截取作为该维度的标杆。
- 三种发散取向、三种收拢方式在标杆库里都要有正例；某一种暂时没有正例时，在库首写明"缺"，不得因此在评审时偏向已有正例的那一种。
- 用户亲口说"这就是我要的""惊艳"的，原话直接入库为 L4（或对应维度 L4）；标准判级与用户判断冲突时用户胜，记录冲突，找出标准漏掉的观察，进入修订。用户说"一般""没帮上忙"的同样入库，作 L1 / L2 校准。

### 6.2 每级放什么

| 级别 | 放什么 | 标注重点 |
|---|---|---|
| L0 | 每条 B 底线至少一件实例 | 哪条底线、哪一栏哪一行、评审重做测试的结果 |
| L1 | 走完流程但处处照模板的过程，含同批撞车组 | 命中哪些维度的哪几条低级感；撞车对象 |
| L2 | 挑不出错、方向确实不同，但都在同行能想到的范围里 | 为什么挑不出错；离 L3 差什么 |
| L3 | 有一个同行不会写出、又只属于这件题材的方向，理由写出了承重前提 | 那个方向和它扎根的事实；换掉承重前提会怎样 |
| L4 | 用户确认的惊艳 | 意外在哪里；为什么事后看是对的；用户原话 |

### 6.3 第一批锚点

**说明**：两轮盲测的评审只评成品，按当时的评审规范不读过程文件（`eval/rubric-v1.md`），所以**没有两位评审都评过过程的锚点**。下面列的是"两位评审对成品意见一致、而原因能在过程文件里直接定位"的作品，作为过程一侧的锚点；"按本标准复核"一栏是标准作者对照过程文件得出的，不是评审意见，入库时要由两位评审按本标准复评确认。编号格式同视觉标准 6.3（轮次-题号-作品号）。

**L0 实例**

| 编号 | 底线 | 评审一致的成品判定 | 过程里的定位 / 按本标准复核 |
|---|---|---|---|
| R2-T1-1、R2-T1-3、R2-T1-4 | B-05 | 两位都按"占位"判 L0（空白填写栏） | 三份过程都把名称、日期等安排类内容归为"事实空白，不编造"，其中两份还把留空方案写进了"替你决定的"——这正是《书》1.2 要分开的两类空白被混在一起 |
| 同上 | B-07 (b) | — | 三份过程的"排除的默认"只写了第一层默认和它的换值变体，没有第二层默认；三件在成品上又互相撞车（见下），按本标准复核未过 |

**D3 反例：第二层默认，同批撞车（两位评审都指出框架组同题三件撞在同一方向）**

| 编号 | 维度 | 为什么 |
|---|---|---|
| R2-T1-1、R2-T1-3、R2-T1-4 | D3 ≤ L2 | 三份独立运行的选定方向互为近亲（同一骨架），命中第二层默认识别第 2 条 |
| R2-T2-2、R2-T2-3、R2-T2-4 | D3 ≤ L2（R2-T2-4 见下） | 三份的选定方向是同一种分层着色的想法，命中第 2 条 |
| R2-T3-3、R2-T3-4、R2-T3-5 | D3 ≤ L2 | 三份的选定方向是同一种同心线收拢成标志的想法，命中第 2 条 |

**D3 维度切片候选**：R2-T2-4。成品两位评审都给 L3；视觉标准与镜头标准都把它作为"命中第二层默认，但多走了一步、让整体形状一眼可见"的范例。过程一侧能否到 L3，待两位评审按本标准复评。

**正例**：暂缺。第 3 轮起由两位评审按本标准评过程后补入；三种发散取向、三种收拢方式各至少一件。

**校准备注**：第 2 轮无框架组编了虚构阵容和票价，成品没被判 L0；那一组没有交付过程文件，无法按 B-06 判它是否把票价标成决定类，不作锚点。按本标准，同样的成品如果过程里没有把价格标"发布前须用户确认"，会判 B-06 未过——这是本标准与成品标准分工不同的直接例子。

## 7. 自动检查清单

脚本尚未实现，建议放在 `standards/tools/check_brief.py`，输出 `delivery`（T）、`judgment`（B）、`measure`（M）三段。输入：主控提供的原话文本、过程文件（UTF-8 纯文本或 Markdown）、成品（若有）。依赖：Python 标准库（`difflib`、`re`、`random`）；成品一侧调用视觉标准的 `check_visual.py` 对应项和一个中文 OCR。可复用《书》的 `domains/需求理解/scripts/draws.py`（抽取复现）、`stop_rule.py`（停止规则复算）、`xref_check.py`（交叉引用）。"人工确认"表示脚本只给候选。

本领域大部分判断只能人工做（近亲判定、替换测试、三问分类、默认满足测试）。脚本的作用是把人工要看的地方圈出来，并把能数的都数清。

## 8. 待实验阈值、跨标准对应与修订

### 8.1 待实验阈值一览

**底线里标"待实验"的阈值（1 个）**：B-13 (d) 不知情测试者人数（两人，取自镜头标准镜 B-02 的同一口径）。

本标准底线的其他判定都是计数为 0 或"有 / 没有"，判定步骤来自《书》（近亲三步、替换测试、三问、默认满足测试），不另设数字。

**维度里的待实验数（1 个）**：低级感"贯穿"的口径（同类问题出现在一半以上的栏目或条目中）。其余计数口径（局部 ≤ 2、≥ 2 条证据）沿用视觉标准第 3 节。D10 的"被认成同一系列的比例低于一半"取自《书》10.5。

**引用但不作判级依据的待实验数**：protocol 的完成标准起点 3–6 条；《书》5.1 停止规则的"连续两次"（只用来核对制作者是否照自己声明的规则停）；取向甲弃用率 50% 复查线。

**校准顺序**：① B-08 近亲判定的评审间一致性（两位评审独立对同一批方向逐对判，看一致率；不一致的对写进标杆库作判例）；② 第二层默认登记表（第 3 轮各取向的选定方向撞车数据）；③ B-13 (d) 的测试人数。

**校准来源**：评审数据（两位评审一致的判断）、用户对方向和简报的直接评价（"没想到""不是我要的"）、下游执行者的反馈（照简报做时卡在哪里）。单条数据不直接改阈值，累积成证据后按 `protocol.md` 修订；改动记入 `CHANGELOG.md`，旧版存入 `standards/archive/`。
