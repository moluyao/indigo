# 需求理解

创作模式的入口。用户给一句话，这本书负责把它变成一份可以交给制作的简报，而且全程遵守宪章公理 3「先放开，再收拢」：**不把一句需求扩写成唯一一份专业提示词；用户没说的，不替用户定死。**

本书所有数字、清单长度、阈值都是我从原理推出的起点值，不是规定；与禁用清单重合而保留的，理由见书末附录。

**怎么用这本书**
- 赶时间或是较弱的模型：直接看第 1 章的流程总图，然后照第 11 章的模板填。每一步都有"做到什么算完"。
- 想看一遍完整走法：第 12 章有三个演示。演示里的具体选择**只是一种走法**，不是答案。
- 想知道为什么：每章开头写了从哪条原理推出。

**全书术语**
- **合同**：用户亲口说的内容，原话照录，任何风格规则都不能改写它。
- **推断**：从合同、题材、平台推得出的约束，写成"我推断 X，因为 Y，你可以否决"。
- **空白**：没说、也推不出的东西。
- **事实空白**：空白里属于事实的那一类（数字、功能、引语、logo、史实）。它只能问、查或标缺失，不能被"决定"。
- **默认作品**：不费力就会做出来的那个作品。它是发散时第一个要被点名、然后排除的东西。
- **近亲**：只在表面（配色、文案、材质）不同、根上相同的两个方向。
- **方向**：一句话说得清的中心想法 + 它怎么组织 + 它排除了什么。
- **简报**：收拢之后交给制作的书面文件，模板见第 11 章。

## 〇、需求理解的六条第一性原理

**R1 回归中心律**（来自生成与认知）：任何生成者，人或模型，在没被约束的地方都会落回自己最熟悉的那一点。一句短需求里大部分维度都没被约束，所以如果没人看见这些空白，作品就会被默认值悄悄填满——用户拿到的是"没人决定过"的东西。

**R2 否决比回答便宜**（来自认知负荷）：让人凭空回答"你想要什么风格"很累，而且答案常是形容词；让人对一条写好的推断说"对 / 不对"几乎不花力气。所以能推断的写成推断让人否决，只把推不出、又贵的那几项拿去问。**唯一例外是事实**：事实推断错了，作品就不可信，所以事实只能问或查。

**R3 裁判律**（来自注意力与目的）：快还是慢、字多还是字少、炫技还是清楚——这些取舍本身没有对错，只有在知道"给谁看、看完要他怎样"之后才分得出胜负。没有受众和目的，所有取舍只能按默认去做。

**R4 固着律**（来自联想与创造性认知）：第一个冒出来的想法会挡住后面的想法，后面的方向会围着它打转、变成它的近亲。要离开它，只能先把它说出来，再明确排除；而且差异必须发生在根上（想法、结构），表面的不同不算。

**R5 代价梯度律**（来自生产）：方向错误越晚发现越贵，返工量按已做完的部分放大。所以发散、比较、确认都放在最便宜的载体上：先文字，再静帧或小样，最后才是整件作品。

**R6 可判律**（来自验收）：一条标准如果写不出"怎样算没做到"，验收时它就永远不会失败，也就不起作用。写进简报的每个数和条件，都必须是之后能拿来对照的东西。

每章开头标注推自哪几条。

## 第 1 章 流程总图，与第一步：把一句话拆成已说、隐含、空白（覆盖 Q1、Q2）

推自 R1、R2。

### 1.1 流程总图（任何模型都照这五步走）

```
① 理解  → 拆出 合同 / 推断 / 空白 / 事实空白，决定哪些要问（第 1–4 章）
② 发散  → 点名默认作品，再写出几个根上不同的方向，含至少一个非默认（第 5 章）
③ 收拢  → 从三种方式里按情况选一种，写出选择理由与放弃了什么（第 6 章）
④ 写简报 → 照第 11 章模板：完成标准 3–6 条、变量集中一处、禁止项（第 7、8 章）
⑤ 交给制作 → 指定第一个便宜的中间产物，以及谁来看它（第 9 章）
```

每一步都有"做到才能进下一步"的门槛：

| 步 | 进下一步的门槛 |
|---|---|
| ① | 每个维度都标了状态；每条推断都写了理由；每个事实空白都有处理方式 |
| ② | 默认作品已写出并排除；任意两个方向不是近亲；至少一个方向你自己觉得"平时不会这么做" |
| ③ | 写得出"选它是因为受众/内容的什么"，写得出"放弃的那个在什么条件下会更好" |
| ④ | 每条完成标准都写得出怎样算失败；简报里没有一个只靠形容词撑着的地方 |
| ⑤ | 下一步要看的东西比整件作品便宜得多，并且指定了看的人或测的方法 |

### 1.2 第一步怎么做：逐维度标状态

拿到需求，先把原话抄下来（这就是合同的全部来源），然后逐个维度过一遍下表，每一行只填两列：**状态** 和 **处理**。

| 维度 | 状态（四选一） | 处理（六选一） |
|---|---|---|
| 题材 / 对象 | 已说 · 隐含 · 空白 · 事实空白 | 照用 · 写推断 · 问 · 替定并声明 · 查 · 标缺失 |
| 受众（谁看） | | |
| 目标反应（看完他会说哪句话、做什么） | | |
| 观看情境（在哪看、有没有声音、看几遍） | | |
| 材料与事实（有什么真东西可以用） | | |
| 格式（尺寸、时长、交付形态） | | |
| 声音 | | |
| 中心想法 | | |
| 外观方向 | | |
| 结构 | | |
| 禁止项 | | |
| "好"的标准 | | |

这张表的维度可以增删，它不是固定问题组；判断是否漏项的方法是：**想象成品摆在面前，有哪一处是你说不出"这是谁决定的"？** 那一处就是漏掉的维度。

**状态的判定规则（照着判，不用凭感觉）**
- 原话里有这个词或同义词 → **已说**。
- 原话里没有，但能写出"因为原话里的 A / 平台 B / 用途 C，所以是 X"，且这句"因为"里不含你的审美偏好 → **隐含**。
- 写不出这样一句"因为"，或者"因为"后面只有"通常""一般都" → **空白**。"通常"就是 R1 说的中心，它不是推断。
- 属于数字、功能、名称、引语、标志、史实、人物 → **事实空白**，不管能不能"猜到"。

**处理的判定规则**
- 已说 → 照用。哪怕它和某种风格规则冲突，也照用户的做，再想办法让它融进同一个作品（Q2）。
- 隐含 → 写推断，放进简报让用户可否决。
- 空白 → 先过第 2 章的"返工测试"：答错会让一个以上的中间产物作废吗？会 → 问；不会 → 替定并声明，或留给发散去比较。
- 事实空白 → 问或查；都做不到就标缺失，并在第 4 章里决定作品怎样不需要它。

### 1.3 多层要求冲突时听谁的（Q2）

从高到低：
1. **底线**：事实、授权、平台硬规则、安全。任何层都不能覆盖。
2. **用户当下明说的**。
3. **项目或品牌已有的约束**。
4. **所选方向自己的规律**（第 6 章收拢后写下的那些）。
5. **风格、方法的原文**——只是研究资料。
6. **任何示例作品的具体做法**——最低，只说明"有人这样做过一次"。

推导：越靠上的越具体地属于这一次任务，信息量越大；越靠下的越是"别人某一次的样子"，照抄就是 R1 的回归（只不过回归的中心换成了那个示例）。

每当你在实现中偏离了第 4–6 层，在简报的"替用户做的决定"一栏记一行：偏离了什么、为什么。

### 1.4 三种拆法取向

- **取向 A：逐维度表格**（上面 1.2 的做法）。起点：每个维度一行，填完再往下走。适合较弱的模型、多人交接、需求很短的时候。推自 R1：维度被列出来，空白才被看见。
- **取向 B：从成品倒推**。先用三句话描述"如果现在交付，最可能交出的那个东西"，然后逐句问"这里的每个决定是谁做的"——凡答案是"没人，是习惯"的，就是空白。适合需求看起来"已经很完整"、实际藏着大量默认的时候。推自 R1、R4：默认作品先被说出来，它里面的默认值才能被一一认领。这是模型平时不会做的方向：模型习惯先做再解释，而不是先预演出默认再拆。
- **取向 C：从受众倒推**。先只写"谁会看到它、他当时在做什么、看完他会说哪一句话"，再从这句话推出其余维度的约束；推不出的才算空白。适合宣传、讲解、需要观众行动的作品。推自 R3：受众是唯一能裁决其他维度的东西，先定它，其余维度里很多"空白"会自动变成"隐含"。

三种可以叠用：先 C 再 A 是最省提问的组合；B 用来最后查漏。

### 1.5 故意违反

**完全不拆，照字面立刻做一版**，把这一版当作探针拿给用户看："这是不加思考会得到的东西，你哪里不想要？"适合用户自己也说不清要什么、但看到东西就能说出不要什么的情况。代价：这一版就是默认作品，必须明确告诉用户它是探针，不能当成交付。

### 1.6 失败点预判

- **把推断写成已说**：简报里出现用户没说过的硬约束，却没有"可否决"的标记。发现方法：简报里每一条约束都要能指回原话里的一个词，或者带着"推断"标记，两样都没有的就是偷渡的。
- **把空白当授权**：替用户换了题材、换了受众、加了用户没要的故事线。发现方法：把简报里的"题材"一行和原话对比，范围是否被扩大或替换。
- **把事实当空白来"决定"**：例如替一个 App 编了一个功能。发现方法：凡事实类维度的处理栏写着"替定"，一律打回。

### 1.7 自检

- 简报里的每一条约束，能否都指回原话的一个词，或者带"推断"标记？（能指回的比例应为 100%。）
- 维度表里"处理"栏写着"替定"的，有没有一项属于事实？（应为 0 项。）
- 写不出"这是谁决定的"的地方还剩几处？

## 第 2 章 要不要问、问什么、什么时候停下等确认（覆盖 Q3，兼及 Q25）

推自 R2、R5。

### 2.1 返工测试：一个问题值不值得问

对每个候选问题，写出一句："如果我猜错了，会作废什么？"
- 会作废**一个以上的中间产物**（例如整份方向、全部素材、时间轴）→ 值得问。
- 只会作废一个局部、改一下就好 → 不问，替定并声明。
- 答案是事实 → 必须问或查，不受此测试限制。

问题和它的后果写在一起交给用户，例如："投放在哪里？——它决定画幅和要不要按静音设计，猜错要整片重排。"这样用户能一眼看出哪个最贵、该先答。

**问几个**：不设固定上限。通过返工测试的有几个就问几个，按返工代价从大到小排。每个问题都附一个推荐答案和理由，并写明"不回答就按推荐做"——这样用户只回答他在乎的那几个，其余等于否决权没有行使（R2）。

### 2.2 确认密度：各家分歧，两端都是取向（待实验）

骨架把"确认节点多少"标为分歧，没有任何对照实验。下面不裁决，只写清各自适合的情况。

- **取向 A：一次问清，然后全自主**。起点：开工前一次性发出全部通过返工测试的问题（附推荐答案）；之后只在完成时交付，中间产物只用于自检。适合：用户不在场、明说"直接做"、任务小、方向的取舍不涉及用户的价值判断。代价：方向错了要到最后才知道。
- **取向 B：在便宜的中间产物上逐级确认**。起点：每当下一步的成本明显高于上一步（文字 → 静帧 → 小样 → 整件），就在跨过去之前停一次。适合：用户在场且愿意被打断、成本高、方向牵涉品牌或个人品味。代价：打断多，用户可能疲劳。推自 R5。
- **取向 C：不问，只交"决定清单"**（模型平时不会默认做）。起点：一句也不问，直接把所有推断和替定的决定写成一张清单，**和作品一起**交给用户，每项都标"如果你不同意，改这一项会影响哪些部分"。适合：用户明确交出决定权、但事后有可能否决。推自 R2：否决权被保留到事后，而且是有地图的否决。

**用户说"直接做"时**：跳过提问，但第 11 章简报里的"推断"和"替用户做的决定"两栏仍然要写，只是不等确认。自主不等于不留痕。

**批准后又要改场景、风格或时长**：回到收拢那一步重新确认，不在实现里悄悄改（Q23 原理）。

### 2.3 授权的写法（Q25）

"放开做""给我惊喜"不是方向，是一个空白（见禁用清单第 1 条）。拿到这类授权时，把它翻成两条可执行的东西：
- **你被允许不沿用什么**（例如现有的风格、上一支作品的结构）。
- **你仍然必须保留什么**（事实、品牌、平台规则、用户明说的任何一项）。

资深人设（"你是顶级导演"）不写进简报：它不可检验（R6），真正约束行为的是顺序、条件和禁止项。

关于"长提示词还是流程"的贡献比例，现有说法依赖策展标记与互动快照，属于**弱证据，待实验**；本书的立场只到这一步：一句话需求 + 本书流程，应当能做到不输长提示词——这本身也待实验验证（见第 13 章）。

### 2.4 故意违反

**先交东西再问**：不问，直接做两个差得很远的便宜样子（一句话描述加一张草图即可），用"你更接近哪一个"代替所有问题。适合用户说不清、但看得出差异的情况。前提是两个样子必须根上不同，否则这只是在让用户挑配色。

### 2.5 失败点预判

- **问一长串礼貌性问题**：发现方法：每个问题后面是否都跟着"猜错会作废什么"。写不出的删掉。
- **号称自主却步步都问**：发现方法：数一数确认节点是否都发生在"成本跃升"处；不在跃升处的确认是打扰。
- **没听到素材就先定视觉**：用户给了声音、录屏等素材时，先描述你从素材里得到了什么，再提方向（第 4 章）。

### 2.6 自检

- 每个发出的问题，都附了推荐答案和"猜错的后果"吗？
- 有没有任何一个问题，其实是事实却被包装成"偏好"？
- 确认节点数是否等于"成本跃升"的次数？

## 第 3 章 受众、目标反应与观看情境（覆盖 Q5、Q6、Q29）

推自 R3。

### 3.1 受众写到什么颗粒度

判断标准只有一条：**这句受众描述，能不能在两个候选方向之间判出胜负？** 能，就够了；不能，就再具体一点。

- 不够："年轻人""大家""推特用户"（平台不是受众，见禁用清单第 42 条）。
- 够了的例子："刚工作一两年、月底才发现钱不够、从没坚持记过账的人。"——拿它去比"炫酷科技感"和"一个月底的窘迫瞬间"，立刻能判。

### 3.2 目标反应：写成观众的一句话

不写"让人觉得专业"，而写**观众看完会对朋友说的那一句话**，例如"这个记一笔只要两秒"。理由：形容词不可检验（R6），一句话可以拿去测——给不知情的人看成品，问他"它在说什么"，对照这句话。

再写一个**行动**（如果有）：看完要他做什么，在哪里做。没有行动的作品（例如壁纸）就写"没有"，这本身也是一个决定。

### 3.3 观看情境决定强度

把观看情境写成三个事实：
- **在哪看**：信息流里自动播放、主动点开、设成背景反复看到、网页里滚动经过。
- **有没有声音**：默认静音的情境，画面必须独立成立（第 7 章 7.7）。
- **看几遍**：只看一次的东西可以更大胆；会被反复看到的东西（壁纸、网页常驻动画、界面动效），每一次的惊喜都在衰减，而每一次的打扰都在累积，所以要更轻、更安静。

这一条推导自注意力的适应：重复的刺激收益递减，干扰却不递减。

**画幅与语言**：不同画幅不是同一构图缩放；长中文可能需要另一套布局。观看情境确定后，把"需要几个画幅"写成推断。

### 3.4 理解水平怎样传导到深浅和术语（Q29）

受众水平写成三档之一并说明依据：外行 / 入门 / 同行。然后照下表推：

| 受众 | 深浅 | 例子 | 术语 |
|---|---|---|---|
| 外行 | 只给直觉，一个机制都不展开 | 一个贯穿全片的具体例子 | 只点名观众之后会去搜的那一个，说一次，可以上屏 |
| 入门 | 直觉 + 一个关键机制 | 一个例子，最后推广一步 | 点名并给一句白话解释 |
| 同行 | 跳过直觉，直接给差异点 | 可以用对比代替例子 | 正常使用，不解释 |

推导：直觉靠白话建立，但术语是观众事后能搜、能复述的把手；一次都不点名，观众看懂了也找不回来。这张表是起点，不是规定。

### 3.5 三种确定受众的取向

- **取向 A：问**。适合委托方明确有目标人群（商业宣传）。
- **取向 B：从题材和平台推断，写成可否决的一句**。适合用户不在场、题材自带人群。
- **取向 C：把受众当成发散的一个维度**（模型平时不会默认做）。受众本身就是空白时，不急着定，而是让第 5 章里不同方向面向不同受众——"给从没记过账的人"和"给已经在用别家记账 App 的人"是两部完全不同的片。收拢时连受众一起收。适合受众没说、且受众的选择本身就是最大的创作决定时。推自 R3、R4。

### 3.6 需求方不是终端观众

委托方喜欢的和观众需要的冲突时，不替任何一方裁决。把冲突写出来交给委托方："你要的 X 会让 Y 观众在第几秒看不懂，可选方案是……"。这一条原料没覆盖，推演见第 13 章。

### 3.7 故意违反

**不写受众，写"反受众"**：只写"这件东西明确不是给谁的"。适合用户自己也说不准给谁、但很清楚讨厌被当成什么人的情况（例如"不是给理财达人的"）。它能排除一大片默认，但不提供方向，必须和一个中心想法配套。

### 3.8 失败点预判

- **默认给同行看**（禁用清单第 41 条）：术语多、节奏快、默认观众懂行。发现方法：把成品给一个按受众描述挑选的人（或按这个水平模拟）看，问他第一处看不懂在哪。
- **受众写得太宽**：发现方法：3.1 的判胜负测试。

### 3.9 自检

- 受众描述能否在两个候选方向之间判出胜负？
- 目标反应是不是一句观众会说出口的话（不含"专业""高级"这类词）？
- 观看情境里"看几遍"写了吗？

## 第 4 章 材料与事实：有什么、缺什么、绝不编什么（覆盖 Q4、Q27）

推自 R1、R2、R6。

### 4.1 从作品的"主张"倒着盘

不要先列手头有什么，而是先列**作品将会在画面或声音里说出的每一句主张**（每个数字、每个功能、每个名字、每张界面、每个地点），然后给每一条贴一个来源标签：

- **〔给〕** 用户提供的
- **〔查〕** 能从可公开核实的地方查到的（记下出处）
- **〔造〕** 由我们自己搭出来、且本身就是真的（例如：真实运行的代码画出的图、本地时间、我们自己拍的东西）
- **〔无〕** 以上都不是

推导：从主张出发，才能抓住"作品要说、但没人给过证据"的那一项；从手头材料出发，只会盘点到已有的东西，漏掉的恰好是会被编造的那部分（R1：模型会在空白处补上最像的假数据）。

**〔无〕的四种处理**（选一种，写进简报）：
1. **改结构**，让作品不需要这一条主张。
2. **降级**到次一级的真材料（没有界面截图 → 只展示真实存在的 logo 和名字）。
3. **显式占位**，并在交付清单里列为"待用户补"。占位要少：每多一个占位，作品就多一处看起来未完成。
4. **问**。

不允许的第五种：编一个。禁用清单第 40 条（编造的用户数、评价、logo，灰色占位界面）就是这一条失败的样子。

### 4.2 唯一事实来源

主张多于三四条时，把所有〔给〕和〔查〕的内容抄进一个"事实清单"，规定**画面上出现的每个数字和说法都只能来自这张清单**。这样核查就变成逐项比对（R6），而不是凭印象。核查由不参与制作的执行者做更好：做的人看不见自己的盲点。

史实、地理类内容在清单里多一列"可信度"；示意性的内容（地图、流程图）在作品里声明是示意。现当代真人、真实商标、真实系统界面：读真的，不凭记忆画；平台的系统界面和控件不要重画或改色，它们是观众认出"这是真的"的锚点。

### 4.3 三种盘材料的取向

- **取向 A：主张倒推**（4.1）。适合宣传、讲解、新闻类，主张多、可信度要紧的作品。
- **取向 B：材料先行**。用户给了很强的真材料（一段录音、一批照片、一段录屏）时，先不提方向，先用文字把"我从材料里看到 / 听到了什么"交还给用户：时长、段落、转折、最有力的一刻、瑕疵。方向从材料长出来。推自 R2：用户对"你听到的对不对"的判断几乎不花力气，却校准了后面的一切。
- **取向 C：零材料，把"没有"当成题材**（模型平时不会默认做）。完全没有真材料时，不去编，也不去找图库凑，而是选择**只用本身就是真的东西**：文字本身、数字本身、此刻的时间、观众自己的设备、作品自身的运行状态。适合信息极少的需求（例如只有一个名词）。推自 R1：在没有约束的地方，选一个"不可能是假的"约束，比选一个"看起来像真的"假象更不会落回默认。

### 4.4 授权

每样〔给〕和〔查〕的材料都标一句：能不能公开用、需不需要告知来源。按本项目规则，作品画面、封面、文案里都不出现素材署名；"告知"只发生在交给用户的文件里，不进作品。

### 4.5 故意违反

**故意让缺失可见**：把〔无〕直接做进作品，例如一块明确标着"这里本该有数据，但它不存在"的空位。适合讲"信息不透明""没人统计过"本身就是论点的作品。只在缺失就是内容时使用，不能用来掩饰没做完。

### 4.6 失败点预判

- **"做不到"被说成"风格如此"**：发现方法：每一项省略都要归类为"有理由的设计选择"或"带阻塞原因的未完成项"，归不进去的就是在包装。
- **占位过多**：发现方法：数占位，超过主张总数的一小部分（由你按作品判断并写下）就改用 4.1 的第 1 种处理。

### 4.7 自检

- 画面上每一条主张都贴了标签吗？〔无〕的有没有一条悄悄出现在作品里？（应为 0。）
- 事实清单之外的数字有几个？（应为 0。）

## 第 5 章 发散：写出几个根上不同的方向（覆盖 Q9、Q17、Q18、Q19）

推自 R4、R5。这是公理 3「先放开」的那一半。

### 5.1 发散的五个动作（照顺序做）

**动作 1：点名默认作品。** 用两三句话写出"不费力就会做出来的那个东西"，再写出它的**显而易见的变体**和**可预测的反面**（默认是亮的，反面就是暗的；默认是热闹的，反面就是空的）。三者都不进候选，只作为参照物。

识别默认时按四层查，每层写一句：
- 表面层：第一时间想到的配色、字体、特效、缓动。
- 构图层：标题放哪、元素怎么排。
- 结构层：怎么开场、中间是什么区块串、怎么结尾。
- 声音层：第一时间想到的音乐和音效。

禁用清单第 29–40 条是已知的默认外观，可以直接对照。其中"深色水面 + 波浪 + 居中白字"一条来自单需求单次运行的肉眼判断，属于**弱证据，待实验**，不要推广成"所有题材都会落到这里"。

**动作 2：挖题材的独有事实。** 列出只有这个对象才有的东西：它的名字和名字的含义、它在哪里、它真实的数字、它面对的约束、它的仪式和时刻、它世界里的印刷物和物件、它的反面、它在互联网出现之前是什么样、它如果是一件实物会是什么样、相邻品类拥有而它缺少的那种感觉。信息极少时，至少写出"它的使用者一天中哪一刻会想起它"。

**动作 3：从不同的"根"出发写方向。** 每个方向只写两三句：**中心想法 + 怎么组织 + 它排除了什么**。不同方向要从不同的根出发，可选的根有：
- 一条独有事实（动作 2）
- 一种受众（3.5 取向 C）
- 一种结构（一个瞬间、一条因果链、一组对照、一次跨尺度的旅行、一个反复的动作）
- 一种借来的媒介或品类——可以翻风格词汇库当"还有哪些可能"的地图，例如 S84（拟物载体与行业原生材质）、S86（借用别的品类）、S27（只用字）、S82（产品界面自演），以及词汇库"地图空白"里尚无原料的方向。**词汇库里的条目都不是默认，引用时按编号，并说明为什么属于这个题材。**
- 需求的字面画面——**最多占一个方向**（禁用清单第 38 条：字面意象做唯一方向是 AI 默认）。

**动作 4：查距离，合并近亲。** 两个方向之间按四层比较：

| 层 | 内容 |
|---|---|
| L1 中心想法 | 它在说什么 |
| L2 结构 | 它怎么组织时间或空间 |
| L3 材质 | 它用什么媒介、什么物件 |
| L4 表面 | 颜色、字、文案 |

**规则：任意两个方向必须在 L1 或 L2 上不同；只在 L3、L4 上不同的，是近亲，合并成一个。** 辅助测试：把方向 A 的描述里的名字换成方向 B，读起来仍然成立，它们就是近亲。

**动作 5：确认至少一个非默认方向。** 对每个方向问："不看这本书，我第一次会写出它吗？"至少有一个答"不会"。如果所有方向都答"会"，回到动作 2，从"它的反面"或"它在互联网之前的样子"重新出发。

**什么时候停**：不设固定数量（禁用清单第 18、19 条）。一直写，直到连续写出的新方向都被动作 4 合并掉——这说明你已经离开最强联想的引力范围又回来了。最少要留下：一个非默认方向，和至少一个与它根上不同的方向。第 12 章三个演示分别停在不同的数量。

**写多长**：每个方向两三句文字。这是 R5：发散发生在最便宜的载体上，收拢之后才画、才搭。

### 5.2 参照与标杆（Q17）

发散时可以找参照，但每个参照都要写两行：**学它的什么**（构图、节奏、镜头语法、色彩逻辑、配乐结构）和**不拿它的什么**（角色、设计、旋律、具体镜头、logo、字体、版式、素材）。用户点名喜欢的某个属性，必须原样保留到成品里。

第一个想到的参照往往是所有人都在用的那个；从题材正典之外找（片头、印刷、游戏、舞台、科学插图、行业自己的印刷物）更能拉开距离。参照的描述要来自真实地看过、量过，不来自记忆。

### 5.3 三种发散取向，以及外部注入与自省的分歧（待实验）

- **取向 A：事实驱动**。每个方向都扎根于一条独有事实（动作 2）。适合题材本身信息丰富的需求。推自 R4：独有事实是品类联想之外的、最近的出口。
- **取向 B：自省排除**。先写满默认、变体、反面，再从排除后剩下的空间里找。适合信息很少、事实挖不出多少的需求。这是分歧的一端：靠模型自己认出自己的默认。
- **取向 C：外部注入**（分歧的另一端，模型平时不会默认做）。不让模型自己想，而是用一个外部机制给出少数几个选项——例如用随机数从风格词汇库里抽两三个编号、或从"地图空白"里抽一项——模型只能在这几个里选，并写出它为什么属于这个题材；写不出就重抽。适合模型反复落回同一类方向时。代价：抽取库自身的边界会变成新的"库味"。

B 与 C 哪个更好，骨架标为分歧，没有对照实验，**待实验**。

### 5.4 对已有体系的局部扩展不发散

用户只是要在已建立的视觉体系里加一个页面、换一张图、改一句文案时，不发起方向竞赛；直接沿用已有体系。发散只用于"方向本身是空白"的需求。

### 5.5 故意违反

**只写一个方向，但把它的默认版本也做出来对照**：适合用户已经非常明确、不需要发散，但你想证明这个方向比默认好的情况。

### 5.6 失败点预判

- **几个方向是同一个方向换皮**（禁用清单第 22 条）：发现方法：动作 4 的距离表。
- **所有方向都是受众每天用的同一类工具的样子**（工具的戏服）：发现方法：数一数方向里有几个的 L3 是"产品本身的外观"，超过一个就重写。
- **发散变成了写长文**：每个方向超过三句，就是在提前实现。

### 5.7 自检

- 默认作品、变体、反面三者都写了吗？
- 任意两个方向在 L1 或 L2 上都不同吗？
- 有几个方向答了"我第一次不会写出它"？（≥ 1。）

## 第 6 章 收拢：三种方式，各自何时用（覆盖 Q20、Q21）

推自 R3、R5。这是公理 3「再收拢」的那一半。

### 6.1 先选收拢方式（照判定表选）

| 情况 | 用哪种 |
|---|---|
| 用户在场；取舍涉及用户自己的品味、品牌、风险偏好；方向用几句话就能让用户看懂差异 | **方式一：让用户挑** |
| 方向在文字上分不出高下，差异主要在观感、节奏、手感上；预算允许做几段小样 | **方式二：小样两两比较** |
| 用户不在场，或明确交出决定权；方向的差异能用"哪个更承载这个内容和受众"判断 | **方式三：按内容契合度自选** |

三种都不是默认。同一种需求在不同情况下应当用不同方式（第 12 章三个演示各用了一种）。

### 6.2 方式一：让用户挑

- **前提**：候选真的根上不同（第 5 章动作 4 已过），而且用户看得懂差异。给用户几个近亲让他挑，等于让他挑配色。
- **怎么给**：每个方向两三句，加一句"它适合你如果……"和一句"它会放弃……"。可以附一个推荐和理由，但推荐不能只是"最稳的那个"。
- **用户的选择是最高等级的校准**，记下来（第 10 章）。

### 6.3 方式二：小样两两比较（本领域语料几乎无人用过，待实验）

- **小样是什么**：每个方向只做最能代表它的那一小段——一张静帧、几秒运动、一个交互片段。小样按最终标准做那一小段，不做粗糙版（粗糙版比较的是粗糙程度，不是方向）。
- **怎么比**：一次只比两个；先写好比较维度（从第 8 章的完成标准里挑一两条，例如"静音下第一眼能否说出它在讲什么"）；最好由不参与制作的人判断，不告诉他哪个是谁做的。多于两个方向时两两淘汰。
- **代价**：贵。只在文字方案确实判不出时用。推自 R5：它把文字上的争论换成观感上的证据，能抓住文字方案看不出的失败。

### 6.4 方式三：按内容契合度自选

- **判据**：哪个方向的材质和结构最能承载这个内容、这个受众、这个观看情境。逐个回答三问：
  1. 它和题材的独有事实绑得多紧？（换成同类对象还成立吗？不成立更好。）
  2. 受众在它的情境里能否得到目标反应那一句话？
  3. 在现有材料和工具能力下，它能不能被做到最终标准？
- **禁止的判据**："最安全""最稳""最不会出错"（禁用清单第 23 条）。最安全的方向通常就是离默认最近的方向（R1）。如果三问之后最契合的恰好是最保守的那个，必须多写一句：它在哪一问上胜过了非默认方向。
- **借用**：选定后，看落选方向里有没有一个元素能让它更强，借过来，但只借一个，且要能融进选定方向的世界。

### 6.5 收拢理由的写法（三种方式通用）

四句话，缺一不可：
1. **选了什么**（一句话复述方向）。
2. **为什么契合**——理由必须落在内容、受众或情境上，不能只有形容词。
3. **放弃了什么**。
4. **被放弃的方向在什么条件下会更好**（例如"如果投放在大屏而不是手机，B 会更好"）。

第 4 句让收拢可以回退：条件变了，用户知道该换哪个。

### 6.6 防止实现阶段悄悄变安全（Q21）

收拢完写一份**方向承诺**，放进简报（第 11 章第 4 栏），只写三样：
- **它拥有的那个想法**，以及它拒绝的那个默认（直接引用动作 1 写下的默认作品）。
- **它自己的世界**：把所有文字去掉，还能认出是这部作品的那套视觉 / 运动 / 声音语言，用一两句话说清。
- **第一眼**：观众最先看到的那一刻是什么。

检查方法：读一遍承诺，如果它读起来只是一种情绪（"温暖而有力量"），就还没定，重写。实现中每当要用一个现成组件、现成特效，问一句"它说的是这个方向的语言吗"——成品组件混进来的地方，就是方向失守的地方。

方向承诺是内部文件，不出现在作品里。方案阶段可以先自评、点名最弱的一项改掉，但自评有偏差，最终仍由不参与制作的人评。

### 6.7 故意违反

**不收拢，做成系列**：几个方向都做，每个都完整。适合用户本来就需要多件（例如一组壁纸、一个账号的连续几期），或者方向的差异本身就是想展示的东西。前提：每一件都按同一套完成标准验收。

### 6.8 失败点预判

- **收拢理由只有形容词**：发现方法：6.5 第 2 句里有没有出现一个受众、内容或情境里的具体名词。
- **方向在实现中被磨平**：发现方法：交付前对照方向承诺逐条核对，再把默认作品的描述读一遍——如果成品更像默认作品而不像承诺，就是被磨平了。

### 6.9 自检

- 收拢方式是按 6.1 的判定表选的，还是习惯？
- 收拢理由四句都有吗？
- 方向承诺去掉文字后还能认出作品吗？

## 第 7 章 简报写多细：颗粒度、风格怎么交代、禁止项（覆盖 Q7、Q8、Q10、Q11、Q12、Q13、Q14、Q15、Q16）

推自 R1、R3、R6。

### 7.1 总规则：写意图还是写参数，按"谁执行、要不要一致"选

骨架把"风格主体写成意图还是参数"（Q10）、"简报里写不写具体值"（Q12）标为分歧。下面三档都是取向，不裁决，**待实验**：

- **档一：意图档**。只写"每个元素承担什么任务、为什么"（例如"颜色只用来区分'你的钱'和'别人的钱'两类"），具体值留给执行领域推导。适合执行者能力强、需要它推广到简报没写到的部分时。风险：意图写得含糊时比参数更危险。
- **档二：参数档**。写成可逐条核对的数值和规格（时长、画幅、色值、字号）。适合多人或多次执行要保持一致、或验收要逐项比对时。风险：参数就是"形"，会被照抄，并排除同一方向里其他合法的做法。
- **档三：参照档**（模型平时不会默认做的那种写法）。用一个具体参照物指向一个点，并写清"学它的什么、不拿它的什么"（5.2）。一个参照一句话能带出许多共现的决定。适合意图说不清、参数又太死的时候。风险：参照可能已经被用滥，而且被用滥的程度无法事先测量。

**不管选哪档，有两条不变**：
1. **只堆形容词的地方一律不算写了**（禁用清单第 2 条）。凡简报里出现"高级、现代、电影感、科技感"这类词，后面必须跟一句意图、一个参数或一个参照，否则删掉。
2. **终检：把标题换成同类的另一个对象，这份简报还成立吗？** 成立，说明方向太泛（R1）。

### 7.2 格式与技术约束（Q7）

格式数字只在被验收引用时才有意义：**写进简报的每个格式数字，第 8 章的完成标准里都要能找到对它的检查**；找不到的，要么删掉，要么补一条检查。

- 用户说了的照用。
- 能从平台推出来的写成推断（例如"手机竖屏"）。
- 推不出的（例如时长），不写"默认值"（禁用清单第 24、25 条是行业默认组合）。用内容推：先写出作品必须让观众得到的几个意义单元，每个单元需要多少时间被看清、读完，加起来就是时长的起点；再拿观看情境（3.3）去裁。
- **生产能力边界**写成约束：所用工具能可靠做到什么、超出就会失败的是什么。这来自工具，不来自审美。昂贵步骤前写明成本，等确认。

技术约束不产生好作品，它只让失败可见；所以技术规格写满而中心想法空着的简报，等于没写。

### 7.3 结构写到什么粒度（Q8）

三档，按"执行者要自己发挥多少"选：
- **粗**：只写几个段落的名称和每段承担的任务。适合执行领域（动效、镜头与叙事）会自己展开时。
- **中**：写成一条**状态变化链**——每一段里"观众此时理解了什么、情绪怎样变"。不写时间。
- **细**：按时间切段，每段写画面里有什么（名词）、在做什么（动词）、为什么。适合必须对齐声音或口播的作品。

不管哪档：**每段只承担一个任务**；没有任务的段落删掉；写明全片挂在哪个时钟上（画面自身、口播、音乐），交给动效与声音领域（第 14 章）。镜头表里不许写抽象口号（"展示强大"），只能写看得见的事件。

### 7.4 运动、镜头、转场写到哪一层（Q11）

需求理解这一层只交代**运动的含义**和**全片是否统一一种语法**，不写曲线与时长——那是动效领域的事（第 14 章）。具体写：
- 每一种运动要解释什么（没有含义的运动是装饰）。
- 全片是否一镜到底、是否允许切、转场由什么承接（物件、动作、方向，还是硬切）。
- 用少量准确的术语，不用形容词。

### 7.5 色彩与字体（Q12）

需求理解这一层写**逻辑**：颜色和字体分别承担什么任务、品牌色出现在哪里（作为底、作为强调、还是只在首尾）、需要预判的联动（例如"调暗后文字对比还够吗"）。具体值是否写进简报，按 7.1 选档。色相和字体不按品类选（禁用清单第 37 条），从中心想法和受众推。

### 7.6 声音什么时候定（Q13）

声音来源（用户自有、合成、配音、静音、由发布者在平台内自选）必须在视觉方案之前写下，因为下游一切时间点都要挂在某个时钟上。按本项目规则，视频号成片默认不混配乐，由发布者在 App 内自选——这是平台规则带来的约束，写成"推断"并可被用户推翻。用户给了音频时，按 4.3 取向 B 先把听到的结构交还给用户。

### 7.7 静音和开头的观众（Q14，各家分歧，待实验）

写下两样东西：**静音观众必须理解的那一两个想法**，以及它们各自落在哪一刻。

开头立即交付还是允许悬念，骨架标为分歧：
- **取向 A：立即交付**。开头就给出主题或承诺，后面用来证明。适合信息流、静音自动播放、观众随时会划走的情境。
- **取向 B：延迟交付**。开头用一个问题、一个冷场或一个看不懂的局部吸住人，稍后揭开。适合主动点开的观看、悬念本身就是吸引力的片种。必须写明理由，并且开头那一刻本身要有足够的东西可看（否则就退化成禁用清单第 39 条：慢开场、结尾才揭晓）。

"开头几秒内必须交付"不作为无推导的硬规则写进简报（禁用清单第 26 条）；具体时刻由观看情境推出。

### 7.8 禁止项与反向定位（Q15）

禁止项写四类，每类只写**这一次真正可能落进去的**，不照搬清单：
- **外观上的**：从第 5 章动作 1 的默认作品里直接抄出最具体的两三样。
- **结构上的**：默认作品的开场方式和区块串。
- **内容上的**：编造、版权素材、敏感对象、出现素材署名。
- **技术上的**：闪烁、某类不可接受的帧。

再写一句**反向定位**："它不是一支……，它更像……"。

警告：禁止项只说"不要什么"。**只有禁止项、没有中心想法，作品会落到禁止区外最近的那个默认**——所以禁止项必须和方向承诺（6.6）同时出现。"禁止项比风格词更起作用"的说法来自单个模板的解读，属于**弱证据，待实验**。

### 7.9 可替换变量集中一处（Q16）

简报里会变的东西——主角、题材名、文案、品牌名、颜色角色、具体数字——全部放进第 11 章模板的"变量区"，正文只引用变量名（例如写〈产品名〉而不写真名）。推导：换内容时只改一处，避免连带改动；同时能看清哪些是"这一次"的，哪些是方向本身的。

**提醒**：变量集中后，最危险的用法是把整份简报当模板换皮复用——那正是禁用清单第 6–11 条那类固定区块串的来历。简报属于一次任务；下一次任务重新走第 1–6 章。

### 7.10 故意违反

**极简简报**：只写一句方向承诺 + 3 条完成标准，其余全部留给执行。适合执行者很强、且你想看到它自己的推导时。代价：可检查性下降，必须靠第 8 章的标准兜底。

### 7.11 失败点预判

- **规格写满，想法空着**：发现方法：方向承诺那一栏是否少于其他任何一栏。
- **简报写得过细，替执行领域做了决定**：发现方法：简报里出现曲线、帧数、色值时，问一句"这是用户或方向要求的，还是我顺手定的"。顺手定的，降回意图档。

### 7.12 自检

- 简报里每个形容词后面都跟了意图、参数或参照吗？
- 把标题换成同类对象，简报还成立吗？（应不成立。）
- 每个格式数字都能在完成标准里找到检查吗？

## 第 8 章 完成标准：做到什么算完（覆盖 Q22）

推自 R3、R6。

### 8.1 写 3–6 条，每条都能失败

**为什么是 3–6 条**：少于 3 条，至少有一类观众侧效果（看懂、看清、记住）没人管；多于 6 条，执行时记不住，标准之间开始互相冲突，等于没有优先级。这是起点，不是规定。

每一条写成三段：**观众侧现象 + 测法 + 怎样算失败**。例如：
> 静音观看时，第一眼就能说出它是关于〈产品名〉的什么。测法：截第一个完整构图的帧，给不知情的人看，问"这在讲什么"。失败：他说不出〈核心功能〉。

### 8.2 从哪里挑这 3–6 条

先从**观众侧**挑（基础可交付性——能播、尺寸对、时长对、字能读——已经普遍达标，不能区分好坏；这一判断来自单个需求的单次实测，**弱证据，待实验**，但它方向上与 R3 一致）：

| 观众侧问题 | 可用的测法（举例，按作品选） |
|---|---|
| 读得完吗 | 逐段数字数，对照停留时间 |
| 看得清吗 | 在目标设备尺寸下截图看；取样文字与背景的对比 |
| 静音能懂吗 | 关声音给不知情的人看 |
| 开头能说出是什么吗 | 首帧或首个完整构图给人看 |
| 节奏拖吗 | 标出所有"没有新信息"的时段，量它们的长度 |
| 有自己的样子吗 | 把名字遮住，问"这能是任何一个同类产品的吗" |
| 目标反应达到了吗 | 给按受众描述挑的人看，让他用一句话复述，对照 3.2 那句话 |

再补**必保项**：方向承诺里最有辨识度的那一两个元素，逐项列出，防止迭代中被丢掉。

再补**差异项**（如果有上一支作品或参照）：在哪一层（第 5 章的 L1/L2）必须与它不同。

### 8.3 预判失败点写进标准

列出这类作品最可能出问题的地方（偏色、闪烁、循环接缝、文字重叠、元素被系统界面遮挡、穿模），挑最可能的一两项写成标准。经验靠积累，写进简报就是把经验变成检查项。

### 8.4 三种写标准的取向

- **取向 A：全部可自动测**。只写能用截图、取样、计时、数数测的条目。适合无人值守、要反复迭代的任务。风险：观众侧最重要的"有没有自己的样子"测不到。
- **取向 B：以盲评为主**。只写两三条，全部由不知情的人回答（"它在讲什么""你会记住哪一刻"）。适合讲解、宣传、需要目标反应的作品。
- **取向 C：用反例定义成功**（模型平时不会默认做）。不写"要做到什么"，而写"如果它被误认为下面这个东西，就算失败"——直接把第 5 章的默认作品写成反例。测法：把成品和默认作品的描述一起给不知情的人，问"它更像哪一个"。适合方向容易在实现中被磨平的时候。推自 R4、R6。

哪些观众侧效果能自动测、哪些只能盲评，各家划分不一，**待实验**。

### 8.5 不能写的标准

- "如果不够好就重做"（禁用清单第 4 条）：不可判。
- 混进手法的标准（"必须用某种转场"）：那是风格规定，不是标准（宪章公理 2）。手法写在方向承诺里，标准只评观众侧效果。

### 8.6 故意违反

**只写一条标准**：适合极小的任务或纯实验作品，用唯一一条最重要的观众侧问题定成败，让执行者在其余方面完全放开。

### 8.7 失败点预判与自检

- 失败点：标准全是交付侧（尺寸、格式），观众侧一条也没有。发现方法：逐条问"这条是观众感觉得到的吗"。
- 自检：每条都写了"怎样算失败"吗？至少一条是观众侧的吗？必保项列了吗？

## 第 9 章 交给制作：第一个便宜的中间产物，与第二轮怎么改（覆盖 Q23、Q24）

推自 R5、R6。

### 9.1 第一个中间产物选哪个

每种中间产物只回答一个问题，按你最怕错的那个问题选：

| 最怕错的是 | 先做 |
|---|---|
| 方向本身 | 文字方案（就是简报）给用户看 |
| 观感、构图 | 一张按最终标准做的静帧 |
| 节奏 | 低清的节拍草稿或联系表 |
| 全片的共性（字幕、质感、镜头幅度、声音电平） | 一镜按最终标准做的样板 |
| 交互手感 | 一个能真用的最小交互片段 |

规则：样板按最终标准做那一小段，不做"先糙后精"（糙的样板确认了也不能当基线）。中间产物先由执行者自己看过、测过、修过，再给用户。用户要求全自主时，中间产物只用于自检。

"样板先行能避免成倍返工"方向可信，但量化来自单个项目复盘，**弱证据，待实验**。

### 9.2 交接时说清三件事

1. 这份简报交给哪些领域（第 14 章）。
2. 第一个中间产物是什么、谁来看、用哪条完成标准判。
3. 哪些决定是替用户做的、可以被推翻（简报第 3 栏）。

### 9.3 第二轮修改意见（Q23）

每一条意见写成三段：
- **现象**：哪一段、哪个元素、什么情况下（"第二段，金额数字在暗底上读不清"）。
- **目标**：要变成什么样，尽量可测或可对照（"在手机尺寸截图里，数字和底的对比能一眼读出"）。
- **验证**：怎么确认改好了（"重截同一帧对比"）。

**模糊愿望要翻译**：用户说"高级一点""更活泼"时，不要默默选一种诠释（常常会选最俗的那种）。把它翻成两三个可选方向让用户点："高级"可以是更少、更慢、更空，也可以是更浓、更重、更有材质——两者都合法。

**一次改几处**：互相牵连的改动一次只改一组，并写明联动（动作更快 → 声音更密；调暗 → 复查文字对比）。批准后的大改（场景、风格、时长）回到第 6 章重新收拢。

**先自检再给方向**：先让执行者自己对照简报，说出"描述的"和"做出的"差在哪里，再补充意见。

### 9.4 三种交接取向

- **取向 A：简报一次交完**，执行领域自己安排中间产物。适合执行者能力强。
- **取向 B：简报 + 指定第一个中间产物**（9.1）。适合较弱的执行者或高成本作品。
- **取向 C：先交"反向简报"**（模型平时不会默认做）。执行领域收到简报后，先用自己的话把简报复述一遍，并写出"我打算怎么做"的三句话，交还给需求理解这一步核对，核对过才开工。推自 R2：误解在最便宜的文字层就暴露。

### 9.5 故意违反

**跳过中间产物，直接做整件**：适合整件本身就很便宜（例如一张静态壁纸），中间产物的成本接近整件时，没有理由多一步。

### 9.6 失败点预判与自检

- 失败点：修改意见只说"不好"不说改哪（禁用清单第 5 条）。发现方法：每条意见是否三段齐全。
- 自检：第一个中间产物比整件便宜吗？每条修改意见都有验证方法吗？

## 第 10 章 连续作品、信号与回流（覆盖 Q25、Q26、Q28）

推自 R1、R4。

### 10.1 连续作品不继承上一支（Q28）

同类需求连续出现时，最大的风险是第 5 章动作 1 的"默认作品"悄悄变成了**上一支作品**。做法：
- 每支作品交付时，记下它的**结构指纹**：中心想法、结构、开场方式、结尾方式、构图形状、视觉语言、声音形状，各一句。
- 下一支发散时，把最近几支的指纹都当作"默认作品"的一部分，一起排除。
- 可以复用的是工具与技法；不复用的是外观（调色、舞台、镜头语法、转场）。

差异检查放在方案阶段最便宜，交付前再查一次，防止实现中回退。

**系列作品**需要统一识别时，把"统一的部分"写进变量区之外的固定区（例如系列名、一个固定的位置），其余每期重做。统一与差异的分界原料没覆盖，推演见第 13 章。

### 10.2 用什么信号判断"写法好不好"（Q26，弱证据）

- 同行收藏、点赞衡量的是"方法可复用"，偏向长的、带槽位的写法。
- 观众播放衡量的是"作品本身吸引人"，与提示词长度关系弱。
- 精选、被重制反映的是策展口味与早期传播。

我们要校准的是观众侧效果，所以同行收藏只能用来判断"哪些方法值得学"，不能用来判断"观众爱看什么"（禁用清单第 43 条）。这一节整体是**弱证据，待实验**：只有一份带互动数据的语料直接给出这一对比，有幸存者偏差；本项目平台的观众数据尚未积累。

### 10.3 三种回流取向

- **取向 A：按作品记录**。每支作品记下用户的选择（第 6 章方式一）和评审结论，累积到足够多再改书。
- **取向 B：按维度记录**。只记"哪个维度当初是空白、被我替定了、事后被用户推翻了"。积累后能回答骨架的知识缺口：用户实际否决推断的频率是多少。
- **取向 C：只记失败**（模型平时不会默认做）。只记录"成品被认成默认作品"的那些案例，以及当时漏掉的是哪个维度。适合想快速找到流程漏洞时。

单条数据不直接改书或标准，累积成证据后再改（宪章第四节）。

### 10.4 故意违反

**刻意继承**：用户就是要一个固定栏目、每期同一个样子时，照做。把"固定"写进合同，差异只发生在内容上。

### 10.5 失败点预判与自检

- 失败点：日志丢失，差异机制悄悄失效。发现方法：开工时找不到上一支的指纹，就先补写再发散。
- 自检：这一支的方向，和最近一支在 L1 或 L2 上不同吗？

### 演示一：「帮我做一张手机壁纸」

> 这只是一种走法：下面的方向、选择和数字都是示例。

**① 理解**

原话：「帮我做一张手机壁纸」。

| 维度 | 状态 | 处理 |
|---|---|---|
| 题材 | 空白 | 留给发散 |
| 受众 | 隐含 | 推断：用户自己用 |
| 目标反应 | 空白 | 替定并声明：每次亮屏不觉得腻 |
| 观看情境 | 隐含 | 推断：一天被看几十上百次；上面压着时钟或图标 |
| 格式 | 隐含 + 空白 | 推断：竖幅静态图；手机型号未知 |
| 锁屏还是主屏 | 空白 | 过返工测试：会决定画面哪块能放主体 → 问 |
| 材料 | 空白 | 可选：用户自己的一张照片 |
| 声音 | 不适用 | — |

关键推断：**看几遍**这一项决定了强度（3.3）——它会被看成百上千次，所以一切靠"第一眼惊艳"的做法都会迅速变成打扰。

要问的问题（只有两个通过返工测试）：
- 放锁屏还是主屏？推荐：都能用，主体放在中间偏下、时钟和底部图标都压不到的那一条带。猜错的后果：主体被时钟或图标盖住。
- 有没有一张你自己的照片想用？推荐：没有也行。猜错的后果：私人物件那个方向做不了。

**② 发散**

默认作品：深色底上紫蓝渐变的模糊光斑，或者霓虹城市夜景、山湖日落。变体：换成暖色光斑。反面：纯黑底一个细线小图形。三者都排除。

独有事实：这块画面每天被看很多次；上面永远压着时间；它离用户的手最近；它是用户的私人空间，不是给别人看的。

方向（写到第 6 个时，新冒出的两个都和已有的合并了，停在 4 个）：
- **方向 ① 给图标做底**：壁纸的任务是让上面的东西好认。大面积几乎没有变化的单一材质（一种真实纸张或织物的近拍），唯一的主体放在图标压不到的那条带。排除了："壁纸本身要好看"这个前提。
- **方向 ② 和时钟对话**（非默认）：画面里留一个形状正好的空位——一扇窗、一个门洞、一块空着的招牌——让锁屏的大号时间恰好落进去，时间成了画中物。排除了：时钟是遮挡物这个看法。
- **方向 ③ 你自己的一样东西**：用户的一张照片（钥匙串、窗外、一盆植物），按博物学图版的方式重画成一张标本图（参考风格词汇库 S14，只学"单个物件 + 精确线条 + 留白"的组织，不拿任何具体图版）。排除了：图库里的风景。
- **方向 ④ 只有一个字**（非默认）：整张壁纸是一个字或一句用户自己的话，字大到被裁切出画面边缘（参考 S27 的思路），天天看到等于天天被提醒一次。排除了：图像。

合并掉的：「月相壁纸」与 ② 近亲（都是"画面和时间关联"，L1 相同）；「城市线路图」与 ③ 近亲（都是"属于用户的私人地理/物件"，L1 相同）。

**③ 收拢：方式一，让用户挑**

理由：这是纯个人品味，没有第三方受众，唯一能裁决的是用户自己（6.1 第一行）；四个方向用两三句话就能看懂差异。

给用户的写法：每个方向一句"它适合你如果……"——① 适合主屏图标多、讨厌花哨的人；② 适合主要看锁屏、喜欢小机关的人；③ 适合有一样想天天看到的东西的人；④ 适合想给自己留一句话的人。

假设用户选了 ②。收拢理由四句：选了"时钟落进画中空位"；契合在于它把壁纸最大的遮挡物变成了内容，看一百次也只是时间在变；放弃了 ① 的"完全安静"；如果用户主要在主屏看手机，① 会更好。借用：从 ① 借"大面积安静材质"做空位周围的底，让画面耐看。

**④ 简报要点**（只列和模板不同的关键栏）
- 变量区：〈空位的形状〉= 一扇窗（可换门洞、招牌）；〈手机〉= 用户回答后填入屏幕比例与时钟位置。
- 做到什么算完：
  1. 在用户手机锁屏上实际设置后截图，时间数字完整落在空位内，四边都不压线。失败：任何一个数字压到空位边缘。
  2. 主屏截图里，所有图标的名字都读得清。失败：有一个图标名在壁纸上读不出。
  3. 把截图缩到缩略图大小，空位仍然看得出是一个"窗"。失败：缩小后只是一块色块。
- 不要：渐变光斑、霓虹、日落；画面里加任何文字或署名；第二个视觉中心。
- 反向定位：它不是一张"好看的图"，它更像一个给时钟用的画框。

**⑤ 交接**：交给视觉设计；写到意图档。整件很便宜，跳过中间产物（9.5），直接出成品，用第 1 条在真机上判。

### 演示二：「做一个高质量的网页动画」

> 这只是一种走法：下面的方向、选择和数字都是示例。

**① 理解**

原话：「做一个高质量的网页动画」。

| 维度 | 状态 | 处理 |
|---|---|---|
| 题材 / 动画为谁服务 | 空白 | 过返工测试：是某个产品页的一部分，还是一件独立作品？两者的方向、尺寸、交互完全不同，猜错整件作废 → 问 |
| "高质量" | 已说，但只是形容词 | 不当方向用；翻译成完成标准（第 7 栏） |
| 受众 | 空白 | 跟随上一问 |
| 观看情境 | 隐含 | 推断：在浏览器里，桌面和手机都可能打开；可能被反复打开 |
| 交互 | 空白 | 留给发散 |
| 格式 | 隐含 | 推断：单个网页，能离线打开 |
| 声音 | 隐含 | 推断：默认无声（浏览器通常不允许自动播放声音） |
| 材料 | 空白 | 视第一问而定 |

问题（只有一个通过返工测试）：
- 它是放在某个页面里、为某件东西服务的，还是一件单独拿出来展示的作品？推荐：当作独立作品做，一个页面一件事。猜错的后果：方向和尺寸全部重来。

假设用户回答："就是展示用的，你看着办。"——这等于交出决定权，但题材仍然空白。

"高质量"的翻译：它是一个形容词，按 7.1 必须变成可检查的东西。我把它翻成三条观众侧的含义（见第 7 栏），而不是翻成某种风格。

**② 发散**

默认作品：近黑底，跟随鼠标的粒子，紫蓝渐变光晕，标题逐字淡入，滚动时卡片依次浮起。变体：换成暖色粒子。反面：白底极简线条缓慢漂浮。三者都排除。

独有事实（网页这种媒介自己有、视频没有的）：观众手里有光标或手指；页面可以被滚动、被缩放、被调整窗口大小；它运行在观众自己的机器上，知道此刻的时间、窗口大小、观众停留了多久；它可以一直不结束。

方向（停在 5 个）：
- **方向 ① 滚动即时间**：没有自动播放，整件作品的进度就是滚动条的位置；一个物件随滚动跨越尺度变形（参考 S59 的思路）。排除了：自动播放的片头。
- **方向 ② 静止，直到你写**（非默认）：页面打开时什么都不动，只有一行小字；动画完全由观众的光标轨迹生成，停手就静止。参考风格词汇库"地图空白"第 15 条（完全静止作为风格，尚无原料）。排除了："动画就是要一直动"。
- **方向 ③ 只有字**：页面上只有一段话，所有动画都发生在字本身（重排、换行、字距随阅读位置改变，参考 S27）。排除了：图形。
- **方向 ④ 一个真实的量**（非默认）：动画可视化一个本身就是真的量——这个页面已经被打开了多少秒、本地此刻离日落还有多久——数字和图形都不是编的（4.3 取向 C）。参考 S69 的单色图解思路。排除了：装饰性动画。
- **方向 ⑤ 可以被弄乱的东西**：页面元素有重量，可以被拖、被扔、被堆起来，用物理驱动。排除了：只能看不能碰。

合并掉的：「鼠标跟随的流体」与默认作品近亲（只在 L3 不同）；「打字机效果」与 ③ 近亲。

**③ 收拢：方式二，小样两两比较**

理由：五个方向在文字上都说得通，真正的差异在手感和节奏上——"滚动即时间"和"静止直到你写"哪个更好，读描述判断不出（6.1 第二行）；用户已经交出决定权，所以不让用户挑。

先用契合度三问粗筛到两个：③ 在手机小屏上字的变化难以读清，淘汰；⑤ 和独有事实"运行在观众机器上"绑得不紧，换成任何互动玩具都成立，淘汰；④ 依赖的"真实量"太弱，观众不在乎页面开了多少秒，淘汰。剩 ① 和 ②。

小样：两个方向各做一个按最终标准的最小片段（① 做一段滚动，② 做光标生成的那部分），由一个不知情的人分别打开，比较维度只用一条：**"打开后十秒内，你有没有主动去动它？"**

假设 ② 胜出。收拢理由四句：选了"静止直到你写"；契合在于它用的正是网页独有、视频没有的东西——观众的手；放弃了 ① 的"讲一段完整的变形故事"；如果用户之后说这是某个产品页的头图，① 会更好，因为它能带着读者往下读。借用：从 ① 借"一个物件跨尺度"——观众写下的轨迹，滚动后可以被拉远成一整幅图。

**④ 简报要点**
- 变量区：〈开场那一行小字〉= ……；〈目标设备〉= 一台普通笔记本 + 一部普通手机。
- 做到什么算完（"高质量"的翻译）：
  1. 在目标设备上持续操作时不掉帧。测法：浏览器性能面板录一段操作。失败：出现可见的卡顿帧。
  2. 打开后，不知情的人在十秒内主动去动它。失败：他等着它自己动。
  3. 系统开启"减少动态效果"时，页面仍然完整可用。失败：内容消失或卡住。
  4. 把它和默认作品的描述一起给人看，问"它更像哪一个"（8.4 取向 C）。失败：答默认作品。
- 不要：粒子跟随鼠标、渐变光晕、逐字淡入、卡片浮起、任何自动播放的片头。
- 反向定位：它不是一个"炫技首页"，它更像一张等人落笔的纸。

**⑤ 交接**：交给动效节奏与视觉设计；写到意图档；第一个中间产物已经在收拢时做了（小样），开工时以胜出的小样为基线。

### 演示三：「给一款记账 App 做 15 秒宣传动效」

> 这只是一种走法：下面的方向、选择和数字都是示例。

**① 理解**

原话：「给一款记账 App 做 15 秒宣传动效」。

| 维度 | 状态 | 处理 |
|---|---|---|
| 时长 | 已说：15 秒 | 合同，照用 |
| 题材 | 已说：一款记账 App | 照用 |
| App 名、界面、它和别家不同的那一点 | 事实空白 | 必须问；不能替它编功能 |
| 投放在哪 | 空白 | 过返工测试：决定画幅、是否按静音设计 → 问 |
| 受众 | 空白 | 问，或在发散里当作维度（3.5 取向 C） |
| 目标反应 | 空白 | 依赖"不同的那一点"这个事实 |
| 画幅、帧率 | 空白 | 不填行业默认（禁用清单第 25 条）；等投放答案 |
| 声音 | 空白 | 推断：若投放在信息流，按静音可懂设计 |
| 用户数、评分、媒体评价 | 事实空白 | 用户不给就不出现，不编 |

问题（三个通过返工测试，按代价排序）：
1. 它和别家记账 App 最不一样的那一点是什么？能给几张真实界面截图或一段录屏吗？推荐：没有就只用 App 名和图标。猜错的后果：方向建立在不存在的功能上。
2. 投放在哪？推荐：手机竖屏信息流、静音自动播放。猜错的后果：画幅和开头策略全改。
3. 主要给谁看？推荐：从没坚持记过账的人。猜错的后果：节奏和例子要换。

假设用户只回答了第 1 题："最大特点是拍小票自动记账，截图有。"——第 2、3 题按推荐执行，写进第 3 栏可否决。

材料盘点（4.1 主张倒推）：
- 「拍小票能自动记一笔」〔给〕，截图为证。
- 「记账只要几秒」〔无〕——用户没给过时长数据，不能说；改结构，让画面里真实演一遍，观众自己看到有多快。
- App 名、图标〔给〕。用户数、评分〔无〕——不出现。

**② 发散**

默认作品：金币飞入、柱状图上升、绿色或蓝色品牌色、手机样机三维旋转、三个功能图标卡依次出现、结尾 logo 加下载按钮。变体：换成橙色。反面：黑白极简只出 logo 和一句标语。三者都排除。

独有事实：小票是纸做的、会褪色、会被揉成团塞在口袋里；记账的人通常是在月底才想起来；拍小票这个动作本身只有一下。

方向（写出 6 个后，新冒出的都与已有的合并，再合并掉 1 个近亲，剩 5 个）：
- **方向 ① 一笔的真实时长**：15 秒里只演一件事——从掏出一张小票到这笔账出现在列表里，用真实界面录屏（S82 的思路），不加速。排除了：功能列表。
- **方向 ② 口袋里的一个月**：开头是一团揉皱、褪了色的小票，一张张被展平、被拍下、变成整齐的一行行（参考 S84 的物件思路，小票就是这个行业原生的印刷物）。排除了：金币和图表。
- **方向 ③ 天气预报式的花销预报**（非默认）：借天气预报的语法（参考 S86）——"本周外卖：大概率；周末购物：局部有雨"——预报的依据就是被拍下的小票。排除了：理财品类的一切外观。
- **方向 ④ 月底那一刻**：一个人月底打开钱包发现钱不知去了哪——十二秒的小故事，App 只在最后三秒出现。排除了：产品前置。
- **方向 ⑤ 只有数字**：画面里只有金额数字本身，它们被拍进来、被归类、被加总（参考 S27 的思路）。排除了：界面和人物。

合并掉的：「小票像雪一样落下」与 ② 近亲（L1 同为"纸质小票变成有序数据"，只在 L2 节奏上略不同，不足以分开）。

**③ 收拢：方式三，按内容契合度自选**

理由：用户只回答了事实题，其余按推荐——等于交出了方向决定权（6.1 第三行）；而方向的差异可以用"哪个最承载'拍小票'这个独有事实"判断。

契合度三问：
- ① 绑紧了"拍一下就记"，但真实录屏在静音信息流里第一眼只是"一个手机界面"，第 2 问（受众能否得到目标反应）偏弱。
- ② 绑紧了"小票是纸、会被揉皱"这个只有它有的事实；第一眼就是一团揉皱的小票，静音也能认出；能用真实截图做最后一拍。三问都过。
- ③ 是非默认方向，记忆点最强，但"花销预报"是一个用户没给过的功能——画面会暗示一个不存在的能力（第 4 章），第 3 问不过。
- ④ App 只在最后三秒，15 秒信息流里大概率在出现之前就被划走（7.7 取向 A 的情境）。
- ⑤ 与"拍小票"绑得不紧，换成任何记账 App 都成立（第 1 问不过）。

选 ②。收拢理由四句：选了"口袋里的一个月"；契合在于它把这个 App 唯一的不同点（拍小票）变成了观众一眼就能认出的实物——一团揉皱的纸；放弃了 ③ 的强记忆点；如果这个 App 以后真的有了"花销预报"功能，③ 会更好。借用：从 ① 借"最后一拍用真实界面、不加速"。

方向承诺：
- 拥有的想法：揉皱的纸变成整齐的一行。拒绝的默认：金币、图表、样机旋转。
- 它自己的世界：纸的褶皱和褪色 vs 界面的干净对齐，全片只有这两种质感在交换。
- 第一眼：一团揉皱的小票，占满画面。

**④ 简报要点**
- 变量区：〈产品名〉；〈核心功能〉= 拍小票自动记账；〈画幅〉= 推断为竖屏，可否决；〈时长〉= 15 秒（合同）。
- 做到什么算完：
  1. 静音观看，首个完整构图的截帧给不知情的人看，他能认出"是小票"。失败：认不出或说成别的纸。
  2. 看完后让他一句话复述，复述里出现"拍小票"或同义的话。失败：只说出"记账 App"。
  3. 画面上每一条主张都在事实清单里（应为 0 条清单外主张）。失败：出现任何用户数、评分或未给出的功能。
  4. 最后一拍里的界面与用户给的截图一致。失败：界面是重画的或改了颜色。
- 不要：金币、柱状图、样机旋转、图标卡、绿色或蓝色作为"财务色"、编造的数字、素材署名。
- 反向定位：它不是一支"功能介绍片"，它更像一张小票被抚平的十五秒。

**⑤ 交接**：交给视觉设计、动效节奏、声音（静音可懂优先，配乐由发布者在平台内自选，属推断可否决）；写到意图档，第 4 条为参数档；第一个中间产物是"首帧静帧 + 最后一拍的真实界面静帧"两张，用第 1、4 条判。

## 第 13 章 补缺：骨架的知识缺口与原料没覆盖的问题（全部「待实验验证」）

每条是我的推演方案，不是结论。验证方法写在后面，供评审回流使用。

### 13.1 骨架各 Q 的知识缺口

| Q | 缺口 | 推演方案（待实验验证） | 怎么验证 |
|---|---|---|---|
| Q1 | 推断置信度多低必须改为提问 | 用"推断理由的来源"代替置信度：理由只来自原话 → 推断；理由含"通常/一般" → 不是推断，按空白处理；空白再过返工测试 | 记录每条推断是否被用户推翻，按理由来源分组统计推翻率 |
| Q1 | 用户实际否决推断的频率 | 第 10 章取向 B 按维度记录 | 累积后看哪些维度最常被推翻，把它们从"推断"改为"问" |
| Q2 | 风格的"本质"与"偶然"怎么分 | 替换测试：把这一项换掉，观众还认得出是这个风格吗？认得出 → 偶然；认不出 → 本质 | 盲评：给评审看替换前后两版，问是否同一风格 |
| Q3 | 确认密度对质量的影响 | 同一需求分别按 2.2 的 A、B、C 三种取向做，盲评对比 | 对照实验 |
| Q4 | 占位与降级对观感的影响；真材料占多少才够 | 起点：真材料不足以撑起中心想法时，改结构而不是加占位 | 同一作品做"占位版"与"改结构版"盲评 |
| Q5 | 受众写错与没写哪个代价大 | 推测"没写"更糟：写错的受众至少给出了一致的裁判，作品内部仍然统一 | 同一需求三版：正确受众 / 错误受众 / 无受众，给真实受众看 |
| Q5 | 目标反应句怎么验收 | 8.2 表最后一行：让按受众描述挑的人一句话复述，对照目标句的关键名词是否出现 | 记录复述命中率 |
| Q6 | 强度与完播的关系 | 起点：会被反复看的取轻，只看一次的可以重；完播数据回流后按平台分组校准 | 平台播放数据 |
| Q7 | 技术约束过细是否挤占创意 | 推测：技术约束本身不挤占，挤占的是"本该写想法的位置被技术规格占满"；检查方法见 7.11 | 对比"规格满、想法空"与"规格少、想法满"两版 |
| Q8 | 何时粗写、何时细写；短片要不要弧线 | 起点：必须对齐外部时钟（口播、音乐）的细写，其余粗写；不足一个意义单元的短作品不强求弧线，但要有一个"变化" | 同需求粗、细两档简报，比较产出质量与多样性 |
| Q9 | 只有一个名词时从哪挖独有事实 | 5.1 动作 2 的最后一条："它的使用者一天中哪一刻会想起它"；再从"它在互联网之前的样子"与"它的反面"各写一条 | 记录这三问各自产出被选中方向的比例 |
| Q10 | 参照的被用滥程度怎么测；意图与参数的比例 | 被用滥的近似测法：让一个不知情的模型对同题材"推荐一个参照"，它第一个说出的就是最被用滥的那个，避开它 | 统计该近似与评审判断的一致性 |
| Q11 | 写原则还是写公式 | 推测：公式让多次产出趋同，原则让产出分化但质量方差变大 | 同一方向两档简报各做多次，测差异与质量 |
| Q12 | 配色逻辑写到多细才能被稳定复现 | 起点：每种颜色写一个"它代表什么"的名词；能写出名词即可，不必写值 | 同逻辑给多个执行者，看产出是否都满足逻辑 |
| Q13 | 无配音的纯动效里声音是否仍应先定 | 推测：仍应先定"时钟来源"，但不一定先定声音本身；时钟可以是视觉拍（交给动效领域） | 对比先定声音与后配声音两版的对齐质量 |
| Q14 | 立即交付与悬念开场的留存差异 | 两端都保留为取向（7.7） | 平台留存数据 |
| Q15 | 有禁止项无想法 vs 有想法无禁止项 | 推测后者更好：想法给出方向，禁止项只给边界 | evidence-notes 已列的待实验项 |

| Q21 | 方向承诺的长度与约束力 | 起点：三样东西各一两句（6.6）；更长的承诺推测会被当成清单而失去重点 | 对比短承诺与长承诺的"被磨平"率 |
| Q22 | 哪些观众侧效果能自动测 | 8.2 表把测法分成了截图、计数、人工三类 | 统计自动测与盲评结论的一致率 |

### 13.2 原料整体没覆盖的问题

1. **需求本身错了**（例如要在极短时长里讲清复杂机制）。方案：先按第 3 章推出"受众要得到目标反应需要几个意义单元"，再按 7.2 推出所需时长；若超出用户给的时长，不默默删内容，而是写成选择题交给用户——"保留时长，只讲一点"或"保留内容，加长"或"改成系列"。待实验验证。
2. **受众与目的的验收**。方案：8.2 表最后一行的复述测试 + 发布后的真实数据回流。待实验验证。
3. **系列作品的统一与差异**。方案：统一的只放三类东西——名字、一个固定位置、一个固定的声音或色彩信号；其余每期按第 5 章重新发散，并用结构指纹排除上一期。统一部分的数量越少，每期的差异空间越大。待实验验证。
4. **多语言与本地化**。方案：语言当作观看情境的一部分写进第 5 栏；长中文、竖排、从右到左等情况在格式维度标"可能需要另一套布局"，交给视觉设计判断。待实验验证。
5. **需求方不是终端观众**。方案：两方偏好冲突时不裁决，写成"你要的 X 会让观众在……处看不懂，可选……"（3.6），由需求方决定，并把决定记在第 3 栏。待实验验证。
6. **简报颗粒度的反向代价**。方案：7.1 三档 + 7.10 极简简报作为对照组；同需求用不同档位各做多次，测作品之间的差异是否随颗粒度变细而变小。待实验验证。
7. **观众数据回流修正维度权重**。方案：第 10 章取向 B 的按维度记录；当某个维度在高播放作品中总是"被明确写过"、在低播放作品中总是"被替定"，就把它的处理从"替定"升为"问"。单条数据不改，累积后改。待实验验证。

## 第 14 章 和其他领域的接口

需求理解是入口，它的输出就是其他领域的输入。原则：**需求理解交意图和约束，不替下游定手法**；下游有自己的发散和收拢，在选定方向之内进行。

| 交给 | 交接什么 | 对方的对应位置 | 不交什么 |
|---|---|---|---|
| **视觉设计** | 受众、观看情境（在哪看、看几遍、设备尺寸）、方向承诺（拥有的想法、它自己的世界、第一眼）、颜色与字体的"任务逻辑"（7.5）、禁止项里的外观部分、事实清单与真实材料 | 视觉设计第 1 章（意图与观看场景）、第 3–5 章（它在方向内部再发散、收拢、排除机器默认感）、第 14–15 章（图像来源与真实界面） | 具体色值、字体名、版式——除非用户明说或简报选了参数档 |
| **动效节奏** | 全片挂在哪个时钟上（画面、口播、音乐）、结构颗粒度（7.3）、运动的含义与是否统一一种语法（7.4）、静音观众必须理解的想法及其时刻（7.7）、观看情境里的"看几遍" | 主时钟、整片能量形状、开场窗口等章节 | 曲线、时长、帧数 |
| **镜头与叙事** | 结构单位与每段任务、开头立即交付还是延迟交付的取向及理由、是否一镜到底、转场承接方式、受众理解水平（3.4） | 叙事结构与镜头语法 | 具体镜头表（除非选了细档） |
| **声音** | 声音来源（7.6）、平台规则（是否由发布者自选配乐）、是否按静音可懂设计、用户给的音频及"听到的结构"（4.3 取向 B） | 声音第 1 章（声音的职责与领拍者）、第 17 章（用户的声音、多语言版本与声源权利） | 具体曲目、音色、电平 |

**下游回传给需求理解的**：
- 任何一个下游发现"简报里的某项做不到"或"两项互相冲突"时，回到需求理解，按第 6 章重新收拢，或改简报第 3 栏，不在实现里悄悄改。
- 评审结论里"被认成默认作品"的案例，回流到第 10 章取向 C。

## 附录：禁用值自查

### A. 作为"取向或做法"被使用的命中项

1. **「三」作为收拢方式的数量**（可能被认为接近第 18 条"固定三个方向给用户挑"）。非它不可的推导：第 18 条禁的是**方向**固定为三个、**收拢**固定为让用户挑。本书的"三种收拢方式"是骨架 Q20 列出的三种机制（用户挑、小样比较、契合度自选），是对"由谁、用什么证据做决定"的完整划分——决定者只能是用户、不知情的第三方、或制作方自己，这三类穷尽了可能的裁判，不是挑出来的数字。方向数量本书明确不固定（5.1 饱和规则），三个演示分别停在 4、5、5 个方向，且各用了一种不同的收拢方式。**保留。**
2. **完成标准「3–6 条」**（可能命中第 21 条"固定若干轴打分"或第 27 条"固定上限"）。推导：这是用户为本书指定的要求；同时 8.1 给出了自己的推导——观众侧至少有"看懂、看清、记住"三类效果需要各有一条，下限因此是 3；超过 6 条标准之间开始互相冲突、失去优先级。它不是打分轴，没有分数和阈值，只有"怎样算失败"。**保留。**
3. **演示三的「15 秒」**（命中第 25 条"宣传片默认十五秒左右、横屏、三十帧的组合"）。推导：15 秒是用户原话里的合同（第 1 章：已说即照用），不是本书替用户选的默认值。第 25 条禁的是"未指定时默认填这个组合"；本书在演示三中**没有**默认填横屏或三十帧，画幅写成"推断：竖屏，可否决"，帧率留空交给下游。**保留。**
4. **演示三的「按静音可懂设计」「配乐由发布者在平台内自选」**。不命中禁用值；列出是因为它们来自本项目平台规则，书中都标为"推断，可否决"，不作为通用默认。**保留。**

### C. 结构同构自查
