# 需求理解

> 版本：r5，2026-11-19，按 r5 修订清单定点修订（含用户 2026-11-19 裁决：随机抽方向改为并列取向；完成标准不写数字）。r4 存档于 `archive/book-before-r5.md`；修订记录见书末附录 E 与「r5 修订记录」。

创作模式的入口。用户给一句话，这本书负责把它变成一份可以交给制作的简报，而且全程遵守宪章公理 3「先放开，再收拢」：**不把一句需求扩写成唯一一份专业提示词；用户没说的，不替用户定死。**

本书所有数字、清单长度、阈值都是我从原理推出的起点值，不是规定；与禁用清单重合而保留的，理由见书末附录。

**怎么用这本书**
- 赶时间或是较弱的模型：直接看第 1 章的流程总图，然后照第 11 章的模板填。每一步都有"做到什么算完"。
- 想看一遍完整走法：第 12 章有三个演示。演示里的具体选择**只是一种走法**，不是答案。
- 想知道为什么：每章开头写了从哪条原理推出。

**全书术语**
- **合同**：用户亲口说的内容，原话照录，任何风格规则都不能改写它。
- **推断**：从合同、题材、平台推得出的约束，写成"我推断 X，因为 Y，你可以否决"。
- **空白**：没说、也推不出的东西。
- **事实空白**：空白里关于真实世界的那一类——真实品牌的数据、真实人物说过的话、真实统计、史实、产品真有的功能、"有多少人认可"这类证明。它只能问、查或标缺失，不能被"决定"，也不能拿"示例"当借口编。
- **样稿空白**：样稿里用户自己日后会换掉的安排类内容——没给的活动名、日期、地点、阵容、价格、栏目名、文案。它**要填**：填一个明显合理的示例，在过程记录和替换表里注明"示例，可替换"；成品上不留空白填写栏、占位线或"XXX"。判别见 1.2。
- **默认作品**：不费力就会做出来的那个作品（第一层默认）。
- **第二层默认**：排除第一层默认之后，同行（或模型）最可能想到的"聪明的第二选择"。它同样要被写出来、一起排除（5.1）。
- **近亲**：一个方向只改了另一个方向里的一个值（换个颜色、换种材质、取个反），观众事后会用同一句话描述它们。判定见 5.1 动作 4。
- **方向**：观众事后会怎么描述它 + 它靠哪条题材事实站住、还缺什么；项数随读者和收拢方式增减（5.1"方向的写法"）。
- **简报**：收拢之后交给制作的书面文件，模板见第 11 章。

## 〇、需求理解的六条第一性原理

**R1 回归中心律**（来自生成与认知）：任何生成者，人或模型，在没被约束的地方都会落回自己最熟悉的那一点。一句短需求里大部分维度都没被约束。站在用户一侧看后果：他拿到成品时，分不出哪一处是照他的话做的、哪一处是生成者的习惯，也就无从否决那些习惯——他能否决的，只有被写出来让他看见的东西。所以空白必须先被看见、写下。

**R2 否决比回答便宜**（来自认知负荷）：让人凭空回答"你想要什么风格"很累，而且答案常是形容词；让人对一条写好的推断说"对 / 不对"几乎不花力气。所以能推断的写成推断让人否决，只把推不出、又贵的那几项拿去问。**唯一例外是事实**：事实推断错了，作品就不可信，所以事实只能问或查。

**R3 裁判律**（来自注意力与目的）：快还是慢、字多还是字少、炫技还是清楚——这些取舍本身没有对错，只有在知道"给谁看、看完要他怎样"之后才分得出胜负。没有受众和目的，所有取舍只能按默认去做。

**R4 固着律**（来自联想与创造性认知）：第一个冒出来的想法会挡住后面的想法，后面的方向会围着它打转、变成它的近亲。要离开它，只能先把它说出来，再明确排除；而且差异必须发生在根上（想法、结构），表面的不同不算。

**R5 代价梯度律**（来自生产）：方向错误越晚发现越贵，返工量按已做完的部分放大。所以发散、比较、确认都放在最便宜的载体上：先文字，再静帧或小样，最后才是整件作品。

**R6 可判律**（来自验收）：一条标准如果写不出"怎样算没做到"，验收时它就永远不会失败，也就不起作用。写进简报的每个数和条件，都必须是之后能拿来对照的东西。

每章开头标注推自哪几条。

## 第 1 章 流程总图，与第一步：把一句话拆成已说、隐含、空白（覆盖 Q1、Q2）

推自 R1、R2。

### 1.1 流程总图（五步；第 ② 步的做法有几种取向）

```
① 理解  → 拆出 合同 / 推断 / 空白 / 事实空白 / 样稿空白，决定哪些要问（第 1–4 章）
② 发散  → 写出第一层默认和第二层默认并排除，挖出独有事实，再从几种并列取向里选一种产生方向（随机抽值再判断 / 从事实直接写 / 借别的生成者扩大排除，第 5 章）
③ 收拢  → 从三种方式里按情况选一种（可组合），写出依据、前提和"前提变了换谁"（第 6 章）
④ 写简报 → 照第 11 章模板：完成标准、变量集中一处、禁止项、示例替换表（第 7、8 章）
⑤ 交给制作 → 指定第一个便宜的中间产物，以及谁来看它（第 9 章）
```

每一步都有"做到才能进下一步"的门槛：

| 步 | 进下一步的门槛 |
|---|---|
| ① | 每个维度都标了状态；每条推断都写了理由；每个事实空白都有处理方式；每个样稿空白都填了示例并进了替换表 |
| ② | 两层默认都已写出并排除；独有事实已编号冻结；每个方向都指得回一条事实；任意两个方向不是近亲；至少一个方向你自己觉得"平时不会这么做"；所选取向的停止规则已触发（5.1）。选了随机取向时，另按 5.1 取向甲的记录义务，每个方向都来自一次有记录的随机抽取 |
| ③ | 写得出选它所依据的、可核对的受众/内容事实；写得出"哪个前提一变就该换到哪个方向" |
| ④ | 每条完成标准都写得出怎样算失败；简报里没有一个只靠形容词撑着的地方 |
| ⑤ | 下一步要看的东西比整件作品便宜得多，并且指定了看的人或测的方法 |

### 1.2 第一步怎么做：逐维度标状态

拿到需求，先把原话抄下来（这就是合同的全部来源），然后逐个维度过一遍下表，每一行只填两列：**状态** 和 **处理**。

| 维度 | 状态（五选一） | 处理（七选一） |
|---|---|---|
| 题材 / 对象 | 已说 · 隐含 · 空白 · 事实空白 · 样稿空白 | 照用 · 写推断 · 问 · 替定并声明 · 查 · 标缺失 · 填示例 |
| 受众（谁看） | | |
| 目标反应（看完他会说哪句话、做什么） | | |
| 观看情境（在哪看、有没有声音、看几遍） | | |
| 材料与事实（有什么真东西可以用） | | |
| 格式（尺寸、时长、交付形态） | | |
| 声音 | | |
| 中心想法 | | |
| 外观方向 | | |
| 结构 | | |
| 禁止项 | | |
| "好"的标准 | | |

这张表的维度可以增删，它不是固定问题组；判断是否漏项的方法是：**想象成品摆在面前，有哪一处是你说不出"这是谁决定的"？** 那一处就是漏掉的维度。

**状态的判定规则（照着判，不用凭感觉）**
- 原话里有这个词或同义词 → **已说**。
- 原话里没有，但能写出"因为原话里的 A / 平台 B / 用途 C，所以是 X"，且这句"因为"里不含你的审美偏好 → **隐含**。
- 写不出这样一句"因为"，或者"因为"后面只有"通常""一般都" → **空白**。"通常"就是 R1 说的中心，它不是推断。
- 属于关于真实世界的断言（真实品牌或产品的数据与功能、真实人物的言论、统计、史实、"多少人用过 / 评价多高"这类证明）→ **事实空白**，不管能不能"猜到"。
- 属于样稿里的安排类内容（用户自己的活动名、日期、地点、阵容、价格、栏目名、文案），用户没给 → **样稿空白**。

**事实空白和样稿空白怎么分**（D1，r5 补第 3 问与"决定类"）。三问，任一答"是"就按事实处理：
1. 这句话是在替**用户以外的人或公共世界**作证吗？（别人的话、别人的数据、公共统计、史实。）
2. 这句话的作用是**证明**"它好 / 它可信 / 有人认可"吗？（用户数、评分、获奖、"老店""最受欢迎"。）——即便是用户自己的品牌，证明类内容填错了就是虚假宣传，而且它的唯一作用就是让人相信，示例值没有任何用处。
3. 这句话描述的是**已经如此的状况**，用户不能凭一句决定让它变成真的吗？（"新手跟得上""停车方便""师傅会修古董表"——这些是对现状的描述，用户说了不算，得看实际情况。）

三问都答"否"的，是安排类内容：用户一句话就能把它定下来（几点集合、在哪、收多少钱、叫什么名），它的作用是让样稿看起来完整、让用户看到版面和节奏，任何合理的值都能完成这个作用，所以填。推自 R2：用户看着一份填好的样稿说"日期改成某天"几乎不花力气；对着一排空白填写栏，他看不到成品的样子，也判断不了方向。

**安排类里的"决定类"**：观众会据此花钱、花时间或赶到某处的安排类内容（价格、时间、地点、报名或预约方式）。判别问："观众照着这一项去做，示例值错了，他会白跑一趟或多花钱吗？"会 → 决定类。它仍是**样稿空白**（用户一句话就能定，不是事实），所以照样**填示例**，成品上不留空栏；但它多三条约束，推自 R2 的例外理由（错了由观众承担，落在 1.3 甲层）：
- 替换表里这一行标"决定类：发布前必须由用户确认"；
- 交付说明里替换表排第一项（4.6、9.2），决定类各行排在表的最前面；
- 用户没有逐行确认之前，作品只能当样稿，不能发布；发布前核对一次成品里的值和用户确认的值逐字一致。

一项内容既像安排又像现状时（"每周六都跑"是安排，"跑了两年"是现状），按句子拆开分别判。

**处理的判定规则**
- 已说 → 照用。哪怕它和某种风格规则冲突，也照用户的做，再想办法让它融进同一个作品（Q2）。
- 隐含 → 写推断，放进简报让用户可否决。
- 空白 → 先过第 2 章的"返工测试"：答错会让一个以上的中间产物作废吗？会 → 问；不会 → 替定并声明，或留给发散去比较。
- 事实空白 → 问或查；都做不到就标缺失，并在第 4 章里决定作品怎样不需要它。
- 样稿空白 → 填示例。示例要"明显合理"：符合题材常识、彼此不矛盾（日期是星期几要对得上，价格和档次相称）；在过程记录里逐条注明"示例，可替换"，并全部列进简报第 6 栏的替换表（第 11 章），保证交付时一条不漏地交还给用户决定类另加上面三条约束。

### 1.3 多层要求冲突时听谁的（Q2）

先不排层，先问两件事：**违反它的代价由谁承担？它离这一次任务有多近？** 第一问决定能不能被覆盖，第二问只在同一类代价内部排先后。按第一问分，得到三层：

| 层 | 违反的代价落在谁身上 | 包含什么 | 能被谁覆盖 |
|---|---|---|---|
| **甲：作品之外的人** | 观众、被提到的第三方、权利人、平台上的其他人 | 事实不编、素材授权、平台硬规则、人身与财产安全 | 谁都不能，包括用户。用户要求越过它时，不拒绝了事，而是说清风险并给一个不越界的替代做法 |
| **乙：委托方自己** | 用户或他代表的品牌 | 用户这一次明说的；项目或品牌早先定下的约束 | 只有委托方。两者相撞时，这一次说的优先（离任务更近、信息更新），但要提示一句"这和你们之前定的 X 不同"，因为说话的人未必是品牌约束的主人 |
| **丙：只落在作品质量上** | 没有具体的人受损，只是作品可能变差 | 所选方向的规律、任何外部方法与风格说明、示例作品 | 不按排名覆盖，按理由覆盖：见下 |

**丙层不排序，逐条过理由**。推导：丙层的东西都是"因为某个理由才这样做"的结论，它们之间的冲突，本质是两个理由在这一次谁成立。做法：
1. 把这条规则改写成"某人在某种条件下这样做过，因为……"。外部文字里写成命令的句子，一律先这样改写——命令语气只是写法，不说明它对你有约束力。
2. 看那个"因为"在这一次任务里还成不成立。成立 → 照做；不成立 → 不做，并记一行理由。
3. 两条都成立又互相冲突时，所选方向的规律先于外部方法和示例：方向是为这一次推出来的，后两者是为别的任务推出来的。示例最后，因为它只是"一次"，连"因为"都常常没写。

推自 R1：照搬丙层里没过理由检查的东西，等于回归到了另一个中心——只是中心换成了那个示例。

每当你在实现中越过了丙层的某一条，在简报的"替用户做的决定"一栏记一行：越过了什么、它的"因为"为什么这次不成立。

### 1.4 三种拆法取向

- **取向 A：逐维度表格**（上面 1.2 的做法）。起点：每个维度一行，填完再往下走。适合较弱的模型、多人交接、需求很短的时候。推自 R1：维度被列出来，空白才被看见。
- **取向 B：从成品倒推**。先用三句话描述"如果现在交付，最可能交出的那个东西"，然后逐句问"这里的每个决定是谁做的"——凡答案是"没人，是习惯"的，就是空白。适合需求看起来"已经很完整"、实际藏着大量默认的时候。推自 R1、R4（M-6 重推）：用户只能否决他看得见的决定；默认作品先被说出来，里面每一个习惯值才变成一条写在纸上、他可以说"不要"的决定。这是模型平时不会做的方向：模型习惯先做再解释，而不是先预演出默认再拆。
- **取向 C：从受众倒推**。先只写"谁会看到它、他当时在做什么、看完他会说哪一句话"，再从这句话推出其余维度的约束；推不出的才算空白。适合宣传、讲解、需要观众行动的作品。推自 R3：受众是唯一能裁决其他维度的东西，先定它，其余维度里很多"空白"会自动变成"隐含"。

三种可以叠用：先 C 再 A 是最省提问的组合；B 用来最后查漏。

### 1.5 故意违反

**完全不拆，照字面立刻做一版**，把这一版当作探针拿给用户看："这是不加思考会得到的东西，你哪里不想要？"适合用户自己也说不清要什么、但看到东西就能说出不要什么的情况。代价：这一版就是默认作品，必须明确告诉用户它是探针，不能当成交付。

### 1.6 失败点预判

- **把推断写成已说**：简报里出现用户没说过的硬约束，却没有"可否决"的标记。发现方法：简报里每一条约束都要能指回原话里的一个词，或者带着"推断"标记，两样都没有的就是偷渡的。
- **把空白当授权**：替用户换了题材、换了受众、加了用户没要的故事线。发现方法：把简报里的"题材"一行和原话对比，范围是否被扩大或替换。
- **把事实当空白来"决定"**：例如替一个产品编了一个功能。发现方法：凡事实类维度的处理栏写着"替定"或"填示例"，一律打回。
- **把样稿空白当事实空白，留一排空栏**（D1 反向失败）：成品上出现"活动名称：____""日期待定"、灰条、占位线。用户看不到成品的样子，样稿失去作用。发现方法：在成品里搜下划线串、"待定""XXX""此处填写"这类字样，以及没有内容的框。

### 1.7 自检

- 简报里的每一条约束，能否都指回原话的一个词，或者带"推断"标记？（能指回的比例应为 100%。）
- 维度表里"处理"栏写着"替定"或"填示例"的，有没有一项属于事实？（应为 0 项。）
- **可测量**：成品（含样稿）里的空白填写栏、占位线、"XXX / 待定 / 此处填写"字样数 = 0；替换表的条数 = 维度表里"填示例"的条数。
- **可测量**：用户指定要上屏、要念出或要照用的文字（他给的店名、口号、一句原话；不是整句需求），在成品里逐字出现，字符差异数 = 0（错一个字就算失败）。需求里没有这类文字时，本条记"不适用"。
- **可测量**：替换表里标"决定类"的行，发布前逐行有用户确认记录（没有的 = 0）。

## 第 2 章 要不要问、问什么、什么时候停下等确认（覆盖 Q3，兼及 Q25）

推自 R2、R5。

### 2.1 返工测试：一个问题值不值得问

对每个候选问题，写出一句："如果我猜错了，会作废什么？"
- 会作废**一个以上的中间产物**（例如整份方向、全部素材、时间轴）→ 值得问。
- 只会作废一个局部、改一下就好 → 不问，替定并声明。
- 答案是事实 → 必须问或查，不受此测试限制。

**每个问题附带什么，从用户回答时要做的三个判断推**（M-6 重推）：他要先判断"这个值不值得我花力气答"——所以附**猜错的后果**；再判断"我怎么答最省力"——所以附一个**推荐答案**，让他只需点头或否决（R2）；最后判断"我不答会怎样"——所以写明**不答就按推荐做**。三个附带项各对一个判断；用户不在场、任务全自主时，三个判断都不发生，问题只记进过程记录，不附带。例如："投放在哪里？——它决定画幅和要不要按静音设计，猜错要整片重排。"这样用户能一眼看出哪个最贵、该先答。

**问几个**：不设固定上限。通过返工测试的有几个就问几个，按返工代价从大到小排。附带项照上面三条写——这样用户只回答他在乎的那几个，其余等于否决权没有行使（R2）。

### 2.2 确认密度：各家分歧，两端都是取向（待实验）

骨架把"确认节点多少"标为分歧，没有任何对照实验。下面不裁决，只写清各自适合的情况。

- **取向 A：一次问清，然后全自主**。起点：开工前一次性发出全部通过返工测试的问题（附推荐答案）；之后只在完成时交付，中间产物只用于自检。适合：用户不在场、明说"直接做"、任务小、方向的取舍不涉及用户的价值判断。代价：方向错了要到最后才知道。
- **取向 B：在便宜的中间产物上逐级确认**。起点：每当下一步的成本明显高于上一步（文字 → 静帧 → 小样 → 整件），就在跨过去之前停一次。适合：用户在场且愿意被打断、成本高、方向牵涉品牌或个人品味。代价：打断多，用户可能疲劳。推自 R5。
- **取向 C：不问，只交"决定清单"**（模型平时不会默认做）。起点：一句也不问，直接把所有推断和替定的决定写成一张清单，**和作品一起**交给用户，每项都标"如果你不同意，改这一项会影响哪些部分"。适合：用户明确交出决定权、但事后有可能否决。推自 R2：否决权被保留到事后，而且是有地图的否决。

**用户说"直接做"时**：跳过提问，但第 11 章简报里的"推断"和"替用户做的决定"两栏仍然要写，只是不等确认。自主不等于不留痕。

**批准后又要改场景、风格或时长**：回到收拢那一步重新确认，不在实现里悄悄改（Q23 原理）。

### 2.3 授权的写法（Q25）

"放开做""给我惊喜"不是方向（禁用清单第 1 条）。先问：**一句空泛授权，比一份能执行的授权少了什么信息？** 授权是把一部分决定权交出来；要接得住，至少得知道三件事，而空泛授权三件都没说：

1. **交出来的是哪些决定**。"放开"指的是外观、结构、受众，还是连题材都能换？不知道范围，执行者要么只敢动表面（结果是默认作品换了颜色），要么越界替用户换了题材。补法：把第 1 章维度表里的每一行标"开放 / 锁定"；合同和甲层（1.3）永远锁定，其余按原话推断，写成可否决。
2. **怎样算赢**。"惊喜"是谁的惊喜、用什么判？没有判据，执行者只能用自己的口味判，而自己的口味就是 R1 的中心。补法：借第 8 章写一条观众侧标准，例如"给不知情的人看，他说出的第一个比喻不是同类作品常用的那几个"。
3. **能承受往哪边错**。大胆的作品可能"太怪、用不上"，稳妥的作品可能"太平、没人记得"。空泛授权没说用户更怕哪一种。补法：从授权的措辞推断（"给我惊喜"推断为宁可太怪），写成可否决的一句："如果做出来偏怪，你能接受吗？不能的话我收到哪一档"。

三件补齐，授权才变成方向的起点。资深人设（"你是顶级导演"）不写进简报：它不可检验（R6），真正约束行为的是顺序、条件和禁止项。

关于"长提示词还是流程"的贡献比例，现有说法依赖策展标记与互动快照，属于**弱证据，待实验**；本书的立场只到这一步：一句话需求 + 本书流程，应当能做到不输长提示词——这本身也待实验验证（见第 13 章）。

### 2.4 故意违反

**先交东西再问**：不问，直接做两个差得很远的便宜样子（一句话描述加一张草图即可），用"你更接近哪一个"代替所有问题。适合用户说不清、但看得出差异的情况。前提是两个样子必须根上不同，否则这只是在让用户挑配色。

### 2.5 失败点预判

- **问一长串礼貌性问题**：发现方法：每个问题后面是否都跟着"猜错会作废什么"。写不出的删掉。
- **号称自主却步步都问**：发现方法：数一数确认节点是否都发生在"成本跃升"处；不在跃升处的确认是打扰。
- **没听到素材就先定视觉**：用户给了声音、录屏等素材时，先描述你从素材里得到了什么，再提方向（第 4 章）。

### 2.6 自检

- 每个发出的问题，都附了推荐答案和"猜错的后果"吗？
- 有没有任何一个问题，其实是事实却被包装成"偏好"？
- **可测量**：确认节点数 = 成本跃升次数；交付时附带的"替你做的决定"条数 ≥ 维度表里"替定"的条数（少一条就是有决定没留痕）。

## 第 3 章 受众、目标反应与观看情境（覆盖 Q5、Q6、Q29）

推自 R3。

### 3.1 受众写到什么颗粒度

判断标准只有一条：**这句受众描述，能不能在两个候选方向之间判出胜负？** 能，就够了；不能，就再具体一点。

- 不够："年轻人""大家""推特用户"（平台不是受众，见禁用清单第 42 条）。
- 够了的例子："下班后想动一动、但一个人跑不下去的上班族。"——拿它去比"燃脂打卡型的激励片"和"一群人一起出发的那一刻"，立刻能判。

### 3.2 目标反应：按目的类型写成可检验的形态

目的不只一种，可检验的形态也不只一种。分类从一个问题推（M-6 重推）：**看完之后，在观众身上的哪里能观察到它起作用了？**——在他当场说出的话里、在他隔一段时间无提示想起的东西里、在他手上做的事里、在他当下的状态里、在他发给别人的东西里。每一个观察位置就是下表的一行；表是开放的，作品要的效果落在别处（例如"改变一个看法"，观察位置是看前看后对同一问题的回答）就加一行，按同样三列写。先判这件作品**主要**要观众得到哪一类结果，再按那一类写；有副目的的，副目的另写一行，但只按主目的裁决取舍。推导：理解、记忆、行动、情绪在观众一侧留下的痕迹不同，能测到它们的时刻和方法也不同（R6）；用一种形态去写所有目的，就会有一类永远测不到。

| 主目的 | 写成什么 | 怎么检验 | 写坏的样子 |
|---|---|---|---|
| **理解** | 观众能用自己的话说出的一个因果或一个区别："A 是因为 B""A 和 B 差在 C" | 看完让不知情的人复述，看复述里有没有那个"因为"或那个"差在" | 只写"让人明白 X"——没说明白到哪一步 |
| **记忆** | 一个事后能被**无提示**想起的东西：一个名字、一个画面、一个说法 | 看完隔几分钟、做点别的事之后再问"刚才那个叫什么 / 你记得哪一幕"，不给选项 | 写"让人印象深刻"——不知道要记住的是哪一样 |
| **行动** | 一个动作 + 在哪里做 + 什么时候想做："看完当场扫码报名" | 行动入口出现时，不知情的人能否说出"现在要点哪里、做什么"；发布后看真实转化 | 写"引导用户行动"——动作和入口都没定 |
| **情绪** | 一对相反的情绪里偏向哪一端，以及在哪一刻转向："从紧张到松一口气" | 给观众一对词（紧张 / 松弛）让他选，看选择是否偏向目标那端；或看他是否回看 | 写"温暖感人"——两个词都只指向一片区域 |
| **被转发** | 观众会把它发给谁，附哪一句话 | 问不知情的人"你会发给谁、配什么话"，看答案是否落在目标人群 | 写"有传播力" |

写好后，**再写一个行动**（如果有）：没有行动的作品就写"没有"，这本身也是一个决定。

### 3.3 观看情境决定强度

把观看情境写成三个事实：
- **在哪看**：信息流里自动播放、主动点开、设成背景反复看到、页面里滚动经过。
- **有没有声音**：默认静音的情境，画面必须独立成立（第 7 章 7.7）。
- **看几遍**：只看一次的东西可以更大胆；会被反复看到的东西（常驻背景、界面里的动效、每天打开的页面），每一次的惊喜都在衰减，而每一次的打扰都在累积，所以要更轻、更安静。

这一条推导自注意力的适应：重复的刺激收益递减，干扰却不递减。

**画幅与语言**：不同画幅不是同一构图缩放；长中文可能需要另一套布局。观看情境确定后，把"需要几个画幅"写成推断。

### 3.4 理解水平怎样传导到深浅和术语（Q29）

**先回答：理解水平要不要分档？** 只有当分档能判出不同做法时才分。按"外行 / 同行"这类人群标签分档，判不出具体做法：同一个"外行"可能恰好懂这次要用到的那个概念，同一个"同行"可能恰好不懂。真正决定做法的不是人，是**这一次的解释要用到的每个概念**。所以不按人分档，按概念逐个判，轴有两条：

- **轴一：观众已经有这个概念吗？**（有 / 没有）
- **轴二：观众看完之后还需要用到这个词吗？**（要去搜、要跟人说、要在产品里找到它 → 需要；只为了这一次听懂 → 不需要）

做法：先把解释拆成一条概念链（要懂 C，先得懂 B，先得懂 A），每个概念过两条轴：

| | 之后要用到这个词 | 之后用不到 |
|---|---|---|
| **已经有** | 直接用术语，不解释 | 用不用术语都行，取更短的那个 |
| **还没有** | 先用白话或一个具体例子建立直觉，再点名一次（可上屏），之后统一用这个名字 | 绕开：换一条不经过它的解释路线；绕不开才用白话讲，不点名 |

推导：直觉靠白话建立，但术语是观众事后能搜、能复述的把手；一次都不点名，观众看懂了也找不回来（R3）。反过来，为一个之后用不到、又是新的概念花时间，等于把观众有限的注意力花在了不属于目的的地方。

**深浅与例子**由表推出：链上"还没有"的概念越多，越需要一个**贯穿全片的具体例子**把它们串起来；"还没有"多到装不下观看时长时，回到 13.2 第 1 条（需求本身可能错了）。

这张表把"按人分档"换成了"按概念判"，是本书推出的起点，**弱证据，待实验**（第 13 章 Q29 行）。跨文化、跨语言观众是另一条维度：同一个概念在不同文化里"有没有"不同，按目标观众所在的文化判，不按制作者的。

### 3.5 三种确定受众的取向

- **取向 A：问**。适合委托方明确有目标人群（商业宣传）。
- **取向 B：从题材和平台推断，写成可否决的一句**。适合用户不在场、题材自带人群。
- **取向 C：把受众当成发散的一个维度**（模型平时不会默认做）。受众本身就是空白时，不急着定，而是让第 5 章里不同方向面向不同受众——"给从没跑过步的人"和"给每周都在一个人跑的人"是两部完全不同的片。收拢时连受众一起收。适合受众没说、且受众的选择本身就是最大的创作决定时。推自 R3、R4。

### 3.6 需求方不是终端观众

委托方喜欢的和观众需要的冲突时，不替任何一方裁决。把冲突写出来交给委托方："你要的 X 会让 Y 观众在第几秒看不懂，可选方案是……"。这一条原料没覆盖，推演见第 13 章。

### 3.7 故意违反

**不写受众，写"反受众"**：只写"这件东西明确不是给谁的"。适合用户自己也说不准给谁、但很清楚讨厌被当成什么人的情况（例如"不是给已经很会的人的"）。它能排除一大片默认，但不提供方向，必须和一个中心想法配套。

### 3.8 失败点预判

- **默认给同行看**（禁用清单第 41 条）：术语多、节奏快、默认观众懂行。发现方法：把成品给一个按受众描述挑选的人（或按这个水平模拟）看，问他第一处看不懂在哪。
- **受众写得太宽**：发现方法：3.1 的判胜负测试。

### 3.9 自检

- 受众描述能否在两个候选方向之间判出胜负？
- 目标反应是否按主目的写成了 3.2 表里对应的形态，并附了检验方法（不含"专业""高级"这类词）？
- **可测量**：每一段须读文字的屏上停留时间 ≥ 找到它的时间 + 字数 ÷ 目标观众的阅读速度。起点按观看情境推：在移动的画面里，先给约 0.5 秒让视线找到文字，再按每秒 4–6 个汉字算阅读（成年人静读纸面更快，但移动画面、手机小屏、外行观众都要往慢里取；**弱证据，待实验**）。逐段列出"字数 / 停留秒数"，不满足的段数 = 0。

## 第 4 章 材料与事实：有什么、缺什么、绝不编什么（覆盖 Q4、Q27）

推自 R1、R2、R6。

### 4.1 从作品的"主张"倒着盘

不要先列手头有什么，而是先列**作品将会在画面或声音里说出的每一句主张**（每个数字、每个功能、每个名字、每张界面、每个地点、每个日期），然后给每一条贴一个来源标签：

- **〔给〕** 用户提供的
- **〔查〕** 能从可公开核实的地方查到的（记下出处）
- **〔造〕** 由我们自己搭出来、且本身就是真的（例如：真实运行的代码画出的图、本地时间、我们自己拍的东西）
- **〔例〕** 样稿空白里填的示例（1.2 的判别三问都答"否"的安排类内容；决定类另标），注明"示例，可替换"
- **〔无〕** 以上都不是

推导：从主张出发，才能抓住"作品要说、但没人给过证据"的那一项；从手头材料出发，只会盘点到已有的东西，漏掉的恰好是会被编造的那部分（R1：模型会在空白处补上最像的假数据）。

**〔无〕怎么处理：按三个变量组合，不按固定的几种**

每条〔无〕的主张，先回答三问：
- **由谁补得上？** 用户补得上（他知道，只是没说）/ 公开能查到（只是还没查）/ 谁都补不上（这个证据本来就不存在）。
- **它承重吗？** 拿掉这一条，作品的中心想法还站得住吗？站不住 = 承重。
- **缺口露出来，伤的是哪一种？** 伤**可信度**（观众会怀疑别的也是假的）还是伤**完成感**（作品看起来没做完）。证明类内容缺了伤可信度；安排类内容缺了伤完成感。

然后照下面组合（推自 R1、R2）：

| 谁补得上 | 承重 | 处理 |
|---|---|---|
| 用户 | 承重 | **问**，并写明"不回答，这个方向就做不成，会换成 ……"。等回答期间可以先做不依赖它的部分 |
| 用户 | 不承重 | 安排类 → 不再是〔无〕，按样稿空白**填示例**；证明类 → **删掉这句**，交付时附一句"如果你有 X 的真实数据，这里可以加一句" |
| 公开可查 | 任意 | **查**，查到改为〔查〕并记出处；查不到降为"谁都补不上" |
| 谁都补不上 | 承重 | **换主张**：让作品改说一句能被现有材料证明的话（没有数据证明"很快"，就让画面不加速地真实演一遍，让观众自己看到快）。这通常意味着回到第 5 章换方向 |
| 谁都补不上 | 不承重 | **删掉**，不留痕迹 |

不允许的处理：编一个；用示例冒充证明；留一个空框等"以后补"。禁用清单第 40 条（编造的用户数、评价、logo，灰色占位界面）就是这一条失败的样子。

**完成感的代价用填示例解决，可信度的代价只能用换主张或删掉解决。** 两者不能互换：拿示例去补证明，伤的是可信度；拿空框去等安排类内容，伤的是完成感。

### 4.2 事实放在哪里、风险边界从哪里来

**要不要把事实集中到一张清单**——按"这些事实会被几个人、在几处碰到"判，不按条数：
- 某条事实会出现在不止一处（画面、口播、封面、文案），或者会经手不止一个执行者 → 集中到一张"事实清单"，规定**作品里出现的每个数字和说法都只能抄自这张清单**。推导：同一条事实散在几处，任何一处改了别处没改，就出现自相矛盾；集中后核查变成逐项比对（R6）。
- 每条事实只出现一次、只有一个人经手 → 就地在主张旁标来源即可，集中只增加一份要同步的文件。
- 这个判据是本书推出的起点，**弱证据，待实验**（第 13 章 Q27 行）。

**谁来核查**：从"核查要抓的是什么"推——要抓的是"制作者以为对、其实不对"的那一类错，而制作者对自己的错最没有感觉（他写下它时就认为它对）。所以逐项比对最好交给没写这份清单、也没做这件作品的执行者；做不到时，至少隔一段时间、换成"逐条找出处"的读法再核一次，不凭印象读。

**准确的和示意的，观众怎么分得出**（U-1 重推）。观众只看画面，分不出一张画得很工整的示意图和一张按真实数据画的图——工整本身就会被读成"准确"。分不出时，他会把示意当真：把示意路线当成真实走法、把示意比例当成真实大小、把推测的年代当成定论，而且会把这份"准确"带到别处转述。由此推出两件事，分给两个读者：
- **给核查的人**：史实、地理、数据类主张在事实清单里多写一项"把握程度"——确定 / 有争议 / 推测。有争议和推测的，作品里的措辞要跟着降一级（"一般认为""大约""可能"），不能比清单上的把握程度更强（与下文风险边界第 2 问一致）。
- **给观众**：示意的东西，声明必须出现在观众**正在看它的那一刻、那一块画面里**——它出现时，同一画面里有"示意"二字或一句"不按比例"，或者整体画法就离写实足够远（见下文"观众天天看到的真实界面"的两端）。推导：本书默认的观看情境是信息流里静音看一遍（第 3 章），片尾字幕、简介、评论区的声明，看那一帧时的观众都看不到。检验：把示意那一帧单独截出来给不知情的人看，问"这张图是按真实比例画的吗"，答"是"就算声明失败。

**风险边界从题材本身推，不从一张通用清单抄**。对每一条主张问两句：
1. **如果它是错的，第一个受损的是谁？** 答案是一个能被认出的真人或机构 → 这条主张必须有出处，且措辞不能比出处更强；答案是"照着做的观众" → 它在给建议，建议的对错要由有资格的来源背书，否则改写成描述而不是建议。
2. **观众会不会靠它做决定？**（花钱、出行、用药、报名、投票。）会 → 它在作品里的醒目程度不能超过它的可信度；不确定的写成不确定。
两问都答"没人受损、没人据此做决定"的主张，风险约束可以放到最低。

**观众天天看到的真实界面**：观众判断真假靠熟悉的细节，越熟悉的界面，偏差越小也会被认出来。所以两端可选，中间不可选：要么**用真的**（读真实截图、录屏、真实设计变量，不改色、不重画）；要么**明显做成示意**（离真实足够远，一眼看出不是在冒充它）。最差的是中间——"看起来像真的，其实是凭记忆画的"，它既不可信，又暗示了一个可能不存在的样子。

### 4.3 三种盘材料的取向

- **取向 A：主张倒推**（4.1）。适合宣传、讲解、新闻类，主张多、可信度要紧的作品。
- **取向 B：材料先行**。用户给了很强的真材料（一段录音、一批照片、一段录屏）时，先不提方向，先用文字把"我从材料里读到了什么"交还给用户。**交还哪些方面，由下游哪些决定要靠这段材料来定**：先列出这些决定，再对每个决定写一句"我从材料里读到的依据"。例如，下游要决定切点放在哪 → 交还"材料里哪些位置可以断开、哪些不能"；要决定全片强弱怎么起伏 → 交还"材料自己的起伏在哪里"；要决定画面和文字怎么分工 → 交还"材料里已经说清了什么、没说清什么"；要决定哪些部分不能用 → 交还"瑕疵和不能公开的部分"。下游不依赖的方面不交还，免得用户在不影响作品的地方花确认的力气。不能实际听或看的执行者，要如实说明自己读到的是什么（例如只读了转写文字）。推自 R2：用户对"你读到的对不对"的判断几乎不花力气，却校准了后面的一切。
- **取向 C：零材料，把"没有"当成题材**（模型平时不会默认做）。完全没有真材料时，不去编，也不去找图库凑，而是选择**只用本身就是真的东西**：文字本身、数字本身、此刻的时间、观众自己的设备、作品自身的运行状态。适合信息极少的需求（例如只有一个名词）。推自 R1：在没有约束的地方，选一个"不可能是假的"约束，比选一个"看起来像真的"假象更不会落回默认。

### 4.4 授权

每样〔给〕和〔查〕的材料都标一句：能不能公开用、需不需要告知来源。按本项目规则，作品画面、封面、文案里都不出现素材署名；"告知"只发生在交给用户的文件里，不进作品。

### 4.5 故意违反

**故意让缺失可见**：把〔无〕直接做进作品，例如一块明确标着"这里本该有数据，但它不存在"的空位。适合讲"信息不透明""没人统计过"本身就是论点的作品。只在缺失就是内容时使用，不能用来掩饰没做完。

### 4.6 失败点预判

- **"做不到"被说成"风格如此"**：审查的人从外面看，分不出一项省略是选择还是做不到——两者在成品里长得一样。能分开它们的只有一个问题：**"如果时间和材料都给足，你还会这样做吗？"** 答"会"，就必须写得出它换来了什么（观众因此少看什么、多看清什么）；答"不会"，就必须写得出卡在哪、补上要什么。发现方法：对每项省略问这一句，两种答案都写不出下半句的，就是在包装。
- **用占位代替处理**：成品里出现空框、"数据待补"、灰色界面。发现方法：数占位，应为 0；每一个占位都回到 4.1 的组合表重新处理——安排类改填示例，证明类改为删掉或换主张。
- **示例被当成事实发布**：样稿里的示例日期、价格没换就上线了。发现方法：交付时把替换表放在交付说明的第一项，逐条要求用户勾"已换 / 就用它"；决定类各行排在最前，没勾的不发布（1.2）。

### 4.7 自检

- 画面上每一条主张都贴了标签吗？〔无〕的有没有一条悄悄出现在作品里？（应为 0。）
- 有没有一条证明类内容被标成了〔例〕？（应为 0。）
- **可测量**：作品里不在事实清单（或就地出处）里的数字个数 = 0；〔例〕的条数 = 替换表条数；成品里的空框、占位线数 = 0。

## 第 5 章 发散：写出几个根上不同的方向（覆盖 Q9、Q17、Q18、Q19）

推自 R4、R5。这是公理 3「先放开」的那一半。

### 5.1 发散的五个动作（动作 3 有几种并列取向，按适用条件选）

动作 1、2、4、5 不论走哪种取向都要做；动作 3"产生方向"有几种并列取向，没有先后、没有默认。

**动作 1：写出两层默认。**

先定这个媒介有哪些层。不要套一份固定的层表，问一句："做这件作品，要分别做哪几类决定？"每一类决定就是一层。一张静止画面至少要决定画什么、怎么摆、什么色与光、有什么字；会动的再加时间怎么组织、东西怎么动、有什么声音；能交互的再加观众做什么、作品怎么回应。媒介不同，层数就不同。

- **第一层默认**：每层写一句"不费力就会选的那个"，合起来就是默认作品。
- **默认的近邻**：只把默认里**某一层上的一个值**换掉（换个颜色、换种材质、取个反、换一个同类意象）得到的东西。不必一一写出，记住判别：和默认相比只有一层不同 → 近邻，不进候选。
- **第二层默认**（D2）：假设第一层默认已经被禁止，写出"一个有经验的同行最可能拿出来的巧妙方案"，一到两个。找法是问自己三句：排除第一层之后，我脑中冒出来最得意的点子是什么？这个题材在作品合集里最常被夸"有想法"的做法是什么？有没有一个现成的双关、一个"把题材里的 X 变成 Y"的转译，几乎就摆在那里等人用？三句的答案就是第二层默认。它和它的近邻同样不进候选。

推导（R4）：固着不止一层。排除第一个想法后，联想会滑到第二强的吸引点；而这个吸引点对所有同样聪明的生成者都是同一个，所以"聪明的第二选择"也会撞车。两轮盲测里，排除了第一层默认的作品稳定地落到了同一批第二选择上，这是本动作的直接来由（样本量和它推不出的东西见 5.3 末段）。

禁用清单第 29–40 条是已知的第一层默认外观，可以直接对照。其中"深色水面 + 波浪 + 居中白字"一条来自单需求单次运行的肉眼判断，属于**弱证据，待实验**，不要推广成"所有题材都会落到这里"。

**动作 2：挖题材的独有事实。**

1. 写出题材最近的两三个同类（同类的产品、活动、地方、现象）。
2. 围绕题材写陈述。到哪里找，由题材自己推：问"它存在于哪里、被谁碰到、什么时候会变"，三问的答案指向它的事实藏在哪。一件东西的事实多在它的材料、尺寸和磨损里；一件事的事实多在它的时刻和参与者里；一个道理的事实多在它反直觉、常被误解的地方——这些只是举例，按题材推，不按这几句抄。
3. 每写一句做**替换测试**：把题材名换成第 1 步的同类，这句话还成立，就划掉。留下来的才是独有事实。
4. 写完给事实编号，**冻结**：动作 3 开始后不再增删改。要补事实，就回到动作 2 重做一遍，并记下"第几次补、补了什么"。推导：事实列表若能边写方向边改，挑哪条事实就会跟着此刻想写的方向走，偏好从这里溜回来。

够不够：至少留下两条再往下走。推导：方向要靠事实扎根（见下文"方向的写法"），只有一条事实时，所有方向都扎在同一条上，动作 4 会把它们判成近亲。少于两条时，问用户一个"只有你知道"的问题（他的这一个和别家的哪里不一样），或者走 4.3 取向 C。

**动作 3：产生方向——三种并列取向（各家分歧，待实验）**

**统一说法**（与视觉设计一书 4.5 相同）："先用外部随机源抽方向、再判断"是几种发散做法之一，和本书其他发散做法并列，各写适用条件和代价，标「待实验」。它不是必做步骤。下面三种没有先后，没有默认，按适用条件选；可以组合（例如乙做完再用甲补一轮）。三种做法的效果**从来没有被放在同一条件下对照过**。

三种取向共同的底线（不论选哪种都要满足）：方向不得是动作 1 两层默认或其近邻；每个方向扎根于动作 2 冻结后的某条独有事实；需求的字面画面最多占一个方向（禁用清单第 38 条），而且它通常已经是第一层默认；被放弃的尝试写出放弃理由，**理由必须指向一条可核对的事实**——需要的材料不存在、落在禁用清单的默认区、和动作 1 已写下的默认重合、作品读不到它需要的东西（例如一段视频读不到观众所在地）。"感觉不合适"不是理由。

**取向甲：外部随机抽值，再判断**
- 做法：用**外部随机源**（掷骰子、随机数程序；不是模型自己说"我随机选一个"）在下面几条轴上各抽一个值，再判断这组值能不能和一条独有事实接成一个方向：能 → 写成方向；不能 → 弃用并写理由。

  | 轴 | 起点值（编号供抽取） |
  |---|---|
  | 甲 骨架动作 | 1 堆积 · 2 拆开 · 3 并排对照 · 4 追着一样东西走 · 5 等待或倒数 · 6 重复中出现一处变化 · 7 跨尺度穿行 · 8 逐步揭开 · 9 倒放或回放 · 10 先失败再成功 |
  | 乙 材料来源 | 1 题材里的实物 · 2 借来的品类（再从风格词汇库的 S 编号里抽一个，见第 14 章）· 3 观众自己（他的手、时间、所在、设备）· 4 只用字或数 · 5 真实记录（录音、录屏、档案、照片）· 6 题材的反面或缺席 |
  | 丙 观众位置 | 1 旁观 · 2 被直接称呼 · 3 要动手参与 · 4 借作品里某个人或物的眼睛 |
  | 丁 尺度 | 1 极小或一瞬 · 2 手边或一天 · 3 一间屋或一季 · 4 一座城或几年 · 5 地图天空或跨代 |

  轴推自 R4：根上的差异发生在"作品怎么组织"和"它用什么说话"；再加两条最常被默认悄悄锁死的变量——观众站在哪里、尺度多大。轴上的值可以加，但只能在**看到题材之前**加，加了要记录（理由和例外见 5.3）。
- 抽取顺序（程序实现时照此写，复现才对得上）：每一次依次抽甲、乙、丙、丁四轴；**四轴都抽完后**，若乙为 2，再抽一个 S 编号。用程序时写明函数和区间，例如 Python `random.Random(种子).randint(1, n)`，两端都含。
- 适用条件：同类需求反复做、跨作品已经在收敛（10.1），或者乙、丙取向做出的方向一再被判成近亲时；手上的独有事实少于两三条、彼此同类，难以直接写出差得远的方向时也适用。（执行者是人还是模型不是区分条件：两者都会收敛。）
- 绕开了什么：生成时的众数偏好——模型直接挑，挑出来的多半就是动作 1 写过的东西或它们的近邻。
- 代价和边界：池子多大，可能性就被限在多大（"库味"）；判断"适不适合"时偏好会从弃用这一步溜回来，所以**弃用率超过一半时，复查弃用理由**；抽到的值和题材常常接不上，要多抽几次，比乙费时。
- 本取向自己的记录义务：所有抽取（种子或骰子结果）、弃用和合并都记下来，放进简报第 4 栏。
- 证据：两轮盲测是支持本取向的**初步证据**，样本量和它推不出的东西见 5.3 末段。**待实验。**

**取向乙：从独有事实直接写方向（只靠判断，不抽取）**
- 做法：两层默认写出并排除之后，按编号逐条拿冻结的独有事实，每条事实问"观众看完会向朋友描述出一个什么画面或事件，而它只能来自这条事实"，写成方向。
- 适用条件：独有事实多而具体（三条以上，且彼此不同类）；或已有同题材的随机取向记录、想对照"不抽会怎样"；或者作品要能向委托方逐条解释"这个方向从哪来"。
- 绕开了什么：随机池的边界——方向的可能性不被一张轴表限死，也没有"库味"；每个方向都能指回一条事实，解释成本低。
- 代价和边界：模型能认出最显眼的默认，但未必认得出"自己觉得聪明的那个"也是默认，所以方向可能落进第二层默认的近邻——这一风险由动作 4 把每个方向和第二层默认逐一比对来管，和甲取向一样，不额外加义务；事实少时方向会挤在一两条事实上。
- 本取向自己的记录义务：每条事实上写了几次、哪次被并入或放弃、理由，记进简报第 4 栏（与甲的抽取记录同一栏）。
- **待实验。**

**取向丙：借别的生成者的第一反应，扩大排除范围**
- 做法：把需求原话（不带你的分析）交给一个或几个别的生成者——另一个模型、另一位同事，或同一模型的全新对话——各写三个方向。把它们的答案全部当作"默认"并入动作 1 的排除表，然后再用乙的做法从事实写方向。
- 适用条件：能便宜地调用第二个生成者；题材是常见题材，同行最可能撞车的地方正是要避开的。（模型平时不会这么做：它习惯只问自己。）
- 绕开了什么：自省的盲区——自己认不出的"聪明第二选择"，别的生成者会直接写出来。
- 代价和边界：同一家族的模型共享大部分默认，借来的答案和自己的重复，扩不了多少；借来的答案只能用来排除，不能拿来当候选，否则就是换了一个中心回归（R1）；多一次调用的成本。
- 本取向自己的记录义务：借了谁、拿回了几个方向、其中几个与自己的两层默认重合（重合率本身就是"自省盲区有多大"的一次测量），记进第 4 栏。
- **待实验。**

**动作 4：查距离，合并近亲。** 按顺序判，判到哪一步有结论就停：
1. 两个方向的**事后描述能互换吗**？（拿 A 的那句去描述 B 的成品，观众也会点头。）能 → 近亲。
2. 不能互换，但**靠的是同一条事实，而且事后描述之间只差一个值**（换了一个物件、一种材质、一个地点）→ 近亲：差别只在怎么包装同一件事。
3. 其余 → 不同。

对两层默认也做这个判定：和任一层默认是近亲的方向，并入那一层默认，排除。合并时逐条写明"谁并入了谁"，**只能并入当时已经写下的方向或默认**；当时没有可并入的对象，它就是一个新方向。核对：写出的方向数 − 并入数 = 剩下的方向数。

**动作 5：确认至少一个非默认方向。** 对每个剩下的方向问："如果只给我需求原话、不给动作 1 的排除表和动作 2 的事实，我第一次会写出它吗？"至少有一个答"不会"。全都答"会"，说明判断时偷偷挑了顺手的组合——回去看放弃记录，把被"不太合适"放掉的重新判一次。

**什么时候停**：不设固定数量（禁用清单第 18、19 条）。
- 甲：一直抽，直到**连续两次抽取都没留下新方向**（被弃用或被合并）。推导：一次落空可能是运气，连续两次说明在这个题材和这个池子上已经接近饱和。
- 乙、丙：每条事实上一直写，直到这条事实上**连续两次写出的都没留下新方向**，换下一条；所有事实都轮过一遍就停。推导同上，只是"池子"换成了每条事实。
- 这个"两次"是起点，**待实验**。它在前几次就可能触发：留下的方向少，说明池子或事实在这个题材上很快饱和，这本身是一条信息，不要为了凑数改规则继续抽。
- 最少要留下：一个非默认方向，和至少一个与它不同的方向。不够时：甲回到动作 2 补事实再抽，或换乙、丙补一轮。第 12 章三个演示的方向数（3、5、6）都是按这条规则逐次模拟得出的，模拟脚本和逐次记录见附录 F。

**方向的写法**

谁读方向：用户（方式一要他挑）、收拢的人（方式二、三要他比和取舍）、之后才有的下游执行者。他们读方向时依次要做三个判断：**这两个是不是同一个？**（区分）**哪个更站得住？**（取舍）**做出来要守住什么？**（执行）。每一项写法只负责一个判断：

1. **事后描述**（负责区分，每个方向必有）：看完的观众向朋友描述它时会说的那一句，必须是一个具体的画面或事件，不是形容词。推导：读者分辨两个方向，靠的是脑中能不能出现两幅不同的画面；抽象的"中心想法"两个方向常写成同一句，而事后描述就是观众真正带走的东西，最能暴露两者是否相同。
2. **靠什么站住**（负责取舍，每个方向必有）：它扎根的那条独有事实的编号，加上它做成还缺什么，用〔给〕〔查〕〔造〕〔缺〕标来源（第 4 章）。推导：收拢时淘汰一个方向，最常见的理由不是"不好看"，而是"它要的东西没有"；把缺口写在方向里，取舍就能按事实判，不按口味判（6.4）。
3. **执行信息不在这一步写**：要守住什么，等收拢之后由 6.6 的方向承诺表写。推导：发散时写执行细节就是提前实现（R5），而且没被选中的方向写了也白写。
4. **只在会混淆时加一句"它不是什么"**：事后描述和某层默认只隔一步、读者可能把它读成那个默认时，加一句"它不是 X"（X 指一层默认或一个已写下的方向）。不会混淆的，不加。推导：这一句只帮"区分"，而区分已由第 1 项负责；它只在第 1 项单独不够时才有用，固定附加只会变成一句没人读的套话。
5. **收拢方式是"让用户挑"时，再加 6.2 的"它适合你如果……"（可连同"它会放弃……"）**，因为这时读者是用户，他要拿自己的情况来对；这两句写在交给用户的那一页上，不必写进发散记录。

所以项数随读者和收拢方式变：最少两项，用户挑时三项，有混淆风险的方向再加一句。

**写多长**：每个方向就是上面这几项。这是 R5：发散发生在最便宜的载体上，收拢之后才画、才搭。

### 5.2 参照与标杆（Q17）

发散时可以找参照，但不预设"学哪些、不拿哪些"的清单——哪一部分可迁移，要对这一个参照逐个特征判。

1. **先确认看的是本体**：参照的描述要来自真实地看过、量过，不来自记忆；并且分出哪些是它的本体，哪些是偶然混进来的（某个版本的字幕、某次转载加的水印、平台压缩出的色偏）。偶然的东西不进入后面的判断。
2. **对每个看中的特征做"换题测试"**：把这个特征搬到我们的题材上，它还在起同样的作用吗？
   - 起作用的原因**不依赖**参照的内容（不依赖它的角色、品牌、故事、那一首曲子）→ 可迁移，可以学。
   - 只因为参照的那个内容才成立 → 私有，不拿。
3. **做"认出测试"**：设想观众看到我们的成品，第一反应会不会说出参照的名字？会 → 拿得太多，即使每一项单独都"可迁移"，加起来也成了翻拍。退回去，减少学的特征数。
4. 用户点名喜欢的某个属性，先过第 2 步：可迁移的原样保留到成品里；私有的（例如别人的角色），向用户说明不能拿，并给一个能起同样作用的做法。

第一个想到的参照往往是所有人都在用的那个；从题材正典之外找（片头、印刷、游戏、舞台、科学插图、行业自己的印刷物）更能拉开距离。

### 5.3 选了随机取向时，注入池从哪里来：三种取向（待实验）

本节只在 5.1 动作 3 选了取向甲时适用，讲的是随机取向内部的分歧：池子从哪里来。

池子的总规则：注入要绕开的是**生成时的众数偏好**，所以随机源必须在模型之外，池子里的值也不能在看到题材之后由模型现编——看到题材后再加的值，就是模型此刻想要的东西。

- **取向 A：池子来自题材自身**。把动作 2 的独有事实编号，和轴甲的骨架动作交叉抽。
  - 和总规则的关系：这些编号对应的内容确实是看到题材之后才有的，所以本取向是总规则的一个**有条件的例外**，条件三条全满足才成立：① 事实列表在第一次抽取之前写完并冻结（5.1 动作 2 第 4 步）；② 事实进列表的唯一门槛是替换测试，不是"我想用它"；③ 抽取只抽编号，抽到哪条用哪条，不能因为"这条不好接"换一条。任一条不满足，就按总规则处理：这个池子是现编的，不能用。总规则管的是"模型挑值"，例外成立的理由是三条件把"挑"换成了"测试 + 冻结 + 外部抽"。
  - 绕开的偏好：品类联想。带来的边界：即便满足三条件，写事实时的注意力本身可能已经偏了（先想到的事实多半是最显眼的）。适合事实丰富的题材。
- **取向 B：池子来自外部库**。轴乙抽到"借来的品类"时，从风格词汇库的编号或它的"地图空白"编号里抽（来源和编号变化时怎么办见第 14 章）。绕开的偏好：模型熟悉的那几种外观；带来的边界：词汇库的覆盖范围就是天花板，常用的编号会累积成库味（第 10 章记下每次抽到的编号，避免连续重复）。适合题材信息少、需要从外面借一个世界时。
- **取向 C：池子来自与题材无关的随机源**（模型平时不会默认做）。例如随机翻到的一个词、随机一个行业、随机一件手边物件，强行和题材接一次。绕开的偏好最多，弃用率也最高；只在 A、B 连续抽不出非默认方向时用。

**证据有多强**。两轮盲测是支持随机取向的初步证据：每组只有少数几件作品；观察到的是"只靠自省排除第一层默认的作品，稳定落到了第二层默认上"。它推不出的东西：① 推不出随机取向比 5.1 的取向乙、丙好——盲测里没有这两种取向在"已经写出并排除第二层默认"之后的对照；② 推不出随机取向在别的题材、别的模型上也成立；③ 推不出正常的弃用率、合适的池子大小。它最直接支持的，其实是三种取向共用的动作 1"写出第二层默认"。

自省与注入各占多少、注入池怎么建、正常的弃用率是多少，都没有对照实验，**待实验**。

### 5.4 对已有体系的局部扩展不发散

用户只是要在已建立的视觉体系里加一个页面、换一张图、改一句文案时，不发起方向竞赛；直接沿用已有体系。发散只用于"方向本身是空白"的需求。

### 5.5 故意违反

**只写一个方向，但把它的默认版本也做出来对照**：适合用户已经非常明确、不需要发散，但你想证明这个方向比默认好的情况。代价：没有方向竞赛，选错了只能靠对照版发现。

**直接从默认出发，只改一层到底**：故意选第一层默认里的一层（例如只动"有什么字"），把它推到极端，其余各层全用默认。这违反了 R4"差异要发生在根上"。适合用户要的是"大家都认得的那种，但要有一个记忆点"，例如节日问候、品牌日常更新。代价：观众事后描述的仍是默认作品，只多一个形容；不能当作发散的结果交出去。

（r4 曾把"跳过随机抽取、只靠自省"列在这里；r5 已把它移回 5.1 动作 3，作为与随机取向并列的取向乙，理由见附录 E。）

### 5.6 失败点预判

- **几个方向是同一个方向换皮**（禁用清单第 22 条）：发现方法：动作 4 的判定顺序。
- **排除了第一层默认，却落进第二层默认**：方向里出现了动作 1 写下的那个"巧妙方案"或它的近邻。三种取向都会发生。发现方法：把第二层默认的事后描述和每个方向逐一做动作 4 的第 1 步。
- **选了随机取向时的假随机**：模型自己"随机选了"一组值，或者抽到不顺手的就换一组而没写理由。发现方法：抽取记录里有没有种子或骰子结果；弃用理由里有没有"不太合适""感觉"这类词。
- **选了取向乙、丙时的事实挤兑**：所有方向都扎在同一条最好接的事实上，其余事实没被轮到。发现方法：数第 4 栏里每条事实各写了几次，有事实是 0 次就没走完。
- **所有方向都是受众每天用的同一类工具的样子**（工具的戏服）：发现方法：数一数有几个方向"靠什么站住"那一项其实是"产品本身的外观"，超过一个就重写。
- **发散变成了写长文**：每个方向超出 5.1"方向的写法"那几项，就是在提前实现。

### 5.7 自检

- 第一层默认和第二层默认都写了吗？每个剩下的方向都和它们做过动作 4 的判定吗？
- 动作 5 的问句里，有几个方向答"不会"？（≥ 1。）
- **可测量**（各取向通用）：第 4 栏里每个方向都能指回一条冻结的事实编号（指不回的 = 0）；"写出数 − 并入数 = 剩下数"这条等式成立；每条"并入 X"里 X 的首次出现早于它（违反的 = 0）；停止那一次之后没有再写方向（违反的 = 0）。
- **可测量**（选了随机取向时）：每个方向都能在抽取记录里找到对应的一次抽取；弃用率 = 弃用数 ÷ 抽取数，超过 50% 就复查弃用理由。

## 第 6 章 收拢：三种方式，各自何时用（覆盖 Q20、Q21）

推自 R3、R5。这是公理 3「再收拢」的那一半。

### 6.1 先选收拢方式（照判定表选）

| 情况 | 用哪种 |
|---|---|
| 用户在场；取舍涉及用户自己的品味、品牌、风险偏好；方向用几句话就能让用户看懂差异 | **方式一：让用户挑** |
| 方向在文字上分不出高下，差异主要在观感、节奏、手感上；预算允许做几段小样 | **方式二：小样两两比较** |
| 用户不在场，或明确交出决定权；方向的差异能用"哪个更承载这个内容和受众"判断 | **方式三：按内容契合度自选** |

三种都不是默认。同一种需求在不同情况下应当用不同方式（第 12 章三个演示各用了一种）。

**组合用法：先文字粗筛，再小样决胜。** 方向多、而小样贵时，常见的情况是：大部分方向在文字上就能判出不合适（材料不存在、观看情境接不住、和独有事实绑不紧），只有最后两个在文字上分不出高下。这时先用方式三的三问（6.4）在文字上淘汰，**只把文字判不出的那几个**送去做小样（方式二）。判定：对每一次淘汰，问"这一步的依据是写得出来的事实，还是观感？"——写得出事实的，在文字层淘汰；只能靠观感判的，留给小样。两种依据不能混用：不能用观感理由在文字层淘汰，也不能把文字就能判的方向拿去做小样浪费预算。

### 6.2 方式一：让用户挑

- **前提**：候选真的根上不同（第 5 章动作 4 已过），而且用户看得懂差异。给用户几个近亲让他挑，等于让他挑配色。
- **怎么给**：每个方向两三句，加一句"它适合你如果……"和一句"它会放弃……"。可以附一个推荐和理由，但推荐不能只是"最稳的那个"。
- **用户的选择是最高等级的校准**，记下来（第 10 章）。

### 6.3 方式二：小样两两比较（本领域语料几乎无人用过，待实验）

- **小样是什么**：每个方向只做最能代表它的那一小段——一张静帧、几秒运动、一个交互片段。小样按最终标准做那一小段，不做粗糙版（粗糙版比较的是粗糙程度，不是方向）。
- **怎么比**：一次只比两个；先写好比较维度（从第 8 章的完成标准里挑一两条，例如"静音下第一眼能否说出它在讲什么"）；最好由不参与制作的人判断，不告诉他哪个是谁做的。多于两个方向时两两淘汰。
- **代价**：贵。只在文字方案确实判不出时用。推自 R5：它把文字上的争论换成观感上的证据，能抓住文字方案看不出的失败。

### 6.4 方式三：按内容契合度自选

- **判据**：哪个方向的材质和结构最能承载这个内容、这个受众、这个观看情境。逐个回答三问：
  1. 它和题材的独有事实绑得多紧？（换成同类对象还成立吗？不成立更好。）
  2. 受众在它的情境里能否得到目标反应那一句话？
  3. 在现有材料和工具能力下，它能不能被做到最终标准？
- **禁止的判据**："最安全""最稳""最不会出错"（禁用清单第 23 条）。最安全的方向通常就是离默认最近的方向（R1）。如果三问之后最契合的恰好是最保守的那个，必须多写一句：它在哪一问上胜过了非默认方向。
- **借用**：选定后，看落选方向里有没有一个元素能让它更强，借过来，但只借一个，且要能融进选定方向的世界。

### 6.5 收拢理由的写法（三种方式通用）

理由有两个用途，组成从用途推：

- **事后可审查**：别人（或下一轮的自己）要能核对"当时的判断对不对"。所以理由必须落在**可核对的依据**上——一条受众描述、一条独有事实、一个观看情境、一次小样的结果——而不是形容词。只写"更有质感""更高级"的理由，没有东西可核对。
- **条件变化可回退**：条件变了，要能马上知道换到哪。所以理由必须写出它**依赖的前提**，以及**每个前提一变，就换到哪个方向**。

由此，理由写成下面这个形式（前提可以不止一条，有几条写几条）：

```
选定：〈方向的事后描述〉
依据：〈可核对的事实 / 受众 / 情境 / 小样结果〉
前提 → 若变 → 换到
  〈前提 1，例如"投放在手机竖屏"〉 → 〈若改成大屏〉 → 〈方向 X〉
  〈前提 2〉 → …… → ……
```

"放弃了什么"不单列：它已经写在"换到"那一列里——每个被放弃的方向，都应能在某个前提变化后被换回来；**一个在任何前提下都换不回来的落选方向，说明它本来就不该进候选**（回头查动作 4）。

### 6.6 防止实现阶段悄悄变安全（Q21）

方向承诺锁住什么，从"实现时最常在哪里失守"推。实现阶段的阻力集中在三处：

1. **最难做的那一个元素**。方向里总有一样东西做起来最费力（一个要真实拍摄的物件、一段要逐帧调的运动、一个要真正读数据的部件）；时间一紧，它最先被换成现成的替代品。
2. **没人盯的小件**。字幕、按钮、角标、转场、结尾的联系方式——它们不在方向描述里，执行者就用现成组件，方向在这里漏气。
3. **强度被悄悄调低**。执行者不确定时，会把对比调弱、把大的缩小、把静止缩短、把怪的地方磨圆，一点一点退回默认。

所以方向承诺对**每一处预计会失守的地方**写一行，三列：

| 失守处 | 失守时会变成什么 | 守住的样子 + 怎么查 |
|---|---|---|
| 最难的元素：〈指名〉 | 〈最可能的替代品，例如图库图、通用 3D 模型〉 | 〈守住的样子〉；查法：〈例如逐帧核对来源〉 |
| 小件：〈逐个指名这件作品里有的小件〉 | 现成组件的默认样子 | 每一件都用方向的语言重做；查法：逐件截图对照 |
| 强度：〈方向赖以成立的那个量〉 | 量被调回默认附近 | 写成一个可测的量和下限，例如主体占画面面积、静止的时长、对比度；查法：实测 |

行数由这件作品实际有几处失守风险决定，不固定。三类里某一类不存在（例如作品没有小件），就不写那一行。每一行写一到两句即可；行数和每行长度是本书推出的起点，长度与约束力的关系**弱证据，待实验**（第 13 章 Q21 行）。

检查方法：读一遍承诺，如果某一行的"守住的样子"读起来只是一种情绪（"温暖而有力量"），这一行就还没写完。实现中每当要用一个现成组件、现成特效，问一句"它在承诺的哪一行里？"——不在任何一行里的现成件，就是新的失守处，补一行。

方向承诺是内部文件，不出现在作品里。方案阶段可以先自评、点名最弱的一行改掉，但自评有偏差，最终仍由不参与制作的人评。

### 6.7 故意违反

**不收拢，做成系列**：几个方向都做，每个都完整。适合用户本来就需要多件（例如一套同主题的图、一个账号的连续几期），或者方向的差异本身就是想展示的东西。前提：每一件都按同一套完成标准验收。

### 6.8 失败点预判

- **收拢理由只有形容词**：发现方法："依据"一栏里有没有出现一个受众、内容或情境里的具体名词，或一次小样的结果。
- **方向在实现中被磨平**：发现方法：交付前逐行核对方向承诺，再把两层默认的事后描述读一遍——如果成品更像默认而不像承诺，就是被磨平了。

### 6.9 自检

- 收拢方式是按 6.1 的判定表选的，还是习惯？用了组合时，每一次淘汰的依据类型（事实 / 观感）和所在的层（文字 / 小样）对得上吗？
- 每个落选方向，都能在"前提 → 若变 → 换到"表里找到换回它的条件吗？
- **可测量**：方向承诺"强度"那一行写成了带下限的量，并在成品上实测达标；"小件"那一行列出的小件，逐件截图后用了现成组件默认样子的件数 = 0。

## 第 7 章 简报写多细：颗粒度、风格怎么交代、禁止项（覆盖 Q7、Q8、Q10、Q11、Q12、Q13、Q14、Q15、Q16）

推自 R1、R3、R6。

### 7.1 总规则：写意图还是写参数，按"谁执行、要不要一致"选

骨架把"风格主体写成意图还是参数"（Q10）、"简报里写不写具体值"（Q12）标为分歧。下面三档都是取向，不裁决，**待实验**：

- **档一：意图档**。只写"每个元素承担什么任务、为什么"（例如"颜色只用来区分'已经发生的'和'还没发生的'两类"），具体值留给执行领域推导。适合执行者能力强、需要它推广到简报没写到的部分时。风险：意图写得含糊时比参数更危险。
- **档二：参数档**。写成可逐条核对的数值和规格（时长、画幅、色值、字号）。适合多人或多次执行要保持一致、或验收要逐项比对时。风险：参数就是"形"，会被照抄，并排除同一方向里其他合法的做法。
- **档三：参照档**（模型平时不会默认做的那种写法）。用一个具体参照物指向一个点，并写清"学它的什么、不拿它的什么"（5.2）。一个参照一句话能带出许多共现的决定。适合意图说不清、参数又太死的时候。风险：参照可能已经被用滥，而且被用滥的程度无法事先测量。

**不管选哪档，有两条不变**：
1. **只堆形容词的地方一律不算写了**（禁用清单第 2 条）。凡简报里出现"高级、现代、电影感、科技感"这类词，后面必须跟一句意图、一个参数或一个参照，否则删掉。
2. **终检：默认满足测试。** 拿第 5 章写下的两层默认作品，逐句问简报："默认作品也满足这一句吗？"满足的句子不约束任何东西——它挡不住 R1 的回归。数出"默认作品不满足"的句子；方向与禁止项两栏里，这类句子一句都没有，说明方向太泛，回第 5、6 章。比较对象选默认作品而不是同类的另一件，是因为简报真正要挡住的是"不费力就会做出来的那个"，而不是某个具体竞争者。

### 7.2 格式与技术约束（Q7）

格式数字只在被验收引用时才有意义：**写进简报的每个格式数字，第 8 章的完成标准里都要能找到对它的检查**；找不到的，要么删掉，要么补一条检查。

- 用户说了的照用。
- 能从平台推出来的写成推断（例如"手机竖屏"）。
- 推不出的（例如时长），不写"默认值"（禁用清单第 24、25 条是行业默认组合）。用内容推：先写出作品必须让观众得到的几个意义单元，每个单元需要多少时间被看清、读完（3.9 的停留时间算法），加起来就是时长的起点；再拿观看情境（3.3）去裁。

**生产能力边界写成约束**。边界来自工具，不来自审美；对这一次要用的每个工具，逐个维度问"它会在哪里失败"：
- **持续**：越长越漂移吗？（同一个人物、物件、颜色在后半段还是同一个吗？）
- **精度**：小字、准确的数字、细线、对齐，它能做对吗？
- **一致**：同一个东西多次生成，长得一样吗？
- **物理**：接触、遮挡、重量、反射，它会穿帮吗？
- **运行**：在观众的设备上能流畅播放或运行吗？
- **可复查**：结果能不能重复、能不能在任意一刻停下检查？
这几个维度是从"工具的输出在哪些方向上可能偏离意图"推出来的举例，按这一次的工具增删。每个"会失败"的维度，要么在简报里绕开（换工具、换做法），要么写进第 8 章的失败点。

**昂贵步骤先停**：什么算贵，按三问判——花真钱吗？做了能撤回吗？失败了会浪费掉多少已经做好的部分？任一答案让你犹豫，就在这一步之前写明代价并等确认。

技术约束不产生好作品，它只让失败可见；所以技术规格写满而中心想法空着的简报，等于没写。

### 7.3 结构写到什么粒度（Q8）

不分固定的几档，从"执行者需要多少自由"推：结构里**必须写的**，是执行者自己推不出、又会被验收的东西；其余留给执行者。由此，结构说明是一层必写的底，加几个按条件触发的附加项：

- **必写：每段的出口条件**。这一段结束时，观众比进入时多了哪一样（一个信息、一个疑问、一次情绪转向）。段数 = 目的（3.2）需要的出口条件数，没有出口条件的段删掉。这一层是"需求侧标注"，评审拿它查"该有的在不在"。
- **附加一：时间绑定**——当作品要对齐外部时钟（口播、音乐、真实事件的时长）时，写出每段的起止挂在那个时钟的哪里。
- **附加二：画面事件**——当执行者不能自己看成品，或换了几个执行者要保持一致时，每段写出画面里看得见的事件（谁、在做什么）。不许写抽象口号（"展示强大"）。
- **附加三：段内禁止**——当某一段特别容易落进默认时（常见于开头和结尾），单独写那一段不要什么。

不管加哪几项：每段只承担一个出口条件；写明全片挂在哪个时钟上（画面自身、口播、音乐），交给动效与声音领域（第 14 章）。

### 7.4 运动、镜头、转场写到哪一层（Q11）

需求理解这一层只交代**运动的含义**和**全片是否统一一种语法**，不写曲线与时长——那是动效领域的事（第 14 章）。具体写：
- 每一种运动要解释什么（没有含义的运动是装饰）。
- 全片是否一镜到底、是否允许切、转场由什么承接（物件、动作、方向，还是硬切）。
- 用少量准确的术语，不用形容词。

### 7.5 色彩与字体（Q12）

需求理解这一层写**逻辑**：颜色和字体分别承担什么任务、品牌色出现在哪里（作为底、作为强调、还是只在首尾）、需要预判的联动（例如"调暗后文字对比还够吗"）。具体值是否写进简报，按 7.1 选档。色相和字体不按品类选（禁用清单第 37 条），从中心想法和受众推。

### 7.6 声音什么时候定（Q13）

声音来源（用户自有、合成、配音、静音、由发布者在平台内自选）必须在视觉方案之前写下，因为下游一切时间点都要挂在某个时钟上。按本项目规则，视频号成片默认不混配乐，由发布者在 App 内自选——这是平台规则带来的约束，写成"推断"并可被用户推翻。用户给了音频时，按 4.3 取向 B 先把听到的结构交还给用户。

### 7.7 静音和开头的观众（Q14，各家分歧，待实验）

**静音观众必须理解几样、各绑在哪一刻，从观看情境推，不设固定上限：**

1. 先估这个情境里观众**会给多长时间**：信息流里自动播放的，观众随时会走，只能把第一个完整画面当作一定会被看到的部分；主动点开的，可以按全长算。
2. 每一样要理解的东西，需要一个**不靠声音也读得懂的画面**，并在屏上停够它的读取时间（3.9）。
3. 数量 = 目的需要的意义单元数，与"预计观看时长里能排下几个读得懂的画面"，两者取小。前者大于后者时，要么删到装得下，要么回 13.2 第 1 条。
4. 每一样都**绑定到一个具体时刻和一个载体**：在第几秒、靠画面还是靠文字承载。载体按"观众拿这一样去做什么"选（M-6 重推）：要他一眼认出、记住样子的，画面承载；要他照着去做、原样记下或转述的（名字、地址、价格、一个数），只有文字能保证他拿到的是原样，文字承载；要他明白一个关系或原因的，画面演出关系、文字给它一个名字，两者都要，并写明谁先出现。一件作品里各样东西的载体可以各不相同，逐样写明。

开头立即交付还是允许悬念，骨架标为分歧：
- **取向 A：立即交付**。开头就给出主题或承诺，后面用来证明。适合信息流、静音自动播放、观众随时会划走的情境。
- **取向 B：延迟交付**。开头用一个问题、一个冷场或一个看不懂的局部吸住人，稍后揭开。适合主动点开的观看、悬念本身就是吸引力的片种。必须写明理由，并且开头那一刻本身要有足够的东西可看（否则就退化成禁用清单第 39 条：慢开场、结尾才揭晓）。

"开头几秒内必须交付"不作为无推导的硬规则写进简报（禁用清单第 26 条）；具体时刻由上面第 1 步的观看时长推出。

### 7.8 禁止项与反向定位（Q15）

禁止项不按固定的几类写，而按"**这一次最可能落进哪里**"写。来源由两问推（M-6 重推）：**是什么力量在把作品往那里拉？落进去了谁承担？** 拉力来自生成者的习惯（R1）和自己的历史；承担者是作品之外的人时，属于 1.3 甲层。这一次常见的来源如下，但清单是开放的——用户在原话里说过"别搞成 X"，那本身就是一个来源（合同）；换一个题材可能多出别的来源：
- 第 5 章动作 1 写下的**两层默认**：各抄出最具体的几样（具体到能在成品里查到，例如"不要逐字淡入"，而不是"不要俗套"）。
- **上一支作品**的眼熟记录（第 10 章），如果有。
- 4.2 推出的**题材风险**：哪些说法不能说、哪些真人和标志不能用。
- **平台规则**：例如不出现素材署名、不带配乐。

把抄出来的禁止项按"落进去的可能性"从大到小排，每条后面标它来自哪个源。推导：禁止项的作用是挡住最可能发生的事，排在前面的执行者最先看到、最不容易漏；标出来源，日后能看出哪个源的禁止项最常被违反。

再写一句**反向定位**："它不是一支……，它更像……"。

警告：禁止项只说"不要什么"。**只有禁止项、没有方向，作品会落到禁止区外最近的那个默认**——所以禁止项必须和方向承诺（6.6）同时出现。禁止项也不宜多到成为一份新的风格规定：一条禁止项如果在这一次根本不可能被触发，删掉。

### 7.9 可替换变量集中一处（Q16）

什么是变量、什么是固定部分，不列清单，**按"这个值的理由是什么"判**：
- 理由是"因为题材是这个 / 因为这次的事实是这样"（名字、数字、文案、示例内容、这次的受众）→ **变量**，放进第 11 章模板的变量区，正文只引用变量名（例如写〈活动名〉而不写具体名字）。
- 理由是"因为方向要求这样"（方向承诺里的那个量、那种组织方式）→ **固定部分**，写在方向与承诺栏。
- 判不出理由的值，多半是顺手定的默认——删掉，或者回去补一个理由。

同样的判法也适用于风格说明和作品之间的分界：设想把这一项换掉，观众会觉得是"同一种做法的另一件作品"还是"另一种做法"？前者是作品变量，后者属于做法本身。

推导：换内容时只改一处，避免连带改动；同时能看清哪些是"这一次"的，哪些是方向本身的。

**提醒**：变量集中后，最危险的用法是把整份简报当模板换皮复用——那正是禁用清单第 6–11 条那类固定区块串的来历。简报属于一次任务；下一次任务重新走第 1–6 章。

### 7.10 故意违反

**极简简报**：只写一句方向承诺 + 最贵的几条完成标准（条数由作品定，待实验），其余全部留给执行。适合执行者很强、且你想看到它自己的推导时。代价：可检查性下降，必须靠第 8 章的标准兜底。

### 7.11 失败点预判

- **规格写满，想法空着**：发现方法：方向承诺那一栏是否少于其他任何一栏；默认满足测试里方向栏是否全被默认满足。
- **简报写得过细，替执行领域做了决定**：发现方法：简报里出现曲线、帧数、色值时，问一句"这是用户或方向要求的，还是我顺手定的"。顺手定的，降回意图档。

### 7.12 自检

- 简报里每个形容词后面都跟了意图、参数或参照吗？
- 默认满足测试：方向与禁止项两栏里，"默认作品不满足"的句子至少各有一句吗？
- **可测量**：静音观众要理解的每一样，都写了"第几秒 + 载体"；在目标设备尺寸的截图里，须读文字的最小字高 ≥ 起点值。起点值由视角推：字高（像素）= 画面高度（像素）× 2·观看距离·tan(视角/2) ÷ 屏幕可视高度。以手机 30–35 cm、可视高 140–155 mm、汉字视角 20–24 角分起算，约为画面高度的 1.13%–1.75%（Python 复算 1.126% 与 1.745%，百分比四舍五入到两位小数；1920 像素高的画面为 21.6–33.5 像素，向上取整为 22–34 像素，脚本 `scripts/e4_glyph.py`）；视角取值是**弱证据，待实验**，复杂字形和外行观众往大里取。
- **可测量**：所有须读文字和主体离画面边缘的距离 ≥ 平台界面在目标设备截图里压住的最大宽度，再加一个字高的余量；被平台界面遮挡的须读文字数 = 0。

## 第 8 章 完成标准：做到什么算完（覆盖 Q22）

推自 R3、R6。

### 8.1 少量、可验证，每条都能失败

**数量的地位**：完成标准前置是用户 2026-11-19 批准的流程规则，写法以 `framework/protocol.md` 现行那一句为准——少量、可验证，条数由作品定，标「待实验」。本书不另写数字。

**怎样判断够不够**（思路，不落成数字）：
- 往下够不够：把这件作品要在观众身上起的几类效果列出来（看清、看懂、记住、去做……由第 3 章的目的推，不固定），每一类有没有至少一条能失败的标准管着？有一类没人管，就是少了。
- 往上多不多：执行者在实现中要拿标准来做取舍；两条标准开始互相拉扯、又说不出哪条优先，或者执行者复述不出全部标准，就是多了——删掉最便宜就能满足、或和别的条目测的是同一件事的那条。
- 必保项和差异项另列，不算在内：它们管的是"别丢"，不管"做到什么算好"。

每一条写成三段：**观众侧现象 + 测法 + 怎样算失败**。例如：
> 静音观看时，第一眼就能说出它是关于〈对象〉的什么。测法：截第一个完整构图的帧，给不知情的人看，问"这在讲什么"。失败：他说不出〈核心那一点〉。

### 8.2 从哪里挑这几条

先从**观众侧**挑。交付侧的检查照做，但不占观众侧标准的位置。理由（U-2 重推）：标准写少，是为了让执行者在冲突时知道先保哪个；交付侧检查不和任何东西冲突——它们要么过、要么不过，用工具就能判，不需要执行者权衡——所以它们归 protocol 的"底线脚本检查"那一步，不进这里。这条理由来自流程分工，不来自实测；本书不再引用任何"它们已普遍达标"的实测说法，也不逐项举例。

观众侧挑哪几条，**不从固定清单挑，从 8.3 的预演里长出来**（M-6 重推）：按观众接触作品的顺序走一遍——注意到它、看清它、读懂它、留下来、带走或去做——每一步问"这一件作品在这里最可能卡住什么"，卡住的那一处就是一条候选。换一个媒介，步骤就不同：装置多一步"走近"，交互作品多一步"伸手"，纯声音作品没有"看清"。下表只是一支**静音信息流短视频**走这一遍时常长出的候选，换题材、换媒介要重新走：

| 观众接触的那一步 | 这类作品常卡住的地方 | 可用的测法（举例，按作品选） |
|---|---|---|
| 注意到 | 开头说不出是什么 | 首帧或首个完整构图给人看 |
| 看清 | 字太小、对比不够 | 在目标设备尺寸下截图；量最小字高（7.12）；取样文字与背景的对比 |
| 读懂 | 读不完；关声音就不懂 | 逐段数字数，对照停留时间（3.9）；关声音给不知情的人看 |
| 留下来 | 中间拖 | 标出所有"没有新信息"的时段，量最长的那一段 |
| 带走 | 记住的是默认的样子 | 看完让不知情的人说出一个他记住的细节，再和两层默认的描述对照：细节落在默认里，就算没有 |
| 去做 / 想起 | 目标反应没发生 | 按 3.2 主目的那一行的检验方法 |

再补**必保项**：方向承诺里"最难的元素"和"强度"两行，逐项列出，防止迭代中被丢掉。

再补**差异项**（如果有上一支作品或参照）：事后描述能否互换（第 5 章动作 4 第 1 步）——必须不能互换。

### 8.3 失败点从这一次推，不列通用清单

失败点不从一份通用清单里挑，而从这一次的三个来源推：
- **媒介**：做一次"预演"——想象成品已经放在它真正的位置上（某个平台、某块屏幕、某面墙），按观众接触它的顺序一步步走：看到第一眼、读第一行字、听到第一声、伸手去碰……每一步问"什么会让他在这里卡住、走开或误解"。
- **工具**：7.2 里答了"会失败"的那几个维度。
- **题材**：4.2 推出的风险——哪一条主张错了会伤人。

三个来源合起来，按"可能性 × 一旦发生的代价"排，挑最前面的一两项写成标准。推导（R6）：通用清单里的项大多与这一次无关，写进去只会稀释注意；从这一次推出来的失败点，验收时才真的可能失败。经验积累到第 10 章后，可以作为预演时的提示，但仍要逐条判断它这一次是否成立。

### 8.4 三种写标准的取向

- **取向 A：全部可自动测**。只写能用截图、取样、计时、数数测的条目。适合无人值守、要反复迭代的任务。风险：观众侧最重要的"有没有自己的样子"测不到。
- **取向 B：以盲评为主**。只写两三条，全部由不知情的人回答（"它在讲什么""你会记住哪一刻"）。适合讲解、宣传、需要目标反应的作品。
- **取向 C：用反例定义成功**（模型平时不会默认做）。不写"要做到什么"，而写"如果它被误认为下面这个东西，就算失败"——直接把第 5 章的两层默认写成反例。测法：把成品和两层默认的事后描述一起给不知情的人，问"它更像哪一个"。适合方向容易在实现中被磨平的时候。推自 R4、R6。

哪些观众侧效果能自动测、哪些只能盲评，各家划分不一，**待实验**。

### 8.5 不能写的标准

- "如果不够好就重做"（禁用清单第 4 条）：不可判。
- 混进手法的标准（"必须用某种转场"）：那是风格规定，不是标准（宪章公理 2）。手法写在方向承诺里，标准只评观众侧效果。

### 8.6 故意违反

**只写一条标准**：适合极小的任务或纯实验作品，用唯一一条最重要的观众侧问题定成败，让执行者在其余方面完全放开。

### 8.7 失败点预判与自检

- 失败点：标准全是交付侧（尺寸、格式），观众侧一条也没有。发现方法：逐条问"这条是观众感觉得到的吗"。
- 自检：每条都写了"怎样算失败"吗？至少一条是观众侧的吗？必保项列了吗？
- **可测量**：每条标准的"失败"都写成了可以读数或可以二选一的判定（一个阈值、一个是/否问题）；元素互相遮挡（须读文字与主体的重叠面积）= 0；"没有新信息"的最长时段有写明的上限，并在成品上实测。

## 第 9 章 交给制作：第一个便宜的中间产物，与第二轮怎么改（覆盖 Q23、Q24）

推自 R5、R6。

### 9.1 第一个中间产物选哪个

每种中间产物只回答一个问题。先把这一次还没确定的问题都列出来，给每个问题估一个**错了的代价** = 它影响到整件作品的多大比例 × 发现它时已经做完了多少。代价最大的那个问题先确认，用最便宜的、能回答它的产物：

| 问题（代价通常从大到小，按这一次重估） | 能回答它的最便宜产物 |
|---|---|
| 方向本身对不对——它影响全部 | 文字方案（就是简报） |
| 时间的骨架对不对（时长、挂在哪个时钟上）——它影响每一个时间点 | 一张时间轴或节拍草稿 |
| 每一镜都会重复的那些共性对不对——它影响每一镜（例如须读文字的字高与位置、主体与背景的明暗关系、全片动作的整体快慢、声音与画面对齐的方式） | 一镜按最终标准做的样板 |
| 某一个画面好不好看——它只影响那一处 | 一张按最终标准做的静帧 |
| 交互手感——它影响所有交互 | 一个能真用的最小交互片段 |

左列不是一份固定的产物种类表（M-6 重推）：它由"这一次还没定的问题"长出来，每个问题配一个"刚好能回答它、再便宜就答不了"的产物。换一个媒介，行就不同：纯声音作品里"时间骨架"的产物是一段节拍样音，"静帧"那一行不存在；印刷品没有"时间骨架"，却多一行"纸和印刷的手感"，产物是一张打样。表里的先后只是常见情况。这一次哪个问题最贵，要按上面的算式重估：例如作品只有一个画面时，"每一镜的共性"就等于"那一个画面"，静帧直接升到第二位。

规则：样板按最终标准做那一小段，不做"先糙后精"（糙的样板确认了也不能当基线）。中间产物先由执行者自己看过、测过、修过，再给用户。用户要求全自主时，中间产物只用于自检。

"样板先行能避免成倍返工"方向可信，但量化来自单个项目复盘，**弱证据，待实验**。

### 9.2 交接时说清四件事

1. **示例替换表**（4.6、1.2）：放在交付说明的第一项，决定类各行排最前；交给制作时一并交给最终发布的人，未逐行确认的不发布。没有〔例〕的作品写"无"。
2. 这份简报交给哪些领域（第 14 章）。
3. 第一个中间产物是什么、谁来看、用哪条完成标准判。
4. 哪些决定是替用户做的、可以被推翻（简报第 3 栏）。

替换表排第一，推自 1.3 甲层：示例被当成事实发布，代价落在观众身上，是四件事里唯一一件错了由作品之外的人承担的。

### 9.3 第二轮修改意见（Q23）

**一条意见怎么写**：按 `framework/protocol.md` 现行写法，建议写成 **现象 → 目标 → 验证方法**，地位是「建议」，**待实验**，以 protocol 为准。本节与外部一种常见的三段写法接近，已申报（附录 C）。本书从"执行者要能动手、下一轮要能判定改完没有"推出的几项，分别落在三段里：

- **现象**：在哪（哪一段、哪个元素、什么情况下出现）+ 现在是什么样。"在哪"并进现象，因为同一个现象只在某处出现时，不写位置执行者就找不到它。
- **目标**：要变成什么样。现象和目标合起来就是"差多少"——写成一个差距，而不是只写目标，因为同一个目标从不同现状出发要做的事不同。
- **验证方法**：一个读数或一个是/否问题，例如"在手机尺寸截图里，这行字的最小字高 ≥ 起点值"。
- **补充项：别动什么**（另列，不并进三段）：这一处周围已经做好、改的时候容易被连带破坏的东西。另列的理由：三段都只盯着要改的那一处，验证方法验的是目标有没有达到，不验旁边有没有被碰坏；执行者只听到"改什么"，没听到"别碰什么"，改一处坏两处。

验证方法写不出的意见，先别发——它还只是一种感觉，按下面"模糊愿望"处理。

**模糊愿望：用轴生成选项，不用固定的翻译。** 用户说"再高级一点""更活泼"时，它有多种合法诠释，执行者默默挑一种，常常挑到最俗的那种（R1）。做法：从下面几条轴里挑两三条和这句愿望相关的，每条把两端都写成一个可做的改法，让用户指：

| 轴 | 一端 | 另一端 | 推自 |
|---|---|---|---|
| 熟悉度 | 往观众认得的某一类讲究的东西靠 | 往观众没见过的方向走远 | R1、R4：熟悉是中心的引力，远离是固着的出口 |
| 密度 | 每一刻的东西更少、停得更久 | 每一刻的东西更多、换得更快 | R3：密度的对错只由受众和情境裁决 |
| 证据感 | 加真实的材料、细节、出处 | 收成更概括的图形和字 | R6、R2：可信靠可核对的东西，概括靠一眼读懂 |
| 代价的可见度 | 让观众看见"这很费功夫"（手工、精度、真实拍摄） | 让它显得毫不费力 | R5：观众对投入的感知来自看得见的成本 |

两端都合法，轴本身也可以换——挑哪几条轴，看这句愿望在这件作品里最可能指什么。不给"高级 = 某一端"这样的固定答案。

**先交承诺对照表，再给意见。** 第二轮开始前，执行者先把方向承诺（6.6）和完成标准（第 8 章）逐行过一遍，每行自己判"守住 / 没守住"，附上判断用的截图或读数。看的人只需要针对两种行写意见：执行者判"没守住"的；执行者判"守住"、而看的人不同意的。自查的盲点在执行者感知不到的地方（不能实际听或看的部分）——这些行不许自判，必须给读数。

**一次改几处**：互相牵连的改动一次只改一组，并写明联动（动作更快 → 声音更密；调暗 → 复查文字对比）。批准后的大改（场景、风格、时长）回到第 6 章重新收拢。

### 9.4 三种交接取向

- **取向 A：简报一次交完**，执行领域自己安排中间产物。适合执行者能力强。
- **取向 B：简报 + 指定第一个中间产物**（9.1）。适合较弱的执行者或高成本作品。
- **取向 C：先交"反向简报"**（模型平时不会默认做）。执行领域收到简报后，先用自己的话把简报复述一遍，并写出"我打算怎么做"的三句话，交还给需求理解这一步核对，核对过才开工。推自 R2：误解在最便宜的文字层就暴露。

### 9.5 故意违反

**跳过中间产物，直接做整件**：适合整件本身就很便宜（例如一张单幅静态图），中间产物的成本接近整件时，没有理由多一步。

### 9.6 失败点预判与自检

- 失败点：修改意见只说"不好"不说改哪（禁用清单第 5 条）。发现方法：每条意见是否四项齐全，尤其是"怎么判"。
- 失败点：改了一处，坏了另一处。发现方法：每条意见的"别动什么"在下一轮逐项复查。
- 自检：第一个中间产物比整件便宜吗？它回答的是不是代价最大的那个问题？
- **可测量**：每条修改意见都带一个判定句（缺判定句的意见数 = 0）；"别动什么"所列元素，修改前后在同一时刻截帧对比，非预期变化处数 = 0。

## 第 10 章 连续作品、信号与回流（覆盖 Q25、Q26、Q28）

推自 R1、R4。

### 10.1 连续作品不继承上一支（Q28）

同类需求连续出现时，最大的风险是第 5 章动作 1 的"默认作品"悄悄变成了**上一支作品**。推导（R1，M-6 重推）：回归的中心是"这个生成者最熟悉的那一点"；做完一支之后，最熟悉的就是刚做完的那一支——它的简报还在手边、代码还能复用、用户上次点过头。所以同质化不是从品类继承来的，而是从执行者自己的上一次继承来的，要排除它，就得先把上一次记下来。

**比较什么：从"观众能否感知到"推。** 同质化是观众感知到的"又是这个"，所以只比观众感知得到的东西，而且用观众带走它的方式来比：
- **事后描述**：第 5 章方向写法的第 1 项，观众会怎么向别人描述它。
- **三帧缩略**：开头第一个完整画面、中段任意一帧、最后一帧，缩到缩略图大小。观众滑过时认出"又是这个"，靠的就是这种尺寸下的整体样子。
- **骨架动作**：它在时间或空间里做的那一个动作。

这三项合起来，记成这一支的**眼熟记录**（U-3 改名：观众滑过时觉得"眼熟、又是这个"，靠的就是这三样；名字按这个判断起），每支交付时记下。下一支发散时，把最近几支的眼熟记录并进动作 1 的默认，一起排除；判定用动作 4（事后描述能否互换；是否靠同一条事实、事后描述只差一个值），再加一个盲测：把两支的三帧缩略并排给不知情的人，问"是不是同一个人做的同一个系列"。

**复用的分界：同样从感知推。**
- 观众感知不到的——代码、工具、流程、测量方法、核查清单——放心复用，复用得越多越稳。
- 普通观众感知得到的——任何会出现在三帧缩略里、或会进入事后描述的东西——不复用，除非用户要的就是系列的统一识别。
- 只有同行感知得到的（例如某条特定的运动曲线）——给普通观众的作品里可以复用，但记进眼熟记录的备注，连续几支都用到时提醒一次。

差异检查放在方案阶段最便宜，交付前再查一次，防止实现中回退。

**系列作品**需要统一识别时，把"统一的部分"写成固定部分（7.9），其余每期重做。统一与差异的分界原料没覆盖，推演见第 13 章。

### 10.2 用什么信号判断"写法好不好"（Q26，弱证据）

- 同行收藏、点赞衡量的是"方法可复用"，偏向长的、带槽位的写法。
- 观众播放衡量的是"作品本身吸引人"，与提示词长度关系弱。
- 精选、被重制反映的是策展口味与早期传播。

我们要校准的是观众侧效果，所以同行收藏只能用来判断"哪些方法值得学"，不能用来判断"观众爱看什么"（禁用清单第 43 条）。这一节整体是**弱证据，待实验**：只有一份带互动数据的语料直接给出这一对比，有幸存者偏差；本项目平台的观众数据尚未积累。

### 10.3 三种回流取向

- **取向 A：按作品记录**。每支作品记下用户的选择（第 6 章方式一）和评审结论，累积到足够多再改书。
- **取向 B：按维度记录**。只记"哪个维度当初是空白、被我替定了、事后被用户推翻了"。积累后能回答骨架的知识缺口：用户实际否决推断的频率是多少。
- **取向 C：只记失败**（模型平时不会默认做）。只记录"成品被认成默认作品"的那些案例，以及当时漏掉的是哪个维度。适合想快速找到流程漏洞时。

单条数据不直接改书或标准，累积成证据后再改（宪章第四节）。

### 10.4 故意违反

**刻意继承**：用户就是要一个固定栏目、每期同一个样子时，照做。把"固定"写进合同，差异只发生在内容上。

### 10.5 失败点预判与自检

- 失败点：日志丢失，差异机制悄悄失效。发现方法：开工时找不到上一支的眼熟记录，就先补写再发散。
- 自检：这一支的事后描述，和最近一支能互换吗？（应不能。）
- **可测量**：三帧缩略盲测中，被认成"同一系列"的比例低于一半（用户要求系列统一的除外）；选了随机取向时，风格词汇库编号与抽取记录里，和最近几支重复的编号数被记下并低于你写下的上限。

## 第 11 章 简报模板：可以直接照填

**使用规则**
- 简报属于一次任务。下一个任务重新走流程，不拿上一份换皮（7.9）。
- 第 3 栏里的每一条，用户都可以一句话推翻。
- 形容词后面必须跟意图、参数或参照，否则删掉（7.1）。


**② 发散**（动作 3 选取向乙：从独有事实直接写方向，不抽取。和演示一、三的随机取向并列，用来展示另一种走法）

选乙的理由：这是讲解题，三条独有事实都具体、彼此不同类（形状、长度、经过的地方），满足取向乙的适用条件；收拢时要能逐条说清"这个方向从哪条事实来"。

第一层默认：旋转的三维地球、发光弧线、蓝色科技界面、飞机图标沿弧线滑动、"你知道吗？"开场。第二层默认：剥开一个橘子皮压平来讲地图为什么变形；在地球仪上两城之间拉一根绳子。两层及其近邻都不进候选。

独有事实（替换测试的同类：为什么地图上格陵兰看起来那么大、为什么船走的航线也弯；写完冻结）：
- 事实 1：这条线在平面上弯向北边，越是高纬度之间的航线弯得越明显——换成"格陵兰为什么大"不成立。
- 事实 2：弯的那条反而更短，短了三千多公里〔造〕——换成船的航线，数字和理由都不同。
- 事实 3：它会经过观众从没想到会经过的地方（北冰洋附近）——换成短途航线不成立。

逐条写（每条事实上连续两次没留下新方向就换下一条，三条都轮过就停）：

| 次 | 事实 | 写出的 | 结果 |

方向（读者是收拢的人，所以每个方向写事后描述、靠什么站住；只有 ⑤ 容易被读成默认，加一句"它不是"）：
- **方向 ① 按纬度排开**：事后描述"几条航线从低纬度到高纬度排开，越往北越弯"｜靠事实 1；纬度和线形由坐标算出〔造〕。
- **方向 ② 两个数字倒着讲**：事后描述"屏幕上先只有两个数，然后倒着讲为什么弯的那条更短"｜靠事实 2〔造〕。
- **方向 ③ 两架飞机比赛**：事后描述"两架飞机同时出发，走弯线的先到纽约"｜靠事实 2〔造〕。
- **方向 ④ 你先画一条**：事后描述"先让你在地图上画一条你觉得最短的线，再揭开真正的那条"｜靠事实 2。
- **方向 ⑤ 跟着一班飞机看地面**（非默认）：事后描述"一直从机翼下往地面看，看着看着下面变成了冰原"｜靠事实 3；要一段可授权的冰原实拍〔缺：要查授权〕，拿不到只能示意。它不是：从太空看地球（第一层默认）。

**③ 收拢：文字粗筛 + 小样决胜（6.1 的组合用法）**

理由：用户不在场，题材也不涉及他的品味；但最后谁更能让人"说出那个因为"，只能看了才知道。所以先在文字层用能写出来的事实淘汰，再把文字判不出的送去做小样。

文字粗筛（每一步都写得出依据，依据类型是事实，不是观感）：
- ① 淘汰：它讲的是"弯多少"，不讲"为什么弯"；观众复述里只会有"越往北越弯"，没有原因（3.2 理解一行的检验做不到）。
- ② 淘汰：只给两个数字，观众只能复述"弯的更短"，复述里不会出现原因（同上）。
- ④ 淘汰：观看情境是信息流看一遍，观众不会停下来去画（3.3 的情境事实）。
- ③ 与 ⑤：都能把"球面"和"平面"同时放进画面，哪个更能让人说出"因为"，取决于看起来清不清楚——这是观感，文字判不出，送小样。

小样：两个方向各做最能代表它的一段，按最终标准做（③ 做两架飞机分开的那几秒，⑤ 做地面变成冰原并揭出"它在北边"的那几秒）。由几个不参与制作的人分别看，不告诉他们哪个是谁做的，比较维度只用一条：**看完能否一句话说出"为什么是弯的"**。

假设 ⑤ 胜出（更多人的复述里出现了"因为地图是被拉平的"）。收拢理由：
- 选定：从机翼下看地面，地面变成冰原，揭出它飞到了北边。
- 依据：小样复述测试的结果；独有事实 3"它经过观众没想到的地方"〔造〕。
- 前提 → 若变 → 换到：改成发在大屏、观众会主动看完的地方 → ③ 也可以，因为比赛结构在大屏上更清楚；如果拿不到可授权的冰原实拍、只能用示意 → ③，因为示意的冰原削弱了"原来它真飞过那里"的惊讶。
- 借用：从 ③ 借最后一拍——两条线并排、标上两个距离，作为"为什么"的证据。

方向承诺：

| 失守处 | 失守时会变成什么 | 守住的样子 + 怎么查 |
|---|---|---|
| 最难的元素：平面上的弯线和球面上的位置对得上 | 手画一条好看的弧线 | 线上每一点都由坐标算出；查法：抽三个点核对经纬度 |
| 小件：城市名、距离数字、"大圆航线"那一次点名 | 科技感标签框（禁用清单第 33 条） | 用地图本身的图例语言标注；查法：逐件截图 |
| 强度：冰原出现的那一刻 | 被剪短成一闪而过 | 冰原画面加"理论最短路线最北约到北纬 84°"标注，停留 ≥ 读完标注的时间；查法：计时 |

**④ 简报要点**
- 变量区：〈出发城市〉〈到达城市〉= 北京、纽约（推断为观众熟悉的城市对，可换）；〈距离〉= 由坐标计算，见事实清单。
- 做到什么算完：
  1. 看完让不知情的人一句话说出为什么弯。失败：复述里没有"拉平 / 球面"这一类原因。
  2. 所有距离和纬度都能由事实清单里的坐标复算出来，误差在取整范围内。失败：有任何一个数复算不出。
  3. 城市名和距离数字的最小字高 ≥ 7.12 的起点值。失败：有一处不足。
  - 必保项：坐标算出的线；冰原那一刻的标注。
  - 失败点（工具）：三维地球渲染在高纬度处容易出现贴图拉伸，正好落在要讲的地方——小样阶段就截图检查北纬 70° 以上。
- 不要（按可能性排）：1 旋转地球、发光弧线、科技界面〔第一层默认〕；2 橘子皮、地球仪拉绳〔第二层默认〕；3 "飞机实际就走这条线"〔题材风险〕；4 "你知道吗"开场〔第一层默认〕。
- 反向定位：它不是一段地理课件，它更像靠窗座位上的一次意外发现。

**⑤ 交接**：交给镜头与叙事、视觉设计、动效节奏；写到意图档；第一个中间产物已在收拢时做了（小样），开工以胜出的小样为基线。

### 演示三：「我家楼下修表铺的老师傅想让我帮他做个短视频介绍一下店，发视频号」

> 这只是一种走法：下面的方向、选择和数字都是示例。

**① 理解**

| 维度 | 状态 | 处理 |
|---|---|---|
| 题材 | 已说：一家修表铺 | 照用 |
| 受众 | 隐含 | 推断：店附近的居民，家里有块不走了的表、不知道哪里能修；可否决 |
| 目标反应 | 隐含 | 主目的 = 记忆：过几天表坏了，能想起"楼下那家……的修表铺"。副目的 = 行动：知道在哪 |
| 观看情境 | 隐含 | 推断：视频号信息流，竖屏，静音自动播放，看一遍；配乐不混，由发布者在 App 内自选（本项目平台规则，可否决） |
| 店名、开了多少年、"老店"一类说法 | 事实空白（证明类） | 问；不给就不出现 |
| 师傅能不能露脸、出声 | 事实空白（授权） | 问 |
| 这家店和别家哪里不一样 | 事实空白 | 问——方向要扎根在这里 |
| 营业时间、地址行、换电池价格 | 样稿空白 · 决定类 | 填示例（见替换表）；观众会照着它上门、按它估钱，三行都标"决定类：发布前必须由用户确认"（1.2） |

要问的问题（三个通过返工测试，按代价排）：
1. 这家店有什么是别的修表铺没有的？推荐：说一件只有店里人知道的小事就行。猜错的后果：方向扎在不存在的东西上。
2. 师傅愿意露脸吗？推荐：不愿意就只拍手。猜错的后果：素材全部重拍。
3. 店名是什么、开了多少年？推荐：年数说不准就不提。猜错的后果：写错年数是虚假宣传。

假设回答："师傅不露脸，手可以拍；店名给了；年数说不准；他抽屉里有一些修好了一直没人来取的表，他都替人收着。"——"抽屉里有修好没人取的表，一直替人收着"转为〔给〕；年数不出现。"还在走"不在回答里，作品不能说它们还在走，除非再问到。

**② 发散**（动作 3 选取向甲：外部随机抽值再判断。并列取向之一，不是必经步骤）

选甲的理由：独有事实只有两条硬的、一条弱的，取向乙会让方向挤在"抽屉"那一条上（5.6 事实挤兑）；"修表铺介绍"同行做得多，容易收敛。

第一层默认：暖黄怀旧调色、齿轮旋转特写、滴答声、放大镜下的剪影、"匠心""时光"大字、胶片颗粒。第二层默认：表针倒转——"修好的是时间"的双关；全片按秒针一秒一切。两层及其近邻都不进候选。

独有事实（替换测试的同类：别的修表铺、手机维修店、钥匙铺；写完冻结）：
- 事实 1：抽屉里有修好了一直没人来取的表，师傅都替人收着〔给〕——换成别家不一定成立。

- 事实 3：修的是机械小件，一只表能拆成一桌零件——换成钥匙铺不成立，但换成别的修表铺仍成立（弱，只作辅助）。

契合度三问：
- ① 换成别的修表铺仍成立（第 1 问弱）。
- ② 换成任何维修店都成立（第 1 问不过）。

- ④ 换成任何维修店都成立；而且修理单上有客人信息（第 1 问不过，另有题材风险）。
- ⑤ "替人收着没取的表"只属于这家店〔给〕；拉开抽屉的第一眼静音也能认出"一抽屉手表"；可实拍。三问都过。

- 选定：拉开抽屉，一排修好了没人来取的表。
- 依据：〔给〕"抽屉里有修好没人取的表，一直替人收着"；主目的是记忆，观众要带走的是"那家替人收着表的店"。
- 前提 → 若变 → 换到：师傅不愿让抽屉出镜（表是客人的）→ ②；用户补来一位客人的真实故事并同意出镜 → ③；找出了旧价目牌 → ⑥。
- 借用：从 ④ 借"修理单上的手写字"——每只表挂一张手写小签，客人姓名一律遮去。

方向承诺：

**④ 简报要点**
- 变量区：〈店名〉= 用户给的；〈营业时间〉〈地址〉〈价格〉= 见替换表。
- 做到什么算完：
  1. 看完后去做别的事，两分钟后问"刚才那家店有什么特别的"，不给选项。失败：只答得出"修表的"。
  2. 抽屉那一帧缩成缩略图，能认出是"一抽屉手表"。失败：认成别的东西。
  3. 地址那一行的停留秒数 ≥ 0.5 + 字数 ÷ 4；离底边的距离 ≥ 视频号界面遮挡宽度 + 一个字高。失败：任一不满足。
  4. 画面中不出现年数、"老店""最"一类证明词。失败：出现任一个。
  - 必保项：实拍的抽屉；拉开后的静止时长与面积。
  - 失败点（题材）：小签或表背面刻着客人的名字——交付前逐帧查，有就遮。
- 不要（按可能性排）：1 暖黄怀旧、胶片颗粒、齿轮特写〔第一层默认〕；2 表针倒转、按秒切〔第二层默认〕；3 "匠心""时光"大字〔第一层默认〕；4 年数与"老店"〔题材风险：未给的证明〕；5 "还在走"〔题材风险：未确认〕；6 素材署名〔平台〕；7 混入配乐〔平台〕。
- 反向定位：它不是一支"老手艺"怀旧片，它更像一句"你的表还在我这儿"。

**⑤ 交接**：交给镜头与叙事（拍摄说明，只拍手）、视觉设计；写到意图档，"强度"一行为参数档；第一个中间产物是"抽屉拉开那一镜的样板，按最终标准拍"——它回答"一抽屉表能不能一眼认出、要停多久"这个最贵的问题，用第 2 条判，并顺带把停留时长定下来。

### 13.2 原料整体没覆盖的问题

1. **需求本身错了**（例如要在极短时长里讲清复杂机制）。方案：先按第 3 章推出"受众要得到目标反应需要几个意义单元"，再按 7.2 推出所需时长；若超出用户给的时长，不默默删内容，而是写成选择题交给用户——"保留时长，只讲一点"或"保留内容，加长"或"改成系列"。待实验验证。
2. **受众与目的的验收**。方案：8.2 表最后一行的复述测试 + 发布后的真实数据回流。待实验验证。
3. **系列作品的统一与差异**。方案：统一的只放三类东西——名字、一个固定位置、一个固定的声音或色彩信号；其余每期按第 5 章重新发散，并用眼熟记录排除上一期。统一部分的数量越少，每期的差异空间越大。待实验验证。
4. **多语言与本地化**。方案：语言当作观看情境的一部分写进第 5 栏；长中文、竖排、从右到左等情况在格式维度标"可能需要另一套布局"，交给视觉设计判断。待实验验证。
5. **需求方不是终端观众**。方案：两方偏好冲突时不裁决，写成"你要的 X 会让观众在……处看不懂，可选……"（3.6），由需求方决定，并把决定记在第 3 栏。待实验验证。
6. **简报颗粒度的反向代价**。方案：7.1 三档 + 7.10 极简简报作为对照组；同需求用不同档位各做多次，测作品之间的差异是否随颗粒度变细而变小。待实验验证。
7. **观众数据回流修正维度权重**。方案：第 10 章取向 B 的按维度记录；当某个维度在高播放作品中总是"被明确写过"、在低播放作品中总是"被替定"，就把它的处理从"替定"升为"问"。单条数据不改，累积后改。待实验验证。
