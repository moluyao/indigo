# 镜头与叙事

一本从原理出发的镜头与叙事手册。书里的数值都是我定的起点，每个都写了推导；改它要改推导，不是改数。命中禁用清单的值，"非它不可"的理由统一放在附录。

**单位**：时间用秒（s），需要帧时按 30fps 换算，换帧率按秒重算。画幅参考横屏 1920×1080、竖屏 1080×1920；尺寸写成画面高 H 或宽 W 的分数，不写死像素。

**怎么读**：每章开头标出覆盖的 Q 编号，每个取向标出"推自"哪条原理。书里没有默认取向：创作时先按内容放开几个方向，再写明理由收拢到一个。风格方向只作为可选项引用风格词汇库的条目编号（如 S73），不代表推荐。

**标记**：「弱证据，待实验」= 依据只有单家或无对照；「分歧·待实验」= 骨架标为各家分歧，书里两端并列，不裁决；「待实验验证」= 我的推演，原料没有回答。

**术语**
- **事件**：一镜首帧与末帧之间，能用"某物 + 做了什么"一句话说出的状态差。
- **读取时长 R**：观众第一次看、全速、可能静音时，发现、理解、写入一件事所需的时间（第 8 章给算法）。
- **承接物**：跨过镜头或段落边界继续存在、并在边界后换了角色的东西。
- **主轴**：一段片子的时间由谁驱动（人声、音乐、因果、阅读）。
- **代表帧**：只被看到一帧时，应该被看到的那一帧。
- **重音**：全片里被刻意加重的少数时刻（转折、峰值、招牌运镜）。

## 〇、六条第一性原理

**N1 状态差律（事件）**：注意和记忆只登记"变化了的东西"，并且按"主体 + 变化"打包存储。一支片被记住的单位不是画面，而是"什么变成了什么"。没有状态差的段落，在记忆里等于不存在。
→ 推出：最小故事、每镜必须有事件、结尾要和开头不同、代表帧要能说出发生了什么。

**N2 串行律（单焦点注意）**：视觉注意一次只能落在一个地方，同时发生的两件事只会被看到一件，另一件要么被错过，要么被读成噪声。工作记忆一次只装得下少数几个块，听觉语言和画面文字争用同一份语言通道。
→ 推出：一镜一个焦点、因果按顺序排、错峰、文字与口播不同时说两件事、镜内预算。

**N3 预期律**：观众每时每刻都在预测下一刻。结构的全部手段就是建立预期，再兑现、推迟或打破。可预测的重复会降级成背景（节拍器）；稀缺的东西因为出乎预期而有重量。
→ 推出：峰值只花一次、转折前留空、重音稀缺、运镜与转场有预算、笑点结构、长短悬殊的节奏。

**N4 作者盲区律（读取延迟）**：作者知道下一步，观众不知道。观众只看一次、全速、常常静音、随时能离开，读取速度系统性地慢于作者的估计。凡是"我觉得够了"的时长，都要换成按观众读取算出来、并能测量的时长。
→ 推出：镜头时长由读取量决定、开场必须静音自洽、代表帧、按实测音频排时间、机器对账。

**N5 同一性律（连续）**：大脑持续追踪"同一个东西"。一个东西在变，被读成一件连续的事；一个东西被换掉，被读成翻页，并且要付出重新定位空间的成本。方向、位置、速度的连贯让追踪不断线。
→ 推出：承接物、转场、一镜到底、屏幕方向、循环接缝、"像幻灯片"的承接病因。

**N6 具身情绪律**：情绪不是被"告知"的，而是被身体性的关系触发：距离远近、尺度大小、光的多少、速度快慢、被包围还是被留下；以及看到另一个人（或物）的反应。写着情绪名字的字，触发的是阅读，不是情绪。
→ 推出：反应镜头要停留、运镜表达情绪、可见量承载情绪弧、画面承载意思而文字只做确认、角色表演。

六条之间的张力是本书大多数分歧的来源：N3 要稀缺和落差，N4 要慢和清楚；N5 要连续，N3 又要意外。每章的取向，本质上是在这几对张力之间选不同的位置。

## 第 1 章 动手之前：放开方向、写阐述（Q39、Q36）

### 1.1 推导：为什么先放开
第一反应是最常被选过的那个反应，模型尤其如此（N3：观众对"见过的"不再分配注意）。而一旦看了示例再动手，继承的不是表面，是底盘：结构、开场、结尾的位置。所以顺序必须是：**先写出自己的方向 → 再看任何标杆 → 再收拢**。

### 1.2 取向一：对立轴发散（推自 N3、N1）
- 先从内容里找出 2–4 条**彼此独立的轴**，每条轴两端都要说得出画面，例如：有角色 / 只有物；按时间讲 / 按空间走；讲解 / 演出；一个连续世界 / 分段；真实素材主导 / 图示主导。
- 每个候选方向在每条轴上选一端。两个候选在一半以上的轴上选了同一端，就算同一个方向，合并。
- **停止规则**（不定数量）：持续发散，直到连续两个新方向都被判为旧方向的变体为止。判据：把每个方向写成"开场画面一句 + 转折一句 + 结尾画面一句"，三句里有两句与某个旧方向说的是同一个物在做同一件事，即为变体。
- 推导：数量是结果不是目标。用"新方向开始重复"作为停止点，内容本身决定能放开多远。

### 1.3 取向二：约束注入（模型平时不会默认这样做；推自 N3）
- 给每个候选随机抽一条**禁止项**，从禁止项反推设计：不许剪辑 / 不许出现文字 / 全片只有一个物 / 主角永远不入画 / 只用一种颜色说话 / 时间倒着走。
- 写不出方案的禁止项，说明这个内容对它强依赖，记下来——这恰好是内容的骨头在哪里。
- 推导：默认方向来自"什么都能用"；拿走一种工具，会迫使结构从别处长出来。

### 1.4 取向三：从代表帧倒推（推自 N1、N4）
- 先画出**唯一一张**能讲完全片的静帧（第 5 章），再问：要走到这张画面，观众之前必须看见什么？之后还剩什么？
- 方向的差异来自代表帧的差异：三张画面不同的代表帧，自然长出三支不同的片。
- 推导：如果找不到这一帧，想法还没落到画面上，后面所有镜头都会是概念的插图。

### 1.5 取向四：品类外标杆
- 标杆至少有一个来自题材之外的品类（风格词汇库 S86"借用别的品类"是其中一条路，不是唯一）。从标杆身上只拿"它的物体服从的那条规则"，不拿它的场景顺序和外观。
- 标杆在第 1.2–1.4 的方向写完之后才看。

### 1.6 阐述要写到什么颗粒度（Q36）
文字和静帧是最便宜的确认物（N4：作者以为清楚的，写下来才暴露不清楚）。三种写法，彼此可替代，按场合选：

- **问题式阐述**（推自 N1、N4）：不按字段填表，而是回答一组问题。看完的人能复述的那一句话是什么？什么物在全片里变成了什么？哪一帧能独立讲完？在哪里转、转之前压低了什么？最可能读不懂的是哪一镜、成片后怎么查出来？结尾和开头是什么关系？——任一题答不出，就不动手。
- **静帧先行**（推自 N4）：先给需求方看少量关键静帧（代表帧、开场、转折前后、结尾），确认后再写逐拍表。适合需求方对文字不敏感、对画面敏感的情况。
- **逐拍表**（推自 N1、N5）：每行回答六件事——锚点（词、拍或因果，不写绝对秒）｜看见的物｜它的状态差｜谁触发它｜什么跨过了这一刀｜风险。写不出"物"和"状态差"的行，说明这一镜只有概念。
- 表前锁定全局：画面"是用什么做的"、颜色怎么分工、角色出不出现——它们一旦镜镜重议，就会变成拼贴。

**自主模式**（无需求方）：让一个没看过制作过程的 agent 只读阐述，复述"这支片讲了什么、哪里转、怎么结束"。复述与作者原意不一致之处，就是阐述的漏洞。「待实验验证」

### 1.7 故意违反
不写阐述、先做后写：直接拿素材即兴排，做完再倒写阐述。得到"发现式"的松弛和意外，适合氛围片、纯形式片、素材本身强到会自己说话的纪实片。代价是返工高，必须在做完后补写阐述并照它检查一遍。

### 1.8 失败点预判
- 阐述只有形容词（"高级、有张力"）。提前发现：把阐述里的形容词全删掉，剩下的部分还能不能拍。
- 候选方向只是同一套卡讲不同故事。提前发现：用 1.2 的三句判据比较。
- 先看了示例，结构被继承。提前发现：和这个创作者上一支片比较开场物、转折位置、结尾物三项，全同即警告。

### 1.9 自检
- 删掉全部形容词后，阐述还剩多少可执行的"物 + 动作"？
- 最终方向在每条对立轴上的选择，能不能各说出一个理由？
- 被杀掉的方向，各自死于什么理由？

## 第 2 章 有参考片时：复刻、拿语法，还是中间（Q38）

### 2.1 推导
看一遍参考片，记住的是印象而不是分布（N4 作用在作者自己身上：看片的人也只看一次）。所以三种取向都先**测量**，只是测完之后拿走的东西不同。骨架标此处为分歧，分歧维度是作品目的，下面三者并列，不裁决。「分歧·待实验」

**测什么**（三种取向共用）：切点位置（场景切换检测，不按固定间隔抽帧）；每镜取首、中、末三帧；逐帧画面差分得到的能量曲线；完全静止帧的占比与最长静止段；最长安静段（声轨）；每个转场的类型；相机运动的方向序列。

### 2.2 取向一：逐帧复刻（目的是展示复刻能力；推自 N4）
- 唯一验收依据是并排测量：同一时刻两片叠化看差异，不看印象。容差从参考片自身推：位置差不超过参考画面里最细文字的笔画宽，切点差为零帧（切点是离散事件，差一帧就是另一个切点）。
- 诚实边界：不复用原片的音乐、人声、真人影像；不暗示合作关系。

### 2.3 取向二：只拿语法（目的是做原创片；推自 N3、N5）
- 把测量结果写成"手法 → 它解决的问题 → 我采用/弃用 + 理由"的清单。学的是语法，不是画面。
- 节拍来自我们自己的概念，不来自参考片的场景顺序：先把自己的阐述写完（第 1 章），再逐条决定语法能不能装进去。
- 判据：把新片的场景顺序与参考片对照，若同序超过一半，退回。

### 2.4 取向三：结构复用、外观重做（中间地带；「待实验验证」）
- 只保留参考片的能量曲线形状和切点密度分布，镜头内容、物、颜色、承接方式全部重做。
- 抄袭边界的可操作判据（我的推演）：把两片都抽象成"每镜的物 + 动作"一列文字，若对应行有一半以上可以互换而不改意思，就是结构抄袭，退到取向二。

### 2.5 故意违反
故意把参考片的语法用在**最不匹配**的题材上（例如把灾难片预告的语法用在一杯咖啡上），得到戏仿与反差喜剧。前提是观众认得出原语法，否则只剩错位。

### 2.6 失败点预判与自检
- 失败：凭印象复刻，切点偏几帧却自以为对；一张参考图被当成全片的风格令。提前发现：复刻片必须出叠化差异图；参考图只标注"它描述的是哪一类镜头"。
- 自检：参考片的完全静止帧占比是多少？我的片是多少？我说得出差值的理由吗？

## 第 3 章 最小故事与笑点（Q1、Q2）

### 3.1 推导
N1 说记忆按"主体 + 变化"打包，N2 说短时记忆只装得下一条线。所以短片最小的结构不是"起承转合"，而是**一个观众能用一句话说出的前后状态差**。笑点是 N3 的特例：先让观众形成一个确定的预期，再用一个事后合理的东西打破它；角色的反应是观众确认"刚才发生了什么"的地方（N6）。

**最小故事的判据**（所有取向共用）：给一个没看过的人看末帧和首帧，他能不能说出"什么变了"。说不出，就没有故事。

### 3.2 取向一：欲望驱动（推自 N1、N6）
- 主体想要某样东西 → 被挡住 → 做了某件事 → 得到或失去。状态差是"拥有"的变化。
- 适合有角色、能画出"目标"与"阻碍"的内容。
- 起点：阻碍要能被画出来（一扇关着的门、一个太高的架子），写不出画面的阻碍换一个。

### 3.3 取向二：物的变形（推自 N1、N5）
- 没有角色，主体是一个物或一个想法，状态差是它的形态、数量、位置的变化：一个变成很多、散的变成整的、小的显出它其实很大。
- 适合产品、机制、抽象概念。观众追踪的是"同一个东西"的连续变化（N5），不需要欲望。

### 3.4 取向三：揭示（信息差；推自 N3）
- 状态差不在画面里，在观众的理解里：开头让观众以为是 A，结尾让他看出其实是 B（尺度揭示、视角揭示、身份揭示）。
- 起点：开头的"误读"必须是观众自己会做的那种，而不是靠隐瞒；结尾的揭示要能回看验证——观众回看开头，会发现线索一直在。

### 3.5 取向四：重复与差异（模型平时不会默认；推自 N3）
- 同一件事完整发生两到三次，每次只改一个变量，意义来自变量本身。不需要冲突，也不需要转折。
- 适合散文式、诗性、比较类内容。重复次数上限由片长决定：每次重复至少要留出观众比较的时间（一次 R，第 8 章）。

### 3.6 笑点的内部（Q2，全节「弱证据，待实验」）
笑点由四个零件组成：**前提**（建立预期）、**升级**（预期被加码）、**打破**（事后合理的意外）、**反应**（确认）。三种组装方式：

- **递进式**（推自 N3）：升级次数 n 由片长决定，每次升级比上次多一个"维度"而不只是更大（更大 → 更多 → 更不合时宜），最后一次打破的方向与升级方向相反。起点：n 取"片长能装下的最大次数减一"，留出一次给打破。
- **一击式**（推自 N3、N4）：没有升级，前提极清楚，然后一次打破。前提的清晰度就是全部成本：前提镜头里不许有第二件事（N2）。
- **反应即包袱**（推自 N6）：事件本身平淡或在画外，笑点全在反应的大小与时机。反应镜头的停留要比事件镜头长——观众笑的那段时间里画面必须还在。起点：反应停留 ≥ 观众笑完的时间，我取 2R（第 8 章），并标「待实验」。
- **不笑的反差**（故意违反的一种）：在所有人都预期出笑点的地方，什么都不发生，或只发生一件极小的事。得到冷幽默，适合已建立喜剧预期的系列片。

**埋伏与兑现**：画面里被特意强调过的东西必须在后面被用到；不兑现就别强调（N3：被强调 = 被承诺）。

### 3.7 故意违反
- 没有状态差的片：全片保持同一状态，只有观察角度在变。适合氛围循环、冥想、产品"在场感"。替代的注意来源见补缺章 C1。
- 多条线并行：两个主体各自变化，最后一刻交汇。适合"原来它们是一件事"的揭示，代价是前段读取量翻倍，片长必须够。

### 3.8 失败点预判
- 只有情绪形容词没有状态差（"展现温暖"）。提前发现：首末帧测试说不出变化。
- 笑点争抢：两个包袱相邻，第二个吃掉第一个的反应时间。提前发现：在逐拍表里检查每个包袱后面是否紧跟反应停留。
- 讲解片里插笑点打断论证。提前发现：删掉这个笑点，论证是否更连贯；更连贯就删。

### 3.9 自检
- 首末帧测试：外人能否一句话说出"什么变了"？
- 每个被强调的物，是否在后文兑现？
- 每个包袱后的反应停留是否 ≥ 2R？

## 第 4 章 全片能量弧：峰值与转折（Q3、Q4）

### 4.1 推导
N3：持续的高能会降级成背景，峰值只有在低处衬托下才被认出来；花过一次的手法第二次就不再意外。N6：情绪无法布置，但距离、尺寸、数量、亮度、相机远近可以布置。所以：**用一个可见量承载情绪弧**，把弧线变成可以画出来、可以测量的曲线；峰值独占一种全片不重复的手法。

**可见量**（选一个作主轴，最多再选一个作副轴）：两物的距离、主体的尺寸、计数、画面亮度、相机与主体的距离、画面里的颜色数量、留白比例。写下它在每一镜的值，连成曲线，就是能量弧。

### 4.2 峰值放在哪：四种取向（「分歧·待实验」：峰值形态与位置）
以下位置都是**算出来**的，不是选一个百分比。

- **后置峰（算位）**（推自 N3、N4）：峰值时刻 = 片尾 − 余波时长。余波 = 峰值之后观众必须读完的东西（结尾画面）的 R + 一次呼吸。峰值离片尾越近，蓄力越长，但余波太短，峰值没被消化就结束。
- **末帧即峰**（推自 N3）：没有余波，峰值就是最后一帧，片子在最高点切断。适合循环片（峰值直接接回开头）、悬念片、"就是它"式结论。代价是结尾记忆不稳，必须配合第 6 章的强代表帧。
- **前置峰（倒金字塔）**（模型平时不会默认；推自 N4）：最强的东西放在开头交付，其后是逐步降低能量的解释与证据。适合新闻快讯、结论先行的讲解、划走率极高的信息流。代价：后段要靠信息新鲜度而不是能量留人，必须让每一镜都带新信息（第 9 章）。
- **无峰平台**（推自 N1）：能量在一个窄带内起伏，没有单一高点，靠缓慢的单调变化（例如亮度一路升高）给出方向。适合氛围片、冥想、陈列。是否需要峰值见补缺章 C2。

**峰值的形态**（两端并列，各自适合不同情况）：
- **聚合**：已出现过的元素回到一起。适合"系统、生态、合力"的主题。
- **孤立**：其他一切退下，只剩一件事。适合"本质、唯一、告别"的主题。
- 二者同片同时使用会互相抵消（N3：两种相反的预期同时兑现，等于都没兑现）。一个片只选一种。

### 4.3 转折：之前、之中、之后（Q4）
转折是预期的方向被改变（N3）。它需要三样东西：一个已经稳定的预期、一个让观众意识到"要变了"的空隙、一个比其余接缝都大的落差。

**转折前的空隙**：长度由上一段的节奏推出，而不是固定值——空隙要明显长于上一段的平均事件间隔，观众才会把它读作"停"而不是"慢"。起点：空隙 = 上一段平均事件间隔 × 2，下限是一个完整的 R（短于读取时间，观众感觉不到停）。上限：超过上一段平均间隔的 4 倍，开始被读作断裂或卡住。「弱证据，待实验」

**由谁承担**（三种取向）：
- **声先于画**（推自 N3、N4）：声音（音乐段落变化、一个音效、一口吸气）先到，画面后翻。大脑先被提示，画面翻转时被"确认"。领先量我取一个可感知但不被读作错位的量：约 2–3 帧（视听同步的宽容窗口里，声音领先比落后更难被察觉）。「弱证据，待实验」
- **画先于声**（推自 N2、N6）：画面先变，声音延后半拍或干脆空掉，观众在"没有声音确认"的那一瞬间感到失重。适合惊愕、悲剧、反高潮。
- **叙述句承担**（推自 N2）：口播的转折词（"但""直到"）开启下一镜；画面不在词前变，在转折词说完后的第一个停顿处切。这样画面结构与论证结构同构。

**密度高点与响度高点分开**：转折那一刻画面要简单（一件事），最忙的段落放在转折之后的展开里。两者重合时，观众在最需要看清的那一刻看到的最多（违反 N2）。

**转折的稀缺**：全片的"大转折"只有一次；其余接缝的落差要明显更小，否则大转折被稀释。音乐片例外：音乐本身有多次释放，每次释放要用不同的手段承担，不能同一种落差重复。

### 4.4 故意违反
- 峰值放在开头而后面不解释、不降：得到"事故现场"式的冲击与茫然，适合真实灾难、突发事件。
- 全片均匀、没有峰：得到催眠、陈列、档案感，适合目录式、标本图鉴式内容（风格词汇库 S88 是一种可能的外观）。
- 每个接缝都做成转折：得到疲惫、混乱，适合表现"信息过载"本身的题材。必须全片一致地过载，否则只像失控。

### 4.5 失败点预判
- 峰值提前花掉：最强的手法在前 1/3 就用了。提前发现：在逐拍表里给每镜标"用了哪种手法"，最稀有的那一种必须只出现在峰值处。
- 承载量的曲线是平的或锯齿：写下每镜的可见量数值画成曲线，看形状。
- 转折前的空隙被音效或字幕填满。提前发现：检查转折前那段的声轨与字幕轨是否真的空。

### 4.6 自检
- 可见量的曲线是什么形状？峰值在哪一镜？能不能用一个数说出峰值比平均高多少？
- 峰值独占的那种手法，在其他镜头出现过吗？（应为 0 次）
- 转折前空隙 ÷ 上一段平均事件间隔 = ?（起点 2，范围 1–4）

## 第 5 章 片长决定结构，主轴决定时间（Q5、Q28、Q37）

### 5.1 推导
每切一次，观众都要在新空间里重新定位（N5 的成本）。片子越短，这笔成本占比越大。所以片长决定的是"能付得起几次重新定位"。另一方面，一段片子的时间到底由谁驱动，取决于这段的瓶颈：讲解段的瓶颈是理解（N4），情绪段的瓶颈是节奏（N3），操作段的瓶颈是因果（N1、N2）。**主轴就是瓶颈的承担者。**

### 5.2 结构单位：三种取向（「分歧·待实验」：连续场景与卡拍蒙太奇并存）
- **重定位预算法**（推自 N5、N4）：每次换空间，观众要先用约一个 R 看清"这是哪"，才能开始看事件。规定重定位总时长不超过片长的 1/5，可换空间次数 = 片长 × 1/5 ÷ R。片很短时这个数会小于 1——也就是只能有一个连续空间。推导：超过 1/5，观众用在"找"上的时间多于用在"看"上的时间的四分之一，开始感到累。「待实验验证」
- **一个想法一个乐章**（推自 N1、N2）：先数想法，每个想法一个乐章（可以是一个空间，也可以是一组镜头），乐章内部连续，乐章之间才允许换空间。切点出现在论证转折处，不在每个句子处。
- **卡拍蒙太奇**（推自 N3）：高频切本身就是语法，观众不再试图在每个空间里定位，而是把整段读作一个"节奏块"。适合音乐驱动、情绪堆积、"很多很多"的主题。重定位成本在这里被转化为冲击。条件：每个镜头必须一眼可读（单焦点、高对比），否则只是闪烁。

**中长片何时必须分场**：当一个连续空间里的站点多到观众记不住"我们从哪来"时。起点判据：同一空间里的站点数超过工作记忆的块数（我取 4）就分场。「待实验验证」

### 5.3 主轴：四种（Q28）
- **人声主轴**：画面和音乐让位于口播；画面事件锚在词上（第 13 章）。
- **音乐主轴**：音乐的段落决定能量弧；有用户指定的曲子时，曲子决定弧线，内容去凑段落。
- **因果主轴**：操作或物理过程的因果决定时间；点击、落下、到达的时刻由"上一步完成"决定，不由拍子决定。
- **阅读主轴**（模型平时不会默认；推自 N4）：没有口播也没有强节奏时，以画面上必须读完的东西为时钟，每个事件的间隔 = 它之前那件事的 R。片子的节奏由内容的读取量自然生成。

**片内切换主轴**：允许，但切换处要有一个"交接点"——上一个主轴的最后一个事件，同时是下一个主轴的第一个事件（例如口播最后一句的最后一个词落在音乐段落起点上）。没有交接点的切换，观众会感到时间突然换了单位。「待实验验证」

**一律按实测排时间**：音频以实测为准，计划时长只用于估算。

### 5.4 时间表怎么组织（Q37）
- 时间写成**相对锚点**：相对于词、拍、上一事件完成，而不是绝对秒。绝对时间只在最后渲染时换算，换算之前不取整（提前取整会让误差层层累积）。
- **一张表派生一切**：字幕、音效、转场点、相机关键帧都从同一张锚点表派生。改一个锚，派生物自动跟随。
- 段落有名字，代码结构与叙事结构同构：改一镜，只动一个子结构。
- 源分析值（实测的词时间、拍位置）与输出偏移（为了观感手动加的提前或延后）分两栏记，不混在一个数里。

### 5.5 故意违反
- 画面与声音用两套不相关的主轴：得到疏离、梦境、"声音来自另一个世界"，适合回忆、失真、焦虑题材。全片都要脱节，脱节一半只像错误。
- 极短片里频繁换空间：得到"闪回、碎片记忆"，适合表现混乱或回忆闪现。

### 5.6 失败点预判
- 讲解段为了卡拍删掉必要条件。提前发现：讲解段若用了音乐主轴，逐条核对论证有没有被删的条件。
- 操作段让拍子决定点击时机，因果变得像巧合。
- 时间线里有未察觉的空隙。提前发现：从锚点表自动列出所有"没有任何事件"的区间及长度。

### 5.7 自检
- 每段写得出它的主轴和瓶颈吗？
- 重定位总时长 ÷ 片长 = ?（起点上限 1/5）
- 改一句稿、换一首同速曲，有多少处要手改？（应接近 0）

## 第 6 章 开场与代表帧（Q6、Q7）

### 6.1 推导
观众在第一次读取（一个 R）之内决定留不留，而且常常静音（N4）。第一印象的容量最低，一个主体做一个完整动作比几个元素同时出现更可读（N2）。不传递具体信息的开场（标题、慢速品牌、"即将开始"）等于把最贵的一秒花在观众不关心的东西上。

**共用底线**：首帧就是一张完成的构图（不是黑场、不是空画面、不是未完成的入场）；关掉声音，开场依然自洽。

### 6.2 开场的四种取向（「分歧·待实验」：开场能量与承诺顺序）
- **承诺先行**（推自 N4）：首帧就说出观众能得到的东西——一个结果、一个反常的数字、一句观众自己会说的话。随后才是证明。适合信息流、讲解、快讯。
- **低能铺垫**（推自 N3、N6）：一个安静、具体、略带疑问的小场景（一个物在等待、一个人在犹豫），不给答案，靠"这里会发生什么"扣住。适合故事片、品牌情绪片、有耐心的受众。代价：在高划走平台上风险高，必须有一个在动的具体物，不能只是空镜。
- **异常先行**（推自 N3）：首帧是一个看起来不对的东西——尺度不对、方向不对、物在做它不该做的事，而且正在动。解释放在后面。适合悬念、揭示型故事（第 3.4 节）。
- **以终为始**（模型平时不会默认；推自 N1、N5）：首帧就是结尾的状态，然后倒回去讲"怎么到这里的"。观众从第一秒就知道状态差的终点，看的是过程。适合改造、建造、成长、事故复盘。

**钩子字**（若用文字承担钩子）：字高 ≥ 画宽的 1/16（竖屏 1080 宽约 68px，横屏 1920 宽约 120px 的标题在小窗里同样够用）。推导：手机竖屏实际宽约 6–7cm，一瞥能读的汉字约需 4mm 高，4/68 ≈ 1/17，取整到 1/16。对比度在真实背景上实测 ≥ 4.5:1（文字下面若有素材或运动，按最差那一帧测）。「弱证据，待实验」

**行动号召在开场要不要出现**：取决于平台是否会在中途截断播放。会截断的平台，开场可以出现一次弱提示（不占主体位置）；不会截断的，留到结尾。「待实验验证」

### 6.3 代表帧（Q7）
静帧是传播的主体：缩略图、截图、减弱动效模式，都只给一帧。处于变化中途的帧（数字滚到一半、形状变形一半）被冻结后读作故障。

三种取向：
- **结果帧**（推自 N1）：状态差落定的那一刻。最稳，适合讲解与产品。
- **开场即代表帧**（推自 N4）：首帧就是代表帧，缩略图与开场一致，观众点进来看到的就是他被承诺的画面。适合"承诺先行"。
- **临界帧**（推自 N3）：事件即将发生的前一瞬——球离杯沿一指、手离按钮一指。它是完成的构图（不是变形中途），但包含一个未决的张力。适合悬念与笑点。

**代表帧测试**：把候选帧单独给一个没看过的人看，问"这里发生了什么"。回答与阐述的一句话一致才算过。找不到能过测试的帧，回到第 1 章——想法还没落到画面上。

**代表帧与封面**：封面是平台另行设计的物，可以在代表帧的基础上重新构图、加字，但其中的主物与主动作应与代表帧一致，否则点进来的人会觉得被骗。「待实验验证」

### 6.4 故意违反
- 全黑或纯色首帧、靠声音开场：适合恐怖、悬疑、"先听见再看见"的叙事。只在有声播放的场合成立，静音信息流里不要用。
- 慢速品牌开场：适合品牌本身就是内容的场合（观众是来看这个品牌的发布）。
- "看到最后才知道"：适合预告片、谜题片，但开场必须仍有一个具体的物在动。

### 6.5 失败点预判
- 首帧是入场动画的第 0 帧（空的或半透明）。提前发现：导出第 0 帧单独看。
- 钩子依赖声音。提前发现：静音看开场，复述它说了什么。
- 开场同时出现三个以上元素。提前发现：数首帧里的独立运动物体。

### 6.6 自检
- 静音、只看第一个 R，能复述这支片要给我什么吗？
- 代表帧测试的回答与一句话阐述是否一致？
- 首帧有没有任何一个元素处于入场或变形中途？

## 第 7 章 结尾与循环（Q8、Q9）

### 7.1 推导
结构闭合让观众感到"讲完了"，而闭合来自与开头的关系（N5：同一个东西回来了）；呼应若带着变化，就同时完成了 N1 的状态差证明。结尾需要停留让记忆写入（N4），但完全冻死又可能被读作卡住。

### 7.2 结尾的五种取向（「分歧·待实验」：结尾能否用文字卡、静止是否保留微运动）
- **变奏呼应**（推自 N1、N5）：结尾与开头同一个构图、同一个物，但状态不同。观众一眼对照出"变了什么"。最接近最小故事判据（第 3.1 节）。
- **尺度揭示**（推自 N3、N6）：相机后退或画框扩大，观众第一次看到全貌，原来前面的一切只是其中一角。适合揭示型故事、"小事放进大世界"。
- **第二次做对**（推自 N1、N3）：开头失败的那个动作，在结尾再做一次并成功。观众因为看过失败，才对成功有感觉。
- **物的最后一个动作**（推自 N1、N6）：不回到任何地方，主物做完一个收束的动作（合上、放下、熄灭、转身）就结束。像影片而不像演示文稿。
- **悬置**（模型平时不会默认；推自 N3）：结尾停在一个未决的时刻，问题留给观众。适合系列片的单集、引发讨论的观点片。条件：问题必须在片中被清楚地建立过，否则只是没做完。

**文字在结尾**：两端并列。一端：结尾落在物上，文字最多是画面一角的一行确认（推自 N6）。另一端：结尾就是一句话，因为这句话就是片子的结论，或者观众需要带走一个可搜索的名字（推自 N4、第 14 章术语）。选后者时，那句话应当是全片论证的结论，而不是金句。

**结尾停留**（「分歧·待实验」）：
- **真冻结**：最后一帧完全静止，时长 = 该帧的 R + 一次确认注视。声音的尾巴（余响、最后一个音的衰减）继续，告诉观众"没卡，是结束了"。
- **单一微生命**：只保留一种极低能量的变化（光的缓慢变化、一缕烟），其余静止。适合循环播放平台与氛围片。
- **主动离场**：不停留，结尾画面自己退出（主物离开画框、灯熄）。适合有声播放、节奏利落的片子。

### 7.3 循环的接缝（Q9）
循环片的末帧接回首帧。观众对因果极敏感（N1），无原因的倒退或清空被读作错误；位置对上而速度跳变，循环仍然会"顿"一下（N5 追踪的是运动，不只是位置）。

**接缝检查法**：把末尾几帧和开头几帧拼成一条连续帧带，逐元素计算跨接缝的速度变化。速度变化不超过约 15% 视为连续（速度辨别的韦伯分数约一到二成，取中间）。「弱证据，待实验」

**重置的四种取向**：
- **可见原因**：有一个东西把累积的内容清掉（一阵风、一只手、一扇门），清空成为一个事件。
- **锚点不动**：主物作为锚点始终在场，其他内容绕着它退场再进场，重置读作"翻页"。
- **遮挡瞬换**：在一个大遮挡（主物经过画面、全屏的光）之下完成重置。
- **传送带**（模型平时不会默认）：没有"重置"时刻，内容从一侧持续进、从另一侧持续出，循环点藏在均匀的流动里。适合陈列、氛围、数据流。

**接缝处的空白**：不超过本片平均事件间隔。更长，观众会注意到"什么都没发生"的那一刻，从而发现循环点。

**叙事型与氛围型循环**：叙事型（故事回到开头）的接缝可以有一个明显的"重新开始"信号，因为故事本身承认了循环；氛围型必须无缝。「待实验验证」

### 7.4 故意违反
- 突然停：在动作中间硬切到黑。得到戛然而止、震惊、"被打断"，适合悲剧、事故、悬念。必须是全片最强的那一刀。
- 结尾与开头毫无关系：得到"走远了"的漂流感，适合公路片式、意识流内容。

### 7.5 失败点预判与自检
- 失败：最后一个理解单元还没落地就结束；结尾的多个信息被压进极短时间；循环接缝处方向突变；新加入的东西凭空消失。提前发现：逐拍表里结尾那一行的 R 是否被完整留出；连续帧带检查。
- 自检：首帧与末帧并排，能说出"变了什么"吗？结尾停留 ≥ 末帧的 R 吗？跨接缝速度变化 ≤ 15% 吗？

## 第 8 章 镜头是一个事件：状态差与可见原因（Q15、Q18）

### 8.1 推导
事件是注意的单位（N1）。只有运动、没有状态差的镜头被读成屏保。变化需要主语：观众对因果极敏感，一个变化若没有可见的触发者，就像页面对着空气反应（N1）；原因可见还顺带告诉视线下一步看哪（N2）。

**事件判据**：每一镜在逐拍表里写得出"某物 + 动词 + 结果"。写成"展示""呈现""体现"的，不是事件。

### 8.2 事件的四种主语
- **角色**：想要、发现、尝试、失败、反应、得到。适合故事片。
- **被操作的物**：被打开、被装满、被拆开、被连接。适合产品与机制。
- **自己变化的物**：生长、分裂、腐蚀、聚集——概念自身就是主体。适合抽象概念、科学、数据。
- **观众的理解**（推自 N3）：画面不变，但一个新信息（一行字、一个声音、一个视角）让同一画面的意义变了。适合揭示与反讽。这一种最容易被误当成"没有事件"，判据是：观众看完能说出"原来……"。

### 8.3 原因的三种取向（Q18）
- **操作者在场**（推自 N1、N2）：一只手、一个光标、一个角色触发变化。原因先于结果出现，并在结果发生前停稳——运动中的原因会抢走结果的注意。起点：原因停稳到结果开始之间留一个短停顿，长度 = 观众视线从原因移到结果所需（原因与结果紧邻时可为 0，离得远时约一次扫视）。
- **概念自担因果**（推自 N1、N5）：没有操作者，原因由内容自身扮演——一个点落下导致波纹，一个数增长推开旁边的东西。适合抽象、系统、物理。判据：把"谁推动了它"问一遍，答得出画面里的某个东西。
- **上一镜即原因**（模型平时不会默认；推自 N5）：这一镜的变化由上一镜的动作引起——上一镜扔出的球，在这一镜打碎了东西。原因跨越切点，因果本身成了承接物（第 10 章）。

**无操作者的后台变化**（系统在别处产生的后果，如服务器、算法、时间流逝）：用"后果的痕迹"代替操作者——先让观众看见一个原本状态，再切到它被改变了的样子，中间插一个"时间或空间在别处"的提示（钟、远景、通知抵达）。「待实验验证」

**原因不要遮住结果**：光标、手、角色的身体不能盖住它触发的目标。聚光圈、高亮框不是操作者，用它们冒充原因，观众仍然不知道"谁做的"。

### 8.4 故意违反
- 有原因无结果：手按下按钮，什么都没发生。得到失望、无力、讽刺，适合讲故障、官僚、失灵。
- 有结果无原因：一切自己在变，且刻意不给解释。得到神秘、超自然、不安，适合恐怖、魔幻、"这背后是什么"的悬念。全片都要这样，偶尔一次只像漏画。
- 纯氛围镜头：没有事件，只有状态。全片中应是少数，并且是有意的（判据：去掉它，能量弧是否少了一次呼吸；少了才留）。

### 8.5 失败点预判
- 角色站着微笑，什么也没发生。提前发现：逐拍表"状态差"一栏写不出。
- 界面自己在变，没有触发者。提前发现：每个界面变化问一次"谁做的"。
- 原因与结果同时发生，观众只看到一个（N2）。提前发现：在时间表里检查原因停稳点是否早于结果起点。

### 8.6 自检
- 每一镜的"某物 + 动词 + 结果"是否都写得出？写不出的镜数 = ?（应为 0，纯氛围镜头单独标注）
- 每个变化能否指出画面里的原因？
- 原因停稳点早于结果起点吗？

## 第 9 章 一个镜头该多长（Q10）

### 9.1 推导：读取时长 R
作者系统性低估观众的读取时间（N4），而两件事同时发生只被看到一件（N2）。所以镜头时长不由"动画需要多久"决定，而由"观众按顺序读完这一镜里每件事需要多久"决定。**动作可以快，含义需要停**：动作时长与含义停留是两个独立的量。

**R = 发现 F + 理解 U + 写入 W**（全节「弱证据，待实验」，系数是我按注视的生理量定的起点）
- **F 发现**：事物出现在当前注视点上，F = 0；出现在别处，F ≈ 0.25s（一次扫视的潜伏加飞行）；画面里每多一个同时在动的竞争者，再加 0.25s。
- **U 理解**
  - 中文文字：按注视次数算，一次注视约覆盖 2 个字、约 0.25s，读完再加一次回扫：U = 0.25s × ⌈字数/2⌉ + 0.25s。
  - 拉丁文字：每词约一次注视：U = 0.25s × 词数 + 0.25s。
  - 图像：数出观众必须辨认的部分（主体、它的状态、它和谁的关系），每部分一次注视约 0.3s。
  - **难度系数 k**：常用词 1；术语、数字、专名 1.5；口播同时在说另一件事 2（语言通道冲突，N2）。U 乘以 k。
- **W 写入**：一般信息一次确认注视约 0.3s；本镜的关键信息（结论、数字、包袱）两次，约 0.6s。
- 一镜里有多件事时按顺序相加：**镜长 ≥ ΣR**。

例：一行 10 字的常用语，出现在注视点外，关键信息：F 0.25 + U(0.25×5+0.25 = 1.5) + W 0.6 ≈ 2.35s。同一行字若口播同时在说别的，U 翻倍，≈ 3.85s——这说明更好的做法是让字和口播说同一件事，而不是延长镜头。

**测量代替估算**：成片后请没看过的人看一遍，在每镜结束时暂停，问这一镜说了什么。答不出的镜，R 被低估了。

### 9.2 三种取向
- **读取预算型**（推自 N4、N2）：镜长 = ΣR × 1.3。1.3 是作者盲区的补偿：作者按自己的读速估 R，而作者已经知道内容。适合讲解、信息密集、多语言。「弱证据，待实验」
- **主轴给定型**（推自 N4，配合第 5 章）：镜长由口播或音乐给定，R 只用来检查：ΣR 超过给定镜长时，**删内容而不是加速**——砍掉一件事，而不是让每件事都快一点。
- **压缩重看型**（模型平时不会默认；推自 N3）：故意让镜长短于 ΣR，让观众第一遍只抓住主体、第二遍才看见细节。只用于会循环播放的平台、彩蛋式细节、"再看一遍才发现"的设计；必要信息不许放进被压缩的那一部分。

### 9.3 故意违反
在一镜里同时放两件同等重要的事：观众只能看到其中一件，不同观众看到不同的那件。得到"多义、人人看到的不一样"，适合引发讨论的片、谜题片。

### 9.4 失败点预判与自检
- 失败：一切同一个轻快速度；结尾的几个理解单元被压进极短时间；作者看了五十遍后觉得"太慢"而全面提速。提前发现：每镜在表里写出 ΣR；改动只能删事项，不能缩短 R 以下。
- 自检：镜长 ÷ ΣR 的最小值是多少？（读取预算型起点 ≥ 1.3，主轴给定型 ≥ 1）首看测试中答不出的镜有几个？

## 第 10 章 节奏的形状与静止（Q11、Q12）

### 10.1 推导
感官适应恒定刺激，注意靠对比维持（N3）。节奏是间隔的形状，不是速度。计量节奏的单位应是**新信息**，而不是新运动：一个在动却没带来新信息的东西不推进节奏，只增加噪声。这一个换算同时治"太密"（运动多、信息少）和"太空"（信息之间间隔过长）。

**事件间隔序列**：把全片的新信息事件按时间列出，相邻差值就是间隔序列，画成曲线就是节奏的形状。

### 10.2 节奏的四种取向
- **长短档位型**（推自 N3）：镜长归成至少 3 档，相邻档之比 ≥ 1.4（时长辨别的韦伯分数约一到二成，1.4 约为两个辨别阈，保证档与档被感知为"不同"）。至少一次**加速**：连续三个以上间隔，每个约为前一个的 0.7 倍（每步变化约 30%，单步就能被察觉，又不至于两三步就塌到不可读）；至少一次**呼吸**：一个间隔 ≥ 其前后局部平均的 2 倍。
- **音乐句法型**（推自 N3）：节奏由音乐的乐句结构承担——切点落在乐句层级而不是每拍；少数切点故意落在反拍或拍前，制造切分。适合音乐主轴段。
- **单调渐变型**（模型平时不会默认；推自 N1、N3）：全片只有一个方向的变化——间隔从头到尾一路变短（越来越急）或一路变长（越来越慢），没有爆发也没有回落。适合单一元素连续变形、倒计时、沉入式的告别。它没有爆发，不算缺陷。
- **爆发—真空型**（推自 N3、N2）：节奏的重心是一两个**爆发**——一组事件的间隔短于发现时间 F，观众无法逐个读，整组被读作一块"质地"；爆发之后紧跟一段明显的真空。爆发位置避开均匀分布的格点（落在格点上会被读成节拍器的一部分）。

**布局级大变化是标点**：大变化的次数 = 乐章数（第 5 章），不按每分钟定额。

**镜头结束方式也要轮换**：同一种收尾（每镜都推进后切、都淡出）连用会形成第二层单调，即使镜长有变化。

### 10.3 静止是休息还是死机（Q12，「分歧·待实验」）
两端都同意：静止必须是设计出来的停留，而不是没东西可做。分歧在于停留时画面要不要还在动。

- **真静止**（推自 N3）：休息必须真的不动，缓推也是运动。静止的总量不定额，由内容推出：全片静止时长 ≈ 全部关键信息的写入时间 W 之和 + 爆发后的真空。适合有爆发对比的发布片、喜剧的包袱后停顿、需要"让它落地"的结论。
- **极缓呼吸**（推自 N6、N5）：观众在听人说话时，一层几乎察觉不到的空间运动能消除"静止画布"感。用**层间视差平移**而不是整体缩放：背景层相对前景层在一镜内总共漂移约 H/60（1080 高约 18px），观众感到空间而不感到运动。适合口播、讲解、长停留的证据画面。
- **分层静止**（模型平时不会默认；推自 N2）：静止按层分配——主体与相机完全静止，只有环境层里一个极低能量的东西在变（光、尘、远处的车）；或反过来，环境冻结，只有主体在动。观众的焦点层是"静"的，生命感来自焦点之外。
- **只让声音动**：画面完全静止，时间由声音推进（脚步、钟、呼吸）。适合紧张、等待、悬疑。

**判别是否"死机"**：静止中，观众是否知道自己在等什么或在看什么。知道 = 休息；不知道 = 死机。

### 10.4 故意违反
- 所有镜头等长：得到机械、仪式、监视器感，适合表现重复劳动、制度、监控的题材。
- 全片无静止：得到窒息、焦虑、追逐，适合短的、要表现"停不下来"的内容。

### 10.5 失败点预判
- 节奏检查全过，但"新运动"多、"新信息"少。提前发现：间隔序列只统计带新信息的事件。
- 每个停留都在缓推，没有真正的休息（这是选了"极缓呼吸"却每镜都用的结果）。提前发现：统计用了缓慢运动的镜头占比，并问每一次的理由。
- 处处在呼吸（光晕脉动、扫光），口播片发抖。提前发现：关掉主体只看环境层，它是否比主体还热闹。

### 10.6 自检
- 镜长有几档？相邻档之比？最长 ÷ 最短 = ?
- 间隔序列里能指出加速段和呼吸段的位置吗？
- 每段静止，观众知道自己在等什么吗？

## 第 11 章 一镜之内：注意力预算与进退场（Q16、Q17）

### 11.1 推导
视觉注意是串行的（N2）：多个同时运动互相抢，错峰把并行信息变成可逐个读的序列。凌乱往往不是哪个动作错了，而是没有预算。"它在配合谁"这一问能把装饰性动作过滤掉。

**计数口径**：按"组"计，不按个数计。共同命运（同向、同速、同时）的一群元素算一组——一群粒子、一列卡片一起移动，是一个元素。降权留守（对比降低、完全静止）的元素计入"在场"，不计入"在动"。

### 11.2 预算的三种取向
- **焦点序列型**（推自 N2）：任一时刻只有一个焦点在动；其余要么降权留守，要么不在场。配合者的运动必须与焦点同向或同时，被并入焦点那一组。在场的组数上限取 4（工作记忆的块数），超过就要有组退场或合并。适合讲解、产品、口播。
- **群体质地型**（推自 N2、N6）：画面主体本身就是群体（人群、鸟群、数据点云），预算按"群体的整体行为"计——群体聚、散、转向是事件，个体运动是质地。适合规模、系统、社会类主题。条件：群体里如果有一个"主角个体"，它必须在对比上明显跳出。
- **满屏探索型**（模型平时不会默认；推自 N3、N4）：故意满屏高密度（风格词汇库 S18 报纸版面、S88 网格墙是可能的外观），让观众自己探索。条件有二：必须有一个对比最高的入口；停留时长按"探索"而不是"读完"计——取入口的 R 加上观众能自选看两三处的时间，并且必要信息只放在入口。适合图鉴、档案、"信息量本身就是重点"。

**背景要被决定**：背景是什么空间、它活不活着、还是有意的空，每一镜都要做出选择并写下来。"有意的空"是合法选择；"没想过"不是。

**视线路径**：从当前焦点到下一个焦点之间的连线上，不放高对比元素——眼睛要沿着这条路走，路上有东西就会被截走。

### 11.3 进场：挂在什么提示上（Q17）
没挂提示的出现被读作随机（N3）；机械的"一句一个新元素"是堆积型凌乱的根源。

- **语义边界进场**（推自 N1、N2）：新元素只在语义边界进场——一个论点开始时。陪衬句不进新元素，只让已有元素响应。转折句开启的是下一镜：旧镜先清场，转折句的画面动作归入下一镜。
- **逐词响应、不逐词进场**（推自 N2、N4）：每个关键词都有画面响应，但响应是**已有元素的变化**（高亮、变形、移动），不是新元素。这样口播的颗粒度和画面的颗粒度对上了，画面元素的数量却不增长。
- **预告显形**（模型平时不会默认；推自 N3）：元素提前以低权重状态出现（轮廓、虚影、局部），到提示点才"兑现"成完整状态。得到"承诺—兑现"的期待感，代价是削弱落点的冲击。适合多步骤流程、观众需要提前知道"一共有几步"的内容。

### 11.4 离场与镜头边界
- **出点保护**：本镜最后一个事件落定后，到切点之间至少留出该事件的 W（一般 0.3s，关键信息 0.6s）。更近，动作被转场吞掉。
- **开镜空窗**：开镜后第一个事件不晚于观众完成重新定位（约一次 R 的发现部分 F 加上辨认空间的一次注视）。更晚，观众会觉得"这镜在等什么"。
- **字画同起同收**：字幕与它描述的画面事件同时出现；字幕消失不早于画面事件落定，两者收尾差不超过一次注视（约 0.25s）。
- **降权留守 ≠ 退场**：把旧主体降权后留在原位，新主体进来时不能落在它的位置上，否则两者相撞。

### 11.5 故意违反
所有元素同时、满屏地出现，没有焦点：得到"淹没、过载、压迫"，适合表现信息爆炸、焦虑、群体噪音。持续时长要短于一个 R，并且之后立刻给出一个单焦点画面作为对照。

### 11.6 失败点预判与自检
- 失败：满屏同时弹入；说到后面满屏静物没人退场；切点时还有东西在入场；元素比它的词早很久显形（不是有意的预告显形）。提前发现：从时间表自动统计每一时刻"在动的组数"和"在场的组数"；列出每个进场所挂的提示。
- 自检：任一时刻在动的组数最大是多少？每个进场挂的是什么提示？每镜最后事件到切点的距离 ≥ 该事件的 W 吗？

## 第 12 章 全片层面：轮换与"像幻灯片"（Q13、Q14）

### 12.1 推导
单镜质检看不见全片节奏：同一个动作连用，观众就感到节拍器（N3）。但每镜换一种画风会变成拼贴，因为观众要不断重新识别"这是什么世界"（N5）。所以**轮换发生在构图层，统一发生在风格层**。"像幻灯片"是 N5 的失败：每一拍替换上一拍，而不是从上一拍长出来；它有多个独立病因，单修一个不够。

### 12.2 轮换的三种取向（Q13）
- **摊表法**（推自 N3、N4）：把全片每一镜摊在一张表上，列出版式变量：构图（主物在哪、多大）、呈现容器（截图、实物、图示、角色）、相机动作、收尾方式。规则：
  - 相邻两镜同一变量取同值，必须是因为它们是同一个连续动作（承接），否则换掉至少一个变量。
  - 一个变量有 k 种取值时，任何一种取值的全片占比不超过 2/k（均匀分布的两倍）。例：容器有 4 种，任何一种不超过一半。
- **母题系统**（推自 N5、N3；风格词汇库 S85 单一母题系统是一种外观）：全片故意只用一个母题（一个形状、一种容器、一个构图），重复本身就是设计；变化发生在母题内部——尺寸、数量、方向、状态逐镜不同。适合品牌系统、极简、"一个想法反复推敲"。判据：观众能说出母题在每一镜里变了什么；说不出，就只是重复。
- **语义映射轮换**（模型平时不会默认；推自 N1、N2）：构图不随机轮换，而是绑定内容关系——对比永远左右分、步骤永远一条路径、因果永远上下、数量永远尺寸。轮换由内容结构产生，观众学会"这种构图意味着这种关系"后，读取更快。

### 12.3 "像幻灯片"的病因清单（Q14）
每一项都能从逐拍表算出来，比成片后修便宜。逐项判，不合成一个总分（各病因相对权重未知，合成分会掩盖最重的那一项）。

| 病因 | 从计划表怎么判 | 推自 |
|---|---|---|
| 节奏 | 镜长只有一档；间隔序列没有加速与呼吸 | N3 |
| 承接 | 边界上没有任何东西跨过这一刀的比例 | N5 |
| 空间 | 全片没有相机层，画布始终静止 | N5、N6 |
| 生命 | 元素入场后即"死"；或反过来所有元素各自无限循环、什么都没落定 | N1 |
| 版面 | 固定页框；要点逐条进入；文字主导的镜头占多数；结尾是居中句子 | N2 |
| 素材 | 全片只有字和图标，没有真实的物、照片、录像 | N4 |

### 12.4 三种治法（可组合，但不必全用）
- **生长治法**（推自 N5）：每一拍从上一拍的某个东西长出来——上一镜的一个数字放大成这一镜的舞台，上一镜的一条线延伸成这一镜的路径。
- **世界治法**（推自 N5、N6）：把所有内容放进一个连续空间，换"页"变成相机在空间里移动（第 13 章一镜到底）。
- **物证治法**（推自 N4）：用真实素材替换示意物（第 15 章）。观众看见"真的东西"，就不再把画面读作演示文稿。

注意：节奏全对仍可能像幻灯片，因为承接是独立的维度；"干净统一但略像幻灯片"有时仍优于花哨拼贴——两种失败里，前者更容易修。

### 12.5 故意违反
故意做成幻灯片：固定页框、翻页声、逐条出现。得到讲座感、冷幽默、对"汇报文化"的戏仿，适合讽刺职场、模仿讲座的喜剧。必须做得比真幻灯片更"标准"，观众才会读出是故意的。

### 12.6 失败点预判与自检
- 失败：多数镜头是同一个"人物在角落、素材在中间、文字在一侧"；全片同一个缓推；反向失败是每镜换画风。提前发现：摊表；把全片每镜首帧缩成一排缩略图并排看。
- 自检：每个版式变量的最高占比 ≤ 2/k 吗？病因表里命中几项、分别打算用哪种治法？缩略图一排里，有没有相邻几张一眼看去一样、却说不出它们是同一个连续动作？

## 第 13 章 边界：承接、转场与连续空间（Q19、Q20、Q21、Q22）

### 13.1 推导
大脑把"同一个东西在变"读作连续事件，把"一个东西被换掉"读作翻页（N5）。注意力被强刺激占据时，对画面其余部分的变化不敏感；运动的方向和速度跨切点保持，大脑读成一次连续移动。每个切点都应说得出理由：下一步、位置匹配、形状变形、尺度穿越、因果、回调。

### 13.2 承接物的取向（Q19）
- **主体延续**（推自 N5）：同一个物跨过切点，在下一镜里换了角色（上一镜的主角成为下一镜的背景、工具或容器）。条件：边界那一刻它在画内且足够大，大到是那一刻的焦点。
- **容器变场景**（推自 N5、N6）：上一镜里的一个容器（一扇窗、一块屏、一个字的内部）被推进，成为下一镜的整个场景。
- **因果承接**（推自 N1、N5）：上一镜的动作在下一镜产生结果（第 8.3 节）。边界上跨过去的不是物，是因果。
- **声音承接**（模型平时不会默认；推自 N5、N2）：画面硬切，但声音跨过切点——下一镜的声音提前进入，或上一镜的声音延续到下一镜。观众的连续感由听觉维持，画面可以大胆地换世界。
- **硬切**（推自 N3）：什么也不承接。保留给连击段、片尾、需要"砸"的那一刀。硬切越少，它越响。

**多元素拼成的承接**（几个小元素一起跨过边界）：观众追踪的是"一个东西"，几个碎片很可能不被读作承接。判据：边界前后两帧并排，没看过的人能不能指出"同一个东西"。「弱证据，待实验」

### 13.3 转场：一套语法还是按接缝变化（Q20，「分歧·待实验」）
- **一套语法贯穿**（推自 N5）：全片只用一种有意义的转场（例如一切都通过"推进容器"换场），重复让它成为这支片的语言。适合系统感、品牌、单一隐喻。风险：退化成通用淡化那样的"没有设计"——区分在于这种转场是否属于这个故事。
- **按接缝变化**（推自 N3）：每个接缝按它的关系选转场：对峙关系用对峙式、因果用因果承接、时间流逝用渐变。适合多段落、多关系的讲解片。风险：手法轮番上，读作炫技。
- **大多数硬切 + 少数转场**（推自 N3）：默认硬切，只在两三个结构点上用转场，转场本身成为标点。

**藏住剪刀**：切点放在注意被占据的时刻——一个大动作的中途、一次全画面的遮挡、一声强音。遮挡必须真的完全覆盖，露缝即穿帮。转场里不许出现空白帧。切点放在口播换气处，不在句子中间。

**转场时长**：从相邻两镜的富余里借（富余 = 镜长 − ΣR）。富余不够，就没有资格做长转场，换成硬切或承接。转场时长是结果，不是选项。

**一个接缝只用一种手法**：叠加多种（闪光 + 震动 + 声效 + 模糊）不会更强，只会让观众不知道该看哪个。

### 13.4 一镜到底与连续空间（Q21）
- **适用**：内容本身有空间、流程、时间线或尺度隐喻。叙事顺序 = 空间路径。
- **站点间距**：相邻站点在相机到达之前不应半成形地入画；要么站点之间的距离超过一个画面宽，要么内容在相机靠近时才成形。
- **行进速度**：移动中需要读的内容，相机速度 ≤ 约 1 屏宽/秒；移动中无需读，可到约 2 屏宽/秒。推导：手机观看时画面约占 13° 视角，平滑追踪约在每秒 30° 以内可靠，即约 2 屏宽/秒为追踪上限；要同时阅读，取一半。「弱证据，待实验」
- **节奏来源**：连续空间里没有切点，节奏只能靠速度变化与停留——在站点停下，就是一次"切"。
- 不必全片一镜：可以整幕连续，幕间仍用转场。

### 13.5 多场景连续性（Q22，「弱证据，待实验」）
- 角色、道具、场景配色用**同一个绘制模块**在各场共享，不按描述各自重画——按描述重画必然漂移。
- 先把一小段做到最终质量，作为质量标杆和工具链验证，再铺开。
- 每个场景边界写交接：上一场结束于什么（物、位置、方向、光），下一场开始于什么。
- 屏幕方向：主体向右走，下一镜还向右；方向翻转要有可见的理由（转身、一个反打镜头）。

### 13.6 故意违反、失败点、自检
- 故意违反：每个切点都跳到完全不相连的世界，不承接也不转场。得到拼贴、梦境、意识流，适合回忆、超现实、"信息碎片"主题。必须全片一致。
- 失败：遮挡露缝；转场切在句中；连续世界中主体被甩出画外；同一道具两场画得不一样；左右交替导致频繁越轴。提前发现：每个边界列出承接物或转场的理由；连续空间里逐帧检查主体是否始终在画内。
- 自检：每个边界的理由写得出吗？无理由的边界数 = ?（应为 0）转场时长都小于相邻镜的富余吗？

## 第 14 章 相机：何时动、像谁在拿、跟不跟拍、表达什么（Q23、Q24、Q25、Q26）

### 14.1 推导
相机的首要职责是让观众看清（N4）；画面自身在动、观众在读字时，相机运动会抢注意（N2）。相机重音像文中加粗，处处加粗等于没有重点（N3）。相机同时也是观众的身体：它靠近、后退、停下、环绕，观众就产生对应的身体性感受（N6）。

**动之前先回答**：当前景别下观众看得清吗？看得清就不必动。若要动，写出动机属于哪一类：**看清**（推近到能读）、**跟随**（主体在走）、**关系**（拉开以显示两者关系）、**情绪**（14.5）、**承接**（推进容器换场）。说不出动机的运动删掉。

### 14.2 运镜密度的三种取向（Q23，分歧维度是片种）
- **不动相机**（推自 N2、N4）：相机全片或几乎全片固定，所有运动由内容承担。适合口播、证据、精密图解、静物美学。相机唯一的一次运动因此成为全片最大的重音。
- **有动机的少数**（推自 N3、N4）：每次运动都属于上面五类动机之一；重音运动（快、大、出乎意料的那种）的次数 ≤ 全片转折点与峰值的数目之和——重音只出现在结构点上。同方向的运动不连续三次；推进之后不立刻拉回（那只是来回晃）。
- **相机即叙述者**（模型平时不会默认；推自 N6、N5）：相机始终在动，像一个在场景里走动的人，它的停、转、靠近就是叙事本身（与一镜到底配合）。适合沉浸、探索、第一人称题材。条件：揭示与读字时刻相机必须停稳。

**素材自身在动时相机让位**：录像、动画、主体在大幅运动时，相机不再叠加运动。

### 14.3 掌镜感（Q24）
掌镜感来自"关键位置怎么放"，不是运动本身。
- **滞后跟随**（推自 N6）：相机晚于主体到达，读作"有人在跟"。滞后量取人的视觉跟踪反应时间：约 0.2s。用一个临界阻尼的跟随（不过冲），而不是固定延迟，主体减速时相机自然追上。
- **提前抵达**（推自 N3）：相机先到落点等主体进来，读作"有人预判了它"，适合体育、动作、精准感。
- **机械稳定**（推自 N4）：完全没有人的痕迹，像轨道或监视器。适合产品、科学、冷静的叙述，也适合"被监视"的题材。
- **手持层**（「分歧·待实验」：要不要加）：加则用无周期重复的低频噪声，幅度小于最小文字的字高，停留时归零（否则没有真休息）。产品与口播片一般不加。
- **参照物**：空背景上看不出相机在动。要让观众感到相机运动，画面里必须有深度或纹理参照。
- **操作时刻先停稳**：点击、揭示的那一刻相机已经静止。
- **主体不出画**：逐帧检查主体包围盒是否始终在画框内（这项常被其他检查漏掉）。

### 14.4 相机与节拍（Q25）
- **时机全落拍、幅度要稀缺**（推自 N3）：相机的起止点落在拍上，但大冲击（整画面的跳、震、砸）只留给少数结构点——每拍都砸就是节拍频率的画面抖动。
- **用速度承载拍点**（推自 N5、N3）：一段内运动方向不变，拍点由速度的阶梯变化承载（每拍提速或顿一下），而不是每拍重新构图——每拍重构图的相机就是节拍器，左右交替还会反复越轴。
- **主体层响应、相机不动**（推自 N2）：拍点全部由画面里的元素响应，相机作为稳定的参照。适合音乐里有人声或画面有文字的段落。
- 音效：密集音乐已提供时间纹理，切点不必每个都加声效；稀疏的声轨反而需要切点有声。

### 14.5 情绪运镜（Q26，「弱证据，待实验」）
相机替观众做出身体动作（N6）。下面是从空间直觉推出的对应，原料只讨论过前两种，其余是我的推演：

| 情绪 | 相机行为 |
|---|---|
| 审视 | 内容时间冻结，相机继续缓慢移动绕看 |
| 孤立、告别 | 相机后退，世界由远及近依次暗下，只剩主体 |
| 压迫 | 相机缓慢逼近且略低于主体，画框里的空间越来越少 |
| 释放 | 相机从近处急速升起或后退，画框突然变大 |
| 亲近 | 相机靠近到主体只剩局部，运动变慢变软 |
| 不安 | 相机持续微小地漂移、不肯停稳 |

- 冻结审视时内容必须肉眼可见地完全静止，否则观众感觉不到"时间停了"。平面元素在大角度环绕下会穿帮，环绕角度上限由元素的平面程度决定：越平越小。
- 情绪运镜的次数 = 全片情绪转折的次数，通常极少；多了就是另一种炫技。与峰值形态要匹配：孤立式峰值配后退，聚合式峰值配逼近或环绕，不交叉。

### 14.6 故意违反、失败点、自检
- 故意违反：相机始终不看重点——主体在画框边缘、相机对着无关的东西，主体只露出一部分。得到偷窥、纪实、"我们不该在这里"的感觉，适合伪纪录、心理恐怖（风格词汇库 S68 是一种外观）。
- 失败：一支片几十次全往里推；每镜匀速慢推；念到一个名词就推一次；主体被甩出画外；停留中仍在漂浮。提前发现：从时间表列出每次相机运动及其动机类别，统计方向序列。
- 自检：每次相机运动的动机类别写得出吗？重音运动数 ≤ 结构点数吗？揭示时刻相机速度为 0 吗？

## 第 15 章 取景与文字：主体多大、意思靠谁讲（Q27、Q32）

### 15.1 推导
取景的首要职责是可读（N4）：一个元素缩到观众看不清，它的动效根本不存在。机位的倾斜与大角度会压缩文字。另一方面，尺度本身就是情绪（N6）：大到填满画框的物让人感到逼近，小在大留白里的物让人感到孤单或安静。文字是第二个阅读任务，会和画面抢注意（N2）；但讲解片里文字又是听觉信息的视觉对位物，静音观众只能靠它（N4）。

### 15.2 主体多大（Q27，「分歧·待实验」：主体要大 vs 小元素大留白，分歧维度是片种与信息密度）
不定比例，从"必须读清的最小细节"反推：
- **细节决定尺度**（推自 N4）：找出这一镜里观众必须看清的最小细节（一个按钮的字、一个表情、一根指针），让它在目标设备上的高度 ≥ 画面高的 1/40（手机竖屏约 3mm，接近一瞥可辨的下限）。主体的尺寸由此倒推出来，而不是先定"主体占多少"。「弱证据，待实验」
- **大主体、裁出画框**（推自 N6、N4）：主体大到被画框裁掉一部分，暗示画框外还有更多；只裁"填充物"（边框、空白、重复的部分），文字、可点控件、结果永远完整。适合产品、物证、"近看"的力量感。
- **小主体、大留白**（推自 N6、N3）：主体小，四周是有意义的空（天空、墙、空房间）。适合孤独、安静、尺度对比、诗性。条件：主体是唯一的高对比物，否则会被留白吞掉；而且这一镜里没有需要读清的细节。
- **满幅无主体**（模型平时不会默认）：画面被一种纹理或图案铺满，没有单一主体，主体是"这一整片"。适合材料、规模、质地。

**边距系统**：元素要么明确对齐到一条边距线，要么明显越过它。差几个像素的"差一点"会被读作失误。

**机位**：风格化机位（倾斜、仰俯、极端角度）逐镜决定——叙事镜可以用，信息密集镜保持正面平视。参考图描述的是一类镜头，不是全片的机位令。

**特写与全景的分工**：每个操作一个特写，全景留给关系本身。页面缩成缩略图时，要么推近到一个组件，要么只取那个组件。

**竖屏**：主体重心放在画面上半到中部（下部常被平台的字幕、按钮遮挡）；上下分区比左右分区更自然；纵向运动（上下推移）是竖屏的主运动方向。「待实验验证」

### 15.3 意思靠画面还是文字（Q32，「分歧·待实验」）
- **画面承载、文字确认**（推自 N2、N6）：意思在画面机制里发生，观众是"看见"而不是"读到"；文字只在画面讲完之后出现一次，作为可带走的名字或结论。适合角色片、产品机制、演出。
- **文字承载论证**（推自 N4）：讲解与新闻类片，文字是静音观众唯一的通道。文字与口播说的是**同一件事**（不同时说两件），每镜只承载一个论点；文字镜头的占比由论点数决定：需要被带走的论点有几个，就有几个文字承担的时刻。适合快讯、讲解、静音平台（风格词汇库 S75 社交字幕新闻是一种外观）。
- **文字就是画面**（推自 N1；风格词汇库 S27 动态排版是一种外观）：字本身是主体，字的变形、排列、出现方式就是事件。适合诗歌、歌词、宣言、引语。此时第 11 章的"文字是第二个任务"不成立，因为没有第一个任务。
- **完全无字**（推自 N6）：靠画面与声音完成全部意思。适合角色短片、氛围片、跨语言传播。条件：代表帧测试（第 6.3 节）在无字状态下仍要通过。

**用户明确要求的文字**优先于本章任何取向——那是需求，不是风格选择；取向只决定它怎么放。

**情绪不上字**：写着情绪名字的字、角色举着写有心情的牌子，是失败的镜头（N6）。

### 15.4 故意违反、失败点、自检
- 故意违反：文字与画面说相反的话（画面里一片混乱，字幕写"一切正常"）。得到反讽，适合讽刺与黑色幽默。观众必须同时看懂两者，所以两者都要极简单。
- 失败：给看不懂的视觉加说明文字，反而更糟（真正该修的是视觉）；每个情绪配字幕标签；讲解片完全去字，静音观众无从理解；按钮被画框切半；全片一个小角色在空旷大景里而没有理由。提前发现：每镜标出"必须读清的最小细节"并量它的高度；静音看一遍。
- 自检：最小必读细节的高度 ≥ H/40 吗？去掉全部文字，代表帧测试还能过吗（无字取向必须过，其余取向记录结果）？每处文字说的，是不是口播同时在说的那件事？

## 第 16 章 讲解：解释语法、证据拍法、口播对齐、术语（Q30、Q31、Q29、Q33）

### 16.1 推导
不同的解释任务需要不同的工具（N1：观众要追踪的"变化"类型不同）。截图承担界面证据，图示承担关系，照片承担对象或情境，三者不可互相冒充——冒充会损失可信度（N4：观众凭真实物判断真假）。口播语义直接映射为镜头动作时，视线被语言和画面同时引导；错位则两个通道互相打架（N2）。

### 16.2 解释语法：按内容关系选（Q30）
先判断这一段在讲哪种关系，再选画法。以下是关系 → 可选画法 → 易误导做法；每种关系都给了不止一种画法，风格词汇库条目仅作可选外观参考。

| 关系 | 可选画法 | 易误导做法 |
|---|---|---|
| 步骤 | 一条路径上依次点亮；同一物经历多个状态；手在做 | 把并行步骤画成串行 |
| 因果、分支 | 一物推动另一物；分岔路径；前后对照 | 把相关画成因果（相关只能并排放） |
| 对比 | 并排同尺度；同一画面的切换；叠在一起看差 | 两边换尺度或换基线 |
| 数量比例 | 尺寸、计数、填充量（S69、S70 是可能外观） | 无数据却画统计图；只有一个数也画图表（一个数用文字或一个尺度物即可） |
| 状态变化 | 同一构图前后两态；连续变形（S59） | 用动效造出产品做不到的结果 |
| 故事情绪 | 角色、场景、物的表演 | 用轻浮的画风讲严肃新闻，冲淡可信度 |

**混用**：全片可以用几种语法，由内容的关系类型数决定，不定上限；但**同一段内只用一种**，否则观众要同时学两套读法（N2）。跨语法切换时，用一个承接物（第 13 章）把两种画法连起来——例如步骤路径上的一个节点放大，变成对比画面的一边。「待实验验证」

**先结构、后数据、最后标注；一镜只标一件事。**

### 16.3 证据与实拍素材怎么"拍"（Q31）
有真实素材时，素材就是主画面；代码画的"像截图的东西"会削弱可信度。贴在屏幕上不动的截图读作贴图。拍法从**口播在指向什么**推出，而不是从一张固定的招式表里挑：
- 口播在说**整体**（"这一页""这份文件"）→ 让观众看见边界：从近景拉出到能看见整页，或整页同时在场。
- 口播在说**某一处**（"注意这个数""就是这句"）→ 先让视线到达（推近或标注），再停住一个 R，再标注。滚动、停留、标注按这个顺序，不同时。
- 口播在说**几处**（"这页有好几个问题"）→ 依次到达每一处，每处一个 R；处数多到超过工作记忆时，分成两镜。
- 口播**只是停着讲** → 素材静止，相机不动（或用第 10.3 的极缓呼吸）。
- 素材**本身在动**（录像、操作录屏）→ 相机让位，不再叠加运动。

**标注钉在内容坐标上**：页面滚动时标注跟着内容走，不跟屏幕；标注位置从素材实测，不目测。标注不偏到别的元素上。

**素材满幅时的替代动作**：横移到下一件、同景别硬切到下一件、多件素材摆在同一空间里由相机巡视（风格词汇库 S73 调查桌、S74 档案推进是可能外观）。

**两种重建取向**（「分歧·待实验」，分歧维度是是否需要深推近与多语言）：用真实截图（最可信，推近时分辨率受限）；按参考像素重建界面（可无限推近、可换语言，可信度依赖重建精度，且不得复制他人品牌身份）。

**如实申报**：找不到素材时，标为"未完成项"，不包装成"极简风格不用素材"。

### 16.4 口播与画面对齐到字（Q29）
- **锚在词上**：画面事件写成"第几句第几个词 ± 偏移"，而不是秒。换配音、换语言，只重读词时间（第 5.4 节）。
- **流程顺序**：配音修剪完成 → 再做词级时间戳 → 之后不再动音频。稿子是真值：识别结果与稿子不一致处（同音字、数字写法、品牌名），以稿子为准修正时间戳，宁可漏剪口水词，不可剪错一个字。
- **落点窗口**：画面落点落在词起点前约 4 帧（约 0.13s）到词起点后 1 帧之间。推导：视听同步感知不对称——声音领先画面更容易被察觉，画面略早于声音（声音"晚到"）宽容得多；所以窗口向前开、向后几乎不开。前沿取约半个发现时间 F：画面早到这么多，观众的视线正好在词出口时抵达落点。偏差超过约 0.25s（一个 F）开始被察觉为错位。「弱证据，待实验」
- **机器对账**：自动比较每个锚点的画面落点与词时间，列出超窗的锚点；手敲秒数的误差在静帧检查里看不出来。
- **多语言**：画面锚在"意思对应的词"上，而不是句首；同一工程按语言读取不同的词时间，不复制工程。语序差异让画面顺序必须改变时，这一段按该语言单独排。
- **句间呼吸**：由口播本身的实测停顿决定，不为凑时长人为拉开句子。

### 16.5 术语（Q33，「弱证据，待实验」：单家孤证）
- **直觉后点名**（推自 N4）：先用白话建立直觉，在直觉刚落地时说出标准术语，并同时上屏停留一个 R。术语附着在已理解的概念上，观众事后能搜到、能转述。
- **点名先行**（推自 N3）：面向半专业受众，先抛出术语制造"这是什么"的悬念，再用白话拆开。
- **全白话**：面向完全外行的娱乐片，可以不点名；但片尾至少给一次名字，否则"讲清楚了却找不回来"。
- 中文语境中英术语并列时，上屏写中文 + 原文，口播只说一种。「待实验验证」

### 16.6 故意违反、失败点、自检
- 故意违反：口播与画面刻意对位（口播讲 A，画面讲与 A 平行的 B），让观众自己连接两者。得到隐喻、散文感，适合观点片、影像散文。只用在观众已理解主线之后。
- 失败：念到一个名词就推一次（给口播配节拍器）；所有段落同一种画法或每镜换一种；标注圈偏；页面滚了标注没动；时间戳后又剪音频导致全体错位。提前发现：机器对账；每段标出关系类型与所选语法。
- 自检：每段的关系类型与语法写得出吗？超出落点窗口的锚点数 = ?（应为 0）全片有几处"代码画的像截图的东西"可以换成真实素材？

## 第 17 章 表演：角色与界面（Q34、Q35）

### 17.1 推导
观众通过另一个身体的反应确认情绪（N6）。情绪变化本身是一个动作，有预备、换形、反应和落定；几个通道（脸、颜色、动作方式、反应大小）一起变，情绪才可读。代码的默认是所有部件同时、同曲线、同幅度运动，这正是机械感的来源——错相与主次给出生命（N5：观众在追踪一个"活的"整体，各部位的时间差证明它是一个有内部结构的身体）。粗糙的角色比没有角色更差，观众第一眼就会把它归类为生成内容。

### 17.2 角色出不出现、出不出脸（Q34，「分歧·待实验」）
- **完整表演角色**（推自 N6）：有脸、有身体、有情绪弧。条件：精细度够得上表演——表情能在一个 R 内被认出，动作有预备与落定。适合故事片、喜剧。
- **局部角色**（推自 N6、N4）：只出现手、背影、影子或剪影。观众把自己代入，精细度要求大幅下降。适合产品、讲解、"你"作为主语的叙事。
- **物即角色**（推自 N6、N1）：一个物有了意图和反应（犹豫、退缩、跃跃欲试），但不长脸——表演全部通过运动方式（速度、停顿、重心）完成。模型平时不会默认这样做（它会给物加脸）。适合抽象概念、品牌、需要避开"吉祥物"感的题材。
- **无角色**：主体是物、空间或系统，第 3.3 节。

### 17.3 表演的做法
- **情绪切换是一个动作**：预备（离开当前情绪的一个小动作）→ 换形（最好在一个遮挡或一次快速动作之中完成，观众看不见"换脸"的那一帧）→ 反应 → 落定（新情绪稳定下来，停一个 R）。一帧瞬切读作换贴图。
- **注意 → 想 → 做**：眼睛（或物的"朝向"）先到目标，身体随后启动。领先量随角色的运动尺度定：大约等于该角色一次头部转动所用时间的一半——眼先动、头跟上、身体最后，三者错开而不是同时。「弱证据，待实验」
- **错相**：左右肢不镜像；群体角色不同步，各自有起始时间和幅度的差异。
- **夸张度**：短片里微妙等于没有。判据：缩到手机小窗里，表情变化是否仍可辨认。
- **画不到位时**：退到局部角色或物即角色，不要用粗糙的完整角色硬撑。
- **反应停留**：反应是情绪被确认的地方（第 3.6 节），比事件本身停得更久。

### 17.4 界面演示（Q35，「弱证据，待实验」：单家为主）
- **故事形状由被看重的价值决定**：
  - 价值是**手感**（流畅、快、顺）→ 少拍、一个连续操作、收益在操作结束的那一刻。
  - 价值是**流程**（一件事从头做到尾）→ 多拍、每一步产出下一步要用的东西，作为镜头承接（第 13 章）。
  - 价值是**后果**（操作在别处产生了结果）→ 操作一拍，然后切到"别处"看见后果（第 8.3 节无操作者变化的反向）。
- **光标是一个人的意图**：每次移动都有目标；移动前后有短暂停靠（人会看一眼再动）；类型随悬停元素切换（箭头、手、文本）；永远不盖住它要点的文字；拍与拍之间停在不遮挡下一个目标的地方。
- **附属元素**（通知、提示、结果卡）在它兑现的那一拍带着内容到达，不提前空着出现。
- **平台惯例**是识别的锚点：系统级的界面元素按观众熟悉的样子画，偏离被读作"假"。演示他人产品时**只借交互、不借身份**——不使用对方的商标、品牌色与标志性外观。
- 一次只追一条因果：同一流程不完整播放两遍；不为讲更多而塞进第二台设备。

### 17.5 故意违反、失败点、自检
- 故意违反：角色完全不反应——世界在他周围崩塌，他面无表情。得到冷幽默、荒诞、疏离，适合讽刺与黑色喜剧。前提是观众已经知道"正常人会怎么反应"。
- 失败：表情一帧瞬切；双臂镜像、群体同步；通用的圆头吉祥物讲解员；角色举牌写情绪；光标盖住按钮文字；自创配色的"仿某应用"。提前发现：逐帧检查情绪切换处有无预备与遮挡；把光标路径单独画出来，检查每段移动的目标。
- 自检：每次情绪切换能指出预备、换形、反应、落定四段吗？缩到小窗里表情可辨吗？每次光标移动的目标是什么？

## 第 18 章 补缺：原料没有回答的问题（全章「待实验验证」）

### 18.1 骨架知识缺口
- **C1 无故事片靠什么维持注意（Q1、Q15）**：用"缓慢的单调变化"替代事件——一个可见量（亮度、密度、颜色温度、相机距离）全片朝一个方向走，观众的预测（N3）对象从"接下来发生什么"换成"它会走到哪"。另加稀疏的"微事件"（一只鸟飞过、一盏灯亮起），间隔不均匀。纯氛围镜头在叙事片中的占比，起点取不超过镜头数的 1/5，与第 5 章重定位预算同理：超过就不再是"呼吸"，而成为片子的主体。
- **C2 氛围片要不要峰值（Q3）**：要一个"转向点"而不要峰值——单调变化在某处改变方向或速度（越来越亮之后开始暗），观众感到"到了"，但没有冲击。
- **C3 峰值位置与划走（Q3、Q6）**：做法：同一支片做后置峰与前置峰两个版本，比较平台留存曲线在峰值前后的斜率。
- **C4 笑点密度与反转前停顿（Q2）**：停顿起点取第 4.3 节转折空隙的同一公式（上一段平均事件间隔 × 2），因为反转就是一次小转折。
- **C5 口播转折句与切点先后（Q4）**：两种都试——切点在转折词之前（画面先转，口播追上来）与之后（第 4.3 节的叙述句承担），比较首看测试里观众复述论证的准确率。
- **C6 阅读公式校准（Q10）**：用第 9.1 节的首看暂停测试校准 F、U、W 三个系数，每类内容（文字、图像、数字）分别校准。
- **C7 节奏可感阈值（Q11）**：做同一内容的三个版本，镜长档位比分别为 1.2、1.4、2，盲评哪个"有节奏"。
- **C8 真静止与极缓呼吸对照（Q12）**：同一口播片做两版，评审不知道差别，比较"像幻灯片"与"发抖"两类评语的出现率。
- **C9 轮换频率与片长（Q13）、病因权重（Q14）**：每修复一个病因就重评一次，记录哪一项的修复让评级提升最多。
- **C10 横竖屏与小窗的预算（Q16、Q27）**：竖屏与小窗里不改组数上限，而是按第 15.2 节把每组的最小必读细节重算一遍（竖屏按画面宽算）；放不下的组合并或分到下一镜。
- **C11 进场时机分布（Q17）**：一镜内的事件偏前放（开镜后尽早开始），给出点保护留出空间；与之对照的偏后放用于悬念镜头。
- **C12 承接的自动判定（Q19）**：以"边界前后两帧，无关观看者能否指出同一个东西"作为人工真值，用来校正任何自动判定。
- **C13 转场种类耐受度（Q20）、一镜到底时长（Q21）、运镜疲劳（Q23）**：都用同一方法：做递增版本，找评审评语从"流畅"转为"累"的拐点。
- **C14 二维动效中的越轴（Q22）**：二维画面里，主体的运动方向就是"轴"；连续两镜方向相反且没有转身动作，视为越轴。
- **C15 手持强度与片种（Q24）、卡拍间隔（Q25）**：手持幅度以最小文字字高为上限，按片种逐档下调到 0；大冲击的间隔不短于一个乐句。
- **C16 主轴切换的代价（Q28）**：比较有交接点与无交接点两种切换的首看复述准确率。
- **C17 词落点容差（Q29）**：做落点偏移 0、±0.1、±0.2、±0.3s 的版本，测观众能否察觉。
- **C18 语法目录与切换（Q30）**：目录按关系类型开放增长；每新增一种关系，必须同时写出它的易误导做法。
- **C19 素材授权受限（Q31）**：降级顺序：自己拍摄的实物 → 有授权的素材 → 按事实重建并明示"示意" → 只用文字转述并标出处类型。每降一级，在片中如实标注。
- **C20 有字无字理解率（Q32）、术语密度（Q33）**：同一内容有字/无字两版，测静音与有声两种观看下的复述率。
- **C21 角色精细度阈值（Q34）**：判据是小窗里的表情可辨性；达不到就退到局部角色。
- **C22 借交互不借身份（Q35）**：保留交互的结构（点击、滑动、弹出的顺序与因果），换掉视觉身份（颜色、图标、字形、布局特征）。
- **C23 自主模式谁确认（Q36）**：第 1.6 节的盲读复述。
- **C24 结构复用的抄袭边界（Q38）**：第 2.4 节的"物 + 动作"互换判据。
- **C25 差异度量化（Q39）**：用第 1.2 节的对立轴：两支片在多少条轴上选了不同的一端。
- **C26 代表帧与封面（Q7）、结尾停留与完播（Q8）、叙事与氛围循环接缝（Q9）**：分别见第 6.3、7.2、7.3 节的推演。

### 18.2 原料整体没覆盖的问题
- **D1 情节类型的多样性**：除欲望驱动与笑点外，至少还有：**散文式**（一个问题被几个不相关的画面轮流照亮，状态差在观众的理解里）；**纪录式**（时间顺序 + 真实素材，状态差是事实本身）；**蒙太奇论证**（并置两个画面让观众推出第三个意思，N3 的推理快感）；**悬疑式**（信息分批释放，每批改变观众对前一批的理解）；**清单式**（同构的几项依次出现，节奏来自项与项的差异，见第 3.5 节）。每种都过第 3.1 节的首末帧判据，只是"变了什么"可以在观众脑中。
- **D2 声画对位与反差**：画面与声音刻意不一致——欢快的音乐配灾难、平静的旁白配混乱。原理是 N3 的双通道版本：两条通道各自建立预期并互相否定，观众被迫产生第三种解读。条件：两条通道都必须各自清楚，否则只像配错了。
- **D3 真人出镜**：口播者的视线是最强的视线引导（N2）——看镜头时观众看他，看向画面某处时观众跟着看过去。可用这一点代替标注：让出镜者转头看向素材。景别按信息分工：讲观点用近景（脸是信息），演示用中景（手是信息）。手势与关键词同步，规则同第 16.4 节。
- **D4 景别体系**：景别是"观众离事件多近"，按第 14.1 节的动机用：要看清 → 近；要看关系 → 远；要建立空间 → 全。相邻两镜景别跳一档以上读作"跳"，跳不到一档读作"抖"（几乎一样的两个景别相接最难看）。这是第 12 章轮换在景别上的应用。
- **D5 悬念与信息差**：观众知道而角色不知道 → 紧张（观众在等角色发现）；角色知道而观众不知道 → 好奇（观众在等揭示）。前者的设计是先给观众看危险，再看角色毫不知情；后者是让角色对画外某物反应，但不给观众看。
- **D6 系列化叙事**：在同一账号的多支片之间保留一个**识别母题**（一个开场的动作、一个反复出现的物），同时按第 1.9 节的差异检查保证每支片的结构不同。母题是"同"的部分，结构是"异"的部分，二者分开。
- **D7 竖屏叙事**：见第 15.2 节；另外竖屏的视线天然自上而下扫，因果可以写成上因下果，叙事方向是纵向的。
- **D8 中文语境**：中文的信息密度高（同样时长装更多意思），第 9.1 节的 U 系数应单独校准；中文笑点大量依赖谐音与字面，画面可以用"字面化"（把一个词的字面意思画出来）作为一种解释语法。
- **D9 平台数据**：书中所有关于开场、片长、节奏的起点值都应在积累播放数据后回填。记录方式：每支片记下它在本书各章选了哪个取向，与留存曲线一起存档，累积到同一取向有多支片后再比较。
