# 镜头与叙事

> 版本说明：r5，2026-11-19，按 r5 修订清单定点修订（S 6 / E 5 / R 2 / M 9 / U 11，处理结果见书末「r5 修订记录」）；r4 版存于 `archive/book-before-r5.md`，更早的 r3 版存于 `archive/book-before-r4.md`。

一本从原理出发的镜头与叙事手册。书里的数值都是我定的起点，每个都写了推导；改它要改推导，不是改数。命中禁用清单的值，"非它不可"的理由统一放在附录。

**单位**：时间用秒（s），需要帧时按 30fps 换算，换帧率按秒重算。画幅参考横屏 1920×1080、竖屏 1080×1920；尺寸写成画面高 H 或宽 W 的分数，不写死像素。

**怎么读**：每章开头标出覆盖的 Q 编号，每个取向标出"推自"哪条原理。书里没有默认取向：创作时先按内容放开几个方向，再写明理由收拢到一个。风格方向只作为可选项引用风格词汇库的条目编号（如 S73），不代表推荐。自检里标「〔测〕」的条目是可以用数字或脚本判定的执行指标。

**标记**：「弱证据，待实验」= 依据只有单家或无对照；「分歧·待实验」= 骨架标为各家分歧，书里两端并列，不裁决；「待实验验证」= 我的推演，原料没有回答。

**术语**
- **事件**：一镜首帧与末帧之间，能用"某物 + 做了什么"一句话说出的状态差。
- **注视 t**：一次注视连同跳到它的那次眼跳，约 0.25s。书中凡是"停一下""看一眼"都换算成注视数。
- **读取时长 R**：观众第一次看、全速、可能静音时，读完一件事所需的时间，按注视数计（第 9.1 节给算法）。
- **承接物**：跨过镜头或段落边界继续存在、并在边界后换了角色的东西。
- **主轴**：一段片子的时间由谁驱动（第 5.3 节）。
- **代表帧**：只被看到一帧时，应该被看到的那一帧（第 6.3 节）。
- **重音**：全片里被刻意加重的少数时刻（转折、峰值、招牌运镜）。

## 〇、六条第一性原理

**N1 状态差律（事件）**：注意和记忆只登记"变化了的东西"，并且按"主体 + 变化"打包存储。一支片被记住的单位不是画面，而是"什么变成了什么"。没有状态差的段落，在记忆里等于不存在。
→ 推出：最小故事、每镜必须有事件、结尾要和开头不同、代表帧要能说出发生了什么。

**N2 串行律（单焦点注意）**：视觉注意一次只能落在一个地方，同时发生的两件事只会被看到一件，另一件要么被错过，要么被读成噪声。工作记忆一次只装得下少数几个块，听觉语言和画面文字争用同一份语言通道。
→ 推出：一镜一个焦点、因果按顺序排、错峰、文字与口播不同时说两件事、镜内预算。

**N3 预期律**：观众每时每刻都在预测下一刻。结构的全部手段就是建立预期，再兑现、推迟或打破。可预测的重复会降级成背景（节拍器）；稀缺的东西因为出乎预期而有重量。
→ 推出：峰值只花一次、转折、重音稀缺、运镜与转场有预算、笑点结构、长短悬殊的节奏。

**N4 作者盲区律（读取延迟）**：作者知道下一步，观众不知道。观众只看一次、全速、常常静音、随时能离开，读取速度系统性地慢于作者的估计。凡是"我觉得够了"的时长，都要换成按观众读取算出来、并能测量的时长。
→ 推出：镜头时长由读取量决定、开场必须静音自洽、代表帧、按实测音频排时间、机器对账。

**N5 同一性律（连续）**：大脑持续追踪"同一个东西"。一个东西在变，被读成一件连续的事；一个东西被换掉，被读成翻页，并且要付出重新定位空间的成本。方向、位置、速度的连贯让追踪不断线。
→ 推出：承接物、转场、一镜到底、屏幕方向、循环接缝、"像幻灯片"的承接病因。

**N6 具身情绪律**：情绪不是被"告知"的，而是被身体性的关系触发：距离远近、尺度大小、光的多少、速度快慢、被包围还是被留下；以及看到另一个人（或物）的反应。写着情绪名字的字，触发的是阅读，不是情绪。
→ 推出：反应要停留、运镜表达情绪、可见量承载情绪弧、画面承载意思而文字只做补充、角色表演。

六条之间的张力是本书大多数分歧的来源：N3 要稀缺和落差，N4 要慢和清楚；N5 要连续，N3 又要意外。每章的取向，本质上是在这几对张力之间选不同的位置。

### 两条外部前提（公开规范与研究结论，全书引用同一处）

**E1 视听同步的不对称**：同一事件的声音早于画面，比声音晚于画面更容易被察觉。广播电视的公开测试结论（ITU-R BT.1359）给出的可察觉门限约为：声音领先约 45ms、声音落后约 125ms。换算到 30fps：声音领先超过约 1.35 帧、落后超过约 3.75 帧就可能被察觉。
→ 推出：凡要"同一时刻"的声画，画面可以略早、只能晚得很少（第 16.4 节落点窗口：扣掉抖动余量后，30fps 下不能晚，60fps 下最多晚 1 帧）；凡要"声音先来"的设计，领先量必须大到被读成一个独立的先行事件，不能落在"像没对齐"的区间里（第 4.3 节）。

**E2 光敏安全底线（WCAG 2.3.1）**：依据是 `reference/WCAG-2.3.1-闪烁阈值.md`（WCAG 2.2 原文摘录）。下面是本书执行用的写法，全书其他章节只引用这里，不各自重述。

- **通过条件（满足任一即通过）**：任意 1 秒内一般闪烁不多于 3 次、且红色闪烁不多于 3 次；**或者**同时发生的闪烁在任意 10° 视野内合计面积不超过 0.006 球面度（这个视野的 25%）。
- **一次闪烁 = 一对方向相反的变化**：一般闪烁是一对相反的相对亮度变化（先升后降或先降后升），每次变化幅度 ≥ 0.1（最大相对亮度 1.0 的 10%），并且这一对里**较暗的那一帧**相对亮度 < 0.80——条件对整对变化成立，不是只加在下降那一次上；两侧都 ≥ 0.80 的亮—更亮变化不算。相对亮度按 WCAG 2.x 公式：sRGB 分量先线性化，再按 0.2126R + 0.7152G + 0.0722B 加权。
- **硬切怎么数**：一次明→暗硬切只是**一次变化**，明→暗→明才是一次闪烁。变化按时间顺序两两配对、**不重叠**，一次变化只能用在一对里（6 次变化 = 3 次闪烁，不是 5 次）。只想粗估时可以"每个高对比硬切记一次"，但要注明这是比原文严一倍的偏严估算。
- **计数窗口（全书唯一口径）**：任意 1 秒的滑动窗口，帧号取**半开区间 [k, k+fps)**；一次闪烁归到它第二次变化所在的帧（完成帧）。别的章节说"任意 1 秒"都指这个窗口。
- **计数对象**：按像素或按小网格各自计数，再看同时闪烁的面积；不把全帧所有像素的变化累加成一个数。
- **红色闪烁**：任何涉及饱和红的一对相反变化都算，与亮度幅度无关，**单独计数**、单独对照"1 秒不多于 3 次"。"饱和红"的判据原文摘录里没有，本书取自 WCAG 2.2 理解文档（Understanding 2.3.1）的注释，那条注释的判据有两半：这一对变化中，有一次变化的起点或终点状态满足 R/(R+G+B) ≥ 0.8，**并且**两个状态在 CIE 1976 UCS 色度图上的距离（Δu′v′）> 0.2。本书一律用**线性化后的分量**算 R/(R+G+B)（同一颜色比按 8 位原值算出的比例更高，更容易判成饱和红，偏严）；纯黑没有色度，按 D65 白点处理。
- **细密均衡图案例外**：白噪声、方格边长小于 0.1° 的交替棋盘这类细密、均衡的图案闪动，不算违规。逐像素或逐网格扫描时要先排除这类区域，否则颗粒、噪点、细纹理会被误报成大面积闪烁。本书的判定（是本书的实现，不是规范原文）：某格在相邻两帧里格内亮度极差都 ≥ 0.1（格里有比 0.1° 更细的结构），且以它为中心 1° 见方邻域的平均亮度变化 < 0.1（明暗均衡），这一帧的变化不计。
- **面积换算**（本书推导，假设写在这里；脚本和结果见附录"r5 光敏复算"）：10° 视野是圆锥视场，立体角 2π(1 − cos 5°) ≈ 0.0239 sr，25% ≈ 0.0060 sr，与原文 0.006 一致；不得把 10° 视野当成 10°×10° 正方形再取 25%（≈ 0.0076 sr，宽约 27%，r4 就错在这里）。屏上面积 ≈ 0.006 × 观看距离²，再按像素密度折算：

## 第 1 章 动手之前：放开方向、写阐述（Q39、Q36）

### 1.1 推导：为什么先放开
第一反应是最常被选过的那个反应，模型尤其如此（N3：观众对"见过的"不再分配注意）。看了示例再动手，继承的不是表面，是底盘：什么时候转、靠什么转、在哪种画面上结束。所以顺序是：**先写出自己的方向 → 再看任何标杆 → 再收拢**。

### 1.2 放开方向的办法：按观众在哪一层认出"又是那一套"
观众说"又是那一套"，是在某一层上认出了熟悉的东西（N3：可预测的东西降级成背景）。认出的层有四种：**物**（看见的是什么、最后变成了什么）、**序**（事情按什么规则展开）、**调**（谁在对谁说、用什么姿态）、**形**（外观和运动的手法）。第一念头在每一层上都落在最常见的那个值上，所以放开方向就是在至少一层上离开它。办法按"它在哪一层上起作用"分：
- **形层：禁掉第一念头最依赖的那件工具**（模型平时不会默认这样做；推自 N3）：先看第一念头靠什么手法成立（大字、快剪、一个转场、一种颜色），就禁掉那一件，不从固定的禁止项清单里抽。禁掉之后写不出方案，说明内容对这件工具是真依赖——那是内容的骨头，留下；写得出，第一念头在形层上就被推开了。
- **物层：先定几个不同的终态**（推自 N1、N4）：观众记住的是"什么变成了什么"（N1），认出雷同也最先在终态上认出。所以先写几个彼此不同的终态（片子最后一刻，什么东西处在什么状态），每个终态反推"观众之前必须看见什么"，长出不同的片；第一念头的终态是要避开的那个。写不出终态，想法还没落到画面上。
- **序层：换一条展开的规则**（推自 N3、N5）：观众的"又是那一套"是分品类的——在一个品类里用滥的展开方式，在另一个品类里没人见过。从受众不重叠的品类里找一条"东西在其中怎么展开"的规则（例如：每一步都留下可见的残局、所有东西只许按大小顺序出场），只搬规则，不搬场景顺序和外观（风格词汇库 S86 是一条找法，不是唯一）。这一招放在其他办法之后，免得先被别人的外观定了调。
- **调层：换一个具体的看的人**（推自 N4、N6）：同一件事，对一个第一次听说的中学生、一个天天用它的老手、一个讨厌它的人，该先给什么、用什么口气都不同。为一个具体的人写，调就跟着变。
- **全层：把第一念头拆开逐层推远**（推自 N3）：老实写出第一念头，拆成"谁 / 在哪 / 怎么变 / 怎么收"，逐个换成反面或远处的东西。第一念头不扔，它是坐标原点，用来量其余候选离开了多远。
- **不定层：先从外部随机源抽一个方向**（「待实验」，按 2026-11-19 用户裁决与其他办法并列，不是必做步骤）：用随机源（随机抽一个风格词汇库条目、一个品类、一个物）先定一个方向，再判断它和内容合不合。它绕开了"第一念头"本身，代价是很多抽到的方向要被丢掉。

| r4 办法 | r5 新轴里的位置 | 变化 |
|---|---|---|
| 拿掉一件工具（抽禁止项） | 形层：禁掉第一念头最依赖的那件工具 | 禁什么由第一念头推出，不再从固定清单抽 |
| 先画终帧 | 物层：先定几个不同的终态 | 理由改为"雷同最先在终态上被认出"，不再从代表帧倒推 |
| 借别的行当的规则 | 序层：换一条展开的规则 | 理由改为"雷同感分品类"，只搬展开规则 |
| 换一个具体的看的人 | 调层 | 保留，归到调层 |
| 把第一念头写下来再拆反 | 全层 | 保留，作为量距离的原点 |
| （无） | 不定层：外部随机抽方向 | 按用户裁决并列，「待实验」 |

**什么时候停**：每个候选写成一行"开场看见 X → 最后看见 Y"。停止信号是饱和：最近写出的三个候选，每一个的 X 或 Y 都和更早的某个候选是同一个物。推导：饱和说明这一轮的想象已经绕回自己，再写只是换词；数量是结果，不是目标。

### 1.3 和上一支片比：比什么、差多少算够
同质化是观众的感受，所以比较维度不从"片子有哪些属性"推，而从"观众看完一次后脑子里留下了什么"推（N1、N4）：
- 留下的是一句复述（什么变成了什么）、一两张画面、一个"它在什么时候变了"的时间感。比较就比这三样。
- **复述重合测试**：请没参与制作的人（或一个只看成片、不看制作过程的 agent）分别看两支片，各写 30 字以内的复述。数两段复述里共有的实词（名词、动词）。共有实词 ÷ 较短一段的实词数 > 1/3，判为"同一个片子"。
- **画面错认测试**：把两支片各取 5 张等距截帧，打乱后请人分成两堆。分错 ≥ 2 张，说明画面层面难以区分。
- **时间感对比**：两支片"最大变化发生在片长的哪一处"，换算成片长百分比；两者相差 < 15 个百分点、且最大变化靠的是同一种手段，记为结构继承的警告。
- 三项里命中两项，退回重新放开。「待实验验证」

### 1.4 阐述要写到什么颗粒度（Q36）
先问两件事：**需求方要判断什么**——这是不是我要的、我会看到什么、哪里可能出问题、要多久；**实现者还缺什么**——每一刻画面上有什么、它在什么时候怎么变、什么是不允许发生的、做完怎么知道对了。阐述就是把这两张清单答完，其余都可以省（N4：作者以为清楚的，写下来才暴露不清楚）。

四种写法，可以组合：
- **两页式**（推自 N4）：第一页给需求方——一句话说"看完的人带走什么"、三张关键画面的文字描述或草图、一个最大的风险、一条"这支片不做什么"。第二页给实现者——每一刻一行：**何时**（挂在哪个词、哪一拍或哪个上一事件之后，不写绝对秒）｜**画面上有什么**（名词）｜**它怎么变**（动词 + 终态）｜**不许发生什么**｜**验收看哪一帧**。写不出名词和终态的行，说明这一刻还停在概念上。
- **灰盒样片**（推自 N4、N1）：不写字，直接做一支灰色方块的粗样（只有位置、大小、时机，没有外观），给需求方看。适合需求方对文字不敏感、对时间敏感的情况。代价：灰盒会让需求方低估最终外观的作用，要事先说明。
- **是非题清单**（推自 N4）：把需要需求方拍板的地方写成一串是非题："开场没有标题，可以吗？""全片不出现人脸，可以吗？"每题一个答案，答案就是阐述。适合需求方时间很少的场合。
- **先给一个错的版本**（模型平时不会默认；推自 N3）：故意先给需求方看一个方向明确偏到一端的极端草案（例如全片无字），用他的反应校准"他要的在哪儿"。代价是一轮沟通，适合需求方说不清自己要什么的时候。

**哪些全局决定要提前定**：不预设清单。对每一个候选的全局决定问一句："如果做到一半再改它，要重做几个镜头？"会波及两个以上镜头的，在写逐行之前定下来；只影响一个镜头的，留到那一行再定。推导：提前锁定的代价是限制，推迟的代价是返工，用返工面积来裁决，比按经验列一张"必锁项"更贴合每支片。

**自主模式**（无需求方）：让一个没看过制作过程的 agent 只读阐述，复述"这支片讲了什么、哪里转、怎么结束"。复述与作者原意不一致之处，就是阐述的漏洞。「待实验验证」

### 1.5 故意违反
不写阐述、先做后写：直接拿素材即兴排，做完再倒写阐述。得到"发现式"的松弛和意外，适合氛围片、纯形式片、素材本身强到会自己说话的纪实片。代价是返工高，必须在做完后补写阐述并照它检查一遍。

### 1.6 失败点预判
- 阐述只有形容词（"高级、有张力"）。提前发现：把阐述里的形容词全删掉，看剩下的部分还能不能拍。
- 候选方向只是同一套画面讲不同故事。提前发现：把候选的"开场看见 X → 最后看见 Y"并排，X、Y 是否反复是同一个物。
- 先看了示例，结构被继承。提前发现：跑第 1.3 节的三项测试。

### 1.7 自检
- 〔测〕删掉全部形容词后，第二页里写得出名词和终态的行数 ÷ 总行数 = ?（应为 1）
- 〔测〕与上一支片的复述重合率 = ?（应 ≤ 1/3）；画面错认张数 = ?（应 ≤ 1）
- 被杀掉的方向，各自死于什么理由？

## 第 2 章 有参考片时：复刻、学手法，还是只借形（Q38）

### 2.1 推导：凭印象读不出什么
看一遍参考片，留下的是印象：气氛、颜色、"挺快的"。印象擅长质地，不擅长分布（N4 作用在看片的人自己身上：他也只看一次、全速）。凭印象最读不出的有四类，只有这四类需要测：
- **时间分布**：每段多长、事情发生在一镜的前部还是后部、长短段怎么排。印象只记得"快"，记不得"哪里快"。
- **小于一次注视的事**：快于约 0.25s 的变化、几帧的闪、切点前后的几帧。肉眼一次看不清，只能逐帧。
- **声画相对时刻**：声音比画面早还是晚、早多少（E1 说这个量级正好在察觉边缘）。
- **占比**：多少时间是静止的、多少镜是文字主导的、相机动的时间占多少。印象会被最醒目的几镜带偏。
颜色、质感、构图这些印象读得出的东西，截几张帧对照就够，不必系统测量。

**怎么测**（四种取向共用）：切点用场景切换检测找，不按固定间隔抽帧；每镜记长度、事件发生的时刻占该镜的比例；对声轨标出强音位置，算它与最近切点或画面事件的差；逐帧画面差分得到"动的量"随时间的曲线，从中读出静止占比与最长静止段。

骨架标此处为分歧，分歧维度是作品目的；下面按目的分四种，不裁决。「分歧·待实验」

### 2.2 取向一：复刻（目的是展示复刻能力；推自 N4）
- 拿走全部层：时间、构图、运动、外观。唯一的验收依据是并排测量，不看印象。
- **位置容差**：叠化后的差异图里，任何边缘的错位 ≤ 参考片自身在静止处的抖动量与 1 个参考像素中较大者。推导：参考片本身有压缩与缩放带来的抖动，比它更严的要求无法被验证。
- **切点容差**（重新推导，见附录 C1）：切点的感知意义在于"段长"和"与声音的关系"，所以分两项验收，不验绝对帧号：
  - 段长：每段长度与参考的差 **≤ 1 帧**（各段一律）。推导：复刻的验收靠并排测量而不是观众感觉，容差应取测量与渲染能表达的最小单位，即 1 帧。r4 另加的"且 ≤ 段长 10%"（时长辨别韦伯分数的下沿）不起作用：段长 ≥ 10 帧时 10% ≥ 1 帧，比 1 帧宽；段长 < 10 帧时 10% < 1 帧，按字面等于不允许任何偏差，附录又改回 1 帧——它在任何段长下都没有收紧要求，已删除（逐段长复算见附录"r5 计算复核"E-4）。感知上的 10% 只在"学手法"取向里有意义，那里不比段长。
  - 与声音的关系：若共用节拍或口播，切点相对声音事件的偏差落在 E1 的不察觉区间：可早不超过 2 帧、不可晚（30fps）。
  - 整体平移（所有切点一起早或晚同一个量）不扣分，它只是起点不同。
- 两片帧率不同时，先把两边的切点都换成秒再比，不比帧号。
- 诚实边界：不复用原片的音乐、人声、真人影像；不暗示合作关系。

### 2.3 取向二：学手法（目的是学一种可迁移的做法；推自 N3、N5）
- 拿走的是**规则层**：这个手法解决了什么问题、靠什么起作用。不拿画面，不拿数值。
- 记录方式：每条写"现象（测到的）→ 我猜它在解决什么 → 换一个完全不同的题材时它还成立吗"。最后一栏答不出的，说明还没拆到规则，只拆到了画面。
- 验收：把这条规则用在一个与参考毫不相干的小题材上做一段，规则在那里也起作用，才算学到。

### 2.4 取向三：原创借形（目的是做原创片；推自 N3、N5）
- 节拍来自我们自己的概念：先把自己的阐述写完（第 1 章），再从测量结果里挑能装进去的东西，只拿**时间分布的形状**（例如"长段后面跟一串短段"），不拿场景顺序。
- 抄袭边界的可操作判据（我的推演）：把两片都抽象成"每镜的物 + 动作"一列文字，若对应行有一半以上可以互换而不改意思，就是结构抄袭，退到取向二。「待实验验证」
- 验收：跑第 1.3 节的复述重合测试，把参考片当作"上一支片"。

### 2.5 取向四：反着学（模型平时不会默认；推自 N3）
- 测出参考片的分布后，故意把它翻过来：它的长段在前，我们的长段在后；它的静止占比高，我们的低；它靠相机，我们靠内容。目的不是反对它，而是借一个已知坐标逼自己离开默认位置。
- 适合"参考片已经很成功，同类片都在学它"的情况：学它的人太多，反过来的那一端才稀缺。
- 验收：在测量的每一项上，新片与参考片的取值落在相反的一侧（以参考片的值为分界）。

### 2.6 故意违反
故意把参考片的语法用在**最不匹配**的题材上（例如把灾难片预告的语法用在一杯咖啡上），得到戏仿与反差喜剧。前提是观众认得出原语法，否则只剩错位。

### 2.7 失败点预判
- 凭印象复刻，段长偏了几帧却自以为对。提前发现：复刻片必须出叠化差异图和段长差值表。
- 一张参考图被当成全片每一镜都要照做的风格规定。提前发现：参考图只标注"它描述的是哪一类镜头"。
- 学手法时只抄到了画面。提前发现：2.3 的最后一栏是否填得出。

### 2.8 自检
- 〔测〕参考片与我的片的静止占比、最长静止段、文字主导镜头占比各是多少？我说得出每一项差值的理由吗？
- 〔测〕复刻取向：段长偏差超过 1 帧的段数 = ?（应为 0）；声音相关切点晚于声音事件的个数 = ?（应为 0）
- 学手法取向：每条规则在无关题材上的试验做了吗？

## 第 3 章 最小故事与笑点（Q1、Q2）

### 3.1 推导：最小单位由几个成分组成
N1 说记忆按"主体 + 变化"打包，N2 说短时记忆只装得下一条线。从这两条往下推，一个能被记住的最小故事只需要**两个成分**：
1. **一个能被追着看的东西**（N5：观众要能认出"还是它"）——人、物、数、一块颜色都行。
2. **它最后和最初不一样**（N1）。

其余都是**可选的放大器**，各自加一种感受，也各自加读取成本：
- 加**预期**（观众先猜它会怎样）→ 有了紧张或悬念（N3）。
- 加**阻力**（变化不顺利）→ 有了不确定，变化显得"挣来的"。
- 加**代价**（变化让什么东西失去了）→ 有了分量。
- 加**见证者**（有谁对变化做出反应）→ 有了情绪的确认（N6）。

片越短，放大器越少；最短的片可以只有两个成分。

**判据**（所有取向共用）：给一个没看过的人看末帧和首帧，他能不能说出"什么变了"。说不出，就没有故事。

### 3.2 取向一：观众替它着急（推自 N3、N6）
- 不靠角色的愿望，靠观众的愿望：先让观众看见一个**快要出事或快要成了**的状态（一摞快倒的杯子、一个只差最后一块的拼图），观众自己会开始盼或怕。状态差是"成了 / 没成"。
- 适合没有角色、但有物理或进度的内容。放大器只用"预期"。
- 起点：开头那个"快要"的状态必须在一个 R 内被看懂；看懂所需超过一个 R，观众还没来得及盼，事情就发生了。

### 3.3 取向二：一个东西的形状变了（推自 N1、N5）
- 主体是一个物或一个想法，状态差是它的形态、数量、位置：一个变成很多、散的变成整的、小的显出它其实很大。
- 适合产品、机制、抽象概念。观众追踪的是"同一个东西"的连续变化（N5），不需要欲望。

### 3.4 取向三：看法翻了（推自 N3）
- 状态差不在画面里，在观众的理解里：开头让观众以为是 A，结尾让他看出其实是 B（尺度、视角、身份）。
- 起点：开头的"误读"必须是观众自己会做的那种，而不是靠隐瞒；结尾的揭示要能回看验证——回看开头，线索一直在。

### 3.5 取向四：同一件事做三遍（模型平时不会默认；推自 N3）
- 同一件事完整发生几次，每次只改一个变量，意义来自那个变量。不需要冲突，也不需要转折。
- 适合散文式、诗性、比较类内容。每次重复之间至少留出观众比较的时间（一次 R，第 9.1 节），重复次数上限由片长 ÷（单次长度 + R）给出。

### 3.6 取向五：有人想要（推自 N1、N6）
- 当内容里本来就有一个会想要东西的主体时：它想要什么，是什么让结果不确定，最后它的处境变了。放大器用"阻力"和"代价"。
- 起点：阻力必须能被画出来（一扇关着的门、一个太高的架子），写不出画面的阻力换一个。
- 它只是五种之一，不作默认；没有天然主角的内容不要硬造一个。

### 3.7 笑点的内部（Q2，全节「弱证据，待实验」）
笑来自预期被建立后再被打破（N3）。所以笑点只有两个必需零件：**一个足够清楚的预期**、**一个事后说得通的打破**。其余（加码、确认、回归）是可选的。

**加码**：预期在被打破前被反复加强。每次加强换一个维度而不只是更大（更大 → 更多 → 更不合时宜）。次数 n 的起点：片长能装下的最大次数减一，留一次给打破。

**确认由谁承担**——观众需要一个信号来确定"刚才确实发生了那件事，而且好笑"。四种承担者：
- **画内的见证者**（推自 N6）：一个角色或物对事件做出反应。反应停留的起点 = 反应本身被认出所需的注视数 + 2 次注视（观众笑出来的那一刻画面还在）。「弱证据，待实验」
- **画面自己停住**（推自 N3）：事件之后画面完全静止一小段，静止本身就是"等你笑"。适合没有角色的片。
- **声音退场**（推自 N3、E1）：音乐或环境声在打破的那一刻突然空掉。适合有声播放。
- **不确认**（模型平时不会默认）：打破之后立刻切走，不给任何停留。只在打破极其清楚时成立，得到干、冷的效果；打破稍有含糊，观众就会错过。

**回归的几种形式**：
- **原样回来但世界变了**：回到开头的构图，同一个动作，但周围已经不同。
- **想回去却回不去**：主体试图恢复原状，失败，这本身是最后一个包袱。
- **不回归**：停在打破之后的新状态上。
- **回归即新前提**：回到开头，但这次观众已经知道会发生什么——为下一个包袱或循环播放铺路。

**埋伏与兑现**：画面里被特意强调过的东西必须在后面被用到；不兑现就别强调（N3：被强调 = 被承诺）。

**不笑的反差**（故意违反的一种）：在所有人都预期出笑点的地方，什么都不发生，或只发生一件极小的事。得到冷幽默，适合已建立喜剧预期的系列片。

### 3.8 故意违反
- 没有状态差的片：全片保持同一状态，只有观察角度在变。适合氛围循环、冥想、产品"在场感"。替代的注意来源见补缺章 C1。
- 多条线并行：两个主体各自变化，最后一刻交汇。适合"原来它们是一件事"的揭示，代价是前段读取量翻倍，片长必须够。

### 3.9 失败点预判
- 只有情绪形容词没有状态差（"展现温暖"）。提前发现：首末帧测试说不出变化。
- 笑点争抢：两个包袱相邻，第二个吃掉第一个的确认时间。提前发现：在逐行表里检查每个包袱后面是否有确认。
- 讲解片里插笑点打断论证。提前发现：删掉这个笑点，论证是否更连贯；更连贯就删。

### 3.10 自检
- 首末帧测试：外人能否一句话说出"什么变了"？
- 每个被强调的物，是否在后文兑现？
- 〔测〕每个包袱后，从打破到下一个新事件的间隔 ≥ 该包袱所选确认方式要求的时长吗？（选"画内见证者"时 ≥ 反应注视数 + 2t）

## 第 4 章 全片能量弧：峰值与转折（Q3、Q4）

### 4.1 推导
N3：持续的高能会降级成背景，峰值只有在低处衬托下才被认出来；花过一次的手法第二次就不再意外。N6：情绪无法布置，但画面里有很多可以布置的量。所以：先找一个**随情绪变化的可见量**，把弧线变成能画、能量的曲线；再让峰值做一件全片其他时刻都没做过的事。

**可见量怎么找**：不从清单里挑。问"这支片的情绪变化，在画面上最直接地改变了什么？"——答案就是载体。判据有三：它能被一眼比较大小（N4）；它在片中的取值能排成一个方向（N1）；它和内容有因果关系，而不是外加的装饰。找不到满足三条的量，就承认这支片没有可见载体，用第 4.2 节的"无峰"取向，不要硬造。

### 4.2 峰值靠什么被认出来、长什么样、放在哪（「分歧·待实验」：峰值形态）
**区分手段**：峰值被认出，是因为它**突破了全片一直守着的某个范围**（N3：范围被守久了，观众就把它当成规则；打破规则才是事件）。所以先列出全片在哪些维度上守着范围——尺度、速度、数量、声音的厚度、视点、被揭示的程度、颜色——然后选**一个**维度，只在峰值处突破。判据：峰值处被突破的那个维度，在其余时刻的取值都落在一个明显更窄的范围内。

**形态**：不预设"满"与"空"两端，而是由两个选择组成——**突破哪个维度** × **朝哪个方向突破**。同一个维度可以朝两头突破：数量可以突然最多，也可以突然只剩一个；声音可以最厚，也可以全空；视点可以最近，也可以最远。哪个方向对，看这一刻要观众感到什么（N6）：被淹没、被托起，还是被留下。同片里两种方向不同时用（N3：两种相反的预期同时兑现，等于都没兑现）。

**位置**：两股力决定峰值的位置——越晚，蓄力越长、但观众越可能已经离开；越早，越不怕流失、但后面要靠别的东西留人。四种取向：
- **按余波倒算**（推自 N3、N4）：峰值时刻 = 片尾 − 余波。余波 = 峰值之后观众必须读完的东西的 R + 一次确认注视。位置是算出来的，不是选一个百分比。
- **能多早就多早**（模型平时不会默认；推自 N4）：峰值放在观众刚好理解前提的那一刻之后，其余时间是展开与证据。适合快讯、结论先行的讲解、划走率极高的信息流。代价：后段要靠信息新鲜度留人，每一镜都要带新信息（第 9 章）。
- **峰即终点**（推自 N3）：没有余波，峰值就是最后一帧。适合循环片（峰值直接接回开头）、悬念片。代价是结尾记忆不稳，必须配合第 6.3 节的强代表帧。
- **多次释放**（推自 N3）：音乐片或有多个乐章的片，每个乐章一个局部峰值，每次突破**不同的维度**；最后一次突破的维度最"远"（观众最没想到会被打破的那个）。

无峰取向见补缺章 C2。

### 4.3 转折：之前、之中、之后（Q4）
转折是预期的方向被改变（N3）。观众的预期有两部分：**接下来是什么**（内容）和**什么时候来**（时机）；观众对"要变了"也可能事先知道或不知道。转折的形状就由这两个问题组合出来——打破的是内容预期还是时机预期，观众有没有被预告——而不是只有一种"先停再落"。

**四种形状**（「弱证据，待实验」：形状本身是推演，效果差别未经对照）
- **预告后换内容**（推自 N3、N4）：观众先收到一个"要变了"的信号，但不知道变成什么。信号可以是空隙（事件突然没了）、一段渐强、一次明显的减速、一个悬住的音。观众把注意准备好，落点被"确认"。
- **不预告换内容**（推自 N3）：预期一路兑现，在快要完成的那一刻换成别的，没有信号。观众被突袭；代价是落点那一刻观众没准备好，所以落点本身要在一次注视内可读。
- **预告了却不按时落**（推自 N3）：观众被预告"马上就来"，到了预期的时刻它没来，真正的落点在观众放松之后才到。打破的是时机。
- **比预期早落**（模型平时不会默认；推自 N3、N4）：观众以为铺垫还要走一阵，落点提前到了——在一段明显的累积还没满的时候就断开。打破的也是时机，但方向相反，读作"猝然"。适合事故、死亡、突发新闻。条件：累积要已经足够长，观众才有"还没完"的预期（见下面"预期多久才算建立"）。

**预期多久才算建立**：观众看到同一种东西第三次，才确认"这是规律"（两次只定一个方向，第三次确认重复；与附录第 41 条同一推导）。所以一个可被打破的预期，至少要有 3 个同向事件，时长 T_建 ≈ 3 × 这一段的平均事件间隔 Ī。

**空隙多长**（只在用空隙做预告时需要；M-7 重推）：观众按 Ī 预测下一个事件。下一个没在预期时刻来，要再多出一个可辨的差（时长辨别的韦伯分数约一到二成，取上沿 0.2）才觉得"晚了"，然后要一次注视 t 去确认"确实没东西"。由此：**空隙 ≥ max(1.2 × Ī + t, 2t)**。第二项是下限：事件极密时，察觉"没了"仍至少要看一眼、确认一眼。例：Ī = 0.5s 时空隙 ≥ 0.85s；Ī = 1s 时 ≥ 1.45s。上限不定，越长越像断裂，由内容决定。「弱证据，待实验」

**落点那一刻谁承担、谁让开**：转折那一刻观众要读懂的只有一件新事（N2）。所以选**一个通道**承担落点，其余通道在这一刻退后。四种承担者，各自能用的形状不同：
- **声音承担**（推自 N3、E1）：声音先到，画面随后翻。声音要么与画面同时——落在第 16.4 节的落点窗口内（30fps 下声音不领先）；要么领先到被读成一个**独立的先行事件**。观众把先到的声音读成"另一件事"而不是"没对齐"，要过三关，领先量 L 取三者最大：
  1. **出了视听捆绑窗**：领先量在这个窗内，大脑仍把声画捆成一个事件，只是"错了一点"。E1 的 45ms 是"能察觉不同步"的门限，捆绑窗比它宽，非言语声音的声先侧约在 0.1–0.15s 量级（「弱证据，待实验」）。
  2. **听出它是什么**：声音本身要被认出（一记敲击几十毫秒就够，一口吸气、一个词要它自身的时长）。
  3. **来得及转向**：观众要在画面翻之前把注意（往往连同视线）转过去，约一次由声音引发的眼动潜伏期，取一次注视 t ≈ 0.25s 的量级。
  所以 **L = max(捆绑窗, 声音的辨认时长, t)**，随声音类型变：短促的敲击 L ≈ t；要辨认的人声或呼吸，L 取它的辨认时长。L 和"同时"之间的区间（30fps：声领先 > 0 帧且 < L）不用。形状上，声音最适合"预告后换内容"（先到的声音本身就是预告）。L 的三项都「弱证据，待实验」，对照实验见第 18 章 X5。
- **画面承担**（推自 N2、N6）：画面先变，声音延后或干脆空掉。观众在"没有声音确认"的那一瞬间感到失重。适合惊愕、悲剧、反高潮；最适合"不预告"与"比预期早落"。
- **语言承担**（推自 N2）：口播的转折词（"但""直到"）承担。画面切点与它的先后见第 11.3 节与补缺章 C5。转折词本身就是预告，所以只能是"预告后换内容"或"预告了却不按时落"。
- **全部让开**（模型平时不会默认；推自 N3）：落点那一刻所有通道同时降到最低——画面几乎不动、声音几乎为零，转折靠"突然什么都没有"被感知。这里空无本身就是落点，所以它前面不能再用空隙预告，只能接在一段满的后面。

**落点之后**：最忙的段落放在落点之后的展开里，而不是落点本身。

**大转折能有几次**（R-1 重推，不写定值）：观众觉得"每一次都重要"，需要三件事同时成立——每次之前都重新建立了预期，每次之后都读完了后果，而且这一次没被前几次教会。由此推出上限：
- 时间：N_时 = ⌊片长 ÷ (T_建 + T_展)⌋，T_建 见上，T_展 = 落点后必须读完的东西的 R（第 9.1 节）+ 一次确认注视。
- 结构：转折落在段落交界上，N_段 = 段落数 − 1。
- 通道：同一承担者连用到第三次就被预测（同上"三次成规律"），所以每个承担者最多用 2 次，N_道 = 2 × 用到的承担者数；同一承担者第二次用时，幅度要比第一次大。
- **大转折数 ≤ min(N_时, N_段, N_道)**。超过一次时，各次的幅度要分级，其中一次和其余拉开可辨的差（比值 ≥ 1.2，同上韦伯上沿），观众才知道哪一次是"那一次"；其余接缝的落差明显更小。音乐片里每个乐章的局部转折按同法各算。例：30s、平均事件间隔 1s、落点后读取约 2s、4 段、用两种承担者时，N_时 = ⌊30 ÷ (3 + 2.25)⌋ = 5，N_段 = 3，N_道 = 4，上限 3。「弱证据，待实验」

### 4.4 故意违反
- 峰值放在开头而后面不解释、不降：得到"事故现场"式的冲击与茫然，适合真实灾难、突发事件。
- 全片均匀、没有峰：得到催眠、陈列、档案感，适合目录式、标本图鉴式内容（风格词汇库 S88 是一种可能的外观）。
- 每个接缝都做成转折：得到疲惫、混乱，适合表现"信息过载"本身的题材。必须全片一致地过载，否则只像失控。

### 4.5 失败点预判
- 峰值提前花掉：被选中的那个突破维度在前面已经被突破过。提前发现：给每镜标出各维度的取值，看被选维度在峰值之前的最大值。
- 承载量的曲线是平的或锯齿：写下每镜的可见量数值画成曲线，看形状。
- 大转折次数超过本片算出的上限，或同一承担者连用三次：后面几次被读成套路。提前发现：在时间表上标出每次转折的承担者与幅度。
- 落点那一刻多个通道同时都在高位。提前发现：在落点前后 0.5s 内，列出画面运动量、声音响度、字幕有无三条，看是否只有一条在高位。

### 4.6 自检
- 〔测〕峰值所突破维度的取值 ÷ 其余时刻该维度的最大值 = ?（应明显 > 1 或明显 < 最小值，不能落在范围内）
- 〔测〕用空隙预告时：空隙 ≥ max(1.2 × Ī + t, 2t) 吗（Ī 为上一段平均事件间隔）？
- 〔测〕声音承担的转折：声音领先量落在第 16.4 节落点窗口内，还是 ≥ 本片按 L = max(捆绑窗, 辨认时长, t) 算出的值？（落在两者之间即不合格）
- 〔测〕大转折数 ≤ min(N_时, N_段, N_道) 吗？同一承担者用了几次（≤ 2）？

## 第 5 章 空间怎么组织、时间由谁驱动、时间表怎么写（Q5、Q28、Q37）

### 5.1 推导
每切到一个新空间，观众都要重新定位：这是哪、主体在哪、和刚才什么关系（N5 的成本）。我把这笔成本记作 **r**，起点取 3 次注视（约 0.75s：看全局一眼、找到主体一眼、确认关系一眼）。重定位期间观众接收不到内容，所以它是从每个想法的时间里扣掉的。另一方面，一段片子的时间到底由谁驱动，取决于这段的瓶颈（第 5.3 节）。

### 5.2 换不换空间：不分档，逐个想法算（「分歧·待实验」：连续场景与密切蒙太奇并存）
片长不直接决定结构，决定结构的是"每个想法有多少时间"和 r 的比例。所以不按片长分档，而是对每个想法单独判断。四种取向：
- **逐想法判定**（推自 N5、N4）：列出全片的想法和各自分到的时长 d。d ≥ 3r（约 2.25s）的想法才值得换一个新空间；d < 3r 的想法留在当前空间里，靠空间内部的变化表达。推导：换空间时，重定位占掉想法时间的比例 = r ÷ d；超过三分之一，观众用来"找"的时间就多到让这个想法显得仓促。「弱证据，待实验」
- **一个空间到底**（推自 N5）：全片不换空间，所有想法都是同一空间的变化。重定位成本只付一次。适合想法彼此紧密相连、或片子很短的情况。
- **回访**（模型平时不会默认；推自 N5、N4）：少数几个空间轮流回来（A → B → A → C → A）。第二次回到同一空间，重定位几乎不要钱（观众已认识它），因此可以在有限片长里换很多次"场"。适合对比、并行、"回到基地"的结构。
- **密切段**（推自 N3）：高频切本身就是语法，观众不再试图在每个空间里定位，而是把整段读作一块。适合音乐驱动、情绪堆积、"很多很多"的主题。条件：每个镜头一眼可读（单焦点、高对比），否则只是闪烁。

**光敏底线（密切段必须过）**：高频切里，一个明暗差大的切点只是一次变化，两次方向相反的切点合成一次闪烁，计数、配对、窗口、红闪都按 E2，不在这里另算。粗估：高对比切点在任意 1 秒内多于 6 个、且明暗交替，就可能超过 3 次闪烁。超限时，要么降低相邻镜头的亮度差（让相对亮度变化 < 0.1，或这一对的暗侧也 ≥ 0.8），要么让同时闪烁的区域小于 E2 表里的面积上限。最终以 E2 的检查脚本结果为准。

**中长片何时必须分场**：当一个连续空间里的站点多到观众记不住"我们从哪来"时。起点判据：同一空间里的站点数超过工作记忆的块数（我取 4）就分场。「待实验验证」

### 5.3 主轴：按这一段的瓶颈来找（Q28）
主轴不是从一张驱动者清单里挑，而是问：**这一段里，观众的哪一项处理先满了？** 先满的那一项卡住接收速度，它也就决定了"谁握着时钟"——下一件事什么时候可以来。观众处理一段片子要用到六种东西，各自满了的样子不同，时钟落在不同的人手里：
- **语言通道被占满，时钟在说话的人手里**（推自 N2、N4）：口播里有必须跟上的论证。语音是串行的、不能回看，观众只能按说话的速度接收，画面再快也进不去。时间 = 实测音频；画面事件锚在词上（第 16.4 节），句间不插画面新信息。
- **视线采样满了，时钟在观众手里**（推自 N4）：画面上有必须读完的字或图，没有口播。观众自己决定看哪里、看几眼，读完才能接收下一件。时间 = 每件事的 R（第 9.1 节），下一件在上一件的 R 之后才来。
- **在等世界做完，时钟在因果手里**（推自 N1、N2）：操作或物理过程，观众要看到上一步的结果才能理解下一步。时间 = 过程本身的时长：下一事件在上一步完成并停稳之后发生，不由拍子决定，也不为凑时长加速。
- **身体在跟一个脉动，时钟在节律手里**（推自 N3、N6）：情绪起伏本身是内容，观众的唤醒跟着一个稳定的脉动（音乐、呼吸、脚步）走。时间 = 脉动的拍与乐句；一段没有音乐时，用一个稳定的环境节奏代替。有用户指定的曲子时，曲子决定弧线，内容去凑段落。
- **每一项都要比对一次，时钟在项的难度手里**（模型平时不会默认；推自 N2、N4）：陈列、图鉴、清点，观众对每一项都要做一次"这是什么"的辨认。时间 = 每一项的辨认时长，难认的多给、好认的少给，不匀速。
- **前面的东西还要拿在手里，时钟在记忆负荷手里**（模型平时不会默认；推自 N2）：后面的内容要和前面几项一起用（累积的论证、和开头比、几项合起来才成立的结论）。卡住观众的不是接收而是"拿住"：工作记忆只装得下少数几块。时间 = 每加进约 3–4 块新东西后，插一拍不加新信息的整合（把前面几块收成一块：一个汇总画面、一个回看、一次停顿），这一拍的长度 = 汇总画面的 R。「待实验验证」

| r4 瓶颈 | r5 新轴（哪一项先满 / 时钟在谁手里） | 变化 |
|---|---|---|
| 要听懂 | 语言通道 / 说话的人 | 补"串行、不可回看"为什么让音频握时钟 |
| 要读完 | 视线采样 / 观众 | 改为按"观众自定步调"定义 |
| 要看清过程 | 等世界做完 / 因果 | 补"停稳之后"这一时刻 |
| 要感受 | 跟一个脉动 / 节律 | 改为按唤醒跟随定义 |
| 要认出很多个 | 逐项比对 / 项的难度 | 改为按辨认时长定义 |
| （无） | 记忆负荷 / 整合拍 | 新轴推出的新瓶颈 |

**片内切换主轴**：允许，但切换处要有一个"交接点"——上一个主轴的最后一个事件，同时是下一个主轴的第一个事件（例如口播最后一个词落在音乐段落起点上）。没有交接点的切换，观众会感到时间突然换了单位。「待实验验证」

**一律按实测排时间**：音频以实测为准，计划时长只用于估算。

### 5.4 时间表怎么组织（Q37）
从两个问题推：误差从哪里来、怎么传；改一处要动几处。
- **误差随派生的层数累积**：一个时间如果是从另一个派生值再派生出来的，每一层的取整与估算误差都叠上去。所以每个时间最多离**实测锚点**一层：直接写"相对哪个词 / 哪一拍 / 哪个上一事件 + 偏移"，不写"相对另一个派生时间"。
- **取整只做一次**：全部计算用秒的连续值，只在渲染时换成帧。若某个点必须对齐到帧（切点），按 E1 的方向取整：与声音相关的画面事件向**早**的一侧取整（画面略早可容忍，略晚不行）。
- **测得值与意图分开记**：实测的词时间、拍位置单独一栏，只读；为观感做的提前或延后写在另一栏，并写一句理由。重新测量时，前一栏被覆盖，后一栏保留。混在一个数里，重测就会把意图冲掉。

三种组织取向，按修改的范围选：
- **一张锚点表派生一切**（推自 N5）：字幕、音效、转场点、相机关键帧都从同一张表派生。改一个锚，派生物自动跟随。适合口播片与多语言版本。
- **分层各管各的**（模型平时不会默认；推自 N2）：每一层（画面事件、音效、字幕）各自拥有自己的时间，只声明它挂在哪个上层事件上（例如音效挂在画面事件上，不挂在词上）。改画面时音效跟着画面走，改口播时只动挂在词上的层。适合画面会大改、而声音设计已定稿的情况。
- **小片直接写死**（推自 N4）：十几秒的片、事件很少时，绝对时间一张表就够，音频锁定后不再变。派生系统的搭建成本超过它省下的修改成本时，用这一种。

段落有名字，代码结构与叙事结构同构：改一镜，只动一个子结构。

### 5.5 故意违反
- 画面与声音用两套不相关的主轴：得到疏离、梦境、"声音来自另一个世界"，适合回忆、失真、焦虑题材。全片都要脱节，脱节一半只像错误。
- 极短片里频繁换空间：得到"闪回、碎片记忆"，适合表现混乱或回忆闪现。

### 5.6 失败点预判
- 讲解段为了卡拍删掉必要条件。提前发现：讲解段若用了音乐主轴，逐条核对论证有没有被删的条件。
- 操作段让拍子决定点击时机，因果变得像巧合。
- 时间线里有未察觉的空隙。提前发现：从锚点表自动列出所有"没有任何事件"的区间及长度。
- 密切段闪烁超标。提前发现：渲染后跑 E2 的检查脚本（`scripts/flash_check.py`）。

### 5.7 自检
- 每段写得出它的瓶颈和主轴吗？
- 〔测〕d < 3r 却换了新空间的想法有几个？（逐想法判定取向应为 0）
- 〔测〕按 E2 脚本：任意 1 秒窗口内一般闪烁、红闪的最大次数各是多少？超过 3 的那几秒，同时闪烁面积峰值是否低于 E2 表里的上限？
- 〔测〕改一句稿、换一首同速曲，有多少处要手改？（应接近 0）

## 第 6 章 开场与代表帧（Q6、Q7）

### 6.1 推导：第一眼装得下多少
观众在信息流里常常静音，第一次停下来看的那一眼决定留不留（N4）。这一眼的容量很低：大约 2–3 次注视（0.5–0.75s）之内，观众能拿到的是**一个主体 + 它在做什么**，再多就只剩"很乱"（N2）。由此推出开场的两条约束：
- **静音可读**：开场的意思不能只在声音里。
- **一眼一件事**：首帧里能被第一眼抓住的只有一个主体；第二个主体至少晚一次注视出现。

**共用底线**：首帧就是一张完成的构图（不是黑场、不是空画面、不是未完成的入场）。

### 6.2 第一眼交付什么：按"哪一格没填"分六种（「分歧·待实验」：开场能量与承诺顺序）
从 6.1 的容量出发：第一眼装得下的是两格——**主体**和**它在做什么**。观众留下来，是因为两格里留着一个没解开的东西，并且他能估出要等多久才解开（N3）。所以分类轴是两个：**哪一格（或两格之间的哪种关系）留着没填**，和**这个问题的解开要等多久**。每种都写出它对静音观众和准备划走的观众意味着什么。
- **两格都填满，问题只剩"真的吗 / 怎么做到"**（推自 N4、N1）：第一眼就是观众能拿走的东西——一个结果、一个反常的数字、一个做完的作品；等待时长为零，后面是证明。静音：结果必须是画面或大字本身，不能在口播里。划走：划走的人也拿走了核心信息，记忆收益高、留存收益低。适合快讯、讲解、信息流。
- **两格都填满，问题是"它是怎么变成这样的"**（推自 N1、N5）：首帧是终点状态，然后倒回去走过程。和上一种的区别在后面接的是**过程**而不是**证据**，观众等的是路径。静音：终点状态要和常态有一眼可见的差。划走：划走的人只看到一个"状态"，不知道有过程，所以首帧里最好露出一点过程的痕迹（脚手架、残片、半成品的边）。适合改造、建造、成长、事故复盘。
- **"在做什么"一格悬空，等待 ≤ 约 1s**（模型平时不会默认；推自 N3、N1）：动作已在进行并快要完成——手离按钮一指、东西正往下掉。观众被"它会怎样落地"拖住，等待短到不需要信任。静音：落点必须看得见。划走：第一秒内几乎不会划走，但落地后若没有第二个未解开的东西，会在落地那一刻集中流失，所以落地即开出下一个问题。首帧本身仍是完成的构图，未完成的只是动作。
- **两格冲突**（推自 N3）：主体在做它这一类不会做的事——尺度不对、方向不对、物在做人的事，而且正在动。观众等的是"为什么"，等待时长 = 到解释出现为止，要靠冲突本身的强度撑住。静音：冲突必须是视觉的，不能靠台词说"这很奇怪"。划走：冲突读不出来的人会把它当成普通画面划走，所以冲突要在一次注视内可见。适合悬念、揭示型故事（第 3.4 节）。
- **"主体"一格留白**（模型平时不会默认；推自 N3、N2）：只给动作或动作的痕迹，不给是谁、是什么——局部特写、剪影、尺度不明的局部、一个结果的影子。观众等的是"这是什么"。等待上限是变量：揭示要在观众的猜测还在收敛时到来（猜到一半最想知道），晚于猜测放弃就变成"看不懂"；起点取 2–4 次注视后揭示，「待实验验证」。静音：留白的东西必须靠画面揭示。划走：没有任何可识别物的首帧最容易被当成"还没开始"划走，所以留白只留主体，动作要清楚。
- **两格都轻、不立明确问题，只立气氛预期**（推自 N3、N6）：一个安静、具体、略带疑问的小场景（一个物在等待、一个人在犹豫），不给答案，观众等的是"这里会发生什么"，等待时长长且不确定。静音：天然静音可读。划走：在高划走平台风险最高，必须有一个在动的具体物，不能只是空镜。适合故事片、品牌情绪片、有耐心的受众。

骨架记录的分歧在第一种与最后一种之间：开场即交付核心承诺，还是低能铺垫。两端都保留，适合的平台与受众不同，没有数据裁决。

| r4 取向 | r5 新轴里的位置 | 变化 |
|---|---|---|
| 交付结果 | 两格都填满，问题只剩"真的吗 / 怎么做到" | 改为按"留下的问题"定义，补静音与划走的后果 |
| 交付终点 | 两格都填满，问题是"它是怎么变成这样的" | 与上一种按"后面接证据还是接过程"区分 |
| 交付一个做到一半的动作 | "在做什么"一格悬空 | 补等待时长与落地时的集中流失 |
| 交付反常 | 两格冲突 | 等待由冲突强度撑住，补"一次注视内可见" |
| 交付一个安静的具体物 | 两格都轻，只立气氛预期 | 保留，补等待时长不确定的代价 |
| （无） | "主体"一格留白 | 新轴推出的新取向 |

**钩子字的大小**（若用文字承担钩子；按 B11 重算，统一用毫米）：
- 前提：一瞥可读的汉字，视角约 0.7°。手机观看距离按 30–35cm，0.7° 对应字高 2 × 300mm × tan(0.35°) ≈ 3.7mm 到 4.3mm，取 4mm。
- 屏幕：手机竖屏可视宽按 68mm 计。字高 ÷ 屏宽 = 4mm ÷ 68mm ≈ 1/17（两侧都是毫米，量纲相消）。
- 换一个屏宽假设复核：62mm 时为 1/15.5，72mm 时为 1/18。同一个比例下，屏越窄，字的物理高度越小，所以**最窄屏 62mm 最严**（需要 1/15.5）。取 **字高 ≥ 画宽 W 的 1/15**：62mm 屏上约 4.1mm、68mm 约 4.5mm、72mm 约 4.8mm，三种假设下都 ≥ 4mm（复算见附录"r5 计算复核"E-1）。r4 写成"屏最宽最严、取 1/16"是推理写反了：1/16 在 62mm 屏上只有约 3.9mm。
- 换算：竖屏 W = 1080px 时 ≥ 72px；横屏在手机上横放时，物理宽变成长边，按同样方法以长边毫米数重算。
- 对比度在真实背景上实测 ≥ 4.5:1（文字下面若有素材或运动，按最差那一帧测）。「弱证据，待实验」

**行动号召在开场要不要出现**：取决于平台是否会在中途截断播放。会截断的平台，开场可以出现一次弱提示（不占主体位置）；不会截断的，留到结尾。「待实验验证」

### 6.3 代表帧（Q7）
静帧是传播的主体：缩略图、截图、减弱动效模式，都只给一帧。处于变化中途的帧（数字滚到一半、形状变形一半）被冻结后读作故障。

三种取向：
- **结果帧**（推自 N1）：状态差落定的那一刻。最稳，适合讲解与产品。
- **开场即代表帧**（推自 N4）：首帧就是代表帧，缩略图与开场一致，观众点进来看到的就是他被承诺的画面。适合第 6.2 节"两格都填满，问题只剩真假"的开场。
- **临界帧**（推自 N3）：事件即将发生的前一瞬——球离杯沿一指、手离按钮一指。它是完成的构图（不是变形中途），但包含一个未决的张力。适合悬念与笑点。

**代表帧测试**：把候选帧单独给一个没看过的人看，问"这里发生了什么"。回答与阐述的一句话一致才算过。找不到能过测试的帧，回到第 1 章——想法还没落到画面上。

**代表帧与封面**：封面是平台另行设计的物，可以在代表帧的基础上重新构图、加字，但其中的主物与主动作应与代表帧一致，否则点进来的人会觉得被骗。「待实验验证」

### 6.4 故意违反
- 全黑或纯色首帧、靠声音开场：适合恐怖、悬疑、"先听见再看见"的叙事。只在有声播放的场合成立，静音信息流里不要用。
- 慢速品牌开场：适合品牌本身就是内容的场合（观众是来看这个品牌的发布）。
- "看到最后才知道"：适合预告片、谜题片，但开场必须仍有一个具体的物在动。

### 6.5 失败点预判
- 首帧是入场动画的第 0 帧（空的或半透明）。提前发现：导出第 0 帧单独看。
- 钩子依赖声音。提前发现：静音看开场，复述它说了什么。
- 首帧里同时有两个以上能抢第一眼的主体。提前发现：数首帧里对比最高的几个区域。

### 6.6 自检
- 静音、只看前 0.75s，能复述这支片要给我什么吗？
- 〔测〕首帧有没有任何一个元素的不透明度 < 1 或缩放处于入场中途？（应为 0 个）
- 〔测〕钩子字高 ≥ W/15 吗？实测最差帧对比度 ≥ 4.5:1 吗？第二个主体出现时刻 ≥ 首帧后 0.25s 吗？
- 代表帧测试的回答与一句话阐述是否一致？

## 第 7 章 结尾与循环（Q8、Q9）

### 7.1 推导：闭合感从哪里来
观众觉得"讲完了"，是他对"后面不会再有东西了"的预测变得有把握（N3）。这个把握有五个来源，彼此独立，结尾选的是来源，不是外形：
- **结构对称**（N5）：观众认出现在的画面和开头是同一个位置或同一个物，"一圈走完了"。
- **账清了**（N3）：片里开过的每一个"等着看"都有了下文，观众手里没有欠着的期待。
- **发动机停了**（N3、N6）：产生事件的东西本身停了——运动、声音、数量降到零，没有东西还能引出下一件事。
- **装进一句话**（N1、N4）：观众能把整支片压成一句话，再看也不会多出东西。
- **约定的终止信号**（N3）：观众从看过的无数片子里学会的"结束"记号——音乐回到主音的终止式、落款、黑场、片尾字、说话人的收尾语。它不来自本片内容，来自观众的习得。

结尾需要停留让记忆写入（N4），但停住的画面也可能被读作卡住。区别在观众能不能看到"停是有意的"证据，见第 7.2 节"结尾停留"。

### 7.2 结尾的取向（「分歧·待实验」：结尾能否用文字卡、静止是否保留微运动）
按闭合感的来源分：
- **结构对称：变了样的归来**（推自 N5、N1）：开头的物或构图回来，但状态不同。观众同时做了两件事——认出"同一个"、比出"不一样"，闭合和全片的状态差在一眼里完成。变体：开头失败的动作在结尾再做一次并成功。
- **账清了：最后一笔下文**（推自 N3）：把片中最早开出、最久没有下文的那个期待留到最后兑现（一直没打开的盒子、一直没说出的名字）。判据：结尾之前列出片里开过的期待，最后一刻之后这张单子是空的。
- **发动机停了：沉下来**（推自 N6、N3）：不回到任何地方，产生事件的那个东西自己收束（合上、放下、熄灭、转身、离开画框），然后一切降到静止。观众感到的是"没有东西能再引出下一件事了"。
- **装进一句话：全貌**（推自 N1、N4）：画框第一次大到装下全部，或最后一句话就是全片论证的结论——观众手里的碎片在这一刻被压成一个整体。
- **约定的终止信号**（模型平时不会默认；推自 N3）：内容可以停在半路，结尾只靠一个观众熟悉的终止记号收住（终止式的最后一个和弦、一个落款、一次干脆的黑场）。适合内容本身是连续流、没有自然终点的片子（直播切片、氛围片、数据流）。代价：信号是借来的，用得太显眼会被读成"模板片尾"。
- **故意不闭合**（模型平时不会默认；推自 N3）：结尾停在一个未决的时刻，问题留给观众。适合系列片的单集、引发讨论的观点片。条件：问题必须在片中被清楚地建立过，否则只是没做完。

| r4 取向 | r5 新来源 | 变化 |
|---|---|---|
| 靠记忆闭合：变了样的归来 | 结构对称 | 改为按"认出同一个 + 比出不一样"两步定义 |
| 靠预期闭合：最后一个承诺兑现 | 账清了 | 补"期待单子清空"的判据 |
| 靠能量闭合：沉下来 | 发动机停了 | 改为按"没有东西能再引出下一件"定义 |
| 靠理解闭合：全貌 | 装进一句话 | 改为按"压成一句话"定义 |
| 故意不闭合 | 故意不闭合 | 保留 |
| （无） | 约定的终止信号 | 新来源推出的新取向 |

**文字在结尾**：两端并列。一端：结尾落在物上，文字最多是画面一角的一行确认（推自 N6）。另一端：结尾就是一句话，因为这句话就是片子的结论，或者观众需要带走一个可搜索的名字（推自 N4、第 16.5 节术语）。选后者时，那句话应当是全片论证的结论，而不是金句。

**结尾停留：观众看到什么才不读成卡住**（「分歧·待实验」）：画面停住时，观众在找"停是有意的"证据。证据有三种：最后一个运动是自己减速到零的（半路截停读作卡住）；还有一条通道在走（声音的余响在衰减）；或者画面里明确有东西离开或熄灭。三种停留各用一种证据：
- **真冻结**：最后一个运动先自己减速到零，再完全静止，时长 = 该帧的 R + 2 次注视（一次确认、一次"知道结束了"）；证据靠声音那条通道——余响或最后一个音的衰减继续走，告诉观众"时间还在，是画面停了"。「弱证据，待实验」（对照实验见第 18 章 X4）
- **单一微生命**：证据在画面里——只保留一种极低能量的变化（光的缓慢变化、一缕烟），其余静止，观众看到"时间在走"。适合循环播放平台与氛围片。
- **主动离场**：证据是离开本身——不停留，结尾画面自己退出（主物离开画框、灯熄），观众看到的是一个完成的动作而不是一张停住的图。适合有声播放、节奏利落的片子。

### 7.3 循环的接缝（Q9）
循环片的末帧接回首帧。观众在接缝处做一次判断：这是**同一个世界在继续**，还是**倒带了**？倒带的证据只有一种——观众认出了一个他已经见过的状态又出现了，而且画里没有让它回来的原因（N1、N5）。所以藏接缝就是不让观众拿到这个证据，有四种方式，按"观众本来会靠什么认出倒带"分：
- **给它原因：世界里有原因**（推自 N1）：允许观众认出状态回到了开头，但画里有一个事件把它带回来（一阵风、一只手、一扇门关上又打开），观众读到的是"被清空了"而不是"倒带"。连续量可以断，因为断有原因。大遮挡下的瞬换（主物经过画面、全屏的光）也属于这一种——遮挡物就是原因；用光做遮挡时，受 E2 约束（计数与面积按 E2）。
- **让它沿路回来：圆环式**（推自 N5、N1）：状态回到开头，但是沿着一条连续的路走回来的（日落之后是日出、堆起来的积木塌回原样），观众一路追着它，看到的是"转了一圈"。接缝处所有连续量（位置、速度、方向、亮度）都相等。
- **不让任何个体被认出两次：流动式**（模型平时不会默认；推自 N5、N2）：观众能认出"又是它"，靠的是追踪某一个个体。流动画面里元素从一侧不断进、从另一侧不断出，只要（1）接缝两侧可见的每个元素位置、速度都一致，（2）没有哪个辨识度高的元素（颜色、形状独特的那一个）在一个循环里被看到两次，观众就没有可追的个体，只有"一直在流"。r4 写成"画面里总量始终不变"，那只是必要条件，不够：总量不变而那个红色的元素在同一位置第二次出现，观众照样认出倒带。适合陈列、氛围、数据流。
- **接缝时观众在看别处**（模型平时不会默认；推自 N2）：观众只能注意一处，接缝发生在注意之外的区域时，变化很难被发现。做法：接缝前后约一次注视内，在画面另一处安排一个夺眼事件，重置发生在远离它的区域；重置区域在夺眼事件之后的一两次注视内完成。条件：夺眼事件本身要有内容，不能是为藏接缝硬加的闪动（闪动受 E2 约束）。「待实验验证」

| r4 分类 | r5 新轴（观众本来会靠什么认出倒带） | 变化 |
|---|---|---|
| 世界里有原因（含大遮挡瞬换） | 给它原因 | 定义改为"认得出回来，但有原因" |
| 状态自己转回来（圆环式） | 让它沿路回来 | 改为按"一路追着它"定义 |
| 流入流出守恒 | 不让任何个体被认出两次 | 补"辨识度高的个体不出现两次"；指出"总量不变"只是必要条件 |
| （无） | 接缝时观众在看别处 | 新轴推出的新方式 |

**接缝检查法**：把末尾几帧和开头几帧拼成一条连续帧带，逐元素计算跨接缝的变化。
- 速度变化 ≤ 约 15%（速度辨别的韦伯分数约一到二成，取中间）。「弱证据，待实验」
- 位置跳变 ≤ 1px（圆环式与流动式）。
- 接缝处的空白不超过本片平均事件间隔。更长，观众会注意到"什么都没发生"的那一刻，从而发现循环点。

**叙事型与氛围型循环**：叙事型（故事回到开头）的接缝可以有一个明显的"重新开始"信号，因为故事本身承认了循环，适合"世界里有原因"；氛围型必须无缝，适合圆环式、流动式或"接缝时看别处"。「待实验验证」

### 7.4 故意违反
- 突然停：在动作中间硬切到黑。得到戛然而止、震惊、"被打断"，适合悲剧、事故、悬念。必须是全片最强的那一刀。
- 结尾与开头毫无关系：得到"走远了"的漂流感，适合公路片式、意识流内容。

### 7.5 失败点预判
- 最后一个理解单元还没落地就结束；结尾的多个信息被压进极短时间。提前发现：逐行表里结尾那一行的 R 是否被完整留出。
- 循环接缝处方向突变；新加入的东西凭空消失。提前发现：连续帧带检查。

### 7.6 自检
- 首帧与末帧并排，能说出"变了什么"吗？这支片的闭合来自第 7.1 节五种来源中的哪一种？
- 〔测〕真冻结时，最后一个运动是自己减速到零的吗？末帧静止时长 ≥ 末帧 R + 0.5s 吗？静止期间声音余响还在走吗？
- 〔测〕跨接缝速度变化 ≤ 15%、位置跳变 ≤ 1px、接缝空白 ≤ 平均事件间隔吗？流动式：辨识度最高的那个元素在一个循环里被看到几次（应为 1）？

## 第 8 章 镜头是一个事件：状态差与可见原因（Q15、Q18）

### 8.1 推导
事件是注意的单位（N1）。只有运动、没有状态差的镜头被读成屏保。变化需要主语：观众对因果极敏感，一个变化若没有可见的触发者，就像页面对着空气反应（N1）；原因可见还顺带告诉视线下一步看哪（N2）。

**事件判据**：每一镜在逐行表里写得出"某物 + 动词 + 结果"。写成"展示""呈现""体现"的，不是事件。

### 8.2 状态差的主语在哪里
从"状态差到底挂在什么上"推：观众登记的是"某个东西的某个属性变了"，而"东西"可以是单个的、成对的、成群的、弥漫的，也可以根本不在画面上。由此分五种：
- **一个东西**（推自 N1、N5）：一个可以被一直追着看的个体变了——它被打开、长大、坏掉、得到了什么。主语可以是角色、物、数字。观众盯住它就够了。
- **两个东西之间**（推自 N1、N6）：变的不是任何一方，而是它们的关系——距离、谁在上、谁挡住谁、谁跟着谁。主语是"关系"。判据：单独看任何一方，看不出发生了什么。
- **一群东西的排列**（推自 N2）：个体都没变，变的是它们的组织——散乱变整齐、一列变一圈、多数中出现一个不一样的。主语是"秩序"。观众要被允许把群体当成一块看（第 11.2 节）。
- **环境本身**（模型平时不会默认；推自 N6）：光、天气、空间的大小、声场变了，里面的东西都没动。主语是"处境"。适合氛围、时间流逝、情绪转换。
- **观众的理解**（推自 N3）：画面不变，但一个新信息（一行字、一个声音、一个视角）让同一画面的意义变了。适合揭示与反讽。这一种最容易被误当成"没有事件"，判据是：观众看完能说出"原来……"。

### 8.3 原因的三种取向（Q18）
- **操作者在场**（推自 N1、N2）：一只手、一个光标、一个角色触发变化。原因先于结果出现，并在结果发生前停稳——运动中的原因会抢走结果的注意。起点：原因停稳到结果开始之间留一个短停顿，长度 = 观众视线从原因移到结果所需（原因与结果紧邻时可为 0，离得远时约一次注视）。
- **概念自担因果**（推自 N1、N5）：没有操作者，原因由内容自身扮演——一个点落下导致波纹，一个数增长推开旁边的东西。适合抽象、系统、物理。判据：把"谁推动了它"问一遍，答得出画面里的某个东西。
- **上一镜即原因**（模型平时不会默认；推自 N5）：这一镜的变化由上一镜的动作引起——上一镜扔出的球，在这一镜打碎了东西。原因跨越切点，因果本身成了承接物（第 13.2 节）。

**无操作者的后台变化**（系统在别处产生的后果，如服务器、算法、时间流逝）：用"后果的痕迹"代替操作者——先让观众看见一个原本状态，再切到它被改变了的样子，中间插一个"时间或空间在别处"的提示（钟、远景、通知抵达）。「待实验验证」

**原因不要遮住结果**：光标、手、角色的身体不能盖住它触发的目标。聚光圈、高亮框不是操作者，用它们冒充原因，观众仍然不知道"谁做的"。

### 8.4 故意违反
- 有原因无结果：手按下按钮，什么都没发生。得到失望、无力、讽刺，适合讲故障、官僚、失灵。
- 有结果无原因：一切自己在变，且刻意不给解释。得到神秘、超自然、不安，适合恐怖、魔幻、"这背后是什么"的悬念。全片都要这样，偶尔一次只像漏画。
- 纯氛围镜头：没有事件，只有状态。全片中应是少数，并且是有意的（判据：去掉它，能量弧是否少了一次呼吸；少了才留）。

### 8.5 失败点预判
- 角色站着微笑，什么也没发生。提前发现：逐行表"它怎么变"一栏写不出。
- 界面自己在变，没有触发者。提前发现：每个界面变化问一次"谁做的"。
- 原因与结果同时发生，观众只看到一个（N2）。提前发现：在时间表里检查原因停稳点是否早于结果起点。

### 8.6 自检
- 每一镜的主语属于五种中的哪一种？
- 〔测〕写不出"某物 + 动词 + 结果"的镜数 = ?（应为 0，纯氛围镜头单独标注）
- 〔测〕每个有操作者的变化：原因停稳时刻 ≤ 结果起点吗？操作者包围盒与目标包围盒的重叠面积 = ?（应为 0）

## 第 9 章 一个镜头该多长（Q10）

### 9.1 推导：读取时长 R 按注视数算，不按心理阶段相加
作者系统性低估观众的读取时间（N4），两件事同时发生只被看到一件（N2）。所以镜头时长由"观众按顺序读完这一镜里每件事需要多久"决定，而不是由"动画需要多久"决定。**动作可以快，含义需要停**：动作时长与含义停留是两个独立的量。

**为什么不分阶段**：把读取拆成"先发现、再理解、再记住"几段相加，有两个问题：各段在真实阅读里是重叠的（眼睛在看这个字时已经在预读下一个），相加会重复计时；而且各段无法单独测量，系数校不准。能被直接观察的量只有一个——**注视次数**（眼动仪能数，首看暂停测试也能间接校）。所以 R 只用一个量来算：

**R = t × (落眼数 + 内容注视数) × c**（全节「弱证据，待实验」，系数是我按注视的生理量定的起点）
- **t**：一次注视连同跳到它的眼跳，约 0.25s。
- **落眼数**：事物出现在观众当前看着的地方为 0；出现在别处为 1；画面里每多一个同时在动的竞争组，再加 1。
- **内容注视数**：
  - 中文文字：一次注视约覆盖 2 个字，⌈字数 / 2⌉。
  - 拉丁文字：约每词一次。
  - 图像：观众必须辨认的部分（主体、它的状态、它和谁的关系）每部分一次。
  - 数字、术语、专名：每个按 2 次计（要逐位或逐字确认）。
- **c 条件系数**：一般信息 1；本镜要被记住的关键信息（结论、数字、包袱）1.5（观众会回看确认）；口播同时在说另一件事时再乘 2（语言通道冲突，N2）。
- 一镜里有多件事时按顺序相加：**ΣR**。

例：一行 10 字的常用语，出现在注视点外，是关键信息：0.25 × (1 + 5) × 1.5 ≈ 2.25s。同一行字若口播同时在说别的，≈ 4.5s——这说明更好的做法是让字和口播说同一件事，而不是延长镜头。

**测量代替估算**：成片后请没看过的人看一遍，在每镜结束时暂停，问这一镜说了什么。答不出的镜，R 被低估了；记下这类内容的实际所需，回填 t 或 c（补缺章 C6）。

### 9.2 四种取向
- **读取预算型**（推自 N4、N2）：镜长 ≥ ΣR × 1.3。1.3 的来历：观众之间读速差异大，若读速的个体差异约为三成，按平均值算的 R 只覆盖一半观众；乘 1.3 约覆盖到读得慢一档的那部分人。适合讲解、信息密集、多语言。「弱证据，待实验」
- **主轴给定型**（推自 N4，配合第 5.3 节）：镜长由口播或音乐给定，R 只用来检查：ΣR 超过给定镜长时，**删内容而不是加速**——砍掉一件事，而不是让每件事都快一点。
- **实测型**（推自 N4）：不用公式，直接做粗样，跑首看暂停测试，逐镜加长到答对率达标为止。适合系列片的第一支（之后用它的结果校公式），以及公式明显不适用的内容（满屏图鉴、复杂图表）。代价是每轮都要找新的观看者。
- **压缩重看型**（模型平时不会默认；推自 N3）：故意让镜长短于 ΣR，让观众第一遍只抓住主体、第二遍才看见细节。只用于会循环播放的平台、彩蛋式细节、"再看一遍才发现"的设计；必要信息不许放进被压缩的那一部分。

### 9.3 故意违反
在一镜里同时放两件同等重要的事：观众只能看到其中一件，不同观众看到不同的那件。得到"多义、人人看到的不一样"，适合引发讨论的片、谜题片。

### 9.4 失败点预判
- 一切同一个轻快速度；结尾的几个理解单元被压进极短时间；作者看了五十遍后觉得"太慢"而全面提速。提前发现：每镜在表里写出 ΣR；改动只能删事项，不能缩短到 R 以下。

### 9.5 自检
- 〔测〕镜长 ÷ ΣR 的最小值 = ?（读取预算型 ≥ 1.3，主轴给定型 ≥ 1，压缩重看型只对非必要信息允许 < 1）
- 〔测〕首看暂停测试中答不出的镜有几个？（应为 0）

## 第 10 章 节奏的形状与静止（Q11、Q12）

### 10.1 推导：数什么才算"发生了一次"
感官适应恒定刺激，注意靠对比维持（N3）。节奏是间隔的形状，不是速度。关键是计量单位：

- 数"新运动"不对：一个在动却没带来任何新东西的元素不推进节奏，只增加噪声，会把"太密"掩盖成"有节奏"。
- 数"新信息"接近，但有缺口：一个纯形式的变化（颜色突然翻转、一次停顿后的重启）没有信息，观众却明显感到"一下"。
- 我取的单位是**一次"夺眼"**：一个让观众的视线重新落脚、或让注意重新收紧的变化。判据：这个变化发生时，没看过的观众会不会不由自主地看向它或感到"变了"。会，就计一次；只是画面里多了点动静、不会让人重新看的，不计。

这一换算同时治两种失败：运动多而夺眼少（花哨但无节奏），夺眼之间间隔过长（空）。新信息事件几乎都是夺眼，但夺眼不一定带信息——节奏用夺眼计，信息量用第 9 章的 R 计，两张表分开。

**夺眼间隔序列**：把全片的夺眼按时间列出，相邻差值就是间隔序列，画成曲线就是节奏的形状。

### 10.2 节奏的五种取向
- **长短档位型**（推自 N3）：镜长归成至少 3 档，相邻档之比 ≥ 1.4（时长辨别的韦伯分数约一到二成，1.4 约为两个辨别阈，保证档与档被感知为"不同"）。至少一次**加速**：连续三个以上间隔，每个约为前一个的 0.7 倍（每步变化约三成，单步就能被察觉，又不至于两三步就塌到不可读）；至少一次**呼吸**：一个间隔 ≥ 其前后局部平均的 2 倍。档位比与加速系数「弱证据，待实验」（对照实验见第 18 章 X1）。
- **音乐句法型**（推自 N3）：节奏由音乐的乐句结构承担——切点落在乐句层级而不是每拍；少数切点故意落在反拍或拍前，制造切分。适合音乐主轴段。
- **单调渐变型**（模型平时不会默认；推自 N1、N3）：全片只有一个方向的变化——间隔从头到尾一路变短或一路变长，没有爆发也没有回落。适合单一元素连续变形、倒计时、沉入式的告别。它没有爆发，不算缺陷。
- **爆发—真空型**（推自 N3、N2）：节奏的重心是一两个**爆发**——一组夺眼的间隔短于一次注视 t，观众无法逐个读，整组被读作一块"质地"；爆发之后紧跟一段明显的真空。爆发位置避开均匀分布的格点。爆发若涉及明暗剧变，受 E2 约束（计数与面积按 E2）。
- **问答型**（推自 N3、N5）：两种节奏交替——一段密、一段疏，像一问一答；每一对里疏的那段长度随内容变，不固定。适合对比、辩论、两个主体轮流出现的内容。

**布局级大变化之间的间隔，观众怎么读**：布局整体改变（画面分区、主物位置、背景空间全换）迫使观众重建"东西在哪"的地图（N5），是代价最大的一种夺眼。观众付了这个代价，会顺手找它的理由，理由只有两个来源（N3）：
- **内容给的信号**：别的通道里刚好有一个"这件事完了"的信号——一句话说完后的停顿、一个问题被答上、一个乐句收住、画面里一个过程到了终点。变化跟在这种信号后面（起点：信号后不晚于一次注视），观众把它读成"进入下一件事"，即结构。
- **时钟**：观众看过两三次变化后，就会用前面的间隔预测下一次（N3）。如果相邻间隔之比 < 1.2（时长辨别的韦伯分数约一到二成，比值 1.2 约为一个辨别阈，再小就分不出长短），观众听到的是"每隔一会儿换一次"，即使每一次都恰好落在想法交界，也会被读成计时器。

由此推出三条：① 每一次布局大变化都要有一个内容信号在它之前不远处（没有就别换，改用局部变化）；② 只有片里有 ≥ 3 次布局大变化时才需要看间隔，相邻间隔比 < 1.2 的连续出现两次就算"像计时"；③ 想法本身长度均匀时，不靠挪时间解决，而是让变化的**幅度**分级——不是每个交界都全换，有的只换分区、有的只换主物位置，让观众从幅度而不是从时钟读出层级。阈值 1.2 「弱证据，待实验」，可并入第 18 章 X1 的档位实验。

**镜头结束方式也要轮换**：同一种收尾（每镜都推进后切、都淡出）连用会形成第二层单调，即使镜长有变化。

### 10.3 静止是休息还是死机（Q12，「分歧·待实验」）
两端都同意：静止必须是设计出来的停留，而不是没东西可做。分歧的核心是一个感知问题：**极缓的运动会不会被观众感知为运动？**
- 运动被察觉，靠的是位移的速度相对于参照物。画面里有静止参照（边框、字、另一层）时，极慢的相对位移也会被看出来；画面整体缓慢移动、没有静止参照时，阈值高得多。
- 换算（Python 复算见附录"r5 计算复核"E-2）：手机竖屏 1080px 宽、屏宽 68mm、30cm 观看时，1px 约 0.72 角分。有参照时，每秒约 1–3 角分的相对位移已接近可察觉，也就是每秒约 1.4–4.2px（r4 写成 2–4px，下沿算粗了）。

两端因此各有道理：
- **真静止**（推自 N3）：只要画面里有字或框这类静止参照，每秒几像素的漂移就会被察觉，休息就不再是休息；爆发与休息的对比因此被削弱。所以休息必须真的不动。静止的总量由内容推出：全片静止时长 ≈ 全部关键信息的确认注视之和 + 爆发后的真空。适合有爆发对比的发布片、喜剧的包袱后停顿、需要"让它落地"的结论。
- **极缓呼吸**（推自 N6、N5）：观众在听人说话时，注意在声音上，不在画面的位移上；一层低于察觉阈的空间运动不会被感知为"在动"，但能消除画面像静止画布的感觉。做法：用层间视差平移（不用整体缩放），背景层相对前景层的速度控制在**每秒 ≤ 1px**（竖屏 1080 宽，约 0.72 角分/s，低于上面察觉区间的下沿 1 角分/s；r4 的 2px/s 约 1.44 角分/s，正落在区间里，不能叫"低于察觉阈"），需要亚像素渲染才平滑；一镜总漂移不设定额，由镜长 × 速度给出。察觉区间本身「弱证据，待实验」，对照实验见第 18.1 节。适合口播、讲解、长停留的证据画面。
- **分层静止**（模型平时不会默认；推自 N2）：静止按层分配——主体与相机完全静止，只有环境层里一个极低能量的东西在变（光、尘、远处的车）；或反过来，环境冻结，只有主体在动。观众的焦点层是"静"的。
- **只让声音动**：画面完全静止，时间由声音推进（脚步、钟、呼吸）。适合紧张、等待、悬疑。

**判别是否"死机"**：静止中，观众是否知道自己在等什么或在看什么。知道 = 休息；不知道 = 死机。

### 10.4 故意违反
- 所有镜头等长：得到机械、仪式、监视器感，适合表现重复劳动、制度、监控的题材。
- 全片无静止：得到窒息、焦虑、追逐，适合短的、要表现"停不下来"的内容。

### 10.5 失败点预判
- 节奏检查全过，但夺眼的都是装饰性运动。提前发现：间隔序列旁边并列一栏"这次夺眼带来了什么"，空着的占多少。
- 每个停留都在缓慢运动，没有真正的休息。提前发现：统计用了缓慢运动的镜头占比，并问每一次的理由。
- 处处在呼吸（光晕脉动、扫光），口播片发抖。提前发现：关掉主体只看环境层，它是否比主体还热闹。

### 10.6 自检
- 〔测〕镜长有几档？相邻档之比的最小值 = ?（长短档位型 ≥ 1.4）
- 〔测〕极缓呼吸取向：任何层相对静止参照的速度最大值 = ?（≤ 1px/s @1080 宽，≈ 0.72 角分/s）；真静止取向：静止段内的像素差分是否为 0？
- 〔测〕每次布局大变化之前一次注视内，有没有一个内容信号（话停、问题答上、乐句收、过程到终点）？≥ 3 次变化时，相邻间隔比 < 1.2 是否连续出现两次？每段静止，观众知道自己在等什么吗？

## 第 11 章 一镜之内：注意力预算与进退场（Q16、Q17）

### 11.1 推导
视觉注意是串行的（N2）：多个同时运动互相抢，错峰把并行信息变成可逐个读的序列。凌乱往往不是哪个动作错了，而是没有预算。

**计数口径**：按"组"计，不按个数计。共同命运（同向、同速、同时）的一群元素算一组。

**层按注意的角色分，不按前后景分**：画面里每一样东西，在每一时刻都处于三种角色之一——
- **正被看**：当前焦点，同一时刻只有一组。
- **等着被看**：已经出现、之后还会再用到，或观众需要它作参照的东西。它在场但不动，对比比焦点低一档。
- **不必看**：环境、底子、质感。它可以活着，但能量必须低到不会夺眼（第 10.1 节的判据）。
"背景是什么"因此不是一个单独要填的栏目：它要么属于"不必看"（就按低能量要求处理），要么在某一刻变成了焦点（那它就是事件的一部分）。没有归属的东西，删掉。

**冻结测试**（检验每个动作是否在服务焦点）：在预览里把某个元素单独冻结，重看这一镜。观众（或作者以第一次看的心态）失去了什么必须知道的东西吗？没失去，这个动作是装饰——要么删，要么归入"不必看"并降到低能量。

**旧焦点怎么处理**：焦点交接时，旧焦点退到"等着被看"——停下、对比降一档、留在原位。新焦点进场的落点不能与它重叠，否则两者相撞。下文把这个状态简称"待用"：它被降级是因为观众此刻不需要它，不是因为它没用了。

### 11.2 预算的四种取向
- **单焦点接力**（推自 N2）：任一时刻只有一组在动；其余处于待用或不在场。配合者的运动必须与焦点同向、同时，被并入焦点那一组。在场的组数上限取 4（工作记忆的块数），超过就要有组退场或合并。「弱证据，待实验」（对照实验见第 18 章 X2）适合讲解、产品、口播。
- **群体当一块**（推自 N2、N6）：画面主体本身就是群体（人群、鸟群、数据点云），预算按"群体的整体行为"计——群体聚、散、转向是事件，个体运动是质地。条件：群体里如果有一个"主角个体"，它必须在对比上明显跳出。
- **双焦点对照**（推自 N2、N3）：两组轮流动，永远一组动、一组待用，交替的节奏就是比较的节奏。适合"前后""两种做法""你与它"。条件：两组的位置在全镜固定，观众的视线在两个落脚点之间来回，不用找。
- **满屏探索**（模型平时不会默认；推自 N3、N4）：故意满屏高密度（风格词汇库 S18 报纸版面、S88 网格墙是可能的外观），让观众自己探索。条件有二：必须有一个对比最高的入口；停留时长按"探索"而不是"读完"计——入口的 R 加上观众能自选看两三处的时间，必要信息只放在入口。

**视线路径**：从当前焦点到下一个焦点之间的连线上，不放高对比元素——眼睛要沿着这条路走，路上有东西就会被截走。

### 11.3 进场：画面单位怎么对应论证单位（Q17）
口播或文字的论证由**论点**组成，一个论点下面有若干支撑句。画面也有单位：一个**布局**（东西摆在哪）和布局里的**变化**。最直接的对应是：一个论点 = 一个布局；支撑句 = 这个布局内部的变化。由此推出：
- 新元素进场挂在论点的开始上，不挂在每一句上。机械的"一句一个新元素"是堆积型凌乱的根源。
- **转折句归哪边**：不预设。看它说的新东西指向哪里——
  - 它在**引出后面**（"但真正的问题是……"）：它开启下一个布局，旧布局在它之前清场。
  - 它在**给前面下结论**（"所以前面这些都没用"）：它属于当前布局，画面在原地做一个反应（变暗、塌掉、被划掉），然后才切。
  - 判据：把转折句删掉，哪一边的画面更难懂，它就属于哪一边。

四种进场取向：
- **论点换布局**（推自 N1、N2）：只在论点边界换布局、进新元素；支撑句只让已有元素响应。
- **逐词响应、不逐词进场**（推自 N2、N4）：每个关键词都有画面响应，但响应是已有元素的变化（高亮、变形、移动），不是新元素。口播的颗粒度对上了，画面元素的数量却不增长。
- **预告显形**（模型平时不会默认；推自 N3）：元素提前以低权重状态出现（轮廓、虚影、局部），到提示点才"兑现"成完整状态。得到"承诺—兑现"的期待感，代价是削弱落点的冲击。适合多步骤流程、观众需要提前知道"一共有几步"的内容。
- **跟着上一步完成进场**（推自 N1）：没有口播时，新元素在上一个动作完成的那一刻进场，因果本身就是提示。

### 11.4 离场与镜头边界
- **出点保护**：本镜最后一个事件落定后，到切点之间至少留出观众确认它的时间 = (落眼数 + 1) × t × c（第 9.1 节的符号）。更近，动作被转场吞掉。
- **开镜空窗**：开镜后第一个事件不晚于观众完成重新定位 r（第 5.1 节，约 0.75s）。更晚，观众会觉得"这镜在等什么"。
- **字和画怎么收**：先变的那个会把视线拉走（N2）。所以字幕不早于它描述的画面事件消失——字先走，眼睛会跟着离开画面。字幕可以与画面事件同时收，或晚收，晚收不超过一次注视 t。

### 11.5 故意违反
所有元素同时、满屏地出现，没有焦点：得到"淹没、过载、压迫"，适合表现信息爆炸、焦虑、群体噪音。持续时长要短于一个 R，并且之后立刻给出一个单焦点画面作为对照。

### 11.6 失败点预判
- 满屏同时弹入；说到后面满屏静物没人退场；切点时还有东西在入场；元素比它的词早很久显形（不是有意的预告显形）。提前发现：从时间表自动统计每一时刻"在动的组数"和"在场的组数"；列出每个进场所挂的提示。

### 11.7 自检
- 〔测〕任一时刻在动的组数最大值 = ?（单焦点接力为 1）；在场组数最大值 = ?
- 〔测〕每镜最后事件到切点的距离 ≥ (落眼数 + 1) × t × c 吗？开镜第一个事件 ≤ 0.75s 吗？字幕早于画面事件消失的次数 = ?（应为 0）
- 每一个动作都过了冻结测试吗？

## 第 12 章 全片层面：轮换与"像幻灯片"（Q13、Q14）

### 12.1 推导
单镜质检看不见全片节奏：同一个动作连用，观众就感到节拍器（N3）。但每镜换一种画风会变成拼贴，因为观众要不断重新识别"这是什么世界"（N5）。所以要分开决定：**哪些东西告诉观众"还是同一个世界"，就让它们统一；哪些东西告诉观众"这里有新东西"，就让它们轮换。**

### 12.2 哪层变、哪层统一，用什么形式检查（Q13）
**按"它在告诉观众什么"分三层**：
- **身份层**——告诉观众"还是这个世界"：画面是用什么材料做的、光从哪来、字长什么样、颜色各自代表什么。全片统一（例外：片子的主题就是"换世界"）。
- **排布层**——告诉观众"这一镜的东西在哪、多大"：主物位置、主物尺度、画面分区。轮换的主战场。
- **观看层**——告诉观众"我们怎么看它"：相机动作、呈现容器（截图、实物、图示、角色）、收尾方式。只在内容的关系变了时才换（例如从"看一个东西"变成"比较两个东西"），不为变化而变化。

**检查的形式**：
- **打乱重排**（推自 N3、N5）：把每镜的中间帧打印或排成一排缩略图，打乱顺序，请一个没看过的人把它们排回去。排得回去，说明每镜都有可辨的位置（排布层在动、而且和叙事挂钩）；排不回、而且好几张互相替换也说得通，说明排布层没有轮换，或者轮换是随机的。
- **一栏一栏读**（推自 N3）：把逐行表的"排布"一栏单独抽出来从上往下读，只看这一栏。相邻两行取同值，必须能说出"因为它们是同一个连续动作"；说不出就换。观看层同样单独读一遍。
- **只看身份层**（推自 N5）：把每镜缩到极小、模糊到看不清内容，只剩材料与颜色。这一排应该看起来像一个系列；若有一张跳出来，它的身份层漂了。

**轮换的四种取向**：
- **按内容关系定排布**（推自 N1、N2）：排布不随机轮换，而是绑定内容关系——对比永远左右分、步骤永远一条路径、因果永远上下、数量永远尺寸。轮换由内容结构产生，观众学会"这种排布意味着这种关系"后，读取更快。
- **一个母题内部变**（推自 N5、N3；风格词汇库 S85 单一母题系统是一种外观）：全片只用一个母题（一个形状、一种容器、一个排布），变化发生在母题内部——尺寸、数量、方向、状态逐镜不同。判据：观众能说出母题在每一镜里变了什么；说不出，就只是重复。
- **只动尺度**（模型平时不会默认；推自 N6）：排布的位置全片几乎不变，只有主物的尺度在变——从很小到填满画框再到很小。轮换完全由距离承担，同时成为情绪弧的载体（第 4.1 节）。
- **占比上限**（推自 N3）：对排布层的每一个变量，任何一种取值的全片占比不超过 2/k（k 为取值种类数，即均匀分布的两倍）。最机械，但最容易检查；适合镜头数多的讲解片。

### 12.3 "像幻灯片"：先说清这个心理模型（Q14）
观众脑中的"幻灯片"是一个具体的东西。把它拆开，它由这些成分组成：
1. 内容装在一页一页**离散的页面**上，翻页 = 整页被**替换**。
2. 每次翻页由一个**外部动作**触发（点一下），翻页之间的间隔差不多。
3. 页框**固定**：页面不动，我们也不动，没有一个"空间"。
4. 页面上的东西是**一条一条加上去**的，加上去之后就**不再变**。
5. 讲的人在**页面之外**；页面只是插图，真正的意思在声音里。
6. 页面上是**字和示意图**，不是真的东西。

这六个成分按"在哪里能查出来"归成三类，用于诊断：
- **时间上的**（成分 1 的"替换"、成分 2）：能在计划表上查（相邻镜之间有没有留下来的东西、间隔的形状）。
- **空间上的**（成分 1 的"页"、成分 3）：能在计划表上部分查（有无相机层、有无深度），要在成片里确认。
- **意义上的**（成分 4、5、6）：只能在成片里查（"死了"和"在活"只能看出来）。

三类相互独立：节奏全对仍可能像幻灯片，因为空间和意义是另外两类。

### 12.4 治法：从每个成分给观众的感受推出
治法不按三类各配一种，而是逐个成分问：这个成分在场时，观众感到的是什么；他缺的是什么；给他什么就不再有这种感受。观众说"像幻灯片"时，追问"哪一刻最像"，他的回答通常落在下表某一行的"感受"里，就从那一行下手。

| 成分 | 观众感到的 | 观众缺的 | 治法（推自） |
|---|---|---|---|
| 1 整页被替换 | "前一页没了"，每次翻页都要重新认一遍画面 | 跨过边界还认得出的东西 | **留一个过界**：每个边界至少有一个元素活过去并在另一侧换了角色——上一镜的数字成了这一镜的舞台，上一镜的线成了这一镜的路（N5，第 13.2 节） |
| 2 外部触发、间隔均匀 | "有人在按键"，时间是画外的人定的 | 变化的原因在画里 | **让前一件事触发下一件**：推、落、指、碰到——画面里一个事件引起下一个变化；间隔由各自的读取量定（N1、N4，第 8.3、10 章） |
| 3 页框固定 | "我在看一块板" | 自己在某个地方的感觉 | **给观众一个位置**：东西有前后，画框外还有世界，东西从框外进来、越过框边出去；内容够连续时，换"页"变成相机在空间里移动（N5、N6，第 13.4 节） |
| 4 加上去就不再变 | "东西一出现就死了" | 已在场的东西还在乎后来的 | **在场者回应**：新元素进场时，已在场的元素让位、重排、被点亮或被推开，回应完再静下来（N1、N2，第 11.3 节） |
| 5 讲者在页外 | "听就够了，画面可以不看" | 画面里有声音没说的东西 | **画面说声音不说的那一半**：画面承担一个口播没有的量——数字的大小关系、一个后果、一个对比；静音看能得到一部分，闭眼听也只得到一部分（N2、N4，第 15.3 节） |
| 6 字和示意图 | "这不是真的" | 证据 | **换成真东西**：用真实素材、实物、界面替换示意物（N4，第 16.3 节）；没有真素材时，至少让示意物守物理（有重量、会遮挡、会投影），观众读成"一个东西"而不是"一个符号" |

与 r4 的对照：r4 的"长出来"拆进第 1、2 行（留一个过界 + 让前一件事触发下一件，二者的观众感受不同，r4 混在一起）；"给一个世界"对应第 3 行；"让它发生、让它是真的"拆成第 4、5、6 行。治法从 3 种变为 6 种，没有删除。

**统一和变化各自做过头，观众会怎么说、修起来多贵**（R-2 重推）：
- 统一过头：观众说"每一镜都一样""像模板""像在翻 PPT"。病在上表某几行，修法是逐行加东西（过界物、触发、回应），通常不必重做外观，返工量 ≈ 出问题的边界数。
- 变化过头：观众说"乱""像拼起来的""不像一支片"。病在身份层（第 12.2 节）没有守住，修法是把每一镜的外观收回到同一套身份，返工量 ≈ 全部镜头。
- 所以偏向哪一侧是条件题，不是结论：

| 条件 | 偏统一 | 偏变化 |
|---|---|---|
| 片长 | 长片（单调会累积，但乱更难被原谅，先保身份再逐边界加活气） | 短片（单调来不及累积，变化的代价小） |
| 内容类型 | 讲解、论证：观众要跟住同一套符号 | 音乐、情绪、展示：变化本身是内容 |
| 返工成本 | 外观改一次很贵（实拍、手绘、重渲染）：先统一，后按表加活气 | 外观可参数化重生成：变化做错了也能廉价收回 |
| 观看场景 | 小屏、信息流：每镜一眼可认比新鲜更要紧 | 大屏、专注观看：观众有余力处理变化 |

四个条件指向不一致时，以返工成本那一行为准：它决定的是"做错了还修不修得起"。「待实验验证」

### 12.5 故意违反
故意做成幻灯片：固定页框、翻页声、逐条出现。得到讲座感、冷幽默、对"汇报文化"的戏仿，适合讽刺职场、模仿讲座的喜剧。必须做得比真幻灯片更"标准"，观众才会读出是故意的。

### 12.6 失败点预判
- 多数镜头是同一个"人物在角落、素材在中间、文字在一侧"；全片同一个缓推；反向失败是每镜换画风。提前发现：三种检查形式至少跑两种。
- 只修了一类病因就以为好了。提前发现：六个成分各写一句"保留了还是用了哪种治法"。

### 12.7 自检
- 〔测〕打乱重排测试：排错位置的镜头数 ÷ 总镜头数 = ?（起点 ≤ 1/4）
- 〔测〕排布栏里相邻同值、却说不出是同一连续动作的次数 = ?（应为 0）
- 六个成分里，这支片还保留了哪几个？保留的每一个是有意的吗？

## 第 13 章 边界：承接、转场与连续空间（Q19、Q20、Q21、Q22）

### 13.1 推导
大脑把"同一个东西在变"读作连续事件，把"一个东西被换掉"读作翻页（N5）。翻页要付重新定位的成本 r（第 5.1 节）。所以每一个边界都要先回答：**这里要观众感到"继续"，还是要他感到"换了"？** 要继续，就给他一个能在边界两侧认出来的东西；要换，就干脆地换，并且让换本身有意义。

### 13.2 观众凭什么在两侧认出"同一个"（Q19）
连续感来自观众在下一帧里找到上一帧的某个东西（N5）。能被找到的东西分五种，按"认出的是什么"分：
- **认出同一个物**（推自 N5）：同一个物跨过边界，在下一镜里换了角色（主角变背景、工具变容器、局部变整体）。条件：边界那一刻它在画内且是那一刻的焦点。
- **认出同一个运动**（推自 N5）：物换了，运动没断——上一镜向右甩出的手，下一镜里一辆车以同样的方向和速度继续向右。观众追踪的是运动本身。条件：方向一致，速度差 ≤ 约 15%（与第 7.3 节同一前提）。
- **认出同一个形状**（推自 N5、N3）：上一镜结尾的一个圆，在下一镜成了另一个圆的东西（一个盘子变成一个月亮）。形状相同、物不同，观众同时感到"连上了"和"变了"。
- **认出一个后果**（推自 N1、N5）：上一镜的动作在下一镜产生结果（第 8.3 节"上一镜即原因"）。跨过去的是因果，不是物。
- **认出同一个声音**（模型平时不会默认；推自 N5、N2）：画面硬切，但声音跨过切点——下一镜的声音提前进入，或上一镜的声音延续。连续感由听觉维持，画面可以大胆换世界。

**什么时候不该承接，直接切**：当翻页本身就是要传达的东西时——话题真的结束了（承接会假装它们相关）；需要一记冲击（承接会把它缓冲掉）；一段由很多一眼可读的镜头组成的密切段（每次都承接，观众反而在追踪上累死）。硬切越少，它越响（N3）。

**多元素拼成的承接**（几个小元素一起跨过边界）：观众追踪的是"一个东西"，几个碎片很可能不被读作承接。判据：边界前后两帧并排，没看过的人能不能指出"同一个东西"。「弱证据，待实验」

### 13.3 转场：用什么占住注意、占多久（Q20，「分歧·待实验」）
**藏住剪刀的原理**：注意被占住时，对画面其余部分的变化不敏感。所以要问的是：什么能占住注意、能占多久？
- **一次突然的强变化**（亮度突变、大物体突然出现）会把注意抓过去，但只占约一次注视（约 0.25s）。切换必须在这个窗口里完成，晚了观众已经回过神。
- **一个正在被追踪的快速运动**：只要观众的眼睛在追它，画面别处的变化就不太被察觉；占住的时长 = 运动持续的时长。
- **一次完全遮挡**：遮挡期间画面根本看不见；必须真的完全覆盖，露缝即穿帮。
- **语言的重音**：听者在处理一个重读词时，对画面变化的敏感度下降，但程度较弱，只能藏小的变化。

**和口播停顿的关系**：不预设"切在停顿处"。按目的定——
- 想**藏住**切点：放在口播仍在进行的时候，最好在重读词上。停顿时听觉通道是空的，注意全在画面上，切点反而最显眼。
- 想**标出**切点（新段落开始）：放在停顿里，切点就是段落标点。

**稀缺型转场绑定什么**：一个强烈的转场本身就是一个大的夺眼，观众会把它读作"这里很重要"（N3：被强调 = 被承诺）。所以它只能用在两种地方：全片最大的那一两个边界；以及转场的物理含义与这一刻的内容含义一致的地方（烧掉 = 毁灭，冲进水里 = 沉入）。含义对不上的强转场，是在空口许诺。

**光敏底线**：一次闪白或闪黑（暗→亮→暗、亮→暗→亮）本身就是一对相反变化，计一次闪烁；单向的亮暗急变只是一次变化，要和下一次反向变化配对才成一次闪烁——配对、窗口、红闪判据都按 E2，不在这里另算。用这类手法藏剪刀，若按 E2 脚本某 1 秒超过 3 次、且同时闪烁面积超过 E2 表里的上限，就改用遮挡或运动来藏。

**四种取向**：
- **一套语法贯穿**（推自 N5）：全片只用一种有意义的转场，重复让它成为这支片的语言。适合系统感、品牌、单一隐喻。风险：退化成通用淡化那样的"没有设计"——区分在于这种转场是否属于这个故事。
- **按接缝变化**（推自 N3）：每个接缝按它的关系选转场。适合多段落、多关系的讲解片。风险：手法轮番上，读作炫技。
- **大多数硬切 + 少数转场**（推自 N3）：这一取向内部以硬切为常态，只在**结构点**上用转场，转场本身成为标点。用几个由片子推出：结构点 = 段落交界数（段落数 − 1）；转场数 ≤ 结构点数，并且 ≤ 第 4.3 节算出的大转折上限加上段落交界里"话题真断"的那几个——转场多于观众能读成"重要"的次数，就不再是标点。4 段的片最多 3 处，1 段到底的片为 0。
- **只让声音转场**（模型平时不会默认；推自 N5、N2）：画面全部硬切，所有"转场"由声音完成——一个声音跨过切点、一段混响的尾巴、环境声的交叉。画面利落，听感连贯。

**转场时长**：从相邻两镜的富余里借（富余 = 镜长 − ΣR）。富余不够，就没有资格做长转场，换成硬切或承接。转场时长是结果，不是选项。转场里不许出现空白帧。

**一个接缝只用一种手法**：叠加多种（闪白 + 震动 + 声效 + 模糊）不会更强，只会让观众不知道该看哪个。

### 13.4 一镜到底与连续空间（Q21）
- **适用**：内容本身有空间、流程、时间线或尺度隐喻。叙事顺序 = 空间路径。
- **新内容何时成形**：若内容在相机运动中成形，观众要同时看"相机在走"和"东西在长"两件事（N2）。两种做法：
  - **先到后成形**：相机到站、停稳，内容才开始成形——成形本身就是这一站的事件。
  - **早已成形、走近才读得清**：内容一直完整地在那里，只是太远、太小而读不清；相机走近时它自然变得可读，不需要额外的动作。
- **相邻内容的间距**：判据不用距离，用可读性——在每一站的停留帧里，相邻一站的文字或必读细节要么在画外，要么小到读不出（高度 < 第 15.1 节最小必读高度的一半）。半读得出最糟，观众的眼睛会被它拉走。
- **行进速度**：移动中需要读的内容，相机速度 ≤ 约 1 屏宽/秒；移动中无需读，可到约 2 屏宽/秒。推导：手机观看时画面约占 13° 视角，平滑追踪约在每秒 30° 以内可靠，即约 2 屏宽/秒为追踪上限；要同时阅读，取一半。「弱证据，待实验」
- **节奏来源**：连续空间里没有切点，节奏只能靠速度变化与停留——在站点停下，就是一次"切"。
- 不必全片一镜：可以整幕连续，幕间仍用转场。

### 13.5 多场景连续性（Q22，「弱证据，待实验」）
原理：并行制作者看不到彼此，一致性的来源越依赖"各自的理解"，漂移越大。所以取向按"一致性来自哪里"分：
- **来自同一份实现**（推自 N5）：角色、道具、场景配色写成一个共享模块，各场调用，不按描述各自重画。漂移最小，前期成本最高。
- **来自可测的规格**（推自 N4）：不共享实现，但把一致性写成可以测量的条目（主色的取值、角色身高与头身比、道具的轮廓），每场渲染后自动与参考帧比对。适合工具链不同、无法共享代码的多人协作。
- **来自最后一道统一手**（推自 N5）：各场自由做，最后由一个人（或一个 agent）把所有场的共享元素统一重描一遍。适合前期需要快速探索、后期才收敛的项目。代价是最后一道的工作量。
- **有意不一致**（模型平时不会默认；推自 N3）：每场一个世界，不一致本身就是结构——选集、梦境、多个讲述者。条件：每场内部必须一致，场与场之间的差异要大到一眼看出是故意的。

**质量标杆何时确立**：两端都可以——先把一小段做到最终质量再铺开（早具体化、少返工，但可能在错误的方向上精雕）；或先做全片粗样确认结构，再挑一段做标杆（方向更稳，但前期的粗样可能误导需求方对质量的判断）。按需求方是更怕方向错还是更怕质量差来选。「待实验验证」

**场景边界的交接**：每个场景边界写清上一场结束于什么（物、位置、方向、光），下一场开始于什么。

**屏幕方向**：主体向右走，下一镜还向右；方向翻转要有可见的理由（转身、一个反打镜头）。

### 13.6 故意违反
每个切点都跳到完全不相连的世界，不承接也不转场。得到拼贴、梦境、意识流，适合回忆、超现实、"信息碎片"主题。必须全片一致。

### 13.7 失败点预判
- 遮挡露缝；为藏剪刀的切点却放在了口播停顿里；连续世界中主体被甩出画外；同一道具两场画得不一样；左右交替导致频繁越轴。提前发现：每个边界列出"继续还是换了"以及理由；连续空间里逐帧检查主体是否始终在画内。

### 13.8 自检
- 〔测〕无理由的边界数 = ?（应为 0）转场时长都 ≤ 相邻镜的富余吗？
- 〔测〕按 E2 脚本：任意 1 秒内一般闪烁、红闪各 ≤ 3 次吗？超出的那几秒，同时闪烁面积峰值低于 E2 表里的上限吗？
- 〔测〕一镜到底的每个停留帧里，相邻站的必读细节高度 < 最小必读高度的一半，或在画外吗？

## 第 14 章 相机：何时动、像谁在拿、跟不跟拍、表达什么（Q23、Q24、Q25、Q26）

### 14.1 推导
相机的首要职责是让观众看清（N4）；画面自身在动、观众在读字时，相机运动会抢注意（N2）。相机重音像文中加粗，处处加粗等于没有重点（N3）。相机同时也是观众的身体：它靠近、后退、停下、环绕，观众就产生对应的身体性感受（N6）。

### 14.2 什么时候动、动多少（Q23，分歧维度是片种）
**检验方式：锁机对照**。把这一镜在相机锁死的状态下渲染一版，和动的版本并排看。锁死版里观众失去了什么必须知道的东西吗（看不清了、不知道两者的关系了、跟丢了主体）？什么都没失去，这次运动删掉。失去的是"感受"而不是"信息"时，它属于情绪运镜（第 14.5 节），按那一节的稀缺规则计数。

**相邻相机动作的哪些组合会出问题**——从观众的感知推：
- **被感知为抵消**：两次相邻运动方向相反、幅度相近，合起来几乎回到原处（推近后立刻拉回、左移后立刻右移）。观众感到的是"晃了一下"，不是两个动作。判据：相邻两次运动的净位移 < 两次位移绝对值之和的 1/5 时报警。
- **被感知为重复**：同一种运动、同一方向连续出现，且没有内容上的理由。第三次出现时观众确认"这是规律"，开始等下一下而不是看内容（N3）。所以同方向同类运动不连续三次（推导见附录）。
- **被感知为越轴**：横向运动左右交替，主体在屏幕上的方向反复翻转（第 13.5 节屏幕方向）。

**全片要不要一个独有的运镜**：不是必需。只有当这支片的峰值（第 4.2 节）选择突破的维度恰好是"相机"时，才需要一个全片只出现一次的相机动作；峰值突破的是别的维度时，相机在峰值处反而应该让位。

**四种密度取向**：
- **不动相机**（推自 N2、N4）：相机全片或几乎全片固定，所有运动由内容承担。适合口播、证据、精密图解、静物美学。唯一的一次运动因此成为全片最大的重音。
- **有理由的少数**（推自 N3、N4）：每次运动都通过锁机对照；重音运动（快、大、出乎意料的那种）的次数 ≤ 全片转折点与峰值的数目之和。
- **只在边界动**（模型平时不会默认；推自 N5、N2）：镜头内部相机完全静止，相机运动只出现在镜头之间，作为承接（推进容器、跟随运动穿过边界）。观众在读的时候画面稳，在换的时候被带着走。
- **相机即叙述者**（推自 N6、N5）：相机始终在动，像一个在场景里走动的人，它的停、转、靠近就是叙事本身（与一镜到底配合）。适合沉浸、探索、第一人称题材。条件：揭示与读字时刻相机必须停稳。

**素材自身在动时相机让位**：录像、动画、主体在大幅运动时，相机不再叠加运动。

### 14.3 掌镜感：观众怎么推断"有人在拿"（Q24）
观众看不见掌镜的人，只能从画框的运动反推（N6：看到另一个主体的反应才有情绪；这里的"主体"就是看不见的掌镜者）。反推出来的有两样东西：**一个有意图的心**（他想看什么、他预判了什么、他在意构图），和**一个有重量的身体**（他站在哪里、他有多重、他是活的）。所以按"这个运动特征让观众推断出心还是身"来分，每种特征写出观众会读出的意图，再按片子要的掌镜者性格挑。

**读出"心"的三种特征**
- **画框跟着谁的事件走**（推自 N2、N6）：画框的位置与运动，和某一个主体的显著事件相关，与其他主体无关——那个主体一抬头，画框就偏过去；另一个主体再动，画框不理。观众读出"他在看那个"，即注意的偏好。机器的特征是画框只跟几何（中心、包围盒）走，与事件无关。做法：有两个以上主体时，画框的偏移只响应其中一个主体的事件。
- **画框和主体的相位**（推自 N6、N3）：画框的运动相对主体是落后、超前还是同步，读出的意图不同。
  - 落后：读作"在跟"，他没料到、在追。临界阻尼（不过冲），起点滞后约 0.2s（人的视觉跟踪反应时间量级），主体减速时画框追上。「弱证据，待实验」（对照实验见第 18 章 X3）
  - 超前：画框先到主体将要到的位置，读作"他预判了"，适合体育、动作、精准感。
  - 同步（零相位）：没有可推断的心，读作机器、轨道、监视器。适合产品、科学，也适合"被监视"的题材。
- **误差之后朝着构图去的纠正**（推自 N6）：主体停稳后，画框做一次小而慢的移动，而且方向是让构图变得更平衡（主体往三分处或中心靠、地平线变平）。观众读出"他在意这个画面"。关键在方向：纠正的方向和构图改善一致才读成意图；方向随机就只是抖。

**读出"身"的三种特征**
- **质量**（推自 N5）：一个有重量的身体拿着相机，起步要加速、停下要减速，方向不能瞬间反转。观众读出的是"有一个物理的身体"，不涉及意图。做法：相机加速度设上限，方向改变必须先减速。
- **可达**（模型平时不会默认；推自 N5、N6）：画框的位置和路径只走人能到的地方——眼高或手持高度、绕过而不是穿过物体、过门要侧身、上不去的地方用仰拍代替。观众读出"有人站在那里"。穿墙、贴地飞行、从不可能的高度俯瞰，读作无身体的视点；这也是一种选择，适合梦、监控、全知叙述。
- **生理节律**（「分歧·待实验」）：活着的身体有呼吸和手的细颤，表现为无周期重复的低频微动。加：幅度小于最小文字字高，停留时归零（否则没有真休息）；不加：靠上面五种特征已足够，产品与口播片一般不加。

| r4 部件 | r5 新轴里的位置 | 变化 |
|---|---|---|
| 取舍 | 心 · 画框跟着谁的事件走 | 从"画框偏向一方"改为"偏移只响应一个主体的事件"，判据从构图位置变成相关性 |
| 时差（晚到 / 早到 / 零时差） | 心 · 画框和主体的相位 | 三档保留，各补观众读出的意图 |
| 修正 | 心 · 误差之后朝着构图去的纠正 | 补"方向与构图改善一致"这一判据，与抖动分开 |
| 惯性 | 身 · 质量 | 明确只读出身体，不读出意图 |
| 要不要加抖动（分歧） | 身 · 生理节律（分歧保留） | 两端都保留 |
| （无） | 身 · 可达 | 新轴推出的新特征 |

**三条前提，与特征无关**：
- **参照物**：空背景上看不出相机在动。要让观众感到相机运动，画面里必须有深度或纹理参照。
- **操作时刻先停稳**：点击、揭示的那一刻相机已经静止。
- **主体不出画**：逐帧检查主体包围盒是否始终在画框内（这项常被其他检查漏掉）。

### 14.4 相机与节拍：拍点由哪种属性承载（Q25）
画面对拍点的响应可以改变很多属性：位置、尺度、角度、速度、亮度、清晰度、颜色。选择的依据是：**承载拍点的属性每拍都在变，它就不能是决定"东西在哪"的属性**——位置和尺度每拍改一次，等于每拍重新构图，空间感和方向感都会断（N5），左右摆还会反复越轴。由此推出四种取向：
- **起止对拍、冲击留给结构点**（推自 N3）：相机的起止点落在拍上，但大冲击（整画面的跳、震、砸）只留给少数结构点——每拍都砸就是节拍频率的画面抖动。
- **拍点交给不改空间的属性**（推自 N5）：拍点由亮度、清晰度、颜色或运动速度的变化承载，空间布局一段内不变。用亮度脉冲时要算 E2：每拍一次"亮—暗"（升再降，一对相反变化）就是一次闪烁，曲速 120 BPM 时每秒 2 次，180 BPM 时每秒 3 次已到上限，更快的曲子要么降低亮度变化幅度到 0.1 以下（或让暗侧也 ≥ 0.80），要么隔拍响应，要么把脉冲区域压到 E2 表里的面积上限以内。
- **主体层响应、相机不动**（推自 N2）：拍点全部由画面里的元素响应，相机作为稳定的参照。适合音乐里有人声或画面有文字的段落。
- **只在乐句边界响应**（模型平时不会默认；推自 N3）：拍内不做任何响应，只在乐句交界处做一次变化。画面的节奏比音乐慢一个层级，观众感到"在呼吸"而不是"在跳"。适合抒情、慢热、需要观众读东西的音乐段。

音效：密集音乐已提供时间纹理，切点不必每个都加声效；稀疏的声轨反而需要切点有声。

### 14.5 相机怎样表达情绪（Q26，「弱证据，待实验」：单家孤证）
相机替观众做出身体动作（N6）。我从"人在空间里的身体关系"推出对应，不从清单出发。每一行是一个空间维度，两端各对应一种感受：

| 空间维度 | 一端 → 感受 | 另一端 → 感受 |
|---|---|---|
| 距离的变化 | 慢慢靠近 → 亲近、关注 | 快速逼近 → 威胁、冲击 |
| 高度 | 从下往上看主体 → 主体强大、敬畏 | 从上往下看主体 → 主体脆弱、渺小 |
| 画框里的余地 | 余地越来越少 → 压迫、被困 | 余地突然变大 → 释放、松一口气 |
| 相机是否陪着主体 | 主体走，相机一直跟 → 忠诚、陪伴 | 主体走，相机留在原地 → 告别、被留下 |
| 相机的稳定 | 稳 → 安全、确定 | 不肯停稳 → 不安 |
| 绕着看 | 慢慢绕 → 端详、审视 | — |

用法：
- 情绪运镜的次数 = 全片情绪转折的次数，通常极少；多了就是另一种炫技。
- 与峰值匹配：若峰值（第 4.2 节）突破的是"距离"或"余地"维度，情绪运镜就用同一个维度，方向一致；两者用不同维度时，情绪运镜不放在峰值处，免得两种手段争抢。
- 绕着看时，画面里的平面元素在大角度下会露出"是平的"；绕的角度上限由画面里最平的那个必读元素决定：它被压缩到读不清之前就停。

### 14.6 故意违反
相机始终不看重点——主体在画框边缘、相机对着无关的东西，主体只露出一部分。得到偷窥、纪实、"我们不该在这里"的感觉，适合伪纪录、心理恐怖（风格词汇库 S68 是一种外观）。

### 14.7 失败点预判
- 一支片几十次全往里推；每镜匀速慢推；念到一个名词就推一次；主体被甩出画外；停留中仍在漂浮。提前发现：从时间表列出每次相机运动、它的锁机对照结论、方向序列。

### 14.8 自检
- 〔测〕没通过锁机对照却保留的运动数 = ?（应为 0）重音运动数 ≤ 结构点数吗？
- 〔测〕相邻运动净位移 < 两者之和 1/5 的对数 = ?（应为 0）揭示与操作时刻相机速度 = 0 吗？主体包围盒出画的帧数 = ?（应为 0）
- 〔测〕用亮度承载拍点时，按 E2 脚本任意 1 秒内的闪烁次数 ≤ 3 吗（或同时面积低于上限）？

## 第 15 章 取景与文字：主体多大、意思靠谁讲（Q27、Q32）

### 15.1 推导
取景的首要职责是可读（N4）：一个元素缩到观众看不清，它的动效根本不存在。另一方面，尺度本身就是情绪（N6）：大到填满画框的物让人感到逼近，小在大留白里的物让人感到孤单或安静。文字是第二个阅读任务，会和画面抢注意（N2）；但讲解片里文字又是听觉信息的视觉对位物，静音观众只能靠它（N4）。

**最小必读高度**：观众可以停下来细看的细节，约 0.5° 视角即可辨认；手机 30–35cm 观看时约 3mm。竖屏可视高按 121mm（68mm 宽、9:16）计，3mm ≈ H/40。一瞥就要读懂的钩子字更大（第 6.2 节，W/15）。

**安全边距**：手机屏的圆角半径约 4–5mm，加上手指与保护壳的遮挡，离左右边 4.5mm 以内的内容有被切或被挡的风险。4.5mm ÷ 68mm ≈ 1/15，所以文字与必读元素离左右边 ≥ W/15（1080 宽约 72px）。上下边另加平台界面的遮挡区，按平台实测。

### 15.2 主体多大（Q27，「分歧·待实验」：主体要大 vs 小元素大留白，分歧维度是片种与信息密度）
不定比例，从"必须读清的最小细节"和"这一刻要观众感到什么"两头推：
- **细节决定尺度**（推自 N4）：找出这一镜里观众必须看清的最小细节（一个按钮的字、一个表情、一根指针），让它 ≥ 最小必读高度。主体的尺寸由此倒推，而不是先定"主体占多少"。「弱证据，待实验」
- **大主体、出画框**（推自 N6、N4）：主体大到被画框裁掉一部分，暗示画框外还有更多。适合产品、物证、"近看"的力量感。
- **小主体、大留白**（推自 N6、N3）：主体小，四周是有意义的空（天空、墙、空房间）。适合孤独、安静、尺度对比、诗性。条件：主体是唯一的高对比物；这一镜里没有需要读清的细节。
- **满幅无主体**（模型平时不会默认）：画面被一种纹理或图案铺满，没有单一主体，主体是"这一整片"。适合材料、规模、质地。纹理若在动（颗粒、噪点、细棋盘、闪烁的点阵），光敏检查按 E2 的细密均衡例外先排除元素小于 0.1° 的区域（手机约 6.9px、桌面约 4.4px）；元素更粗、或明暗不均衡的整片闪动不享受例外，照常计数。
- **尺度随弧变**（推自 N6、N3）：主体在全片里的尺度本身就是情绪弧的可见量（第 4.1 节）——从小到大，或从大到小，峰值处突破全片的尺度范围。

**什么可以被裁、什么不能**：观众会自动补全画框外"猜得出来"的部分（重复的、对称的、熟悉的形状、填充物），裁掉它们只增加"画外还有"的感觉，不损失信息。猜不出来的部分不能裁：要读的字、可操作的控件和它的目标、结果、以及**带信息的边缘**（图表的轴端、一段文字的最后一个字、物体的轮廓决定了它是什么的那一段）。判据：被裁掉的那一部分，观众能不能准确说出它是什么样。

**位置要么对齐、要么明显不对齐**：两个边缘的位置差很小但不为零，观众会读成"没对齐"的失误。所以两条边要么对齐（差 ≤ 1px），要么错开到一眼看出是故意的（差 ≥ 2 倍最小必读高度）。落在两者之间的，改到其中一端。

**远近的分工**：一个关系的所有参与者都必须同时在画框里，关系才看得见。所以取景选**能装下当前关系全部参与者的最紧的那一档**：讲一个东西的状态，可以近到只剩它；讲两个东西的关系，就退到两者都在。页面缩成缩略图时，要么推近到一个组件，要么只取那个组件。

**风格化机位用在哪**：倾斜和仰俯会让平面在一个方向上被压缩，压缩比约为倾角的余弦。所以作用范围按可读性逐镜算：机位倾斜后，这一镜的必读细节在被压缩的方向上仍 ≥ 最小必读高度，就可以用；不够，就回到正面平视。没有必读细节的叙事镜可以大胆用。参考图描述的是一类镜头，不是对全片每一镜的机位规定。

**竖屏**：主体重心放在画面上半到中部（下部常被平台的字幕、按钮遮挡）；上下分区比左右分区更自然；纵向运动是竖屏的主运动方向。「待实验验证」

### 15.3 意思靠画面还是文字（Q32，「分歧·待实验」）
- **画面承载、文字补充**（推自 N2、N6）：意思在画面机制里发生，观众是"看见"而不是"读到"；文字只在画面讲完之后出现一次，作为可带走的名字或结论。适合角色片、产品机制、演出。
- **文字承载论证**（推自 N4）：讲解与新闻类片，文字是静音观众唯一的通道。文字与口播说的是**同一件事**（不同时说两件），每镜只承载一个论点；文字镜头的占比由论点数决定。适合快讯、讲解、静音平台（风格词汇库 S75 社交字幕新闻是一种外观）。
- **文字就是画面**（推自 N1；风格词汇库 S27 动态排版是一种外观）：字本身是主体，字的变形、排列、出现方式就是事件。适合诗歌、歌词、宣言、引语。此时第 15.1 节"文字是第二个阅读任务"不成立，因为没有第一个任务。
- **完全无字**（推自 N6）：靠画面与声音完成全部意思。适合角色短片、氛围片、跨语言传播。条件：代表帧测试（第 6.3 节）在无字状态下仍要通过。

**用户明确要求的文字**优先于本章任何取向——那是需求，不是风格选择；取向只决定它怎么放。

**文字与表演什么时候互相替代**：当一行字和一段表演携带的是**同一个内容**时，观众会先读字——字的解码快、而且占用的是注意最优先的语言通道（N2）。读完之后，表演就降级成了这行字的插图，观众是在**核对**它，而不是从身体里**读出**它（N6）。情绪恰恰是在"自己读出来"的那一步产生的；字替观众读完了，这一步就被跳过。所以：
- 字和表演携带同一内容时，它们是替代关系，留一个（通常留表演）。
- 字和表演携带不同内容时，它们是互补关系：字擅长身体给不出的东西——名字、数字、时间、地点、出处；表演擅长字给不出的东西——怎么样、多强烈、在犹豫还是在决定。
- 判据：把这行字念出来，它说的是不是画面里那个身体此刻正在演的东西？是，就删字。
- 例外：字与表演故意说相反的话（见下文故意违反）。

### 15.4 故意违反
文字与画面说相反的话（画面里一片混乱，字幕写"一切正常"）。得到反讽，适合讽刺与黑色幽默。观众必须同时看懂两者，所以两者都要极简单。

### 15.5 失败点预判
- 给看不懂的视觉加说明文字，反而更糟（真正该修的是视觉）；每个情绪配字幕标签；讲解片完全去字，静音观众无从理解；按钮被画框切半；全片一个小角色在空旷大景里而没有理由。提前发现：每镜标出"必须读清的最小细节"并量它的高度；静音看一遍。

### 15.6 自检
- 〔测〕最小必读细节的高度 ≥ H/40（倾斜机位按压缩后算）吗？文字与必读元素离左右边 ≥ W/15 吗？
- 〔测〕必须完整的元素（字、控件、结果）被画框裁到的个数 = ?（应为 0）边缘差在 1px 到 2 倍最小必读高度之间的"差一点"对齐有几处？（应为 0）
- 每处文字，是在替代表演还是补充表演？去掉全部文字，代表帧测试还能过吗？

## 第 16 章 讲解：解释语法、证据拍法、口播对齐、术语（Q30、Q31、Q29、Q33）

### 16.1 推导
讲解的每一段都在让观众在脑子里搭一个东西（N1：观众要追踪的"变化"类型不同）。画法要和他要搭的东西同构，否则画面会让他搭出一个错的结构。画面又各自带着一种**证明主张**：截图在说"这个界面上确实有这个"，照片在说"这个东西或场面确实存在过"，图示只在说"它们是这样相关的"，生成的示意图什么都没证明。主张不同的画面互相冒充，可信度就受损（N4：观众凭真实物判断真假）。

### 16.2 解释语法：按观众要搭的东西选（Q30）
观众看解释画面时，会把**画面里的几何与视觉关系直接读成概念关系**：排在前面的读成先发生，碰到之后才动的读成被推动，大的读成多，框在一起的读成一体，同色同形的读成同类，有照片质感的读成真的（N2：这种读法几乎不花力气，所以它先于口播发生）。由此推出两件事：观众要搭的东西按"他在回答哪个问题"分六类；搭错的原因都一样——画面里某个**没打算用来表达的性质**恰好带着这种读法。

| 观众要搭的（他在回答） | 画面里承载它的性质 | 可选画法 | 什么时候搭错（那个性质被无意用上了） |
|---|---|---|---|
| **先后**（什么时候） | 阅读方向（左→右、上→下）、出场先后 | 沿一条路径依次出现；同一物依次换状态；手在做 | 本来并行的几样东西因为出场有先后、或排成一行，被读成一个接一个；排版方向和时间方向相反 |
| **依赖**（为什么） | 接触与随后的运动：碰到之后对方才动 | 一物推动另一物；撤掉一方另一方跟着垮；分岔 | 两样东西只是恰好同时动、或相邻出场，被读成谁导致谁；表示"下一步"的箭头被读成"导致" |
| **多少**（差多大） | 长度、面积、高度 | 同尺度同基线并排；同一位置前后切换；拿一个熟悉的物当尺子（S69、S70 是可能外观） | 两边尺度或基线不同；用面积表示一维的量（边长翻倍、面积成四倍，观众读成四倍）；只有一个数也画成图表 |
| **组成**（由什么构成） | 包含与边界：在一个框里 = 属于它 | 拆开再合上；剖面；局部放大再回到整体 | 只是为了排版放进同一个框的东西被读成同一个整体的部分；部分加起来画得不等于整体 |
| **归类**（属于哪一类） | 相同的颜色、形状、对齐 | 同类同色同形；把新东西拖进已有的一组 | 为好看用了同一种颜色的两样东西被读成同类；同一类东西因配色轮换被读成不同类 |
| **真假**（是真的吗） | 质感：照片颗粒、界面截图、手持晃动 | 真实截图、照片、录像，配出处类型 | 示意图、重建画面或生成图带了照片质感，被读成证据；用动效造出产品做不到的结果；轻浮的画风让真实事件被读成虚构 |

与 r4 的对照：r4 五类（先后、依赖、差别、组成、真假）在新表里都保留，但"误导"一列不再是各自列举，而是统一由"画面里哪个性质被无意用上"推出，各行的例子按这个推导重写；"差别"改为"多少"，并补了面积读法的误导；"归类"是新推出的一类。

**混用**：全片可以用几种语法，由内容的类型数决定，不定上限；但**同一段内只用一种**，否则观众要同时学两套读法（N2）。跨语法切换时，用一个承接物（第 13.2 节）把两种画法连起来——例如先后路径上的一个节点放大，变成差别画面的一边。「待实验验证」

**素材的职责**：按证明主张分工——要证明"存在"，只能用截图、照片、录像；要说明"关系"，用图示；要让人"感到"，可以用表演或生成画面，但它不能出现在证据位上。

**标注的先后**：一个标注是在说"看这里"。观众还没建立参照系（不知道这是什么页面、什么图）时，"这里"指向的是空白。所以顺序是：**先让观众认出参照系 → 再指 → 再说指的东西是什么**。例外：参照系上一镜已经建立过，指向本身可以第一个出现，作为这一镜的事件。一镜只指一处，除非意图本身就是"比"（第 16.3 节）。

### 16.3 证据与实拍素材怎么"拍"（Q31）
有真实素材时，素材就是主画面；代码画的"像截图的东西"会削弱可信度。贴在屏幕上不动的截图读作贴图。拍法从**口播要观众的眼睛做什么**推出——意图按它要求的视线行为分：
- **找**（"这页里有一个地方……"）：视线要从整体缩到一处。拍法：先给整体，再收窄到那一处，到达后停住一个 R，再标注。
- **比**（"左边这个和右边这个"）：视线要在两处之间来回。拍法：两处同时在画内，交替提亮，相机不动。
- **跟**（"从这里一路到这里"）：视线要沿一条路径走。拍法：沿路径推进或滚动，速度按第 13.4 节的阅读上限。
- **停**（口播只是在讲，没有指向）：视线不需要移动。拍法：素材静止，相机不动（或第 10.3 节的极缓呼吸）。
- **量**（"这有多大""这么多"）：视线要拿它和一个已知的东西比。拍法：引入一个尺度参照物，或拉远到能看见它和周围的比例。
- **回看**（"还记得刚才那个吗"）：视线要回到之前见过的地方。拍法：之前那一帧原样回来，再在上面做新的变化。

**素材满幅时还能怎么变**：素材已经占满画框，相机再动就要裁掉它。变化只能来自另外四处：素材内部在变（滚动、播放）；叠加层在变（标注、遮罩）；同位置同尺度地换成下一件素材（只有内容变，框不变）；拉远揭示它只是一组素材中的一件（风格词汇库 S73 调查桌、S74 档案推进是可能外观）。

**标注钉在哪个坐标上**：看它指的是什么。指的是内容里的某个东西，就钉在内容坐标上，内容滚动它跟着走；说的是整个画面的事（章节名、出处、"示意"），就钉在屏幕坐标上。标注位置从素材实测，不目测。

**两种重建取向**（「分歧·待实验」，分歧维度是是否需要深推近与多语言）：用真实截图（最可信，推近时分辨率受限）；按参考像素重建界面（可无限推近、可换语言，可信度依赖重建精度，且不得复制他人品牌身份）。

**如实申报**：找不到素材时，标为"未完成项"，不包装成"极简风格不用素材"。

### 16.4 口播与画面对齐到字（Q29）
**误差从哪里来**：识别把字认错（同音字、数字写法、专名）；识别给的词边界本身有几十毫秒的偏差；打了时间戳之后又剪了音频，剪点之后的全部时间都错位；手敲秒数。**哪种错代价大**：剪错一个真字，观众会听到缺字，无法补救；漏剪一个口水词，只是略拖沓。所以凡拿不准是口水还是字的，不剪。

**流程的三种取向**：
- **先剪后对**（推自 N4）：音频全部剪完 → 冻结 → 用稿件文字做强制对齐得到词时间 → 派生一切。剪点错位这类误差被彻底消除。适合音频能一次定稿的情况。
- **先对后剪、剪辑记账**（推自 N5）：在原始音频上对齐一次；之后每一次剪辑都记成"在哪里、删了多长"，自动把剪点之后的所有词时间平移。适合音频要反复修改、画面已经开工的情况。
- **每改必重对**（推自 N4）：每次改音频后整段重新对齐。对齐自动化后最省心，代价是每次都要重跑与复查。

**稿件与识别冲突时**：时间由音频决定，文字由稿件决定（强制对齐只用稿件的字，识别认错的字不影响时间）。但若说话人实际说的和稿件不同（加了字、改了说法），以音频为准，把稿件改成实际说出的样子；不要为了贴合稿件去剪音频。

**落点窗口**（按 E1 推导，与第 4.3 节同一前提）：画面事件要与词"同时"，而 E1 说画面略早于声音（声音落后）可容忍到约 125ms，画面略晚于声音（声音领先）只能容忍约 45ms。再各扣掉一帧作为编码与显示的抖动余量：
- 30fps：画面落点在**词起点前 2 帧到词起点前 0 帧**之间（−67ms 到 0）。
- 60fps：**前 6 帧到后 1 帧**（−100ms 到 +17ms）。换帧率时按毫秒重算：早侧 = ⌊(125ms − 1 帧)/帧长⌋ 帧，晚侧 = ⌊(45ms − 1 帧)/帧长⌋ 帧（复算见附录"r5 计算复核"E-3）。
- 判定只看窗口：画面**晚于窗口后沿**的落点不合格。30fps 的后沿就是词起点，所以 30fps 下任何晚都不合格；60fps 下晚 1 帧（约 17ms）仍在 E1 扣余量后的不察觉区间内，允许。r4 在 60fps 窗口后又写"晚于词起点一律不合格"，与窗口自相矛盾，已按推导改为以窗口后沿为准。「弱证据，待实验」（门限来自公开测试，扣一帧余量是我的选择）

**机器对账**：自动比较每个锚点的画面落点与词时间，列出超窗的锚点；手敲秒数的误差在静帧检查里看不出来。

**多语言**：画面锚在"意思对应的词"上，而不是句首；同一工程按语言读取不同的词时间，不复制工程。语序差异让画面顺序必须改变时，这一段按该语言单独排。

**句间呼吸**：由口播本身的实测停顿决定，不为凑时长人为拉开句子。

### 16.5 术语：名字怎么挂到概念上（Q33，「弱证据，待实验」：单家孤证）
名字和概念在观众脑中连起来，需要两个条件：两者**同时**在工作记忆里（一个先走了，另一个到来时无处可挂）；概念已经成形到能被当作"一个东西"（N2、N4）。所以时机不是"早一点还是晚一点"，而是"用什么办法让两者在同一刻都在场"。按这个问法推出五种：
- **让名字等概念**（推自 N3、N2）：名字先出现，作为一个没内容的问题被观众拿在手里。名字靠悬念保持在场，悬念撑不了多久，所以概念必须在同一个论点内成形，成形那一刻名字再出现一次完成连接。跨过一个论点还没填，名字已经掉出工作记忆，连接失败。适合半专业受众。
- **让概念成形时名字刚好到**（推自 N4）：用白话把概念讲到观众刚好"懂了"的那一刻——此时概念最活跃——说出名字并同时上屏，停留 ≥ 名字自己的 R。两者天然同时在场，最省力。适合普通受众。
- **事后重新叫回概念再给名字**（推自 N4、N1）：全程不点名，到结尾才给名字。这时概念早已不在工作记忆里，所以给名字的同时必须把概念**重新叫回来**——重放它最有代表性的那个画面（第 6.3 节代表帧的同类），名字贴在这个画面上。只在片尾打一行字而不叫回画面，名字挂不上。适合完全外行的娱乐片。
- **每用一次绑一次，逐步撤掉画面**（模型平时不会默认；推自 N2、N4）：名字第一次和概念一起出现后，后面每次用到这个名字，都带上概念的小图形；用到第三次左右，只留名字。每次"名字 + 图形"同时在场都是一次加固，撤掉图形之前观众已经能单凭名字叫出概念。适合一支片里同一个术语要被反复用到的讲解。
- **名字已在观众手里**（模型平时不会默认；推自 N3、N4）：受众正是在搜这个词，名字在他脑中先于片子存在，缺的是概念。开场第一眼就是这个名字，片子的任务是把它填满；名字一直在场，所以连接在概念成形时自动完成。

| r4 取向 | r5 新问法（用什么办法让两者同时在场） | 变化 |
|---|---|---|
| 先给空名字，马上填 | 让名字等概念 | 补"名字靠悬念在场、所以不能跨论点"的推导 |
| 成形那一刻点名 | 让概念成形时名字刚好到 | 保留，推导改为"概念此刻最活跃" |
| 全白话、末尾补名 | 事后重新叫回概念再给名字 | 改为必须重放代表画面，只打字不算 |
| 名字就是钩子 | 名字已在观众手里 | 推导改为"名字先于片子在场" |
| （无） | 每用一次绑一次，逐步撤掉画面 | 新问法推出的新取向 |

中文语境中英术语并列时，上屏写中文 + 原文，口播只说一种。「待实验验证」

### 16.6 故意违反
口播与画面刻意对位（口播讲 A，画面讲与 A 平行的 B），让观众自己连接两者。得到隐喻、散文感，适合观点片、影像散文。只用在观众已理解主线之后。

### 16.7 失败点预判
- 念到一个名词就推一次（给口播配节拍器）；所有段落同一种画法或每镜换一种；标注圈偏；页面滚了标注没动；时间戳后又剪音频导致全体错位。提前发现：机器对账；每段标出"观众要搭的东西"与所选语法。

### 16.8 自检
- 每段的"要搭的东西"与语法写得出吗？每处证据位上的画面，证明主张对得上吗？
- 〔测〕超出落点窗口的锚点数 = ?（应为 0）；画面晚于窗口后沿（30fps：词起点；60fps：词起点后 1 帧）的锚点数 = ?（应为 0）
- 〔测〕钉在内容坐标上的标注，与目标中心的偏差最大值 = ?（起点 ≤ 最小必读高度）术语上屏时长 ≥ 它的 R 吗？

## 第 17 章 表演：角色与界面（Q34、Q35）

### 17.1 推导
观众通过另一个身体的反应确认情绪（N6）。代码的默认是所有部件同时、同曲线、同幅度运动，这正是机械感的来源——错相与主次给出生命（N5：观众在追踪一个"活的"整体，各部位的时间差证明它是一个有内部结构的身体）。粗糙的角色比没有角色更差，观众第一眼就会把它归类为生成内容。

### 17.2 角色出不出现、出不出脸（Q34，「分歧·待实验」）
- **完整表演角色**（推自 N6）：有脸、有身体、有情绪弧。条件：精细度够得上表演——表情能在一个 R 内被认出，动作有预备与落定。适合故事片、喜剧。
- **局部角色**（推自 N6、N4）：只出现手、背影、影子或剪影。观众把自己代入，精细度要求大幅下降。适合产品、讲解、"你"作为主语的叙事。
- **物即角色**（推自 N6、N1）：一个物有了意图和反应（犹豫、退缩、跃跃欲试），但不长脸——表演全部通过运动方式完成。模型平时不会默认这样做（它会给物加脸）。适合抽象概念、品牌、需要避开"吉祥物"感的题材。
- **无角色**：主体是物、空间或系统，第 3.3 节。

### 17.3 表演的做法
**通道：观众从哪里读出情绪**。不按身体部位分，按"观众读到的是什么"分，因为同一种读法可以由不同的身体（或物）完成：
- **姿态**：重心在哪、身体收着还是展开、高还是低。连没有脸的物也有姿态（立着、歪着、塌下去）。
- **节奏**：动作的快慢、是否有停顿、是否反复。犹豫是"开始—停—再开始"，决心是"一次到位"。
- **趋避**：朝着一个东西去，还是离它远一点；靠近的速度和距离。这是物即角色最主要的通道。
- **脸**：只在出脸时可用，信息最密，也最容易做粗。
- **声音**：一口气、一声哼、一个停顿。
可读的情绪至少有两个通道在说同一件事；只有一个通道在变，观众容易读错（例如只有脸变了、身体没变，读作"换了贴图"）。没有脸的角色，用姿态 + 节奏 + 趋避三条就够。

**情绪切换：两个阶段就够**。情绪变化必须被观众看作"同一个身体在变"，而不是"换了一个"（N5）。所以切换只需要两件事：
1. **旧状态被打断**：一个可见的中断——动作停住、重心一晃、视线离开。观众知道"有什么事发生了"。打断与换形可以在同一个动作里完成（在转身、低头或一次遮挡之中换），看不见"换脸"的那一帧。
2. **新状态被读出**：新状态稳定下来、停住，停留 ≥ 新状态的 R，观众才把它登记为新的情绪。
预备、过冲、反应这些是放大器，片长与精细度允许时才加，不是必需的阶段。一帧瞬切读作换贴图。

**思考怎么被看见**：观众判断"它在想"，靠的是**输入和输出之间多出来的那段时间**。所以思考的可见形式是：刺激出现 → 角色没有立刻反应（停住、视线离开刺激、或在原地做一个小的无关动作）→ 然后才动。"想"的长度就是这段延迟。延迟越长，读作越慎重；没有延迟，读作本能。

**注意的方向先于身体**：眼睛（或物的"朝向"）先到目标，身体随后启动。领先量随角色的运动尺度定：大约等于该角色一次头部转动所用时间的一半——眼先动、头跟上、身体最后，三者错开而不是同时。「弱证据，待实验」

**错相**：左右肢不镜像；群体角色不同步，各自有起始时间和幅度的差异。

**夸张度**：短片里微妙等于没有。判据：缩到手机小窗里，姿态与表情变化是否仍可辨认。

**画不到位时怎么退**：按"保留哪些通道"逐级退——先去掉脸，保留姿态、节奏、趋避（局部角色或剪影）；仍不够，去掉身体，只留一个物的趋避与节奏（物即角色）；仍不够，去掉角色，让事件直接由物的状态差承担（第 3.3 节）。不要用粗糙的完整角色硬撑。

**反应停留**：反应是情绪被确认的地方（第 3.7 节），比事件本身停得更久。

### 17.4 界面演示（Q35，「弱证据，待实验」：单家为主）
**故事形状从"观众心里的那个怀疑"推**：看界面演示的观众默认是怀疑的（N4：他知道演示是剪过的、挑过的）。一个价值被相信，是因为它最可能招来的那个怀疑被一种证据打消了。怀疑有六种，各自只有一种证据能打消，证据的形状就是故事的形状：
- **"真的比原来好吗"→ 同一任务的前后对比**：先给旧做法（可以压缩，但要让观众数得出步数或时长），再完整给新做法。证据是两段之间的差。适合省时间、省步骤。
- **"这真能做到吗"→ 先看见做不到**：先让观众看见一个明确的失败或空白（同样的任务卡住了），再让同一个任务被完成。证据是"不可能 → 可能"的那一刻。
- **"是剪出来的吧"→ 一个不剪的连续过程**：一个不被打断的连续操作，不切、不加速，屏幕上带着能证明时间连续的东西（时钟、光标轨迹、输入过程）。证据是"中间没有藏东西"。适合手感、流畅、实时性。
- **"出错了会怎样"→ 把错误演出来并被接住**：演示一个本来会出错的操作，在出错的那一刻被界面接住（拦下、撤回、提示）。证据是一个没有发生的坏后果。适合少出错、安全。
- **"它到底改变了什么"→ 别处的后果**：操作一拍，然后切到"别处"看见后果（另一台设备、真实世界里的物、另一个人收到了），证据是界面外的变化（第 8.3 节无操作者变化的反向）。
- **"是不是只挑了好例子"→ 换几个输入连着做**（模型平时不会默认；推自 N4、N3）：同一个操作在几个明显不同的输入上连着做（不同长度、不同语言、一个难的），每个都成。证据是"不是碰巧"。节奏上它天然是第 3.5 节"同一件事做三遍"，第三个输入最难。

| r4 类型（按价值分） | r5 新轴（按要打消的怀疑分） | 变化 |
|---|---|---|
| 省时间 | 真的比原来好吗 → 前后对比 | 补"让观众数得出旧做法的代价" |
| 能做到以前做不到的事 | 这真能做到吗 → 先看见做不到 | 保留，归到怀疑 |
| 手感 | 是剪出来的吧 → 不剪的连续过程 | 推导改为"证明中间没藏东西"，补时间连续的证据物 |
| 少出错 | 出错了会怎样 → 错误被接住 | 保留，归到怀疑 |
| 操作在别处产生了后果 | 它到底改变了什么 → 别处的后果 | 保留，归到怀疑 |
| （无） | 是不是只挑了好例子 → 换几个输入连着做 | 新轴推出的新类 |

**附属元素怎么到达**：通知、提示、结果卡是"系统对操作的回应"，它们的到达本身就是因果的后半段（N1）。所以它们在触发它的那个动作完成之后到达，而且一到达就带着内容；提前空着出现，等于在原因之前给了结果的位置。到达的方式跟随平台惯例（从哪边滑入、是否带声音），因为观众靠惯例识别"这是系统在回应"。

**光标是一个人的意图**：每次移动都有目标；移动前后有短暂停靠（人会看一眼再动）；类型随悬停元素切换（箭头、手、文本）；永远不盖住它要点的文字；拍与拍之间停在不遮挡下一个目标的地方。

**平台惯例**是识别的锚点：系统级的界面元素按观众熟悉的样子画，偏离被读作"假"。演示他人产品时**只借交互、不借身份**——不使用对方的商标、品牌色与标志性外观。

一次只追一条因果：同一流程不完整播放两遍；不为讲更多而塞进第二台设备。

### 17.5 故意违反
角色完全不反应——世界在他周围崩塌，他面无表情。得到冷幽默、荒诞、疏离，适合讽刺与黑色喜剧。前提是观众已经知道"正常人会怎么反应"。

### 17.6 失败点预判
- 表情一帧瞬切；双臂镜像、群体同步；通用的圆头吉祥物讲解员；角色举牌写情绪；光标盖住按钮文字；自创配色的"仿某应用"。提前发现：逐帧检查情绪切换处是否有可见的打断；把光标路径单独画出来，检查每段移动的目标。

### 17.7 自检
- 每次情绪切换能指出"打断"和"新状态停住"两处吗？每种情绪至少有两个通道在说吗？
- 〔测〕新状态停留时长 ≥ 它的 R 吗？光标与目标文字包围盒重叠的帧数 = ?（应为 0）
- 〔测〕附属元素在触发动作完成之前出现的次数 = ?（应为 0）缩到小窗（画面宽 1/3）里姿态变化可辨吗？

## 第 18 章 补缺：原料没有回答的问题（全章「待实验验证」）

### 18.1 骨架知识缺口
- **C1 无故事片靠什么维持注意（Q1、Q15）**：用"缓慢的单调变化"替代事件——一个可见量（亮度、密度、颜色温度、相机距离）全片朝一个方向走，观众的预测（N3）对象从"接下来发生什么"换成"它会走到哪"。另加稀疏的"微事件"（一只鸟飞过、一盏灯亮起），间隔不均匀。纯氛围镜头在叙事片中的占比，起点取不超过镜头数的 1/5：超过就不再是"呼吸"，而成为片子的主体。
- **C2 氛围片要不要峰值（Q3）**：要一个"转向点"而不要峰值——单调变化在某处改变方向或速度（越来越亮之后开始暗），观众感到"到了"，但没有冲击。
- **C3 峰值位置与划走（Q3、Q6）**：同一支片做"按余波倒算"与"能多早就多早"两个版本，比较平台留存曲线在峰值前后的斜率。
- **C4 笑点密度与反转前停顿（Q2）**：反转就是一次小转折，停顿起点用第 4.3 节"空隙多长"的同一规则：≥ max(1.2 × 上一段平均事件间隔 + t, 2t)。
- **C5 口播转折句与切点先后（Q4）**：两种都试——切点在转折句之前（画面先转，口播追上来）与之后（第 11.3 节按归属判定），比较首看测试里观众复述论证的准确率。
- **C6 阅读公式校准（Q10）**：用第 9.1 节的首看暂停测试校准 t、每注视字数与 c，每类内容（文字、图像、数字）分别校准。
- **C7 节奏可感阈值（Q11）**：见 X1。
- **C8 真静止与极缓呼吸对照（Q12）**：同一口播片做两版，评审不知道差别，比较"像幻灯片"与"发抖"两类评语的出现率；另做一组极缓呼吸速度 1、2、4px/s 的版本，问评审"画面有没有在动"。
- **C9 轮换频率与片长（Q13）、病因权重（Q14）**：每修复一类病因（时间、空间、意义）就重评一次，记录哪一类的修复让评级提升最多。
- **C10 横竖屏与小窗的预算（Q16、Q27）**：竖屏与小窗里不改组数上限，而是按第 15.1 节把每组的最小必读细节重算一遍；放不下的组合并或分到下一镜。
- **C11 进场时机分布（Q17）**：一镜内的事件偏前放（开镜后尽早开始），给出点保护留出空间；与之对照的偏后放用于悬念镜头。
- **C12 承接的自动判定（Q19）**：以"边界前后两帧，无关观看者能否指出同一个东西"作为人工真值，用来校正任何自动判定。
- **C13 转场种类耐受度（Q20）、一镜到底时长（Q21）、运镜疲劳（Q23）**：都用同一方法：做递增版本，找评审评语从"流畅"转为"累"的拐点。
- **C14 二维动效中的越轴（Q22）**：二维画面里，主体的运动方向就是"轴"；连续两镜方向相反且没有转身动作，视为越轴。
- **C15 手持强度与片种（Q24）、卡拍间隔（Q25）**：手持幅度以最小文字字高为上限，按片种逐档下调到 0；大冲击的间隔不短于一个乐句。
- **C16 主轴切换的代价（Q28）**：比较有交接点与无交接点两种切换的首看复述准确率。
- **C17 词落点容差（Q29）**：做画面相对词起点 −133、−67、0、+33、+67ms 的版本，测观众能否察觉，检验第 16.4 节窗口。
- **C18 语法目录与切换（Q30）**：目录按"观众要搭的东西"开放增长；每新增一类，必须同时写出它会误导观众搭出的错结构。
- **C19 素材授权受限（Q31）**：降级顺序：自己拍摄的实物 → 有授权的素材 → 按事实重建并明示"示意" → 只用文字转述并标出处类型。每降一级，在片中如实标注。
- **C20 有字无字理解率（Q32）、术语密度（Q33）**：同一内容有字/无字两版，测静音与有声两种观看下的复述率。
- **C21 角色精细度阈值（Q34）**：判据是小窗里的姿态与表情可辨性；达不到就按第 17.3 节逐级退。
- **C22 借交互不借身份（Q35）**：保留交互的结构（点击、滑动、弹出的顺序与因果），换掉视觉身份（颜色、图标、字形、布局特征）。
- **C23 自主模式谁确认（Q36）**：第 1.4 节的盲读复述。
- **C24 结构复用的抄袭边界（Q38）**：第 2.4 节的"物 + 动作"互换判据。
- **C25 差异度量化（Q39）**：第 1.3 节的复述重合、画面错认、时间感三项。
- **C26 代表帧与封面（Q7）、结尾停留与完播（Q8）、叙事与氛围循环接缝（Q9）**：分别见第 6.3、7.2、7.3 节的推演。

### 18.2 弱证据数值的对照实验（B12）
每条写清自变量、观测量与判据。
- **X1 档位比与加速系数（第 10.2 节）**：自变量：同一内容三个版本，相邻档位比 1.2 / 1.4 / 2，加速系数 0.85 / 0.7 / 0.5。观测量：盲评"有节奏 / 平 / 乱"三选一的比例；首看复述准确率。判据：选出"有节奏"比例最高、且复述率不低于最平版本的那组参数；若 1.2 已与 1.4 无差别，下调起点。
- **X2 在场组数上限（第 11.2 节）**：自变量：同一讲解镜在场组数 3 / 4 / 5 / 6，焦点始终只有一组在动。观测量：暂停后让观众指出"刚才在讲哪个"的正确率，与报告"乱"的比例。判据：正确率开始明显下降的那个组数减一，即为上限。
- **X3 跟随滞后量（第 14.3 节）**：自变量：临界阻尼跟随的滞后 0 / 0.1 / 0.2 / 0.35s。观测量：评审对"像有人在拿 / 像机器 / 像跟不上"的判断比例。判据："像有人在拿"比例最高、且"跟不上"比例未上升的滞后量。
- **X4 真冻结的停留时长（第 7.2 节）**：自变量：末帧静止时长 = 末帧 R + 0 / 0.25 / 0.5 / 1.0s，声音尾巴相同。观测量：观看后能否复述末帧内容；是否有人报告"卡住了"。判据：复述率达到平台期、且"卡住"报告未上升的最短时长。

- **X5 声音先行的领先量（第 4.3 节）**：自变量：领先量 0 / 33 / 67 / 133 / 250 / 400ms × 两类声音（短促敲击、需辨认的人声或吸气），画面变化相同。观测量：评审对"没对齐 / 先听到一个提示 / 两件无关的事"三选一的比例。判据：对每类声音，"先听到一个提示"比例超过"没对齐"的最小领先量即为该类的 L；若敲击类的 L 明显小于 t，下调 t 一项的起点。

### 18.3 原料整体没覆盖的问题
- **D1 情节类型的多样性**：除"有人想要"与笑点外，至少还有：**散文式**（一个问题被几个不相关的画面轮流照亮，状态差在观众的理解里）；**纪录式**（时间顺序 + 真实素材，状态差是事实本身）；**蒙太奇论证**（并置两个画面让观众推出第三个意思，N3 的推理快感）；**悬疑式**（信息分批释放，每批改变观众对前一批的理解）；**清单式**（同构的几项依次出现，节奏来自项与项的差异，见第 3.5 节）。每种都过第 3.1 节的首末帧判据，只是"变了什么"可以在观众脑中。
- **D2 声画对位与反差**：画面与声音刻意不一致——欢快的音乐配灾难、平静的旁白配混乱。原理是 N3 的双通道版本：两条通道各自建立预期并互相否定，观众被迫产生第三种解读。条件：两条通道都必须各自清楚，否则只像配错了。
- **D3 真人出镜**：口播者的视线是最强的视线引导（N2）——看镜头时观众看他，看向画面某处时观众跟着看过去。可用这一点代替标注：让出镜者转头看向素材。景别按信息分工：讲观点用近景（脸是信息），演示用中景（手是信息）。手势与关键词同步，窗口同第 16.4 节。
- **D4 景别体系**：景别是"观众离事件多近"，按第 15.2 节"能装下当前关系全部参与者的最紧一档"选。相邻两镜景别跳一档以上读作"跳"，几乎一样的两个景别相接最难看（读作"抖"）。这是第 12 章排布层轮换在景别上的应用。
- **D5 悬念与信息差**：观众知道而角色不知道 → 紧张（观众在等角色发现）；角色知道而观众不知道 → 好奇（观众在等揭示）。前者的设计是先给观众看危险，再看角色毫不知情；后者是让角色对画外某物反应，但不给观众看。
- **D6 系列化叙事**：在同一账号的多支片之间保留一个**识别母题**（一个开场的动作、一个反复出现的物），同时按第 1.3 节的差异测试保证每支片的结构不同。母题是"同"的部分，结构是"异"的部分，二者分开。
- **D7 竖屏叙事**：见第 15.2 节；另外竖屏的视线天然自上而下扫，因果可以写成上因下果，叙事方向是纵向的。
- **D8 中文语境**：中文的信息密度高（同样时长装更多意思），第 9.1 节"每注视约 2 字"应单独校准；中文笑点大量依赖谐音与字面，画面可以用"字面化"（把一个词的字面意思画出来）作为一种解释语法。
- **D9 平台数据**：书中所有关于开场、片长、节奏的起点值都应在积累播放数据后回填。记录方式：每支片记下它在本书各章选了哪个取向，与留存曲线一起存档，累积到同一取向有多支片后再比较。

1. 观众对切点的感知不是"它在第几帧"，而是两件事：这一段有多长（与前后段比），以及它和声音的关系。绝对帧号本身观众感知不到——整支片晚一帧开始，没有人看得出来。所以验收不应比绝对帧号，而应比段长与声画关系；整体平移不扣分。

3. 声画关系：按 E1，画面早于声音可容忍到约 125ms、晚于声音约 45ms；扣一帧抖动余量后，30fps 下为"早 ≤ 2 帧、不晚"。
4. 两片帧率不同时，"0 帧"无法定义（两边的帧不对齐），只能换成秒比较——这也说明"0 帧"不是一个可执行的判据。
